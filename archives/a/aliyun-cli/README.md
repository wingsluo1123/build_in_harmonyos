# aliyun-cli

Alibaba Cloud CLI — command line tool for Alibaba Cloud services.

## Overview

The Alibaba Cloud CLI is an open source tool to manage and use Alibaba Cloud resources through a command line interface. It is written in Go and built on top of Alibaba Cloud OpenAPI.

## Versions

| Version | Status  | Notes                         |
|---------|---------|-------------------------------|
| 3.4.11  | built   | Adapted for HarmonyOS (arm64) |

## Build System

- **Language**: Go
- **Build**: `go build`
- **Dependencies**: Go module dependencies (managed via go.mod)
- **Submodule**: aliyun-openapi-meta (metadata for Alibaba Cloud APIs)
