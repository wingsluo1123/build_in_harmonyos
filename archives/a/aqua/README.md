# aqua

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Declarative CLI Version manager. Support Lazy Install and Sharable configuration mechanism named Registry. Switch versions seamlessly.

## Build System

- **Language**: Go
- **Build**: `go build -trimpath -ldflags="-s -w -X main.version=v2.60.0" -o aqua ./cmd/aqua`
- **CGO**: Disabled (pure Go)
- **Entry point**: `cmd/aqua/main.go`
