# ax25-apps

AX.25 amateur radio protocol user programs for HarmonyOS PC (aarch64).

## Description
ax25-apps provides the following user-space programs for the AX.25 amateur radio protocol:
- **call**: Connect to an AX.25 station
- **listen**: Listen to and dump AX.25 traffic
- **ax25ipd**: AX.25 over IP daemon
- **ax25rtd**: AX.25 routing daemon
- **ax25rtctl**: Control utility for ax25rtd
- **ax25mond**: AX.25 monitor daemon

## Dependencies
- libax25/0.0.12-rc5
- ncursesw
- libiconv (for call binary)
