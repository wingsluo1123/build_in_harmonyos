# bandwhich

Display current network utilization by process, connection and remote IP/hostname.

## Versions

| Version | Status | Build System | Dependencies |
|---------|--------|--------------|--------------|
| 0.23.0 | built | cargo (Rust) | libpcap/1.10.6 |

## Description

bandwhich is a CLI utility for displaying current network utilization by process, connection and remote IP/hostname. It is written in Rust and uses the pnet crate for packet capture.
