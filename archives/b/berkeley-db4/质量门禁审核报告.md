## 补充说明

### 适配过程中解决的问题

1. **sha256 哈希值不匹配**：更新为实际计算值
2. **补丁文件不完整**：移除了格式错误的 0004-dist-configure.patch
3. **HMDFS 临时目录权限问题**：在 conanfile.py 中用 Python 代码全局替换 configure 脚本中的 `umask 077` 为 `umask 022`，解决 HMDFS 文件系统 setgid 位导致的权限问题
4. **C++ 代码兼容性问题**：禁用 C++ 支持（`--disable-cxx`），因为 Berkeley DB 4.8.30 的 C++ 代码与现代 libcxx 不兼容

### 已知限制

- 禁用了 C++ API 支持，仅保留 C API
- 禁用了 SQL 支持（configure 警告：unrecognized options: --enable-sql）
- 编译时有一个关于 `jobserver mkfifo` 的警告（HMDFS 文件系统限制），但不影响功能
