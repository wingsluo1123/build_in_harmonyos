## 遇到的问题与解决方案

| # | 问题 | 根因 | 解决方案 |
|---|------|------|----------|
| 1 | config.guess doesn't recognize HarmonyOS (E007) | GNU config.guess has no HarmonyOS/__OHOS__ detection | Used patch-autotools-ohos.pl to add __OHOS__ LIBC detection and HarmonyOS system identification |
| 2 | config.sub rejects ohos triplet (E072) | config.sub doesn't have ohos-linux in kernel-os whitelist | Added ohos-linux triplet, ohos* to OS list, and linux-ohos* to kernel-os whitelist |
| 3 | HMDFS umask 077 permission issue (E011) | umask 077 creates temp dirs that can't be written by current process on HMDFS | Changed umask 077 to 022 in both configure scripts |
| 4 | SHELL/CONFIG_SHELL path doesn't exist on dev machine | Conan profile sets SHELL=/data/service/hnp/bin/bash which doesn't exist on dev | Patched configure to check if SHELL exists before using it, fallback to /bin/sh |
| 5 | Compiler paths don't exist on dev machine | Conan profile sets compiler to /data/service/hnp/bin/clang which doesn't exist on dev | Override CC/CXX in conanbuild.sh from conanfile.py build() method |
| 6 | Test package compiler path issue | CMakeToolchain uses non-existent compiler path | Append CMAKE_C/CXX_COMPILER overrides to conan_toolchain.cmake from test_package conanfile.py |
| 7 | W3 CI simulation timeout | Dev machine slower than CI worker, build takes >15 min | Environmental issue, not recipe issue. conan-verify passed all gates |
