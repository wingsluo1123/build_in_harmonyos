# ffmpeg2theora

ffmpeg2theora is a command-line tool that converts various media formats (via FFmpeg)
to Ogg Theora video and Ogg Vorbis audio.

## Build System
- SCons (Python-based build system)

## Dependencies
- ffmpeg (libavcodec, libavformat, libavutil, libswscale, libswresample, libavfilter, libavdevice)
- libtheora (theoraenc, theoradec)
- libvorbis (vorbis, vorbisenc)
- libogg
