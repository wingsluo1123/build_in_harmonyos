# FlitCore 4.1.0 for HarmonyOS PC

Official self-bootstrapping Flit backend with published target Python3.12.9.1, pytest9.1.1 and testpath0.6.0. The seven original test programs retain the complete219 parameterized case inventory:218 applicable pass and one original Python-version guard is explicitly accepted as not applicable. Original test and backend source bytes are retained.

Three installed-backend consumers build and inspect a wheel with verified RECORD and installed API, a real sdist and a PEP660 editable wheel. One independent HarmonyOS test compares actual mapped-UID HMDFS source with same-UID0700 POSIX source, requiring identical backend-generated wheel bytes in owned POSIX output. Official bootstrap_install.py installs the wheel into the Conan package.

Formal W3, exact-HEAD platform CI, Review and submission are checked separately.
