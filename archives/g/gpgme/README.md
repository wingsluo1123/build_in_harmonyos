# GPGME GnuPG Library

> GnuPG Made Easy - library for GPG operations

## 简介
GPGME (GnuPG Made Easy) is a library for accessing GnuPG functionality from applications.

## OHOS 适配要点
1. Requires gnupg and libassuan
2. Library only, provides API for applications

## 依赖
| 依赖 | 版本 | 说明 |
|------|------|------|
| gnupg | 2.5.20 | GnuPG |
| libassuan | 2.5.7 | IPC library |
