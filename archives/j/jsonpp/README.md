# jsonpp

**A fast command line JSON pretty printer written in Go.**

## Description

jsonpp is a command-line tool that pretty-prints JSON data. It can:
- Format JSON from stdin (pipe) or files
- Handle multiple JSON objects in a single stream
- Format already pretty-printed JSON with the `-s` flag
- Customize indentation via the `JSONPP_INDENT` environment variable
