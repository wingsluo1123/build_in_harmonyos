# kaldi-vosk

Kaldi fork used by Vosk, upstream https://github.com/alphacep/kaldi.
This archive is distinct from `kaldi` (kaldi-asr upstream) and `vosk-api`.

The g20231219 recipe targets HarmonyOS PC armv8 native CPU computation and
Linux comparison builds. It retains 22 CPU library modules, OpenFST, OpenBLAS
and LAPACK, with all 125 registered upstream CPU test programs.

See [g20231219/notes.md](g20231219/notes.md) for the pinned source, changes,
scope and validation status. Consumers can use `find_package(kaldi-vosk CONFIG)`
with `Kaldi::online2`, `Kaldi::matrix`, individual `Kaldi::<module>` targets or
the aggregate `kaldi-vosk::kaldi-vosk` target generated by Conan.
