# kubent (Kube No Trouble)

## 概述
kubent (Kube No Trouble) 是一个开源工具，用于检查 Kubernetes 集群中已弃用 API 的使用情况。
它支持从集群、文件、Helm v3 等多种来源收集资源信息，并基于 Rego 规则检测使用了已弃用 API 的资源。

- 上游仓库: https://github.com/doitintl/kube-no-trouble
- 许可证: MIT
- 构建系统: Go (go build via Makefile)
- 语言: Go
