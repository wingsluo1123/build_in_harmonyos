# lcdf-typetools

LCDF Typetools is a bundle of programs for manipulating PostScript Type 1 and OpenType fonts. It includes:

- **cfftot1**: Convert PostScript CFF (Compact Font Format) fonts to Type 1 format
- **mmafm/mmpfb**: Create multiple-master Type 1 font instances from AMFM files
- **otfinfo**: Print information about OpenType fonts
- **otftotfm**: Generate TeX font metric and encoding files from OpenType fonts
- **t1dotlessj**: Create Type 1 fonts with a dotless j
- **t1lint**: Check Type 1 fonts for errors
- **t1rawafm**: Generate AFM font metric files from raw Type 1 fonts
- **t1reencode**: Reencode Type 1 fonts
- **t1testpage**: Create test pages for Type 1 fonts
- **ttftotype42**: Convert TrueType fonts to Type 42 format
