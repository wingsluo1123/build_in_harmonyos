## Conan-specific closure

Conan owns source download and SHA-256 checks, patch application, CMake
toolchain and installation. Native OHOS linker rules provide SONAME/runtime
flags without faking Linux identity or successful compiler/thread probes.
musl-fts is a test-only requirement; VirtualRunEnv plus recipe-declared private
test directories are sufficient for complete execution. No outside runner
injects signed dependencies or a hidden runtime library path.

The installed public consumer exercises Blocks, 64-bit callbacks, atomic
completion, queue/group, once, monotonic timers and data mapping. Both native
linkage modes passed. Packaging/signing and ABI evidence are in the report.

## CI93083: original worker TMPDIR is not a DAC capability

The current a10e2171 worker reached 36/37 tests: its saved TMPDIR still allowed
creation inside a chmod(000) directory. The earlier repair was insufficient on
this filesystem, despite its real PASS on another native device. Do not reuse
that PASS as evidence for this successor.

The recipe now examines the original absolute TMPDIR and application-sandbox
temp/cache candidates. In a unique owned mkdtemp directory, exclusive creation
must return exactly EACCES after chmod(000), then succeed after restoring0700.
Only such a root is passed to the existing C fixture. Each probe is cleaned;
existing parent permissions are never changed. All candidates failing is a
hard error. The original C synchronous/asynchronous EACCES and 256-byte
unwritten-data assertions remain unchanged, as do all15 source patches.

## Native timing-fixture failures discovered during this repair

Released r10 static observed submission peak9/expected10; released r11 shared
observed315/320 dispatch_read deliveries while all10240 bytes arrived. Both
transactions remain FAIL, even though the permission case passed and independent
finish r8 completed with RC0. Fixed10ms sleeps cannot establish either full
overlap or one-read-callback-per-pipe-write on a loaded scheduler.

dispatch_concur.c now uses a bounded semaphore rendezvous before submission
callbacks may finish; the expected width, work count, queue hierarchy and

10240-byte assertions. Either readiness wait timing out is a real failure;
no expected value is reduced. Only the two corresponding source patches are
regenerated, via the official refresh-patch generator, without reorganizing
the patch set. Fresh native verification must bind these successor bytes.
