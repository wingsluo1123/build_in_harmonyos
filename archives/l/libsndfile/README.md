# libsndfile

libsndfile 是一个用于读写包含采样音频数据文件的 C 库。

## 描述

libsndfile 提供了一套标准的 API，用于读取和写入多种音频文件格式，包括 WAV, AIFF, AU, FLAC, OGG/Vorbis 等。
