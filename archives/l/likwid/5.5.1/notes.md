# likwid 5.5.1 - OHOS adaptation notes

Upstream: https://github.com/RRZE-HPC/likwid tag `v5.5.1`
(sha256 `25c7830e63b20396fcfc3b16ae79c39b4220a86d376ceb7cd6949b5ff991db78`).

## Build configuration

`make COMPILER=CLANGARMv8 ACCESSMODE=perf_event BUILDFREQ=false`, with
`CC/CXX/AR/AS` from the Conan toolchain and the bundled hwloc 2.9.3 / Lua 5.4.
`HAS_MEMPOLICY`, `HAS_SCHEDAFFINITY` and the glibc version are pinned because
the upstream `config_checks.mk` probes (`ldd --version`, `uname -r`) do not
work on OHOS ("HongMeng Kernel ..." breaks the version parse).

## Patches

1. `0001-ohos-clang-portability.patch`
   - `-Dstatic_assert=_Static_assert`: `ext/cwisstable` is C11 while the build
     uses `-std=c99`.
   - `src/includes/pthread_affinity_compat.h` (generated by the recipe) is
     force-included; bionic has no `pthread_[sg]etaffinity_np`, so the helpers
     are mapped onto `sched_[sg]etaffinity(0, ...)` (likwid only ever pins the
     calling thread).
   - `src/topology.c` `cpu_count()` used glibc's private `__cpu_mask`
     `cpu_set_t` layout; replaced with a portable `CPU_ISSET` loop.
   - `bench/likwid-bench.c`: bionic has no `_SC_LEVEL1_DCACHE_LINESIZE`.

2. `0002-ohos-hwloc-sysfs.patch`
   - `ext/hwloc/.../config.h`: disable `HAVE_DECL_PTHREAD_[SG]ETAFFINITY_NP`,
     `HAVE_PROGRAM_INVOCATION_NAME` and `HAVE___PROGNAME` (all glibc-only).
   - `ext/hwloc/hwloc/topology-linux.c`: `check_sysfs_cpu_path()` required
     `core_siblings` + `thread_siblings`; OHOS only exposes
     `core_siblings_list` / `thread_siblings_list`, so hwloc aborted CPU
     discovery and fell back to a single PU.  Accept either pair.

3. `0003-ohos-no-package-mempolicy.patch`
   - `src/topology_hwloc.c`: hwloc builds no Package/Socket object on OHOS
     (`physical_package_id` is not turned into an object), so fall back to a
     PU object for CPU identity instead of failing with `-EFAULT`.
   - `src/numa_proc.c`: OHOS seccomp kills the `get_mempolicy()` syscall with
     SIGSYS (exit 159) instead of returning `ENOSYS`; use `virtual_numa_init()`.

## Runtime

- `likwid-topology` works: 20 HWThreads, 6 sockets, 8 cores/socket, 1 NUMA
  domain, CPU "HUAWEI KirinX90".
- `likwid-pin -c 0 <cmd>` works (pins via `sched_setaffinity`).
- `likwid-bench -h` works (the aarch64 benchmark assembly is generated by the
  bundled perl Template toolkit and assembled with clang).
- Counter measurement (`likwid-perfctr`, `likwid-powermeter`) cannot run:
  OHOS denies `perf_event_open` and there is no `/dev/cpu/*/msr`.

## Build-environment shims

- `cpp`: likwid-bench's `bench/perl/AsmGen.pl` shells out to a bare `cpp`;
  OHOS has none, so the recipe provides `cpp` -> `clang -E`.
- `install`: OHOS toybox has no `install`; the recipe provides a minimal
  `install` (handles `-m`, `-d`, and file-to-file / file-to-dir copies).
