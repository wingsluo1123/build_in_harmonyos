# mdBook

## Description

mdBook is a command-line tool to create books with Markdown. It is written in Rust and is designed to be fast, efficient, and easy to use. Like GitBook but implemented in Rust.

## Homepage

https://github.com/rust-lang/mdBook

## Build System

- **Type**: Cargo (Rust)
- **Build command**: `cargo build --release --target aarch64-unknown-linux-ohos`
- **Dependencies**: Cargo manages all Rust dependencies internally; no external Conan-level dependencies needed.
