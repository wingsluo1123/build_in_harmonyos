# MIR 1.0.0 native OHOS ARM64 adaptation notes

## Source changes

- Configure the thread probe from the same compiler used by GNUmake; retain the upstream parallel frontend mode.
- Resolve OHOS libc using `/system/lib64/libc.so` in the frontend and bytecode drivers.
- Discover native compiler system include roots for C2MIR; use OHOS/musl macros, unsigned wchar_t and a matching typedef guard. Declaration attribute/asm annotations are compatibility-only; this is not general GNU extension support.
- Correct the stale public API calls in three upstream C fixtures. No original return-value assertions or expected exit codes are removed.
- Use a checked TMPDIR/mkstemp serialization round trip; preserve real write/read/content comparisons.
- Include generated bootstrap tables from the out-of-source build directory.
- Keep every native architecture/option filter and verify stdout, stderr and exit codes; replace unsupported Toybox diff `-p` with the equivalent supported unified diff presentation.
- Fix actual ARM64 code emission in both invisible lazy callback wrappers: preserve full q8-q15 rather than trusting the C ABI's lower-half guarantee, reverse the push/pop order correctly and retain 16-byte SP alignment and the old r10 save-slot offset.

All 14 source patches are generated by the prescribed `refresh-patch --auto`; no hand-written patch representation is substituted. The hand-authored GNUmakefile and embedded target-header sources are SOURCE inputs, not generated build output.
