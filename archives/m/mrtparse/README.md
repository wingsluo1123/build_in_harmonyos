# mrtparse

mrtparse is a Python library for MRT routing records, licensed under Apache-2.0.
The 1.6 candidate repairs consumption of the four-byte BGP4MP_ET timestamp before
delegating the remaining payload to the shared BGP4MP decoder.

The candidate includes the unmodified upstream examples and all 12 sample inputs.
It exports a Python module through PYTHONPATH and does not install a CLI.
Host and H1-002 OpenHarmony target evidence is summarized in `1.6/notes.md`: 5
consumer methods and 12 original sample comparisons passed, as did official local
W3 and the real library-removal negative check. Reports and logs stay in the
author local evidence. The bounded internal Conan pure-library readiness decision
reuses these results; original complete finish rc1 is retained. Software README/PF9,
formal review and actual platform delivery conditions remain pending. This is a locally prepared candidate, not a published package or completed
contest submission.
