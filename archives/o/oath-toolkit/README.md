# oath-toolkit

OATH Toolkit — one-time password (OTP) library and tools.

Provides:
- **liboath**: OTP library (HOTP/TOTP RFC 4226/6238)
- **libpskc**: PSKC library (RFC 6030, depends on libxml2)
- **pam_oath**: PAM module for OTP authentication (depends on linux-pam)
- **oathtool**: CLI tool for OTP generation and validation
- **pskctool**: CLI tool for PSKC document management

Homepage: https://oath-toolkit.codeberg.page/
