# ocaml-re (re)

Pure OCaml regular expression library with Perl / Posix / Emacs / Glob /
Str-compatible syntaxes.

- Homepage: https://github.com/ocaml/ocaml-re
- License: LGPL-2.1-or-later WITH OCaml-LGPL-linking-exception
- Conan package name: `ocaml-re` (distinct from the unrelated C library
  packaged as `re/4.9.0` in this registry)
- Ships an empty `seq` findlib stub (Seq is part of the OCaml >= 4.14
  Stdlib; required by this library's META).
