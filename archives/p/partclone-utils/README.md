# partclone-utils

Utilities for partclone image files, including:
- **imagemount** - Mount partclone images via NBD
- **partclone_imageinfo** - Display partclone image information
- **ntfsclone_imageinfo** - Display ntfsclone image information
- **cfchanges** - Partclone change file tool
- **cfdump** - Partclone change file dump tool

Homepage: https://github.com/vasi/partclone-utils
