# plotsauce

plotsauce 是 Cavewhere 生态的 Qt5 命令行工具，将 Survex .3d 洞穴勘测数据文件
转换为（gzip 压缩的）XML 文档。

- 上游仓库: https://github.com/Cavewhere/plotsauce
- 许可证: GPL-2.0-or-later（vendored survex img.c 亦为 GPL-2.0-or-later）
- 类型: 命令行工具（commands.json 已声明）
- 上游构建系统: QBS（本仓配方以 CMake 补丁改写，先例: dewalls/1.0.0）
