# pure-ftpd

Free, secure, production-quality and standard-conformant FTP server.

## Versions

| Version | Status | Build System | Dependencies |
|---------|--------|--------------|--------------|
| 1.0.52-r0 | built | autotools | openssl/1.1.1w |

## Description

pure-ftpd is a free (BSD-2-Clause), secure, production-quality and standard-conformant FTP server. It doesn't provide useless bells and whistles, but focuses on efficiency and ease of use.

## Features

- TLS/SSL support (via OpenSSL)
- Virtual users (PureDB)
- External authentication modules
- Bandwidth throttling
- Upload/download ratios
- Disk quotas
- Per-user concurrency limits
- Virtual hosts
- Virtual chroot
- Directory aliases
- Upload script support
- Fortune cookies
- Alternative log format (Apache-like)
