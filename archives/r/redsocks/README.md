# redsocks

Transparent TCP-to-proxy redirector. Redirects TCP connections to SOCKS4/SOCKS5/HTTP-connect proxy.

## Versions

| Version | Status | Notes |
|---------|--------|-------|
| 0.5 | built | Adapted for HarmonyOS PC (aarch64), conan recipe with libevent dependency |

## Dependencies

- libevent/2.1.12
