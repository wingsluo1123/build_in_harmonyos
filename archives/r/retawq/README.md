# retawq

retawq is a text-based web browser that runs in a terminal. It supports HTTP/HTTPS/FTP/NNTP protocols, cookies, threading, and can be used as a local CGI runner.

- Homepage: https://retawq.sourceforge.net/
- License: GPL-2.0
- Build system: custom (itchconfig)
- Dependencies: ncurses/6.6, openssl/1.1.1w
