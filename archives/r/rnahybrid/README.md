# RNAhybrid

`rnahybrid/2.1.2` installs `RNAhybrid`, `RNAcalibrate`, `RNAeffective`, their man pages and official examples.
This is the libm-only computation variant; optional g2/gd graphical output is not provided.

The recipe executes upstream `make check` (zero registered tests). The consumer runs eight functional cases using the installed programs and official FASTA/frequency inputs.
