## 软件简介
scdoc 是一个简单的 man page 生成工具，使用自定义的标记语言编写，可以生成标准的 roff 格式 man pages。

## 编译步骤

scdoc 使用简单 Makefile，无需 configure 步骤：

```bash
# 下载并解压
tar xzf scdoc-1.11.3.tar.gz
cd scdoc-1.11.3

# 编译
make CC=clang -j1

# 运行测试
make check

# 安装
make install DESTDIR=$PREFIX PREFIX=
```

## 遇到的问题与解决方案

| # | 问题 | 根因 | 解决方案 |
|---|------|------|----------|
| - | 无问题 | - | 1.11.3 已修复 1.11.0 的所有已知问题 |

### 与 1.11.0 的差异
1. **str_create() 函数原型**: 1.11.0 中 `str_create()` 空参数列表触发 -Wstrict-prototypes 警告，1.11.3 已修复为 `str_create(void)`
2. **install 命令**: 1.11.0 中 `install -m755` 在 toybox 上失败，1.11.3 仍使用此格式但 OHOS `/system/bin/install` 兼容
3. **Makefile DESTDIR**: 1.11.3 的 install 目标增加了 `$(DESTDIR)` 前缀，支持 staging 安装
