# sigutils

`sigutils` (BatchDrake/sigutils) is a digital signal processing utility
library for SDR applications: NCQO oscillators, PLL / Costas loops, AGC,
IIR filters, channel detectors, specttuner and Matlab `.mat` file I/O.
LGPL-3.0-or-later, shared library, pkg-config name `sigutils`.
