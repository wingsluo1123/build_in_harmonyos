# Tang 15 HarmonyOS adaptation notes

- Upstream: `latchset/tang` tag `v15`, commit `02105756ee2a3afbd7065a47664d202788c9b584`.
- Runtime dependencies: published `jose/15` and `http-parser/2.9.4`.
- Build/test tools are explicitly declared: `meson/1.11.0`, `ninja/1.13.2`, `pkgconf/3.0.6`, `jose/15`, and `socat/1.8.1.3`. The consumer test also declares `jose/15`, because `tangd-keygen` invokes the jose CLI from `PATH`.
- A fresh Conan home downloaded the declared host and tool packages from `ohpcd`. The Registry API lists the direct dependencies and all five tool requirements. The transitive `jansson/2.15.1.1` and `openssl/3.5.8.1` API rows have no public `webUrl`/`registryAddress`, but Conan downloaded their exact binaries from `ohpcd`.
- Meson now accepts Conan's `http-parser` pkg-config dependency while retaining the original system-library lookup for non-Conan builds.
- Meson receives the packaged `pkgconf` path in its native machine file; the archiver and ranlib are set to absolute SDK paths. The worker's process-capable Ninja is selected through `NINJA`: the published Conan Ninja binary returns `posix_spawn: No such file or directory` when asked to launch any child on OHOS.
- CI-039 #88474 failed before checkout because its worker could not spawn `curl` or `wget`. CI-027 #88870 installed its dependencies, then failed to start `meson setup` with `Errno 11` and no Meson output (worker process exhaustion). A later CI-038 #89256 setup failed to resolve bare `llvm-ar`; the absolute archiver path is now injected.
- The complete nine-test upstream Meson suite runs serially. The test compatibility patch gives the tests a writable build-tree `TMPDIR`, and uses Python socket/entropy fallbacks where HarmonyOS does not provide `ss` or `shuf`. `socat` remains present so all four socat integration tests execute.
- Compilation is capped at two jobs, tests run at one job, and `wrap_mode=nodownload` disables implicit subproject fetches. The project has no upstream subprojects.
- Meson's `install` target relinks `tangd` on the device, invalidating the ELF code signature generated by the OHOS linker; `package()` copies the already-tested executable and generated scripts byte-for-byte instead.
- The independent consumer check executes the packaged `tangd-keygen`, `tangd`, and `tang-show-keys` binaries/scripts, and checks generated key permissions and the advertised key file.
- Device result in an independent Conan home: `conan create` exited 0 with `tools.build:jobs=2`; all 9 upstream Meson tests passed with 0 skipped, and the consumer test passed 1/1. The final test run reused the source and binaries fetched by that initially empty home after a separate empty-home attempt hit GitHub connection timeouts.
