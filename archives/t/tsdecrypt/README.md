# tsdecrypt

tsdecrypt is a command-line MPEG transport stream decryptor with UDP/RTP input,
file or multicast output, constant control words, and CAMD client support.

The HarmonyOS PC package installs the signed `tsdecrypt` executable and its
manual page. The `10.0` recipe uses the published OpenSSL and libdvbcsa Conan
packages and retains the upstream command-line feature set.
