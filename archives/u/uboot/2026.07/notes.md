# uboot/2026.07 适配笔记

## 选型与目标

- 上游：Denx U-Boot v2026.07 官方发行包（ftp.denx.de，sha256 78e8bfc3...）。
- 两个 Kbuild 目标：
  - `sandbox_defconfig` — U-Boot 编译为**宿主 userspace 二进制**。上游把
    全部 C 侧单元测试编译进该目标（`u-boot.sym` 链接器列表符号
    `_u_boot_list_2_ut_<suite>_2_<name>` 口径共 **919** 个子测试，与上游
    `test/py/conftest.py:39` 枚举正则一致；2 个 `_norun` 条目按
    conftest.py:394 收集期排除），
    无需 QEMU/开发板即可在构建产物上逐子测试独立进程全量执行（上游
    pytest 同款；单进程 `ut all` 有跨用例状态污染，上游不裸跑）；配套 host 工具
    mkimage/dumpimage/fit_info/mkenvimage/fdtgrep 为包内 CLI 产物。
  - `qemu_arm64_defconfig` — 真实 aarch64 固件（u-boot.bin），OHOS 上
    以 clang 原生构建（显式 `HOSTCC=clang CC=clang`，见决策表第 1 条）。
- 上游另一测试面 test/py pytest 套件（tests/ 85 文件 296 个 `def test_*`，
  按 sandbox_defconfig 收集 619 例）：其夹具依赖 Linux 宿主能力（mount、
  `mkfs.vfat -d`、debugfs、sgdisk）与 openssl 可执行文件，且受"上游测试
  文件零修改"约束，设备侧不执行 pytest 本体；等价覆盖 = 块级重建夹具
  （mkfixtures.sh）+ 上游同枚举口径逐子测试全量（919/919，即 pytest 在
  Linux 上会逐一展开执行的同一批 `_u_boot_list_2_ut_*` 子测试）（见
  「验证记录」）。
