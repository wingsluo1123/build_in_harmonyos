# valgrind

valgrind — 动态二进制插桩框架 / 内存调试工具集。

上游主页: https://valgrind.org/
上游源码: https://sourceware.org/pub/valgrind/

## 适配版本

| 版本 | 状态 | 说明 |
|------|------|------|
| 3.24.0 | published | OHOS PC/aarch64 适配，见 3.24.0/notes.md |

## 工具集

memcheck（内存检查）、helgrind（线程检查）、drd（数据竞争检测）、massif（堆剖析）、callgrind（缓存剖析）、cachegrind（缓存模拟）、lackey、exp-bbv、dhat（堆块剖析）。
