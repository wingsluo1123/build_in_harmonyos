## 覆盖范围

- 三个安装命令在被测 Conan 包中的存在性、可执行性和无副作用版本探针，拒绝 PATH
  上系统同名命令造成假绿。
- 64 字节有限文件输入的 EOF 状态机：进程成功退出、恰好一个 UDP 数据报、样本数、
  非零帧号及载荷逐字节正确；原始上游隔离构建在相同输入上实测 rc=234。
- 以目录作为文件后端输入稳定触发读取错误，断言错误不会被当作 EOF 成功吞掉，且不会
  发送任何数据报。
- `vban_sendtext` 成功退出码及独立接收的黄金 UDP 报文：魔数、格式字节、流名零填充、
  32 位小端帧号和文本载荷逐字节校验。
- Python 独立构造含非对称帧号字节的黄金音频报文并交给真实 `vban_receptor` 解码，验证
  接收端不依赖发送端的同源序列化实现，且 PCM 载荷逐字节保持不变。
- 文件后端经 UDP 的 4096 字节 PCM 原样回环及输入 EOF 正常退出。
- 文件后端测试把短设备名传给 CLI，并将子进程工作目录固定到隔离测试目录，避免上游
  64 字节设备名字段截断不同 Worker 的绝对临时路径；实际读写仍由真实文件后端完成。
- HarmonyOS `TMPDIR`/HMDFS 命名管道能力分支：支持 FIFO 时执行真实回环；目标文件系统
  返回权限错误时，验证非零退出、诊断使用 `$TMPDIR/vban_0` 且无残留。

测试不依赖真实声卡或音频服务，但构建仍完整保留上游默认的三种音频后端。

## 已知环境事项

已发布的 PulseAudio 17.0.1 共享库缺少当前 HarmonyOS 加载器要求的 `.codesign` 节。
测试配方把依赖运行库复制到任务私有目录，去除副本可能携带的旧签名后统一重新签名，
并验证每个副本只有一个新 `.codesign`；未修改制品仓依赖或待发布包。
HMDFS 不支持创建 FIFO 时，测试执行并验证该平台能力失败路径，不把限制记为跳过或成功。
