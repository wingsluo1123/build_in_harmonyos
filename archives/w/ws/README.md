# ws（IXWebSocket）

WebSocket/HTTP 客户端-服务端库 + `ws` 命令行工具（Alpine Linux 同名包的命名约定）。
上游 <https://github.com/machinezone/IXWebSocket>，BSD-3-Clause。

本目录是鸿蒙 PC（OHOS, arm64）适配归档：每个版本一个子目录，内含 conan 配方
（conanfile.py + conandata.yml + 补丁）与 test_package 消费者测试。
