## 补充说明

上游程序紧密绑定 Wayland client、XKB 和虚拟键盘协议，没有可直接复用的跨平台输入/显示抽象，符合高难度标准中的“强绑定操作系统接口、无跨平台抽象层”。移植保留布局与修饰键行为，以小型可移植 C core 承载行为；系统输入、显示及会话由 HarmonyOS Stage 输入法扩展、IMEKit 和 ArkUI 实现。
