§E. `session_ctrl` 入口的可执行性差分探针
------------------------------------------------------------------------------
$ make -j1 -C src/xitk session_ctrl
  PASS —— 产出 27008 字节 ELF arm64 动态可执行文件（校验交叉编译与链接）
$ src/xitk/session_ctrl 0
  rc=159（128+31=SIGSYS），零输出

独立探针（与 xine-ui 无关，证明是平台系统调用策略而非适配缺陷）：
  setuid(geteuid())            -> rc=0，进程存活
  setreuid(getuid(), getuid()) -> rc=159（SIGSYS），进程被终止

调用点归属（源码实测）：
  51:int connect_to_session(int session) {
  src/xitk/session_common.c:66-70
    
        snprintf(saddr.un.sun_path, sizeof(saddr.un.sun_path), "%s%s%d", (xine_get_homedir()), "/.xine/session.", session);
        if (setreuid(stored_uid, euid) == -1)
          perror("setreuid() failed");
    #ifdef SUN_LEN
  38:  if((fd = connect_to_session(session)) == -1)   # ctrl_test.c 的 main 调用它

=> `session_ctrl` 在鸿蒙 PC 上只能编译、不能执行，故配方 build() 只构建不运行；
   该入口计入「实测 2 次调用（编译 + 运行尝试）」，运行结果按平台事实记录，不计失败用例。
