# yabasic

Simple BASIC interpreter for OpenHarmony (aarch64).

## Available Versions

| Version | Status | Date |
|---------|--------|------|
| 2.91.4  | built  | 2026-06-25 |

## Description

yabasic is a simple BASIC interpreter for Unix and Windows. It supports
common BASIC features like loops, subroutines, and graphics.

## Dependencies

- ncurses 6.4
- libx11 6.4.0
- xorgproto 2024.1
- libxau 6.0.0
