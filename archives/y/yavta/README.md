# yavta

Yet Another V4L2 Test Application

A tool to test Video4Linux2 devices with a very simple interface. It supports
many of the latest V4L2 capabilities such as multi-plane capture, and many
video formats. It also has capabilities to detect timing issues on the frame
capture.
