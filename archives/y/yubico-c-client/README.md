# yubico-c-client

Yubico YubiKey OTP 验证 C 客户端库。

## 描述

yubico-c-client 是 Yubico 公司提供的 YubiKey 一次性密码 (OTP) 验证 C 客户端库。
它允许应用程序通过 YubiCloud 验证服务验证 YubiKey OTP 令牌。

## 依赖

- curl (HTTP 通信)
- zlib (curl 传递依赖)
