# zerofree

Zero free blocks from ext2, ext3 and ext4 file-systems.

## Description

zerofree is a utility to zero (or set to a chosen value) the free blocks in an ext2, ext3 or ext4 filesystem. This is useful for making disk images compress better, or for securely erasing free space.
