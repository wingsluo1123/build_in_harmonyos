# E1000: OHOS SDK 26 的 fpos_t 是无 __pos 成员的 union，源码取 fpos_t 内部字段编译失败

## 基本信息
- **严重度**: 2
- **类别**: portability, musl, fpos-t, sdk-header
- **作者**: 4A7C

## 错误特征
```
no member named '__pos'|union _G_fpos64_t|__opaque[16]|_G_fpos64_t
```

## 根因分析
OHOS SDK 26.0.0.18 sysroot 的 stdio.h 定义

## 推荐方案
**方法**: source-patch

**说明**: 把“读取 fpos_t 内部整数成员”的写法替换为标准接口调用：

**修复命令**:
```
见 patches 形式：HTS_ftell() 内 fpos_t pos; fgetpos(...); return (size_t) pos.__pos;
```

**验证**:
```
/data/service/hnp/bin/clang -I. -Iinclude -c lib/HTS_misc.c -o /dev/null
```
