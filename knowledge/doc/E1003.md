# E1003: OHOS Meson tests require scoped direct DT_NEEDED and final-location signing for copied runtime roots

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, meson, runtime, testing
- **作者**: 1146
- **来源 PR**: 10543

## 错误特征
```
Error loading shared library .*\.so|symbol not found|direct or indirect DT_NEEDED unresolved despite LD_LIBRARY_PATH
```

## 根因分析
A target test can receive an LD_LIBRARY_PATH containing every dependency directory and can execute through a wrapper that restores absolute LD_PRELOAD paths, yet the OHOS worker loader can still fail to resolve a SONAME needed only by a just-built shared library. Meson puts transitive libraries on the executable link line, but its default --as-needed removes entries for libraries whose symbols are not referenced directly by the executable. Putting forced roots in MesonToolchain.c_link_args is also too early: those arguments reach Meson's unsigned native compiler-runnability probe and make configure fail. Project-scoped direct DT_NEEDED repairs that scope, but a copied release-signed root can still be rejected at its task-private identity; the observed roots must be freshly self-signed as the final mutation at every loader-visible copied location.

## 推荐方案
**方法**: direct-needed-and-final-path-signing

**说明**: Materialize valid aliases, inject only the observed roots as Meson project link arguments after compiler detection, then freshly self-sign task-private copies at every final loader-visible location. Keep no-as-needed, each library path, and as-needed as separate driver arguments so tests gain direct roots without contaminating the native compiler-runnability probe.

**修复命令**:
```
conan create <recipe> --build=<package>; llvm-readelf -d <each-test-elf>; verify direct DT_NEEDED roots and require platform CI to run the full upstream denominator
```

**验证**:
```
Stage every verified dependency .so and SONAME alias with conflict detection, link only the observed runtime roots inside a local --no-as-needed/--as-needed state, self-sign the task-private root copies at their final paths, verify .codesign plus every target test ELF direct DT_NEEDED entry, and require the full N/N platform target result plus an independent frozen target consumer transaction.
```
