# E1005: DJB 风格发行包在 OHOS 上的构建安装三类平台陷阱与 supervise 测试缺口

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, selinux, install, testing, filesystem
- **作者**: 8BEF

## 错误特征
```
No rule to make target 'MAN', needed by 'install'|installer: fatal: unable to write |installer: fatal: unable to read setuser.8|supervise: fatal: unable to read supervise/control|cannot create fifo '
```

## 根因分析
DJB 风格发行包（自写 Makefile + conf-* 配置 + 自带 installer 的 mkdir/chmod）把 GNU/Linux 的文件系统语义写死在构建与安装脚本里，在 OHOS 上叠加四类差异：

## 推荐方案
**方法**: recipe-side-djb-conf-interface

**说明**: 用上游文档化的 conf-* 接口配置构建（写 conf-cc/conf-ld 与 conf-bin/conf-man），用 make -B 代替 make clean 做全量重建，安装前按 MAN 清单预建安装目录（走 installer 已实现的 EEXIST 分支），对发行版 MAN 清单里不存在的 setuser.8 用 installer 自带的可选前缀 '?' 打补丁。

**修复命令**:
```
见 daemontools-encore/1.11/conanfile.py build()/package()：save(conf-cc/conf-ld) → make -j1 -B programs man → 预建 MAN 的 d 行目录 → make -j1 install
```

```
四步最小探针（均可直接复制执行；本设备 /tmp 是只读 erofs，统一用 ${TMPDIR:-$HOME/tmp} 作为可写目录）：
```
