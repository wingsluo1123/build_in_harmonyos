# E1006: Conan conf 子键形态被当作未注册 conf：self.conf.get('tools.build:compiler_executables:c') 抛 ConanException

## 基本信息
- **严重度**: 2
- **类别**: toolchain, conan, recipe
- **作者**: 5BB4

## 错误特征
```
ConanException.*tools.build:compiler_executables:c does not exist in configuration list
```

## 根因分析
tools.build:compiler_executables 是字典型 conf；写成 tools.build:compiler_executables:c 会让 self.conf.get() 把它当成一个未注册的 conf 名并抛 ConanException。模板 templates/conanfile-makefile.py.tmpl 里给的正是这个错误写法，照抄即踩坑。

## 推荐方案
**方法**: dict-form-conf-read

**说明**: 整体读取字典型 conf 再取子键：self.conf.get("tools.build:compiler_executables", check_type=dict, default={}).get("c", "clang")

**修复命令**:
```
compilers = self.conf.get("tools.build:compiler_executables", check_type=dict, default={}); cc = compilers.get("c", "clang") if compilers else "clang"
```

**验证**:
```
conan create <recipe-dir> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing | grep -c "compiler_executables:c does not exist"   # 期望 0
```
