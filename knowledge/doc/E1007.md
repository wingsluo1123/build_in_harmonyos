# E1007: 旧式 extern inline 辅助函数在 OHOS Clang 下产生重复符号

## 基本信息
- **严重度**: 3
- **类别**: compat, portability, linking, compilation
- **作者**: 4C48

## 错误特征
```
ld.lld:[[:space:]]*error:[[:space:]]*duplicate symbol.*ext2fs_|duplicate symbol:[[:space:]]*ext2fs_|multiple definition.*ext2fs_
```

## 根因分析
旧版 ext2fs 头文件依赖 GNU89 风格的 extern inline 语义，并同时提供 inline.c 中的外部实现。OHOS Clang 的默认 C 语义会让多个包含头文件的翻译单元生成外部定义，最终与静态库中的 inline.c 对象重复。

## 推荐方案
**方法**: disable-header-inline-implementation

**说明**: 在 OHOS 目标编译的 CPPFLAGS 中定义 NO_INLINE_FUNCS，让头文件只保留声明，使用库内 inline.c 提供唯一的外部实现。

**修复命令**:
```
CPPFLAGS="$CPPFLAGS -DNO_INLINE_FUNCS" make -j1
```

**验证**:
```
nm libext2fs.a | rg "ext2fs_get_inode_bitmap_start|ext2fs_get_block_bitmap_start" && clang -Wl,--no-undefined <objects> libext2fs.a -o <program>
```
