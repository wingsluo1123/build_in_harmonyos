# E1008: setuptools_scm 包从发布 tarball 构建时取不到版本，需注入 SETUPTOOLS_SCM_PRETEND_VERSION

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, python, packaging, pip
- **作者**: U4D2

## 错误特征
```
LookupError: setuptools-scm was unable to detect version|SETUPTOOLS_SCM_PRETEND_VERSION|VCS_VERSIONING_PRETEND_VERSION|error: metadata-generation-failed
```

## 根因分析
pyproject.toml 声明 setuptools_scm 为版本来源（setup.py 里 use_scm_version=True），

## 推荐方案
**方法**: inject-pretend-version-env

**说明**: 在调用 pip 构建时给子进程注入 SETUPTOOLS_SCM_PRETEND_VERSION=<本配方 version>，

**修复命令**:
```
SETUPTOOLS_SCM_PRETEND_VERSION=4.3.1 python3 -m pip install --no-deps
```

**验证**:
```
python3 -m pip install --no-deps --no-build-isolation --prefix=$HOME/tmp/pfx <源码目录>
```
