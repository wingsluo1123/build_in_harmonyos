# E1009: 4.2BSD 信号接口 sigvec/sigblock/sigsetmask/sigmask 在 OHOS musl 缺失，须改写为 POSIX sigaction/sigprocmask

## 基本信息
- **严重度**: 3
- **类别**: compat, portability, libc, musl, posix
- **作者**: lkjing2021345 <1908499668@qq.com>
- **来源 PR**: (本 PR)

## 错误特征
```
variable has incomplete type 'struct sigvec'|call to undeclared function 'sigvec'|call to undeclared function 'sigblock'|call to undeclared function 'sigsetmask'|call to undeclared function 'sigmask'|implicit declaration of function 'sigvec'|implicit declaration of function 'sigblock'|implicit declaration of function 'sigsetmask'|undefined symbol: sigvec|undefined symbol: sigblock|undefined symbol: sigsetmask|undefined reference to `sigvec'|undefined reference to `sigblock'|undefined reference to `sigsetmask'
```

## 根因分析
4.2BSD 的 struct sigvec 与 sigvec()/sigblock()/sigsetmask()/sigmask() 从未进入 POSIX；

## 推荐方案
**方法**: port-bsd-signals-to-posix-sigaction

**说明**: 按 POSIX 逐点改写，不加平台宏：struct sigvec→struct sigaction（sv_handler→sa_handler；

**修复命令**:
```
grep -rnE 'struct sigvec|sig(vec|block|setmask|mask)\(' --include='*.[ch]' . ; 逐处改写后 track-edit add + refresh-patch --auto
```

**验证**:
```
grep -rnE 'struct sigvec|\bsig(vec|block|setmask|mask)[[:space:]]*\(' --include='*.[ch]' <src>
```
