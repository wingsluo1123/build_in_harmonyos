# E1011: 旧版 FUSE 低层 API 迁移到 libfuse 3 时必须同时迁移生命周期和回调语义

## 基本信息
- **严重度**: 3
- **类别**: compat, portability, headers, build-system
- **作者**: 11A1

## 错误特征
```
fuse_mount.*not declared|fuse_kern_chan_new.*not declared|too few arguments.*op_rename|incompatible function pointer.*fuse_lowlevel_ops|fuse_dirent_size.*not declared
```

## 根因分析
旧项目以 FUSE 2 的 channel、mount 和目录项接口为边界，升级到 libfuse 3 后不仅是头文件路径变化，还涉及 FUSE_USE_VERSION、低层回调签名、session 生命周期和目录项编码方式的整体契约变化。只替换 include 或库名会留下可编译但语义不完整的路径。

## 推荐方案
**方法**: fuse3-lowlevel-session-port

**说明**: 将 FUSE_USE_VERSION 升到 31，使用 session_new/session_mount/session_loop/session_unmount，按 libfuse 3 更新回调签名，并用 fuse_add_direntry 生成目录项。

**修复命令**:
```
git apply patches/0001-configure-fuse3.patch patches/0002-src-fuse3-api.patch patches/0006-fuse3-session-direntry.patch
```

**验证**:
```
git apply --check archives/e/ext2fuse/0.8.1/patches/0001-configure-fuse3.patch archives/e/ext2fuse/0.8.1/patches/0002-src-fuse3-api.patch archives/e/ext2fuse/0.8.1/patches/0006-fuse3-session-direntry.patch && rg -n "fuse_session_mount|fuse_session_loop|fuse_add_direntry" src
```
