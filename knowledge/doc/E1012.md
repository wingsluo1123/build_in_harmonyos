# E1012: 环境级 PIP_* 配置（尤其 PIP_TARGET）会让配方内的私有 --prefix/--target 安装直接失败

## 基本信息
- **严重度**: 2
- **类别**: compat, build-system, python, environment, pip
- **作者**: U4D2

## 错误特征
```
ERROR: Cannot set --home and --prefix together|Can not combine '--target' and '--prefix'|ERROR: Cannot set --target and --prefix together
```

## 根因分析
OHOS/OpenDesk 环境把 pip 的全局配置放在环境变量里（PIP_TARGET / PIP_ONLY_BINARY /

## 推荐方案
**方法**: strip-pip-env-before-private-install

**说明**: 在配方内调用 pip 前，从子进程环境中剥离全部 PIP_* 变量，再显式传 --index-url/

**修复命令**:
```
env = {k: v for k, v in os.environ.items() if not k.startswith("PIP_")}
```

**验证**:
```
PIP_TARGET=$HOME/tmp/pipglobal python3 -m pip install --no-deps --no-build-isolation
```
