# E1013: CMake 在 HarmonyOS 上是「未知平台」：SONAME/RPATH 链接标志与 UNIX 变量全部缺失，且 cmake --install 的 RPATH 改写会破坏 OHOS ELF 签名

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, cmake, linking, conan
- **作者**: 9C41

## 错误特征
```
Error loading shared library liblsl\.so|System is unknown to cmake, create|Platform/HarmonyOS to use this system|exec .* Operation not permitted|no RUNPATH|Library runpath
```

## 根因分析
conan 的 CMakeToolchain 把 settings.os=OHOS 映射为 CMAKE_SYSTEM_NAME=HarmonyOS，但 CMake 4.1.2 只提供 Modules/Platform/OHOS.cmake（内容仅是 include(Platform/Linux)），没有 Platform/HarmonyOS.cmake，于是平台模块回落成 generic：CMAKE_SHARED_LIBRARY_SONAME_{C,CXX}_FLAG、CMAKE_SHARED_LIBRARY_RUNTIME_{C,CXX}_FLAG/_FLAG_SEP、CMAKE_SHARED_LIBRARY_RPATH_ORIGIN_TOKEN、CMAKE_EXECUTABLE_RUNTIME_{C,CXX}_FLAG 全为空 ⇒ ①共享库即使设了 VERSION/SOVERSION 也没有 DT_SONAME；②任何 RPATH 都写不进去，bin/ 下的工具在裸环境加载不到 ../lib 的 .so。同一根因还导致 Platform/HarmonyOS-Initialize.cmake 缺失 ⇒ CMake 的 UNIX 变量根本没人 set(UNIX 1)（CMakeCache 里连 UNIX 条目都没有），于是上游 `if(UNIX AND NOT APPLE)` 分支里的 CMAKE_INSTALL_RPATH 设置被整体跳过。第三层：即使补上了 RPATH，若构建期 RPATH 与安装期 RPATH 不同，cmake --install 会对 ELF 做 RPATH_CHANGE 就地改写，破坏 OHOS 的 .note.ohos.ident 代码签名 —— 装出来的可执行文件 exec 直接 EACCES（Operation not permitted，rc=126，措辞极易被误读成路径/权限问题）。

## 推荐方案
**方法**: rules-override-plus-build-with-install-rpath

**说明**: 在 generate() 里针对 OHOS 三件事一起做：①写一份规则文件（CMAKE_SHARED_LIBRARY_SONAME_*、CMAKE_SHARED_LIBRARY_RUNTIME_*、_FLAG_SEP、RPATH_LINK、RPATH_ORIGIN_TOKEN、CMAKE_EXECUTABLE_RUNTIME_* 全部按 Platform/Linux.cmake 的取值补齐），用 CMAKE_USER_MAKE_RULES_OVERRIDE_C 与 _CXX 指过去（该文件在 CMakeCInformation/CMakeCXXInformation 里、平台模块之后被 include，所以能覆盖）；②显式设 CMAKE_INSTALL_RPATH=$ORIGIN;$ORIGIN/../lib（因为 UNIX 未定义，上游的 Linux 分支不会执行）；③设 CMAKE_BUILD_WITH_INSTALL_RPATH=ON，让构建产物直接带上最终 RPATH，install 阶段两侧一致因而不再改写 ELF。先例：archives/c/curl/8.15.0.1（①的形态）、archives/a/azure-identity-cpp（只做 SONAME 的窄形态）。

**修复命令**:
```
tc.variables["CMAKE_USER_MAKE_RULES_OVERRIDE_C"]=rules; tc.variables["CMAKE_USER_MAKE_RULES_OVERRIDE_CXX"]=rules; tc.variables["CMAKE_BUILD_WITH_INSTALL_RPATH"]="ON"; tc.variables["CMAKE_INSTALL_RPATH"]="$ORIGIN;$ORIGIN/../lib"（rules 文件内容见 doc）
```

**验证**:
```
① readelf -d <pkg>/lib/libX.so.N.N.N 应同时出现 (SONAME) Library soname [libX.so.N] 与 (RUNPATH) [$ORIGIN;$ORIGIN/../lib]；② env -u LD_LIBRARY_PATH <pkg>/bin/<tool> --version 必须 rc=0（不能靠 conanrun 的 LD_LIBRARY_PATH）；③ cmake --install 前后对包内每个 .so/可执行文件 sha256sum 对比必须逐字节一致；④ grep -c harmonybrew <build>/CMakeCache.txt 必须为 0
```
