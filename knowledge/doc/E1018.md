# E1018: CMakeDeps 生成的 Catch2 配置未把包内 lib/cmake/Catch2 加入 CMAKE_MODULE_PATH，上游 include(Catch) 报 include could not find requested file: Catch

## 基本信息
- **严重度**: 3
- **类别**: cmake, conan, dependency, packaging, testing
- **作者**: 693C, pc3-6

## 错误特征
```
include could not find requested file:.*Catch|include could not find requested file: Catch|Unknown CMake command "catch_discover_tests"|catch_discover_tests.*Unknown CMake command
```

## 根因分析
>

## 推荐方案
**方法**: cmake-module-path-override-in-generate

**说明**: 在配方 generate() 中把 <catch2包目录>/lib/cmake/Catch2 显式写入 CMakeToolchain 的 CMAKE_MODULE_PATH 变量（用绝对路径、正斜杠）

**修复命令**:
```
tc.variables["CMAKE_MODULE_PATH"] = os.path.join(self.dependencies["catch2"].package_folder, "lib", "cmake", "Catch2").replace("\\", "/")
```

**验证**:
```
find "$(conan cache path catch2/3.16.0)" -name 'Catch.cmake' — 确认模块在包内；
```
