# E1026: 上游 CMake 平台分支只判 Linux/Darwin/Windows，HarmonyOS 下漏编 POSIX 源文件导致链接期 undefined symbol

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, build-system, cmake, linking
- **作者**: 3464

## 错误特征
```
ld.lld: error: undefined symbol: osqp_start_interrupt_listener|undefined symbol: osqp_is_interrupted|undefined symbol: osqp_end_interrupt_listener
```

## 根因分析
上游以 CMAKE_SYSTEM_NAME 精确匹配 Linux/Darwin/Windows 推导 IS_LINUX/IS_MAC/IS_WINDOWS，再据此挑选平台源文件。OHOS 上 CMAKE_SYSTEM_NAME=HarmonyOS，三个变量全 OFF，POSIX 实现源文件被静默剔除；而功能开关（如 OSQP_ENABLE_INTERRUPT）默认 ON 且公共代码无条件引用其符号 → 链接期 undefined symbol。

## 推荐方案
**方法**: cmake-platform-branch-add-harmonyos-ohos

**说明**: 在构建系统补丁里为该分支同时追加 HarmonyOS 与 OHOS 两种系统名（覆盖 conan 映射前后的差异），把 POSIX 实现纳入编译。禁止改用 __OHOS__ 源码宏（R8/PF5 禁补丁引入平台宏）。

**修复命令**:
```
elseif(IS_MAC OR IS_LINUX OR CMAKE_SYSTEM_NAME STREQUAL "HarmonyOS" OR CMAKE_SYSTEM_NAME STREQUAL "OHOS")
```

**验证**:
```
grep -n 'CMAKE_SYSTEM_NAME STREQUAL "Linux"' CMakeLists.txt; cmake --build build 2>&1 | grep 'undefined symbol'
```
