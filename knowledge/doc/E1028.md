# E1028: Cross-built OHOS test binaries require a native host harness and bounded fixtures

## 基本信息
- **严重度**: 2
- **类别**: ohos, network, build-system, meson, testing
- **作者**: 1146

## 错误特征
```
cannot execute binary file|Exec format error|exit status 77|TIMEOUT.*killed by signal 15|Could not configure.*build.dat|TLS support is not available|GDummyTlsBackend|Could not connect to 127\.0\.0\.1: Connection refused|Error loading shared library.*\.so
```

## 根因分析
A Meson test directory generated by an OHOS/aarch64 cross build contains target ELF executables that WSL/Linux x86_64 cannot execute, so Meson reports exit status 77 or Exec format error before any assertion runs. Legacy upstream tests may call an external HTTPS service; a native target without a GIO TLS backend reports GDummyTlsBackend before request assertions. Even a loopback test is nondeterministic when it spawns a raw server thread without a readiness handshake. After packaging, Conan's run environment may omit component-backed transitive directories, and some native OHOS loaders still fail to reach indirect SONAMEs in later entries of a printed long LD_LIBRARY_PATH. Treating any of these outcomes as PASS hides an unexecuted or indeterminate test.

## 推荐方案
**方法**: native-host-test-with-private-fixture

**说明**: Build the same upstream tests natively in a task-owned prefix. When the target has no GIO TLS backend, replace only external HTTPS transport with a loopback HTTP fixture while preserving assertions. Start every loopback service through one readiness-signalled ephemeral-port helper. For the packaged consumer, independently enumerate the tested package plus all host transitive component libdirs, materialize every validated SONAME into one conflict-checked loader-first directory, self-sign critical copied roots at their final native path, and retain conanrun.

**修复命令**:
```
meson setup <host-build> <host-source> -Dtests=true && meson compile -C <host-build> -j2 && meson test -C <host-build> --no-rebuild --print-errorlogs --num-processes 2
```

**验证**:
```
PYTHONPATH=<task>/meson-runtime python3 -m mesonbuild.mesonmain test -C <task>/host-native-build --no-rebuild --print-errorlogs --num-processes 2; verify the summary is N/N PASS with skipped=0, timeout=0, and hash-bind the raw log and fixture request log
```
