# E1029: Conan test_package 必须为缺失 bash 配置提供可执行命令回退

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, packaging
- **作者**: H472

## 错误特征
```
RUN: "None" .*hamlib-test-command\.sh|/system/bin/sh: None: inaccessible or not found|Error 127 while executing
```

## 根因分析
test_package 只读取 tools.microsoft.bash:path；平台 CI 的 OHOS host/Windows build 配置未提供该可选 conf，Conan 将空值格式化为命令 None，导致目标 shell 无法执行测试编译脚本并以 RC 127 失败。

## 推荐方案
**方法**: 使用 self.conf.get("tools.microsoft.bash:path", default="bash", check_type=str) or "bash"，保留显式 Windows Bash 路径并在平台未提供该 conf 时使用 PATH 中的 bash。

**说明**: 可选工具路径配置必须有平台可执行的命令名回退；不能把 None 直接插入 self.run 命令。回退只覆盖 Bash 解析，不替代编译器、目标 binary 或 W3 执行验证。

**修复命令**:
```
conan create <recipe> --profile:host <ohos-profile> --build=missing
```

**验证**:
```
conan create archives/h/hamlib/4.7.2 --profile:host local-ohos.profile --build=missing; 回读日志应包含 RUN: ".../bash.exe" hamlib-test-command.sh、test_package RC=0 且不出现 None: inaccessible or not found。
```
