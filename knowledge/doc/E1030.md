# E1030: Windows Autotools shell paths and Linux-only APIs need explicit OHOS tool wrappers and guards

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, headers, threading, autotools
- **作者**: H472

## 错误特征
```
C:/Program Files.*syntax error.*unexpected \(|/f/.*toolchain.*not found|sockaddr_storage.*redefinition|undefined symbol: pthread_cancel
```

## 根因分析
Windows-hosted Autotools generated commands are evaluated by a POSIX shell; SDK and w64devkit paths containing spaces or MSYS-style /drive prefixes can be split or become unresolvable. Independently, OHOS defines __linux__ while its sysroot may expose incompatible Linux UAPI headers and its libc may omit optional pthread cancellation APIs.

## 推荐方案
**方法**: Keep compiler and host tools behind task-owned executable wrappers whose paths contain no spaces from the shell's perspective; bind SHELL and MAKE for recursive Automake calls; guard Linux-only UAPI blocks with __linux__ && !__OHOS__; replace unavailable cancellation-only shutdown with an OHOS cooperative stop flag and pthread_join when the thread is joinable.

**说明**: Rebind every tool that libtool or Autoconf may place inside eval (compiler, linker, archiver, nm, sed, grep, make and shell), then apply source guards based on actual OHOS capability rather than the broad __linux__ macro. Preserve non-OHOS behavior and test a real consumer link. Keep workstation paths out of the recipe: derive compiler, make and Bash directories from Conan configuration, and create a build-folder shell wrapper (using a short path when available) for CONFIG_SHELL and recursive Make so paths with spaces cannot be split. Treat generated Autotools install helpers as separate capability boundaries: a w64devkit helper can report an awk program as an unrecognized shell command while make still returns success, so verify package contents and close missing headers/tools with explicit source_folder copies. Conan test_package generators are emitted into source_folder, not build_folder; remove them before candidate freeze. OHOS toybox ps may hide command arguments, so validate daemon readiness by process count and real socket behavior rather than port-text matching.

**修复命令**:
```
configure --host=aarch64-linux-ohos with task-owned wrappers; make -j1 SHELL=<task>/toolchain/sh; compile a consumer including the public header and linking libhamlib.a; inspect ELF header and link return code.
```

**验证**:
```
Configure with task-owned no-space command wrappers and aarch64-linux-ohos target; build a minimal consumer against the produced archive; confirm no sockaddr_storage redefinition or pthread_cancel undefined symbol remains.
```
