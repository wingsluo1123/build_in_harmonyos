# E1032: 可选 SIMD 的 CMake try_run 探测在交叉编译中必须显式关闭

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, cmake
- **作者**: 7C2A

## 错误特征
```
try_run\(\) invoked in cross-compiling mode|C_HAS_[A-Z0-9_]+_EXITCODE
```

## 根因分析
上游用 try_run 编译并执行 SIMD 能力探针；交叉构建产生的目标 ELF 不能在宿主机运行，CMake 要求猜测 *_EXITCODE，导致配置失败或把不可复核的宿主假设写入目标特性

## 推荐方案
**方法**: 同时关闭 SIMD 自动执行探测与 SIMD 优化，保留可移植实现；回读最终 cache 后构建目标架构产物，并在真实目标设备运行功能消费者

**说明**: 使用上游公开选项禁用无法在宿主执行的可选探针，不猜测 try_run 退出码；上游完整测试仍在可运行环境独立执行，目标机消费者证明便携路径

**修复命令**:
```
-DFIND_SIMD=OFF -DENABLE_SIMD=OFF
```

**验证**:
```
cmake -S <source> -B <build> -DCMAKE_TOOLCHAIN_FILE=<ohos-toolchain> -DFIND_SIMD=OFF -DENABLE_SIMD=OFF && cmake --build <build> --parallel 2 && <signed-target-consumer>
```
