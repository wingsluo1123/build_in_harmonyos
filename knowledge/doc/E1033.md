# E1033: 根 .gitignore 的 reports/ 规则吞掉归档报告目录，需局部反选

## 基本信息
- **严重度**: 2
- **类别**: build-system, packaging
- **作者**: BAF9

## 错误特征
```
git add archives/.*后 reports/ 下文件未被暂存|git check-ignore.*reports/test-report.md.*reports/
```

## 根因分析
根 .gitignore 第 91 行的 unanchored 模式 reports/ 匹配任意深度的 reports 目录，归档目录（archives/p/povray/3.7.0.10/reports/）下的 test-report.md/audit-result.json 会被忽略；根 .gitignore 不允许协作者修改

## 推荐方案
**方法**: 在归档局部 .gitignore（archives/<字母>/<软件>/<版本>/.gitignore，随归档提交）写反选：!reports/ + !reports/*.md + !reports/audit-result.json，再用 git add 即可入库（tcping/handbrake/x3270 根反选先例；abiword 的归档局部 .gitignore 同款）；reports/conan-create.log 仍应显式忽略不入库

**说明**: 归档局部 .gitignore 反选 reports/ 必需文件（!reports/*.md + !reports/audit-result.json），conan-create.log/w3-local-ci.log 显式忽略

**修复命令**:
```
printf '!reports/\n!reports/*.md\n!reports/audit-result.json\n' >> ${ARCHIVE_DIR}/.gitignore && git add ${ARCHIVE_DIR}/reports/test-report.md
```

**验证**:
```
git check-ignore -v archives/p/povray/3.7.0.10/reports/test-report.md  # 命中根规则 reports/ 即复现
```
