# E1034: OHOS 的 diff 是 toybox 实现、只支持 unified 输出，上游测试脚本里的 diff -c 让整组用例 FAIL

- **来源 PR**: 11609

## 错误特征
```
|
```

## 根因分析
鸿蒙 PC 的 /usr/bin/diff 由 toybox 提供，只实现 unified 格式输出（-u / -U N），不认识 POSIX 的 context 格式选项 -c / -C N。

## 推荐方案
**方法**: test-script-diff-unified

**说明**: 在测试脚本里把 `diff -c` 改为 POSIX 的 `diff -u`（`-C N` 改为 `-U N`）：toybox 与 GNU diffutils 都支持，读 stdin 的 `-` 也照常可用，比对语义（相同退出 0、不同退出 1）不变，只是失败时的差异展示格式从 context 变为 unified。

**修复命令**:
```
sed -i 's/\bdiff -c\b/diff -u/' <src>/test1 <src>/test2 ...   # 在 .work 中修改后 refresh-patch --auto
```

**验证**:
```
grep -rnE '\bdiff\s+-[a-zA-Z]*[cC]\b' <src>/test* <src>/tests <src>/Makefile.am 2>/dev/null
```
