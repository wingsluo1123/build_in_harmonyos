# E1036: glibc 专属头文件（如 ieee754.h）在 OHOS musl 系 libc 缺失，需用可移植位域 union/内联定义替代

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, musl, headers
- **作者**: 0F3E

## 错误特征
```
fatal error: 'ieee754.h' file not found|ieee754.h.*No such file|'bits/.*\.h' file not found
```

## 根因分析
部分上游 C/C++ 测试或工具代码包含 glibc 专属头文件（如 <ieee754.h> 的 ieee754_float 位域联合）。OHOS 基于 musl 的 libc/sysroot 不提供该头，clang 报 file not found。修复思路不是换 libc，而是把用到的位域布局（sign/exp/mantissa）内联为可移植 union，保持字段名不变。

## 推荐方案
**方法**: inline-portable-bitfield-union

**说明**: 移除 glibc 专属 include，在测试/工具源码内联等价的 IEEE-754 单精度位域 union（mantissa:23 exponent:8 negative:1），字段名与 glibc 一致（.ieee.negative/.exponent/.mantissa），无需改动其余逻辑；属于 portability patch。
