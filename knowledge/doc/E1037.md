# E1037: conan test_package test_type=explicit 下 test() 工作目录即 test_package/ 源目录

## 基本信息
- **严重度**: 3
- **类别**: build-system, conan
- **作者**: DD3A

## 错误特征
```
SameFileError.*test_package.*are the same file|Error in test\(\) method.*SameFileError
```

## 根因分析
conan 2.29 test_type=explicit 且未定义 layout 时，test() 的工作目录不是独立 build 目录而是 test_package/ 源目录本身；shutil.copy(source/test.pov, test.pov) 复制到自身抛 SameFileError；同时输出文件（banner.txt/test.png）也会直接写进归档目录造成污染

## 推荐方案
**方法**: test() 内用 tempfile.mkdtemp(prefix=...) 建独立工作目录，输入场景文件用绝对路径 +I 引用，输出（+O/重定向日志）全部写临时目录；不要 shutil.copy 到 CWD

**说明**: test() 所有输出写入 tempfile.mkdtemp 临时目录并在 finally 中 rmtree 清理，输入用绝对路径引用

**修复命令**:
```
workdir = tempfile.mkdtemp(prefix="${SOFT}_test_")  # Python；渲染 +O 指向 workdir
```

**验证**:
```
cd archives/<软件>/<版本>/test_package && python3 -c "import shutil; shutil.copy('test.pov','test.pov')"  # SameFileError 即复现
```
