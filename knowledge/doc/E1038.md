# E1038: 面向 libpng 1.0/1.2 写的程序在 libpng ≥1.4 下编译失败：私有 API 与结构体字段全部不再公开

## 基本信息
- **严重度**: 3
- **类别**: compat, portability, headers, build-system
- **作者**: unknown

## 错误特征
```
|
```

## 根因分析
libpng 1.4 起把 png_struct / png_info 改成不透明类型并停止随 png.h 安装内部头，四类旧写法同时失效：

## 推荐方案
**方法**: port-to-public-libpng-api

**说明**: 整体迁移到公共 API，而不是逐个错误打补丁：删掉自制的分块遍历函数，改用 png_read_png(png_ptr, info_ptr, 0, NULL) 一次读完（IDAT 之后的 tEXt/tIME 同样进 info）；

**修复命令**:
```
sed -i 's/^#define PNG_INTERNAL$//' <src>/*.c && grep -n 'png_handle_\|png_ptr->\|info_ptr->' <src>/*.c
```

**验证**:
```
grep -nE 'PNG_INTERNAL|png_handle_|png_ptr->|info_ptr->' <src>/*.c
```
