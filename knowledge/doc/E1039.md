# E1039: 上游 Makefile flags 硬编码 x86 专属编译选项在 aarch64/OHOS 被 clang 拒绝（unknown FP unit 'sse'），需 patch 移除或配方侧覆盖

## 基本信息
- **严重度**: 2
- **类别**: portability, make, compiler, flags
- **作者**: CEE7

## 错误特征
```
unknown FP unit 'sse'|mfpmath=sse|msse2.*not supported|argument unused.*msse2
```

## 根因分析
上游 Makefile 的 flags/CFLAGS 文件常写死 x86 专属编译选项（-msse2 -mfpmath=sse -mfma -mno-fma4）。在 aarch64（OHOS armv8）上 clang 对 -mfpmath=sse 报 unknown FP unit 'sse' 直接失败，其余选项仅警告。此类 Makefile 项目无 configure，只能 patch flags 文件移除 x86 专属项或用配方 CXXFLAGS 覆盖。

## 推荐方案
**方法**: patch-flags-remove-x86-options

**说明**: 将上游 flags/CFLAGS 文件中的 x86 专属编译选项（-msse2 -mfpmath=sse -mfma -mno-fma4 等）patch 移除，保留可移植项（-std/-Wall/-frounding-math/-ffp-contract=off/-pedantic）；或 conan 配方 build() 用 conf 编译器 + 显式 CXXFLAGS 覆盖。

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan create archives/s/symfpu/0.0-git.40bdec00 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
