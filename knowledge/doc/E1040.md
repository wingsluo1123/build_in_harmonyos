# E1040: OpenLDAP 2.6 头文件默认隐藏旧版 LDAP API 声明；musl/OHOS sysroot 不传递包含 time.h

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, headers
- **作者**: 0643

## 错误特征
```
call to undeclared function 'ldap_init'|call to undeclared function 'ldap_simple_bind_s'|call to undeclared function 'ldap_search_s'|unknown type name 'time_t'
```

## 根因分析
OpenLDAP 2.6+ 将旧版（LDAP_DEPRECATED）API 声明放在 #if LDAP_DEPRECATED 内；conan openldap/2.6.7 包未定义该宏导致声明被隐藏（符号仍在 libldap.so 导出）。另 2002 年前后源码常用 time_t 但漏 include <time.h>，glibc 下靠传递包含侥幸编译通过，musl/OHOS sysroot 不含。

## 推荐方案
**方法**: CFLAGS 加 -DLDAP_DEPRECATED=1 恢复旧 API 声明（符号已导出，无需改库）；同时为缺失的 time.h 补 #include <time.h>

**说明**: 定义 LDAP_DEPRECATED=1 使 ldap.h 暴露旧版 API 声明；补 time.h 修复 time_t

**修复命令**:
```
make INC="-I$P/include -DLDAP_DEPRECATED=1"  # P=<openldap package_folder>
```

**验证**:
```
nm -D $P/lib/libldap.so | grep -E 'T ldap_init|T ldap_simple_bind_s'; grep -rn "LDAP_DEPRECATED" $P/include/ldap.h | head
```
