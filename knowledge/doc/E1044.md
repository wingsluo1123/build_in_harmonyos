# E1044: Autotools 包的 make check 只计入 TESTS runner 而不是 check_PROGRAMS 注册数，上游 runner 列表为空时必须先按注册数清点 N，再用上游 harness 补跑未派发程序并分栏申报

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, testing, rule4, test-counting
- **作者**: libfshfs-20260130 适配任务（本 PR 交付）
- **来源 PR**: (同 PR 交付)

## 错误特征
```
SKIP:\s*test_tools\.sh|exit status:\s*77|Test input directory not found|TOOLS_TESTS="";|TOTAL\s+3[^0-9]|PASS\s+1|SKIP\s+2
```

## 根因分析
Automake 的 make check 只执行 tests/Makefile.am 的 TESTS 变量（本包为 test_library.sh / test_tools.sh / test_fshfsinfo.sh），check_PROGRAMS 里注册的 C 测试程序由这些 shell runner 的**内部遍历列表**决定是否真跑：runner 只跑它自己 LIBRARY_TESTS / TOOLS_TESTS 变量里列出的名字。libfshfs 20260130 的 tests/test_tools.sh 把 TOOLS_TESTS 与 TOOLS_TESTS_WITH_INPUT 都写成空串，于是 4 个已注册（且已被 make check 编译出来）的 fshfs_test_tools_* 程序一个也没被派发，automake 只看到 runner 以 exit 77 结束并记成 SKIP。后果是 make check 汇总只有 TOTAL 3 / PASS 1 / SKIP 2，而 tests/Makefile.am 的 check_PROGRAMS 有 36 项、test_library.sh 实际派发并通过 32 项。只按 automake 汇总或 runner 数申报就会漏报 4 个已注册用例（审方按上游当前 HEAD 的 check_PROGRAMS 清点，命中“实测 N 大于声明 N”的少报红线）；反过来把 36 全写成 PASS 而没有补跑证据，则等于把未执行的程序谎报成通过。另外逐程序 PASS 证据既不在 make 的 stdout，也不在 tests/test-suite.log，而在 automake 的每 runner 日志 tests/test_library.sh.log，取数命令写错会得到 0 条。

## 推荐方案
**方法**: count-check-programs-then-dispatch-through-upstream-harness

**说明**: 先按 check_PROGRAMS 注册数取 N（设备与被审版本各取一次，并与上游当前 HEAD 的注册数比较，取最大值作下界并逐项归因差额）；再用 automake 的每 runner 日志 tests/<runner>.log 统计实际派发与通过数（本包 test_library.sh 32 PASS / 0 FAIL）；对“已注册但 runner 未派发”的程序，用上游自带的 tests/test_runner.sh 里的 run_test_with_arguments 在同一个 harness 下补跑（不改上游用例源码、不新增断言），把结果计入程序级合计；汇报时同时给两个单位——程序级 TOTAL 等于 check_PROGRAMS 数，runner 级 TOTAL/PASS/SKIP 取 automake 汇总，差额逐项写明（本包 runner 级 2 个 SKIP 分别是 test_tools.sh 空列表与 test_fshfsinfo.sh 无 input 夹具，均 exit 77）。

**修复命令**:
```
sed -n '/^check_PROGRAMS/,/^$/p' tests/Makefile.am | sed '1s/check_PROGRAMS *=//' | tr -d '\\' | wc -w ; grep -c ' (PASS)' tests/test_library.sh.log ; grep -n 'TOOLS_TESTS=' tests/test_tools.sh
```

**验证**:
```
sed -n '/^check_PROGRAMS/,/^$/p' tests/Makefile.am | sed '1s/check_PROGRAMS *=//' | tr -d '\\' | wc -w ; grep -E '^# (TOTAL|PASS|SKIP|FAIL|ERROR)' tests/test-suite.log ; grep -c ' (PASS)' tests/test_library.sh.log ; grep -c ' (FAIL)' tests/test_library.sh.log ; grep -n 'TOOLS_TESTS=' tests/test_tools.sh ; cd tests && . ./test_runner.sh && for n in info_handle mount_path_string output signal; do run_test_with_arguments "Testing:\ tools_${n}" "./fshfs_test_tools_${n}" || exit 1; done
```
