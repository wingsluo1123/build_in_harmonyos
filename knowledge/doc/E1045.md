# E1045: OHOS musl 运行时无法从用户目录加载版本化 .so, 库包默认静态链接

## 基本信息
- **严重度**: 3
- **类别**: ohos, runtime
- **作者**: FAE3, "libproperties-1.1.2 任务", 086C

## 错误特征
```
Error loading shared library libIrc[^\ ]*\.so\.[0-9]|shared library.*not found.*needed by
```

## 根因分析
OHOS musl 动态链接器对用户态目录(HMDFS/conan 缓存)的版本化 .so 搜索受限: LD_LIBRARY_PATH 手动注入无效, DT_RPATH 与 RUNPATH(含 --disable-new-dtags)均无效, 静态链接是唯一实测可靠路径

## 推荐方案
**方法**: static-link-default

**说明**: 库包 conanfile.py default_options shared=False, test_package 静态链接被测库

```
可选: 具体命令模板(${VAR}变量引用)
```
