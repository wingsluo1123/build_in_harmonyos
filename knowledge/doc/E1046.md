# E1046: The CI worker's interpreter ships pip but not setuptools (Python 3.12 no longer bundles it), so pip wheel --no-build-isolation cannot import the PEP 517 backend and dies with BackendUnavailable, while the same recipe passes locally on an interpreter that has setuptools

## 基本信息
- **严重度**: 2
- **类别**: build-system, python, conan, packaging, environment
- **作者**: 826F
- **来源 PR**: 13191

## 错误特征
```
BackendUnavailable: Cannot import 'setuptools.build_meta'|No module named 'setuptools'|pip wheel .*--no-build-isolation|prepare_metadata_for_build_wheel
```

## 根因分析
Under --no-build-isolation pip must import the build backend from the ambient interpreter, so a missing setuptools turns the wheel build into "BackendUnavailable: Cannot import 'setuptools.build_meta'" (surfaced through pip._vendor.pyproject_hooks). Python 3.12 stopped shipping setuptools with the interpreter, and the worker's build interpreter (/data/service/hnp/bin/python3, plain pip only) has none, while conan on the developer machine runs on a different interpreter (.../python.org/python_3.12/bin/python3.12) that does. A recipe that hardcodes --no-build-isolation therefore passes W3 and fails the moment CI reaches build().

## 推荐方案
**方法**: probe-setuptools-and-fall-back-to-an-isolated-build-env

**说明**: Probe the build interpreter before invoking pip (importlib.util.find_spec('setuptools')) and use --no-build-isolation only when setuptools is importable; otherwise drop the flag so pip provisions its own isolated build environment and installs the backend into a throwaway venv. This keeps the offline local path byte-identical and does not mutate the shared worker interpreter, unlike pip install setuptools. Reproduce CI locally with python3 -m venv (a 3.12 venv has pip but no setuptools).

**修复命令**:
```
python3 -c "import importlib.util,sys; sys.exit(0 if importlib.util.find_spec('setuptools') else 1)"  # rc=0 -> keep --no-build-isolation; rc=1 -> drop it
```

**验证**:
```
python3 -c "import importlib.util,sys; sys.exit(0 if importlib.util.find_spec('setuptools') else 1)"; echo rc=$?
```
