# E1050: conan MesonToolchain 将 libexecdir 映射为 bin：meson 安装目录断言需按实际布局（libexecdir/turnstile→bin/turnstile）

## 基本信息
- **严重度**: 2
- **类别**: ohos, meson, toolchain, conan, packaging
- **作者**: DFA1

## 错误特征
```
missing packaged file|install_dir|libexecdir
```

## 根因分析
conan 2 MesonToolchain 生成的 conan_meson_native.ini 将 libexecdir 固定为 'bin'（与 CMakeToolchain CMAKE_INSTALL_LIBEXECDIR=bin 同族问题），上游 meson 安装到 libexecdir 的数据/脚本实际落盘到 bin/，test_package 按上游 libexec 路径断言会报 missing packaged file

## 推荐方案
**方法**: assert-actual-packaged-layout

**说明**: test_package 按 conan 安装后实际布局断言（MesonToolchain libexecdir→bin 映射），上游路径仅作参考；必要时可显式 tc.project_options['libexecdir'] 覆盖

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan create archives/t/turnstile/0.1.11 后 find 包内实际路径（bin/turnstile/dinit 而非 libexec/turnstile/dinit），修正断言后 G2 PASS
```
