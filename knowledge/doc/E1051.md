# E1051: conandata.yml 版本键形如 N 或 N.N（日期/快照/两段版本）不加引号时被 YAML 解析成 int/float，按 self.version 查 sources 抛 KeyError

## 基本信息
- **严重度**: 3
- **类别**: conan, packaging, version
- **作者**: 82B2

## 错误特征
```
KeyError: '[0-9]+(\.[0-9]+)?'
```

## 根因分析
Conan 用 yaml.safe_load（YAML 1.1）读 conandata.yml：只含数字且至多一个点的裸键被解析成数字，

## 推荐方案
**方法**: quote-conandata-version-keys

**说明**: conandata.yml 的 sources/patches 版本键一律加双引号（"20160311.094456":），与仓库 945 份配方主流写法一致；配方保持 get(self, **self.conan_data["sources"][self.version], strip_root=True)

**修复命令**:
```
sed -i -E 's/^(  )([0-9]+(\.[0-9]+)?):[[:space:]]*$/\1"\2":/' conandata.yml && python3 -c 'import yaml;d=yaml.safe_load(open("conandata.yml"));assert all(isinstance(k,str) for k in d["sources"]),d["sources"].keys()'
```

**验证**:
```
python3 -c 'import yaml;print({k:type(k).__name__ for k in yaml.safe_load(open("conandata.yml"))["sources"]})'  # 任何非 str 的键即命中
```
