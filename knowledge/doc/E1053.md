# E1053: OHOS libc++ 无 <tr1/memory>：旧代码 std::tr1::shared_ptr 需迁移到 <memory> + std::shared_ptr

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, headers
- **作者**: 4EEF

## 错误特征
```
fatal error: .tr1/memory. file not found|tr1/memory.*No such file|std::tr1::shared_ptr.*no member|std::tr1::enable_shared_from_this.*no member
```

## 根因分析
OHOS 工具链的 libc++（LLVM libc++）不提供 C++ TR1 兼容头 <tr1/memory>；仍使用 std::tr1::shared_ptr / std::tr1::enable_shared_from_this（C++11 之前 TR1 写法）的旧版 C++ 代码，在编译时直接报 "fatal error: 'tr1/memory' file not found"。

## 推荐方案
**方法**: std-library-migration

**说明**: 将 #include <tr1/memory> 改为 #include <memory>，std::tr1::shared_ptr / std::tr1::enable_shared_from_this 改为 std:: 命名空间对应类型（C++11 标准库已内置，无需额外依赖链接）。

**修复命令**:
```
sed -i 's|#include <tr1/memory>|#include <memory>|; s|std::tr1::shared_ptr|std::shared_ptr|g; s|std::tr1::enable_shared_from_this|std::enable_shared_from_this|g' include/shared_ptr.hpp
```

**验证**:
```
1) 编译前 grep -rn "tr1/memory|std::tr1" 源码确认引用位置；2) 修复后重新 make，确认无 tr1/memory 相关报错。已在 vzlogger 0.8.9 实证：修复 shared_ptr.hpp 后编译通过。
```
