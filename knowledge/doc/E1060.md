# E1060: uname -s 在鸿蒙返回 HarmonyOS：Makefile 的 ifeq ($(SYS),Linux) 守卫会静默漏编内核相关源文件

## 基本信息
- **严重度**: 3
- **类别**: detection, ohos, build-system, make, cross-compile
- **作者**: L7F2

## 错误特征
```
(uname -s.*HarmonyOS|HarmonyOS.*uname|SYS[ =:]+HarmonyOS|ifeq \(\$\(SYS\), *Linux\))
```

## 根因分析
|

## 推荐方案
**方法**: pass-sys-explicitly

**说明**: 构建期显式传 `SYS=Linux`（鸿蒙内核接口就是 Linux 的），需要时一并显式传 `ARCH=<目标架构>`。不改源码、不新增平台宏，属最小参数集适配；同时保留上游判定逻辑的完整性。

**修复命令**:
```
make SYS=Linux ARCH=aarch64 -j$(nproc) lib
```

**验证**:
```
uname -s; grep -rn "uname -s" Makefile config.mk; make -n lib | grep -c pfmlib_perf_event
```
