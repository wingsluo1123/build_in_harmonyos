# E1063: 源码自带 compat/ 头若直接 include glibc 专属头，在 OHOS 上必须改为自包含实现

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability, libc, headers
- **作者**: BD15

## 错误特征
```
fatal error: 'bits/byteswap.h' file not found|fatal error: 'byteswap.h' file not found|features.h: No such file or directory|__GLIBC__.*byteswap
```

## 根因分析
部分软件为兼容老系统自带 compat/byteswap.h，其内部 include <features.h>/<bits/byteswap.h> 等 glibc 专属头；OHOS musl 系 sysroot 不含这些头，编译即 fatal error

## 推荐方案
**方法**: patch-compat-header-self-contained

**说明**: 用补丁把 compat/ 头替换为自包含可移植实现（内联字节序探测 + __builtin_bswap16/32/64），不再 include 任何 glibc 专属头

**修复命令**:
```
python3 $SKILL_ROOT/scripts/ohc-run.py refresh-patch --auto <pkg> <ver>  # 或手工维护 patches/NNNN-compat-<name>-portable.patch
```

**验证**:
```
grep -rn 'bits/byteswap.h\|features.h' compat/ src/compat/ 2>/dev/null
```
