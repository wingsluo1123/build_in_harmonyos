- **类别**: portability, libc, headers, testing, struct

```
(ABI size|abi_sz|sizeof.*(struct|attr)|__WORDSIZE|bits/wordsize\.h|PFM_(PMU_INFO|PERF_ENCODE)_ABI0)
```

## 推荐方案
**方法**: portable-lp64-macros

**说明**: 用编译器内置的 LP64 宏替代 __WORDSIZE：`defined(__LP64__) || defined(_LP64) || (defined(__SIZEOF_POINTER__) && __SIZEOF_POINTER__ == 8)`。补丁同时改公共头文件，保证库与消费者看到的 ABI 常量一致；属可移植修复（不含任何平台宏），具备上游化条件。

**修复命令**:
```
patch -p1 < patches/0001-include-perfmon-pfmlib.h.patch
```

**验证**:
```
grep -rn "__WORDSIZE\|bits/wordsize.h" include; ./tests/validate 2>&1 | grep -i "abi size"
```
