# E1067: conandata.yml 注释中的裸 URL 被 CI 预下载改写，污染真实源码 URL

## 基本信息
- **严重度**: 2
- **类别**: conan, source
- **作者**: L4F7

## 错误特征
```
ERROR:.*Error downloading file.*file:///.*predl_cache|Incorrect archive|sha256 mismatch|404.*predl_cache
```

## 根因分析
CI 预下载步骤会正则扫描 conandata.yml 全文（含注释）中的所有 http(s) URL 并改写为本地 file:// 路径。若注释里的裸 URL（如上游主页 https://github.com/Owner/Repo）是真实归档 URL 的前缀，改写会命中真实 URL 的前缀部分，产出 file:///…/<hash>_<name>/archive/refs/tags/X.Y.Z.tar.gz 这类不存在的路径，source() 随即失败。

## 推荐方案
**方法**: keep-conandata-comment-url-free

**说明**: conandata.yml 里只保留 sources.url 一个 http(s) URL；注释只写域名/路径的纯文本形式（如 github.com/Owner/Repo），不写完整 http(s):// 前缀。

**修复命令**:
```
grep -cE '^\s*#.*https?://' archives/<l>/<pkg>/<ver>/conandata.yml  # 期望 0
```

**验证**:
```
grep -nE 'https?://' archives/*/*/*/conandata.yml  # 检查注释里是否有裸 URL；观察 .build-cache/predl_cache 是否出现以 URL 末段命名的目录
```
