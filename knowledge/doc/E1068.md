# E1068: refresh-patch --auto 依据 generate 期差异重生成补丁，会删除配方内手工补丁

## 基本信息
- **严重度**: 3
- **类别**: toolchain, conan, packaging, patch
- **作者**: A853

## 错误特征
```
refresh-patch --auto.*regenerated|patches/.*count.*0|hand-written patch.*(deleted|overwritten)|0001-config.guess.patch
```

## 根因分析
refresh-patch --auto 比对 build 期 work 目录与 .orig 基线，只要 work 目录残留任何未还原的探索性改动（如被新版 config.guess 覆盖），auto_mode 即判定为 recipe 补丁并整体重生成，覆盖/删除 patches/ 下手工维护的补丁

## 推荐方案
**方法**: restore-work-dir-before-finish

**说明**: 跑 finish 前把 work 目录被替换的文件（config.guess/config.sub 等）恢复为 .orig 基线版本，使 auto_mode 判定无改动，从而保留手工补丁；补丁仍以手工方式维护

**修复命令**:
```
cp $ORIG_DIR/config.guess $WORK_DIR/config.guess && git status --porcelain archives/<l>/<pkg>/<ver>/patches/
```

**验证**:
```
git status --porcelain patches/ && ls patches/
```
