# E1070: ATF/kyua 测试栈在 OHOS 无 kyua 时的全量执行协议：prog -l 枚举 + 单用例位置参数逐条执行 + atf-sh 环境装配与用例数对账

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, toolchain, conan, testing
- **作者**: 9C4A

## 错误特征
```
Running test cases outside of kyua\(1\) is unsupported|kyua.*inaccessible or not found|Must provide a test case name|Cannot find the test program in the source directory|Failed to execute .*/bin/bash.*No such file|ATF_LIBEXECDIR|ATF_PKGDATADIR|examples_test
```

## 根因分析
kyua 尚未适配 OHOS（下游任务），而 ATF（atf-c++/atf-sh）上游测试套件默认由 Kyuafile+kyua 编排；无 kyua 时缺少可复用的枚举-执行-对账范式：ATF 测试程序仅支持 -l 列出用例（TP 格式 ident）与单个位置参数运行一个用例（-r 是结果文件参数，非运行全部），直接裸执行只打印 kyua 警告；atf-sh 脚本的 shebang 取自 pkg-config 的 interpreter 变量，atf-sh 编译期默认 ATF_SHELL/ATF_LIBEXECDIR/ATF_PKGDATADIR 可能是构建机私有路径，examples_test 还要求在 make install 之后运行才能用已安装的 pkg-config 元数据编译示例

## 推荐方案
**方法**: atf-program-cli-direct-execution

**说明**: 以 ATF 测试程序自身 CLI 全量执行：-l 枚举 ident，逐用例以单个位置参数运行并按退出码判定（0=通过）；按程序强对账用例数；atf-sh 套件运行前显式设置 ATF_LIBEXECDIR/ATF_PKGDATADIR/ATF_SHELL，且 examples_test 在 make install 后运行

**修复命令**:
```
prog -l 枚举; prog <case> 逐条执行; 退出码 0=通过
```

**验证**:
```
./prog -l 枚举 ident; 逐条 ./prog <case> 以退出码判定; 用例总数与各程序用例数须与源码清点一致
```
