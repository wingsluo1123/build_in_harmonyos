# E1074: conandata.yml 注释/非 sources 段含 https URL 被 build_and_test.sh pre-download 正则误提取为下载源

## 基本信息
- **严重度**: 2
- **类别**: python, ci-script, package, url-extraction
- **作者**: 3325, j669539, pc1-23

## 错误特征
```
NotADirectoryError: \[Errno 20\] Not a directory: '.*predl_cache.*/archive/v2\.0\.tar\.gz'|gh-proxy\.com/file://|Could not download from the URL .*file:///
```

## 根因分析
ci/conan/build_and_test.sh 的 pre-download 脚本用 url_pattern

## 推荐方案
**方法**: comment-url-free-conandata

**说明**: conandata.yml 的注释行不得包含带 scheme 的 https:// URL，

**修复命令**:
```
sed -i 's|# upstream: https://github.com/\(.*\)|# upstream: \1|' conandata.yml
```

**验证**:
```
python3 -c "import re;raw=open('conandata.yml').read();\
```
