# E1076: libc++abi 22 构建依赖 clang19+ 的 libc++ 头文件，改用设备 SDK libc++ 15 头文件并收敛差异

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, libc, headers, build-system
- **作者**: 0BA0

## 错误特征
```
__thread/support\.h|__libcpp_aligned_free|source_location|_LIBCPP_HAS_LIBRARY_ALIGNED_ALLOCATION
```

## 根因分析
libcxxabi 22 源码必须搭配同一版本的 libc++ 22 头文件，而 libc++ 22 头文件要求 clang 19+（设备与 CI 工具链为 clang 15），故无法直接用源码树自带头文件构建

## 推荐方案
**方法**: sdk-libcxx15-headers

**说明**: 改用设备 SDK 随附的 libc++ 15 头文件（CMAKE_CXX_FLAGS 中 -isystem 注入，libcxxabi 22 无独立 libcxx includes 变量），命令行补 libc++ 22 配置宏（线程模型/异常/对齐分配），并用补丁收敛三类 API 差异：<__thread/support.h> 用 __has_include 守卫、fallback_malloc 改用 SDK15 <new> 的 __libcpp_aligned_*、stdlib_new_delete 用 libc++ 版本宏区分 __libcpp_aligned_free 重复定义

**修复命令**:
```
cmake -DCMAKE_CXX_FLAGS="-isystem $SDK/include/libcxx-ohos/include/c++/v1 -D_LIBCPP_HAS_THREADS=1 -D_LIBCPP_HAS_THREAD_API_PTHREAD=1 -D_LIBCPP_HAS_EXCEPTIONS=1 -D_LIBCPP_HAS_LIBRARY_ALIGNED_ALLOCATION=1 -fPIC" -DLIBCXXABI_LIBCXX_PATH=<src>/libcxx -DLIBCXXABI_LIBCXX_LIBRARY_PATH=$SDK/lib/aarch64-linux-ohos
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 通过且 libcxxabi/test 全量 pass
```
