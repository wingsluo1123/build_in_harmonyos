# E1079: patch_makefile_in_include_path

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools
- **作者**: CCA7

## 错误特征
```
fatal error: 'otf.h' file not found|otf.h: No such file or directory|top_builddir
```

## 根因分析
上游 Makefile.in/am 只给了 -I$(top_builddir)/src，In-source 构建下 builddir==srcdir 所以正常；Conan 一律 out-of-tree（VPATH）构建，builddir != srcdir，生成的 .o 目录里没有 otf.h，于是示例程序编译报 otf.h file not found

## 推荐方案
**方法**: patch_makefile_in_include_path

**说明**: 给子目录 Makefile.in 的 AM_CPPFLAGS/CPPFLAGS 补 -I$(top_srcdir)/src（源码头文件目录），保留原有 -I$(top_builddir)/src 以兼容 in-source 构建生成的配置头

**修复命令**:
```
patch -p1 < patches/0004-example-Makefile.in.patch
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64（报 otf.h not found 即复现）
```
