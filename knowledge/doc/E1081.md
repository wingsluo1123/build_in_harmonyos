# E1081: HMDFS 大小写不敏感：tarball 顶层 BUILD 文档与 build/ 目录冲突导致 conan 解包在 source 阶段失败

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, portability, build-system, conan, filesystem
- **作者**: 00C9

## 错误特征
```
FileExistsError: [Errno 17] File exists:|Error in source() method, line
```

## 根因分析
鸿蒙设备工作区是 HMDFS，文件系统大小写不敏感（touch AAA 后 stat aaa 与 AAA 返回同一 inode）。

## 推荐方案
**方法**: exclude-collision-member-at-extraction

**说明**: 在解包成员层排除冲突项：conan get(self, **sources, strip_root=True, excludes=['<根目录>/BUILD'])

**修复命令**:
```
get(self, **self.conan_data["sources"], strip_root=True, excludes=["dinit-0.21.0/BUILD"])
```

**验证**:
```
python3 -c "import os;open('AAA','w').close();print(os.path.exists('aaa'))"   # True = 大小写不敏感
```
