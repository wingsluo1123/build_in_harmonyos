# E1083: merge_patches_per_file

## 基本信息
- **严重度**: 3
- **类别**: build-system, tooling
- **作者**: E98D

## 错误特征
```
hunk no.[0-9]+ doesn't match source file at line|doesn't match source file at line|Apply patch failed
```

## 根因分析
patch-ng 是 Conan 的补丁器，严格按 hunk 行号定位，不做 GNU patch 式上下文偏移搜索；同一文件被多个补丁依次修改时，前序补丁的行数增删（本例 configure 被前序补丁改动 +16 行）使后续补丁整块失配，apply 返回 False；而同样两个补丁用 GNU patch 顺序应用却成功——差异只在补丁器实现

## 推荐方案
**方法**: merge_patches_per_file

**说明**: 把同一目标文件的多个补丁合并为一个补丁：所有 hunk 行号统一基于原始文件，patch-ng 一次应用即通过；不要依赖 patch 的模糊偏移能力

**修复命令**:
```
diff -u --label a/configure --label b/configure orig/configure work/configure > patches/0003-configure.patch
```

**验证**:
```
cd 目标文件所在目录 && python3 -c 'import patch_ng; p=patch_ng.fromfile("patches/x.patch"); print(p.apply(strip=1))'（False 即复现）
```
