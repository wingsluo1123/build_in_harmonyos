# E1084: CMake project() 语言列表含 Fortran 时强制探测 Fortran 编译器，与相关 option 关闭无关

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, cmake, toolchain
- **作者**: 9315

## 错误特征
```
No CMAKE_Fortran_COMPILER could be found|CMAKE_Fortran_COMPILER|project\(.*C Fortran\)|Fortran language
```

## 根因分析
CMake 的 project(<name> C Fortran) 在 configure 阶段无条件要求每个声明语言都有可用编译器；即使 CMakeLists.txt 中提供了关闭该语言相关特性的 option（如 FORTRAN_LIB=OFF），编译器探测仍在 project() 处发生，缺失 Fortran 编译器即报 No CMAKE_Fortran_COMPILER could be found

## 推荐方案
**方法**: remove-language-from-project-declaration

**说明**: 从 project() 语言列表移除 Fortran（project(libccp4 C Fortran) → project(libccp4 C)），同时以 option 关闭 Fortran 库构建；适用于 Fortran 部分为可裁剪特性、核心功能在 C 库的场景

**修复命令**:
```
sed -i 's/project(\([^)]*\) C Fortran)/project(\1 C)/' CMakeLists.txt
```

**验证**:
```
cmake .. -DFORTRAN_LIB=OFF 2>&1 | grep "No CMAKE_Fortran_COMPILER" || echo fixed
```
