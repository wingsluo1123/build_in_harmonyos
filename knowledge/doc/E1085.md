# E1085: test_package 访问传递依赖产物时 package_folder 为 None（Conan 判 Skipped binaries）——须显式 requires 该依赖

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, testing, dependencies
- **作者**: 7B7D

## 错误特征
```
Skipped binaries|expected str, bytes or os.PathLike object, not NoneType
```

## 根因分析
Conan 计算 test_package 依赖图时只实例化「被测引用及其被实际消费的依赖」：被测包为 application 且静态链接该依赖、test_package 自身又不链接它时，该传递依赖的 binary 被判为不需要并打印 Skipped binaries <pkg>/<ver>，其 Dependency.package_folder 保持 None，配方里 os.path.join(..., None, 'bin') 于是抛 TypeError

## 推荐方案
**方法**: explicit-require-transitive-dep-in-test-package

**说明**: 在 test_package/conanfile.py 的 requirements() 内显式声明 self.requires(<dep>/<ver>)（版本与被测配方声明完全一致），使 Conan 实例化该 binary 并填充 package_folder；再用 os.path.join(self.dependencies[<dep>].package_folder, 'bin') 定位工具，不从 PATH 取

**修复命令**:
```
def requirements(self): self.requires(self.tested_reference_str); self.requires("cdb/20251021")
```

**验证**:
```
复现：test_package/conanfile.py 只写 self.requires(self.tested_reference_str)，test() 用 self.dependencies[<dep>].package_folder 时 conan create 先打印 Skipped binaries <dep>/<ver> 再抛 TypeError: expected str, bytes or os.PathLike object, not NoneType（dbskkd-cdb 3.00 实测）；在 requirements() 增加与配方完全同版本的 self.requires(<dep>/<ver>) 后同一条命令通过
```
