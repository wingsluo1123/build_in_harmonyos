# E1088: QBS 生态项目适配 OHOS：上游仅提供 .qbs 构建文件，改写为 CMakeLists.txt 补丁并在 Conan 配方注入 Qt5 消费路径

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan, qt5
- **作者**: unknown

## 错误特征
```
"qbs: command not found|Project file.*\\.qbs.*not found|Automatic MOC.*moc.*symbol not found|source/target file does not exist:( --- b'.*)"
```

## 根因分析
上游项目（如 dewalls 1.0.0）仅提供 QBS（Qt Build Suite）构建文件 dewalls.qbs，仓库无 CMakeLists.txt/Makefile/configure。OHOS 适配 CI（build_in_harmonyos）能力矩阵无 QBS 工具链（仅有 gcc/clang/make/cmake/ninja/bash），QBS 在离线/CI 环境不可用。直接编译必然失败。改写为 CMakeLists.txt 是唯一可行路径：需要根据 dewalls.qbs 声明的目标全集（DynamicLibrary dewalls + CppApplication dewalls-test，Depends Qt core，AUTOMOC/AUTORCC）手工等价转换，并处理 OHOS 特有坑（qt 产物 CMake 找不到、moc 运行时缺 libc++_shared.so、新文件补丁头必须是 /dev/null 而非 a/）。

## 推荐方案
**方法**: qbs-to-cmake-rewrite-with-qt5-conan-consumption

**说明**: "(1) 删掉 orig 目录 0 字节污染文件后运行 refresh-patch --auto，用 /dev/null 头 + strip:1 生成新增 CMakeLists.txt 补丁；(2) CMakeLists.txt 用 file(GLOB) 聚合 src/*.cpp + src/*.h，set(CMAKE_AUTOMOC ON), set(CMAKE_AUTORCC ON), find_package(Qt5 5.15 REQUIRED COMPONENTS Core)，add_library(dewalls SHARED ...) 并 set_target_properties VERSION/SOVERSION（OHOS 必须显式 CMAKE_SHARED_LIBRARY_SONAME_CXX_FLAG=-Wl,-soname,）；(3) 测试目标 add_executable(dewalls-test test/*.cpp qrc) + enable_testing/add_test，构建期 ctest 运行上游 Catch 测试；(4) Conan 配方 requirements 中 qt/5.15.19 用 visible=False（qt 自带 Qt5Config.cmake 且 cmake_find_mode=none，CMakeDeps 不生成 qt-config，避免下游 find_dependency(qt) 崩溃），消费者自理 Qt5：generate() 把 qt package_folder 注入 CMAKE_PREFIX_PATH、test_package 显式 requires qt/5.15.19 + CMakeDeps.set_property(\"qt\",\"cmake_find_mode\",\"none\")；(5) AUTOMOC 的 moc 运行需 libc++_shared.so：generate()/build() 把 OHOS SDK llvm/lib 与 aarch64-linux-ohos 子目录 prepend LD_LIBRARY_PATH；(6) conandata.yml patches 声明 strip: 1（abx 先例同款）。"

**验证**:
```
conan create archives/d/dewalls/1.0.0 -pr:h=ci/conan/profiles/ohos-aarch64 ... && ctest --test-dir build --output-on-failure
```
