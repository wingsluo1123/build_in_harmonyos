# E1091: raw Makefile 配方手工拼接 GnuToolchain 的 CFLAGS 时 defines 是裸宏名，缺 -D 前缀被 clang 当成源文件

## 基本信息
- **严重度**: 2
- **类别**: make, toolchain, conan
- **作者**: F93D

## 错误特征
```
no such file or directory: 'NDEBUG'|CFLAGS="-O3 NDEBUG"
```

## 根因分析
GnuToolchain.defines 返回的是「裸宏名」列表（Release 下为 ['NDEBUG']），-D 前缀由消费方补——AutotoolsToolchain/CMakeToolchain 内部自行拼 -D 与 /D，而 raw Makefile 工程没有 configure/cmake 代它拼 flags；配方按直觉写 " ".join(tc.cflags + tc.defines) 时 NDEBUG 就变成独立的编译参数，clang 把第一个非选项参数当成输入文件，报 no such file or directory: 'NDEBUG'，真实错误完全落在 clang/源文件名上而不指向配方行

## 推荐方案
**方法**: add-cflags

**说明**: 拼接 CFLAGS 时给 defines 逐项补 -D 前缀：cflags = " ".join(tc.cflags + [f"-D{d}" for d in tc.defines])

**修复命令**:
```
make -j1 CC="${CC}" CFLAGS="<tc.cflags> -D<tc.defines 逐项>"
```

**验证**:
```
grep -m1 'RUN: make' <conan create 日志>  # 修复后应出现 CFLAGS="-O3 -DNDEBUG"；未修复时同一行是 CFLAGS="-O3 NDEBUG"，紧随其后首条错误为 clang-15: error: no such file or directory: 'NDEBUG'
```
