# E1093: 手写 install-data-local 缺 DESTDIR 且未用 srcdir 前缀，conan staging 下装错位置或找不到源文件

## 基本信息
- **严重度**: high
- **类别**: build-system, autotools, packaging
- **作者**: BED8
- **来源 PR**: !9639

## 错误特征
```
package 内缺少 etc/cpu.conf（或文件装到了宿主 /etc 而非包的 DESTDIR 下）；doc/Makefile.in 的 install-data-local 报 "cpu.conf: No such file or directory"（out-of-tree 时）
```

## 根因分析
老 autotools 工程的手写 install-data-local 规则假设两点：①安装目标是宿主根(缺 $(DESTDIR) 前缀)；②源文件在构建目录中(直接用 cpu.conf 而非 $(srcdir)/cpu.conf)。conan 走 out-of-tree 构建 + DESTDIR staging，两个假设同时失效：文件找不到 或 静默装进宿主 /etc（污染构建机）

## 推荐方案
**方法**: patch-install-rule

**说明**: 以最小补丁修正 install-data-local：源文件加 $(srcdir)/ 前缀、目标补 $(DESTDIR) 前缀（cpu 的 0004-doc-Makefile.in.patch 即此形态，可上游化）

**修复命令**:
```
patch doc/Makefile.in: "cpu.conf $(sysconfdir)/cpu.conf" → "$(srcdir)/cpu.conf $(DESTDIR)$(sysconfdir)/cpu.conf"
```

**验证**:
```
make install DESTDIR=$TEST_PREFIX 后检查 $TEST_PREFIX/etc/cpu.conf 是否存在，并确认宿主 /etc/cpu.conf 未被写入
```
