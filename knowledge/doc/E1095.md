# E1095: conan self.run() always dies with SIGSEGV on this platform

## 基本信息
- **严重度**: high
- **类别**: toolchain, conan, runner
- **作者**: F695
- **来源 PR**: !9639

## 错误特征
```
ConanException: Error -11 while executing
```

## 根因分析
The platform /bin/sh (mksh) cannot launch external programs from conan's runner: every self.run() in test_package ends with Error -11 (string form, list form, with and without env=conanrun, even self.run(["echo"])); the build phase (autotools, env="") is unaffected.

## 推荐方案
**方法**: bypass-conan-runner

**说明**: Do not call self.run() in test(); start the script with Python subprocess and set LD_LIBRARY_PATH / PATH / CPU_TEST_ROOT yourself

**修复命令**:
```
subprocess.check_call([bash, "test.sh"], cwd=os.path.dirname(os.path.realpath(__file__)), env=env)
```

**验证**:
```
conan test test_package <ref> -pr:h ci/conan/profiles/ohos-aarch64 --build=never
```
