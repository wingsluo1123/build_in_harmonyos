# E1096: OHOS libc 导出 index 但不导出 BSD 遗留别名 rindex：先 nm 核对符号表再改写为 POSIX strchr/strrchr

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability, libc, musl
- **作者**: EB2A, 1D03

## 错误特征
```
undefined symbol: rindex|did you mean: index|call to undeclared library function 'rindex'|include the header <strings.h> or explicitly provide a declaration for 'rindex'
```

## 根因分析
|

## 推荐方案
**方法**: source-patch

**说明**: 先把 index/rindex 统一改写为 POSIX strchr/strrchr（两者都在 string.h 中声明，

**修复命令**:
```
sed -i 's/rindex(/strrchr(/g' <files>   # toybox sed 不支持 \b 词边界，只用字面串
```

**验证**:
```
nm -D --defined-only $SYSROOT/usr/lib/aarch64-linux-ohos/libc.so | grep -E ' (index|rindex)$'
```
