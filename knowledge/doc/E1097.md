# E1097: 老 CLI 工具只登记短选项，CI 的 --version/--help 冒烟测试失败

## 基本信息
- **严重度**: 2
- **类别**: portability, testing, cli, getopt
- **作者**: 272F

## 错误特征
```
unrecognized option '--version'|invalid option -- 'version'|--help.*usage
```

## 根因分析
上游用 getopt 只登记 -v/-h/-o；CI 的 L2 冒烟测试用 --version/--help 探测可执行产物，未知长选项会打印 usage 并按上游逻辑退出（rc 非 0），导致冒烟测试判定失败

## 推荐方案
**方法**: patch-getopt-long

**说明**: 补丁把 getopt 换成 getopt_long 并把 --help/--version/--output 映射到既有短选项分支，保持原行为；注意 usage 文本也要补长选项说明

**修复命令**:
```
getopt_long(argc, argv, "ho:qv", long_options, NULL); && <tool> --version && <tool> --help
```

**验证**:
```
<tool> --version && <tool> --help
```
