# E1102: 老 CMakeLists 的 FIND_PATH/FIND_LIBRARY 写死 /usr 路径，交叉编译找不到依赖；用 cache_variables 注入同名变量即可，无需改上游脚本

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, cross-compile, conan
- **作者**: 6052

## 错误特征
```
Could NOT find XML2|Could NOT find ZLIB|FIND_LIBRARY.*NOTFOUND
```

## 根因分析
FIND_PATH(XML2_INCLUDE_DIR libxml/xmlreader.h /usr/local/include/libxml2 /usr/include/libxml2) 只在这些绝对路径查找；但 FIND_* 命中同名 cache 变量时直接采用，因此可在配方 generate() 阶段按 self.dependencies[dep].cpp_info 注入 <PKG>_INCLUDE_DIR/<PKG>_LIBRARY

## 推荐方案
**方法**: cache-variable-injection

**说明**: 在 conanfile generate() 用 tc.cache_variables 注入 XML2_INCLUDE_DIR/XML2_LIBRARY（值取 self.dependencies['libxml2'].cpp_info），比改上游 CMakeLists 侵入更小；静态依赖（zlib）显式指向 libz.a 以符合 R26

**修复命令**:
```
conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing
```

**验证**:
```
grep -E 'XML2_(INCLUDE_DIR|LIBRARY)|ZLIB_(INCLUDE_DIR|LIBRARY)' build/CMakeCache.txt && conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing
```
