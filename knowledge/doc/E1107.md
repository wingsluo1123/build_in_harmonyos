# E1107: 手写 Makefile 用命令行 VAR= 注入工具链会整条替换复合定义（丢掉 $(DEFS)/-I）或抑制 += 累积，两种形态两种表象

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, headers, build-system
- **作者**: 5818

## 错误特征
```
file not found|use of undeclared identifier
```

## 根因分析
GNU make 的变量优先级是「命令行赋值 > makefile 内赋值 > 环境变量」，命令行的 VAR=value 不是追加而是接管：makefile 把 CC 写成复合值（gcc 拼上全部 flags）时，命令行 CC=clang 会整条替换该定义，上游自己的 $(DEFS)/-I/-Wall 一并丢失，表现为「找不到头文件」；makefile 用 CFLAGS += 累积 flags 时，命令行 CFLAGS= 会抑制该 +=，累积内容全部消失，表现为「找不到宏」

## 推荐方案
**方法**: shape-aware-makefile-var-injection

**说明**: 先判形态再选修法：复合定义形态在 makefile 里加 CC_BIN ?= gcc 旋钮并把 CC 改为引用它（配方传 CC_BIN="$CC"，flags 仍归 makefile）；+= 累积形态改用环境变量传 flags（环境变量不会被抑制）；递归构建必须逐个子目录 makefile 一起改

**修复命令**:
```
make -j1 linux CC_BIN="$CC" ; grep -rn '^\s*CC\s*=' src/ --include='Makefile*'
```

**验证**:
```
grep -nE '^\s*(CC|CXX|CFLAGS|CPPFLAGS)\s*[:+?]?=' src/Makefile* && make CC=clang V=1 2>&1 | grep -m1 '^clang'
```
