# E1108: CI worker 无法直连外部源码主机导致下载超时（改用 CDN/镜像端点）

## 基本信息
- **严重度**: medium
- **类别**: network
- **作者**: 435E

## 错误特征
```
源码下载超时 (https://<origin-host>/...); Worker 网络受限，无法访问外部源码仓库
```

## 根因分析
CI worker 出网受限：对非镜像表内的外部主机（如 snapshot.debian.org 源站，单机限速/无 CDN）直连下载 5MB 级 tarball 无法在 curl --max-time 300 预算内完成；ci/conan/build_and_test.sh 的 get_mirrors 只为 github/gnu/gnome/kernel/xorg/pythonhosted/sourceforge 等白名单主机生成镜像列表，Debian 归档类端点不在表内，因此没有 fallback

## 推荐方案
**方法**: 1) 优先选择 CI 可达的官方 CDN/镜像端点：Debian snapshot 用 snapshot-cloudflare.debian.org（与 snapshot.debian.org 同源同字节，sha256 不变），主归档用 deb.debian.org；2) 换端点后必须复验 sha256 与本地 conan create；3) 若目标主机仅源站可用，先按 R41/W3 止损口径评估 external_dependency
