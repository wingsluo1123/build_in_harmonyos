# E1110: 工程完全没有 cmake_minimum_required 时 CMake 4 直接硬报错，CMAKE_POLICY_VERSION_MINIMUM 不生效

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, build-system, cmake
- **作者**: 00AE

## 错误特征
```
No cmake_minimum_required command is present
```

## 根因分析
CMake 4.x 对缺少 cmake_minimum_required 的工程直接报错（CMP0000 硬错误）；-DCMAKE_POLICY_VERSION_MINIMUM 仅对已声明 <3.5 的工程生效，对完全没有该命令的工程无效

## 推荐方案
**方法**: patch-cmake-minimum

**说明**: 在顶层 CMakeLists.txt 顶部补 cmake_minimum_required(VERSION 3.5) 并以补丁归档（与 E321 的 cache_variables 路线区分；E321 适用已声明旧版本的工程）

**修复命令**:
```
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=ohos.toolchain.cmake && cmake --build build
```

**验证**:
```
grep -q '^cmake_minimum_required(VERSION 3.5)' CMakeLists.txt && cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=ohos.toolchain.cmake && cmake --build build
```
