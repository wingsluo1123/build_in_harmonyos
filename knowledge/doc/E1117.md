# E1117: legacy libmpeg3 Makefile portability fixes for OHOS

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, make
- **作者**: 08C6

## 错误特征
```
No rule to make target 'mpeg3css\.c'|mpeg3css\.c: No such file|__off64_t( undeclared)?
```

## 根因分析
upstream source assumes bundled CSS source and nonportable __off64_t

## 推荐方案
**方法**: use distributed fake CSS implementation and standard off_t; ref: archives/l/libmpeg3/1.8.dfsg/notes.md

**说明**: Apply the three portability fixes before building libmpeg3 on OHOS

**修复命令**:
```
conan create archives/l/libmpeg3/1.8.dfsg -pr:h=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create archives/l/libmpeg3/1.8.dfsg -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
