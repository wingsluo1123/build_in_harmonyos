# E1118: 大型 Debian Blend（40+ 元包：45 science-* 包 + 46 tasks + 42 desc 段落）的 R47 预检分流：识别为 metadata/registry 包而非编译型包

## 基本信息
- **严重度**: 2
- **类别**: detection, ohos, build-system, make, packaging
- **作者**: unknown

## 错误特征
```
detected_language.*\bc\b.*无源文件可统计|include /usr/share/blends-dev|^Package:\s+science-\S+|^Task:\s+\S+.*\n.*^Key:\s+science-
```

## 根因分析
lang_detect.py 三级判定（manifest>构建系统>源码统计≥70%）中，大型 Debian blend 元包与小型 blend 同构：顶层 Makefile 仅一行 "include /usr/share/blends-dev/Makefile" → 归为 make 构建系统 → 推入 c/cpp 兼容族；源码统计为零（97 文件无任何 .c/.cpp/.h 可统计文件）→ 命中"构建系统优先"路径，输出 detected_language=c 且 exit 0。规模特征（control 45 个 Package 声明 / tasks 46 个任务文件 / desc 42 段落）是**识别置信信号**，用于判定"这是打包元数据而非编译源码"；关键结论是分流——detected=c 只说明检测器把它归入了 C 兼容族，**既不意味着需要硬编 C/C++ 配方，也不意味着不可适配**：blend 元包的真实价值在依赖图 + task/desc 定义 + tasksel 元数据，可用单个 metadata/registry Conan 包装载真实上游产物（任务文件 + tasksel desc + 官方依赖快照 + 派生 registry.json），零 Conan requires，配套消费者测试即可交付

## 推荐方案
**方法**: debian-pure-blend-metadata-registry-package

**说明**: 识别大型 blend 的四重规模特征（①control 多 Package: 声明且全部 Architecture: all、②tasks/ 大量 Deb822 任务文件、③tasksel desc 的 Task:/Key: 层级、④dependency_data 版本序列 JSON）后，按 metadata/registry 包路径适配：单 recipe、package_type="unknown"、settings 四项（过 CI L0 门禁）、requirements() 为空（**Debian 的 Depends/Recommends/Suggests 是 OS 包选择，禁止机械复制为 Conan requires**）、package() 装真实上游产物（tasks/* 原文 + tasksel desc 原文 + 官方依赖快照 + build() 纯解析派生的 registry.json + licenses/copyright）、package_info() 置 resdirs=["share"]。registry.semantics 记录 blends 旧格式语义（无 Format: 头 → 文件级 Depends 降级为元包 Recommends，元包另 Depends: <blend>-tasks (=version)）。R47 的 detected_language 仍按 §4.6 如实填 c（c↔cpp 兼容族），但任务**继续走适配主流程而非终止**

**修复命令**:
```
conan create archives/d/debian-science/1.15 -pr:h ci/conan/profiles/ohos-aarch64 -pr:b ci/conan/profiles/ohos-aarch64   # 实测 RC=0，test_package 33 项断言全 PASS（参考实现与判据见 notes.md / test_package/MANIFEST.yml）
```

**验证**:
```
python3 scripts/ohc-run.py lang-preflight debian-science 1.15 --src ${SRC_DIR} → detected_language=c、exit 0；分流辅助证据 grep -c '^Package:' debian/control → 45、ls tasks/ | wc -l → 46、grep -c '^Task:' debian-science-tasks.desc → 42、grep -c '^Key:' debian-science-tasks.desc → 41、find -type f \( -name '*.c' -o -name '*.cpp' -o -name '*.h' \) | wc -l → 0
```
