# E1119: ohpcd libcurl ships a TLS-less variant (https -> CURLE_UNSUPPORTED_PROTOCOL); build a test-only TLS curl into a private prefix from source + device OpenSSL

## 基本信息
- **严重度**: 2
- **类别**: ohos, network, conan, testing
- **作者**: Awstme

## 错误特征
```
CURLE_UNSUPPORTED_PROTOCOL|error_code\(\) == 1|with_openssl|SSL.*symbol not found|https.*response_code\(\) == 0
```

## 根因分析
ohpcd 发行 libcurl/8.5.0 的 .so 无任何 TLS 后端：

## 推荐方案
**方法**: test-only-curl-private-prefix

**说明**: 按 workflow §7.3「测试依赖自建私有 prefix」路径：下载与

**修复命令**:
```
cmake -S . -B build-cmake -G Ninja -DCMAKE_INSTALL_PREFIX=$TASK_DIR/test-prefix -DBUILD_CURL_EXE=OFF -DBUILD_TESTING=OFF -DCURL_USE_OPENSSL=ON -DOPENSSL_ROOT_DIR=$HOME/.harmonybrew -DHAVE_LINUX_TCP_H=OFF -DCURL_USE_LIBPSL=OFF -DUSE_LIBIDN2=OFF -DUSE_NGHTTP2=OFF -DCURL_ZLIB=OFF && ninja -C build-cmake -j1 && cmake --install build-cmake
```

**验证**:
```
strings <conan curl p>/lib/libcurl.so | grep -c 'OpenSSL/[0-9]'; readelf -d <同上> | grep NEEDED —— 均 0/仅 libc 即确认无 TLS 变体；运行时 LD_LIBRARY_PATH=<curl lib> curl 形消费者 https 返回 CURLE_UNSUPPORTED_PROTOCOL(1)
```
