# E1120: OHOS musl 的 libutil.a 是零成员空档案：链接探测“成功”但零符号贡献，BSD pty 函数已并入 libc

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, libc, musl, linking
- **作者**: CBD3

## 错误特征
```
(unable to find library -lutil)|(ld\.lld.*cannot open.*libutil\.a)|(-lutil.*no such file)|(^ar t .*libutil\.a$)
```

## 根因分析
OHOS musl 把 BSD pty 接口（forkpty/openpty/login_tty 等）

## 推荐方案
**方法**: drop-unused-ldflags

**说明**: 配方不执行上游的 -lutil：直接按上游源码同义改写链接

**修复命令**:
```
sed -n '9p' Makefile  # LIBS ?= -l$(CURSESLIB) -lutil
```

**验证**:
```
ar t /storage/.../usr/lib/aarch64-linux-ohos/libutil.a | wc -l  # → 0
```
