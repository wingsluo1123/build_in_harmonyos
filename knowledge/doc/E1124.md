# E1124: Meson 项目 CI 专杀：native file 未声明 ar 且 worker PATH 无 llvm-ar——setup 阶段探测静态归档器即失败

## 基本信息
- **严重度**: 2
- **类别**: build-system, meson, conan
- **作者**: unknown, pc1-17
- **来源 PR**: "!8549"

## 错误特征
```
Unknown linker\(s\): \[\[.[a-z-]*ar.\]\]|Running .[a-z-]*ar --version. gave|No such file or directory.*llvm-ar
```

## 根因分析
"Conan MesonToolchain 生成的 conan_meson_native.ini 的 [binaries] 段只写 c/cpp 的绝对路径、不写 ar；meson setup 在编译器探测阶段要为 C 工具链探测静态归档器，按裸名 llvm-ar/ar 逐个尝试。本地设备 PATH 携带 ar（如 ~/.local/bin、harmonybrew），验证全绿；CI worker PATH（/data/app/bin:/system/bin:/system/sbin:/vendor/bin:~/.local/bin）没有，setup 即报 ERROR: Unknown linker(s): [['llvm-ar']]。header-only、没有任何库目标的项目同样在探测阶段被杀——失败与目标产物无关，纯粹是工具链探测。"

## 推荐方案
**方法**: inject-absolute-ar-into-meson-native-file

**说明**: "generate() 里 tc.generate() 之后，对 <generators_folder>/conan_meson_native.ini 做内容替换：把 [binaries] 段落首行前插入 ar = '<绝对路径>/ar'（取 /data/service/hnp/bin/ar，与 profile 已钉死的 clang 同目录，bstring 与 c-stdaux 双先例 CI 实证）；替换锚点 '[binaries]\\nc =' 不存在时必须 raise，防止静默失效。"

**修复命令**:
```
sed -i "s|\\[binaries\\]|\\[binaries\\]\\nar = '/data/service/hnp/bin/ar'|" conan_meson_native.ini（配方内以 Python 精确替换实现）
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
