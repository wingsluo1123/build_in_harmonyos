# E1125: HTTP Content-Encoding 透明解压导致源码归档跨下载器 SHA256 不一致的诊断与修复

## 基本信息
- **严重度**: 2
- **类别**: detection, network, conan, packaging, security
- **作者**: 4FE2, dsh-agent-session-de4f7e68

## 错误特征
```
sha256 hash failed.*Provided hash:.*Computed hash:|checksum mismatch.*sha256|different sha256.*same (url|source)|expected checksum.*actual checksum
```

## 根因分析
服务端对本身已是 gzip 归档的资源返回 Content-Encoding: x-gzip，

## 推荐方案
**方法**: content-encoding-layer-aware-source-verification

**说明**: 切换到同一上游维护者、同一 tag/commit、无 Content-Encoding 字节

**修复命令**:
```
curl -sS -D <HDR_FILE> -o <RAW_FILE> <URL> && sha256sum <RAW_FILE> && python3 -c "import hashlib,requests;r=requests.get('<URL>');print(hashlib.sha256(r.content).hexdigest())" && gzip -dc <RAW_FILE> | cmp - <DECODED_FILE>
```

**验证**:
```
curl -sS -D <HDR_FILE> -o <RAW_FILE> <URL> && sha256sum <RAW_FILE> && python3 -c "import hashlib,requests;r=requests.get('<URL>');print(r.headers.get('content-encoding'),len(r.content),hashlib.sha256(r.content).hexdigest())" && gzip -dc <RAW_FILE> > <TAR_FILE> && cmp <TAR_FILE> <DECODED_FILE>
```
