## 推荐方案
**方法**: >

**说明**: 头文件中全局变量全部改 extern 声明；新增一个 .c 集中定义；同步注册进构建文件——注意 tarball 预生成 Makefile.in 时 make 实际读 .in，需同时改 Makefile.am（base 列表）与 Makefile.in（base 与 am__objects_1），缺一处则链接缺符号或定义不参与构建。案例（dirb/2.22）与 AUR 同源 patch 同思路。

**修复命令**:
```
编辑头文件加 extern；新增 src/variables.c；注册 src/Makefile.am 的 base 与 src/Makefile.in 的 base 及 am__objects_1；重新 configure && make
```

**验证**:
```
mkdir -p /tmp/probe-fnoc && cd /tmp/probe-fnoc && printf 'typedef struct { int x; } opts_t;\nopts_t g_opts;\nint g_counter;\n' > globals.h && printf '#include "globals.h"\nint main(void){ return g_counter + g_opts.x; }\n' > a.c && printf '#include "globals.h"\n' > b.c && clang a.c b.c -o prog_default
```
