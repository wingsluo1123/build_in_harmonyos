# E1131: Meson install rewrites DT_RUNPATH bytes inside .dynstr and invalidates the embedded .codesign hash; overwrite the installed .so with the pristine build-tree artifact

## 基本信息
- **严重度**: 2
- **类别**: ohos, meson, packaging, security
- **作者**: Awstme

## 错误特征
```
Error loading shared library|Permission denied.*dlopen|dlopen.*Permission denied|symbol not found.*NEEDED|Error relocating
```

## 根因分析
hnp 工具链的 ELF 产物自带链接器签名（.codesign section，

## 推荐方案
**方法**: overwrite-installed-so-with-build-artifact

**说明**: package() 阶段把 build 目录中的原始 .so 复制覆盖安装后的

**修复命令**:
```
shutil.copy2(os.path.join(self.build_folder, "<lib>.so.<ver>"), os.path.join(self.package_folder, "lib", "<lib>.so.<ver>"))
```

**验证**:
```
readelf -S <安装副本.so> | grep -c codesign; sha256sum <build-tree .so> <安装副本 .so> —— 两文件哈希不同且安装副本仍带 .codesign section 即确认
```
