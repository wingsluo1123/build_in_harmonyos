# E1133: C 库临时文件模板缓冲区按硬编码 /tmp 路径长度定长计算：长 TMPDIR 被 snprintf 长度检查拒绝或截断

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, portability, libc, build-system
- **作者**: E861

## 错误特征
```
Cannot create a unique file name|mkdtemp: Read-only file system|Mat_VarDelete.*error|snprintf.*truncat
```

## 根因分析
上游按硬编码 "/tmp/" + "XXXXXX" + "/temp.mat"（21 字节）定长计算临时文件模板缓冲区 MAT_MKTEMP_BUF_SIZE，且 mkdtemp 模板硬编码 /tmp。OHOS 根文件系统只读 → mkdtemp("/tmp/XXXXXX") 直接失败；即使代码读取 $TMPDIR，snprintf 的长度检查也会拒绝比 21 字节长的任何真实临时目录路径，或截断后回退 /tmp 仍然失败

## 推荐方案
**方法**: source-patch-tmpdir-pathmax-buffer          # 见 DESIGN §5 impl 列表

**说明**: 模板缓冲区以 PATH_MAX 计算 + TMPDIR 优先解析 + 超长 TMPDIR 回归测试的三位一体源码修复

**修复命令**:
```
TMPDIR=<超长可写目录> ctest -R readwrite_delete_variables && conan test test_package
```

**验证**:
```
TMPDIR=<长度>21B 的可写目录 ctest -R readwrite_delete_variables；修复前 391/8197 失败，修复后 8197/8197 全过
```
