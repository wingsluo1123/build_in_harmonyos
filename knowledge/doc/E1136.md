# E1136: HarmonyOS toybox gzip 解压仅识别 .gz 后缀 → 脚本解压 .tgz/.tar.z 需用 -c 管道输出

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, portability
- **作者**: E8BC
- **来源 PR**: 8957

## 错误特征
```
gzip: no \.gz: .*\.tar\.z|gzip: no \.gz|cannot defeather .*\.tar\.z|gzip: Unknown option 'S'
```

## 根因分析
HarmonyOS gzip 为 toybox 0.8.12，gzip -d 仅识别 .gz 后缀文件名；脚本（如 z 工具）解压 .tgz 时先改名 .tar.z 再调 gzip -d，toybox 报 gzip: no .gz 拒绝解压，且 toybox gzip 不支持 -S 选项改后缀

## 推荐方案
**方法**: 解压调用改为 gzip -d -n -c "$arg" > "$tarf"（stdout 管道输出不检查后缀），失败回退原命令

**说明**: gzip 解压改 -c 管道重定向，绕过后缀检查（toybox 兼容）

**修复命令**:
```
sed -i 's|\$ucommand "\$arg"|if $ucommand -c "$arg" > "$tarf" 2>/dev/null; then rm -f "$arg"; else rm -f "$tarf"; $ucommand "$arg"; fi|' z
```

**验证**:
```
cp x.tgz x.tar.z && gzip -d -n -c x.tar.z > out.tar && echo OK
```
