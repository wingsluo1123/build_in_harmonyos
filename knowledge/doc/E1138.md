# E1138: 纯 Makefile 项目 pkg-config 依赖探测回退与 make 命令行 LDFLAGS 接管

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, conan
- **作者**: DB80

## 错误特征
```
cannot find -lssl|cannot find -lcrypto|pkg-config: not found|undefined reference to .SSL_|undefined reference to .OPENSSL
```

## 根因分析
plain Makefile 项目常以 LDFLAGS += $(SSL_LIBS) 方式注入依赖且 SSL_LIBS 由 pkg-config 探测;OHOS 无系统 openssl 开发库时 pkg-config 失败,Makefile 回退为裸 -lssl -lcrypto,链接器在默认搜索路径找不到库而报 cannot find -lssl

## 推荐方案
**方法**: command-line-LDFLAGS-takeover

**说明**: make 命令行传入 LDFLAGS=-L<conan_pkg>/lib -lssl -lcrypto 与 CFLAGS=-fPIC -O2 -I<conan_pkg>/include;make 命令行变量优先级高于 Makefile 内 += 追加赋值,可整体接管链接参数并指向 conan openssl 静态库,无需打补丁

**修复命令**:
```
make -j1 CC=clang CFLAGS=-fPIC -O2 -I$(conan cache path openssl/3.5.6.1)/include LDFLAGS=-L$(conan cache path openssl/3.5.6.1)/lib -lssl -lcrypto
```

**验证**:
```
conan create 后 readelf -d bin/<binary> 确认无 libssl.so NEEDED(静态链接成功)且 proxytunnel -V 正常输出
```
