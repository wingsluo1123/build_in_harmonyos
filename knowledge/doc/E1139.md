# E1139: inetd 风格 CLI（micro_inetd 类 spawner）在无 systemd/特权环境下的 test_package 真实 socket→stdin/stdout 契约验证方法与三段式进程清理

## 基本信息
- **严重度**: 2
- **类别**: ohos, socket, network, testing, process-control
- **作者**: 1A5C

## 错误特征
```
inetd|spawner|accept.*fork|dup2.*socket|socket.*stdin|execv.*service|
```

## 根因分析
inetd 风格程序（micro_inetd 类 spawner）本体只做 listen→accept→fork→dup2(socket 到 0/1/2)→execv，自身不实现应用协议；无 systemd/inetd 的目标环境没有现成挂载点，--help/--version 冒烟不证明 socket 契约，execv 失败的 perror 会沿 dup2 后的 stderr(socket) 回传客户端（真实 inetd 语义），且无特权端口可用、测试结束不 waitpid 会留孤儿/僵尸与端口占用

## 推荐方案
**方法**: inetd-spawner-socket-contract-test

**说明**: test_package 自带极小服务 fixture，C 驱动 fork+execl 已安装的 spawner，6 用例覆盖字节中继/退出码 EOF/并发/重复连接/execv 失败回传/usage；端口 bind(0) 探测，三段式 SIGTERM→waitpid 轮询→SIGKILL 兜底清理，负向验证证明测的是安装产物。

**修复命令**:
```
conan test <pkg>/test_package micro_inetd/2014-8-14 -pr:h ohos-aarch64 -pr:b ohos-aarch64
```

**验证**:
```
conan create <pkg> --name=micro_inetd --version=2014-8-14 -pr:h ohos-aarch64 -pr:b ohos-aarch64 && conan test <pkg>/test_package micro_inetd/2014-8-14 && ps aux | grep -c "[m]icro_inetd\|[s]vc_"
```
