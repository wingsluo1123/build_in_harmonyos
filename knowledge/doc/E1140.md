# E1140: clang aarch64 下 (int64_t)NaN float→int64 转换在 -O2 为 UB 生成垃圾值

## 基本信息
- **严重度**: 2
- **类别**: platform, compiler, testing, optimization, ub
- **作者**: PC32

## 错误特征
```
cvtss_si64_nan|_mm_cvtss_si64|res == indefinite|int64.*NaN
```

## 根因分析
sse2neon _mm_cvtss_si64 用 C++ static_cast 将 NaN float 转 int64；(int64_t)NaN 是未定义行为。clang aarch64 -O2 常量折叠/代码生成返回垃圾值（实测 370999932605、543919170456 等，非 0 非 INT64_MIN），-O0 返回 0（上游允许值）；x86 硬件则返回 INT64_MIN（indefinite）

## 推荐方案
**方法**: 诊断：分别 -O0/-O2 编译同一 NaN 转换复现；-O0 返回 0 而 -O2 返回垃圾值即为命中。处置：涉 NaN float→int64 的业务代码需显式 isnan/isfinite 守卫或使用饱和转换指令；适配库测试失败如实记录为编译器 UB 差异，-O0 通过即满足上游允许语义

**说明**: 涉 NaN→int64 转换必须显式守卫；上游测试失败记录为编译器 UB 差异而非平台缺陷

**修复命令**:
```
clang++ -O0 -I. -march=armv8-a+fp+simd tests/nan.cpp tests/common.cpp tests/binding.cpp -lm -o /tmp/nan-O0
```

**验证**:
```
printf '(int64_t)NaN at -O0/-O2'
```
