# E1141: CMake 定向 --target 构建绕过 ALL 生成目标，cmake --install 因安装清单引用的生成物（.pc/compat 头/软链）缺失而失败

## 基本信息
- **严重度**: 3
- **类别**: detection, ohos, build-system, cmake, packaging
- **作者**: 9C21

## 错误特征
```
CMake Error.*file INSTALL cannot find|file INSTALL cannot find \"[^"]+\"|INSTALL.*cannot find.*\.pc|cmake --install.*failed|Installing:.*\.pc.*No such file|file INSTALL cannot find.*zziplib\.pc|file INSTALL cannot find.*\.so\.[0-9]+|cannot install.*file.*does not exist
```

## 根因分析
构建闭包未覆盖安装清单闭包（两因素叠加）：配方显式 --target 只编部分目标绕过上游 ALL 闭包中的元数据生成目标；平台门控 if(UNIX OR MINGW) 使 HarmonyOS 下元数据选项静默默认 OFF。

## 推荐方案
**方法**: restore-default-all-install-generation-closure

**说明**: ① 删除显式 --target 列表，恢复默认 ALL 构建，让上游挂在 ALL 上的

**修复命令**:
```
cmake -B build -S src -D<XXX>_PKGCONFIG=ON -D<XXX>_COMPAT=ON -D<XXX>_LIBTOOL=ON && LD_LIBRARY_PATH=build/<libdir> cmake --build build -j$(nproc) && ls build/<subdir>/*.pc && cmake --install build --prefix <pkg> && conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64
```

**验证**:
```
grep -R -nE 'add_custom_target\([a-zA-Z_]+ ALL|install\(FILES' <src> | head -30; grep -R -n 'if(UNIX OR MINGW)' <src>/*/CMakeLists.txt; cmake -B build -S <src> 2>&1 | grep -iE 'installing.*pkgconfig|installing.*compat|option.*OFF'
```
