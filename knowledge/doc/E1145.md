# E1145: lang-preflight 源码统计被生成文档资产污染致 mixed 误报：文档资产识别与按主体裁定

## 基本信息
- **严重度**: 3
- **类别**: detection, toolchain
- **作者**: E4F7
- **来源 PR**: "!8542"

## 错误特征
```
detected=mixed → env_unsupported|manifest=cpp 但统计 nodejs|主体占比 [0-9]+%|nodejs:[0-9]+, cpp:[0-9]+|语言不匹配: task=cpp, detected=mixed
```

## 根因分析
lang_detect 的 source_stats 统计把 doc/html/ 等 doxygen 生成文档资产（jquery.js、search/*.js、*.html）计为 nodejs/html 源文件，当文档资产数量超过真实源码文件时（如 utfcpp20 0.3 为 nodejs:22 对 cpp:6，"主体占比 79%"），统计主体被文档资产劫持，与 manifest（CMakeLists.txt project() → cpp）冲突判 mixed，并自动写入 env_unsupported 终态（draft:false，R46 兜底会写共享路径 result.json）

## 推荐方案
**方法**: doc-asset-evidence-override

**说明**: 三步处置：①取证 js 文件路径全部位于 doc/ 文档目录（生成资产非源码）；②manifest 与构建系统均判任务语言 → 按 R47 附录主体裁定继续适配（tinydng/tinyvdb/hashchop/smashtable 误报族先例）；③全门禁闭环后 result --force 覆盖误报终态，误报证据写入 notes.md 留档

**修复命令**:
```
find ${src} -name "*.js" -not -path "*/doc/*" -not -path "*/docs/*" | wc -l
```

**验证**:
```
find ${src} -name "*.js" | grep -c "/doc/"（= js 总数即全部为文档资产）；对照 manifest 判定与构建系统判定是否均与任务语言一致
```
