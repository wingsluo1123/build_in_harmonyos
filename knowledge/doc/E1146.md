# E1146: meson+wrap 网络拉取型上游测试可用直编方案在 CI/离线设备执行（免 meson）

## 基本信息
- **严重度**: 2
- **类别**: portability, network, build-system, testing
- **作者**: CEED
- **来源 PR**: 8557

## 错误特征
```
Dependency "doctest" not found|Dependency "fmt" not found|Subproject .* does not exist and cannot be downloaded|Failed to download|subprojects/[a-z]+\.wrap
```

## 根因分析
上游测试套件由 meson 驱动且测试依赖经 subprojects/*.wrap 在配置期从网络拉取（doctest/fmt 等），离线或网络受限的 CI/设备无法完成拉取，导致上游测试整体不可执行

## 推荐方案
**方法**: direct-compile-upstream-tests

**说明**: 用与 wrap 锁定版本一致的官方依赖 tarball 头文件加上游自带辅助 TU，逐 TU 直接编译运行上游测试，完全绕开 meson 与网络拉取，不修改上游测试源码

**修复命令**:
```
clang++ -std=c++17 -DDOCTEST_CONFIG_IMPLEMENT_WITH_MAIN -I include -I <doctest解包>/doctest -I <fmt解包>/include -I test test/unit/<TU>.cpp <Counter.o> <fmt_format.o> <fmt_os.o> <api.o> -o t.bin && ./t.bin
```

**验证**:
```
clang++ -std=c++17 -DDOCTEST_CONFIG_IMPLEMENT_WITH_MAIN -I include -I <doctest解包>/doctest -I <fmt解包>/include -I test test/unit/<TU>.cpp <辅助对象> -o t.bin && ./t.bin | tail -3
```
