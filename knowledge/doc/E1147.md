# E1147: C 库安装公共头不自包含：库侧补 include 使其自包含（消费者以安装头独立编译必失败）

## 基本信息
- **严重度**: 2
- **类别**: headers, conan, packaging, c, self-contained
- **作者**: unknown

## 错误特征
```
unknown type name 'pthread_mutex_t'|unknown type name 'json_t'|unknown type name '(DIR|FILE|cchar_t)'|fatal error: '.*\.h' file not found.*Vt[A-Za-z]+\.h
```

## 根因分析
库安装的公共头直接使用外部依赖类型（如 VtObject.h 宏内 pthread_mutex_t、VtResponse.h 函数签名 json_t），

## 推荐方案
**方法**: patch-public-headers-self-contained

**说明**: 用 conan 补丁（modified-file diff）给库的公共头补上缺失的依赖类型 include，使安装头自包含：

**修复命令**:
```
# 补丁后重跑 conan create 验证（test_package 必须包含一个"仅 include 公共头"的消费者编译）:
```

**验证**:
```
grep -RInE "pthread_mutex_t|json_t" <pkg>/include/ | grep -vE "#include" ; 头文件仅依赖
```
