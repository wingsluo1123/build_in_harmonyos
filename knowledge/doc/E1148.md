# E1148: meson GIR (generate_gir) 选项化以适配无 gobject-introspection 工具链的 OHOS 目标

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, meson, gir, introspection
- **作者**: 9AD5, 40FF, 0189

## 错误特征
```
Dependency "gobject-introspection-1.0" not found|Program .*g-ir-scanner.*not found|generate_gir.*requires.*gobject-introspection
```

## 根因分析
OHOS 目标侧无 gobject-introspection 工具链（g-ir-scanner/g-ir-compiler 不可执行，pygobject 无法 dlopen glib 共享库——HMDFS exec 限制）；上游 meson.build 无条件调用 gnome.generate_gir 导致 configure 硬失败

## 推荐方案
**方法**: meson-optionize-generate-gir

**说明**: 给上游 meson 打最小补丁：meson_options.txt 新增 introspection 布尔选项（默认 true 保持上游行为），src/meson.build 的 gnome.generate_gir 以 get_option("introspection") 包裹；配方 MesonToolchain 传 -D introspection=false。库本体/头文件/pkg-config 正常交付；无 GIR typelib 不影响 C API 类型注册（鸿蒙专项测试回归验证）

**修复命令**:
```
(conanfile generate()) tc.project_options["introspection"] = "false"; 详见 archives/l/libhitaki/0.2.1/patches/0001-meson_options.txt.patch + 0002-src-meson.build.patch
```

**验证**:
```
conan create archives/l/libhitaki/0.2.1 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
