# E1149: Exult OHOS Autotools 配方的 SDL2 头文件与消费者验证

## 基本信息
- **严重度**: 2
- **类别**: ohos, headers, autotools, consumer
- **作者**: CCD4
- **来源 PR**: 9238

## 错误特征
```
"SDL\.h: No such file|fatal error: SDL\.h|make check.*No such file|command not found: exult|command not found: expack|command not found: ipack"
```

## 根因分析
Exult 源码直接包含 SDL.h，而 SDL2 Conan 包通常将头文件安装在 include/SDL2；同时 OHOS 交叉编译需要显式 build/host triplet，安装后的命令行工具必须通过消费者测试实际调用。

## 推荐方案
**方法**: autotools-ohos-sdl2-header-and-consumer-validation

**说明**: 使用 AutotoolsToolchain 注入 SDL2/include/SDL2，OHOS 构建时设置 aarch64-linux-ohos build/host，并在 test_package 中执行每个安装的命令验证输出和文档规定的退出码。

**修复命令**:
```
"tc.extra_cxxflags.append(f'-I{self.dependencies[\"sdl2\"].package_folder}/include/SDL2'); tc.configure_args.extend(['--build=aarch64-linux-ohos', '--host=aarch64-linux-ohos'])"
```

**验证**:
```
"conan create archives/e/exult/1.12.1 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing && bash test_package/test.sh"
```
