# E1150: Keep OHOS host settings separate from the Windows Conan build executor

## 基本信息
- **严重度**: 1
- **类别**: windows-ohos-cross-build-execution
- **作者**: A7F3

## 错误特征
```
"'.' is not recognized|Invalid setting 'OHOS'|CMAKE_CXX_COMPILER.*not.*existing|file://.*predl_cache"
```

## 根因分析
Conan can generate POSIX conanbuild.sh and an OHOS toolchain while running on Windows. Using one OHOS profile for both contexts makes cmd.exe source a .sh file or makes CMake try a target linker as the Windows build executor; predownload file URLs can also lose the drive letter under MSYS.

## 推荐方案
**方法**: task-local-dual-profile-overlay

**说明**: Use an isolated launcher that replaces only conan create's build profile, invoke recipe and test_package commands with argument lists and env=None on Windows, provide target compiler/sysroot fallback, and disable only the broken MSYS predownload rewrite while preserving official URLs.

**修复命令**:
```
conan create <recipe> -pr:h=<ohos-profile> -pr:b=<windows-profile> --build=missing
```

**验证**:
```
conan profile show -pr:h=<ohos-profile> -pr:b=<windows-profile>; run conan create through a task-local launcher and verify host/ build settings plus test_package output.
```
