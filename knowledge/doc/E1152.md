# E1152: When a consumer needs dependency symbols the intermediary shared library does not export, link a minimal archive of exactly the defining translation units

## 基本信息
- **严重度**: 2
- **类别**: linking, pkg-config, libs, static
- **作者**: Awstme

## 错误特征
```
undefined symbol: g_uuid_string_random|undefined symbol: g_zlib_compressor_new|undefined symbol.*-Wl,--no-undefined|unable to find library -lffi
```

## 根因分析
单副本教义（E 系：GObject 多副本撕裂）要求静态 glib 的

## 推荐方案
**方法**: link-minimal-archive

**说明**: 用 `ar x` 从静态库提取**仅有的两个**定义翻译单元

**修复命令**:
```
ar x ${glib2_pkg}/lib/libglib-2.0.a guuid.c.o && ar x ${glib2_pkg}/lib/libgio-2.0.a gzlibcompressor.c.o && ar qc libglib-min.a guuid.c.o gzlibcompressor.c.o
```

**验证**:
```
readelf --dyn-syms --wide libgupnp-1.6.so.0.106.10 | awk '$7!="UND"' | wc -l  # 257；g_* 定义 8 个；g_type_/g_object_ 定义 0
```
