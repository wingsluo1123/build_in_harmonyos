# E1153: 无条件 pragma clang diagnostic ignored 引用 Clang>=16 才有的诊断组（-Wunsafe-buffer-usage），Clang 15/-Weverything -Werror 下报 unknown warning group 编译错误；用 __has_warning() 守卫

## 基本信息
- **严重度**: 2
- **类别**: portability, compiler, clang, warnings, --has-warning
- **作者**: pc4-48

## 错误特征
```
unknown warning group .-Wunsafe-buffer-usage., ignored \[-Werror,-Wunknown-warning-option\]
```

## 根因分析
上游测试/源码无条件使用 #pragma clang diagnostic ignored "-Wunsafe-buffer-usage"，而该诊断组仅 Clang>=16 存在；OHOS 工具链 Clang 15 下被当作 unknown warning group，配合上游 -Weverything -Werror 提升为编译错误

## 推荐方案
**方法**: has-warning-guard

**说明**: 用 __has_warning("-Wunsafe-buffer-usage") 条件编译守卫包裹该 pragma（与同文件 -Wglobal-constructors / -Wunsafe-buffer-usage-in-libc-call 既有模式一致），低版本 Clang 跳过不存在的诊断组

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

```

```
