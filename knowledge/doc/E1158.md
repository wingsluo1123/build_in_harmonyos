# E1158: C/C++ 库测试夹具目录内嵌 vendored Go 工具（go.mod）会被 lang-preflight 计为主体语言判 mixed(go)，按 R47 辅助脚本/夹具不算主体应判 c/cpp 正常适配

## 基本信息
- **严重度**: 2
- **类别**: go, c, env-unsupported, false-positive, lang-preflight
- **作者**: 7989, 234A
- **来源 PR**: ""

## 错误特征
```
任务标记 cpp，实测源码为 mixed（go），无法按 cpp 适配|detected_language=mixed|build_system=go|go.mod 存在
```

## 根因分析
lang_detect.py 的源码统计按全树扩展名计数，未排除测试夹具目录中的

## 推荐方案
**方法**: fixture-tooling-not-main-language

**说明**: 遇 lang-preflight detected=mixed 且 go 文件全部位于测试夹具目录时，

**修复命令**:
```
python3 scripts/ohc-run.py lang-preflight <name> <ver> --src <src-dir>
```

**验证**:
```
|
```
