# E1159: Conan 配方经 conandata 子模块 tarball + 镜像回退拉取缺失的 git 子模块

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, packaging
- **作者**: 6403

## 错误特征
```
include could not find requested file.*cmake-scripts|extract_version\.cmake|submodule.*missing
```

## 根因分析
上游 GitHub/Gitee tag tarball 不含 git 子模块内容（仅 .gitmodules），CMake configure include cmake-scripts/*.cmake 失败

## 推荐方案
**方法**: conandata-submodule-tarball-get

**说明**: conandata.yml 增加 submodules.<name> 条目（官方 URL 优先 + gh-proxy 镜像回退 + sha256），conanfile.py source() 用 get(url, sha256, strip_root=True, destination='<subdir>') 拉取子模块 tarball；构建期需要子模块脚本（CMake include）时必须拉取，不能留空占位

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
