# E1164: CMake 平台枚举缺少 OHOS 时的无 x86 平台配置与 Conan 绑定

## 基本信息
- **严重度**: 2
- **类别**: portability, cmake, cross-compile, conan
- **作者**: GE01

## 错误特征
```
CMake Error.*cmake/platforms/.*config.cmake|System is unknown to cmake|unsupported platform|argument unused during compilation.*-m64|unrecognized command-line option.*-m64
```

## 根因分析
上游 CMake 通过自定义平台枚举加载平台配置，而不是直接依据 CMAKE_SYSTEM_NAME。OHOS 不在枚举中时配置阶段无法加载；复用 x86 Linux64 配置又会向 arm64 clang 注入 -m64。对于完整自带第三方源码的库，问题还会被误判为 Conan 依赖缺失，实际需要的是目标工具链与平台配置绑定。

## 推荐方案
**方法**: add-capability-based-ohos-platform-config

**说明**: 在配方补丁中增加仅目标平台使用的 OHOS-clang 配置，复用上游 Linux-clang 的语言/警告/ABI 能力设置但不复制 Linux64 的 x86 标志；Conan build() 显式绑定 CMAKE_TOOLCHAIN_FILE、OHOS_ARCH、平台枚举和功能开关，并回读最终缓存值。若库已有官方 OHOS 配置则优先使用官方配置。

**修复命令**:
```
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=<ohos.toolchain.cmake> -DOHOS_ARCH=arm64-v8a -DVORPALINE_PLATFORM=OHOS-clang -DGEOGRAM_LIB_ONLY=ON -DGEOGRAM_WITH_GRAPHICS=OFF
```

**验证**:
```
读取 CMAKE_TOOLCHAIN_FILE、VORPALINE_PLATFORM 和最终 CMAKE_CXX_FLAGS；配置与编译通过后检查 build.ninja 中没有 -m64，消费者用 CMakeDeps 的 geogram::geogram 目标完成真实 API 编译链接。
```
