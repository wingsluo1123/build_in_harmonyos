# E1167: m4 生成型 Makefile 修改必须同补 m4 模板与再生产物并钉时间戳

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: 7554

## 错误特征
```
No rule to make target 'ifneq'|No rule to make target 'Makefile'|m4: command not found|No rule to make target '.*'.*needed by 'all'
```

## 根因分析
GNU make 启动时若发现 Makefile 存在 Makefile: m4/Makefile.m4 规则且 m4 源比 Makefile 新,会自动调用 m4 再生 Makefile;CI 构建机无 m4 时构建中断;只补 Makefile 不补 m4 模板则修改在再生后被回滚

## 推荐方案
**方法**: dual-file-patch-plus-timestamp-pin

**说明**: 同一补丁同改 m4 模板与再生产物,build() 内 os.utime 把两者钉到同一历史时间戳

**修复命令**:
```
m4 -P -Dcbf_system=default m4/Makefile.m4 > Makefile ; os.utime(('Makefile','m4/Makefile.m4'), (1600000000,1600000000))
```

**验证**:
```
补丁应用后 diff 再生产物与原始 tarball 仅含预期 hunk; os.utime 钉定后 touch 检查 make 不再生
```
