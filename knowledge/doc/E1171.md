# E1171: can_run() 必须从 conan.tools.build 导入——顶层模块 conan.tools.can_run 不存在

## 基本信息
- **严重度**: 2
- **类别**: ohos, cross-compile, conan, packaging, testing
- **作者**: 0229

## 错误特征
```
ModuleNotFoundError: No module named 'conan\.tools\.can_run'|ImportError: cannot import name 'can_run' from 'conan\.tools'|No module named 'conan\.tools\.can_run'
```

## 根因分析
Conan 2.x（含 OHOS 适配版 2.29.1）中 can_run() 是 conan.tools.build 包内的函数，不存在独立的 conan.tools.can_run 模块。配方顶部写 from conan.tools.can_run import can_run 会在 recipe 加载阶段抛 ModuleNotFoundError；由于报错行只提 conan.tools.can_run，易被误判为"conan 版本太旧缺组件"而走错排查方向（实际版本支持该函数，只是导入路径不同）。

## 推荐方案
**方法**: fix-import-path

**说明**: 导入语句改为 from conan.tools.build import can_run，test() 内用 if can_run(self): 包裹 self.run(...)，跨平台分支语义不变。

**修复命令**:
```
sed -i 's/from conan.tools.can_run import can_run/from conan.tools.build import can_run/' test_package/conanfile.py
```

**验证**:
```
python3 -c "from conan.tools.build import can_run; print('OK', can_run)" ; python3 -c "import conan.tools.can_run" 2>&1 | grep -o "No module named 'conan.tools.can_run'"
```
