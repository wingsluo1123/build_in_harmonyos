# E1173: test_package 断言绑定环境相关返回值（本机绿 / CI 沙箱红）

## 基本信息
- **严重度**: medium
- **类别**: testing
- **作者**: EADD

## 错误特征
```
ERRtest failed: .* @ test_package/test\.c:[0-9]+ \| hid_.*\(\) -> -1 \| TAssert\(.*\) 断言绑定宿主能力
```

## 根因分析
用例断言把宿主环境能力当作适配正确性：hidapi 的 hid_init() 依赖 /dev/bus/usb 访问，开发机返回 0、CI 沙箱返回 -1，本机 W3 全绿而 CI 红（build-51367）；同类还有依赖 udev/systemd、/usr/lib 路径存在性、可写 /tmp、网络可达等断言。

## 推荐方案
**方法**: ①断言改值域而非单值（如 hid_init() == 0 || == -1，并把两种值语义写进输出）；②只在初始化成功后调用配套 API（hid_exit），避免未定义行为；③平台/环境不满足时显式 SKIP 而非 exit(1)；④本地 W3 通过不代表 CI 通过——环境相关断言必须在 CI 侧复核。

**说明**: 断言改值域（接受环境相关返回值），不把宿主能力当作适配正确性；平台/环境不满足时显式 SKIP。

**修复命令**:
```
见 PR #9686 test_package/test.c 的 test_ohos_loader_dependency_contract（TAssert(rc == 0 || rc == -1)）
```

**验证**:
```
python3 $SKILL_ROOT/scripts/ohc-run.py conan-verify <name> <ver>  # 本地绿后仍需 CI 复核
```
