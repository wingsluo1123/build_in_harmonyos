# E1174: OHOS 工具链默认不设 SONAME 旗标：无 SONAME 共享库使消费者 DT_NEEDED 记为相对路径，dlopen 按进程 CWD 相对解析而失败

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, cmake
- **作者**: C5D4
- **来源 PR**: 14369

## 错误特征
```
dlopen.*failed|cannot open shared object|DT_NEEDED
```

## 根因分析
OHOS clang/lld 默认不加 -Wl,-soname（Linux 工具链自动派生 soname）：消费者链接无 SONAME 共享库时，链接器把被依赖库的相对路径原样写入消费者 DT_NEEDED，dlopen 时按进程 CWD 相对解析找不到库

## 推荐方案
**方法**: soname-flags-inject

**说明**: 配方 generate() 注入 CMAKE_SHARED_LIBRARY_SONAME_CXX_FLAG/C_FLAG=-Wl,-soname,，恢复标准 soname 机制（CMake 拼出 -Wl,-soname,<soname>）

**验证**:
```
readelf -d <库.so> | grep SONAME（应有条目）；readelf -d <消费者.so> | grep NEEDED（应为库名而非路径）
```
