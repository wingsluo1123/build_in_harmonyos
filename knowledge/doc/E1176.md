# E1176: Meson standalone cc.has_header is a false positive when the header only breaks in combination with another system header; probe the realistic TU instead

## 基本信息
- **严重度**: 2
- **类别**: detection, kernel, headers, build-system
- **作者**: Awstme

## 错误特征
```
redefinition of 'struct sockaddr_storage'|linux/socket.h.*redefinition|gupnp-linux-context-manager|has_header.*rtnetlink|netlink headers
```

## 根因分析
Meson 的 cc.has_header() 把被测头放在一个独立的最小编译

## 推荐方案
**方法**: detection-patch

**说明**: 修探测逻辑而不是打平台宏：把单头 has_header 换成

**修复命令**:
```
netlink_available = cc.has_header('linux/rtnetlink.h') and cc.compiles('#include <sys/socket.h>\n#include <linux/netlink.h>\n#include <linux/rtnetlink.h>\nint main(void) { return 0; }\n', name: 'netlink headers usable together with sys/socket.h')
```

**验证**:
```
printf '#include <sys/socket.h>\n#include <linux/netlink.h>\n#include <linux/rtnetlink.h>\nint main(void){return 0;}\n' | clang -fsyntax-only -xc -
```
