# E1179: CMake 4.x 对 -D 传入的相对值安装目录变量在 set(CACHE PATH) 类型升级时解析到 CMAKE_BINARY_DIR，安装目的地落入构建树被 cmake --install 静默跳过

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake
- **作者**: C14B
- **来源 PR**: 14369

## 错误特征
```
source directory matches the destination|CMake Warning.*install|LIB_INSTALL_DIR
```

## 根因分析
本环境 CMake 4.1.2 对经 -D 以普通变量传入的相对值（如 lib），在上游 CMakeLists 执行 set(<VAR> ... CACHE PATH) 类型升级时按 CMAKE_BINARY_DIR 解析；安装目的地遂等于构建树产物目录（源=目的），cmake --install 静默跳过该 target，主库不进包且无任何报错

## 推荐方案
**方法**: absolute-install-dir

**说明**: 配方 generate() 对安装目录缓存变量传包目录绝对路径（self.package_folder 拼接），绝对值直通不受 CMAKE_BINARY_DIR 解析影响

**验证**:
```
conan create 后 ls <pkg>/lib/lib*.so 确认主库在包内；与构建树 lib/ 对照（两边都有即目的地被解析到构建树）
```
