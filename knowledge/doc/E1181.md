# E1181: make 变量名含 + 号无法用命令行赋值覆盖(C++=x 被解析为变量 C+ 的追加)

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: B155

## 错误特征
```
bash: line [0-9]+: g\+\+: command not found|g\+\+.*command not found.*Error 127
```

## 根因分析
GNU make 解析命令行赋值时把紧邻 = 的 + 识别为追加操作符:参数 C++=x 被拆成变量名 C+ 与追加值 =x,makefile 内的 C++ = g++ 仍然生效

## 推荐方案
**方法**: question-mark-equals-env-override

**说明**: 模板改 ?= 后经 env(1) 传非法 shell 变量名,make 视环境变量为已定义

**修复命令**:
```
sed 模板 'C++\t= g++' -> 'C++\t?= g++' ; env 'C++=<clang++>' make -j1 ...
```

**验证**:
```
printf 'C++ = g++\nall:\n\t@echo [${C++}]\n' > m.mk && make -f m.mk 'C++=x'   # 输出 [g++] 证明命令行不可覆盖
```
