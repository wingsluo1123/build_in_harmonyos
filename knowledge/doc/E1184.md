# E1184: automake all-local/clean-local 的 `cd <相对子目录>` 在 out-of-tree 构建（conan build_folder）中找不到源码子目录，需改用 $(top_srcdir) 前缀

## 基本信息
- **严重度**: 2
- **类别**: autotools, conan, all-local, out-of-tree, vpath
- **作者**: 7989
- **来源 PR**: ""

## 错误特征
```
cd libtap: No such file or directory.*all-local|cd [a-zA-Z0-9_-]+: No such file or directory.*make\[[0-9]+\].*all-local
```

## 根因分析
上游 t/Makefile.am 的 all-local/clean-local 写死 `cd libtap` 相对路径

## 推荐方案
**方法**: use-top-srcdir-in-all-local

**说明**: 将 t/Makefile.in（或 ac 源）all-local/clean-local 的 `cd libtap && $(MAKE)`
