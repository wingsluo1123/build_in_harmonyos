# E1186: QSharedDataPointer 前置声明类型的复制赋值应在实现文件中定义

## 基本信息
- **严重度**: 2
- **类别**: headers, c++, compilation, testing, api
- **作者**: 5521

## 错误特征
```
member access into incomplete type.*WSDiscoveryTargetServiceData|member access into incomplete type.*QSharedDataPointer
```

## 根因分析
公开类持有 QSharedDataPointer<ForwardDeclaredData>，而私有数据类仅在 .cpp 定义；若头文件未声明复制赋值，编译器生成的内联赋值运算符会在消费者翻译单元中实例化 QSharedDataPointer 对不完整类型的引用计数操作。

## 推荐方案
**方法**: out-of-line-qshareddata-copy-assignment

**说明**: 在公开类声明复制赋值运算符，并在私有数据类型定义之后的 .cpp 中使用 = default 定义，以便 QSharedDataPointer 实例化时完整类型可见。

**修复命令**:
```
declare operator=(const T &) in the class; define T::operator=(const T &) = default after the data class definition
```

**验证**:
```
conan create <recipe> -pr:h=<native-profile> -pr:b=<native-profile> --build=missing; ctest --test-dir <test-package-build> --output-on-failure
```
