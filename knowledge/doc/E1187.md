# E1187: ltrace 缺少 aarch64 支持，需创建符号链接到 arm

## 基本信息
- **严重度**: medium
- **类别**: build-system, architecture, aarch64
- **作者**: unknown

## 错误特征
```
No rule to make target.*sysdeps/linux-gnu/aarch64|sysdeps.*aarch64.*No such file
```

## 根因分析
ltrace 0.7.3 (2013年发布) 早于 aarch64 普及，只包含 arm (32-bit) 的 sysdeps 目录，没有 aarch64 支持。构建系统无法找到 aarch64 相关文件。

## 推荐方案
**方法**: |

**说明**: 创建 aarch64 → arm 符号链接，复用 ARM32 的实现

**修复命令**:
```
ln -sf arm sysdeps/linux-gnu/aarch64
```

**验证**:
```
ls -l sysdeps/linux-gnu/aarch64
```
