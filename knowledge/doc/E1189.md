# E1189: OHOS getpwuid 失败平台上工具身份 fallback 分叉导致上游测试比较断言失配与登录类测试不可行

## 基本信息
- **严重度**: 2
- **类别**: platform, testing, passwd
- **作者**: 4026
- **来源 PR**: !8605

## 错误特征
```
failed to identify current user|Login attempt for nonexistent user|@localhost|PermissionDenied|assert .* == .*(localhost)|comment.*mismatch
```

## 根因分析
OHOS 当前 uid 无 /etc/passwd 条目; getpwuid 返回 NULL 后不同工具各自 fallback（ssh-keygen 公钥 comment 写 uid 派生值@host 而 dropbearkey 写 @host）; 非 root 网络服务仅允许 pw_uid==euid 的用户登录使认证类上游测试平台性不可行

## 推荐方案
**方法**: 按环境限制归类并逐工具实测 fallback 证据; 测试计数如实分列且不用 PASS 掩盖; 功能等价性用工具自身往返转换等替代验证证明; 不修改上游测试断言; 不伪造系统用户条目

```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
python3 -c "import pwd,os; pwd.getpwuid(os.getuid())" 触发 KeyError 即确认无 passwd 条目; ssh-keygen -f k -t ed25519 -N '' 后 k.pub comment 为 uid派生值@host 而 dropbearconvert+dropbearkey -y 为 @host 即确认 fallback 分叉
```
