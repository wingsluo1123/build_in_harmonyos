# E1190: 鸿蒙设备上 test_package 脚本经 /system/bin/sh 执行时，每个 here-document 都要在 /tmp 建临时文件；/tmp 只读导致失败，但 shell 不中止脚本，`cat > f <<EOF` 会把 f 静默写成空文件，被测工具随后报出与根因无关的错误。脚本里 export 一个可写 TMPDIR 也救不回来——正确做法是 fixture 一律用 printf 生成并校验非空

## 推荐方案
**方法**: printf-fixtures-with-nonempty-guard

**说明**: 在设备上运行的脚本里，fixture/配置/期望输出一律用 printf '%s\n' 行参数写文件，不用任何形式的 here-document（<<EOF、<<-EOF、<<'EOF'）；写完立即校验非空，把「静默空文件」变成显式失败

**修复命令**:
```
printf '%s\n' \
```
