# E1193: 导出的 CMake 包配置调用 find_dependency 前须包含宏定义模块

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, packaging, testing
- **作者**: KDSC

## 错误特征
```
Unknown CMake command "find_dependency"|Unknown CMake command.*find_dependency
```

## 根因分析
上游生成的 KDSoapWSDiscoveryClientConfig.cmake.in 直接调用 find_dependency，但没有 include(CMakeFindDependencyMacro)；当消费者只通过 find_package 加载此配置且调用方没有提前定义该宏时，CMake 将 find_dependency 当作未知命令并中止配置。

## 推荐方案
**方法**: include-cmake-find-dependency-macro

**说明**: 在导出包配置模板中于第一个 find_dependency() 前加入 include(CMakeFindDependencyMacro)，再从独立 Conan consumer 调用 find_package(... CONFIG REQUIRED) 验证。

**修复命令**:
```
sed -i '/@PACKAGE_INIT@/a include(CMakeFindDependencyMacro)' KDSoapWSDiscoveryClientConfig.cmake.in
```

**验证**:
```
grep -n 'find_dependency\\|CMakeFindDependencyMacro' KDSoapWSDiscoveryClientConfig.cmake.in; cmake -S test_package -B test_package/build
```
