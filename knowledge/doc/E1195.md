# E1195: OHOS worker 上 /tmp 只读时 zsh 的 here-doc 临时文件会连带打挂 W3 闸门（L0i 谎报 conanfile.py AST 解析失败、L0m 结构检查失败），修法是 ZDOTDIR 里的 .zshenv 设 TMPPREFIX

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, environment, shell, ci-gate
- **作者**: C6EC

## 错误特征
```
can.t create temp file for here document: read-only file system|cannot touch .*/tmp|Read-only file system
```

## 根因分析
本平台 /tmp 为只读挂载（E002）。ci/conan/build_and_test.sh 以 zsh 执行，脚本内多处 python3 - <<PYEOF 的 here-doc 需要落临时文件；zsh 的 here-doc 临时文件名取自 TMPPREFIX（默认 /tmp/zsh-），而 TMPPREFIX 是 PM_DONTIMPORT 参数——环境变量注入无效，TMPDIR 也不被 zsh 的 here-doc 采纳。临时文件建不出来时该行整体失败，L0i 便输出 conanfile.py AST 解析失败（还附带 BOM/语法错误的误导性 hint），L0m 同样失败，W3 阻塞；实测与 conanfile.py 内容完全无关（无 BOM、语法正确的 tlog 14 同样报）。

## 推荐方案
**方法**: point-zsh-tmp-prefix-at-writable-dir-via-zdotdir

**说明**: (1) 在可写目录建 zdot/.zshenv 写入 TMPPREFIX=<writable>/zsh/zsh- 并 export TMPDIR/TMP，然后以 ZDOTDIR=<该目录> 运行 ohc-run.py finish/submit（zsh 非交互启动会读 ZDOTDIR 下的 .zshenv；runner 用 os.environ.copy() 传环境，可透传到 zsh 子进程）；(2) 不要改 ci/ 框架脚本来绕过（框架文件只读，改动等于越权）；(3) 判据：L0i 报 AST 解析失败但 conanfile.py 无 BOM/语法错误时，先验证 here-doc 临时目录可否写，而不是去改配方；(4) 只设 TMPDIR 无效，必须让 zsh 参数 TMPPREFIX 生效。

**修复命令**:
```
mkdir -p ~/tmp/zdot ~/tmp/zsh && printf TMPPREFIX=~/tmp/zsh/zsh- > ~/tmp/zdot/.zshenv && ZDOTDIR=~/tmp/zdot ohc-run.py finish <pkg> <ver> published
```

**验证**:
```
touch /tmp/ohc-tmp-probe   # 失败（Read-only file system）即命中本坑
```
