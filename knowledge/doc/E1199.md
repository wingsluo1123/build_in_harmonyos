# E1199: Conan 仓库内 test_package 以自身为 build_folder：测试产物（被测包副本/activate 脚本）会混入归档并被提交

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, testing, git
- **作者**: 943F

## 错误特征
```
archives/[a-z0-9]/[^/]+/[^/]+/test_package/moved-[a-z0-9._-]+|test_package/(conanbuild|conanrun|deactivate_conan)[a-z]*[.]sh|test_package size (8[0-9]|[0-9]{3,})M|untracked.*test_package/(moved-|conanbuild)
```

## 根因分析
Conan 对仓库内的 test_package 直接以该目录自身作为 build_folder，run_test.sh 生成的 moved-<pkg> 副本、conanbuild/conanrun/deactivate 脚本都落在源码树内；若入库前不清理，构建产物会被当作源码提交，使归档体积与 CI 行为随残留状态漂移

## 推荐方案
**方法**: 在 test_package/conanfile.py 的 test() 中用 try/finally + shutil.rmtree(moved, ignore_errors=True) 无条件清理 build_folder 产物（成功/失败/异常都清理）；激活脚本交由仓库 .gitignore 兜底

**说明**: 在 test() 中用 try/finally 确保无论测试成功、断言失败还是抛异常，build_folder 内的被测包副本都被删除；归档只保留纯输入（conandata.yml / conanfile.py / manifest.yaml / notes.md / patches / test_package 源文件）

**修复命令**:
```
moved = os.path.join(self.build_folder, "moved-r-base")\ntry:\n    self.run(command, env=None)\nfinally:\n    shutil.rmtree(moved, ignore_errors=True)
```

**验证**:
```
du -sh <pkg>/test_package; git status --porcelain <pkg>  # 出现 moved-<pkg>/conanbuild.sh 等即为污染
```
