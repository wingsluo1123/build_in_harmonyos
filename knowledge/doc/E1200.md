# E1200: Imake/xmkmf 构建系统在 OHOS 不可用（无 imake 工具链）——老式 X11 软件需改为配方内手工 Makefile/直接编译

## 基本信息
- **严重度**: 3
- **类别**: platform, portability, build-system, x11
- **作者**: 7DD4

## 错误特征
```
xmkmf: inaccessible or not found|xmkmf: not found|imake: No such file|No rule to make target 'Xaw3dP.h'|Imakefile.*No such file|imake -I.*failed
```

## 根因分析
Imake 体系（xmkmf/imake + *.cf 规则）依赖 X11 开发树（/usr/lib/X11/config）与 imake 预处理器，OHOS 工具链不携带；上游 configure 内部调 xmkmf 生成 Makefile 时立即失败

## 推荐方案
**方法**: manual-makefile-extraction

**说明**: 不碰 imake：通读 Imakefile 提取编译单元（SRCS/OBJS/DEFINES/INCLUDES/LIBS），在配方内用 Conan 工具链变量写手工 Makefile 或直接 self.run() 编译；Vendored 子目录（如 xaw3dxft）若含 yacc/lex 生成步骤，用 tool_requires bison/flex 或本机 flex/bison 补齐生成物

**修复命令**:
```
grep -E "^(SRCS|OBJS|DEFINES|SYS_LIBRARIES|X.*_LIB)" Imakefile   # 提取编译单元
```

**验证**:
```
ls Imakefile 2>/dev/null && ! which xmkmf && echo "E546: Imake project, xmkmf unavailable"
```
