# E1201: aarch64 pt_regs 结构使用 regs[] 而非 ARM32 的 uregs[]

## 基本信息
- **严重度**: high
- **类别**: architecture, aarch64, arm
- **作者**: unknown

## 错误特征
```
'struct pt_regs'.*has no member named 'uregs'|ARM_r\d+.*uregs
```

## 根因分析
ARM32 的 pt_regs 使用 uregs[] 数组存储通用寄存器，而 aarch64 使用 regs[] 数组。直接访问 uregs[] 在 aarch64 上编译失败。

## 推荐方案
**方法**: |

**说明**: 使用宏抽象 ARM32 和 aarch64 的 pt_regs 结构差异

**修复命令**:
```
|
```

**验证**:
```
grep -n "\.uregs\|\.regs\[" *.c
```
