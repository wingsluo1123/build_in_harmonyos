# E1202: 跨 DSO 各自实例化同一模板特化产生多个 WEAK typeinfo，Itanium 唯一 typeinfo 语义下 dynamic_cast 恒失败（空指针解引用 SIGSEGV）

## 基本信息
- **严重度**: 3
- **类别**: portability, build-system
- **作者**: 53FC
- **来源 PR**: 14369

## 错误特征
```
Segmentation fault|SIGSEGV|core dumped|dynamic_cast
```

## 根因分析
OBPairTemplate<int/double/bool> 在各 DSO 隐式实例化，各自生成 WEAK typeinfo/vtable 符号；aarch64 Itanium ABI 为唯一 typeinfo 语义（typeinfo operator== 只比指针），跨 DSO dynamic_cast<OBPairFloatingPoint*> 恒判失败返回 null，调用方未完整判空即解引用 → SIGSEGV

## 推荐方案
**方法**: extern-template-single-instantiation

**说明**: 头文件加 extern template 声明（目标特化），库内一个 .cpp 单点显式实例化：全部 TU 绑定库内唯一强符号 typeinfo/vtable，跨 DSO dynamic_cast 恢复

**验证**:
```
nm <主库.so> | grep "typeinfo.*OBPairTemplate"（修复后 3 个特化各 1 个强符号）；上游 ctest forcefield/descriptor 用例无 SIGSEGV
```
