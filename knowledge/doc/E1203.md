# E1203: "gupnp-av 的 XSD 运行时寻址：GUPNP_AV_DATADIR 必须指向包内 share/gupnp-av（DATADIR 宏是编译期 prefix）"

## 基本信息
- **严重度**: 2
- **类别**: meson, runtime, environment, library, xml
- **作者**: unknown

## 错误特征
```
I/O warning : failed to load "/share/gupnp-av/didl-lite-v2\.xsd"|Schemas parser error : Failed to locate the main schema resource
```

## 根因分析
gupnp-av 的 DIDL-Lite 校验器（fragment-util.c get_data_dir）按 GUPNP_AV_DATADIR 环境变量 > 编译期 DATADIR 宏（prefix+datadir+'gupnp-av'，conan 下 prefix=/ → "/share/gupnp-av"）的顺序寻址 XSD。conan 包安装路径不在 "/"，消费者运行时不设 GUPNP_AV_DATADIR 的话 libxml2 加载 XSD 失败：新 writer 会打 "I/O warning" + "Schemas parser error"（部分路径直接 abort/SIGTRAP）。上游 tests/gtest/meson.build 正是用 GUPNP_AV_DATADIR 指向源码 data/ 目录来跑测试的——这是上游设计的运行时寻址机制，不是适配 bug。

## 推荐方案
**方法**: 参考 archives/g/gupnp-av/0.14.5 的 package_info()（PR #7999 CI 全绿验证）。注意 conanrun 环境只在 test_package/消费者用 conanrunenv 时生效；裸跑二进制需手动设置。推广：带编译期数据目录宏的库（.xsd/.dtd/locale 数据）在 conan 打包后都需检查运行时寻址是否断裂，用 runenv_info.define_path 注入包内绝对路径。
