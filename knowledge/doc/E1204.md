# E1204: 给脚本类包打完 shebang 适配补丁（E165）后，用「./工具」形式自举的上游测试会在非鸿蒙构建机上整片失败——失败的是 shebang 路径不存在，不是工具本身；必须建立解释器映射或显式解释器调用来复现，禁止据此判定补丁破坏功能、更禁止改上游用例

## 根因分析
E165 要求把脚本 shebang 从 /bin/sh、/bin/bash 改写为鸿蒙真实

## 推荐方案
**方法**: interpreter-mapping-for-verification

**说明**: 在适配机上建立与鸿蒙同名的解释器映射（/system/bin/sh -> /bin/dash 等），用它复跑上游自举测试，确认补丁前后通过数一致；映射属构建机准备，绝不写进配方或补丁

**修复命令**:
```
mkdir -p /system/bin && ln -sf /bin/dash /system/bin/sh
```
