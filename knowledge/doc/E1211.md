# E1211: Geometry exact endpoint equality must precede normalization-based overlap

## 基本信息
- **严重度**: 2
- **类别**: clang, floating-point, geometry
- **作者**: GE11

## 错误特征
```
coincident line endpoint intersection count mismatch
```

## 根因分析
Projection roundoff can make an exactly coincident segment lose endpoint intersections; exact forward/reversed endpoint identities must be preserved before approximate normalized projection.

## 推荐方案
**方法**: exact-endpoint-fast-path

**说明**: Handle exact equal/reversed endpoints before approximate projection; retain generic overlap tolerance and complete tests.

**修复命令**:
```
ctest --output-on-failure --verbose --parallel 2
```

**验证**:
```
Full native CTest plus installed geometry consumer; preserve exact endpoint and reversed segment assertions.
```
