# E1212: 全局 BUILD_SHARED_LIBS 传播到内置 GoogleTest 时需在 post-build discovery 前提供测试库路径

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, runtime-loader, test-discovery
- **作者**: unknown

## 错误特征
```
Error loading shared library libgtest(_main)?\.so|GoogleTestAddTests.*Error running test executable|_ZTIN7testing4TestE: symbol not found
```

## 根因分析
上游全局 BUILD_SHARED_LIBS=ON 同时把内置 GoogleTest 编为共享库。CMake gtest_discover_tests 默认在构建后立即执行测试二进制，因此仅为后续 ctest 设置运行环境太晚；Conan VirtualRunEnv 只知道外部依赖，不自动包含 build/lib 中的内置测试库。

## 推荐方案
**方法**: scoped-build-time-loader-environment

**说明**: 在 CMake.build 之前建立任务局部 LD_LIBRARY_PATH，同时加入被测库输出目录与 bundled GoogleTest 输出目录，保留 Conan 外部依赖环境；同一作用域执行全部 ctest。安装后的库仍单独验证，不能把构建目录测试 PASS 当作包 PASS。

**修复命令**:
```
with VirtualRunEnv(self).vars().apply(), private_build_dirs.vars(self).apply(): cmake.build(); self.run("ctest --output-on-failure", env="conanrun")
```

**验证**:
```
新的原生 conan create，要求 discovery 成功、全部上游 ctest N/N 和独立安装包消费者通过
```
