# E1214: Conan 配方复制中的版本子串碰撞与冻结依赖身份独立漂移

## 基本信息
- **严重度**: 3
- **类别**: detection, build-system, conan
- **作者**: CD11

## 错误特征
```
Version conflict: Conflict between .* and .* in the graph|frozen dependency identity mismatch
```

## 根因分析
复制配方时全局替换主包版本子串，误改含相同子串的独立依赖版本；随后只修配方仍可能保留冻结 identity 的旧依赖标签，因此 conan create RC0 不能证明冻结闭包一致。 A raw PR diff can omit a binary sample payload even when the Git source branch is mergeable. Carry the original fixture as bounded text, decode it only into the consumer build directory, and verify its original byte count/SHA256 separately from the text carrier hash. Autoconf creates config.status scratch directories in two branches with owner-only masks. On HMDFS, changing file modes later or repairing PR transport cannot establish creation-time access. Replace both creation branches with exclusive mkdir under the recipe-private TMPDIR, use umask 022 at creation, restore configure timestamps, and prefix TMPDIR after Conan environment activation. Preserve cleanup and every original test. The producer shared=True/fPIC option cannot change an already published non-PIC static dependency. Pin the same-upstream static-PIC suffix artifact and force one consistent dependency version through both direct and transitive paths; keep system-name zlib static rather than adding a competing libz.so.

## 推荐方案
**方法**: structured-reference-and-frozen-identity-consistency

**说明**: 按字段精确替换主包版本，不对整文件替换版本子串；明确核对独立依赖与中间包的版本图。冻结前从同一已解析图生成依赖身份，已消费旧事务保持原状，修正后在新事务验证而不是追改旧证据。 A raw PR diff can omit a binary sample payload even when the Git source branch is mergeable. Replace both creation branches with exclusive mkdir under the recipe-private TMPDIR, use umask 022 at creation, restore configure timestamps, and prefix TMPDIR after Conan environment activation. Preserve cleanup and every original test. The producer shared=True/fPIC option cannot change an already published non-PIC static dependency. **修复命令**:
```
对每个 self.requires/self.tool_requires 字符串作完整包引用校验，再与同一候选解析图和 identity.dependencies 精确比对。
```

**验证**:
```
分别解析配方 requirements/build_requirements 引用、Conan 已解析图与冻结 identity.dependencies；按名称、版本、RREV/PID/PREV 比对，保存当前输入哈希。
```
