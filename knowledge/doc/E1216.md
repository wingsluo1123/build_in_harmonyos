# E1216: 头内 inline function-local static 插件注册表被各 DSO 私享，跨 DSO 插件查找恒失败（SetInFormat false / 格式插件查不到）

## 基本信息
- **严重度**: 3
- **类别**: portability, build-system
- **作者**: B0C9
- **来源 PR**: 14369

## 错误特征
```
Open Babel Error.*LoadAllPlugins|Unable to find OpenBabel plugins|No valid OpenBabel plugs|SetInFormat
```

## 根因分析
头文件 MAKE_PLUGIN 的默认分支把插件注册表 Map() 定义为 inline function-local static：每个 DSO（主库、格式插件模块、消费者可执行文件）各编译一份私有注册表，插件注册（插件 .so 构造期）与调用方查表落在不同 DSO，FindType() 恒返回 null

## 推荐方案
**方法**: out-of-line-registry-singleton

**说明**: 无条件启用外置定义路径（上游 Cygwin/MinGW 分支已内置同一问题的正解）：头内删条件编译留外置声明，库内由 PLUGIN_CPP_FILE 宏单点发出强定义，全进程共享一份注册表

**验证**:
```
nm --defined-only <主库.so> | grep -c "Map"（修复后主库内恰 1 个强定义）；上游 ctest 格式转换用例 SetInFormat 成功
```
