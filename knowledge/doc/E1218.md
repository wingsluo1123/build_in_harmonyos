# E1218: PMIx 5.x 无服务器时 PMIx_Init 返回 UNREACH(-25)——test_package 必须走 simptest server 模式端到端（附：适配版 conan run() 无 timeout，输出捕获用 stdout 文件对象 + L0d 门禁要求 self.run）

## 基本信息
- **严重度**: 2
- **类别**: portability, conan, packaging, runtime, testing
- **作者**: 9F41

## 错误特征
```
PMIx_Init.*returned -25|
```

## 根因分析
PMIx 是 client/server 架构：客户端 PMIx_Init 需要环境变量（PMIX_NAMESPACE 等）

## 推荐方案
**方法**: simptest-server-mode-test

**说明**: test_package 按 simptest 范式写：①父进程 PMIx_server_init(NULL, NULL, 0)

**修复命令**:
```
|
```

```
grep -n "PMIx_server_init" test_package/test_pmix.c; grep -n "subprocess" test_package/conanfile.py
```
