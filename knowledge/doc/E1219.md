# E1219: OHOS 不支持 GNU error.h，需替换为标准库函数

## 基本信息
- **严重度**: high
- **类别**: compat, portability, libc
- **作者**: unknown

## 错误特征
```
error\.h.*No such file|implicit declaration of function 'error'|undefined reference to `error'
```

## 根因分析
OHOS 平台不提供 GNU 扩展库中的 error.h 和 error() 函数。许多 GNU 工具（如 ltrace, coreutils 等）依赖 error() 进行错误报告和退出处理。

## 推荐方案
**方法**: |

**说明**: 使用标准库函数 fprintf()/exit()/strerror() 替换 GNU error()

**修复命令**:
```
|
```

**验证**:
```
grep -n "error\.h\|error(" file.c
```
