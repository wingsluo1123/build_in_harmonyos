# E1221: test_package 硬编码构建机个人绝对路径：目标 worker 缺少该路径时 set -e 直接中止整个 test_package，包无法通过 CI 发布

## 基本信息
- **严重度**: 2
- **类别**: portability, conan, packaging, testing
- **作者**: 88DB

## 错误特征
```
cannot statx '/storage/Users/[^']*': No such file or directory|cannot stat ['"]?/storage/Users/[^ '\"]+['"]?: No such file or directory|test_package.*(failed|error).*set -e|Failed to run test_package|conan create.*test_package.*ERROR
```

## 根因分析
test_package 脚本把构建机个人绝对路径（如 /storage/Users/<user>/.harmonybrew）当作必然存在的校验对象，配合 set -e 在目标 worker 上 stat 失败即中止整条测试链，导致 conan create 失败、包永远无法进入 release 流水线

## 推荐方案
**方法**: 把宿主路径校验改为「根存在才执行」，不存在时输出 SKIPPED 且不改变退出码；必须保留的无条件校验层（如遮蔽 ~/.conan2）继续无条件执行，负向控制强度不降级

**说明**: 可选校验层按「根存在才执行」降级：root="$HOME/.harmonybrew"; if [ -e "$root" ]; then chmod 000 "$root"; mask=1; else mask=0; fi；收尾同样以 $mask 判定，并打印 HARMONYBREW_MASK=SKIPPED (root absent)

**修复命令**:
```
[ -e "$HOST_ROOT" ] && chmod 000 "$HOST_ROOT" || echo "HOST_MASK=SKIPPED (root absent: $HOST_ROOT)"
```

**验证**:
```
grep -nE '/storage/Users/|[.]conan2' <pkg>/test_package/*.sh  # 出现构建机个人路径即高危
```
