# E1225: open(path, O_WRONLY|O_CREAT) 缺第三个 mode 参数：变参 open() 在 musl 上读到寄存器残留值，新建文件权限位不确定（属主无读写权限），编译器不告警

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, libc, musl, posix
- **作者**: 5C1D

## 错误特征
```
output file mode is 0[0-7]{3}, want 0[0-7]{3}|Permission denied.*(out|output|new) ?file|^-[-r][-w]x?[-r]-x[-r]-x .*(out|output)
```

## 根因分析
open() 是变参函数：只有 flags 含 O_CREAT（或 O_TMPFILE）时 libc 才用 va_arg 取第三个参数 mode。

## 推荐方案
**方法**: add-explicit-mode-to-open-ocreat

**说明**: 给每个含 O_CREAT 的 open() 补上显式 mode：普通数据文件用 0666（交给 umask 过滤），私密文件 0600，

**修复命令**:
```
grep -rnP '\bopen\s*\(\s*[^,()]+,\s*[A-Z_|\s]*O_CREAT[A-Z_|\s]*\)' <src>   # 找出缺 mode 的调用点，逐个人工补 mode
```

**验证**:
```
printf '#include <fcntl.h>\nint main(void){return open("t.out",O_WRONLY|O_CREAT)<0;}\n' > t.c
```
