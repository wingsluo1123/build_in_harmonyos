# E1226: Conan AutotoolsToolchain 丢弃自定义 CPPFLAGS 且不注入依赖 include：改用 extra_cflags/extra_cxxflags 显式注入

## 基本信息
- **严重度**: 2
- **类别**: headers, build-system, autotools, toolchain, conan
- **作者**: 4936
- **来源 PR**: pending

## 错误特征
```
configure: error: fst/fst\.h header not found|
```

## 根因分析
Conan 2 的 AutotoolsToolchain 在 generate() 中自行拼装环境文件

## 推荐方案
**方法**: extra-flags-channel-injection

**说明**: 在 generate() 里改用 AutotoolsToolchain 的 extra_cflags / extra_cxxflags

**修复命令**:
```
tc = AutotoolsToolchain(self)
```

**验证**:
```
grep -n '^export CPPFLAGS' <build_folder>/conanautotoolstoolchain.sh
```
