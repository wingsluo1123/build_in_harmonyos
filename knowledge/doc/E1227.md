# E1227: "OHOS python subprocess 工具链子进程动态库加载失败的通用诊断模式（ninja/lld 裸名探测静默失败三变体）"

## 基本信息
- **严重度**: 2
- **类别**: ohos, meson, toolchain, linking, environment
- **作者**: unknown

## 错误特征
```
ERROR: Could not detect Ninja v1\.8\.2 or newer|ERROR: Unable to detect linker for compiler.*-Wl,--version|Error loading shared library libc\+\+_shared\.so: \(needed by .*ninja\)|Error loading shared library libxml2\.so\.16: \(needed by .*lld\)|Error relocating .*lld: xmlFreeDoc: symbol not found|Error relocating .*ninja: _Znwm: symbol not found
```

## 根因分析
OHOS 上所有动态链接的工具链组件（ninja、lld 等）在 python subprocess 子进程链路（conan python → bash → meson python → subprocess）中按继承的 LD_LIBRARY_PATH 解析伴生共享库；真机 SSH 交互环境与 CI worker（AppSpawn 沙箱）的 LD_LIBRARY_PATH 内容不同，导致同一工具"本地能跑、CI 报工具不存在"。三条故障变体同根因：(V1) ninja + libc++_shared.so：构建进程从桌面环境继承的 LD_LIBRARY_PATH 含应用层路径（/data/storage/el1/bundle/...），/data/service/hnp/bin/ninja 加载 libc++_shared.so 失败 rc=127 无 stderr，meson 把 127 当"不可运行"静默跳过 → "Could not detect Ninja"（本地 conan create 场景，glib2 2.84.0/gupnp-av 0.14.5 双实证）。(V2) lld + libxml2.so.16：OHOS SDK 的 lld 动态链接 libxml2.so.16（伴生于 SDK llvm/lib 目录）。真机 SSH 环境自带该路径，CI worker 缺失 → meson 编译器探测阶段 `clang -Wl,--version` 拉起 lld 失败（xmlFreeDoc 等 symbol not found）→ "Unable to detect linker"（pycairo 1.29.0 #21029、gupnp-av 0.14.5 #37807/37842/37847 三台 worker 实证）。(V3) 裸名 PATH 解析：OHOS python subprocess（_IS_HARMONYOS 定制，posix_spawn 分支）对裸名命令不做 PATH 搜索，`subprocess.run(['ninja'])` 直接 FileNotFoundError 即使 which 能找到——meson 的裸名探测全部落空。共性：上层工具（meson/conan）把子进程失败静默降级为"工具不可用"，报错信息完全不指向真实根因（动态库加载），极易误判为"没装工具"而放弃配方侧修复。

## 推荐方案
**方法**: 配方层通用手法（不改框架/不依赖平台修复）：meson native file wrapper（_inject_meson_tools 内替换 c/cpp）+ test_package build() 改写 conan_toolchain.cmake（_wrap_toolchain_compilers）双堵；NINJA 绝对路径与 /system/lib64 前置作 ninja 变体双保险。参考实现：archives/g/gupnp-av/0.14.5（PR #7999 七轮攻坚验证，2026-09-04 CI 全绿）。诊断口诀：交互 shell 能跑 + 子进程报"工具不存在" = 先查动态库加载（LD_LIBRARY_PATH），再查裸名解析（NINJA/绝对路径），最后才怀疑工具本身。关键教训：先例会随 CI 环境演进失效（pycairo 1.29.0 的 buildenv_info 方案 8/13 合入、9/4 实证已失效）；wrapper（脚本内 export 后 exec）是唯一不依赖环境继承机制的根治法。
