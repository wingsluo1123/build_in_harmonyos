# E1228: kamailio core 插件独立打包：dlopen 需消费者进程提供 core 符号 shim（musl 无惰性绑定）

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, libc
- **作者**: 34E4

## 错误特征
```
undefined symbol:.*|dlopen.*failed.*undefined symbol|Error relocating.*symbol not found|RTLD_NOW.*undefined
```

## 根因分析
共享模块（如 kamailio 模块 debugger.so）不把宿主程序本体写进 DT_NEEDED，其引用的宿主符号只在 dlopen 时解析；OHOS/musl 无惰性绑定（RTLD_LAZY 等价 RTLD_NOW），因此宿主符号缺失时 dlopen 立即失败，而不是等到首次调用才失败

## 推荐方案
**方法**: consumer-shim-export-dynamic

**说明**: 在 test_package 里实现消费者进程：提供宿主未定义符号的 shim（含全局量与函数），用 -Wl,--export-dynamic 链接使 shim 进入动态符号表，再 dlopen 模块并真实调用其入口（dlsym 取导出表 → init → child_init），含负例

**修复命令**:
```
clang test_package/shim.c test_package/e2e.c -Wl,--export-dynamic -ldl -o e2e && ./e2e <module>.so
```

**验证**:
```
llvm-nm -u <module>.so | wc -l  # 列出模块未定义符号；llvm-readelf -d <module>.so | grep NEEDED  # 确认未 NEEDED 宿主本体
```
