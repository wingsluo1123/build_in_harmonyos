# E1229: PseudoTCP negative send result duplicates input byte

## 基本信息
- **严重度**: 1
- **类别**: ohos, portability, testing
- **作者**: 1D7D

## 错误特征
```
Sending .* bytes : -1|Binary files rand and rand-copy differ|total_wrote <= total_read
```

## 根因分析
On EWOULDBLOCK pseudo_tcp_socket_send returns -1 for zero accepted bytes, but the upstream test counts -1 and calculates a rewind of len plus one bytes, duplicating the preceding input byte and undercounting received data.

## 推荐方案
**方法**: normalize-negative-send-count

**说明**: Normalize negative send returns to zero before updating counters or calculating the file rewind.

**修复命令**:
```
if (wlen < 0) wlen = 0; fseek (in, (long) wlen - (long) len, SEEK_CUR)
```

**验证**:
```
MALLOC_PERTURB_=84 test and compare input and output files
```
