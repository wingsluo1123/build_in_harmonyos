# E1232: init-build 把上游 Git 仓库 URL 当 tarball 下载并可能长时间卡住

## 基本信息
- **严重度**: 2
- **类别**: network, build-system, source-download
- **作者**: 0086

## 错误特征
```
init-build.*--url=.*\.git|下载: https://github\.com/[^ ]+\.git
```

## 根因分析
init_build.py 的 --url 是压缩包下载地址而非 git clone 入口；_guess_tar_format 对 .git URL 回退 tar.gz，_download_one 使用 urllib 下载仓库页面且 timeout=300 秒；仓库页面超时或即使下载成功也不是 gzip，无法创建 .orig/.work。此问题不同于 E483 的 Conan get() 解压扩展名误判。

## 推荐方案
**方法**: choose-versioned-official-tarball

**说明**: 先核对目标 tag 的 Git tree 与 submodule gitlink；传 GitHub 官方 tag 的 tar.gz 源码归档 URL 给 init-build；若 tag 确有 gitlink，应另行以固定 commit 递归获取对应子模块，禁止混用当前主线的子模块状态。

**修复命令**:
```
python3 scripts/ohc-run.py init-build swuniq 0.5 --url=https://codeload.github.com/mterron/swuniq/tar.gz/refs/tags/v0.5
```

**验证**:
```
python3 -c "import sys; sys.path.insert(0, 'scripts'); from ohc.init_build import _guess_tar_format; print(_guess_tar_format('https://github.com/mterron/swuniq.git'))"  # 输出 tar.gz；改用官方 tag archive 执行 init-build 后 .work/Makefile 存在
```
