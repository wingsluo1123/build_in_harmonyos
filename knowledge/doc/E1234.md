# E1234: Conan 2 取 tool_requires 依赖必须走 self.dependencies.build，否则 generate() 抛 KeyError

## 基本信息
- **严重度**: 3
- **类别**: build-system, conan, recipe
- **作者**: NGS1

## 错误特征
```
not found in the dependency set
```

## 根因分析
Conan 2 的 self.dependencies 默认只暴露 host context。tool_requires（build requires）的包在 build context，用 self.dependencies[pkg] 取值抛 KeyError not found in the dependency set，异常发生在 generate() 阶段，容易被误判为制品仓缺包而去补依赖。

## 推荐方案
**方法**: 取 build context 依赖必须写 self.dependencies.build[pkg]；host 侧依赖才是 self.dependencies[pkg] 或 self.dependencies.host[pkg]。把 tool_requires 的可执行路径注入 CMake cache 变量时尤其容易踩到。

**说明**: tool_requires 的包只在 build context，Conan 2 取用需显式 .build 层

**修复命令**:
```
sed -i 's/self\.dependencies\["pkg"\]/self.dependencies.build["pkg"]/' conanfile.py
```

**验证**:
```
conan create <pkg>/<ver>  # generate() 不再抛 KeyError 'not found in the dependency set'
```
