# E1236: OHOS /tmp、/var/tmp 只读导致上游硬编码临时路径测试失败

## 基本信息
- **严重度**: 2
- **类别**: platform, testing, filesystem
- **作者**: E3AD, B46E

## 错误特征
```
mkstemp.*No such file or directory|/var/tmp/.*XXXXXX|Read-only file system.*unix:/tmp|bind\(sockfd
```

## 根因分析
OHOS /tmp、/var/tmp 只读挂载；上游测试硬编码 /tmp、/var/tmp 路径，TMPDIR 环境变量无法规避该类用例

## 推荐方案
**方法**: 按配方范围不改上游测试；受限用例如实计入 failed + 恢复条件（挂载可写 tmpfs）；可规避用例以 TMPDIR=~/tmp 运行；台账如实记录

**说明**: 不改上游源码；受限用例按平台限制计入台账并给恢复条件；可规避用例以 TMPDIR 运行

**修复命令**:
```
TMPDIR=~/tmp ./<test-binary>
```

**验证**:
```
TMPDIR=~/tmp ./capnp-tests && ./kj-heavy-tests（对照 reports/test-report.md 双口径台账逐项核对通过/失败）
```
