# E1238: libploticus 嵌入 API：ploticus_init/ploticus_execline 就地修改入参，传字符串字面量 SIGSEGV

## 基本信息
- **严重度**: 1
- **类别**: portability, api-contract
- **作者**: B58F

## 错误特征
```
Segmentation fault|SIGSEGV|rc=139|ploticus_execline|ploticus_init
```

## 根因分析
该 API 按脚本语言就地解析（会写回入参缓冲区）；调用方传字符串字面量时写入只读段 -> SIGSEGV。另外仅用 execline 而不先经过一次 execscript 循环也会崩溃

## 推荐方案
**方法**: 照搬上游 apitest.c 调用序列（init -> arg -> execscript -> end -> init -> arg -> execline* -> end），所有入参用可写缓冲区（char buf[N]; strcpy(...)）

**说明**: 嵌入 API 必须传可写缓冲区并按上游序列调用

**修复命令**:
```
strcpy(buf, "#proc annotate"); ploticus_execline(buf);
```
