# E1239: musl libc 差异：无 rdtsc/rdtscp 时钟、无 NETDB_INTERNAL 宏、netdb 错误分支不同

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability, libc, musl
- **作者**: unknown

## 错误特征
```
invalid output constraint '=a'|use of undeclared identifier 'NETDB_INTERNAL'|undefined reference to.*h_errno|implicit declaration of.*rdtsc
```

## 根因分析
OHOS 用 musl libc：①x86 的 TSC 内联汇编（rdtsc/rdtscp）在 aarch64 无效且 musl 无 vdso 兜底 ②netdb.h 无 glibc 专用的 NETDB_INTERNAL 枚举 ③gethostbyname_r/h_errno 语义与 glibc 有差异，错误分支不能直接比较 glibc 专用常量

## 推荐方案
**方法**: musl-portable-replacement

**说明**: ①时钟改 clock_gettime(CLOCK_MONOTONIC)（或 gettimeofday 换算毫秒）②#ifndef NETDB_INTERNAL 定义 fallback (-1)（musl 语义等价）③h_errno 错误分支按 musl 返回码判断，禁止依赖 glibc 专用枚举

**修复命令**:
```
参考 archives/l/libco/1.0/patches/0001-co_hook_sys_call.cpp.patch
```

**验证**:
```
grep -rn "rdtsc\|NETDB_INTERNAL\|h_errno" <src_dir>；编译报 invalid output constraint '=a' 或 undeclared NETDB_INTERNAL 即命中
```
