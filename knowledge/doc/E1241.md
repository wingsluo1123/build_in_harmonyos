# E1241: Upstream release tag references a header it never ships (AArch64 NEON shim for SSE intrinsics)

## 基本信息
- **严重度**: 2
- **类别**: headers, cmake, packaging, compilation, aarch64
- **作者**: 98FF

## 错误特征
```
fatal error: 'sse_to_neon.h' file not found|.*sse_to_neon.h.*No such file
```

## 根因分析
上游发布 tag（以及 master）在 src/xxx.c 的 __aarch64__ 分支引用 include/sse_to_neon.h（SSE→NEON 翻译头），但该文件从不出现在仓库历史与任何 release tarball 中（README/CMakeLists 声称存在），导致 AArch64 首次构建即缺头失败

## 推荐方案
**方法**: 在当前库以最小补丁新增自包含 include/sse_to_neon.h：直接基于 <arm_neon.h> 实现源码实际使用的 SSE2/SSSE3/SSE4.1 内建（__m128i=int32x4_t；PSHUFB 用 vqtbl1q+0x8F 掩码；per-lane 移位用 vshlq 负计数且≥位宽归零；PMOVMSKB 用 vshr+加权水平加；cvtepi8_epi32 用 vmovl_s8+vmovl_s16），保持 Intel 拼写使库体免改动，并用上游单测+ctest 校验语义

**说明**: 新增自包含 NEON shim 头文件补齐上游缺失头；补丁头必须为 --- /dev/null 新增文件格式；环境 patch 为 toybox 时需先装 GNU patch（toybox 的 --dry-run 会在 orig 目录落盘 0 字节占位导致刷新误判为编辑）

**修复命令**:
```
grep -A5 "Apply patch" <conan-create.log>
```

**验证**:
```
ctest --output-on-failure && conan create ../../ -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
