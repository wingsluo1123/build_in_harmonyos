# E1242: Legacy upstream .tar.Z cannot be decoded by OHOS Toybox gzip: use a verified authoritative gzip repack

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, packaging
- **作者**: 7DD0

## 错误特征
```
gzip: not gzip|tar: Not tar|unsupported.*\.tar\.Z
```

## 根因分析
The official source uses the historical UNIX compress/LZW format (.Z), not gzip; OHOS Toybox gzip lacks LZW decoding and tar cannot read the stream. Conan get() also does not natively unpack .tar.Z.

## 推荐方案
**方法**: verified-authoritative-repack

**说明**: Use a versioned archive from an authoritative distribution mirror that already uses tar.gz; verify its SHA256 and compare library sources, public headers, and test fixtures against the official .tar.Z unpacked on a machine with LZW support. Record both source identities and keep Conan's checksum enforcement.

**修复命令**:
```
conanfile.py source(): get(self, **self.conan_data["sources"], strip_root=True)
```

**验证**:
```
sha256sum volpack-1.0b3.tar.Z; gzip -dc volpack-1.0b3.tar.Z | tar tf -; sha256sum volpack_1.0b3.orig.tar.gz; conan create archives/v/volpack/1.0b3 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64
```
