# E1244: OHOS libc.a 比 libc.so 多导出 ~380 个符号：-static 探针链接成功掩盖交付动态构建的 undefined symbol（rindex 等）

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, musl, linking
- **作者**: 6EE2

## 错误特征
```
ld\.lld: error: undefined symbol: (rindex|getw|cuserid|ecvt|fcvt|gcvt|getpass|lchmod|stime|setkey|encrypt)\b
```

## 根因分析
OHOS NDK sysroot 的 usr/lib/aarch64-linux-ohos/libc.a 与 libc.so 导出表不一致：libc.a 全局 T/W 符号 2319 个、libc.so 动态导出 1592 个，

## 推荐方案
**方法**: prefer-posix-branch-or-standard-api

**说明**: 优先切到上游自带的 POSIX/SysV 分支（如 macutils 去掉 -DBSD，hexbin 的 search_last 走 strrchr、wrfile 走 memcpy/memset、curtime 走 <time.h>），

**修复命令**:
```
_UPSTREAM_CF = "-DTYPES_H -DDIRENT_H -DTERMIOS_H -DNODOT -DAPPLEDOUBLE"  # 去掉 -DBSD
```

**验证**:
```
NM=$NDK/llvm/bin/llvm-nm; S=$NDK/sysroot/usr/lib/aarch64-linux-ohos; $NM -D --defined-only $S/libc.so | grep -cw rindex （0）; $NM --defined-only $S/libc.a | grep -cw 'T rindex' （1）
```
