# E1245: protobuf 33 把 utf8 校验拆为 libutf8_range/libutf8_validity 独立库，手工拼链接清单遗漏导致 VerifyUTF8Fallback 未解析

## 基本信息
- **严重度**: 2
- **类别**: compat, build-system, linking
- **作者**: 5EC1

## 错误特征
```
undefined reference to 'google::protobuf::internal::EpsCopyInputStream::VerifyUTF8Fallback|undefined reference to .*utf8_validity.*|undefined reference to .*Utf8Validate.*
```

## 根因分析
protobuf 33 起 utf8 校验拆分为独立静态库 libutf8_range.a 与 libutf8_validity.a，

## 推荐方案
**方法**: cmake-imported-target-link

**说明**: 用 CMake find_package(Protobuf CONFIG REQUIRED) + target_link_libraries(... protobuf::libprotoc) 让 conan 依赖图自动解析 utf8_range/validity/absl 全链；Protobuf_DIR/utf8_range_DIR/absl_DIR 三个变量直指包内 config 目录

**修复命令**:
```
find_package(Protobuf CONFIG REQUIRED) → target_link_libraries(protoc-gen-grpc-web PRIVATE protobuf::libprotoc)
```

**验证**:
```
ls <conan_package>/lib/libutf8_range.a <conan_package>/lib/libutf8_validity.a && grep -A3 "add_library(protobuf::libprotobuf" <pkg>/lib/cmake/protobuf/protobuf-targets.cmake | grep utf8
```
