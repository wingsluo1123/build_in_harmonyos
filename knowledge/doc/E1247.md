# E1247: ohos-hmdfs-python-exec-and-loader-mount-quirks

## 基本信息
- **严重度**: 2
- **类别**: toolchain, packaging, runtime
- **作者**: 37CC

## 错误特征
```
PermissionError.*install-sh|Permission denied.*zsh|unable to find library -l|Error loading shared library|SAFE_DELETE_BULK_GUARD_ERROR
```

## 根因分析
OHOS hmdfs(hmmac=use_task) 三重限制: 1) conan 解压丢失可执行位且 chmod 被 setgid 强制 770; 2) python posix_spawn 只能 exec 预装二进制(用户创建的脚本/链接/ELF 一律 EACCES)且不按 PATH 搜索裸命令名; 3) 动态加载器无法打开 hmdfs/网络挂载上的 .so; 另: 会话 PATH 中 rm 被 safe-delete 垫片劫持、PYTHONPATH 注入 sitecustomize 会在 conan 批量删临时目录时抛 PermissionError 杀死 conan

## 推荐方案
**方法**: relocate-conan-home-to-local-fs-and-probe-exec

**说明**: 把受 FS 限制影响的执行/加载面整体迁到应用沙箱本地 FS(el2), 并用

**修复命令**:
```
CONAN_HOME=/data/storage/el2/base/cache/conan2 env -u PYTHONPATH python3 scripts/ohc-run.py finish <pkg> <ver> built
```

**验证**:
```
PYTHONPATH=<conan-libexec> python3 <conan-libexec>/bin/conan --version   # conan 经「python3 读取入口脚本」执行应稳定输出版本号(绕 execve); 对照: 直接 exec 同一脚本间歇性 RC=126 → 证实 label 翻转而非缺包
```
