# E1248: 构建期生成器 cat 构建机 /usr/include 头文件再用 awk 抽表：交叉编译与鸿蒙真机上 2>/dev/null 吞掉缺失，静默生成空表，运行期按名解析信号全部失效

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, headers, build-system, cross-compile
- **作者**: 31E6

## 错误特征
```
Invalid "timeout" signal: SIG|/usr/include/bits/signum.h 2> /dev/null|cat /usr/include/signal.h
```

## 根因分析
上游 Makefile 用 `cat /usr/include/signal.h /usr/include/sys/signal.h

## 推荐方案
**方法**: generate-from-target-preprocessor

**说明**: 改为向目标编译器要宏定义：`echo '#include <signal.h>' | $(CC) $(CPPFLAGS)

**修复命令**:
```
echo '#include <signal.h>' | $(CC) $(CPPFLAGS) -E -dM -x c - | awk -f signals.awk > signals.h
```

**验证**:
```
grep -nE 'cat[[:space:]]+/usr/include' Makefile* */Makefile* 2>/dev/null;
```
