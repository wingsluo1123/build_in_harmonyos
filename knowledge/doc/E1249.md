# E1249: OHOS HMDFS 大小写不敏感下 autotools 目标名与源码目录同名冲突

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, portability, build-system, autotools
- **作者**: 2FCD

## 错误特征
```
cannot remove 'linuxpba': Is a directory|rm: cannot remove .*: Is a directory|make.*Error 1
```

## 根因分析
OHOS HMDFS 文件系统大小写不敏感（case-insensitive），autotools 的 sbin_PROGRAMS 目标可执行文件名（如 linuxpba）与源码目录名（如 LinuxPBA）大小写仅不同时被视作同一路径，链接时 make 先执行 rm -f 目标名即误伤源码目录，报 'Is a directory'。

## 推荐方案
**方法**: rename-target-avoid-case-collision

**说明**: 将可执行目标改名为与源码目录大小写不同的名字（如 linuxpba → sedutil-pba），同步修改 sbin_PROGRAMS 与对应 _SOURCES 变量

**修复命令**:
```
sed -i 's/linuxpba/sedutil-pba/g' Makefile.am && sed -i 's/linuxpba_SOURCES/sedutil_pba_SOURCES/' Makefile.am && automake && ./config.status Makefile && make -j1
```

**验证**:
```
stat -c %i linuxpba LinuxPBA 对比 inode 相同；make -j1 观察 rm: cannot remove 'linuxpba': Is a directory
```
