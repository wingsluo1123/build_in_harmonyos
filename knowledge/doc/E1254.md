# E1254: qmake 模块 .pri 路径重写正则漏 .cache/conan2 形态导致 QML 插件被静默跳过

## 基本信息
- **严重度**: 3
- **类别**: path-rewrite
- **作者**: QT5A

## 错误特征
```
Cannot read .*/mkspecs/modules-inst/qt_lib_(qml|quick|qmlmodels)\.pri: No such file or directory|qtHaveModule\(quick\).*false
```

## 根因分析
配方 _fix_qtbase_paths() 重写上游 qt5-qtdeclarative 包 mkspecs/modules*.pri 中的构建期旧路径时，正则只覆盖 /\.conan2/p/b/ 一种形态；当 conan home 位于 ~/.cache/conan2 时 .pri 内记录的是 .cache/conan2/p/b/ 形态，匹配不到导致旧路径残留，qmake 读不到 QtQuick 模块描述使 qtHaveModule(quick) 为假，src/src.pro 中 `qtHaveModule(quick): SUBDIRS += chartsqml2` 整个子目录被静默跳过；qmake 对读不到的 .pri 只告警不报错，退出码仍为 0

## 推荐方案
**方法**: widen-path-regex

**说明**: 把路径重写正则改为宽版以同时覆盖两种 conan home 形态，并提取为类级常量供所有 .pri/.prl/.pc/cmake 重写调用点复用，避免只修一处

**修复命令**:
```
_BUILD_DIR_PATTERN = re.compile(r"(/[^\s]*/(?:\.cache/)?\.?conan2/p/b/qt5-q[0-9a-f]+/b)")
```

**验证**:
```
grep -c "Cannot read .*mkspecs/modules-inst" build.log; ls $(conan cache path qt5-qtcharts/5.15.2:*)/qml/QtCharts/libqtchartsqml2.so
```
