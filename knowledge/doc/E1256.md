# E1256: 手写 Makefile C99 库的 Conan 静态库打包与参数化测试核算

## 基本信息
- **严重度**: 2
- **类别**: ohos, libc, make, conan, test-quality
- **作者**: LM01

## 错误特征
```
No rule to make target|consumer test hangs|test count mismatch
```

## 根因分析
上游仅提供手写 Makefile，且 Greatest 参数化注册次数与 TEST 函数定义数不同；消费者并发计数若非原子会丢增量造成假性挂起。

## 推荐方案
**方法**: manual-make-conan-recipe-and-instance-counting

**说明**: 固定源码 tarball sha256；配方在 source_folder 执行上游 make ci，手工复制库与头文件；逐个统计 RUN_TEST/RUN_TESTp 展开的实例，分别记录有据跳过；消费者测试的共享计数必须使用原子操作。

**修复命令**:
```
make CC=clang AR=llvm-ar ci
```

**验证**:
```
make CC=clang AR=llvm-ar ci; conan create archives/l/loom/0.1.1 --build=missing
```
