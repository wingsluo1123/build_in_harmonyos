# E1259: Python3 整数除法传给 random.randint 触发 float TypeError

## 基本信息
- **严重度**: 2
- **类别**: compat, python, testing
- **作者**: F73D

## 错误特征
```
TypeError: 'float' object cannot be interpreted as an integer|random\.randint\([^)]*float
```

## 根因分析
上游 Python2 时代测试/工具脚本在 Python3 下运行：/ 为真除法返回 float，random.randint/range/index 需要 int，导致 TypeError

## 推荐方案
**方法**: 将 / 改为 //（整数除法），如 random.randint(0, frame_size/16-4) -> random.randint(0, frame_size//16-4)

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
python3 -c "import random; random.randint(0, 40//4-4)" 修复前 frame_size/16 抛 TypeError，修复后正常
```
