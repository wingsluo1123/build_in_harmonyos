# E1260: ExternalProject 期 googletest 下载失败时用 Conan gtest 包 + 裸 target 桥接保留上游测试

## 基本信息
- **严重度**: 2
- **类别**: network, build-system, cmake, conan, testing
- **作者**: unknown

## 错误特征
```
CMake step for googletest failed|git clone.*googletest.*failed|googletest-download.*(FAILED|error)|Could not download.*googletest|GIT_REPOSITORY.*googletest.*Operation timed out
```

## 根因分析
上游 CMakeLists 在 BUILD_TESTING 分支里用 configure_file + execute_process 驱动

## 推荐方案
**方法**: external-gtest-via-conan-plus-bare-target-bridge

**说明**: 不打注释式跳过。把 configure 期 googletest 下载块整体替换为

**修复命令**:
```
补丁: find_package(GTest CONFIG REQUIRED); if(NOT TARGET gtest)
```

**验证**:
```
cd <pkg> && conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 2>&1 | tail -20; ctest --output-on-failure 或直接运行各测试可执行
```
