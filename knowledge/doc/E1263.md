# E1263: 脚本 shebang 写 #!/bin/sh 却使用 bash 方言（test ==、$[ ]、echo -n），在 OHOS 的 POSIX shell 下报 `[: ==: unexpected operator`，且因 test 失败走 else 分支而功能静默丢失

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, posix, shell
- **作者**: nyaco3 <aqjCItYW1QmEJQuF.gcw_XDpqZ8sO@noreply.gitcode.com>

## 错误特征
```
\[: ==: unexpected operator|
```

## 根因分析
Linux 桌面发行版上 /bin/sh 常被链到 bash，脚本即使声明

## 推荐方案
**方法**: posix-shell-normalize

**说明**: 打补丁把 bash 方言改成 POSIX 等价写法，保留 #!/bin/sh：

**修复命令**:
```
sed -i 's/\[ \$\([A-Za-z_][A-Za-z0-9_]*\) == "\([^"]*\)" \]/[ "$\1" = "\2" ]/g' script; sed -i 's/\$\[\([^]]*\)\]/$((\1))/g' script; dash ./script -h
```

**验证**:
```
dash ./script --help; echo "rc=$?"   # 或 sh 为严格 POSIX 实现的环境；对比 bash ./script --help
```
