# E1267: find_program 缓存断链符号链接 (glib-mkenums) 导致 idotypebuiltins 生成失败

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, toolchain, conan
- **作者**: E556
- **来源 PR**: 7826

## 错误特征
```
glib-mkenums: No such file or directory|Error 126|find_program
```

## 根因分析
CI bundle 的 /data/service/hnp/bin/glib-mkenums 是指向旧版阐库 glib_2.38.2 的断链符号链接; CMake find_program 在 configure 期按 PATH 缓存该坏路径, build 期执行失败 (Error 126)

## 推荐方案
**方法**: cmaketoolchain-variable-override-find_program-cache

**说明**: CMakeToolchain 变量显式覆盖 find_program 缓存的坏路径: tc.variables["GLIB_MKENUMS"] 指向 glib 包内真实脚本绝对路径, 并把 glib 包 bin/ 前置 PATH 兜底, 绕过断链符号链接缓存

**修复命令**:
```
tc.variables["GLIB_MKENUMS"] = os.path.join(self.dependencies["glib"].package_folder, "bin", "glib-mkenums"); env.prepend_path("PATH", glib_bin)
```

**验证**:
```
conan create 成功生成 idotypebuiltins.h 并完整构建; test_package ctest PASS
```
