# E1268: OHOS Python C 扩展必须使用 Conan Python 头文件与共享库路径

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, python, packaging
- **作者**: DF80
- **来源 PR**: !8218

## 错误特征
```
command 'cc' failed: No such file or directory|fatal error: Python.h file not found|ImportError:.*undefined symbol|PyInit_.*not found|Permission denied.*_fastconstmap.*\.so|temporary directory .* is not owned
```

## 根因分析
Python C 扩展的构建解释器、头文件、libpython 和 OHOS 加载权限若依赖设备私有 PATH，会导致编译器缺失、ABI 符号缺失或 HMDFS 拒绝加载

## 推荐方案
**方法**: conan-python-build-path

**说明**: 将 python/3.12.9 作为 Conan 依赖，动态发现其头文件与 libpython，并从 profile/conf 或 PATH 发现编译器和签名工具；test_package 用 ensurepip 加官方固定 wheel 的 SHA-256 校验安装 pytest 到一次性目录，并以显式 --basetemp 规避 HMDFS 所有权元数据问题，最终通过 runenv 暴露包的 Python 路径

**修复命令**:
```
conan create archives/f/fastconstmap/0.9.0 --build=fastconstmap/* -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create archives/f/fastconstmap/0.9.0 --build=fastconstmap/* -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 -s:h os.version=6.0 -s:b os.version=6.0
```
