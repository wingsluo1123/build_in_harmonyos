# E1269: tacopie-connect-timeout: select() with nfds=0 never monitors the connecting socket, so any timed connect() always throws

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, socket, network
- **作者**: DE47

## 错误特征
```
connect\(\) timed out|connect\(\) failure|tacopie_error
```

## 根因分析
upstream unix connect() calls select(0, NULL, &set, NULL, &tv): nfds=0 tells the kernel to monitor no file descriptor, so select() always waits the full timeout and returns 0; the connect() completion is never observed and the code throws 'connect() timed out' even when the peer accepted the connection

## 推荐方案
**方法**: fix-select-nfds

**说明**: pass m_fd + 1 as the nfds argument to select() so the connecting socket is actually monitored for writability

**修复命令**:
```
select(m_fd + 1, NULL, &set, NULL, &tv)
```

**验证**:
```
conan create . --profile=ohos-aarch64; ./test_tacopie（回环往返校验 payload）
```
