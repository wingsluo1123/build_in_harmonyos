# E1270: OHOS 缺少 Boost.Test 链接库时保留上游套件的 header-only 迁移与消费验证

## 基本信息
- **严重度**: 2
- **类别**: ohos, headers, cmake, conan, testing
- **作者**: Awstme

## 错误特征
```
undefined reference.*boost.*unit_test|libboost_unit_test_framework.*not found|Boost.Test.*header-only
```

## 根因分析
部分 OHOS 制品仓 Boost 包提供 Boost.Test 头文件但没有可链接的 libboost_unit_test_framework，直接沿用上游 unit_test.hpp 入口会在链接阶段失败。仅关闭上游测试会丢失真实覆盖；应区分运行时包依赖与测试构建依赖，沿用上游全部测试源，将入口切到 included/unit_test.hpp，并用 Conan CMakeDeps/CMakeToolchain 让独立 test_package 验证安装后的 CMake target。

## 推荐方案
**方法**: header-only-boost-test-with-independent-consumer

**说明**: 不改动上游断言或删减测试文件；通过可审查补丁把唯一测试入口改为 boost/test/included/unit_test.hpp，在 recipe 中以 test-only tool_requires 提供 Boost 头文件，按上游五个或实际完整测试翻译单元编译并运行；package_info 保持 header-only 运行时图，test_package 用 CMakeDeps 找到安装后的 CMake config/target，并执行真实 map/set API 检查。

**修复命令**:
```
patch tests/main.cpp: boost/test/unit_test.hpp -> boost/test/included/unit_test.hpp; compile all upstream test translation units with -std=c++11 and -DBOOST_DISABLE_THREADS; conan create ...; test_package consumer
```

**验证**:
```
conan create <recipe> --profile:host=ohos-aarch64 --profile:build=ohos-aarch64 --build=missing; grep -E "Running [0-9]+ test cases|No errors detected"; conan test test_package
```
