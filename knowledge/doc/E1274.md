# E1274: 鸿蒙 toybox grep 不支持 BRE 交替 \| → test_package 断言假失败

## 基本信息
- **严重度**: 2
- **类别**: platform, shell, test
- **作者**: BF6C

## 错误特征
```
grep -q .a\\|b. 返回 1|断言只在 conanrun 环境下失败|本地 shell 里同一条 grep 却通过
```

## 根因分析
鸿蒙 worker 上同时存在 /data/service/hnp/bin/grep（GNU 3.12）与 /usr/bin/grep → toybox（0.8.12）。conan 的 conanrun 环境 PATH 不含 hnp/bin，测试脚本里的 grep 落到 toybox，而 toybox 的 BRE 不支持 GNU 扩展 \| 交替，模式被当字面量，断言永远失败

## 推荐方案
**方法**: test-package-grep-fixed-string

**说明**: test_package/构建脚本里的字符串断言只用 grep -qF（固定串）或 grep -qE（ERE 的 | 被支持），不要用 BRE 的 \|

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
printf "xsection\n" | env -i PATH=/usr/bin:/bin sh -c "grep -q \"section|Title\"" ; echo $?
```
