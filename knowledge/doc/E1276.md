# E1276: 无 VPATH 支持的老 Makefile.in 在 Conan 默认 out-of-source 构建下找不到源文件

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools
- **作者**: B4CF

## 错误特征
```
No rule to make target '[a-z0-9._-]+\.c', needed by '[a-z0-9._-]+\.o'|No targets specified and no makefile found
```

## 根因分析
2010 年代早期及更老的 Makefile.in 把编译规则写成 foo.o: foo.c（无 $(srcdir) 前缀、无 VPATH 支持），Conan 2 默认 out-of-source 布局（basic_layout，构建目录与源码目录分离），make 在构建目录里找不到源文件。

## 推荐方案
**方法**: in-source-layout

**说明**: conanfile 的 layout() 改为源码目录就地构建（folders.source 与 folders.build 同置 "."），使 configure/make 与源码同目录，老 Makefile 规则原样可用

**修复命令**:
```
def layout(self): self.folders.source = "."; self.folders.build = "."
```

**验证**:
```
grep -c 'srcdir' Makefile.in 为 0 且 Makefile 规则形如 foo.o: foo.c 即中招
```
