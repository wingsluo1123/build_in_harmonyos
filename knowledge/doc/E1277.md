# E1277: CI pre-download 正则扫描 conandata.yml 全文（含注释）抓 URL，子串替换把真实源码 URL 污染成 gh-proxy.com/file://…

## 基本信息
- **严重度**: 2
- **类别**: detection, conan, packaging
- **作者**: B1A7

## 错误特征
```
gh-proxy\.com/file://.*Forbidden|NotADirectoryError:.*predl_cache.*\.tar\.gz|Could not download from the URL https://gh-proxy.com/file:///
```

## 根因分析
ci/conan/build_and_test.sh 的 pre-download 步骤用正则 (?:^|\s)(?:url:?\s*)?["']?-?\s*(https?://[^\s"']+) 扫描 conandata.yml 全文件提取 URL，然后 content.replace(url, file://...) 逐条子串替换。若注释里也写了 http(s) URL（如 # Upstream: https://github.com/owner/repo），该 URL 会被一起下载并替换；而它又是真实源码 URL 的前缀子串时，先替换短 URL 会把长 URL 改写成 https://gh-proxy.com/file:///…，final URL 既 403 又无法解析，conan source() 抛 NotADirectoryError。

## 推荐方案
**方法**: remove-non-source-urls-from-comments

**说明**: conandata.yml 注释中不要写裸 http(s):// URL（改用无 scheme 的 host/path，如 github.com/owner/repo）；只保留 sources.url 一个真实 URL。命令口径：用上面的 verification_cmd 确认 extract 到的 URL 数 = 1。

**修复命令**:
```
python3 -c "import re;raw=open('archives/l/p/v/conandata.yml').read();assert len(re.findall(r'https?://',raw))==1"
```

**验证**:
```
python3 -c "import re;raw=open('archives/<l>/<pkg>/<ver>/conandata.yml').read();print(re.findall(r'(?:^|\s)(?:url:?\s*)?[\"\x27]?-?\s*(https?://[^\s\"\x27]+)',raw,re.M))"
```
