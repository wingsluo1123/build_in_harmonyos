# E1278: PREFER_CONFIG=ON 时 conan 的 expat-config.cmake 只导出 expat::expat，exiv2 静态闭包 EXPAT::EXPAT 未定义

## 基本信息
- **严重度**: 2
- **类别**: compat, build-system, cmake, dependency
- **作者**: B188

## 错误特征
```
The link interface of target "[^"]*" contains:\s*EXPAT::EXPAT|EXPAT::EXPAT.*but the target was not found|IMPORTED target.*EXPAT::EXPAT
```

## 根因分析
exiv2/0.28.x 的静态库导出 exiv2Config.cmake，其 exiv2Targets.cmake 把传递依赖写成

## 推荐方案
**方法**: avoid-prefer-config

**说明**: 不设置 CMAKE_FIND_PACKAGE_PREFER_CONFIG（保持默认模块优先），使 find_dependency(EXPAT) 命中

**修复命令**:
```
从 conan_cmakedeps_paths.cmake 中移除 set(CMAKE_FIND_PACKAGE_PREFER_CONFIG ON)
```

**验证**:
```
cmake configure 日志中应无 "contains: EXPAT::EXPAT but the target was not found"；
```
