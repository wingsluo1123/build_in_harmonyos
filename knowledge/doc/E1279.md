# E1279: aarch64 协程切换汇编：返回地址与 real sp 必须存 regs 槽位而非依赖栈

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, portability, aarch64, assembly
- **作者**: unknown

## 错误特征
```
Segmentation fault|invalid output constraint|bus error.*coroutine|coroutine.*crash
```

## 根因分析
ARM64 的 BL 指令不压栈返回地址（返回地址在 x30/LR），照搬 x86_64 协程库的 call/ret 栈式语义会导致恢复上下文时跳错地址或 sp 错乱，表现为所有协程切换后 Segmentation fault

## 推荐方案
**方法**: aarch64-regs-array-swap

**说明**: 按 x86_64 原版语义把 callee-saved 寄存器、fp/lr、real sp、resume 地址、参数全部存入 ctx->regs 固定槽位，切换时 mov sp/br 恢复；与 C 侧 coctx_make 的槽位常量严格对齐（如 kA64SP=12/kA64RETAddr=13/kA64X0=22/kA64X1=23）

**修复命令**:
```
参考 archives/l/libco/1.0/patches/0004-coctx_swap.S.patch（保存 x19-x28/x29-x30/sp+lr/d8-d15/参数 x0-x1 进 regs[0..23]，恢复后 mov sp, x9; br x8）
```

**验证**:
```
编译 example 后运行：全部协程 example 立即崩溃（或首切即崩）= 汇编槽位/返回地址语义错；按 x86_64 原版"存/取 regs 数组"语义重写后 10 万次切换压测通过
```
