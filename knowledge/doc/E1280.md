# E1280: Conan CMakeDeps 导出目标名必须以实际生成结果为准

## 基本信息
- **严重度**: 2
- **类别**: compat, headers, cmake, conan, testing
- **作者**: A73F
- **来源 PR**: 7705

## 错误特征
```
Target.*links to.*minilua::|target was not found|Conan: Target declared.*minilua
```

## 根因分析
test_package 依据配方设置的 cmake_target_name 链接了命名空间目标 minilua::minilua，但设备端 Conan 2.29.1 的 CMakeDeps 根据该配置实际导出了未命名空间的 minilua 目标；错误发生在 CMake 生成阶段，不是编译器、链接器或上游 API 缺陷。

## 推荐方案
**方法**: cmake-target-name-from-generated-config

**说明**: 先查看设备端 CMakeDeps 的实际导出目标，再让 test_package 的 target_link_libraries 与生成目标完全一致；配方属性和消费者写法必须作为一组验证。

**修复命令**:
```
conan create archives/m/minilua/5.4.7 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```

**验证**:
```
conan create archives/m/minilua/5.4.7 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
