# E1281: 上游 tarball 自带 ltmain.sh 与 aclocal.m4 声明的 libtool 版本错配：生成的 libtool 缺 func_* 内建函数，链接期报 func_opt_split 不存在 / Version mismatch error

## 基本信息
- **严重度**: 3
- **类别**: compat, portability, build-system, autotools
- **作者**: A443, 0F4C

## 错误特征
```
libtool: Version mismatch error\.|Definition of this LT_INIT comes from libtool [0-9.]+|libtool\[[0-9]+\]: func_[a-z_]+: (inaccessible or not found|command not found)|func_opt_split: (inaccessible or not found|command not found)
```

## 根因分析
发行 tarball 内 ltmain.sh 与 aclocal.m4 不同源：libydpdict 1.0.4 的

## 推荐方案
**方法**: replace-ltmain-with-matching-libtool-release

**说明**: 用与 aclocal.m4 声明版本同号的 GNU libtool 官方发行包里的 ltmain.sh

**修复命令**:
```
conandata.yml: libtool_source.url=https://ftpmirror.gnu.org/libtool/libtool-2.4.tar.gz
```

**验证**:
```
grep -m1 'package_revision=' $SRC/ltmain.sh && grep -m1 'macro_revision=' $SRC/aclocal.m4
```
