# E1282: protobuf 30+ descriptor accessor 返回 absl::string_view，下游 protoc 插件按 std::string 消费产生批量编译错误

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, build-system
- **作者**: A2AC

## 错误特征
```
no matching function for call to 'std::map<.*>::insert\(.*absl::string_view|no match for 'operator\+'.*std::__1::basic_string.*absl::string_view|cannot convert.*absl::string_view.*to.*std::string|no viable conversion from 'absl::string_view' to 'std::string'
```

## 根因分析
protobuf 30 起（含 33.x）把 descriptor accessor（name()/full_name()/package()/

## 推荐方案
**方法**: source-patch-stringview-migration

**说明**: 只读 helper 形参 absl::string_view 化 + map key/拼接点显式 std::string() 包裹 accessor 返回值，固化为规范 patch 随 conandata.yml 应用

**修复命令**:
```
生成补丁后 conandata.yml 声明 patches（patch_type: compatibility），build() 内 apply_conandata_patches(self)
```

**验证**:
```
grep -n "absl::string_view" $(conan cache path protobuf 2>/dev/null)/include/google/protobuf/descriptor.h 2>/dev/null || grep -rn "string_view name()" <protobuf>/include/google/protobuf/descriptor.h
```
