# E1283: RLIMIT_AS 单位混用（MB 当字节）导致子进程 execvp 恒失败 ENOMEM

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, syscall
- **作者**: 9C4A

## 错误特征
```
status:.*execvp failed|exec failed: errno=12
```

## 根因分析
setrlimit(RLIMIT_AS) 传入以 MB 计的 space_limit 但内核单位为字节：地址空间被限到 ~31KB，execvp 装载动态库失败 ENOMEM（子进程随后 SIGUSR1 通知父进程，工具报 execvp failed）。Linux/OHOS 通用，与平台无关。

## 推荐方案
**方法**: scale-unit-to-bytes

**说明**: MB 值左移 20 位（乘 1048576）并强转 rlim_t 防 32 位溢出后传给 setrlimit(RLIMIT_AS)

**修复命令**:
```
l.rlim_cur = l.rlim_max = ((rlim_t) space_limit << 20);
```

**验证**:
```
setrlimit(RLIMIT_AS, 31914) 后 execv("/bin/echo") → errno=12 ENOMEM；改为 ((rlim_t) 31914 << 20) → 执行成功
```
