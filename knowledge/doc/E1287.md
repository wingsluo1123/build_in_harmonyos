# E1287: autotools AC_CHECK_DECLS(__builtin_ffs) 在 clang 下报 builtin must be directly called

## 基本信息
- **严重度**: 2
- **类别**: detection, ohos, portability, libc, autotools
- **作者**: 695D

## 错误特征
```
No ffs implementation found|builtin functions must be directly called|use of undeclared identifier 'ffs'
```

## 根因分析
OHOS musl 头文件未声明 ffs；configure 对 __builtin_ffs 的 AC_CHECK_DECLS 生成 (void)__builtin_ffs 取地址写法，clang 拒绝 builtin 取地址，三个 ffs 探测全失败

## 推荐方案
**方法**: preset-cache-var

**说明**: configure 中预设 ac_cv_have_decl___builtin_ffs=yes（clang 确定支持 __builtin_ffs，仅声明探测写法不兼容），或改 configure.ac 用 AC_LINK_IFELSE 直接调用探测

**修复命令**:
```
perl -0pi -e 's/(ac_fn_check_decl "\$LINENO" "__builtin_ffs")/ac_cv_have_decl___builtin_ffs=yes\n$1/' configure
```

**验证**:
```
cd $BUILD_SRC_DIR && grep -c ac_cv_have_decl___builtin_ffs configure && ./configure --prefix=$DEFAULT_PREFIX --with-int=imath && make check
```
