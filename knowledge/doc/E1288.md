# E1288: Conan toolchain 强制 CMAKE_CXX_EXTENSIONS=OFF 导致 GNU 扩展项目编译被拒

## 基本信息
- **严重度**: 2
- **类别**: cmake, toolchain, conan
- **作者**: 66FA

## 错误特征
```
requires compiler-specific extensions.*-std=gnu|CMAKE_CXX_EXTENSIONS OFF|std=gnu\+\+14
```

## 根因分析
Conan CMakeToolchain 对 compiler.cppstd=17 生成 set(CMAKE_CXX_EXTENSIONS OFF)，覆盖 cache_variables；capnproto 等上游要求 GNU 扩展(-std=gnu++NN)

## 推荐方案
**方法**: generate() 中 tc.cache_variables['CMAKE_CXX_EXTENSIONS']=True 后，对生成的 conan_toolchain.cmake 做字符串补丁 OFF->ON（同 capnproto 1.1.0/1.3.0 配方）

**说明**: 在 generate() 中设 cache_variables 后对生成的 conan_toolchain.cmake 做 OFF->ON 字符串补丁

**修复命令**:
```
sed -i 's/set(CMAKE_CXX_EXTENSIONS OFF)/set(CMAKE_CXX_EXTENSIONS ON)/' <generators>/conan_toolchain.cmake
```

**验证**:
```
conan create archives/c/capnproto/1.3.0 --user=ohpcd --channel=stable -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
