# E1290: 改变结构体布局的特性宏必须经 cpp_info.defines 下发，否则消费者与已编译库 ABI 不一致

## 基本信息
- **严重度**: 3
- **类别**: compat, portability, headers, socket
- **作者**: 5CC4

## 错误特征
```
no member named 'sin6_family'|struct sockaddr.*sin6|sizeof.*mismatch|invalid application of 'sizeof'
```

## 根因分析
特性宏分两类：只决定符号存在与否的功能开关，两侧不一致会表现为链接错误；而改变公共头里结构体/联合体成员类型的布局（ABI）宏，两侧不一致不报编译错，静默变成运行期越界。真机实测 fossa 的 NS_ENABLE_IPV6 使 sizeof(union socket_address) 从 16 变 28（fossa.h:537），配方最常见的疏漏是只把 -D 传给库、忘了写进 cpp_info.defines

## 推荐方案
**方法**: propagate-layout-macros-via-cpp-info-defines

**说明**: 把编进库的特性宏与下发给消费者的特性宏定义为同一份常量，package_info 里原样赋给 cpp_info.defines，并在 test_package 用编译期布局断言把这条契约钉住（宏不下发就编译不过）

**修复命令**:
```
self.cpp_info.defines = list(FEATURE_DEFINES)
```

**验证**:
```
clang -fsyntax-only -I<pkg>/include test.c        # 缺宏 ⇒ no member named 'sin6_family'
```
