# E1291: GNU make 默认目标为 all 时，conanfile build() 裸跑 make 再带 DESTDIR 不会执行安装 → stage 空 → 空包 → test_package Error 127

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, make, packaging, testing
- **作者**: 5C64

## 错误特征
```
No files in this package|inaccessible or not found|ConanException: Error 127|package\(\).*WARN.*No files|DESTDIR.*stage.*empty
```

## 根因分析
部分 GNUmakefile 的默认目标(default goal)是 all 而非 install。conanfile build() 若先 `make` 构建，再不带目标地执行 `make ... DESTDIR=<stage>`，只会再次重建 all，根本不会触发 install 规则——DESTDIR stage 目录保持为空，随后 package() 从 stage 复制得到空包。W3/CI 的 test_package 因此报 `.../bin/<exe>: inaccessible or not found` → ConanException Error 127（空包无 bin，与 ELF 签名/E011 无关）。

## 推荐方案
**方法**: explicit-install-target

**说明**: build() 中做 make install 时必须显式传 'install' 目标：`make ... install DESTDIR=<stage>`（确保 prerequisites 如 docs/数据一次性就绪，个别 (ignored) 目标如 myman.txt 依赖 col 缺失可忽略）。

**修复命令**:
```
make -j1 <同上变量> install DESTDIR=$STAGE
```

**验证**:
```
make -pn 2>/dev/null | grep -m1 '^.DEFAULT_GOAL' ; 或 conan create 后检查 <pkg>/bin 是否为空; 或运行 'make DESTDIR=$PWD/stage' 后 ls stage/usr/local/bin
```
