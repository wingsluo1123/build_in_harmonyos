# E1292: conan 包公共头依赖第三方头/平台宏却未传播给消费者（transitive_headers / cpp_info.defines 缺失）

## 基本信息
- **严重度**: 2
- **类别**: compat, musl, headers, threading, conan
- **作者**: 58D4

## 错误特征
```
fatal error: 'boost/[a-z0-9_/]+\.hpp' file not found|use of undeclared identifier 'pthread_setcancelstate'|Could not find a package configuration file provided by "(Boost|boost|OpenSSL)"|find_package\(boost\) (failed|not found)
```

## 根因分析
包内安装的公共头 include 了第三方头（如 kea/hooks/*.h → boost/any.hpp、

## 推荐方案
**方法**: conan-declare-transitive-headers-and-defines

**说明**: 在 requirements() 里对“会被公共头 include”的依赖显式声明 transitive_headers=True

**修复命令**:
```
self.requires("boost/1.85.0", transitive_headers=True)  # requirements();  self.cpp_info.defines = ["BOOST_SP_NO_PTHREAD_SETCANCELSTATE"]  # package_info()，if self.settings.os == "OHOS"
```

**验证**:
```
grep -n "INTERFACE_INCLUDE_DIRECTORIES" -A3 <test_package_build>/generators/<pkg>-Target-*.cmake; grep -rn "^#include <\(boost\|openssl\|log4cplus\)/" <package_folder>/include
```
