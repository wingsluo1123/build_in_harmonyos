# E1293: OHOS upstream Boost.Test can use verified source headers when Conan binaries are unavailable

## 基本信息
- **严重度**: 2
- **类别**: ohos, dependency, boost, test
- **作者**: F8E9

## 错误特征
```
Could NOT find Boost|Boost_INCLUDE_DIR|unit_test_framework|Missing prebuilt package for.*boost|Missing prebuilt package for.*zlib
```

## 根因分析
The upstream test project links Boost::unit_test_framework, but the OHOS arm64 Conan graph may have no compatible boost and transitive zlib binaries; configuring the original test project therefore fails before testing.

## 推荐方案
**方法**: source-boost-header-only

**说明**: Keep Boost out of the package requires graph; download a pinned official Boost source archive as test-only input, replace only the generated test main include with boost/test/included/unit_test.hpp, compile unchanged upstream test sources, and run the resulting binary.

**修复命令**:
```
clang++ -std=c++17 -DTSL_DEBUG -UNDEBUG -DBOOST_DISABLE_THREADS -isystem<boost-root> -I<package-include> <generated-main.cpp> <all-upstream-test-sources.cpp> -o upstream-tests -pthread
```

**验证**:
```
conan install --requires=boost/1.84.0 --build=never; cmake -S tests -B build; compile all upstream test translation units with Boost 1.86.0 header-only entry and run the suite.
```
