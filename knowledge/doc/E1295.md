# E1295: conan 的 OHOS profile 两侧同构使 cross_building 为 False，autotools 不获得三元组；配方写死 --build 又会反噬 x86 交叉构建机

## 基本信息
- **严重度**: 2
- **类别**: portability, autotools, cross-compile, conan
- **作者**: nyaco3 <aqjCItYW1QmEJQuF.gcw_XDpqZ8sO@noreply.gitcode.com>

## 错误特征
```
configure: error: cannot run C compiled programs|
```

## 根因分析
ci/conan/profiles/ohos-aarch64 被同时用作 -pr:h 与 -pr:b，两侧 settings 完全相同，

## 推荐方案
**方法**: host-triplet-only-with-config-guess-patch

**说明**: 补齐两个 autoconf 辅助脚本，配方仅在 settings.os == "OHOS" 时追加

**修复命令**:
```
tc.configure_args.append("--host=aarch64-linux-ohos")  # 配合 patches/ 修 config.sub 与 config.guess
```

**验证**:
```
./config.sub aarch64-linux-ohos && ./config.guess &&
```
