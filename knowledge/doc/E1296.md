# E1296: OHOS /tmp 只读：上游写死编译期 TMPDIR 的临时目录路径导致静默失败（ploticus proc drawcommands）

## 基本信息
- **严重度**: 2
- **类别**: platform, hardcoded-path, tmpdir
- **作者**: 40EF

## 错误特征
```
Cannot open draw commands file|error 522: Cannot open|/tmp/plo[A-Za-z0-9_]+|TDH_tmpdir
```

## 根因分析
上游把编译期宏 TMPDIR(/tmp) 直接拷进运行时全局 TDH_tmpdir，运行期不读环境变量；HarmonyOS PC 将 /tmp 挂载为只读，于是所有临时文件写入失败（进程仍返回 0 -> 静默降级，图元/中间结果丢失）

## 推荐方案
**方法**: 把临时目录改为运行期选择：$TMPDIR(可用) -> 编译期默认(可用) -> 当前工作目录；可用性用 fopen 探测文件实测（access() 在 HMDFS 不可靠）

**说明**: 运行期选择可用临时目录（探测文件法），不引入平台宏

**修复命令**:
```
sed -i 's|strcpy( TDH_tmpdir, TMPDIR );|/* runtime tmpdir selection */|' src/preliminaries.c
```
