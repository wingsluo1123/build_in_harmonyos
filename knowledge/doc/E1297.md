# E1297: autotools 单目标 make（如 make src/env）跳过 BUILT_SOURCES 生成头导致编译失败

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools
- **作者**: 40AB

## 错误特征
```
configmake\.h.*file not found|stdckdint\.h.*file not found|stdcountof\.h.*file not found|fatal error: 'configmake\.h' file not found
```

## 根因分析
autotools 项目的 BUILT_SOURCES（configmake.h/stdckdint.h/stdcountof.h 等）仅在 all 目标中生成；直接 make <单目标> 会跳过这些生成头，编译 src/*.c 时 #include 报 file not found。

## 推荐方案
**方法**: full-make-or-built-sources

**说明**: 不要用单目标 make 跳过生成步骤；用完整 make（或先 make 生成头再单目标），或在配方 build() 内保证 BUILT_SOURCES 构建

**修复命令**:
```
make -j2
```

**验证**:
```
make -j1 src/env 报 configmake.h not found；完整 make 后生成 lib/configmake.h lib/stdckdint.h 等，src/env 编译通过
```
