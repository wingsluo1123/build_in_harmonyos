# E1299: add-include-limits-h

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, headers, vendored
- **作者**: 2EE3

## 错误特征
```
use of undeclared identifier 'PATH_MAX'|ZPL_MAX_PATH|zpl.h
```

## 根因分析
内嵌(zpl-c/zpl)聚合头 zpl.h 在 ZPL_SYSTEM_UNIX 分支使用 PATH_MAX 定义 ZPL_MAX_PATH，但头文件自身未包含 <limits.h>；glibc 环境常被其他系统头传递包含而掩盖，OHOS musl/clang 环境无传递包含导致 'use of undeclared identifier PATH_MAX'

## 推荐方案
**方法**: add-include-limits-h

**说明**: 在 zpl.h 的 include 区（stdarg.h/stddef.h 之后）补 #include <limits.h>

**修复命令**:
```
sed -i '/#include <stddef.h>/a #include <limits.h>' code/vendor/zpl.h
```

**验证**:
```
grep -n 'ZPL_MAX_PATH\|limits.h' code/vendor/zpl.h
```
