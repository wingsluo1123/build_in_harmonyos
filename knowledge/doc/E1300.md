# E1300: OHOS clang 包装器隐式 sysroot 使 CMake find_path 找不到内核头，ECM FindInotify 失败静默禁用 KDE 包的 KINOTIFY 门控测试树

## 基本信息
- **严重度**: 2
- **类别**: cmake, cross-compile, testing, ecm, kde
- **作者**: calbee21 <calbee21@noreply.gitcode.com>
- **来源 PR**: baloo 6.28.0

## 错误特征
```
No tests were found|BUILD_KINOTIFY.*FALSE|Inotify.*not been found|find_path.*sys/inotify.h
```

## 根因分析
>

## 推荐方案
**方法**: sysroot-prefix-injection

**说明**: >

**修复命令**:
```
list(PREPEND CMAKE_PREFIX_PATH "<sysroot>/usr")
```

**验证**:
```
grep -i "Inotify" <build>/CMakeCache.txt; ctest --test-dir <build> -N
```
