# E1301: OHOS 上 CPython subprocess 走 posix_spawn 不解析 PATH：meson 以裸名探测 llvm-ar 报 ENOENT（which 却能找到）

## 基本信息
- **严重度**: 3
- **类别**: platform, meson, toolchain
- **作者**: unknown

## 错误特征
```
Unknown linker\(s\): \[\[\'llvm-ar\'\]\]|Running `llvm-ar --version` gave "\[Errno 2\] No such file or directory"
```

## 根因分析
OHOS(musl) 上 CPython 3.12 subprocess 走 posix_spawn，执行不含 '/'

## 推荐方案
**方法**: absolute-path-tool-injection

**说明**: 任何把外部工具名写进构建配置（machine file、Makefile、探测脚本）的
