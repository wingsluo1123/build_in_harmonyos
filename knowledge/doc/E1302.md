# E1302: MesonToolchain machine-file pkg_config_path 完全替换 env PKG_CONFIG_PATH，遮蔽依赖经 buildenv_info 暴露的 pc 目录

## 基本信息
- **严重度**: 2
- **类别**: meson, toolchain, conan, pkg-config
- **作者**: 1512

## 错误特征
```
Dependency "[a-z0-9_-]+proto" not found \(tried pkg-config and cmake\)|Run-time dependency [a-z0-9_-]+ found: NO
```

## 根因分析
conan MesonToolchain 无条件在 conan_meson_native.ini 写 pkg_config_path=<generators folder>。mesonbuild/dependencies/pkgconfig.py _get_env() 用 env.set('PKG_CONFIG_PATH', machine-file 列表) 调用 pkg-config——是替换而非追加进程 env。于是依赖配方用 buildenv_info.append_path('PKG_CONFIG_PATH', <pkg>/share/pkgconfig) 暴露的 pc 模块（xorgproto 的 29 个 proto pc: dri2proto.pc 等，PkgConfigDeps 只按 cpp_info/pkg_config_name 生成一个 pc，不会复制包内自带的 proto pc）对 meson 完全不可见，dependency('dri2proto') 报 not found。autotools 不受影响（AutotoolsToolchain 用 env.prepend_path 追加）。

## 推荐方案
**方法**: rewrite-machine-file-pkg-config-path-list

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
generate() 中 tc.generate() 后正则改写 conan_meson_native.ini 的 pkg_config_path 行为 meson 列表: pkg_config_path = ['<generators>', '<dep>/share/pkgconfig', '<dep>/lib/pkgconfig']（generators 在前保持 conan 生成 pc 优先级）；参考 archives/l/libvdpau/1.5/conanfile.py _extend_meson_pkg_config_path()
```

**验证**:
```
PKG_CONFIG_PATH= conan create … 2>&1 | grep 'Run-time dependency dri2proto found'
```
