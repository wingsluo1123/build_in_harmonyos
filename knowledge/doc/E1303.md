# E1303: patch-generated-libtool-quoting

## 基本信息
- **严重度**: 3
- **类别**: compat, autotools, libtool
- **作者**: unknown

## 错误特征
```
libtool: link: ar cru $|
```

## 根因分析
2020 年代的 ltmain.sh（libtool 2.4.x，随 openconnect-8.10

## 推荐方案
**方法**: patch-generated-libtool-quoting

**说明**: configure 后 make 前修补生成的 libtool：双引号模板赋值改单引号、\ 去转义、print→printf、损坏的 archive_expsym_cmds 置空（或 --disable-symvers）、依赖 .la libdir 重写 + -lpthread 剥离

**修复命令**:
```
参考实现 archives/o/openconnect/8.10/conanfile.py 的 _fix_libtool_quoting/_fix_dependency_la_paths/_strip_libpthread_from_makefile（确定性文本变换）
```

**验证**:
```
grep -n 'old_archive_cmds=' <builddir>/libtool | head -2;
```
