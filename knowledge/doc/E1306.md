# E1306: 上游 C 库 malloc(1)+strncat 拼接前缀导致堆缓冲区溢出（get_neighbor 高精度邻居截断）

## 基本信息
- **严重度**: 2
- **类别**: memory, c, safety, upstream-bugfix
- **作者**: 0542

## 错误特征
```
get_neighbor.*strncat|malloc\(sizeof\(char\) \* 1\)|Expected hash.*w40k|neighbors.*truncat
```

## 根因分析
上游 geohash.c get_neighbor() 中 char *base = malloc(1) 后用 strncat 追加 hash 前缀并 strcat 追加末字符，任何长度>0 的 hash 都会越界写堆内存；高精度(≥8) hash 的邻居计算产生截断/越界读（未定义行为，堆布局相关）。属上游缺陷，与 OHOS 平台无关。

## 推荐方案
**方法**: heap-buffer-alloc-length-plus-1

**说明**: 按前缀长度 + 末尾字符 + NUL 分配：malloc(hash_length+1)，再 strncat 前缀 + strcat 末字符；杜绝 strncat/strcat 在不足空间上的拼接。属通用 C 内存安全修复，可跨库复用。

**修复命令**:
```
char *base = malloc(sizeof(char) * (hash_length + 1)); base[0]='\\0'; strncat(base, hash, hash_length - 1); ... strcat(base, last_hash);
```

**验证**:
```
clang geohash_test.c geohash.c -o a.out && ./a.out —— 修复前输出 3 条 neighbor Error（w40k/w40s/w40j 截断），修复后 0 错误；test_package ctest 高精度邻居 8 断言全过
```
