# E1307: 在 find 仍在读取的目录里用 find -exec 改名或复制：OHOS 的 toybox find 边读边处理，会把改名后的新目录项再次匹配，同一文件被改名两次（GNU find 先读完整个目录，桌面上不暴露）

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, filesystem, shell
- **作者**: nyaco3 <aqjCItYW1QmEJQuF.gcw_XDpqZ8sO@noreply.gitcode.com>
- **来源 PR**: 11843

## 错误特征
```
FAIL .*renamed file present: expected <1> got <0>|
```

## 根因分析
GNU find 基于 fts：进入一个目录时先把全部目录项读进内存，再逐个处理，

## 推荐方案
**方法**: snapshot-find-results-before-mutating

**说明**: 先把 find 的全部匹配结果存进变量（快照），遍历结束后再逐个处理：

**修复命令**:
```
matches=$(find ./ -name "$1"); oldifs=$IFS; IFS=$(printf '\n_'); IFS=${IFS%_}; set -f; for m in $matches; do handle "$m"; done; set +f; IFS=$oldifs
```

**验证**:
```
d=$(mktemp -d); cd "$d"; for i in $(seq 200); do : > f$i.log; done; toybox find ./ -name '*.log' -exec sh -c 'mv "$1" "p_$(basename "$1")"' sh {} \; ; ls | grep -c '^p_p_'   # >0 即命中
```
