# E1309: LINPACK dqrdc/dqrsl 缺失：openblas/lapack 不含经典 LINPACK QR 例程，需自带 netlib 源码

## 基本信息
- **严重度**: 2
- **类别**: linking, fortran
- **作者**: 96CE

## 错误特征
```
undefined symbol dqrdc_/dqrsl_ when linking Fortran R-package code that calls classic LINPACK QR routines; openblas and lapack packages both lack dqrdc/dqrsl (only dgeqrf/dgeqp3)
```

## 根因分析
openblas and lapack provide BLAS+LAPACK but not the classic netlib LINPACK routines dqrdc/dqrsl; R provides them internally from its own LINPACK bundle, so R packages that call them link fine under R but break standalone

## 推荐方案
**方法**: bundle public-domain netlib LINPACK dqrdc.f/dqrsl.f into src/ via a patch that adds new files (conandata patches support new file mode); compile them with flang along with the package's own Fortran sources

```
llvm-nm libopenblas.a 2>/dev/null | grep dqrdc_  # 空即确认缺失；链接报 undefined symbol dqrdc_ 即触达
```
