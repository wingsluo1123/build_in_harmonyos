# E1310: LLVM monorepo 构建 LLDB 必须启用 clang 项目（LLVM_ENABLE_PROJECTS=clang;lldb）

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, system
- **作者**: 78DD

## 错误特征
```
Expected directory for clang-resource headers not found|LLDBConfig.cmake:305|clang resource headers|LLVM_ENABLE_PROJECTS.*lldb
```

## 根因分析
LLDB 的表达式求值器与命令层链接 Clang 库，LLDBConfig.cmake 要求 clang/<version> resource headers 目录；若 monorepo 构建仅启用 LLVM_ENABLE_PROJECTS=lldb 而缺 clang，configure 阶段即 FATAL_ERROR

## 推荐方案
**方法**: LLVM_ENABLE_PROJECTS 必须设置为 clang;lldb（分号分隔），并保持 LLVM_TARGETS_TO_BUILD=AArch64；conanfile.py generate() 中注入

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan create -pr:h=ci/conan/profiles/ohos-aarch64 --build=missing 通过; lldb --version 输出 lldb version 17.0.0rc
```
