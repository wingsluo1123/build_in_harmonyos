# E1311: LLDB/LLVM monorepo CMake 平台分支缺 HarmonyOS（LLDB_ENABLE_POSIX + 多插件分支）

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, cmake
- **作者**: 374F

## 错误特征
```
LLDB_ENABLE_POSIX.*OFF|LLDB_ENABLE_POSIX 0|CMAKE_SYSTEM_NAME MATCHES "Linux\|Android"|TCP_NODELAY.*undeclared|NativeProcessLinux::Manager.*undefined|unable to locate lldb-server
```

## 根因分析
LLVM 17 monorepo 内多个 CMake 文件(HandleLLVMOptions/LLDBConfig/LLDBGenerateConfig/Host/Process/Initialization/lldb-server) 的平台分支仅含 Linux|Android，OHOS 工具链 CMAKE_SYSTEM_NAME=HarmonyOS 全部落空: LLDB_ENABLE_POSIX=OFF 导致 netinet/tcp.h 等 POSIX 头不包含(TCP_NODELAY 未声明), Linux/POSIX 插件目录未加入, lldb-server 未构建(NativeProcessLinux 未链入)

## 推荐方案
**方法**: 将 HarmonyOS 加入全部平台分支字符串: HandleLLVMOptions.cmake elseif(FUCHSIA OR UNIX OR CMAKE_SYSTEM_NAME STREQUAL HarmonyOS), LLDBGenerateConfig if(UNIX OR HarmonyOS), Host/Process/Initialization/lldb-server CMakeLists 的 Linux|Android 匹配扩展为 Linux|Android|HarmonyOS, LLDBConfig LLDB_CAN_USE_LLDB_SERVER 加入 HarmonyOS

**说明**: 一句话描述这个推荐方案

```
可选: 具体命令模板(${VAR}变量引用)
```
