# E1312: musl open_memstream needs explicit fflush before fclose

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, libc, musl, stdio
- **作者**: 76B9, Awstme
- **来源 PR**: (本 PR)

## 错误特征
```
open_memstream.*fclose.*not.*sync|open_memstream.*fflush|f_size.*0.*open_memstream|double.free.*open_memstream
```

## 根因分析
musl open_memstream only publishes buffered writes to the external buffer after an explicit fflush; fclose alone does not sync the buffer, and freeing the buffer without flushing triggers a double-free

## 推荐方案
**方法**: open-memstream-explicit-fflush-before-fclose

**说明**: Call fflush() on the open_memstream stream before fclose() (and before reading back the returned buffer or freeing it); the same applies to fseek overwrite writes that must be flushed to take effect

**修复命令**:
```
before fclose(): fflush(fres); // also fflush after fseek overwrite writes
```

**验证**:
```
conan create archives/p/pipewire/1.4.9 --build=missing && meson test -C build (test-spa json_data, test-support)
```
