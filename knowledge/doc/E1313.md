# E1313: OHOS memfd denies fstat; fall back to known size for mmap bounds check

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, syscall, fstat, memfd
- **作者**: 6186

## 错误特征
```
fstat.*EACCES.*memfd|memfd.*fstat|fstat\(.*memfd
```

## 根因分析
OHOS memfd denies fstat with EACCES; mapping code that gates mmap on fstat() bounds check fails even though mmap itself succeeds

## 推荐方案
**方法**: memfd-fstat-fallback-known-size

**说明**: When fstat() on a memfd fails, fall back to the known allocation size for the bounds check instead of aborting the mapping

**修复命令**:
```
patch mem.c: if (fstat(fd,&sb) != 0) { memset(&sb,0,sizeof(sb)); sb.st_size = block->size; }
```

**验证**:
```
conan create archives/p/pipewire/1.4.9 --build=missing && test_package/test_ohos
```
