# E1315: SDL2 无加速渲染环境（dummy 视频驱动/无 GPU）需回退 SDL_RENDERER_SOFTWARE

## 基本信息
- **严重度**: 2
- **类别**: headless, rendering, sdl2
- **作者**: B8FC

## 错误特征
```
Couldn.t find matching render driver|SDL_CreateRenderer.*NULL|renderer.*is invalid.*sdl.cpp
```

## 根因分析
SDL_CreateRenderer(mw, -1, SDL_RENDERER_ACCELERATED) 在 dummy 视频驱动或未提供 OpenGL 加速的环境返回 NULL；上游游戏不处理 NULL renderer，后续 SDL_Render* / SDL_CreateTexture 全部失败并在渲染循环 SIGSEGV。

## 推荐方案
**方法**: 创建加速渲染器失败时回退 SDL_CreateRenderer(mw, -1, SDL_RENDERER_SOFTWARE)。SDL 软件渲染器在 dummy 驱动下可用，支持 SDL_TEXTUREACCESS_TARGET 渲染目标，可支撑无头冒烟测试（SDL_VIDEODRIVER=dummy + timeout 运行不崩溃）。
