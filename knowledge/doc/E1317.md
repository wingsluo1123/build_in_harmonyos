# E1317: 引号 #include "SDL.h" 在大小写不敏感 FS 上经 -I. 命中项目自身 sdl.h，导致 SDL_image.h 报 unknown type name

## 基本信息
- **严重度**: 2
- **类别**: autotools, filesystem, include
- **作者**: 035C

## 错误特征
```
unknown type name .SDL_Texture|SDL_image.h:.*unknown type name|non-portable path to file.*differ.*in case
```

## 根因分析
SDL_image.h/SDL_ttf.h 内部用引号 #include "SDL.h"。当项目自身头文件也叫 sdl.h（lbreakouthd 的 src/sdl.h）且编译命令含 -I. 时，在大小写不敏感 FS（HMDFS）上 "SDL.h" 先解析到项目 sdl.h 而非真实 SDL.h，产生环形包含与 SDL 类型未定义。上游在大小写敏感 Linux 上无此问题。

## 推荐方案
**方法**: 调整项目 include 顺序：先 #include <SDL2/SDL.h> 再含 SDL_image.h/SDL_ttf.h，使真实 SDL.h 已完整处理，后续引号 SDL.h 命中项目 sdl.h 时被 include guard 跳过。

**说明**: 一句话描述这个推荐方案
