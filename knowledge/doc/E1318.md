# E1318: conan test_package 端到端运行 GUI/CLI 二进制时动态库无法加载：test() 显式注入依赖库 dirs 与 OHOS SDK libc++ 运行时路径

## 基本信息
- **严重度**: 2
- **类别**: ohos, conan, runtime, testing
- **作者**: B560, GoliWie
- **来源 PR**: 未合并（分支 feat/kjumpingcube-26.04.0，run kjumpingcube-26.04.0）

## 错误特征
```
Error loading shared library lib[^ ]+\.so|symbol not found.*X[A-Z]|wmsmixer --version.*Error 32512|Error 32512
```

## 根因分析
application 包（GUI/CLI 可执行文件）的 test_package 若在 test() 中端到端

## 推荐方案
**方法**: test-inject-ld-library-path

**说明**: test_package/conanfile.py 的 test() 中遍历 self.dependencies 收集各依赖

**修复命令**:
```
ld_paths = [sdk_libcxx] + [os.path.join(d.package_folder, d2) for d in self.dependencies.values() if d.package_folder for d2 in (d.cpp_info.libdirs or [])]
```

**验证**:
```
conan create <recipe> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
