# E1322: 发行 tarball 的 autotools 时间戳触发 aclocal/automake 重跑（OHOS 无 automake）

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, autotools
- **作者**: 3F4A

## 错误特征
```
aclocal-1\.16: inaccessible or not found|WARNING: 'aclocal-1\.16' is missing on your system|Makefile:.*aclocal\.m4.*Error 127
```

## 根因分析
发行 tarball 中 configure.ac 比 aclocal.m4/configure 新，make 触发 am--refresh 重跑 aclocal/automake，而 OHOS 没有 automake

## 推荐方案
**方法**: normalize-source-mtime

**说明**: 在 source() 内把整棵源码树 mtime 归一为同一值，使 make 认为已生成文件均为最新，不再触发 am--refresh

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
make -n | grep aclocal
```
