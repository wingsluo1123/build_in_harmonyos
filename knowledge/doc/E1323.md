# E1323: upstream tag may advertise a self-test option or build target that is unimplemented or BROKEN - verify before claiming testability

## 基本信息
- **严重度**: 2
- **类别**: upstream-test-verification
- **作者**: 11A7

## 错误特征
```
self-test option exits non-zero silently|OPT_TEST registered but never handled|no test target in Makefile|target marked BROKEN|exit code 3 from -T flag
```

## 根因分析
上游某个 tag 的 CLI 可能已登记自检选项（如 digitemp v3.7.2 的 -T 仅置位 OPT_TEST 标志，src/digitemp.c:2423，无任何后续处理）或已在 Makefile 标注 BROKEN 的目标（ds2490 需 libusb）。上游 CI workflow 里出现的命令不保证在该 tag 上可用：v3.7.2 执行 ./digitemp_DS9097 -T 恒返回 exit 3，且 Makefile 无 check/test 目标，因此不能据此认定存在可执行的上游测试套件。

## 推荐方案
**方法**: 先在上游源码中检索该选项的处理分支与 Makefile 的测试目标（grep 选项字符/OPT_ 常量/check/test/installcheck），确认实现存在；确认无实现则按 ci/config/no_official_test.txt 机制申报无官方测试，并保留实际执行证据（退出码）写入 test-report.md
