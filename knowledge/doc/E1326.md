# E1326: 上游 auxil/broker 硬编码 /tmp 临时目录，鸿蒙 /tmp 为只读 HMDFS 挂载，mkstemp 失败致 broker.backend 测试失败（Unable to create unique filename: Read-only file system）

## 基本信息
- **严重度**: 2
- **类别**: platform, hmdfs, portability, posix
- **作者**: B2E7
- **来源 PR**: 11976

## 错误特征
```
Unable to create unique filename: Read-only file system|broker\.backend.*FAILED|mkstemp.*Read-only
```

## 根因分析
auxil/broker/libbroker/broker/detail/filesystem.cc 的 make_temp_file_name() 硬编码 char fname[] = "/tmp/broker.test.XXXXXX"；鸿蒙 PC 上 /tmp 为只读 HMDFS 挂载，mkstemp 返回 EROFS，测试进程打印错误并 exit。与 E002（平台 /tmp 只读）的关系：E002 是纯平台侧现象（任何写 /tmp 失败），本条是"源码硬编码 /tmp"×"平台 /tmp 只读"双因素碰撞——仅 export TMPDIR 无效（源码不读取 TMPDIR），必须源码可移植化补丁，且测试时 TMPDIR 需指向可写目录（补丁在 TMPDIR 为空时回退 /tmp，上游主机行为不变）。

## 推荐方案
**方法**: tmpdir-portable-rewrite

**说明**: 将硬编码 /tmp 字面量替换为 ::getenv("TMPDIR")（为空回退 /tmp）+ snprintf（512 缓冲，溢出 exit(1) 并打印消息）；补丁仅改测试临时文件命名路径，生产运行路径零影响。测试执行时 export TMPDIR=<可写目录>（如 /storage/Users/currentUser/tmp/...）。zeek 8.2.1 实测：broker.* 25/26 → 26/26（100%）。

**修复命令**:
```
TMPDIR=<可写目录> ctest -R 'broker\.'
```

**验证**:
```
grep -n '"/tmp' auxil/broker/libbroker/broker/detail/filesystem.cc  # 无输出=已修复；修复后 TMPDIR=<可写目录> ctest -R 'broker\.' 应 26/26
```
