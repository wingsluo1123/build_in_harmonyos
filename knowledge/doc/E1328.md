# E1328: OHOS /bin/sh 对 SIGHUP 以 WIFEXITED(129) 退出而非 WIFSIGNALED：编译期子进程 shell 覆盖修复

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability, syscall, shell
- **作者**: 4F2C

## 错误特征
```
WIFSIGNALED|ExitInterrupted.*vs|kill -HUP|SIGHUP.*129|128\+1
```

## 根因分析
OHOS 设备 /bin/sh（toybox 系，musl aarch64）收到 SIGHUP 时以 exit(128+1)=129 正常退出（WIFEXITED）而非被信号杀死（WIFSIGNALED）；依赖 WIFSIGNALED(SIGHUP) 做中断检测的上游测试（如 ninja SubprocessTest.InterruptChildWithSigHup 期望 ExitInterrupted=130）在 OHOS 上失败（实际 129）。POSIX 信号语义 shell（如 /data/service/hnp/bin/bash）实测 WIFSIGNALED(SIGHUP) 正确

## 推荐方案
**方法**: subprocess-shell-compile-override

**说明**: 把子进程 shell 路径改为编译期宏（如 NINJA_SUBPROCESS_SHELL，默认 /bin/sh 保持其他平台不变），OHOS 构建以 -DNINJA_SUBPROCESS_SHELL=/data/service/hnp/bin/bash 覆盖为 POSIX 信号语义 shell

**修复命令**:
```
cmake . -DNINJA_SUBPROCESS_SHELL=/data/service/hnp/bin/bash && cmake --build . --target ninja_test
```

**验证**:
```
./ninja_test --gtest_filter=SubprocessTest.InterruptChildWithSigHup  → PASSED（补丁后 130==ExitInterrupted）
```
