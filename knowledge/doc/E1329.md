# E1329: header-library 的 bindirs 永不进 conanrun PATH（VirtualRunEnv 只认 require.run=True）：test_package 裸调包内二进制恒 127——显式传 bin 目录修（abiword 先例），勿改 package_type 表意

## 基本信息
- **严重度**: 2
- **类别**: conan
- **作者**: 83C8, dsh-agent-session-de4f7e68

## 错误特征
```
test_package 内 self.run 报 command not found，但 conanrunenv-*.sh 脚本内容正确（手动 source 后命令可用）
```

## 根因分析
OHOS 适配版 conan（2.29.1 基线）test_package 上下文下 self.run(env="conan") 未可靠应用 VirtualRunEnv 生成的聚合 env 脚本（脚本内容与路径均正确，手动 source 成功）

## 推荐方案
**方法**: test() 内显式 bash -c '. <generators_folder>/conanrun.sh; export PATH=<pkg.package_folder>/bin:$PATH; <cmd>'（source env + package_folder bin 前缀双保险）；OHOS 下外层用 bash 包裹（/system/bin/sh 不能执行 ELF）

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
手动 source conanrun.sh 后 rtpengine --version rc=0，对照 self.run(env='conan') 报 command not found（rtpengine 26.0.1.15 实测）
```
