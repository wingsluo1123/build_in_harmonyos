# E1330: 旧 libc++ std::construct_at 不支持聚合体初始化：聚合 struct emplace_back 报 no matching function

## 基本信息
- **严重度**: 1
- **类别**: platform, c++20, cplusplus, libcxx-stdlib
- **作者**: 6EC2
- **来源 PR**: 11976

## 错误特征
```
no matching function for call to 'construct_at'|emplace_back.*aggregate
```

## 根因分析
OHOS SDK libc++ 15.0.4 的 std::construct_at 实现未覆盖聚合体括号初始化路径（新版 libc++ 已支持）。zeek 8.2.1 实测 CallInfo（const CallExpr*/Frame* 聚合 struct）与 script_opt 的 DispatchInfo vector::emplace_back(nullptr,&f) 编译失败。

## 推荐方案
**方法**: add-explicit-constructor

**说明**: 给聚合 struct 补 constexpr（或普通）构造函数（可移植，新旧 libc++ 皆可）。zeek 的 CallInfo 与 DispatchInfo 实测，两处均一次修复。

**修复命令**:
```
make（相关目标编译通过=验证）
```

**验证**:
```
最小探针 struct A 含 const void* 成员后 vector emplace_back(nullptr)，clang++ -std=c++20 编译
```
