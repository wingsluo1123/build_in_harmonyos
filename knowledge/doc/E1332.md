# E1332: 上游 find_package(GTest) 大写 vs CMakeDeps 小写 gtest：GTest_DIR 指向包内 CMake 配置

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan
- **作者**: 2C1D

## 错误特征
```
GTest::gtest.*target was not found|find_package\(GTest\)|but the target was not found
```

## 根因分析
ninja 上游 CMakeLists 调用 find_package(GTest)（大写）并链接 GTest::gtest 目标，而 Conan CMakeDeps 生成的是小写 gtest 配置；将 GTest_DIR 指向 conan gtest 包自带的 lib/cmake/GTest/GTestConfig.cmake（定义 GTest::gtest 导入目标）即解决目标名不匹配

## 推荐方案
**方法**: point-gtest-dir-to-package-config

**说明**: generate() 中把 GTest_DIR 设为依赖包自带 GTestConfig.cmake 目录，绕过 CMakeDeps 大小写差异

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan create . -pr:h=ohos-aarch64  → CMake configure 通过并链接 GTest::gtest
```
