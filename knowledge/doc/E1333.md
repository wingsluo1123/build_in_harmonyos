# E1333: 上游测试目录名可能是单数 test/ 且同时含两套测试框架（pytest + lit/filecheck）：source 必须用 GitHub 官方 tag archive（sdist 常不含测试），test_package 内两套都要跑并分别落标记；包外工具（snitch）需随副本提供

## 基本信息
- **严重度**: 2
- **类别**: detection, python, conan, packaging, testing
- **作者**: D3BE

## 错误特征
```
ERROR: file or directory not found: (tests|tests/)|no tests ran in .*s|404.*archive/refs/tags|Passed: 0|Testing: 0 tests
```

## 根因分析
PyPI sdist 与 GitHub tag archive 由不同打包规则产出：poetry 只按 pyproject 收文件，riscemu 2.2.7 的 sdist 完全不含 test/（pytest 用例与 lit/filecheck 用例都只在仓库里）；且上游测试目录名是单数 test/（不是惯例 tests/），并含两套框架——.github/workflows/ci-pytest.yml 同时跑 pytest -W error 与 lit --timeout=5 -v test/filecheck；此外 riscemu 的 pyproject 只打包 riscemu/ 包，snitch/（lit 的 snitch 用例要用 python3 -m snitch）不在 wheel 内，且 lit.cfg 把 cwd 设为 test/filecheck 的上两级以便从源码树 import snitch

## 推荐方案
**方法**: github-tag-archive-pinned-sha-and-run-both-suites

**说明**: conandata.yml 用 https://github.com/<owner>/<repo>/archive/refs/tags/<tag>.tar.gz（tag 名逐字核对，本例 v2.2.7）并固定 sha256；把 test/*.py 逐字节复制到 test_package/tests/ 跑 pytest（与上游同参 -W error），把 test/filecheck/ 逐字节复制到 test_package/filecheck/ 跑 lit（同参 --timeout=5 -v）；lit 需要的包外模块（snitch）随副本放进 test_package 并加进 PYTHONPATH，两套结果聚合进一条 HMBS_UPSTREAM_TEST_RESULT 标记

**修复命令**:
```
python3 -m pytest test_package/tests/ -q --no-header -o addopts= -W error ; lit --timeout=5 -v test_package/filecheck
```

**验证**:
```
tar tzf riscemu-2.2.7-py3-none-any.whl/ sdist 列表 | grep -c '/test/'  # sdist 期望 0；tar tzf v2.2.7.tar.gz | grep -c 'test/'  # tag archive 期望 >0；conan create 日志中 grep HMBS_UPSTREAM_TEST_RESULT  # 期望 pytest 49 + lit 11 全 pass
```
