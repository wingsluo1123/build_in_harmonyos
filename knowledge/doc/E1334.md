# E1334: OHOS sysroot 缺 fts.h/libfts（FTS 目录遍历 API）：递归目录遍历编译失败

## 基本信息
- **严重度**: 2
- **类别**: platform, musl, headers, cplusplus
- **作者**: B3BA
- **来源 PR**: 11976

## 错误特征
```
fatal error: 'fts.h' file not found|fts_open|fts_read
```

## 根因分析
OHOS musl 系 sysroot 无 fts(3) 目录遍历 API 与 libfts；zeek 的 auxil/libunistd 内嵌 fts 是 macOS 专属路径不参与 Linux 构建，无树内兜底。

## 推荐方案
**方法**: replace-fts-with-std-filesystem

**说明**: 用 C++17 std::filesystem::recursive_directory_iterator 重写遍历函数（可移植、无平台宏），#include <fts.h> 同步改 <filesystem>。zeekygen Target.cc 的 dir_contents_recursive 实测。

**修复命令**:
```
make zeekygen（编译通过=验证）
```

**验证**:
```
ls <sysroot>/usr/include/fts.h（不存在=命中）; find <sysroot> -name 'libfts*'（无=命中）
```
