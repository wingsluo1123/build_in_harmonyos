# E1338: 上游测试文件未被任何构建目标接入且缺 include：最小补丁纳入测试目标

## 基本信息
- **严重度**: 1
- **类别**: build-system, cmake, testing
- **作者**: 16F2

## 错误特征
```
variable has incomplete type 'BuildConfig'|unknown type name 'StatusPrinter'|no such test
```

## 根因分析
上游 ninja 1.13.2 的 src/status_test.cc 存在但未被 CMakeLists.txt/configure.py 的任何测试目标接入，且文件本身缺 status_printer.h/build.h include 导致无法编译；按源码测试入口恢复规则以最小补丁将其纳入 ninja_test 目标并补 include 后编译运行通过

## 推荐方案
**方法**: minimal-patch-test-inclusion

**说明**: 核对无上游排除条件后，以最小补丁把枚举到但未实例化的独立测试文件纳入正确测试目标并补齐缺失 include

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
cmake -DBUILD_TESTING=ON; ./ninja_test --gtest_filter=StatusTest.*  → 2 用例通过
```
