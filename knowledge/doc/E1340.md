# E1340: OHOS HMDFS 不支持 mknod/FIFO：上游 FIFO 类测试为平台阻塞

## 基本信息
- **严重度**: 2
- **类别**: platform, hmdfs, filesystem
- **作者**: E86D

## 错误特征
```
Could not create FIFO|mknod.*Operation not permitted|PermissionError.*Operation not permitted
```

## 根因分析
OHOS 可写挂载点全部为 HMDFS（mknod FIFO 返回 EPERM Operation not permitted），/dev/shm 等 tmpfs 亦被权限拒绝（EACCES），/tmp 为只读 erofs；设备上不存在任何可写且支持 POSIX FIFO 的挂载点，依赖 mknod/FIFO 的上游测试（如 ninja Jobserver.PosixFifoClient、make jobserver）为真实平台阻塞

## 推荐方案
**方法**: document-platform-block

**说明**: 逐项验证候选挂载点后如实记录平台阻塞与恢复条件（提供支持 mknod/FIFO 的写入挂载点）

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
python3 -c "import os;os.mkfifo('/storage/Users/currentUser/tmp/x')"  → EPERM
```
