# E1343: make 默认 /bin/sh 下 which 探测失效导致 pkg-config 探测噪声（应显式传 SHELL=bash）

## 基本信息
- **严重度**: 1
- **类别**: platform, ohos, build-system, make
- **作者**: 7643

## 错误特征
```
--libs: No such file or directory|--cflags: No such file or directory
```

## 根因分析
上游模块 Makefile 用 BUILDER=$(shell which pkg-config) 探测 pkg-config；在 OHOS 上 GNU make 默认 shell（toybox /bin/sh）下该探测不稳定，出现 'make[1]: --libs: No such file or directory' 噪声，pkg-config 取到的链接参数不可靠。

## 推荐方案
**方法**: 驱动 make 时显式传 SHELL=<bash 绝对路径>（可用 CONFIG_SHELL 兜底，缺失回退 /bin/sh）；同时用 PKG_CONFIG_PATH 指向 conan PkgConfigDeps 生成的 .pc 目录，使探测确定化。

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
