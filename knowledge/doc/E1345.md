# E1345: 构建参数 CFLAGS_DEFAULT= 与 LDFLAGS_DEFAULT= 置空剥离 LTO 回退值；同时摘除 Ma

## 基本信息
- **严重度**: 2
- **类别**: linking
- **作者**: 131B

## 错误特征
```
ld.lld: cannot find -latomic（LTO 链接期）
```

## 根因分析
dpkg-buildflags 缺失时 config.mk 回退值含 -flto=auto；clang 对 LTO 链接自动追加 -latomic，而 OHOS 工具链不带 libatomic；部分 Makefile 还硬编码 LDLIBS += -latomic（发行版假设）

## 推荐方案
**方法**: 构建参数 CFLAGS_DEFAULT= 与 LDFLAGS_DEFAULT= 置空剥离 LTO 回退值；同时摘除 Makefile 中硬编码的 -latomic；两者缺一不可

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
对照：带 -flto=auto 链接报 ld.lld: cannot find -latomic，CFLAGS_DEFAULT=/LDFLAGS_DEFAULT= 剥离后通过（rtpengine 26.0.1.15 实测）
```
