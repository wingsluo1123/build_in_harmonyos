# E1347: PkgConfigDeps 生成的 glib-2.0.pc 缺 -lintl 致 g_libintl_* 链接错误（--no-undefined）

## 基本信息
- **严重度**: 2
- **类别**: linking
- **作者**: 034A

## 错误特征
```
undefined reference to .g_libintl|g_libintl_dngettext|--no-undefined|glib-2.0.pc
```

## 根因分析
PkgConfigDeps 生成的 glib-2.0.pc Libs 仅 -lglib-2.0 缺 -lintl。新版源码直调 g_libintl_dngettext（如 libadwaita 1.8.x 的 adw-main.c/adw-tab-overview.c）+ meson 库链接 --no-undefined 时必炸；旧版本无此直调则幸免（1.2.0 过、1.8.8 炸）。glib/2.84.0.1.1 包自带 libintl.so.8（12 个 T g_libintl_* 定义），补 -lintl 指向同包即自洽

## 推荐方案
**方法**: 主配方 generate() 在 PkgConfigDeps 之后强制回写 6 个 glib 系 .pc：prefix 统一指向 self.dependencies["glib"].package_folder + glib-2.0.pc 的 Libs 追加 -lintl（参考 libadwaita/1.8.8 conanfile.py _normalize_glib_pc）。先 nm -D glib 包内 libintl.so.8 确认 T 定义存在

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
