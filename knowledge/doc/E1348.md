# E1348: static libmagic finds no magic.mgc on OHOS without MAGIC env

## 基本信息
- **严重度**: 2
- **类别**: ohos, runtime, libmagic
- **作者**: F387

## 错误特征
```
Failed to load the file magic database|could not find any valid magic files
```

## 根因分析
libmagic built static keeps its compiled database at <pkg>/share/misc/magic.mgc but default search dirs (/usr/share/misc, /etc) do not exist on OHOS musl, so magic_load(NULL) fails and every omindex MIME probe throws

## 推荐方案
**方法**: export MAGIC=<libmagic package_folder>/share/misc/magic.mgc via recipe Environment(scope=build) before make/make check; document for runtime deployment; reference archives/o/omega/2.0.0/conanfile.py generate()

**说明**: 注入 MAGIC 环境变量指向包内 magic.mgc

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
MAGIC=$LIBMAGIC/share/misc/magic.mgc ./omindextest
```
