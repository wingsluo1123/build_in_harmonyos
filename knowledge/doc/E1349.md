# E1349: 上游站点停服(OSDN)后的源码权威获取：FreeBSD distcache

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, network
- **作者**: F318

## 错误特征
```
Could not resolve host: (ja\.)?osdn\.net|Connection timed out.*distcache
```

## 根因分析
上游原站 OSDN（SourceForge.JP 后继）已停服，ja.osdn.net / osdn.net 域名 DNS 不再解析；tarball 仅存量于 FreeBSD 官方 distcache 与少数发行版缓存

## 推荐方案
**方法**: 用 distcache.{,eu,us-east,us-west}.FreeBSD.org/ports-distfiles/<file> 取原始 tarball，并与 FreeBSD ports distinfo 的 sha256 + SIZE 交叉校验；主站 distcache.FreeBSD.org 走 Fastly，受限网络可能超时，区域站点需放宽证书校验（*.freebsd.org 不覆盖二级子域）

**说明**: 把 FreeBSD 官方 distcache 作为 OSDN 停服后的权威源码镜像，双元数据（sha256+SIZE）校验确认上游原件

**修复命令**:
```
curl -sSLk -o <name>-<ver>.tar.gz https://distcache.us-east.FreeBSD.org/ports-distfiles/<name>-<ver>.tar.gz && sha256sum <name>-<ver>.tar.gz
```

**验证**:
```
curl -sS -o /dev/null -w '%{http_code}' https://distcache.us-east.FreeBSD.org/ports-distfiles/<file>.tar.gz
```
