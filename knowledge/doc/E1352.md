# E1352: exclude-tests-via-variable-override

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, libc, testing, gap
- **作者**: CEC1

## 错误特征
```
mq_open: Function not implemented|mq_send.*errno=38|POSIX mqueue.*not supported|mq_timedreceive.*ENOSYS|librt.*mq|cannot test mqueue|case-10-mqueue|case-20-mqueue
```

## 根因分析
OHOS libc 的 librt 为空壳（约 8 字节），未实现 POSIX mqueue（mq_open/mq_send/mq_receive 等返回 ENOSYS 或链接期即不可用）。上游依赖 POSIX mqueue 的测试用例（如 lsof case-10-mqueue/case-20-mqueue/mq_fork/mq_open）在 OHOS 上不可运行，须从 TESTS/check_PROGRAMS 配置层排除，属平台能力缺口而非移植缺陷。

## 推荐方案
**方法**: exclude-tests-via-variable-override

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
