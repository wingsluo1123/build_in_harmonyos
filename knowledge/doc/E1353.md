# E1353: application 包 test_package 臆测 stdin 管道用法导致 create 必炸

## 基本信息
- **严重度**: 2
- **类别**: conan, testing
- **作者**: C82D

## 错误特征
```
application package test_package 用 echo|binary - 冒烟: 'main() is not defined' / 程序立即失败退出 1, conan create test 阶段炸
```

## 根因分析
为 application 型包写 test_package 时臆测二进制存在 stdin 管道用法，未读上游 main/usage。很多 CLI 的 '-' 只是参数分隔符（如 picoc 仅有 文件模式/-s 脚本/-i 交互 三种用法），管道输入被忽略导致必然失败；连续改 test_package 会形成调参螺旋（picoc 任务实测 6 个重复 fix 提交）。

## 推荐方案
**方法**: 先读上游入口 usage 再定测试命令；提交真实输入文件(smoke.c)到 test_package/（满足 L0e），test() 用 'bin input | grep -q 断言串'；OHPCD conan 2.29.1 fork 的 ConanFile.run 无 output/capture_output 关键字。

**说明**: 读上游 usage，提交真实输入文件并用管道 grep -q 断言执行包内二进制

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
grep -n 'Format\|Usage' picoc.c 2>/dev/null | head
```
