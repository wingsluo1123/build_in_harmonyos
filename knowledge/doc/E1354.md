# E1354: OHOS 内核 ppoll() 运行时返回 ENOMEM：需强制 pselect 路径

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, kernel
- **作者**: B8F9

## 错误特征
```
ppoll: Out of memory|ppoll.*ENOMEM|SubprocessTest.*hang
```

## 根因分析
OHOS PC 内核 ppoll() 在运行时返回 ENOMEM（toybox/bionic poll 限制），导致 ninja 子进程调度无限刷 'ppoll: Out of memory'；上游提供 NINJA_FORCE_PSELECT=ON 选项强制使用 pselect() 规避

## 推荐方案
**方法**: force-pselect-build-option

**说明**: 构建时设置 NINJA_FORCE_PSELECT=ON（或等价 pselect 开关）绕过 ppoll ENOMEM

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
cmake -DNINJA_FORCE_PSELECT=ON -DBUILD_TESTING=ON; ./ninja_test 无 ppoll ENOMEM 刷屏
```
