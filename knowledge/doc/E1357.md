# E1357: 共享 conan 缓存陈旧 .so 污染（.so 运行行为偏离源码）

## 基本信息
- **严重度**: 2
- **类别**: build-cache
- **作者**: A027

## 错误特征
```
.so 行为偏离源码|反汇编一致|conan cache 陈旧|同机多会话|conan remove
```

## 根因分析
同机并行任务/多会话共享 ~/.conan2 缓存，旧会话（不同 recipe revision/不同源码）残留同包 build/package 目录，conan 目录名哈希碰撞使陈旧目录被复用——运行加载陈旧 .so，行为偏离当前源码（md5/反汇编与现源码一致但运行实测值对不上）。实测案例：09-14 会话残留 libadwaita/1.8.8 缓存导致 easing 实测值与源码公式不符、崩溃点随 .so 新旧而漂移

## 推荐方案
**方法**: 运行行为偏离源码（源码 md5/反汇编一致但实测值对不上）时，第一嫌疑=缓存陈旧 .so：conan remove "<name>/*" -c 清本包全部旧条目后 clean-room 重建，核验包目录 .so 的 mtime/sha256。多任务并行机器上正式构建前必清本包旧条目。conan 不会重新校验已存在 source 目录的 sha256（只校验下载时刻）

**说明**: 一句话描述这个推荐方案

