# E1358: SCons 工程语言预检误判：识别表无 SCons 信号 + android/java 子树稀释主体统计

## 基本信息
- **严重度**: 1
- **类别**: detection, build-system
- **作者**: 9FF1

## 错误特征
```
detected_language.*(java|mixed)|lang-preflight.*mismatch|主体语言.*(java|mixed)
```

## 根因分析
lang_detect 的构建系统识别表只覆盖 Cargo/pyproject/go/CMake/Meson/QMake 等，SConstruct/SConscript 不在表内 → 退化为全树源码统计；工程常同时带 android/ 或其它语言子树，主体语言被稀释 → detected 落 java/mixed

## 推荐方案
**方法**: source-scope-reextract

**说明**: 用 tar 排除法只重建主体作用域树（排除 android/、ios/、java/ 等非目标平台子树），再对作用域树跑 lang-preflight；主体统计 ≥70% 时按主体语言判（R47 边界规则：manifest 缺失时以构建系统/主体统计为准）

**修复命令**:
```
tar xf <src>.tar.gz -C <dir> --exclude="*/android/*" --exclude="*/ios/*" --exclude="*/java/*" && python3 $SKILL_ROOT/scripts/ohc-run.py lang-preflight <name> <ver> --src <dir>
```

**验证**:
```
python3 $SKILL_ROOT/scripts/ohc-run.py lang-preflight <name> <ver> --src <scope-tree>
```
