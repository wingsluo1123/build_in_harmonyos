# E1362: per-dir-install-and-skip-host-secrets

## 基本信息
- **严重度**: P1
- **类别**: platform, installation
- **作者**: 4405

## 错误特征
```
make\[1\]: \*\*\* \[Makefile:N: install\] Error 69|open\(.*map\): File exists|is not private|顶层 make install 返回 0 但子目录失败
```

## 根因分析
两类安装期陷阱：(1) autotools 顶层 install 目标用 shell for 循环递归子目录，最后一项成功即 rc=0，掩盖前面子目录的真实失败；(2) 程序对输出文件做“私有权限”检查（如 DCC 的 HAVE_PRIVATE_FILES 要求 0600），而 HMDFS/tmpfs 把任何文件权限归一化为 0660 且 chmod 无效 → 检查必然失败

## 推荐方案
**方法**: per-dir-install-and-skip-host-secrets

**说明**: ① 改逐目录安装 make -C <dir> install，让失败显性化（不要整体 make install 只看 rc）；② 包内只交付可重定位产物，跳过主机专属密钥/状态生成（如 DCC 的 /var/dcc/{map,ids}，含随机 secret），改为交付静态原型 + 部署期脚本；③ 判定“权限检查失败”前先实测文件系统：os.open(...,0o600) 后 stat 是否仍为 0600（/dev/shm 保留 0600，HMDFS/存储区归一化为 0660）。

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
逐目录 make -C <dir> install 全部 rc=0（dcc-extras 2.3.169 15 个组件）
```
