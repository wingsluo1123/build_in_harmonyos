# E1364: 本仓 OHOS 适配版 conan 的 self.run(env=) 语义是环境文件名而非环境变量表

## 基本信息
- **严重度**: P1
- **类别**: conan, api
- **作者**: 3CE2

## 错误特征
```
env argument to ConanFile.run() should be a list
```

## 根因分析
该 conan 的 ConanFile.run(env=...) 形参语义是“环境文件名字符串列表”（默认 conanbuild/conanrun），不是 Conan 2 官方文档中的环境变量表。传 dict 触发 assert 报 should be a list；传 [(k, v)] 则在解析成路径时报 expected str/bytes/os.PathLike, not tuple。

## 推荐方案
**方法**: 不要用 self.run(env=) 传自定义环境变量；改用 GnuToolchain(self).extra_env.define(K, V) + tc.generate()。

**说明**: 自定义环境变量走 toolchain 的 extra_env，而不是 self.run 的 env 形参。

**修复命令**:
```
tc = GnuToolchain(self) ; tc.extra_env.define("BRANCH", "master") ; tc.generate() ; self.run('make release CC="<cc>" -j1', cwd=self.source_folder)
```

**验证**:
```
conan create 通过且生成的 conangnutoolchain.sh 含目标 export；由 rtl-wmbus/1.1.0 实测。
```
