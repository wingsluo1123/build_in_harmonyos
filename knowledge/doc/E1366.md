# E1366: 32-bit float WAV 头解析要求：wFormatTag 必须为 3 (IEEE_FLOAT) 且 BlockAlign=channels*4

## 基本信息
- **严重度**: 1
- **类别**: portability, testing, audio
- **作者**: 068A

## 错误特征
```
unsupported .WAV format|is an unsupported .WAV format
```

## 根因分析
音频工具链（如 ART）对 32-bit float WAV 要求 wFormatTag=3 (WAVE_FORMAT_IEEE_FLOAT) 且 BlockAlign=NumChannels*(bits/8)；用格式码 1 (PCM) + 32bit 或错误的 BlockAlign 写头会被判 unsupported .WAV format。合成测试 WAV 时头字段必须正确

## 推荐方案
**方法**: correct-wav-float-header

**说明**: 生成测试 WAV 时：32-bit float 用 wFormatTag=3、nBlockAlign=channels*4、nAvgBytesPerSec=sr*blockalign；整数 PCM 限 4-24 bit

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
python3 生成 wFormatTag=3 BlockAlign=8 的立体声 WAV 后运行工具重采样 exit 0
```
