# E1367: GLES geometry-shader fragment depth: preserve requested 32-bit precision with D32F

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, runtime
- **作者**: VTK9

## 错误特征
```
format=81a[56] mode=fragment .*match=0
```

## 根因分析
On the measured Maleoon 916 B301 driver, a geometry stage followed by explicit gl_FragDepth produces low-24-bit float encodings in D16/D24 attachments; matching D32F attachments preserve the values. This is a measured driver-specific behavior, not a GLES-wide claim.

## 推荐方案
**方法**: preserve-requested-32-bit-depth-with-d32f

**说明**: When the API requests 32-bit depth and fixed 32-bit depth is absent, use supported GL_DEPTH_COMPONENT32F with GL_FLOAT consistently for renderbuffers, textures and copy/resolve targets. Verify actual depth values and multisample/viewport behavior.
