# E1368: conan perl 包空前缀安装导致 @INC 指向 //lib/perl5，Perl 脚本找不到核心模块

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system
- **作者**: P9T4

## 错误特征
```
Can.t locate (strict|warnings)\.pm in @INC|@INC entries checked: //lib/perl5|//lib/perl5/site_perl
```

## 根因分析
conan perl 包以空前缀打包，perl 内建 @INC 为 //lib/perl5/...，依赖 strict/warnings 等核心模块的 Perl 脚本失败

## 推荐方案
**方法**: env-variable

**说明**: 在构建命令前置 PERL5LIB=<perl 包>/lib/perl5

**修复命令**:
```
PERL5LIB="$PERL_PKG/lib/perl5" make PERL="$PERL_PKG/bin/perl" ...
```

**验证**:
```
PERL_PKG=$(conan cache path perl/5.42.2.3:<pkgid>); "$PERL_PKG/bin/perl" -e 'use strict'; PERL5LIB="$PERL_PKG/lib/perl5" "$PERL_PKG/bin/perl" -e 'use strict'
```
