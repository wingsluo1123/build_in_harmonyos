# E1369: Dispatch on actual payload, not a fixed outer tuple, before MusicXML export

## 基本信息
- **严重度**: 2
- **类别**: compat, python, runtime
- **作者**: orrkri

## 错误特征
```
TypeError: 'int' object is not subscriptable
```

## 根因分析
Every normal note is carried by a fixed outer tuple; checking that outer tuple prevents numeric payload normalization. Dispatch on extra instead, preserving -1 rest and letter pitch spelling.

## 推荐方案
**方法**: dispatch-on-payload-before-export

**说明**: Replace isinstance(ply, tuple) by isinstance(extra, tuple); preserve the rest sentinel and original letter tuples; compare semantically equivalent numeric and letter notes.

**修复命令**:
```
python3.12 -B -m unittest discover -v
```

**验证**:
```
python3.12 -B -m unittest discover -v
```
