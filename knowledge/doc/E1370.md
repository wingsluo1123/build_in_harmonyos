# E1370: ohpcd libtool 制品把独立 libltdl 发行版装在 share/libtool/，libtoolize --ltdl 复制失败导致 autoreconf 终止

## 基本信息
- **严重度**: 2
- **类别**: autotools, conan, packaging
- **作者**: LPR5

## 错误特征
```
libtoolize:\s+error: '.*share/libtool-conan/libltdl/.*' not found|autoreconf: error: .*libtoolize failed with exit status: 1
```

## 根因分析
libtool/2.5.4 制品的 package() 把上游独立 libltdl 发行版（含 pregenerated configure、ltdl.c、loaders/、Makefile.in）装到 share/libtool/，而 libtoolize 查找 ltdl 的路径是 <pkgdatadir>/libltdl（该包里是 share/libtool-conan/libltdl，只剩头文件）→ LT_CONFIG_LTDL_DIR 声明的项目（libprelude、Gnumeric 等）无法用 libtoolize --ltdl 自举

## 推荐方案
**方法**: materialize-libltdl-from-libtool-package

**说明**: 不跑 autoreconf；在 conanfile.build() 里依次执行 libtoolize -c --force --automake（忽略其 ltdl 复制失败）→ 从 tool_requires 的 libtool 包把 share/libtool 复制成源码树的 libltdl/ → 清掉 libltdl/Makefile.in 里未被替换的 @MAINTAINER_MODE_TRUE@ 字面量 → 手工跑 aclocal/autoconf/autoheader/automake 完成自举

**修复命令**:
```
self.run('"$LIBTOOLIZE" -c --force --automake', ignore_errors=True); shutil.copytree(<libtool>/share/libtool, <src>/libltdl)
```

**验证**:
```
ls <libtool 包>/share/libtool/configure && (libtoolize -c --force --ltdl --automake; echo $?)
```
