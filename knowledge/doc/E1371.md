## 推荐方案
**方法**: inject-dep-libdirs-ld-library-path

**说明**: conanfile.py generate() 中用 conan.tools.env.Environment 把全部 host 依赖的

**修复命令**:
```
conanfile.py::generate(): env = Environment(); for dep in self.dependencies.values(): for libdir in dep.cpp_info.libdirs: env.append_path("LD_LIBRARY_PATH", libdir); env.vars(self).save_script("conanbuildenv-<pkg>-runtime")
```
