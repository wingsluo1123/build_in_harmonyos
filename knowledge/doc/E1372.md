# E1372: OHOS 受限 /dev/bus 下 libusb_init() 失败 + 未检查返回值 → NULL context SIGSEGV

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, limitation, ohos, portability
- **作者**: FBD7

## 错误特征
```
Can't initialize libusb|libusb_init.*r=-1|sysfs_get_device_list.*errno=13|libusb_get_device_list.*NULL
```

## 根因分析
libusb_init() 在 OHOS 受限环境（无 /dev/bus/usb 访问权限；sysfs_get_device_list opendir /sys/bus/usb/devices 返回 EACCES/13）下返回 -1，ctx 保持 NULL。调用方若忽略返回值并把 NULL 传给 libusb_get_device_list()，会解引用 libusb 默认 context 而 SIGSEGV(139)。

## 推荐方案
**方法**: check-libusb-init-return

**说明**: 调用 libusb_init() 后必须检查返回值；非 0 时打印可读错误并退出，禁止把可能为 NULL 的 context 继续传给 libusb_get_device_list()。

**修复命令**:
```
if(libusb_init(&context) != 0) { printf("ERROR: Can't initialize libusb\r\n"); return -1; }
```

**验证**:
```
LIBUSB_DEBUG=4 ./tool  # 观察 libusb_init r=-1；./tool <subcmd>; echo $?  # 修复前 139，修复后 255
```
