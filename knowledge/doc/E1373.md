# E1373: OHOS SDK 缺 llvm-ranlib：纯 CMake 项目显式指定 CMAKE_RANLIB 引用 hnp/bin 预置 softlink

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, toolchain, archive
- **作者**: F1A6, OpenDesk

## 错误特征
```
Error running link command: no such file or directory
```

## 根因分析
OHOS SDK native/llvm/bin 缺 llvm-ranlib，CMake 推断 RANLIB 为不存在路径；/data/service/hnp/bin/llvm-ranlib 是 SDK 预置 multi-call softlink 可直接引用

## 推荐方案
**方法**: cmake-configure-explicit-ranlib

**说明**: CMake 配置时显式指定 CMAKE_AR/CMAKE_RANLIB 指向 /data/service/hnp/bin 下 SDK 预置的 llvm multi-call softlink，无需 wrapper 或 overlay

**修复命令**:
```
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=<ohos.toolchain.cmake> -DCMAKE_AR=/data/service/hnp/bin/llvm-ar -DCMAKE_RANLIB=/data/service/hnp/bin/llvm-ranlib
```

**验证**:
```
test ! -x /data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/bin/llvm-ranlib; test -x /data/service/hnp/bin/llvm-ranlib; cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=ohos.toolchain.cmake -DCMAKE_AR=/data/service/hnp/bin/llvm-ar -DCMAKE_RANLIB=/data/service/hnp/bin/llvm-ranlib && cmake --build build
```
