# E1377: 单头文件 C 库在 aarch64/OHOS 上三处可移植性缺陷：x86 SIMD 头无条件包含、stdio.h 条件包含位置、heap allocator 误用 posix_memalign

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, memory, aarch64, single-header
- **作者**: EE6C

## 错误特征
```
emmintrin.h.*only meant to be used on x86|FILE.*undeclared identifier|posix_memalign.*EINVAL
```

## 根因分析
zpl 9.8.0 上游三处平台分支缺陷：(1) 非 Android/iOS/Emscripten 分支无条件包含 x86 专用 <emmintrin.h>，aarch64 编译失败；(2) <stdio.h> 仅出现在 Windows/OSX/与 ZPL_THREADING affinity 段，而 ZPL_THREADING 在 ARM 上被禁用，导致 FILE/tmpfile 未声明；(3) heap allocator 对 x86 Linux 用 aligned_alloc、ARM Linux 误用 posix_memalign，posix_memalign 对入参对齐 4（base64 解码路径）返回 EINVAL。

## 推荐方案
**方法**: (1) SIMD 头以 ZPL_CPU_X86 守卫，否则包含 <sched.h>；(2) 主头非 Windows 分支无条件包含 <stdio.h>；(3) ARM Linux 与 x86 一致使用 aligned_alloc
