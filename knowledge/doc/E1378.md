# E1378: 上游 third_party 子模块（capnproto/googletest）以 host 选项+制品仓 tool_requires 替代，工具可执行路径须消费方显式注入

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, cmake
- **作者**: E718

## 错误特征
```
CAPNP_EXECUTABLE.*(empty|not set|undefined)|capnpc-c\+\+.*(No such file or directory|command not found)
```

## 根因分析
UHDM UHDM_USE_HOST_CAPNP=ON 分支仅 find_package(CapnProto) 不设 CAPNP_EXECUTABLE/CAPNPC_CXX_EXECUTABLE（子项目分支才 FORCE 设置）；third_party/capnproto 子模块钉 1.1-dev，源码直编需 CMAKE_CXX_EXTENSIONS ON 修复（见 knowledge/drafts/E543-draft-66FA.kv）

## 推荐方案
**方法**: host 选项跳过上游子模块（UHDM_USE_HOST_CAPNP=ON、UHDM_BUILD_TESTS=OFF）；tool_requires capnproto/1.3.0（制品仓 static+fPIC 现成二进制，免源码编译）；generate() 用 tc.cache_variables 注入 capnproto 包 bin/capnp 与 bin/capnpc-c++ 绝对路径（参考 archives/u/uhdm/1.86/conanfile.py）

**说明**: host 选项 + tool_requires + cache_variables 注入工具路径；capnproto 1.3.0 制品仓二进制绕开 E543 家族 CXX_EXTENSIONS 坑

```
可选: 具体命令模板(${VAR}变量引用)
```
