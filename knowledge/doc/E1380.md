# E1380: patch-less Conan recipe must still declare export_sources()/apply_conandata_patches to pass conan-verify G1

## 基本信息
- **严重度**: 2
- **类别**: conan, recipe-structure
- **作者**: E4BC

## 错误特征
```
G1 Recipe completeness.*FAIL|missing export_sources|missing apply_conandata_patches|配方完整性
```

## 根因分析
conan-verify G1 静态检查按字面量要求 conanfile.py 同时含 export_sources() 方法与 apply_conandata_patches 调用。无补丁的包不写这两项脚手架（或用 exports_sources 属性）会被判 FAIL，导致 finish 步骤降级并阻塞 submit。Conan 2 这两个 API 在 conandata.yml 无 patches 键时均为 no-op，可安全保留。

## 推荐方案
**方法**: 在 conanfile.py 中补 from conan.tools.files import apply_conandata_patches, export_conandata_patches；定义 def export_sources(self): export_conandata_patches(self)；在 build() 首行调用 apply_conandata_patches(self)；conandata.yml 显式声明 patches: []

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
