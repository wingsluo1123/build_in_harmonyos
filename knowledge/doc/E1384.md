# E1384: CMake 构建期 python 代码生成依赖 pip 包：--no-deps 钉版装 build_folder 私有前缀 + PYTHONPATH 注入（R49/E524）

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, build-system
- **作者**: DCA9

## 错误特征
```
orderedmultidict.*not installed|ModuleNotFoundError.*orderedmultidict|pip.*orderedmultidict
```

## 根因分析
CI clean 环境无 site-packages，UHDM generate.py（模型代码生成）依赖 pip orderedmultidict；注入共享 /usr/local 会污染共享文件系统的 CI worker（E524 根因，asterisk-srtp 19 轮 CI 教训）

## 推荐方案
**方法**: build() 内 python3 -m pip install --no-deps --target <build_folder>/pydeps orderedmultidict==1.0.2 six==1.17.0（社区源 pypi.cnb.cool 由 setup.sh 预配置；先例 adb-enhanced/2.8.0）；generate() VirtualBuildEnv.define PYTHONPATH；TMPDIR 指向 build_folder/tmp（E002/E544-E3AD，见 knowledge/drafts/E544-draft-E3AD.kv）

**说明**: pip 构建期依赖私有前缀注入范式；--no-deps + 精确钉版保证可复现（参考 archives/u/uhdm/1.86/conanfile.py）

```
可选: 具体命令模板(${VAR}变量引用)
```
