# E1385: 对 GBoxed 调用 g_object_unref 导致 SIGSEGV（类型混淆误判为 gobject 损坏）

## 基本信息
- **严重度**: 2
- **类别**: runtime
- **作者**: D78A

## 错误特征
```
SIGSEGV|g_object_run_dispose|fault @0x|GBoxed
```

## 根因分析
AdwSpringParams 是 GBoxed（G_DEFINE_BOXED_TYPE+gatomicrefcount），测试代码用 g_object_unref() 释放=UB：GObject 内部把 boxed 内存当 GObject 结构解释，mass 字段（double，offset 16）位模式被当弱引用链指针解引用（fault@0x1，g_object_run_dispose 内）。真 GObject 对照组（G_TYPE_OBJECT/自定义类型创建+unref）全部正常，库与平台均无问题，根因在测试侧 API 误用

## 推荐方案
**方法**: 释放前先查头文件类型宏：G_DEFINE_BOXED_TYPE→用 boxed 专用 unref（如 adw_spring_params_unref）；G_DEFINE_TYPE→用 g_object_unref。SIGSEGV 落在 g_object_run_dispose 时勿先假设 gobject 库损坏——先用最小 GObject 对照组分离平台问题 vs 对象类型误用
