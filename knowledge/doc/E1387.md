# E1387: kamailio（经典 Makefile）OHOS 交叉编译：OS=harmonyos 未被 Makefile.defs 识别 + 依赖探测回退 LOCALBASE + core 锁机制与 musl _res 缺失

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, build-system
- **作者**: D35C
- **来源 PR**: 12739

## 错误特征
```
No rule to make target .cfg-defs.|cfg-defs|HAVE_GETHOSTBYNAME2|HAVE_SCHED_YIELD|no way to determine|no locking method selected|undeclared identifier '_res'
```

## 根因分析
kamailio Makefile.defs 只识别 linux/solaris/freebsd/darwin 四分支，OS=harmonyos 落无名分支导致 HAVE_* 平台宏全缺，core 头 resolve.h/sched_yield.h 直接 #error；且未先 make cfg 时无 cfg-defs 规则；模块 Makefile 依赖探测在 CROSS_COMPILE 为空时走 pkg-config，未命中才回退 LOCALBASE

## 推荐方案
**方法**: build-cli-macro-inject

**说明**: 不改源码：先 make cfg，再用 make 命令行 extra_defs 注入 linux 分支等价平台宏集，并用 BUILDER=/SSL_BUILDER= 等空赋值钉死 LOCALBASE 回退分支（make 命令行变量优先于 Makefile 内部赋值）

**修复命令**:
```
make cfg include_modules=${MOD} LOCALBASE=${DEP_PKG} BUILDER= extra_defs='-D_GNU_SOURCE -DHAVE_GETHOSTBYNAME2 -DHAVE_SCHED_YIELD -DHAVE_MSG_NOSIGNAL -DHAVE_MSGHDR_MSG_CONTROL -DHAVE_ALLOCA_H -DHAVE_TIMEGM -DHAVE_SCHED_SETSCHEDULER -DHAVE_IP_MREQN' && make modules modules=modules/${MOD} -j1 LOCALBASE=${DEP_PKG} BUILDER=
```

**验证**:
```
make cfg include_modules=<mod> LOCALBASE=<dep pkg folder> BUILDER= extra_defs=... && make modules modules=modules/<mod>
```
