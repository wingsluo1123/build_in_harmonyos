# E1390: Python -m runner 的 CWD 导入不会传给 script-mode 子解释器：用安装来源与继承环境双向验证防止源码假通过

## 基本信息
- **严重度**: 2
- **类别**: python, packaging, testing, shell
- **作者**: D041

## 错误特征
```
ModuleNotFoundError: No module named 'dill'|Parent CWD import succeeds but script-mode child import fails
```

## 根因分析
The parent python -m runner locates its package through current-directory sys.path[0]; subprocess Python script invocations instead set sys.path[0] to their test-script directory. sys.path mutations are process-local. The dependency is the package under test itself, so installing unrelated dependencies is wrong. Adding source PYTHONPATH fixes execution but does not prove the installed artifact; use a private setuptools installation and an independent working directory with inherited installed-root PYTHONPATH and origin assertions.

## 推荐方案
**方法**: installed-origin-plus-child-environment-proof

**说明**: Diagnose parent and child import paths before adding dependencies; install via published build tools into build-private site; inherit that site through PYTHONPATH; run unchanged upstream scripts from an empty verification directory; assert module origin and execute a fresh-interpreter consumer; perform a reversible payload removal negative control. Count runner scripts separately from conditional optional branches.

**修复命令**:
```
Environment().prepend_path("PYTHONPATH", installed_site); python -s -P -m dill.tests from verification directory (-P on Python >=3.11 only)
```

**验证**:
```
Run original python -m dill.tests with PYTHONPATH unset, then with source root inherited; run staged installed suite from a separate directory; remove installed payload and verify consumers fail, restore and rerun.
```
