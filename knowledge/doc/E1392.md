# E1392: Debian 包（尤其是 native 脚本包）里常有**带 `@VAR@` 占位符的模板脚本**（本例 `mkinitramfs` 的 `@VERSION@`/`@BUSYBOX_PACKAGES@`）：Debian 的 `override_dh_install` 是用 sed 替换后才安装的，若不照做（直接原样 `cp` 进产物）会把占位符带进包；**修法 = 照抄 Debian 的替换 + 在消费者校验里断言"占位符已消失且含版本号"**

## 基本信息
- **严重度**: 3
- **类别**: packaging, debian, template
- **作者**: CB0D

## 错误特征
```
@VERSION@|@BUSYBOX_PACKAGES@|占位符残留|模板化脚本|override_dh_install|sed -e 's,@X@,
```

## 根因分析
这类工程的源码里保留的是"模板"，值在打包期由 dh 的目标注入（版本号来自 changelog/pkg-info， 依赖包名来自 rules 里的变量）。不跑 dh 的适配（OHOS 无 dh/debhelper）如果只是把文件 cp 进产物， 就漏掉了这一步——产物里的脚本会带着 `@VERSION@` 去执行，行为不可预期（且极难从"能装能跑"看出来）。

## 推荐方案
**方法**: replicate-the-distro-substitution-and-assert-it

**说明**: ①在源码里 `grep -rn '@[A-Za-z_]*@'` 找出模板化文件（本例 `mkinitramfs`）；②去 Debian 打包侧看替换规则（`debian/rules` 的 `override_dh_install`，本例是 `sed -e 's,@BUSYBOX_PACKAGES@,…,' -e 's,@VERSION@,<pkg-info version>,'`）；③在 `package()` 里读模板 → 替换 → 写产物（保留可执行位），并对"关键占位符"加断言（若模板里找不到占位符就报错，避免上游改版后静默失效）；④在 test_package 里**断言无残留 + 含正确版本号**——这一步最能防回归；⑤把替换规则与来源（哪个 debian/rules 目标）写进 notes/PR。

**修复命令**:
```
grep -rn '@[A-Za-z_]*@' <src> ; sed -e 's,@VERSION@,<version>,g' -e 's,@BUSYBOX_PACKAGES@,<pkgs>,g' mkinitramfs > <pkg>/sbin/mkinitramfs ; grep -q '@' <pkg>/sbin/mkinitramfs && echo LEFTOVER
```

**验证**:
```
`grep -rn '@[A-Z_]*@' <package_folder>`（应为空）；或对具体脚本 `grep -q '@VERSION@' <pkg>/sbin/mkinitramfs`（应无命中）且 `grep -q '<版本号>' <pkg>/sbin/mkinitramfs`（应有命中）
```
