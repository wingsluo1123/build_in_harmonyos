# E1397: java-consumer-e2e-needs-container-free-entrypoint

## 基本信息
- **严重度**: 2
- **类别**: java, testing, quality
- **作者**: BD24

## 错误特征
```
NoClassDefFoundError|ClassNotFoundException|unexpected: .*|AssertionError
```

## 根因分析
只做 Class.forName/反射加载只能证明类文件在包里，无法暴露依赖链与 classpath 缺陷；而库的核心功能往往需要容器（servlet/JSP）才能调用。若不挑一个不依赖容器的真实入口（静态工具类/纯函数）调用并断言返回值，消费者校验会绿得很虚。

## 推荐方案
**方法**: pick-container-free-static-entrypoint-for-e2e

**说明**: ①在库内找无容器依赖的真实入口（静态工具类/纯函数）；②classpath 覆盖包内全部 jar + 必需容器 API；③断言真实返回值而非类可加载；④保留证据（rc、stdout、classpath）。判据：把断言写错时校验必须变红。

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
javac -cp <pkg jars>:<必需容器API> -d out Consumer.java && java -cp <同上>:out Consumer   # 断言 Functions.toUpperCase("atom") == "ATOM"
```
