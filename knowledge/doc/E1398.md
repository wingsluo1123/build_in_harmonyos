# E1398: 依赖包自带 .pc 漏声明 system_libs：静态 C++ 依赖链入共享对象时 C++ 运行时未解析（链接 rc=0 静默隐患）

## 基本信息
- **严重度**: 2
- **类别**: linking, conan, cxx
- **作者**: B596

## 错误特征
```
__gxx_personality_v0|_ZSt9terminatev|__cxa_begin_catch|symbol not found
```

## 根因分析
libmemcached/1.0.18 是静态 C++ 实现，conanfile 声明 system_libs=[m,c++]，但包内自带 .pc 的 Libs 只有 -lmemcached -lmemcachedutil；消费方用 pkg-config 取链接参数时不会带入 -lc++。共享对象链接允许未定义符号，rc=0，产物却残留 __gxx_personality_v0/_ZSt9terminatev/__cxa_begin_catch，dlopen 时报 symbol not found。

## 推荐方案
**方法**: 不要使用依赖包内自带的 .pc 取链接参数；改用 conan PkgConfigDeps 生成的 .pc（自动带上 package_info 声明的 system_libs）。验证：llvm-nm -u <产物> 无 C++ 运行时残留；llvm-readelf -d 确认 DT_NEEDED 含 libc++_shared.so。

**说明**: 一句话描述这个推荐方案
