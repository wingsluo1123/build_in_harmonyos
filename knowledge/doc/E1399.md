# E1399: Imakefile/xmkmf 项目在无 imake 工具链环境下绕过 xmkmf 直接 clang++ 编译

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, toolchain
- **作者**: B560

## 错误特征
```
xmkmf: (command )?not found|imake: (command )?not found|Imake\.tmpl.*not found|Makefile generated by imake|ComplexProgramTarget.*imake
```

## 根因分析
上游用 X11R6 时代的 Imakefile + xmkmf（imake）生成 Makefile 的构建体系，

## 推荐方案
**方法**: bypass-xmkmf-direct-compile

**说明**: 不依赖 imake/xmkmf 生成 Makefile，在 conanfile.py build() 中直接调用

**修复命令**:
```
clang++ -O2 -fPIC -std=c++17 ${incs} wmsmixer.cc -o wmsmixer \
```

**验证**:
```
which xmkmf imake; echo $?  # 非 0 即确认工具链缺失；
```
