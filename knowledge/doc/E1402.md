# E1402: 纯脚本/补全脚本包被 conan-init 误判为 autotools，且 G1 强制要求 export_sources/apply_conandata_patches 字面项

## 基本信息
- **严重度**: 2
- **类别**: build-system, conan, script
- **作者**: AEA2

## 错误特征
```
缺少: export_sources\(\) 方法|缺少: 补丁应用调用|G1: FAIL|No rule to make target 'check'
```

## 根因分析
构建系统探测见顶层 Makefile 即判 autotools，脚本包的 Makefile 只有 install 目标无编译规则；G1 用字符串字面量 export_sources/apply_conandata_patches 判完整性，patches 为空时同样必须出现；test_package 默认 C 模板（test.c+CMakeLists）对无符号脚本包不可链接

## 推荐方案
**方法**: 改用 templates/conanfile-headeronly.py.tmpl 变体 C：删 Autotools/generate 与 shared option，build() 仅核验脚本存在与非空但保留 apply_conandata_patches(self)，def export_sources() 调 export_conandata_patches(self)，package() copy 到 share/bash-completion/completions/，package_info() libs/bindirs/libdirs/includedirs 置空 + resdirs=[share]，package_id() self.info.clear()；test_package 用 .sh 断言 + self.run(bash …)

**说明**: 把 conan-init 生成的 autotools 骨架改写为「无编译脚本包」形态：只装不编、安装落包内 share/、test_package 用 shell 断言真实 source 被测脚本

**修复命令**:
```
python3 scripts/ohc-run.py conan-init <软件> <版本>   # 之后按变体 C 手工改写 conanfile.py 与 test_package/
```

**验证**:
```
python3 scripts/ohc-run.py conan-verify <软件> <版本> 2>&1 | grep -E "G1: (PASS|FAIL)|缺少: export_sources|补丁应用调用"
```
