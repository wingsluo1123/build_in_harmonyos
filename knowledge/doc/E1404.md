# E1404: clibs 单文件 C99 库（Makefile 无 configure 无 make install 仅 make test）的自定义 Conan 配方：直接 CC 编译 bytes.c + llvm-ar 归档 libbytes.a + 手动安装头文件/静态库

## 基本信息
- **严重度**: 2
- **类别**: build-system, make, packaging, custom-recipe
- **作者**: ADA1

## 错误特征
```
No rule to make target.*install|make:.*No such file or directory|make install:.*No rule|asprintf.*implicit-function-declaration
```

## 根因分析
clibs 风格单文件 C99 库的 Makefile 只提供 test 目标（编译运行断言式测试），无 configure、无 make install、无库目标；通用 Autotools/CMake 模板配方无法直接使用

## 推荐方案
**方法**: custom-conanfile-single-file-lib

**说明**: 自定义 Conan 配方：CC 直接编译 bytes.c 并用 llvm-ar/ranlib 归档 libbytes.a，package() 手动安装头文件与静态库

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
make test && conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing && ctest 在 test_package build 目录执行
```
