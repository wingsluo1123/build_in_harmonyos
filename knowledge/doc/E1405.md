# E1405: conan-download-readtimeout-use-curl-with-own-sha256

## 基本信息
- **严重度**: 2
- **类别**: conan, environment, tooling
- **作者**: ACE5

## 错误特征
```
ReadTimeoutError|Max retries exceeded|SSL.*error|error 35|Error downloading file
```

## 根因分析
本环境 Conan 的 `download()` 对 Maven Central（repo1/repo.maven.apache.org）的若干 jar **反复 ReadTimeout**（最长重试也失败），而用 `curl` 请求同一 URL 正常返回 → 说明不是文件/镜像问题，而是客户端链路问题；若把编译期依赖都交给 download()，构建会被网络随机卡死。

## 推荐方案
**方法**: fetch-with-curl-and-verify-own-sha256-plus-optional-local-seed

**说明**: ①用 `curl -fsSL --retry 3 --retry-delay 2` 抓取，落盘后**自算 sha256 与钉值比对**（不匹配即失败，不静默降级）②支持可选的本地预置目录（环境变量指向，sha256 一致才采用），便于离线/网络不稳时复现；CI 不设该变量时走网络、行为一致 ③把该现象与口径写进 notes。

```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
curl -sI --max-time 20 <url>   # 与配方内 download() 的表现对照；抓取后自算 sha256 与钉值比对
```
