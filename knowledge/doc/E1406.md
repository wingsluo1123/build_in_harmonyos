# E1406: KF5 依赖链 Qt5 基线分裂触发 Version conflict，且 cmake_find_mode=none 依赖的 config 目录必须手动注入

## 基本信息
- **严重度**: 2
- **类别**: ohos, dependency, version, qt
- **作者**: AC34

## 错误特征
```
Version conflict: Conflict between qt5-qtbase|Could not find a package configuration file provided by "KF5
```

## 根因分析
制品仓中同一条 KF5 5.116.0 依赖链的包分裂在两个 Qt5 基线上——kcoreaddons5/5.116.0（及 kglobalaccel5、attica-kf5）精确 pin 无 Widgets 的桩 qt5-qtbase/5.15.2，而所有含 Widgets 的 KF5 包（kwidgetsaddons5、kitemviews5…）用 qt5-qtbase/5.15.2.2；同时这些 KF5 包把 cpp_info 的 cmake_find_mode 设为 none（自带 KF5*Config.cmake），CMakeDeps 便不再把它们写入 CMAKE_PREFIX_PATH，导致下游 find_package(KF5CoreAddons) 与已安装 config 内的 find_dependency() 都找不到配置文件。

## 推荐方案
**方法**: unify-qt-base-and-inject-config-paths

**说明**: 用 force=True 把自身所需的 Qt5 变体提升为全图唯一版本（保留消费语义以便 generate() 取 package_folder），并在 generate()/test_package 中遍历 self.dependencies.values() 把每个依赖的 lib/cmake、lib、include 前置注入 CMAKE_PREFIX_PATH / CMAKE_LIBRARY_PATH / CMAKE_INCLUDE_PATH。

**修复命令**:
```
self.requires("qt5-qtbase/5.15.2.2", force=True)  # 版本冲突统一；generate() 循环注入各依赖 lib/cmake
```

**验证**:
```
conan create <pkg_dir> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing --user=ohpcd --channel=stable
```
