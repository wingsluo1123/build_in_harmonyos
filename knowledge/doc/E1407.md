# E1407: 2003 年前后的老 C++ 源码在 clang 15 + libc++ 下两处典型不可编译：隐式 ostream→bool 转换与老 BSD 非标准类型 uint

## 基本信息
- **严重度**: 2
- **类别**: portability, clang, cpp, legacy-code, libcxx
- **作者**: AB38

## 错误特征
```
no viable conversion from returned value of type 'std::ostream' to function return type 'bool'|unknown type name 'uint'|return out << in.rdbuf
```

## 根因分析
libc++ 移除了 std::ostream 的隐式 operator void*（operator bool 为 explicit），老代码 return out << in.rdbuf();（函数返回 bool）不再能隐式转换；同时 uint 是老 BSD sys/types.h 的非标准 typedef，glibc/libc++ 不提供，clang 报 unknown type name 'uint'。两者都是语言/运行库现代化问题，与平台无关，但只在换成 clang+libc++ 后才暴露（上游当年用 gcc+libstdc++ 编译通过）。

## 推荐方案
**方法**: minimal-source-portability-patch

**说明**: 最小改动：① 把 'return out << in.rdbuf();' 改为 'out << in.rdbuf(); return !out.fail();'（语义等价于原隐式转换的 !fail()）；② 非标准类型 uint → unsigned int。不做平台宏守卫（属通用编译器可移植性修复，非 OHOS 专属），不改语义、不引第三方依赖。

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
grep -n 'return out << in.rdbuf' <src>/wputil.h; grep -n '\buint\b' <src>/vbrfix.cpp; 打补丁后 make -j4 应 0 error
```
