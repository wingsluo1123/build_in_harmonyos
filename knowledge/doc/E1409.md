# E1409: Conan 2 zip strip_root 对扁平压缩包（无顶层目录）误判公共字符串前缀为根目录并 IndexError

## 基本信息
- **严重度**: 3
- **类别**: conan, packaging
- **作者**: A31F

## 错误特征
```
IndexError: list index out of range.*files.py.*member.filename = name.split|Uncompressing.*IndexError|strip_root.*IndexError
```

## 根因分析
Conan 2 的 unzip strip_root 实现用 os.path.commonprefix（纯字符串前缀而非路径组件）检测根目录：扁平 zip（如 NIST tnt_126.zip，21 个 tnt*.h 直接位于压缩包根）的公共前缀 tnt 被误判为根目录，随后对不含 / 的条目执行 name.split('/', 1)[1] 直接 IndexError。tar.gz 路径实现不同，无此问题。

## 推荐方案
**方法**: verify-archive-layout-then-strip-root-false

**说明**: 解包前先核实归档布局（zipfile namelist / unzip -l）：无顶层目录的扁平包必须 strip_root=False；有单一顶层目录才用 True。conandata.yml 注释记录布局特征，配方 source() 内注释说明原因。

**修复命令**:
```
python -c "import zipfile; n=zipfile.ZipFile('src.zip').namelist(); print(all('/' not in x for x in n))"  # True=扁平包 → 配方改 strip_root=False
```

**验证**:
```
python -c "import zipfile; n=zipfile.ZipFile('<file>.zip').namelist(); print('flat:', all('/' not in x for x in n))"
```
