# E1416: musl 下 FILE 为不透明类型导致 sizeof(FILE) 编译失败

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, musl
- **作者**: 99D3

## 错误特征
```
sizeof on FILE in musl: arithmetic on pointer to opaque type / invalid application of sizeof to incomplete type FILE
```

## 根因分析
musl 的 FILE 为不透明类型，sizeof(FILE) 直接编译失败。glibc 时代源码常用 sizeof(FILE) 作 FILE 存储上限估算，musl/OHOS 上必须改常量。

## 推荐方案
**方法**: libc 能力守卫：__GLIBC__ 分支保留 sizeof(FILE)，其余用固定上限(512)。案例 picoc 2.1 patches/0001-cstdlib-stdio.c.patch

**说明**: 以 __GLIBC__ 能力守卫替换 sizeof(FILE)：glibc 保留精确值，其余 libc 用固定上限
