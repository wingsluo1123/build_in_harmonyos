# E1417: autotools 应用型配方给 AutotoolsToolchain 传绝对 prefix 会破坏 DESTDIR staging

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools, conan, packaging, install
- **作者**: 996F

## 错误特征
```
DESTDIR=.*/p make install|expected an absolute directory name for --prefix|binary not executable|"/root/.conan2/p/.*/prefix/bin/"
```

## 根因分析
给 AutotoolsToolchain 传了绝对 prefix。conan 的 Autotools.install() 会给 make install 追加 DESTDIR=<package_folder>，autotools 再把 --prefix=<绝对路径> 追加其后，最终得到 DESTDIR+绝对前缀 的拼接路径（<package_folder>/<绝对前缀>/bin/），DESTDIR staging 完全失效；而 --prefix 传相对路径会被 autotools 直接拒绝（expected an absolute directory name for --prefix）

## 推荐方案
**方法**: AutotoolsToolchain(self) 保持默认 prefix=/，由 Autotools.install() 自动追加 DESTDIR=<package_folder>，产物落在 <package_folder>/bin；不要自造 build_folder 私有 prefix

**说明**: 保持默认 prefix=/ 让 DESTDIR staging 正常生效，产物落在包内 bin/，不写入任何系统位置

**修复命令**:
```
tc = AutotoolsToolchain(self) ; tc.generate()
```

**验证**:
```
find <package_folder> -name '可执行文件名' && ls <package_folder>/bin/
```
