# E1418: Conan 离线源喂包：backup source sha256+json 配对与 URL scheme 共性问题

## 基本信息
- **严重度**: blocker
- **类别**: conan
- **作者**: 9531

## 错误特征
```
NotFoundException: Sources for <URL> not found in remote backup; No connection adapters were found for file://; No scheme supplied (download_urls); ConanException: Error downloading file <base>/<sha256>
```

## 根因分析
conan 2.29.1 backup sources 机制三条共性陷阱：①<sha256> 包与 <sha256>.json 元数据必须成对提供（caching_file_downloader.py:104-107），缺 json 整体按 NotFoundException 判负；②file:// scheme 无 requests connection adapter、裸路径报 No scheme supplied；③上一次任务的 TEMP global.conf 配置残留把 source() 指向死端口/旧目录

## 推荐方案
**方法**: 本地 http.server 喂源：目录内成对放 <内容sha256> 与 <内容sha256>.json（references 指回官方 URL），core.sources:download_urls=["http://127.0.0.1:<port>/"]；或同构成对预置 download_cache；TEMP 配置用后必须还原 global.conf。检测脚本与样例见 knowledge/operations/conan-offline-source-feed/（样例库 japa 0.9.4 三连失败复现→修复后 create RC=0）

**说明**: 一句话描述这个推荐方案

```

```
