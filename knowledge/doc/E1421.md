# E1421: Makefile 默认 CXXFLAGS 含 x86 专属 SIMD 标志（-msse4/-msse）在 aarch64/arm64 上不适用

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, portability, build-system
- **作者**: 91E7

## 错误特征
```
argument unused during compilation: '-msse4'|unknown argument: '-msse4'|unrecognized command-line option '-msse|invalid feature.*sse4
```

## 根因分析
>

## 推荐方案
**方法**: override-build-flags

**说明**: conanfile build() 中覆盖 CXXFLAGS，移除 -msse4，保留 -O3 -std=c++11 -pthread

**修复命令**:
```
make -j1 CC={cc} CXX={cxx} CXXFLAGS="-O3 -std=c++11 -pthread" CFLAGS="-Wall -O2" CPPFLAGS={include_flags} LDFLAGS={libdir_flags}
```
