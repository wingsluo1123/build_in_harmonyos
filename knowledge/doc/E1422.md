# E1422: aarch64 基线 FMA + clang 默认 -ffp-contract=on 改变浮点结果，导致上游数值断言失败

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, clang, testing, numerics
- **作者**: 8FC3

## 错误特征
```
Assertion failed: ApproxEqual.*has to be|Assertion failed: !MyPGon->Contains
```

## 根因分析
aarch64 基线含 FMA，clang 从 -O2 起默认 -ffp-contract=on，把 a*b+c 融合成单条 FMA 指令，改变浮点结果；上游参考平台 x86-64 无 FMA 不会发生收缩

## 推荐方案
**方法**: ffp-contract-off

**说明**: 在配方 CMakeToolchain 加 tc.extra_cxxflags.append('-ffp-contract=off')，关闭浮点收缩以与上游 x86 参考数值一致

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
ctest --output-on-failure   # 期望 100% tests passed
```
