# E1424: FreeBSD 专有接口（sysctl/errc/cdefs 宏）迁移 OHOS 的守卫与替换

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, libc, bsd-make, cdefs-macro
- **作者**: 8B20

## 错误特征
```
sys/sysctl.h.*No such file|errc.*undefined symbol|__FBSDID.*undeclared|incompatible integer to pointer conversion passing 'long' to parameter of type 'const char \*'
```

## 根因分析
FreeBSD 源码头文件 sys/cdefs.h 提供 __FBSDID/__dead2 等宏、sys/sysctl.h 提供 sysctl(3)、libc 提供 errc()，OHOS 均缺失；且平台守卫若整块包裹 getenv 赋值会导致未初始化局部变量 UB

## 推荐方案
**方法**: ①sysctl/sysctlbyname 用 #ifdef __FreeBSD__ 守卫（只守卫调用本体，保留 getenv 赋值）；②编译参数注入 -D'__FBSDID(x)=' 与 -D'__dead2=__attribute__((__noreturn__))'；③errc() 等价替换为 errno=EAGAIN + err()

**说明**: bsdmake-24 适配实践：Apple BSD make 依赖 FreeBSD 专有接口，OHOS 需守卫与替换

**修复命令**:
```
clang -D'__FBSDID(x)=' -D'__dead2=__attribute__((__noreturn__))' -DDEFSHELLNAME=\"sh\" -DMAKE_VERSION=\"5200408120\" -I. -c *.c
```

**验证**:
```
conan create archives/b/bsdmake/24 --build=missing 后运行 test_package/test.sh（4 组断言全通过）
```
