# E1427: BSD make 项目在 OHOS(GNU make) 下的构建适配

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, build-system
- **作者**: 846C

## 错误特征
```
missing separator|No targets specified and no makefile found
```

## 根因分析
上游 Makefile 使用 BSD make 专有条件语法(.ifdef/.else/.endif)与变量定义选项(-DWITH_X)，OHOS 仅有 GNU make；GNU make 把 .ifdef 当普通文本行 → missing separator，把 -D 当未定义选项 → 递归子 make 打印 usage

## 推荐方案
**方法**: 改写条件语法为 ifdef/else/endif；-DWITH_X 改为命令行变量 WITH_X=1；install 用 mkdir -p + cp -f + chmod 替代缺失的 install(1)；补 prefix ?= /usr/local 与 DESTDIR

**说明**: 最小补丁把 BSD make 条件语法 / WITH_* 宏传递 / install 三处改写为 GNU make + OHOS 可用形态，全程不引入平台宏

**修复命令**:
```
patch -p1 < 0001-Makefile.patch && make CC=clang -j1 && make install DESTDIR=${PKG} prefix=/usr/local
```

**验证**:
```
grep -nE '^\.(if|ifdef|ifndef|else|endif)' Makefile src/Makefile
```
