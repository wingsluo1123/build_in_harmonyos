# E1429: COIN-OR autotools 依赖探测 pkg-config 名与 ohpcd 包名偏离：生成 osi.pc/osi-clp.pc 兼容别名

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, pkg-config, packaging, coin-or
- **作者**: 8317

## 错误特征
```
CglLandP.hpp not found|CglLandP.hpp file not found|COIN_HAS_OSICLP not defined|osi-clp not found|checking for osi-clp
```

## 根因分析
ohpcd 将 Osi 发布为包名 coin-or、Clp 包只导出 clp.pc，而上游 AC_COIN_CHECK_PACKAGE 按 osi/osi-clp 探测 pkg-config 名，探测失败致 COIN_HAS_OSICLP 未启用、CglLandP 源被条件宏跳过、下游 CbcSolver.cpp:216 #include CglLandP.hpp 编译失败

## 推荐方案
**方法**: generate-pkg-config-compat-alias

**说明**: conan generate() 中为 coin-or 包写 osi.pc（Requires: coin-or）、为 clp 包写 osi-clp.pc（Requires: clp）兼容别名，使 AC_COIN_CHECK_PACKAGE 探测成功

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan create 通过；nm libCgl.a | grep CglLandP 有符号；CbcSolver.cpp 编译链接成功；osiUnitTest/gamsTest/CInterfaceTest 通过
```
