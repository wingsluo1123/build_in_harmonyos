# E1430: zero-runtime-deps-not-zero-compile-time-deps

## 基本信息
- **严重度**: 2
- **类别**: build-system, java, packaging
- **作者**: 82F7

## 错误特征
```
error: cannot find symbol|error: package [\w.]+ does not exist|no suitable method found
```

## 根因分析
「零运行期依赖」不等于「零编译期依赖」：H2 核心 jar 运行期零依赖（java.sql 即用），但 src/main 里含可选集成类（servlet web 控制台 / OSGi DataSourceFactory / JTS 几何 / Lucene 全文检索 / slf4j 适配），编译它们需要对应 API；只按「运行期无依赖」就上 javac 会成片报 cannot find symbol / package does not exist。

## 推荐方案
**方法**: enumerate-third-party-imports-then-add-compile-only-jars

**说明**: ①先把 src/main 的第三方 import **列全**（一次列清，避免逐个试错）②把对应 jar 作为**编译期依赖**取入（钉 sha256）并只用于 javac 的 -cp ③产物里只放本库 jar，不夹带这些 API ④在 manifest/notes 里如实写明「仅编译期、非运行期依赖」及其用途文件。

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
grep -rhE '^import ' src/main | sed 's/^import //' | grep -vE '^(org\.<本库>|java\.|javax\.(sql|naming|xml|tools|script|crypto))' | awk -F. '{print $1"."$2}' | sort -u
```
