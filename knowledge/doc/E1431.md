# E1431: Python 适配两个隐蔽坑：Conan 2 的 test_requires 在 test 上下文（host/build 遍历取不到）；sdist 时间戳归一化到 epoch 会打到"按 mtime 造 zip"的上游用例

## 基本信息
- **严重度**: 1
- **类别**: compat, portability, build-system
- **作者**: 7F91

## 错误特征
```
No module named 'aiohttp'|ModuleNotFoundError|ZIP does not support timestamps before 1980|test_requires
```

## 根因分析
两个都是"看起来像上游/测试坏了，其实是环境与 Conan 语义"的坑：①**test_requires 的上下文**——Conan 2 里 `self.test_requires("aiohttp/x.y.z")` 声明的依赖落在 **test 上下文**，收集依赖 site-packages 时只遍历 `self.dependencies`（默认 host）或 `.build` **都拿不到**（实测两次遍历都是空集合），必须加 `self.dependencies.test`；而且**不要用"库名子串"匹配 conan 包路径**——包目录是截断名（`.conan2/p/aioht9f1a043272ee1/p/…` 里没有 `aiohttp` 子串），按路径匹配会假阴性、把存在的依赖判成"没找到"，应改判**模块目录是否存在**（`os.path.isdir(os.path.join(site, "aiohttp"))`）。②**sdist 时间戳归一化**——PyPI sdist 常把成员时间戳归一到 **epoch（`mtime = 0`，SOURCE_DATE_EPOCH 那套）**，而上游 `test_import__without_package_metadata` 用 `zipfile.write()` 按**源文件 mtime** 造 zip → `ValueError: ZIP does not support timestamps before 1980`（在 git 检出、mtime 正常时该用例通过）。
