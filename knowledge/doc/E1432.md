# E1432: vvenc 1.14.0 OHOS 构建工程约定：C++ 运行时解析、源码树输出开关、上游测试入口（39 项）

## 基本信息
- **严重度**: P2
- **类别**: build-convention
- **作者**: 7B94

## 错误特征
```
libvvenc.so.*not found|libc++_shared.so.*not found|CMAKE_SOURCE_DIR 被写入 lib/ bin/|ctest 用例数少于预期
```

## 根因分析
三条与单库绑定的工程事实：(1) OHOS 设备默认搜索路径已含 /system/lib64/libc++_shared.so，C++ 共享库消费者无需额外 LD_LIBRARY_PATH；(2) 上游 VVENC_TOPLEVEL_OUTPUT_DIRS 默认 ON，会把 lib/ 与 bin/ 写进 CMAKE_SOURCE_DIR 并带 release-<shared|static> 后缀，Conan 构建必须置 OFF，否则污染源码导出并干扰补丁生成；(3) 上游测试入口为 cmake/modules/vvencTests.cmake 的 add_test 注册，shared 构建 39 项，static 构建额外含 Test_vvenc_unit_test。

## 推荐方案
**方法**: Conan recipe 中显式设 VVENC_TOPLEVEL_OUTPUT_DIRS=OFF 并启用 VVENC_ENABLE_INSTALL/VVENC_INSTALL_FULLFEATURE_APP；不要为 libc++_shared.so 额外注入 LD_LIBRARY_PATH；统计上游测试数以 shared 构建的 39 项为基线。

**说明**: 在 Conan recipe 中固定三项工程约定：关闭源码树输出（VVENC_TOPLEVEL_OUTPUT_DIRS=OFF）、C++ 运行时按设备默认路径解析（不额外注入 LD_LIBRARY_PATH）、以上游 shared 构建的 39 项 ctest 为测试基线

**修复命令**:
```
cmake -S . -B build -DVVENC_TOPLEVEL_OUTPUT_DIRS=OFF -DVVENC_ENABLE_INSTALL=ON -DVVENC_INSTALL_FULLFEATURE_APP=ON && cmake --build build -j && ctest --test-dir build -N
```

**验证**:
```
ctest -N | tail -3（shared 构建期望 39 项）；构建后源码树内不应出现 lib/ 与 bin/ 目录
```
