# E1434: kernel-data-gap-report

## 基本信息
- **严重度**: 2
- **类别**: ohos, kernel, testing, false-fail, fdinfo
- **作者**: 76B1

## 错误特征
```
lsof: no fdinfo flags:|flags:02u|expected 01u.*got 02u|expected 00u.*got 02u|pipe endpoint missing direction|pty endpoint missing direction|3r/4w.*not found
```

## 根因分析
OHOS(HongMeng)内核对 pipe/pty fd 的 /proc/<pid>/fdinfo/<fd> 的 flags 字段统一上报 02u(O_RDWR)，不提供上游 Linux 内核的方向位 01u(写)/00u(读)。lsof 等 fd 消费工具依赖 flags 方向位推断管道端点角色（3r/4w 配对显示），上游 make check 的 pipe/pty endpoint 类用例因此恒 FAIL。数据源在内核侧，用户态补丁无法修复——属平台级数据缺口而非移植缺陷。
