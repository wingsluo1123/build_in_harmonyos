# E1435: 流到数据报桥接必须三态处理 read 返回值并验证精确报文基数

## 基本信息
- **严重度**: 2
- **类别**: posix, network, testing
- **作者**: 7015
- **来源 PR**: 15313

## 错误特征
```
packet prepared is invalid|file emitter failed at EOF|EOF emitted an extra datagram|sample count underflowed
```

## 根因分析
流读取后调用者只处理负错误码，遗漏 read 返回 0 的正常 EOF，把零长度送入 payload_size / frame_width - 1 的协议算术，造成无符号下溢并在有效数据已发送后伪失败退出。

## 推荐方案
**方法**: tri-state-read-loop-with-exact-datagram-cardinality

**说明**: 在读取循环统一区分负错误、零 EOF 和正载荷；只有正载荷进入长度计算和发送，并用有限输入独立断言成功退出、精确包数、帧边界与载荷。

**修复命令**:
```
python3 test_package/test_vban.py <package-bin-dir>
```

**验证**:
```
用 64 字节有限输入断言 rc=0 且恰好一个正确报文，再以目录输入触发读取错误并断言非零退出且零报文
```
