# E1436: HarmonyOS 沙箱全局拒绝 mkfifo(2)（EPERM）：命名管道不可用，依赖 FIFO 的功能/测试需运行期探测后跳过或回退

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: 6E9E, kasumizawa-miyuu <241250031@smail.nju.edu.cn>, AtomCode

## 错误特征
```
mkfifo: Operation not permitted（make 并行 jobserver 初始化失败）
```

## 根因分析
HMDfs/FUSE 文件系统不支持 FIFO（mkfifo 返回 EPERM），GNU make 的 -j 并行 jobserver 依赖 FIFO，OHOS 设备上系统级不可用

## 推荐方案
**方法**: 构建一律 make -j1 串行；conanfile.py build() 中固定 -j1；不要尝试 MAKEFLAGS/-jN 绕过（会复现 EPERM）；CI 同设备类型同约束

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
对照实验：make -j4 报 mkfifo: Operation not permitted，make -j1 通过（rtpengine 26.0.1.15 实测）
```
