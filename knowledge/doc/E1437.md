# E1437: OHOS sysroot 的 fenv.h（musl 系）不提供 glibc 扩展 feenableexcept/fedisableexcept，需 __GLIBC__ 能力守卫

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, libc, musl, headers
- **作者**: 69E4

## 错误特征
```
use of undeclared identifier 'feenableexcept'|did you mean 'feraiseexcept'
```

## 根因分析
feenableexcept/fedisableexcept 是 GNU libc 扩展；OHOS sysroot 的 fenv.h 只有标准 fenv 函数，而源码仅按 __GNUC__ && !__APPLE__ 守卫（clang 定义 __GNUC__），故在 OHOS 上被编译

## 推荐方案
**方法**: glibc-capability-guard

**说明**: 把 <fenv.h> include 提到守卫之前（让 __GLIBC__ 可见），再用 defined(__GLIBC__) 能力守卫包住 feenableexcept 调用；非 glibc 上退化为 no-op，不引入平台宏

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
echo | clang -E -dM -x c - | grep -c __GLIBC__   # 0 表示无 glibc 扩展
```
