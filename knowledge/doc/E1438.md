# E1438: ohpcd ncurses/6.6 的 TUI 以 root 运行时忽略 TERMINFO/TERMINFO_DIRS/~/.terminfo（据推断是构建时 configure 把系统判为非多用户系统所致）：x86 runner（root）上 qemu 实跑报 cannot initialize terminal type，降权为非 root 即恢复

## 基本信息
- **严重度**: 2
- **类别**: ohos, runtime, testing, environment, security
- **作者**: 5ED1

## 错误特征
```
ncurses: cannot initialize terminal type \(\$TERM="[^"]*"\); exiting|Error opening terminal: [A-Za-z0-9._+-]+\.
```

## 根因分析
ncurses 6.6 的 configure 只在 "conventional multiuser system"（/etc/passwd 中存在 uid>=100

## 推荐方案
**方法**: run-local-tui-verification-as-non-root

**说明**: 本地（x86 runner）用 qemu 实跑 ncurses TUI 的消费者测试时降权为非 root：把静态重链产物、测试

**修复命令**:
```
D=<scratch>; cp -r <ncurses>/share/terminfo $D/terminfo; chmod -R a+rX $D; chmod 777 $D
```

**验证**:
```
llvm-nm -A <ncurses>/lib/libncursesw.a | grep ' U _nc_env_access'                 # 4 处：db_iterator/home_terminfo/write_entry 三处来自 use_terminfo_vars()，comp_error 一处是直接调用（不计）
```
