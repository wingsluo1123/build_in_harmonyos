# E1439: 子串匹配的单元测试过滤器会让逐用例断言数重复计数，必须按名字长度降序做超串归减法

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, testing
- **作者**: 5CC4

## 错误特征
```
assertion count|测试用例数|run [0-9]+ in|TEST_FILTER|RUN_TEST|strstr
```

## 根因分析
上游测试框架用 strstr(#test, filter) 选测（Cesanta unit_test 等），一个过滤器会连带命中所有名字包含它的用例，逐个过滤器求和必然重复计数；同时该框架的 RUN_TEST 在首个失败即 return，全量跑一次只能拿到第一个失败之前的断言数，两个缺陷合起来让『用例数/断言数』无法直接照抄日志

## 推荐方案
**方法**: desc-length-substring-subtraction

**说明**: 按用例名长度降序逐个以名字为过滤器运行，每个 run 的断言总数减去其中已计量过的长名字超串断言数，即得该用例真实断言数；求和即无重复的真实总数

**验证**:
```
python3 - <<'PY'  # 计算过滤器集合是否存在掩码对
```
