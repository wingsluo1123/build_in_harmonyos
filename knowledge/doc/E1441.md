# E1441: 共享宿主上 python(conan) 派生 clang 若继承终端 stdin 会静默失败(rc=1 无输出)，CMake 编译器自检报 broken；stdin 重定向 /dev/null 即恢复

## 基本信息
- **严重度**: 3
- **类别**: platform, cmake, toolchain, clang, conan
- **作者**: 5BFE

## 错误特征
```
is not able to compile a simple test program|Check for working C compiler.*broken|The C compiler identification is unknown
```

## 根因分析
OHOS 环境下由 python 通过 posix_spawn/subprocess 派生 clang 且子进程继承 tty stdin 时，clang 静默退出码 1、无任何输出；由 sh/zsh 派生或 stdin 为文件/管道/dev/null 时正常。矩阵实验(各 10 次)复现 30/30 vs 0/10

## 推荐方案
**方法**: stdin-dev

**说明**: 以 conan create ... < /dev/null（或 > 重定向）运行，避免子进程继承终端 stdin；CI/无人值守环境天然无 tty

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
python3 -c "import subprocess;print(subprocess.run(['clang','--version'],capture_output=True).returncode)"  # < /dev/null 时为 0
```
