# E1443: Python 应用配方的未发布依赖三级处置（requires / 守护补丁 / pip 钉版本打入包）

## 基本信息
- **严重度**: 2
- **类别**: portability, python, dependency, packaging
- **作者**: 5961

## 错误特征
```
No module named|ModuleNotFoundError|unpublished dependency|Recipe not found
```

## 根因分析
Python 应用的上游依赖分三类：已发布/未发布但可降级/未发布且必需（含传递依赖）。未发布依赖声明进 requires 会被 R36 的 L0i/PF4 闸拦截；直接联网 pip install 又不可复现。

## 推荐方案
**方法**: dependency-tiered-dispatch

**说明**: 已发布→requires；未发布但可降级→守护补丁（try/except ImportError + 受控报错）；未发布且必需/传递依赖→pip 钉版本 --target 打入本包 site-packages。

**修复命令**:
```
pip install --no-compile --target=<stage> <pkg>==<ver>
```

**验证**:
```
bash ci/scripts/preflight_check.sh <pkg>/<ver> --deps "<dep>/<ver> ..."
```
