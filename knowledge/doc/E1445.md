# E1445: lit 为每个用例重建最小环境（只保留 PATH + pass_vars 白名单），HOME 与 PYTHONPATH 都不转发：上游 lit 用例会假失败（调试器写 history 抛 FileNotFoundError、python3 -m <pkg> 解析不到被测包），--timeout 还需要 psutil；用 lit.local.cfg 平台 shim 显式补回，不改上游测试文件

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, python, conan, packaging
- **作者**: 57BF

## 错误特征
```
fatal: Setting a timeout per test not supported.*psutil|'riscemu': command not found|'riscemu' is not recognized|FileNotFoundError.*riscemu_history|No such file or directory.*\.riscemu_history|EXPECTED: \[CPU\] Program exited with code
```

## 根因分析
lit 的 TestingConfig.fromdefaults() 从零构造 environment（只有 PATH + LLVM_DISABLE_CRASH_REPORT + pass_vars 固定白名单），不继承调用者环境；riscemu 的 fibs.asm 用例走到 ebreak 时 debug.py 会 write_history_file(expanduser('~/.riscemu_history'))，HOME 缺失导致 expanduser 失败抛 FileNotFoundError 中断，CHECK 行永不出现（同一条命令手工带 HOME 跑必过）；同因 PYTHONPATH 也被丢弃，lit RUN 行里的 python3 -m riscemu 会解析到环境里别的 riscemu 或直接 ModuleNotFoundError，使被测对象不是本次 conan 包

## 推荐方案
**方法**: lit-local-cfg-platform-shim

**说明**: 在 test_package 的 lit 测试目录放一个最小的 lit.local.cfg 平台 shim：把 HOME（无则 tempfile.mkdtemp 兜底）与 PYTHONPATH 显式写回 config.environment；test_package/conanfile.py 的 test() 里再确保 psutil（lit --timeout 依赖，上游 dev 依赖同版本区间）已安装，并用 PATH 检查 filecheck CLI；上游测试文件逐字节不改

**修复命令**:
```
config.environment['HOME']=_home; config.environment['PYTHONPATH']=os.environ['PYTHONPATH']  # lit.local.cfg；pip install 'psutil>=5.9,<6' 'lit>=16,<17' 'filecheck==0.0.23'
```

**验证**:
```
lit --timeout=5 -v test_package/filecheck  # 未加 shim: Passed: 10 Failed: 1（fibs.asm）；加上转发 HOME/PYTHONPATH 的 lit.local.cfg: Passed: 11；python3 -c 'import psutil' 缺则 lit 报 fatal: Setting a timeout per test not supported
```
