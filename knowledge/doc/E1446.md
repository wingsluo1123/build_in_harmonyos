# E1446: OHOS 下 bash + GNU cat 的 heredoc 失败导致 autoconf conftest 为空

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, limitation, build-system, autotools
- **作者**: 578B

## 错误特征
```
cat: -: Permission denied|C compiler cannot create executables|undefined symbol: main
```

## 根因分析
HNP bash 与 cmd-pkgs GNU coreutils 的 cat 组合下 heredoc stdin 不可读, autoconf 的 cat confdefs.h - 生成空 conftest.c, 链接报 undefined symbol main, configure 报 C compiler cannot create executables

## 推荐方案
**方法**: conanfile generate() 中把 CONFIG_SHELL/SHELL 固定为 /bin/sh 并自行执行 configure(需自行读 conanbuild.conf 的 configure_args)

**说明**: 把 configure 的执行 shell 固定为 /bin/sh（profile [buildenv] 的 SHELL/CONFIG_SHELL 在 toolchain 脚本之后加载, 需在命令行前置赋值）

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
env -i PATH=/data/service/hnp/bin:/bin:/usr/bin sh -c 'cat /dev/null - <<EOF\nB\nEOF'; /data/service/hnp/bin/bash -c 'cat /dev/null - <<EOF\nB\nEOF'
```
