# E1448: CPM 生产依赖本地注入：CPMAddPackage 改 SOURCE_DIR + 源码下载缓存，实现禁 GitHub 环境下自包含构建

## 基本信息
- **严重度**: 2
- **类别**: network, build-system, cmake, conan, dependency
- **作者**: 5301

## 错误特征
```
CPMAddPackage.*GITHUB_REPOSITORY.*failed|git clone.*github.com.*timed out|Source .*retrieved from local download cache|Could not resolve host.*github|Failed to apply patch
```

## 根因分析
FastNoise2 等 CPM 工程在 configure 期从 GitHub clone 生产依赖（FastSIMD/benchmark），CI/本机禁 GitHub 直连时配置失败；镜像改写不可控且污染官方 URL

## 推荐方案
**方法**: cpm-local-source-dir-injection

**说明**: 下载依赖精确 commit 官方 tarball 核验 SHA-256 后，将 CPMAddPackage 的 GITHUB_REPOSITORY/GIT_TAG 改为 SOURCE_DIR 指向本地解包目录（补丁形式），并用 conan core.sources:download_cache 缓存主源码与依赖 tarball

**修复命令**:
```
conandata.yml 声明 fastsimd/benchmark 官方 URL+sha256；conanfile.py source() 解包到 deps/；patches 改 SOURCE_DIR
```

**验证**:
```
cmake -B build -DFASTNOISE2_TESTS=ON && cmake --build build && ./build/Release/bin/FastNoiseCpp11Test
```
