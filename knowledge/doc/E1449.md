# E1449: OHOS 上可选 python-keyutils 不可用（无 wheel + 无 libkeyutils + 内核 keyring 系统调用被沙箱阻止）；C 扩展在沙箱无法 dlopen

## 基本信息
- **严重度**: 2
- **类别**: limitation, ohos, portability
- **作者**: 51D8

## 错误特征
```
ModuleNotFoundError: No module named 'keyutils'|keyutils.*(No module|ImportError)|Error relocating.*PyType_Ready: symbol not found
```

## 根因分析
udiskie/cache.py 顶层 import keyutils；python-keyutils 是绑定 libkeyutils/内核 keyring 的 C 扩展：OHOS 制品仓与社区 PyPI 镜像仅有 sdist（缺 keyutils.h、系统无 libkeyutils），且内核 keyring 系统调用（arm64 add_key=248/request_key=249）在本环境被 seccomp 沙箱阻止（进程被 kill）
