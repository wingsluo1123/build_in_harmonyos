# E1452: Conan 2：package_type=library 的包其依赖默认不算传递头文件，公开头 include 依赖头时消费者编译失败

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, build-system, cmake, conan
- **作者**: 456A

## 错误特征
```
fatal error: 'VecCore/VecCore' file not found|: error: .* file not found
```

## 根因分析
Conan 2 对 header-library 中间包默认 transitive_headers=True，但对 package_type=library 默认 False；此时 CMakeDeps 为消费者生成的包目标既不带依赖的 include 目录也不生成 find_dependency，即使写了 cpp_info.requires 也不生效

## 推荐方案
**方法**: transitive-headers-flag

**说明**: 在 requirements() 里写 self.requires('<dep>/<ver>', transitive_headers=True)，并保留 cpp_info.requires 作为显式转发

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan install --requires=<pkg> -g CMakeDeps --output-folder=out && grep -E 'FIND_DEPENDENCY_NAMES <Dep>|Dep::' out/*-data.cmake out/*-Target-release.cmake
```
