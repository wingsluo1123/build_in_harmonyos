# E1455: 非阻塞 TLS 握手完成只更新 ready 状态而未重新调度握手前应用发送队列，

## 基本信息
- **严重度**: 2
- **类别**: socket, network, runtime, testing, security
- **作者**: 4084

## 错误特征
```
TLS handshake.*(?:success|complete).*(?:first|Version).*(?:timeout|not received)|
```

## 根因分析
事件驱动服务器允许在 TLS 未 ready 时排队应用帧，但 poll/epoll

## 推荐方案
**方法**: flush-application-queue-at-tls-ready-transition

**说明**: 将“握手完成”视为调度状态转换而不只是布尔赋值。在确认 TLS ready

**修复命令**:
```
add flush_queued() guarded by tls_ready && tx_buffer_empty && !queue_empty;
```

**验证**:
```
rg -n 'SSL_accept|SSL_do_handshake|SSLready|txMsgQueue|POLLOUT' src;
```
