# E1456: published conan package xapian-config prefix=/ consumer rewrite

## 基本信息
- **严重度**: 2
- **类别**: conan, recipe-dependency-consumption
- **作者**: 3F8F

## 错误特征
```
xapian-config --cxxflags -> -I//include|fatal error: xapian.h file not found
```

## 根因分析
conan Autotools.install relocates install prefix to / when packaging; xapian-core bin/xapian-config bakes prefix="/" and reports -I//include -L//lib, so consumers whose configure macro mandates an executable *-config (xapian.m4 XO_LIB_XAPIAN) fail to find headers even though the dependency package is correct

## 推荐方案
**方法**: consumer recipe generate(): load dependency config script, replace single prefix="/" assignment with dependency package_folder, save private executable copy under self.build_folder/bin, chmod 0755, export via XAPIAN_CONFIG through Environment(scope=build); reference archives/o/omega/2.0.0/conanfile.py _make_working_xapian_config

**说明**: 生成私有修正副本并注入 XAPIAN_CONFIG（保留原包只读）

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
sh $XAPIAN_CONFIG --cxxflags
```
