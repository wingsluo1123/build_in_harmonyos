# E1457: maven-snapshot-module-version-jar-naming

## 基本信息
- **严重度**: 2
- **类别**: build-system, java, packaging
- **作者**: 3A6F

## 错误特征
```
target/.*-SNAPSHOT\.jar|artifact not found.*\.jar
```

## 根因分析
上游发布树的模块 pom 版本可能写作 X.Y.Z-SNAPSHOT（发布时未改成正式版本号），其产物文件名随之带 -SNAPSHOT；配方若按 <artifactId>-<version>.jar 写死路径就找不到产物，而评审/消费者期望的是正式发布名。JSTL 3.0.2 的 impl 模块即如此（pom 写作 3.0.2-SNAPSHOT，产物 jakarta.servlet.jsp.jstl-3.0.2-SNAPSHOT.jar）。

## 推荐方案
**方法**: locate-by-artifact-prefix-then-rename-to-release-name

**说明**: ①package() 用 <artifactId 前缀>*.jar 定位并排除 -sources/-javadoc；②需要正式名时重命名为 <artifactId>-<发布版本>.jar（jar 内 MANIFEST 与文件名无关）；③把改名一事如实写进 manifest/notes/PR；④消费者校验按包内实际文件名断言。

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
grep -m1 '<version>' <module>/pom.xml ；ls <module>/target/*.jar
```
