# E1458: CMake pkg_check_modules 只链接 ${PROJECT_DEPS_LIBRARIES} 未用 _LIBRARY_DIRS 导致传递 -L 丢失

## 基本信息
- **严重度**: 2
- **类别**: cmake, linking, conan, pkg-config
- **作者**: 33BD
- **来源 PR**: 7826

## 错误特征
```
unable to find library -l(jpeg|turbojpeg|zstd|cairo-gobject)|PROJECT_DEPS_LIBRARIES
```

## 根因分析
上游 CMakeLists 只用 target_link_libraries(${PROJECT_DEPS_LIBRARIES}) 而未用 pkg_check_modules 的 PROJECT_DEPS_LIBRARY_DIRS, 传递依赖 (cairo-gobject/libjpeg-turbo/zstd/tiff/webp) 的 -L 路径全部丢失, ld 无法解析

## 推荐方案
**方法**: conanfile-generate-inject-all-dependency-libdirs

**说明**: conanfile.py generate() 中遍历 self.dependencies 全部包, 把存在的 <package_folder>/lib 以 -L 追加注入 CMAKE_SHARED_LINKER_FLAGS 与 CMAKE_EXE_LINKER_FLAGS, 弥补上游只链接 ${PROJECT_DEPS_LIBRARIES} 而未用 PROJECT_DEPS_LIBRARY_DIRS 丢失的传递 -L

**修复命令**:
```
见 conanfile.py generate()（tc.variables["CMAKE_SHARED_LINKER_FLAGS"] 与 CMAKE_EXE_LINKER_FLAGS 赋值为 sorted(link_dirs) 拼接）
```

**验证**:
```
conan create 链接通过 (libayatana-ido3-0.4.so 完整, 含 cairo-gobject/jpeg/zstd/tiff/webp 传递依赖); test_package ctest 1/1 PASS
```
