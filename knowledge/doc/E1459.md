# E1459: conan 2.29 不可见传递依赖 package_folder=None 致配方遍历 TypeError

## 基本信息
- **严重度**: 2
- **类别**: conan
- **作者**: 32DD

## 错误特征
```
conan recipe build() 遍历依赖取路径 TypeError: expected str, bytes or os.PathLike object, not NoneType
```

## 根因分析
ohpcd conan 2.29 对消费者不可见的传递依赖（Traits headers=False/libs=False，如 bzip2/xz/openssl）不为其解包，Dep.package_folder=None；且 self.dependencies.values() 遍历的是全部传递依赖（非仅直接 requires），os.path.join(None, ...) 即 TypeError

## 推荐方案
**方法**: 配方遍历依赖取路径处一律先 pf = d.package_folder; if not pf: continue；只取特定依赖用 self.dependencies[name]（直接依赖均有 folder）。实证：16 直接依赖全有 folder，bzip2/xz/openssl 三个 None（2026-09-27 mpd 0.24.12 实测）

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
