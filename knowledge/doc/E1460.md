# E1460: 'HarmonyOS 6.0 aarch64 真机上的 pty TIOCSTI 输入注入返回 EACCES：只排除依赖注入能力的键盘测试'

## 基本信息
- **严重度**: 2
- **类别**: ohos, kernel, testing, permissions
- **作者**: 32AB

## 错误特征
```
'PermissionError: \[Errno 13\] Permission denied|ioctl\(.*TIOCSTI.*EACCES|TIOCSTI.*errno=13'
```

## 根因分析
'在 HarmonyOS 6.0 aarch64 真机的当前测试进程凭据下，对自己通过 pty.openpty() 打开的伪终端从端调用 TIOCSTI 输入注入 ioctl 被内核/系统权限边界拒绝，Python fcntl.ioctl 将 errno 13 作为 PermissionError 暴露。该证据只限定于已测设备、版本和进程上下文；它不证明所有 HarmonyOS 版本或权限上下文的行为，也不等价于 TCFLSH 或 TIOCSCTTY。'

## 推荐方案
**方法**: probe-tiocsti-capability-and-gate-dependent-tests

**说明**: '先在目标设备上用自有 pty slave 探测 TIOCSTI；若返回 EACCES，只跳过明确依赖该注入能力的测试用例，保留并运行其它键盘测试，并在结果中区分 N/A 与 PASS。若同一二进制需要覆盖多种 HarmonyOS 策略，优先按运行时探测结果注册用例。'

**修复命令**:
```
"python3 -c 'import pty,fcntl; m,s=pty.openpty(); fcntl.ioctl(s,0x5412,bytes([120]))'"
```

**验证**:
```
|-
```
