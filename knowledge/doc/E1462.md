# E1462: Align OpenSSL ABI across reused Conan binaries and source-built dependencies

## 基本信息
- **严重度**: 2
- **类别**: linking, conan, dependency, runtime
- **作者**: 2C1E

## 错误特征
```
Version conflict.*openssl|libnice/0[.]1[.]21.*OpenSSL 1[.]1[.]1w.*libwebsockets/4[.]3[.]5[.]1.*OpenSSL 3[.]5[.]6
```

## 根因分析
A Conan version override changes the selected dependency graph but does not rebuild a previously published binary. Reusing a libnice binary built against OpenSSL 1.1.1w while compiling libwebsockets against its default OpenSSL 3.5.6 can leave components in one process with incompatible OpenSSL ABI assumptions.

## 推荐方案
**方法**: align-openssl-to-reused-binary-abi

**说明**: Read the reused artifact's build-time OpenSSL requirement, pin the consumer graph to that exact version with a root override, and build any incompatible source dependency against the pinned version. Verify the resolved graph and exercise the final executable on the target.

**修复命令**:
```
self.requires("openssl/1.1.1w", override=True)  # match the published libnice binary; build libwebsockets from source
```

**验证**:
```
In the Janus package directory, run the recorded OHOS AArch64 conan create command and confirm the resolved graph selects openssl/1.1.1w; then run the native test_package REST and WebSocket flows on the target.
```
