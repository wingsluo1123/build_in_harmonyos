# E1465: 上游 Makefile 硬编码 Intel 专用 gcc 标志（-mavx2）在 OHOS aarch64 clang 报 unknown argument

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, make, compiler
- **作者**: 225B

## 错误特征
```
mavx2|unknown argument.*-mavx2|not.*recognized.*mavx2
```

## 根因分析
上游 Makefile 硬编码 gcc -mavx2（Intel x86 专用 SIMD 标志），OHOS aarch64 的 clang 不认识该标志直接报 unknown argument；纯 Makefile 项目（无 configure/install/check）配方直接编译时必须移除架构专用标志

## 推荐方案
**方法**: strip-arch-specific-flags-direct-compile

**说明**: 纯 Makefile 项目适配 OHOS aarch64：不用上游 Makefile 原样跑，配方直接以 clang 编译源码（无 configure/install 目标），并移除上游硬编码的 x86 专用优化标志（-mavx2/-msse*），保留功能宏（-DENABLE_THREADS 等）

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
make CC=clang 2>&1 | grep -E "unknown argument.*mavx2"（aarch64 上直接复现）；修复后 make artest && ./artest -s44k -d48k -n3 -i -m -h 通过即验证
```
