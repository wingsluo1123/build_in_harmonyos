# E1467: libmaa: mkc (BSD make/mk-configure) 构建体系与 GNU make 不兼容 — 配方内等价手工编译 + 检测宏注入

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, build-system, make
- **作者**: 1356

## 错误特征
```
\.for|include <mkc\.|SIZEOF_LONG.*undefined|struct rusage.*incomplete
```

## 根因分析
mkc 体系用 .for/.include <mkc.*.mk>，GNU make 无法解析；mkc configure 的 MKC_CHECK_SIZEOF long 与 MKC_CHECK_HEADERS sys/resource.h 检测被跳过，需在 conanfile build() 注入 -DSIZEOF_LONG=8 -DHAVE_HEADER_SYS_RESOURCE_H=1 并 awk 生成 arggram.c 后等价编译

## 推荐方案
**方法**: conanfile.py build(): awk -f arggram2c arggram.txt > arggram.c；-DSIZEOF_LONG=8 -DHAVE_HEADER_SYS_RESOURCE_H=1 -DHAVE_HEADER_ALLOCA_H=1 注入 CFLAGS；全量 24 源 clang 编译；ar/ranlib 静态 + clang -shared 动态；install maa.h。适用于所有 mkc 单目录 C 库（dict 生态）

**说明**: 配方内等价手工编译，绕过 BSD make (mkc) 与 GNU make 不兼容，注入 mkc 检测宏
