# E1468: OHOS musl libc 无 shadow 口令 API（shadow.h 无 getspnam）——依赖该 API 的组件须裁剪或桩化

## 基本信息
- **严重度**: 2
- **类别**: platform, limitation, libc, musl, headers
- **作者**: 1314

## 错误特征
```
incompatible integer to pointer conversion initializing 'struct spwd|undefined symbol: getspnam|undefined reference to .getspnam|implicit declaration of function .getspnam|did you mean: .?getpwnam
```

## 根因分析
shadow 口令数据库 API（getspnam/getspent/sgetspent/getspnam_r）是 glibc 扩展，不属 POSIX。

## 推荐方案
**方法**: disable-optional-component-via-upstream-switch

**说明**: 先用上游/构建系统的能力探测（cmake check_symbol_exists、meson

**修复命令**:
```
cmake: include(CheckSymbolExists); check_symbol_exists(getspnam shadow.h HAVE_GETSPNAM)
```

**验证**:
```
先探测能力，再验裁剪结果：
```
