# E1469: make命令行CFLAGS覆盖Makefile的+=追加导致-DVERSION丢失

## 基本信息
- **严重度**: 2
- **类别**: build-system, compiler
- **作者**: 0E26

## 错误特征
```
use of undeclared identifier \bVERSION\b|-DVERSION missing|command-line variable overrides Makefile CFLAGS \+=
```

## 根因分析
GNU make 中命令行传入的变量覆盖 Makefile 内赋值，且 Makefile 中的 CFLAGS += 追加对命令行变量不生效，导致配方自带的 -DVERSION 等关键宏丢失

## 推荐方案
**方法**: raw Makefile 项目配方只注入 CC 等工具变量，不要传 CFLAGS/CXXFLAGS；确需追加编译参数时用 override 变量或补丁改 Makefile 默认值

**说明**: 只注入 CC，保留 Makefile 自带 CFLAGS 与 += 追加，-DVERSION/-Wall 等宏全部保留

**修复命令**:
```
make -j1 CC="${cc}"
```
