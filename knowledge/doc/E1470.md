# E1470: parse-autotest-banner

## 基本信息
- **严重度**: 1
- **类别**: detection, autotools, testing
- **作者**: 0E20

## 错误特征
```
All [0-9]+ tests were successful|testsuite\.log.*# TOTAL|no_tests|上游测试计数未解析
```

## 根因分析
上游 make check 直接执行 tests/testsuite（原生 autotest），套件只在日志末尾输出汇总横幅（All N tests were successful.），没有 automake 并行驱动的 # TOTAL: 汇总块。只按 # TOTAL: 解析的适配脚本会把 N 个用例当成 0，误判 no_tests 并触发自失败。

## 推荐方案
**方法**: parse-autotest-banner

**说明**: 解析器兼容两种格式：优先 automake 的 # TOTAL:/# PASS: 汇总块，未命中则回退解析 autotest 横幅（All N tests were successful / K of N tests failed / were skipped），并用 tests/*.at 的 AT_SETUP 数交叉校验（本例 12+16+3=31 与横幅一致）。

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
grep -E "All [0-9]+ tests were successful" tests/testsuite.log
```
