# E1471: Conan 2.29 GnuToolchain has no .vars — use extra_env.define()

## 基本信息
- **严重度**: P1
- **类别**: conan, api
- **作者**: 0DA9

## 错误特征
```
AttributeError: .GnuToolchain. object has no attribute .vars.
```

## 根因分析
本仓 OHOS 适配版 conan 2.29.1 的 GnuToolchain 类不再提供 tc.vars 属性，自定义环境变量接口改为 tc.extra_env（Environment 对象）。访问 tc.vars 直接抛 AttributeError。

## 推荐方案
**方法**: 把 tc.vars["K"]="V" 改为 tc.extra_env.define("K", "V")，随后 tc.generate()。

**说明**: 用 tc.extra_env.define() 替代已移除的 tc.vars，变量写入 build scope 的 conanbuild env 文件。

**修复命令**:
```
from conan.tools.gnu import GnuToolchain ; tc = GnuToolchain(self) ; tc.extra_env.define("TAG", self.version) ; tc.generate()
```

**验证**:
```
conan create 后检查生成的 conangnutoolchain.sh 含 export TAG=...；本条由 rtl-wmbus/1.1.0 实测，横幅正确输出 1.1.0。
```
