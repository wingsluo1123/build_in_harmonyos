# E1473: 在本环境对 **wasm 模块**做 Node 端到端，要先解决两条互斥的路径问题——①**裸 `node` 会因 JIT 崩溃**（`Check failed: 12 == (*__errno_location())` + `Signal 5 (core dumped)`，与 E29001 同签名）；②但 **`node --jitless` 下 V8 不支持 WebAssembly**（`ReferenceError: WebAssembly is not defined`）→ 校验脚本应"**先试默认、再试 `--jitless`，谁真把 wasm 跑起来用谁**"，并在**两条证据同时出现**时才把该子项记作具名阻塞。另：wasm-bindgen 模块在 Node 里应走**手动实例化**（`WebAssembly.instantiate(..., {"./x_bg.js": bg})` + `bg.__wbg_set_wasm(instance.exports)`），因为上游 ESM 入口会 `import ... from "./x_bg.wasm"`（Node 直接导入 `.wasm` 受限）；用**合成输入**调用业务函数可能触发 wasm trap（上游用 `syn` 解析源码，非法输入即 panic）→ 该子项按具名证据 SKIP，**其余真跑通过项保留**

## 基本信息
- **严重度**: 3
- **类别**: testing, environment, nodejs, wasm
- **作者**: 0AED

## 错误特征
```
Check failed: 12 == \(\*__errno_location\(\)\)|Signal 5 \(core dumped\)|WebAssembly is not defined|sm-function\[\d+\]:0x|ReferenceError
```

## 根因分析
①本环境的 node 存在 JIT 崩溃问题（缺 `--jitless` 必崩），而 V8 的 jitless 模式**主动禁用 WebAssembly**（两者不可兼得）；②wasm-bindgen 的 ESM 入口面向打包器（browser/webpack），在 Node 里 直接 import `.wasm` 需要实验性标志；③wasm 内的 Rust panic 会表现为 V8 的 wasm stack（`sm-function[N]:0x…`）， 与"环境不可用"外形相似，必须用**证据组合**区分，不能一把梭 SKIP。

## 推荐方案
**方法**: two-path-node-wasm-check-with-manual-instantiation-and-dual-evidence-blocking

**说明**: ①Node 校验脚本先按**默认**方式跑；②再按 `--jitless`（并 `NODE_OPTIONS=--jitless`）跑；③**择优**：哪次输出里真的出现 wasm 导出/业务结果就用哪次；④wasm 加载走**手动实例化**（`WebAssembly.instantiate` + 胶水的 `__wbg_set_wasm`），绕开"Node 不能直接 ESM 导入 .wasm"；⑤断言分层：**wasm 可实例化 + API 面可调用 + 关键类型可构造**＝真跑通过项；业务函数若因**合成输入**trap（`sm-function[…]`/`panicked`），按具名证据记 SKIP 并**明确写上"未以真实输入执行"**（不冒充通过）；⑥**双证据**才允许把"无法执行 wasm"整项记为阻塞：须同时看到 `Check failed … __errno_location`/`Signal 5` **与** `WebAssembly is not defined`；⑦其余失败一律判真实缺陷。

**修复命令**:
```
node check.mjs ; node --jitless check.mjs ; node -e "const b=require('fs').readFileSync('x_bg.wasm');WebAssembly.instantiate(b,{...}).then(r=>console.log(Object.keys(r.instance.exports).length))"
```

**验证**:
```
①`node script.mjs`（默认；看是否出现 `Check failed: … __errno_location` / `Signal 5`）②`node --jitless script.mjs`（看是否 `WebAssembly is not defined`）③Node 内手动实例化：`WebAssembly.instantiate(bytes, {"./x_bg.js": bg})` + `bg.__wbg_set_wasm(instance.exports)` ④跑业务函数看是否 `sm-function[…]` trap
```
