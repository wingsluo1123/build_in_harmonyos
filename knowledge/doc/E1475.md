# E1475: Legacy Maven pom hardcodes source/target 1.5 and JDK 17 rejects it

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, build-system
- **作者**: 0180

## 错误特征
```
Source option 5 is no longer supported|Target option 5 is no longer supported|maven-compiler-plugin
```

## 根因分析
Legacy pom.xml pins maven-compiler-plugin <source>/<target> to 1.5 as explicit plugin configuration; JDK 17 removed javac support for source/target below 7, and an explicit plugin <configuration> outranks the maven.compiler.source property, so a command-line -D cannot override it.

## 推荐方案
**方法**: patch-build-file-compiler-level

**说明**: Raise the compiler level inside the build file itself: patch maven-compiler-plugin <source>/<target> from 1.5 to 8 (>= 7) through patches/0001-*.patch, generated with "ohc-run.py refresh-patch --auto". Do not touch the Java sources.

**修复命令**:
```
mvn clean package -B -DskipTests=false   # after apply_conandata_patches() has applied patches/0001-pom.xml.patch
```

**验证**:
```
sh <maven>/bin/mvn clean package -B   # in a JDK 17 environment, expect "[ERROR] Source option 5 is no longer supported"; grep -A8 maven-compiler-plugin pom.xml | grep -E '<source>|<target>'
```
