# E1476: Libretro 核心消费者测试必须先注册 retro_set_environment 再调用 retro_init，否则 dlopen 后 retro_init 处 Signal 11 段错误

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, ohos, testing, dlopen
- **作者**: unknown

## 错误特征
```
Signal 11 \(core dumped\)|Segmentation fault|139|retro_init.*segfault|retro_set_environment
```

## 根因分析
Libretro ABI 契约要求前端先调用 retro_set_environment() 注册 environ 回调，

## 推荐方案
**方法**: libretro-environ-pre-register

**说明**: 消费者测试（test_package）在 dlopen 后、retro_init 前调用 retro_set_environment 注册

**修复命令**:
```
test_ohos.c 中 set_environment(test_ohos_environ); core_init(); ... core_deinit();
```

**验证**:
```
编译并运行 test_ohos.c（dlopen 核心 + set_environment + init + get_system_av_info
```
