# E1477: ohc-run.py 在仓库工作区运行时 find_project_dir 误指 skill 安装目录，归档/上下文文件写错位置

## 基本信息
- **严重度**: 2
- **类别**: conan, init, init-build, project-dir, tooling
- **作者**: 7669

## 错误特征
```
归档路径出现在 \$HOME/.opendesk/apps/skills/resources/openharmony-compile-agent/archives/|找不到 .build-context-<name>-<ver>
```

## 根因分析
ohc.utils.find_project_dir() 的搜索序：①OHC_PROJECT_DIR 环境变量（要求该目录下有 SKILL.md）②从脚本位置向上找 SKILL.md（skill 安装目录自带 SKILL.md，优先命中）③ATOMCODE_HOME ④~/.opendesk。当在 build_in_harmonyos 仓库工作区执行 ohc-run.py 而未设置 OHC_PROJECT_DIR 时，②先命中 skill 安装目录（\$/storage/.../openharmony-compile-agent，其下有 SKILL.md 且自带完整 archives/ 镜像），归档骨架与 .build-context 被写到 skill 目录而非仓库

## 推荐方案
**方法**: export-project-dir

**说明**: 每次执行 ohc-run.py 前 export OHC_PROJECT_DIR=<仓库绝对路径>（仓库根有 SKILL.md 才生效），同时给子命令带 --project-dir <仓库路径> 双保险（init-build/conan-init/conan-verify/finish/graph 均支持）。若已误建：删除 skill 目录 archives/<字母>/<包名> 误建内容与误生成的 .build-context-*，然后带 --project-dir 重跑

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
echo \$OHC_PROJECT_DIR && ls \$OHC_PROJECT_DIR/archives/<字母>/<包名>/<版本>/manifest.yaml
```
