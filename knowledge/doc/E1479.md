# E1479: OHOS 上 autotools 原生模式 works-check 执行 conftest 被沙箱拦截，必须以 build≠host 交叉规避

## 基本信息
- **严重度**: 3
- **类别**: ohos, autotools, configure, cross-compile, works-check
- **作者**: 2301_76770579
- **来源 PR**: 6705

## 错误特征
```
C compiler cannot create executables|checking whether the C compiler works|conftest|AC_PROG_CC
```

## 根因分析
autoconf 原生模式（--build==--host）下 works-check 会真实执行

## 推荐方案
**方法**: force-cross-build-neq-host

**说明**: conanfile generate() 传 --build=aarch64-unknown-linux-ohos

**修复命令**:
```
CI_PACKAGES="archives/l/libxdamage/1.1.6" zsh ci/conan/build_and_test.sh
```

**验证**:
```
CI_PACKAGES="archives/l/libxdamage/1.1.6" zsh ci/conan/build_and_test.sh
```
