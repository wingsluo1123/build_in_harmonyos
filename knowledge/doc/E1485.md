# E1485: 老版 config.sub 仍含 `-linux*) -> linux-gnu` 改写，ohos 补丁必须在该 case 之前插入 `-linux-ohos*)` 空 case，否则 canonical 三元组被错误改写为 linux-gnu

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, autotools, cross-compile, config.guess
- **作者**: 2301_80739235
- **来源 PR**: 6755

## 错误特征
```
machine `.*-linux' not recognized|system `ohos' not recognized|Invalid configuration `.*linux-ohos'
```

## 根因分析
autoconf 对 --build/--host 三元组调用 config.sub 做 canonical 化。

## 推荐方案
**方法**: config-sub-guess-ohos-portability

**说明**: 先确认 config.sub 版本与是否含 `-linux*) -> linux-gnu` 改写。2021+ 只需：

**修复命令**:
```
CI_PACKAGES="archives/l/libXres/1.2.1" zsh ci/conan/build_and_test.sh
```

**验证**:
```
(patch 后) ./config.sub aarch64-unknown-linux-ohos  # -> aarch64-unknown-linux-ohos
```
