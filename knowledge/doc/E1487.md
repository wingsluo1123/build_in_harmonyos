# E1487: Evidence-bound OHOS test gating and Conan-native packaging for minimal Make projects

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, packaging, testing
- **作者**: BBEA
- **来源 PR**: 7841

## 错误特征
```
bind: Operation not permitted|make: install: No such file or directory|install: command not found
```

## 根因分析
On the OHOS PC runner, pathname AF_UNIX bind is denied even in a user-writable directory, while the minimal device toolset may not provide the GNU install utility. A small Make project can therefore compile successfully but fail in its upstream socket harness or Conan package() stage for two independent platform/tool boundaries.

## 推荐方案
**方法**: evidence-bound-test-gate-plus-conan-copy

**说明**: Probe the platform capability first, gate only the proven unsupported upstream test subset with an explicit environment variable, preserve all supported tests, and use conan.tools.files.mkdir/copy for package outputs when install is unavailable.

**修复命令**:
```
SOCKET99_SKIP_UNIX=1 make -j1 test; conan create <recipe-dir> --build=missing -pr:h=<ohos-profile> -pr:b=<ohos-profile>
```

**验证**:
```
command -v install; run the unmodified upstream socket harness in a writable user directory and record the errno; then run the same harness with an explicit capability gate, build the package with conan create, and execute an installed-package consumer.
```
