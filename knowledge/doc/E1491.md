# E1491: 上游 CPMAddPackage 依赖在禁网 CI 下无法下载：patch 增加 SOURCE_DIR 本地源分支 + conandata 预下载源码

## 基本信息
- **严重度**: 2
- **类别**: portability, network, cmake, test
- **作者**: 392D

## 错误特征
```
CPM: error: Failed to download|
```

## 根因分析
上游 CMake 项目用 CPM.cmake 拉取测试依赖（googletest/zlib 等），

## 推荐方案
**方法**: cpm-addpackage-source-dir-branch

**说明**: 给上游 CPMAddPackage 增加 if(DEFINED <PKG>_LOCAL_SOURCE_DIR) 本地

**修复命令**:
```
CXXGRAPH_GTEST_SOURCE_DIR=${build_folder}/gtest_src CXXGRAPH_ZLIB_SOURCE_DIR=${build_folder}/zlib_src
```

**验证**:
```
配方内 conan create 成功（configure/build/test 全过）+ 测试日志出现
```
