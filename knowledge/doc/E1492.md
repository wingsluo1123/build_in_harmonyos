# E1492: patch-threadlib-m4-force-no-weak

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, autotools, gnulib
- **作者**: unknown

## 错误特征
```
use of undeclared identifier 'pthread_cancel'|
```

## 根因分析
内嵌旧版 gnulib 的 autotools 项目在 OHOS(musl libc) 上,

## 推荐方案
**方法**: patch-threadlib-m4-force-no-weak

**说明**: patch gl/m4/threadlib.m4, 在 AC_CACHE_CHECK

**修复命令**:
```
sed/patch gl/m4/threadlib.m4 + configure gl_cv_have_weak=no
```

**验证**:
```
grep "USE_POSIX_THREADS_WEAK" config.h
```
