# E1494: 旧式 C inline 定义与生成文件依赖导致现代构建失败

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, autotools
- **作者**: 9758

## 错误特征
```
undefined symbol.*(Credit|HostIp2CharIp|FindIp)|use of inline function.*never defined|conf\.tab\.h.*not found
```

## 根因分析
2009 年代 C 源码把需要外部链接的函数定义为 plain inline；现代 clang 的 C99/C23 inline 语义不再提供同样的外部定义，因而链接阶段缺少符号。该源码的 Makefile.in 还未声明 conf.l.o 对 conf.tab.h 的生成依赖，启用并行 make 时会暴露生成顺序竞争。

## 推荐方案
**方法**: add-cflags

**说明**: 在 Conan Autotools 工具链中加入 -fgnu89-inline，保留上游 plain inline 的外部链接语义；同时对该快照使用串行 make，避免 conf.tab.h 生成竞争。

**修复命令**:
```
"toolchain.extra_cflags.append('-fgnu89-inline'); autotools.make(args=['-j1'])"
```

**验证**:
```
"make -j1 && nm -u bandwidthd | grep -E 'Credit|HostIp2CharIp|FindIp' || true; grep -n 'conf.tab.h' Makefile.in"
```
