# E1496: Legacy boolean bitwise operators become Clang -Werror failures

## 基本信息
- **严重度**: 2
- **类别**: compat, compiler, c++, warnings
- **作者**: 5468

## 错误特征
```
error:.*-Wbitwise-instead-of-logical|use of bitwise.*boolean operands|warnings and.*errors generated
```

## 根因分析
Legacy C++ code uses bitwise & between boolean expressions. Clang diagnoses this as -Wbitwise-instead-of-logical, and an upstream -Werror policy turns the warning into a build failure even though the intended operation is logical conjunction.

## 推荐方案
**方法**: source-warning-fix

**说明**: Replace boolean bitwise operators with logical operators when the operands are predicates, preserving the intended short-circuit semantics and keeping the strict warning policy.

**修复命令**:
```
Apply a narrow source patch changing predicate & predicate to predicate && predicate, then rebuild with the original -Wall -Werror command.
```

**验证**:
```
clang++ -Wall -Werror source.cc -o probe; inspect that no -Wbitwise-instead-of-logical error remains
```
