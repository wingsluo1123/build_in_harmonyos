# E1504: EA 家族头文件（eaplatform.h/eastdarg.h）缺少 OHOS aarch64 平台检测分支

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, libc, musl, headers
- **作者**: D384

## 错误特征
```
EA_SYSTEM_LITTLE_ENDIAN.*(undefined|未定义)|va_list_reference.*va_list|EA_PLATFORM_MIN_MALLOC_ALIGNMENT.*(8|16)|pthread_setaffinity_np.*undeclared|pthread_getaffinity_np.*undeclared|pthread_setcancelstate.*undeclared
```

## 根因分析
EA 家族头文件（EABase 的 eaplatform.h / eastdarg.h）平台检测分支未覆盖 OHOS aarch64：

## 推荐方案
**方法**: source-patch

**说明**: 在 eaplatform.h aarch64 Linux 分支补 #define EA_SYSTEM_LITTLE_ENDIAN 1；eastdarg.h va_list_reference 条件追加 (defined(EA_PLATFORM_LINUX) && defined(EA_PROCESSOR_ARM64))；EA_PLATFORM_MIN_MALLOC_ALIGNMENT 以 POSIX 风格条件 (EA_PLATFORM_LINUX && EA_PROCESSOR_ARM64) 设为 8（aarch64 Linux-family malloc 实测最小 8 字节对齐）；EAThread 测试框架以 EA_PLATFORM_LINUX/EA_PROCESSOR_ARM64 组合判定跳过 affinity/cancel 调用（aarch64 通用，不限于单一平台宏、不进交付物）

**修复命令**:
```
见 eabase 0699a15 patches/0001-include-Common-EABase-config-eaplatform.h.patch 与 0002-include-Common-EABase-eastdarg.h.patch
```

**验证**:
```
clang -dM -E -I include/Common <(echo '#include <EABase/eabase.h>') | grep -E 'EA_SYSTEM_LITTLE_ENDIAN'; clang++ -std=c++17 -I include/Common test_ohos/TestEABaseOHOS.cpp
```
