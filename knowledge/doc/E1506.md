# E1506: patch-makefile-uname-whitelist

## 基本信息
- **严重度**: 2
- **类别**: platform, build-system, install
- **作者**: E542

## 错误特征
```
No rule to make target 'install'|make: \*\*\* No targets specified and no makefile found|install target not defined
```

## 根因分析
纯 Makefile 项目（无 configure）在顶层 Makefile 用 ifneq(filter Linux Darwin ..., $(UNAME)) 白名单包裹整个安装规则段，UNAME=HarmonyOS 不在白名单内导致 install 目标与 DESTDIR 目录变量整体未定义，make install 报 No rule to make target 'install'。与 E108（install 命令缺失 Error 127）不同：本条是目标未定义，E108 是命令不存在

## 推荐方案
**方法**: patch-makefile-uname-whitelist

**说明**: 在源 Makefile 的 UNAME filter 白名单中追加 HarmonyOS（R1/R6：改源文件并经 track-edit 记录，补丁由 refresh-patch --auto 生成）；若系统同时缺 GNU install 命令，参照 E108 用 cp -p/mkdir -p 替换 INSTALL/INSTALL_DATA/INSTALL_DIR

**修复命令**:
```
编辑 Makefile: ifneq (,$(filter Linux Darwin ... HarmonyOS , $(UNAME)))
```

**验证**:
```
make -n install
```
