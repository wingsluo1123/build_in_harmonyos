# E1508: clean-verify G0 对无 configure 的 Makefile 项目硬失败属预期（框架 autotools 假设）

## 基本信息
- **严重度**: 1
- **类别**: build-system, make, clean-verify
- **作者**: 24C0

## 错误特征
```
G0.*configure.*failed.*exit 127|./configure: No such file or directory|clean-verify.*configure 失败
```

## 根因分析
clean_verify.py 的 G0 阶段硬编码先执行 ./configure（autotools 框架假设）。纯 Makefile 项目（NetSurf 系 libwapcaplet/libnsutils 等，无 configure 脚本）在此阶段必然 exit 127 失败。此为框架层 G0 的构建系统假设局限，不是配方缺陷；且 clean-verify 属非阻塞门禁（finish [3/10]），权威干净构建可复现验证是 conan-verify G2 的 conan create（从干净源码 build+test）。

## 推荐方案
**方法**: verify-via-conan-create

**说明**: clean-verify G0 configure 失败标记为预期（参考 notes.md 记录），不修改配方伪造 configure；以 conan-verify G2 真实 conan create 作为干净构建验证

**修复命令**:
```
python3 scripts/ohc-run.py conan-verify <软件> <版本>
```

**验证**:
```
python3 scripts/ohc-run.py conan-verify libwapcaplet 0.4.3.2（G2 conan create 通过即视为干净构建可复现）
```
