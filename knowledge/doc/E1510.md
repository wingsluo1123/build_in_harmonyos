# E1510: Windows Conan 配方必须绑定 OHOS SDK toolchain 并固定 Ninja 生成器

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, cmake, cross-compile, conan
- **作者**: 2301_80739235
- **来源 PR**: 8439

## 错误特征
```
C compiler cannot create executables|cannot find -lgcc_eh|MinGW Makefiles|CMakeFiles.*not recognized
```

## 根因分析
Windows 主机仅提供 target clang 路径时，Conan/CMake 仍可能选择 MinGW 生成器和主机链接规则；没有 OHOS SDK toolchain 的系统名、target triple、sysroot、lld 与 compiler-rt，编译器探测会落到 MinGW 并报 -lgcc_eh 或无效 CMakeFiles 目标。

## 推荐方案
**方法**: recipe-self-discover-ohos-toolchain

**说明**: 在 build() 与 package() 的 OHOS 分支自发现 profile user_toolchain、OHOS_NDK_HOME 或设备 SDK 路径，使用官方 ohos.toolchain.cmake、Ninja、OHOS_ARCH=arm64-v8a 和 C++ 标准；host profile 的 user_toolchain 让 test_package 的 CMakeToolchain 继承同一闭包。

**修复命令**:
```
conan create . -pr:h=<ohos-profile> -pr:b=<windows-profile> --build=missing
```

**验证**:
```
conan create . -pr:h=<ohos-profile> -pr:b=<windows-profile> --build=missing; require recipe build and test_package configure logs to bind the same official ohos.toolchain.cmake and Ninja generator; run the frozen target test inventory on HarmonyOS PC
```
