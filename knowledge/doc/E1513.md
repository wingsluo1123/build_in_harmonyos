# E1513: 传递依赖以 visible=False 引用时其 include 目录不进 cpp_info 聚合,裸 Makefile 直连注入缺头(xorgproto/X11-X.h 型)

## 基本信息
- **严重度**: 2
- **类别**: headers, conan, graph, x11
- **作者**: 5219

## 错误特征
```
fatal error: .X11/X.h. file not found|Xlib\.h.*X\.h.*not found|required both with visible=True and visible=False
```

## 根因分析
xorgproto 等纯头文件包被 libx11/libsm/libice 等传递引用且图内 visible=False,其 include 路径不出现在下游包可枚举的 cpp_info 聚合里;CMakeDeps 消费者无感,但裸 Makefile 手工聚合依赖路径的包直接缺头

## 推荐方案
**方法**: force-visible-transitive-headers

**说明**: 配方 requirements() 显式 self.requires("xorgproto/<ver>", force=True) 把纯头包拉为直接依赖,其 include 目录进入 _dep_flags 聚合;识别信号: conan graph WARN 'required both with visible=True and visible=False' 且报错头文件位于传递依赖包内

**修复命令**:
```
self.requires('xorgproto/<ver>', force=True)  # requirements() 中声明为直接依赖
```

**验证**:
```
conan graph info . --order-by=host 确认 xorgproto 已列为直接依赖
```
