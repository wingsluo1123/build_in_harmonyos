# E1514: install-layout-plus-real-consumer

## 基本信息
- **严重度**: 2
- **类别**: build-system, packaging, consumer-validation
- **作者**: 2301_80739235

## 错误特征
```
"installed build metadata not found|NSSHARED.*unset|Makefile.tools.*No such file|consumer.*cannot.*archive"
```

## 根因分析
A build-system-only upstream release can have no compiled artifact, so a package that merely reports a successful no-op build does not prove that its installed makefile fragments are usable. Consumers also fail when the package path is not exported consistently.

## 推荐方案
**方法**: install-layout-plus-real-consumer

**说明**: Preserve the upstream share layout, expose its root through Conan build/run environment metadata, and add a consumer fixture that invokes the installed build fragments with a real compiler and archiver.

**修复命令**:
```
"make test; set NSSHARED=<package>/share/netsurf-buildsystem; make -C <consumer> all"
```

**验证**:
```
"run the upstream test target; assert installed fragment and helper paths; export NSSHARED; compile and archive a small consumer through the packaged fragments"
```
