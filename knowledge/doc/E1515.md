# E1515: 裸 Makefile 多程序包适配:依赖 include/lib 经上游 CMDLINE_CPPFLAGS/CMDLINE_LDFLAGS 钩子注入(零 Makefile 修改)

## 基本信息
- **严重度**: 2
- **类别**: make, conan, flags, injection
- **作者**: 3B7D

## 错误特征
```
make.*CC=.*CMDLINE|bare.*Makefile.*conan|makefile-only.*multi.*program|No rule to make target .check
```

## 根因分析
无 configure 的多可执行 Makefile 工程无法走 AutotoolsToolchain 注入工具链;直接改 Makefile 又违反最小补丁原则

## 推荐方案
**方法**: upstream-cmdline-flag-hooks

**说明**: 上游 settings.make 预留 CMDLINE_CFLAGS/CMDLINE_CPPFLAGS/CMDLINE_LDFLAGS 命令行钩子时,conanfile.build() 直接 make CC=<conf 编译器> CMDLINE_CPPFLAGS=<依赖 include 聚合> CMDLINE_LDFLAGS=<依赖 lib 聚合>;依赖路径遍历 self.dependencies 的 cpp_info 去重聚合;basic_layout 下裸 Makefile 在 source_folder 原地编译,package() 从 source_folder 取产物;E501(单库直连编译)的多程序扩展

**修复命令**:
```
make CC=<conf编译器> CMDLINE_CPPFLAGS='<依赖 cpp_info.includedirs 去重聚合>' CMDLINE_LDFLAGS='<libdirs + libs 聚合>'
```

**验证**:
```
make -n <target> 检查注入的 -I/-L/CC 已出现在命令行
```
