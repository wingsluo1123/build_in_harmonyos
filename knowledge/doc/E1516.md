# E1516: Reconstruct a Debian +ds split source from its matching orig and Debian sidecar before CMake

## 基本信息
- **严重度**: 3
- **类别**: security, debian-repack, licensing, split-source
- **作者**: 2501_91199785

## 错误特征
```
Cannot find source file:.*|No SOURCES given to target
```

## 根因分析
A Debian repacked orig tar can intentionally exclude functional source files while the matching debian.tar carries them and debian/rules copies them into place before configuration. Consuming orig.tar alone therefore makes the untouched upstream CMakeLists refer to absent files.

## 推荐方案
**方法**: checksum-bound-matching-sidecar-restoration

**说明**: Obtain the exact matching Debian source tar, export only the required sidecar files with their hashes, restore them before configure, and update the package license to include their actual license. Keep the official orig tar URL/hash and reject missing or changed sidecar inputs.

**修复命令**:
```
inspect .dsc and debian/rules; export matching sidecar files; verify SHA-256 before copying into source(); run complete target build and tests
```

**验证**:
```
Verify both tarball SHA-256 values against the signed .dsc; inspect debian/copyright Files-Excluded and debian/rules; hash each sidecar file; run conan create, the upstream test driver, and an installed-package consumer on the target.
```
