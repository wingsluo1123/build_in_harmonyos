# E1517: OHOS musl libintl.h 为空壳头:gettext 无声明导致 _() 宏隐式声明编译失败

## 基本信息
- **严重度**: 2
- **类别**: portability, musl, nls, cflags
- **作者**: 1531

## 错误特征
```
incompatible integer to pointer conversion.*fputs\(|call to undeclared function .gettext|_\(x\) gettext\(x\).*error
```

## 根因分析
OHOS <libintl.h> 存在但不声明 gettext(),上游 gettext 本地化宏 _(x) 展开为隐式函数声明,clang15 按 ISO C99 隐式声明返回 int,向 char* 参数传 int 全部报错

## 推荐方案
**方法**: gettext-identity-macro-cmdline

**说明**: 无需源码补丁:CMDLINE_CFLAGS 注入恒等宏 -D'gettext(x)=x'(输出英文消息,与 musl 无 gettext 默认行为一致);注意 make 变量需嵌套引号(外双内单)防括号被外层 shell 剥掉

**修复命令**:
```
make CMDLINE_CFLAGS="$(CMDLINE_CFLAGS) -D'gettext(x)=x'"  # make 变量外双内单引号防括号剥离
```

**验证**:
```
clang -E -D'gettext(x)=x' -xc - <<< 'const char*s=gettext("x");' 无报错
```
