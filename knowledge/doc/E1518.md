# E1518: meson 配置期 compile-and-run 探针 127 —— host 共享依赖不在 LD_LIBRARY_PATH

## 基本信息
- **严重度**: 2
- **类别**: build-system, meson, conan
- **作者**: C112

## 错误特征
```
Checking if "(LOG4CPLUS_INITIALIZER_H|Get Log4cplus version)" .* runs: NO \(127\)|Error loading shared library liblog4cplus\.so\.9|meson\.build:[0-9]+:[0-9]+: ERROR: Unknown variable "log4cplus"
```

## 根因分析
meson 的 dependency() 特性探针是“编译并运行”，探针可执行文件在配置期

## 推荐方案
**方法**: inject-runtime-libdirs

**说明**: 在 conanfile.generate() 中把各 host 依赖的 cpp_info.libdirs 追加进

**修复命令**:
```
env = Environment(); 遍历 self.dependencies.values() 的 cpp_info.libdirs 调 env.append_path("LD_LIBRARY_PATH", libdir); env.vars(self).save_script("conanbuildenv-<pkg>-runtime")
```

**验证**:
```
grep -n -B3 -A3 'runs: NO (127)' <builddir>/meson-logs/meson-log.txt
```
