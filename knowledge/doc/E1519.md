# E1519: OHOS target linker invocations need compiler-relative runtime binding

## 基本信息
- **严重度**: 2
- **类别**: ohos, toolchain, linking, runtime
- **作者**: 2301_80739235
- **来源 PR**: pending

## 错误特征
```
Error loading shared library libxml2.so.16|Error relocating.*lld|unable to execute command
```

## 根因分析
An OHOS worker may invoke the target clang from an SDK whose lld binary depends on shared libraries under the same LLVM installation. If the worker environment does not expose that SDK runtime directory, clang can compile objects but lld fails before producing the target ELF.

## 推荐方案
**方法**: compiler-relative-linker-runtime

**说明**: Derive runtime directories from the exact target compiler path and prepend them only for target compiler invocations. Preserve the existing environment, keep Windows handling separate, and fail if the linker still cannot load a dependency; do not copy shared libraries into global system directories.

**修复命令**:
```
LD_LIBRARY_PATH=<compiler-dir>:<compiler-parent>/lib:$LD_LIBRARY_PATH <target-compiler> <args>
```

**验证**:
```
env LD_LIBRARY_PATH=<llvm-bin>:<llvm-lib> <target-clang> ... -o <target>; read the linker stderr and verify the output ELF exists
```
