# E1521: OHOS CI workers need a source-bound fallback for host-only generators

## 基本信息
- **严重度**: 2
- **类别**: ohos, cross-compile, conan, packaging
- **作者**: 2301_80739235
- **来源 PR**: pending

## 错误特征
```
a build-machine C compiler is required|host compiler unavailable|scdoc-host
```

## 根因分析
An OHOS Conan worker may expose only the target compiler and sysroot. A recipe that unconditionally builds a host generator with gcc or cc fails before packaging even though target compilation is valid. Reusing the target compiler for the host helper would create a target-architecture binary that cannot run on the worker.

## 推荐方案
**方法**: optional-host-generator-with-source-bound-output

**说明**: Detect a real build-machine compiler separately from target tools. When it is unavailable, consume checked-in outputs generated from the matching upstream inputs and fail closed if those outputs are missing; never substitute a target compiler for a host executable. Regenerate outputs when a host compiler is available.

**修复命令**:
```
host_compiler=$(command -v gcc || command -v cc); if [ -n "$host_compiler" ]; then build_host_generator; else copy_verified_prebuilt_outputs; fi
```

**验证**:
```
conan create <recipe>; inspect build log for target compile and host fallback; verify generated files and package contents
```
