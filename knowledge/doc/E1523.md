# E1523: 上游构建系统的 FIND_PACKAGE 探测可能是残余死逻辑，声明 Conan 依赖前先 grep 实际 include

## 基本信息
- **严重度**: 3
- **类别**: build-system, dependency
- **作者**: 69AD
- **来源 PR**: feat/clucene-core-2.3.3.4

## 错误特征
```
Boost not found, using local|FIND_PACKAGE.*Boost|boost not found
```

## 根因分析
clucene 2.3.3.4 的 CMake 仍探测 boost（GET_BOOST_INCLUDE_PATH，找不到时回退 src/ext 捆绑头），但全部源码零 boost include；照搬构建系统探测声明 boost/1.84 会拖入巨型依赖链且无功能收益。

## 推荐方案
**方法**: include-audit-before-requires

**说明**: 对上游源码 grep '#include <pkg/'（排除捆绑目录）确认真实调用面后再声明依赖；探测命中的依赖若零调用则不声明

**修复命令**:
```
grep -rn 'include.*<boost/' src/ --include='*.cpp' --include='*.h' | grep -v /ext/
```

**验证**:
```
ldd 与 nm -u 核对产物无 boost 符号且测试全通过
```
