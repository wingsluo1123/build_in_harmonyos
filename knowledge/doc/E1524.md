# E1524: 上游多线程模式测试在 musl/OHOS 必现 SIGSEGV 时改用上游官方便携（单线程）模式开关

## 基本信息
- **严重度**: 2
- **类别**: portability, threading, test
- **作者**: D4A0
- **来源 PR**: feat/clucene-core-2.3.3.4

## 错误特征
```
cl_test.*SIGSEGV|Segmentation fault.*cl_test|monitored command dumped core
```

## 根因分析
上游 MT 代码存在数据竞争缺陷（如 clucene FSDirectory FSIndexInput::close 的 dounlock 分支 bug），glibc 时序掩盖；musl 调度下必现。上游同时提供官方 OPTION(DISABLE_MULTITHREADING) 便携模式，但该模式宏自 2.3.3.4 位腐烂需修复。

## 推荐方案
**方法**: upstream-portable-mode

**说明**: 用上游官方 DISABLE_MULTITHREADING=ON（Adelie/chimera musl 同口径）并修复该模式缺失宏，全量跑上游测试

**修复命令**:
```
cmake -DDISABLE_MULTITHREADING=ON ..
```

**验证**:
```
make cl_test && ./cl_test（DISABLE_MULTITHREADING=ON 时 159/159 通过）
```
