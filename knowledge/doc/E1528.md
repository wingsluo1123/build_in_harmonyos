# E1528: HarmonyOS Clang 上 Arm 能力寄存器读取必须降级为保守探测

## 基本信息
- **严重度**: 2
- **类别**: detection, ohos, portability, compiler, architecture
- **作者**: 8DAC

## 错误特征
```
expected readable system register|ID_AA64ZFR0_EL1
```

## 根因分析
StringZilla 的 Arm SIMD 能力检测在 HarmonyOS Clang 目标上读取 ID_AA64ZFR0_EL1 等系统寄存器；该寄存器对当前用户态工具链不可读，导致跨编译阶段直接失败。

## 推荐方案
**方法**: ohos-conservative-capability-probe

**说明**: 在 OHOS shared target 复用上游已有的 SZ_AVOID_LIBC=1 保守能力探测路径，避免 Linux POSIX Arm 系统寄存器读取，同时关闭 libc 符号覆盖；不新增平台条件宏。

**修复命令**:
```
Set CMake's OHOS shared target to SZ_AVOID_LIBC=1 and SZ_OVERRIDE_LIBC=0, then validate the Conan consumer.
```

**验证**:
```
使用 ohos-aarch64 Conan profile 构建目标库并运行已安装 C consumer；确认编译、链接和消费者执行均通过。
```
