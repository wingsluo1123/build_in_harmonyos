# E1529: Distinguish an omitted published Guile umbrella header from the obsolete gh interface and propagate its public header closure

## 基本信息
- **严重度**: 3
- **类别**: ohos, conan, dependency, guile, public-header
- **作者**: 2501_91199785

## 错误特征
```
fatal error: 'guile/gh.h' file not found|fatal error: 'libguile.h' file not found|fatal error: 'gmp.h' file not found
```

## 根因分析
The published OHOS Guile 2.2.7.1 binary contains libguile/* but omits libguile.h; a consumer's configure then fails modern API detection and falls back to removed guile/gh.h. Supplying libguile.h exposes GMP and GC headers, which Conan does not propagate to downstream consumers by default.

## 推荐方案
**方法**: version-matched-public-header-overlay

**说明**: Export the exact upstream 2.2.7 libguile.h in the consuming recipe, provide it to configure and the installed package, and mark Guile, GMP, and GC requirements with transitive_headers=True. Keep Guile's published binary unchanged and retain a runtime consumer test.

**修复命令**:
```
exports_sources='patches/*'; copy libguile.h from export_sources_folder into source_folder; prepend source_folder to CPPFLAGS for configure; copy libguile.h into package/include; self.requires('guile/2.2.7.1', transitive_headers=True, transitive_libs=True); self.requires('gmp/6.3.0', transitive_headers=True); self.requires('gc/8.2.12', transitive_headers=True)
```

**验证**:
```
Check the exact Guile package include tree for libguile.h and libguile/*; confirm the upstream header version and SHA; inspect configure feature results; run conan create with upstream tests and an installed-package consumer that compiles, links, and executes.
```
