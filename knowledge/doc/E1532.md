# E1532: Prefer an upstream plain-glob fallback when GNU glob flags are unavailable

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, posix, cmake
- **作者**: 2501_91199785

## 错误特征
```
GLOB_BRACE.*undeclared|use of undeclared identifier 'GLOB_BRACE'
```

## 根因分析
A project may detect glob() and still unconditionally compile GNU-only GLOB_BRACE or GLOB_TILDE. OpenHarmony's musl headers provide glob() without those extensions, so the feature check passes but compilation fails.

## 推荐方案
**方法**: enable-upstream-glob-fallback

**说明**: Inspect the upstream code for an existing flag-free glob path. Enable it via the project's own CMake option, preserving upstream source and testing the resulting behavior on the target.

**修复命令**:
```
CMakeToolchain(self).cache_variables["CVD_INTERNAL_GLOB_IS_BAD"] = True
```

**验证**:
```
Configure libcvd with CVD_INTERNAL_GLOB_IS_BAD=ON; compile on OHOS arm64; run ctest --output-on-failure -j1 (5/5) and the Conan consumer test.
```
