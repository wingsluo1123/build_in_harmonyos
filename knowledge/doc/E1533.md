# E1533: 序列化往返的数据值、引用身份与私有文件语义分层验证

## 基本信息
- **严重度**: 2
- **类别**: functional-oracle, object-graph, private-state, serialization
- **作者**: A139

## 错误特征
```
Roundtrip alias/cycle|Object state|Actual serialized state|Bad owned inode
```

## 根因分析
对象图序列化必须保留协议承诺的引用关系和类型，标量值或版本字符串不能证明该语义；实际文件状态还需独立验证所有权、权限、完整写读与删除。

## 推荐方案
**方法**: value-identity-type-and-owned-file-oracles

**说明**: 序列化往返需要分别验证数据值、共享引用身份、自引用回边和对象类型；实际私有文件再独立验证创建所有权、0600权限、完整写读及删除。只有承诺对象图语义的协议才适用引用身份断言；标量相等不能证明别名或循环被保留。

**修复命令**:
```
serialize actual shared/cyclic graph; deserialize and compare reference identity and class; independently verify owned-file roundtrip
```

**验证**:
```
使用实际解释器执行未改原测试与真实安装消费者，比较原源哈希、TAP程序/计划/结果、实际模块路径和独立原生回执。
```
