# E1534: 对解释型消费者的结构识别补充

## 基本信息
- **严重度**: 2
- **类别**: conan, interpreted-consumer, test-evidence
- **作者**: A139

## 错误特征
```
no_test_sources|Foreign module|Incomplete original full TAP aggregation
```

## 根因分析
固定后缀检查不能识别所有解释型后端，包安装根与解释器系统路径也不能单独证明实际加载来源；必须分别绑定真实前端执行、实际包模块与原TAP完整身份。

## 推荐方案
**方法**: real-interpreter-frontend-and-installed-source-binding

**说明**: 对解释型消费者的结构识别补充：保持原语言文件和源码身份，受支持的前端必须用已声明的实际解释器执行原消费者并保留退出码；同时核验实际安装模块、原程序清单和完整TAP，不能以包装文件存在代替真实依赖或测试。

**修复命令**:
```
<platform-shell> <real-exec-wrapper> <declared-package-interpreter> <original-consumer>
```

**验证**:
```
使用实际解释器执行未改原测试与真实安装消费者，比较原源哈希、TAP程序/计划/结果、实际模块路径和独立原生回执。
```
