# E1537: CMake 原测试驱动必须保全 argv 类型域及字面环境值

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, environment, argv, test-driver
- **作者**: 2301_80739235

## 错误特征
```
direct executable succeeds but CMake wrapper truncates launcher argv or expands literal environment values
```

## 根因分析
macro中的ARGN经文本替换与普通cmake_parse_arguments再次展开；PROGRAM误标单值截断launcher选项和目标路径，字面变量和反斜线随之变化。函数改造若未显式传回结果会让调用者原比较读取错误作用域。

## 推荐方案
**方法**: function-parse-argv-typed-command-result-propagation

**说明**: 改为function和PARSE_ARGV；明确单值配置与多值PROGRAM/ARGS/EMULATOR，保留真实execute_process COMMAND及原期望RC/stderr/输出比较。仅将原驱动需要的结果与过滤流传回PARENT_SCOPE，不串回shell、不删launcher或断言；先逐值子进程比较，再执行原组和完整原套件。 新正式事务 hdf5-official-private-build-220-20261014-standard-marker-r193 使用真实进程UID所有、规范非链接0700私有POSIX目录承载CMake构建与generators，最终安装仍为实际Conan包根。原ctest并行度保持1；同轮原3216个唯一测试、全部四组原Shell测试零失败/跳过，真实双rank MPI消费者1项与原生产溢出场景1项通过。鸿蒙C源SHA-256保持72f434731a9a28dd7ff10953ee636656059b6f354bbc75fd42d8f9666c9e80a5，只移入现行harmony_tests结构并在原测试成功后输出标准成功标记。正式Finish自动生成W3回执，唯一launch、完整回执链、进程归零及release/postrelease独立核验。测试输入tree e99b8ceab3094c99933182b33f65853cf34b5f24，日志SHA-256 ec3d1a3aa59a5f38dd9ee6c58f7d43bef6cea044282f7738b43ec55c31c35f23。保留此前超时、L0结构失败与L1成功标记缺失的真实失败；此结果不代表新HEAD平台CI、提审或制品发布已完成。

**验证**:
