# E1539: 构建工具 stdout 混入 Conan 图 JSON 时的独立报告通道

## 基本信息
- **严重度**: 2
- **类别**: evidence, native-signing, structured-output
- **作者**: 2301_80739235

## 错误特征
```
Extra data.*line 1|JSONDecodeError.*conan-create.*stdout
```

## 根因分析
配方调用的原生子工具继承 stdout，诊断文本与 conan create --format=json 的图对象混流；RC 0 只能证明命令成功，不能证明捕获 stdout 是单一 JSON 文档。将同一通道同时当作人读日志和机器读图会使真实成功构建在控制器中被错误解析或被危险裁剪。

## 推荐方案
**方法**: separate-structured-report-from-process-logs

**说明**: 在冻结前把机器图写入任务私有独立新文件，保留原始 stdout/stderr 不裁剪。RC、图 schema/节点、实际测试清单和产物哈希分别 fail closed。旧解析失败事务保留真实 FAIL，不追认成功；新事务重新完整执行。独立报告不是单凭可解析即接受。

**修复命令**:
```
conan create <recipe> --format=json --out-file=<task-private-new-graph.json>; independently hash and parse graph, retain original stdout/stderr and RC
```

**验证**:
```
使用新事务冻结 conan create --format=json --out-file=<private-new-path>，分别保全 RC、stdout、stderr 和图文件 bytes/SHA-256；核对完整图节点、实际测试分母及目标产物身份。
```
