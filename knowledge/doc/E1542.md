## 错误特征

```
malformed-container-accepted-with-nonzero-exit|version-only-media-test
```

## 根因分析
版本命令只验证可执行性，损坏容器的错误路径且接受 RC 0 或 1 不能证明真实媒体转换可用。只有合法输入经过实际复用和解复用、格式字段及全部样本回读一致，才形成无损数据流证据；跨 libc 的浮点合成还会引入与产品无关的差异。

## 推荐方案
**方法**: deterministic-lossless-dataflow-and-independent-platform-scenario

**说明**: 依据官方支持格式生成仅含整数运算的充分时长 fixture，保持上游代码和测试不变。普通消费者与平台专项用不同样本分别运行；平台专项绑定真实 HarmonyOS/aarch64、HMDFS 私有根、中文空格路径、当前父目录投影属主、输入与输出 SHA256。任何步骤非零退出、数据不同或清理失败都必须失败。

**修复命令**:
```
运行 media_roundtrip.py consumer 和 harmony；消费者七项及平台专项一项分别计数，不将内部断言或三个命令重复计为三项专项。
```

**验证**:
```
用已安装被测包的绝对二进制执行合法 PCM 输入到容器再到 PCM；逐项要求 RC 0、采样率/通道/位宽/帧数一致、全部样本逐字节一致，原始输入哈希不变并清理独占测试目录。
```
