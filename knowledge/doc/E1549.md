# E1549: 特权控制台守护程序的安全 CLI 与签名 HMDFS 证据分层

## 基本信息
- **严重度**: 2
- **类别**: portability, runtime, testing
- **作者**: D310
- **来源 PR**: 13401

## 错误特征
```
TIOCLINUX|codesign|CLI.*特有测试|upstream.*0/0
```

## 根因分析
帮助和版本入口在 VT/input 初始化前退出，三项消费者检查只能证明包布局和安全CLI；它们不能证明控制台后端，也不能只因执行平台是HarmonyOS就计为平台专属测试。源码没有 TESTS/check_PROGRAMS 也不构成0/0=100%。

## 推荐方案
**方法**: source-bound-native-test-and-runtime-closure

**说明**: 从原源码核对早退出顺序，用发布依赖闭包和精确补丁构建守护程序，仅运行 --help/--version。独立检查目标ELF AArch64机器字段及非空.codesign，在HMDFS私有目录进行精确字节搬移、原生加载、退出状态和删除后不存在检查，计为平台运行时测试；VT/TIOCLINUX缺权限则单列未执行。

**修复命令**:
```
设置任务私有 TEMP/TMPDIR 与运行库查找路径；运行原框架，不改断言；按入口与轮次回读 RC。
```

**验证**:
```
核对精确发行源码与候选补丁，执行原测试框架及独立签名 HMDFS 探针，保全进程 RC 和回执链。
```
