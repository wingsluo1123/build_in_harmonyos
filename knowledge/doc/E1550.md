# E1550: Meson 测试权限标签与静态运行库符号的验证边界

## 基本信息
- **严重度**: 2
- **类别**: portability, runtime, testing
- **作者**: D310
- **来源 PR**: 13633

## 错误特征
```
needs-uinput|This test needs to run as root|static-symbols-leak|libc.a
```

## 根因分析
Meson suite 标签描述测试集合，不是 main 的权限门禁。共享标签中的无设备进程仍可执行；完全静态 test-link 还带入平台 libc 的 public 符号，原脚本不能仅凭符号数量把污染归咎于被测库。

## 推荐方案
**方法**: source-bound-native-test-and-runtime-closure

**说明**: 先按实际 main/suite 注册和原框架输出统计进程与断言；TEMP 指向私有目录的修法复用 DRAFT-E571，不重复建立 Check 修复。保留原 test-link.c、libevdev.a 与原静态脚本，仅对平台运行库 libc.a 使用 --exclude-libs,libc.a；通过原断言验证后独立标注解释器适配。

**修复命令**:
```
设置任务私有 TEMP/TMPDIR 与运行库查找路径；运行原框架，不改断言；按入口与轮次回读 RC。
```

**验证**:
```
核对精确发行源码与候选补丁，执行原测试框架及独立签名 HMDFS 探针，保全进程 RC 和回执链。
```
