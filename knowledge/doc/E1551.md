# E1551: PRE_TEST postpones test discovery but not independent POST_BUILD executables

## 基本信息
- **严重度**: 2
- **类别**: cmake, runtime, testing
- **作者**: A715

## 错误特征
```
hwy_list_targets|POST_BUILD|CMAKE_GTEST_DISCOVER_TESTS_DISCOVERY_MODE
```

## 根因分析
The GoogleTest discovery mode affects gtest_discover_tests only; independent custom POST_BUILD commands still execute during cmake.build and require native execution and build-tree shared-library providers at that earlier phase. Conan creates CMake generator directories before recipe generate(); a source BUILD file can collide with the default build directory on a case-insensitive target filesystem. Select a non-colliding cmake_layout build_folder rather than deleting the upstream build-system input.

## 推荐方案
**方法**: separate-build-execution-and-test-discovery-environments

**说明**: Inventory build-time custom commands independently of discovery; provide task-scoped build-tree runtime libraries during cmake.build, sign completed test binaries, then discover and run the full upstream suite. Conan creates CMake generator directories before recipe generate(); a source BUILD file can collide with the default build directory on a case-insensitive target filesystem. Select a non-colliding cmake_layout build_folder rather than deleting the upstream build-system input.
