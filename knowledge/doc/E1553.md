# E1553: Captured Conan test output must survive the command exception

## 基本信息
- **严重度**: 2
- **类别**: conan, testing, logging
- **作者**: A713

## 错误特征
```
Error [0-9]+ while executing.*ctest|upstream tinytest case inventory/result mismatch
```

## 根因分析
ConanFile.run raises on failed commands before code after the call can replay a StringIO buffer, hiding the original CTest diagnostics while retaining only the command error.

## 推荐方案
**方法**: replay-captured-output-in-finally

**说明**: Replay captured output in finally, propagate the original command exception unchanged, and evaluate success inventory only after a zero exit.
