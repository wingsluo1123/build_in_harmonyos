# E1555: VirtualBuildEnv introspection can disable automatic tool-require environment generation

## 基本信息
- **严重度**: 2
- **类别**: build-system, toolchain, conan
- **作者**: 2501

## 错误特征
```
meson: inaccessible or not found|Required .* executable unavailable
```

## 根因分析
Conan VirtualBuildEnv constructor defaults auto_generate=False and immediately disables conanfile.virtualbuildenv. A temporary vars().apply() used only for tool-path introspection can therefore suppress the later automatic buildenv generation, even after a toolchain requested it. Installed tool packages are present but disappear from self.run PATH.

## 推荐方案
**方法**: preserve-automatic-buildenv-generation

**说明**: Use VirtualBuildEnv(self, auto_generate=True) at every temporary introspection call. Alternatively generate the build environment explicitly once. Require genuine existing declared tools; do not replace tool_requires with ambient tools. auto_generate=True does not restore an already-disabled flag.

**修复命令**:
```
with VirtualBuildEnv(self, auto_generate=True).vars().apply():
```

**验证**:
```
Inspect constructor flag changes; inspect generated conanbuild script; run native conan create with the same declared tool dependencies.
```
