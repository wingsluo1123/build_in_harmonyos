# E1556: 目录视图测试须保留父子视图与配置映射，生命周期断言不可比较释放地址

## 基本信息
- **严重度**: 3
- **类别**: portability, configure, testing
- **作者**: 2301

## 错误特征
```
duplicate cache after directory remapping|cache basename mismatch|freed pointer equality
```

## 根因分析
不同执行域的测试布置不能直接复制；子进程路径映射会污染父进程的预期枚举，空占位目录会生成额外缓存，重复目录声明会覆盖已有映射；释放地址也可能被分配器复用，不能证明对象生命周期。

## 推荐方案
**方法**: preserve-test-semantics

**说明**: 用任务私有且可恢复的目录映射布置目标语义，只在原生子命令期间切换视图，执行前校验路径归属并在返回前恢复；保留配置的映射与不可见占位语义及全部原始断言；生命周期用可观测哨兵状态和故意保留状态的负测验证。

**验证**:
```
frozen upstream-r8 five positive repetitions and retained-state negative; frozen upstream-r11 test_sandbox.py real 5/5 with zero skips
```
