# E1557: Autoconf 已探测科学计算依赖但手写 Makefile 链接线忽略 @LIBS@：

## 基本信息
- **严重度**: 2
- **类别**: autotools, fortran, conan, runtime, testing
- **作者**: ohpcd <ohpcd@localhost>
- **来源 PR**: 11647

## 错误特征
```
undefined symbol: _FortranA.*|
```

## 根因分析
这是三个可独立验证的契约断裂叠加。① configure.ac 用

## 推荐方案
**方法**: preserve-autoconf-provider-result-and-audit-elf-topology

**说明**: 给 AutotoolsToolchain 只追加每个 Conan 依赖的 include/lib

**修复命令**:
```
tc.extra_cflags/cxxflags += -I<dep.include>;
```

**验证**:
```
grep -nE 'AC_(CHECK_LIB|SEARCH_LIBS)' configure.ac;
```
