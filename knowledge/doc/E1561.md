# E1561: Debian-native 源码包无 configure 且 po4a 子目录缺 po4a-translate 即 exit 1：单文件 C 工具绕过 autotools 直接编译，且 --version 回显上游内置版本而非包版本

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, autotools, conan, testing
- **作者**: 8735

## 错误特征
```
po4a-translate not installed, failing to rebuild changed man page translation|
```

## 根因分析
Debian 自家维护（native）的源码包（debianutils 等）只发布 configure.ac/Makefile.am，

## 推荐方案
**方法**: direct-compile-single-c-file

**说明**: 配方不跑 autoreconf/configure：只取目标 C 文件直接编译，手工提供 config.h 宏

**修复命令**:
```
clang -O2 -fPIE -DPACKAGE_VERSION='"5.23.1"' -DHAVE_GETOPT_H -DHAVE_PATHS_H -D_FILE_OFFSET_BITS=64 run-parts.c -o run-parts -static-pie
```

**验证**:
```
grep -n "TRANSLATE = " po4a/de/Makefile.am; grep -n "DEBIANUTILS_VERSION" acinclude.m4;
```
