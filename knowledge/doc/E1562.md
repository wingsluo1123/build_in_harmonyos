# E1562: 包内 XML 配置、启用模板与应用缓存必须分别绑定

## 基本信息
- **严重度**: 3
- **类别**: portability, configure, testing
- **作者**: 2301

## 错误特征
```
Cannot load default config file|Expected upstream relative conf.d include|Missing regular packaged config template
```

## 根因分析
共享库和头文件交付不能证明运行时配置可用；硬编码系统配置路径在沙箱内可能缺失，conf.d 的启用软链接可能逃出安装根，而把缓存放在共享只读包中会造成写权限和消费者间污染。

## 推荐方案
**方法**: explicit-runtime-config

**说明**: 安装阶段校验 XML 根与相对 include 并保留规则，仅实体化启用且同名的包内模板；消费者按当前 package_folder 绑定配置路径，缓存由应用独立选择，缺失/非法配置必须显式失败。

**验证**:
```
python test_fontconfig_21833_local.py; conan create archives/f/fontconfig/2.18.3.3 --build=fontconfig/*; target consumer must separately load config, enumerate fonts and match a real file
```
