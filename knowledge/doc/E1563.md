# E1563: Automake 发布包携带检查源码但检查目录不在 SUBDIRS，顶层 make check 成功却未生成检查程序

## 基本信息
- **严重度**: 3
- **类别**: detection, build-system, autotools, make, testing
- **作者**: YDPB

## 错误特征
```
misc/ydpstress.*inaccessible or not found|Error 127 while executing.*misc/ydpstress
```

## 根因分析
DIST_SUBDIRS 控制发布内容，SUBDIRS 控制递归构建；libydpdict 1.0.4 的 misc 只在 DIST_SUBDIRS，所以顶层 make check 未进入 misc，四个 check_PROGRAMS 未构建；该目录又没有 TESTS，显式构建后仍须逐个执行，不能把 make 返回 0 计为程序通过。

## 推荐方案
**方法**: explicitly-build-omitted-check-directory

**说明**: 先清点发布源码及递归目录；顶层 check 后在已生成的构建目录执行 make -C misc check，再准备合成词典并逐个执行四个上游程序，检查返回码；原生运行和交叉编译分栏记录。

**修复命令**:
```
make check && make -C misc check
```

**验证**:
```
python3 archives/l/libydpdict-1.0.4/https-github.com-wojtekka-libydpdict/build_support/verify_upstream_census.py --source-archive libydpdict-1.0.4.tar.gz && conan create archives/l/libydpdict-1.0.4/https-github.com-wojtekka-libydpdict -pr:h ci/conan/profiles/ohos-aarch64 -pr:b ci/conan/profiles/ohos-aarch64 --build="libydpdict-1.0.4/*" -nr
```
