# E1564: 纯 Perl 包的 autotools 探测/测试执行目标架构 perl，x86 构建机无法运行（模块探测为空 + PERL5LIB 污染主机 perl）

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools, cross-compile, testing
- **作者**: GCW8

## 错误特征
```
aarch64-binfmt-P: Could not open '/lib/ld-musl-aarch64.so.1'|Can't load '.*aarch64-linux-thread-multi/auto/.*\.so' for module|modtest.*(no|yes)|checking for JoeDog::Config support|Can't locate JoeDog/Config\.pm in @INC
```

## 根因分析
仓库的 perl 依赖（perl/5.42.2.x）是 aarch64-linux-ohos 的 musl 动态 ELF。x86 构建机/runner 上 binfmt 只能

## 推荐方案
**方法**: recipe-equivalent-substitution-and-scoped-perl5lib

**说明**: 不跑上游 configure/Makefile，在 build() 用 Python 复刻 sed 替换与自带模块安装；测试里逐候选 perl 单独设 PERL5LIB

**修复命令**:
```
"build(): 读 src/*.in 做 %_VAR% 替换、shebang 指向依赖 perl 绝对路径、用 tarfile 直接取出自带 .pm 装到 lib/<pkg>/；test: 对每个 perl 候选用 subprocess 试 `perl -e 'use LWP::UserAgent'`，仅对 shebang 所指依赖 perl 继承 conanrun 的 PERL5LIB，其余候选剔除之"
```
