# E1565: OHOS 根文件系统没有 /var：硬编码 FHS 路径（/var/lock 等）的锁文件/pid 文件需回落到可写运行目录

## 基本信息
- **严重度**: 2
- **类别**: platform, limitation, portability, filesystem
- **作者**: 66BA

## 错误特征
```
Cannot create the lockfile /var/lock/.*|/var/lock.*No such file or directory|/var/run.*No such file or directory|/var/spool.*No such file or directory
```

## 根因分析
OpenHarmony 根文件系统**没有 /var 目录**（/var/lock、/var/run、

## 推荐方案
**方法**: runtime-dir-fallback

**说明**: 把固定路径改为“候选目录列表 + 首个可写者”策略：按

**修复命令**:
```
static const char *dirs[] = {getenv("APP_LOCKDIR"), "/var/lock", getenv("XDG_RUNTIME_DIR"), getenv("TMPDIR")}; /* 取首个 access(W_OK) 且 snprintf 未截断者 */
```

**验证**:
```
ls -d /var ; ls -d /var/lock ; touch /var/lock/probe → 全部报 No such file or directory
```
