# E1566: 依赖的 ncurses 以 NCURSES_OPAQUE=1 生成头文件：访问 WINDOW 内部字段编译失败，需换 getmaxx()/getmaxy()/clearok() 公共 API

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, portability, headers
- **作者**: 7C36

## 错误特征
```
member access into incomplete type 'WINDOW'|incomplete type 'WINDOW' \(aka '_win_st'\)|forward declaration of '_win_st'|_maxx|_maxy|_clear
```

## 根因分析
制品仓的 ncurses 包按 --enable-opaque-curses 生成头文件，

## 推荐方案
**方法**: opaque-api-translate

**说明**: 用公共 API 等价替换内部字段访问：

**修复命令**:
```
maxx = getmaxx(stdscr); maxy = getmaxy(stdscr); clearok(main_window, TRUE);
```

**验证**:
```
grep -n "NCURSES_OPAQUE" <ncurses_pkg>/include/curses.h → "#define NCURSES_OPAQUE       1"
```
