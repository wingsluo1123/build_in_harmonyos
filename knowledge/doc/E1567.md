# E1567: Chunked EXIF scanners must track marker discovery and reset stream state before seeking

## 基本信息
- **严重度**: 2
- **类别**: c++, testing, image-parser, stream-state
- **作者**: tank_you

## 错误特征
```
"No EXIF/TIFF data found|return code 0 without EXIF fields"
```

## 根因分析
The scanner initialized its marker-found flag to true, so it stopped after the first buffer even when the marker was later in the file. A short final read also set failbit together with eofbit; clearing only eofbit left subsequent seekg in a failed state. The CLI still returned zero without EXIF output.

## 推荐方案
**方法**: marker-state-and-seek-repair

**说明**: Initialize the found flag to false, set it only on a full marker match, preserve overlap across chunk boundaries, and clear stream state before seekg after a recoverable EOF. Keep genuine I/O errors distinguishable from expected short reads.

```

```

**验证**:
```
"Run the installed consumer CLI on TIFF, late-marker JPEG, short JPEG and buffer-split EXIF fixtures; assert exit status and parsed field content."
```
