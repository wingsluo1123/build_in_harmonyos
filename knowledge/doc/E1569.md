# E1569: 有限生命周期程序的后台 stdin 读取：区分 EOF 忙循环与 stdio 锁阻塞退出

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, posix, threading, testing
- **作者**: 2501

## 错误特征
```
TimeoutExpired.*timed out after|finite timer.*stdin|background.*fgetc.*exit
```

## 根因分析
后台键盘监视线程把 stdin 流读取与有限生命周期进程的退出耦合；EOF 未处理会继续循环，保持输入打开时阻塞的 fgetc 则可能占有 stdio 流锁。仅用关闭输入的测试不能证明正常退出边界。

## 推荐方案
**方法**: descriptor-input-watcher-with-independent-eof

**说明**: 单一输入所有者以 read(STDIN_FILENO,&byte,1) 读取按键，EINTR 重试，EOF/真实输入错误只结束监视线程，不冒充有限任务完成；保持计时任务自己的回调与退出码。

**修复命令**:
```
使用 read 的 ssize_t 返回值判断 0/负值；不要把 EOF 分支接到成功退出回调。
```

**验证**:
```
conan create <recipe> -pr:h=<native-profile> -pr:b=<native-profile> --build=<package>/*; 分别验证关闭 stdin 与保持 stdin 打开时有限命令自然退出且没有发送退出键或信号。
```
