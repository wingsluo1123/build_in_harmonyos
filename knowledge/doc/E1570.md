# E1570: CLI 程序只有可执行文件时，用真实工具产出驱动消费者编译和运行

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, conan, testing
- **作者**: 5752

## 错误特征
```
规则 12.*鸿蒙特有测试.*N=0|CLI.*test_package.*仅.*断言|consumer.*only.*checks.*file
```

## 根因分析
CLI 包不暴露可链接库，test_package 容易退化成文件存在性或符号断言；即使执行 CLI，未让包的真实输出进入消费者构建和运行，也不能证明鸿蒙平台消费者端到端行为。

## 推荐方案
**方法**: cli-output-compiled-consumer

**说明**: Conan test_package 引用 tested_reference_str，运行包内静态 OHOS CLI 处理实际输入；将 CLI 产出的字节数据生成为 C 头文件，再由目标 clang 编译并用 qemu 执行 C 消费者验证输出字节；三段过程全部进入 conan create 必跑路径，并留命令、退出码及输出证据。

**修复命令**:
```
python3 scripts/ohc-run.py conan-verify sickle 1.33-git20150314.f3d6ae3
```

**验证**:
```
conan create <recipe-dir> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing; grep -E 'FastQ records kept: 1|OHOS consumer: gzip FASTQ processed' <recipe-dir>/reports/conan-create.log
```
