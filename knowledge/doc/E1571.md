# E1571: XS 加载不兼容时保留原生成器：按解析树数据契约替换 parser 而非重写生成代码

## 基本信息
- **严重度**: 3
- **类别**: portability, conan, code-generation
- **作者**: 2501

## 错误特征
```
PL_markstack_ptr.*symbol not found|XML::Parser.*Expat.*load
```

## 根因分析
动态 XS 库引用解释器未导出的 ABI 符号；模块搜索路径正确不等于 ABI 兼容。生成器真正消费的是有序 Tree 数据，不是 XS 本身。

## 推荐方案
**方法**: parser-data-contract-bridge

**说明**: 保留原生成器，将 parser 输出序列化成原 Tree 的有序交替结构，以解释器核心 JSON 模块读回；保留默认属性、CDATA 与相邻字符数据，不接入任意网络或外部实体。

**修复命令**:
```
先确认真实加载错误和解释器 ABI；明确 parser 数据契约并限定实体输入；从同一发行包完整生成和编译全部输出，核对插件 ID 和真实处理结果。
```

**验证**:
```
对照原 Tree 的节点、属性、文本合并和本地 DTD 语义；运行未删减的原校验器、原生成器、全部模块构建以及安装消费者。
```
