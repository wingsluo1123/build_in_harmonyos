# E1573: autotools install-sh 无条件调用 `id` 判非 root；OHOS 无 id/chown 命令 → test 语法错 + chown not found → make install Error 127

## 基本信息
- **严重度**: 2
- **类别**: build-system, install
- **作者**: D674

## 错误特征
```
install-sh.*: id: inaccessible or not found|
```

## 根因分析
autotools install-sh 无条件执行

## 推荐方案
**方法**: real-uid-fallback

**说明**: 给 install-sh 打补丁：REAL_UID=$OWNER 之后加

**修复命令**:
```
patch install-sh: 在 REAL_UID=$OWNER 后加
```

**验证**:
```
command -v id || echo "no id"
```
