# E1574: OHOS musl libc 缺 glibc/BSD 专属符号（rindex、re_comp/re_exec、versionsort、HZ、qsort_r）——逐个移植标准等价物

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, compilation
- **作者**: D674

## 错误特征
```
implicit declaration of function 'rindex'|
```

## 根因分析
OHOS 基于 musl libc，若干 glibc 下"默认存在"的

## 推荐方案
**方法**: portable-equivalent

**说明**: 逐个替换为标准 C/POSIX 等价物：rindex→strrchr；

**修复命令**:
```
sed -i 's/\brindex(/strrchr(/g' file.c  # 仅当参数模式吻合时
```

**验证**:
```
grep -rn "rindex(\|re_comp(\|versionsort\|\bHZ\b\|qsort_r" \
```
