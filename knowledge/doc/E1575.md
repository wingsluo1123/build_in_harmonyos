# E1575: 上游无 git tag 的库：任务版本取自 cmake_minimum_required 等源码版本声明，conandata 官方源固定官方 commit 归档 + 实测 SHA-256

## 基本信息
- **严重度**: 2
- **类别**: portability, conan, sourcing, versioning
- **作者**: DEA1

## 错误特征
```
404.*tar.gz|Unable to find .*tag|not found.*archive|remote:.*tags|git ls-remote.*空|empty tags
```

## 根因分析
部分上游仓库不发布 git tag/release（如 README 直接指向 master 单文件），

## 推荐方案
**方法**: pin-official-commit-archive

**说明**: 以任务版本建归档目录；conandata sources.url 固定官方 master/指定 commit 的

**修复命令**:
```
curl -sSL <official commit archive URL> | sha256sum; 写入 conandata.yml
```

**验证**:
```
git ls-remote --tags <upstream>; curl -sI https://codeload.github.com/<owner>/<repo>/tar.gz/<commit>
```
