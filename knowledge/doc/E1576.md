# E1576: 单头文件 C++ 库缺 #include <system_error>：OHOS libc++ 无传递包含致消费者编译失败（上游 doctest include 顺序掩盖）

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, conan, libc++
- **作者**: DEA1

## 错误特征
```
no member named 'system_error' in namespace 'std'|no member named 'system_category' in namespace 'std'|invalid library name in argument '-stdlib=libstdc++'
```

## 根因分析
源码头文件使用了 std::system_error / std::system_category() 却未显式

## 推荐方案
**方法**: add-system-error-include

**说明**: 在头文件中显式加入 #include <system_error>（源码补丁或 conandata patches），保证头文件自包含

**修复命令**:
```
patch 添加 `#include <system_error>` 于 include 区（patch_ng / GNU patch 均可）
```

**验证**:
```
/data/service/hnp/bin/clang++ -std=c++17 -Wall -Wextra -Werror -I include -x c++ -fsyntax-only <consumer.cpp> （仅含该公开头）
```
