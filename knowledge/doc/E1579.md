# E1579: C API target probes must exercise the required handle lifecycle before CRUD calls

## 基本信息
- **严重度**: 2
- **类别**: ohos, conan, testing, api-lifecycle
- **作者**: 2301_80739235

## 错误特征
```
"DB->put: method not permitted before handle's open method|HARMONY_TEST_PASS=1/1"
```

## 根因分析
A target probe called a Berkeley DB handle's put method immediately after db_create, but Berkeley DB requires the handle to be opened with a database type and path before any CRUD operation. The host consumer passed because it used the complete open-put-get-close lifecycle, while the HarmonyOS-specific probe bypassed that contract and failed at runtime.

## 推荐方案
**方法**: lifecycle-complete-target-probe

**说明**: Model the target probe on the library's documented state machine: create, configure/open, perform the minimal operation, close, and remove task-local artifacts on every exit path. Keep the probe independent from host-only behavior and bind it to the exact package include/library tree.

**修复命令**:
```
"cc -I<package>/include <probe.c> -L<package>/lib -Wl,-rpath,<package>/lib -l<library> -o <probe>; <probe>"
```

**验证**:
```
"compile the probe against the frozen package; execute it with the package runtime closure; require HARMONY_TEST_PASS=1/1 and verify the temporary database path is absent after exit"
```
