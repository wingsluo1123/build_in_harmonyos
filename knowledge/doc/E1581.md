# E1581: OHOS SDK 头文件警告 + 上游 -Werror → meson project_options werror=false

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, meson, compiler, warnings
- **作者**: unknown

## 错误特征
```
CMSG_NXTHDR.*signedness|sys/socket\.h:.*warning.*expanded from macro|warning:.*comparison of integers of different signedness.*-Werror
```

## 根因分析
OHOS SDK 的 sys/socket.h 中 CMSG_NXTHDR 宏展开（__CMSG_LEN(cmsg) + sizeof(struct cmsghdr) >= __MHDR_END(mhdr) - (unsigned char *)(cmsg)）产生无符号/有符号比较警告；上游 meson 工程 default_options 开启 werror=true，将 SDK 头文件自身的警告升级为编译错误。问题不源于目标库源码。

## 推荐方案
**方法**: meson-werror-off

**说明**: 在 generate() 中对 MesonToolchain 设置 tc.project_options["werror"] = "false"（仅 OHOS 平台），从 native 配置层面关闭警告升级；无需源码补丁，不影响上游文件。

**修复命令**:
```
# conanfile.py generate(): if self.settings.os == "OHOS": tc.project_options["werror"] = "false"
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
