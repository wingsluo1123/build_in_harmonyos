# E1582: CMake 4 不识别 HarmonyOS 平台导致 SONAME 缺失：LINK_FLAGS 显式 -soname + RUNPATH 修复

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, linking
- **作者**: 49C8

## 错误特征
```
System is unknown to cmake|readelf.*-d.*无 SONAME|NEEDED.*\.\./.*\.so|Error loading shared library \.\./.*\.so|SONAME.*not set
```

## 根因分析
CMake 4.1.2 不识别 HarmonyOS 平台（configure 报 "System is unknown to cmake"，

## 推荐方案
**方法**: soname-link-flags-injection

**说明**: 绕过 CMake 平台命名机制：在共享库 target 的 set_target_properties 中

**修复命令**:
```
set_target_properties(razer PROPERTIES LINK_FLAGS "-Wl,-soname,librazer.so");
```

**验证**:
```
1) cmake -B build 2>&1 | grep "System is unknown to cmake" 确认平台不识别;
```
