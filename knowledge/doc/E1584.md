# E1584: 精简 zsh 有版本号却缺函数与模块，发布包测试素材也可能缺失

## 基本信息
- **严重度**: 2
- **类别**: shell-runtime-completeness
- **作者**: tank_you

## 错误特征
```
is-at-least function definition file not found|failed to load module zsh/mapfile|read-only file system /tmp
```

## 根因分析
HarmonyOS PC 提供 zsh 5.9 可执行文件但未安装标准 autoload 函数和可选模块；zshdb 默认这些组件与可写 /tmp 都存在，1.1.4 发布包还漏装一个集成用例的三份素材。

## 推荐方案
**方法**: probe-shell-components-and-preserve-upstream-test-evidence

**说明**: 分别验证 zsh 版本、fpath 函数和模块；缺 mapfile 或 PCRE 捕获时提供功能等价降级；临时文件使用私有 TMPDIR；发布包缺测试素材时与同版本官方标签逐字节核对。

**修复命令**:
```
'zsh --version; zsh -fc "autoload -Uz is-at-least; is-at-least 5.4.1"; zsh -fc "zmodload zsh/mapfile"'
```

**验证**:
```
conan create with OHOS armv8 profile; make -j1 check; installed-package debugger consumer test
```
