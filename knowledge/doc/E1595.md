# E1595: Catch2 v2（含源码包内置 2.9.2 单头）不支持 `-r <reporter>::<file>`：须用 `-r <reporter> -o <file>` 才能把 per-case XML 落盘

## 基本信息
- **严重度**: 3
- **类别**: cli-usage, test-framework
- **作者**: unknown

## 错误特征
```
Unrecognized reporter, '.*::.*'\. Check available with --list-reporters|Unrecognized reporter
```

## 根因分析
Catch2 v3 起 `-r, --reporter <reporter[::output-file]>` 支持 `::` 指定输出文件；v2（含各项目随源码包内置的单头 `catch2.hpp`，实测 2.9.2）的 `-r` 只接受 reporter 名，`::` 会被整体当成 reporter 名 → “Unrecognized reporter”。v2 用独立的 `-o, --out <file>` 指定输出文件。

## 推荐方案
**方法**: v2 用 `-r <reporter> -o <file>`；先 `--list-reporters` 确认可用 reporter 集合

**说明**: (1) 用 `-r junit -o upstream_junit.xml`（实测 rc=0，XML 落盘）；(2) 需要同时看控制台摘要时，跑两次（compact 到 stdout + junit 到文件）比赌多 reporter 语法更稳；(3) 先 `./<bin> --list-reporters` 查可用集合：v2.9.2 实测为 compact/console/junit/xml 四个；(4) 若测试计数口径要求“用例级”，注意 junit reporter 在 v2 里按 **SECTION 路径**出 testcase（tuning 实测 61 条 = 61 个 section），TEST_CASE 总数仍以 `--list-tests` 末尾的 “N test cases” 为准。

**修复命令**:
```
./tuning-library-tests --list-reporters && ./tuning-library-tests -r junit -o upstream_junit.xml && ./tuning-library-tests --list-tests
```

**验证**:
```
./<tests-bin> -r junit -o upstream_junit.xml && python3 -c "import re,sys;print(len(re.findall(r'<testcase', open('upstream_junit.xml').read())))"
```
