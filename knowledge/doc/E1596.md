# E1596: 纯 Rust rlib 库的 OHOS 适配组合拳：工具链/运行库签名 + rustlib 实体复制 + cargo 的 OpenSSL≥3.5 门 + 用 clang-15 ELF 取代 SDK 包装脚本作 linker

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, toolchain, linking, rust
- **作者**: AB38

## 错误特征
```
'can.t find crate for .(std|core).|may not be installed|SSL_get0_group_name: symbol not found|Error loading shared library libssl\.so|Permission denied \(os error 13\).*bin/cargo|could not exec the linker|ld\.lld: error: cannot open Scrt1\.o|unable to find library -lc|Text file busy \(os error 26\)|Package type is .library., but no .shared. option declared|BadZipFile: File is not a zip file|NotFoundException: Not found: https://harmonybrew\.atomgit\.com/bottles/zlib'
```

## 根因分析
五个互相独立、按暴露顺序出现的问题，全部源于「cargo 工程 × OHOS loader/签名策略 × SDK 包装脚本」：

## 推荐方案
**方法**: stage-signed-toolchain-real-rustlib-clang15-elf-linker

**说明**: 在 build folder 内自建签名工具链（copytree rustlib + 签名 bin/so），cargo config 指定

**修复命令**:
```
binary-sign-tool sign -inFile <bin> -outFile <bin>.signed -selfSign 1; cp -a <toolchain>/lib/rustlib <build>/rust-toolchain/lib/rustlib; cargo build --release --target aarch64-unknown-linux-ohos
```

**验证**:
```
rustc --print sysroot; cargo --version; readelf -d <bin> | head; rustc --print cfg --target aarch64-unknown-linux-ohos
```
