# E1602: W3 的 predl「还原」会把 CI 注入的镜像 URL 永久写回 conandata.yml（日志声称还原成功、构建全绿），提交前必须人工 git diff 核对并还原

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, build-system, ci-script, r39
- **作者**: unknown, 主理-34
- **来源 PR**: (pending)

## 错误特征
```
gh-proxy\.com|ghfast\.top|Source URLs rewritten with mirror fallback|conandata\.yml 已还原为官方 URL|Pre-downloaded 2 files|mirror fallback.*residue|conandata.*mirror.*pollution
```

## 根因分析
`ci/conan/build_and_test.sh` 的两个步骤顺序颠倒导致原始内容不可恢复：(1) 镜像回退改写（replace_url/get_mirrors）先把 conandata.yml 的 `url:` 单值行就地改写成 `url:` + 镜像 + 官方的列表并写回磁盘；(2) Pre-download 阶段才执行 `cp "$CONANDATA" "$PREDL_BACKUP"` 取备份——由于此时文件已被改写，备份里存的是镜像版；(3) 预下载再把 URL 全部替换成 file:// 路径；(4) 退出时 `trap _restore_conandata EXIT` 从备份还原，于是「还原为官方 URL」实际写回的是镜像列表。原始单值 URL 在步骤 (1) 写回磁盘那一刻就已丢失，文件内没有任何副本可恢复。污染是静默的：改写成 2 条 URL 后预下载把两份都下成功（日志 `Pre-downloaded 2 files` 即特征），构建不受影响，W3 全绿并打印「已还原为官方 URL」，只有 git diff 才看得到。gh-proxy.com/ghfast.top 属 PF7/R39 的镜像域名黑名单（14 域），一旦提交即命中硬闸，并会被 W4 独立审计判 P1（verdict=fail）。

## 推荐方案
**方法**: post-finish-diff-and-revert-conandata-plus-residue-cleanup

**说明**: (1) 每次 `finish`（W3）结束后、提交之前，对版本目录执行 `git diff -- archives/` 并逐行读一遍，重点确认 conandata.yml 的 `sources.url` 仍是**单值官方 https 源**、manifest.yaml 的 `source.url` 一致；发现镜像前置（gh-proxy.com / ghfast.top / ghproxy.* / kkgithub.com / moeyy.* / fastgit.org / cnb.cool 等 14 域）立即还原为官方单值 URL。(2) 同时清理 `conandata.yml.ghfast-bak`、`conandata.yml.orig`、`*.predl-orig` 等备份残留（JC3 以 `\.(bak|orig|rej|ghfast-bak)$` 拦截，进了提交即 fail）。(3) 不要把「构建通过」当作配文件正确的证据——本族缺陷的判定信号是 `git diff`，不是退出码；也不要因为 `conan-verify` 通过就跳过这一步（两者只共享下载缓存，不共享还原逻辑）。(4) 特征串速查：W3 日志里出现 `Source URLs rewritten with mirror fallback` + `Pre-downloaded N files`（N≥2 说明 url 已被改成列表）+ 结尾 `conandata.yml 已还原为官方 URL`，三者同时出现即高度可疑，必须去看 diff。(5) 该缺陷在 CI 侧修法是把 `PREDL_BACKUP=...; cp` 挪到镜像改写之前，但适配 PR 不应改 `ci/` 框架文件（W2 原子性），故只能提交前人工核对与还原。

**修复命令**:
```
git diff -- archives/l/libfuse/ | head -40 ; /usr/bin/rm -f archives/l/libfuse/3.16.1/conandata.yml.ghfast-bak archives/l/libfuse/3.16.1/conandata.yml.orig
```

**验证**:
```
git diff -- archives/ | grep -nE "gh-proxy|ghfast|ghproxy|mirror" ; git status --short -- archives/
```
