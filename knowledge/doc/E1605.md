# E1605: kpackage/6.18.0.2 consuming karchive/6.19.0 fails KF6ArchiveConfig find_dependency(ZLIB) unless transitive zlib/OpenSSL/zstd paths are injected by the recipe

## 基本信息
- **严重度**: 2
- **类别**: conan, recipe-dependency-graph
- **作者**: unknown

## 错误特征
```
Could NOT find ZLIB|missing: ZLIB_LIBRARY ZLIB_INCLUDE_DIR|find_dependency\(ZLIB\)|KF6ArchiveConfig\.cmake
```

## 根因分析
The published karchive/6.19.0 binary exports KF6ArchiveConfig.cmake which unconditionally runs find_dependency(ZLIB), find_dependency(OpenSSL) and pkg_check_modules(LibZstd); its KF6ArchiveTargets INTERFACE_LINK_LIBRARIES carries $<LINK_ONLY:ZLIB::ZLIB>, $<LINK_ONLY:OpenSSL::Crypto> and $<LINK_ONLY:PkgConfig::LibZstd>. A consumer recipe whose hand-written conan_cmakedeps_paths.cmake only exposes the direct KF deps (karchive/kcoreaddons/ki18n) never makes the transitive zlib/1.3.1.1, openssl and zstd packages discoverable to FindZLIB/FindOpenSSL/pkg-config, so configure fails with "Could NOT find ZLIB (missing: ZLIB_LIBRARY ZLIB_INCLUDE_DIR)".

## 推荐方案
**方法**: recipe-layer-transitive-dependency-path-injection

**说明**: In the consumer conanfile.py generate(): (1) require the direct dep karchive/6.19.0 and also openssl/3.5.6.1 so the exported Config's find_dependency(OpenSSL) is satisfiable; (2) prepend the transitive zlib/1.3.1.1 and openssl package root/lib/cmake/include into the generated conan_cmakedeps_paths.cmake (declared dependency metadata, not hard-coded cache paths); (3) prepend the transitive zstd lib/pkgconfig dir onto ENV{PKG_CONFIG_PATH} (set(ENV...) prepend); (4) since karchive/6.19.0 is a static library linked by bare -lKF6Archive and its LINK_ONLY transitive libs never reach the link line, add -L<zlib/zstd libdir> -lz -lzstd to CMAKE_SHARED_LINKER_FLAGS and CMAKE_EXE_LINKER_FLAGS. Preserve R05/R07 relocatability (no .conan2/.cache path in DT_NEEDED/RPATH/RUNPATH).

**修复命令**:
```
conan create archives/k/kpackage/6.18.0.2 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create archives/k/kpackage/6.18.0.2 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
