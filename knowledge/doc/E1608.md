# E1608: GNOME 归档库硬依赖的制品仓组件缺失（cogl-pango/cairo-gobject 无 .so 无 .pc），正解不是重打包依赖库，而是按"符号面分析→上游等价 stub→转发 .pc"三步闭合：先 nm -D --undefined-only 实测消费库真正引用的符号集（远小于组件全 API），再逐符号写上游语义等价的 stub（直传/no-op/GType 注册三类），最后生成 Libs 直接带 stub .o 的转发 .pc 链接期闭合

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, packaging
- **作者**: unknown
- **来源 PR**: 14164

## 错误特征
```
No package 'cogl-pango-1.0' found|No package 'cairo-gobject' found|undefined symbol: cogl_pango_font_map_new|undefined symbol: cairo_gobject_context_get_type|configure: error: Package requirements (cogl-pango-1.0) were not met
```

## 根因分析
GNOME 同世代栈（clutter 1.26 依赖 cogl 1.22）的组件化程度高：clutter 的 CLUTTER_BASE_PC_FILES/CLUTTER_DEPS 硬性要求 cogl-pango-1.0 与 cairo-gobject >= 1.14。而制品仓的 cogl/1.22.8 二进制当年构建时禁用了 cogl-pango 组件（OHOS 无显示服务一并禁了 cairo/pango 链），cairo/1.18.4 二进制同样不含 cairo-gobject 组件。configure 的 PKG_CHECK_MODULES 在 PKG_CONFIG_PATH 全链找不到 .pc 直接 fatal；绕过 configure 后链接期又会撞 undefined symbol。第一直觉"重打包 cogl/cairo 带上组件"成本高且动了他人在档依赖；正解是接受制品仓现状，在消费方配方内就地 stub。关键洞察：nm -D --undefined-only libclutter-1.0.so 实测，cogl_pango_* 未解析符号仅 8 个、cairo_gobject_* 仅 2 个——上游 cogl-pango 是 PangoCairoFontMap 的"假子类"（qdata 挂 CoglContext），fontmap 系列全部可直传 pango 对应 API；glyph-cache/render 系列是 GL 渲染路径（OHOS 无显示服务不可达）no-op 安全；cairo-gobject 是 CAIRO_GOBJECT_BOILERPLATE 展开的引用计数 boxed 类型注册，逐行重写即与上游等价。

## 推荐方案
**方法**: component-subset-stub-with-forwarding-pc

**说明**: 三步闭合：①符号面分析——nm -D --undefined-only 实测消费库未解析符号，确认真实引用面（本例 8+2 个，远小于组件全 API）；②stub 实现源——直传类（cogl_pango_font_map_new = pango_cairo_font_map_new()）按上游源逐行对齐语义，不可达路径（GL glyph-cache/render）no-op，GType 注册类（cairo_gobject_context/surface_get_type）按上游 g_boxed_type_register_static 原样（类型名字符串也照抄，保 GType 兼容）；stub 头若缺（cogl-egl.h/cogl-pango.h）一并按上游布局放 exports_sources；③转发 .pc——在 generators_folder 写 stub 版 cogl-pango-1.0.pc / cairo-gobject.pc：prefix=stub、Libs 直接带 stub .o 绝对路径、Requires 指向真实组件链（cogl-1.0 pangocairo / cairo gobject-2.0）、Cflags 指向真实头目录。同配方先例可用真实文件时优先转发（cairo 包内若在档则 prefix=/ 重写转发，stub 仅兜底）。注意：./configure 的 --enable-egl-backend 在 OHOS 用 --disable-x11-backend --disable-gdk-backend --disable-wayland-backend --disable-quartz-backend --disable-win32-backend --disable-mir-backend --disable-cex100-backend --disable-evdev-input --disable-tslib-input 全禁 + 仅 EGL——EGL 经 cogl 封装无需直连 egl 包，egl.h 由 clang 默认 sysroot 解析（先验证 #include <EGL/egl.h> 裸编译过再决定是否加 -I）。

**修复命令**:
```
nm -D --undefined-only <lib>.so | grep -E "cogl_pango_|cairo_gobject_" ; clang -c stub.c -o stub.o `pkg-config --cflags glib-2.0 gobject-2.0` && printf 'prefix=stub\nName: cogl-pango\nLibs: %s/stub.o\nRequires: cogl-1.0 pangocairo\n' $PWD > gens/cogl-pango-1.0.pc
```

**验证**:
```
nm -D --undefined-only libclutter-1.0.so | grep -E "cogl_pango|cairo_gobject" && pkg-config --cflags --libs cogl-pango-1.0 cairo-gobject
```
