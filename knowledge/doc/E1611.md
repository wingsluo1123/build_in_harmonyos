# E1611: "CMake 属性值中的分号列表未加引号，导致 set_directory_properties 参数数量错误"

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake
- **作者**: 2501_91199785

## 错误特征
```
"set_directory_properties Wrong number of arguments"
```

## 根因分析
"CMake 在未引用的变量展开时将分号列表拆成多个实参；set_directory_properties(PROPERTIES key value) 因而收到额外参数。"

## 推荐方案
**方法**: "quote-the-complete-list-property-value"

**说明**: "保持列表元素不变，仅在传给 set_directory_properties 的属性值外加双引号；重新配置，确认该处错误消失，并继续检查后续配置及构建日志。"

**修复命令**:
```
"set_directory_properties(PROPERTIES ADDITIONAL_MAKE_CLEAN_FILES \"${CLEAN_FILES}\")"
```

**验证**:
```
"对比 libpinyin W3 031713Z 的 data/CMakeLists.txt:104 配置失败与修复后 042115Z 的完整 conan create、CTest 6/6 和消费者 7/7；验证日志 SHA-256 e21131a6c166851675c034f2db19f65ea2895b053eb86a9fe7d5666957a0b4f1"
```
