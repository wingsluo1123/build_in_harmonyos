# E1612: 平台头探针假阳性让 x86 专属符号混入单产物插件库，导致整库 dlopen 失败

## 基本信息
- **严重度**: 2
- **类别**: compat, detection, ohos, libc, linking
- **作者**: B183

## 错误特征
```
Error relocating .*: (ioperm|iopl|inb|outb|inb_p|outb_p): symbol not found
```

## 根因分析
① 探针层：构建系统用「头文件存在性」推断「接口可用性」

## 推荐方案
**方法**: disable-platform-object-via-upstream-switch

**说明**: 优先用**上游自带开关**关掉平台专属对象，不打补丁、不改源码：

**修复命令**:
```
生产样例: archives/p/pd-zexy/2.4.4/conanfile.py（本拓展样例库）
```

**验证**:
```
nm -uD <pkg>/lib/pd-externals/*.pd_linux | grep -xE 'ioperm|iopl|inb|outb|inb_p|outb_p' | wc -l
```
