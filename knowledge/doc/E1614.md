# E1614: 旧 POSIX 源码引用非标准 sys/unistd.h 时，核查标准 unistd.h 是否已覆盖

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, headers
- **作者**: 4523, junshi_liu

## 错误特征
```
fatal error: 'sys/unistd.h' file not found
```

## 根因分析
老源码把非标准 sys/unistd.h 当作 POSIX 头；OHOS sysroot 只提供标准 unistd.h。本例同一头文件后文已包含 unistd.h，前者是冗余引用。

## 推荐方案
**方法**: remove-redundant-nonstandard-include-in-build-copy

**说明**: 先核实 unistd.h 已覆盖所用声明，再仅在临时构建副本中删除精确匹配的冗余 sys/unistd.h 引用；源码布局变化时 fail closed。

**修复命令**:
```
在配方 build() 检查两个 include 各出现一次，修改临时副本后执行 conan create。
```

**验证**:
```
审核缺失头引用与标准头引用的精确次数，再在 OHOS aarch64 运行 conan create 和消费端执行测试。
```
