# E1620: Legacy interactive configure hardcodes g++/cc and defines no test target

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, autotools
- **作者**: 32C1

## 错误特征
```
Interactive (Y/N|enter|choice)|Invalid entry|g\+\+ -[IO]|cc -[IO].*\.c
```

## 根因分析
The upstream configure script is an interactive prompts-only wrapper that asks for memory/terrain limits and then emits hard-coded g++/cc compile commands, so it cannot be driven non-interactively in CI and ignores the Conan toolchain.

## 推荐方案
**方法**: recipe-side-source-replay           # 见 DESIGN §5 impl 列表

**说明**: Bypass the interactive script in the recipe's build(): replay its documented non-interactive choices as a written config header, then compile the same upstream sources directly with the Conan toolchain compilers.

**修复命令**:
```
${CONAN_FILE}: self.run("cp -f ${SRC}/Makefile.ohos .") && self.run('${CC} ${CFLAGS} ...')  # toolchain from tools.build:compiler_executables
```

**验证**:
```
grep -nE 'read |g\+\+|cc ' configure | head -20
```
