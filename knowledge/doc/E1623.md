# E1623: C++ 构造函数未初始化成员在 libc++ 下读出巨大垃圾值

## 基本信息
- **严重度**: 2
- **类别**: portability, memory, cpp
- **作者**: 7F53

## 错误特征
```
[0-9]{15,}\.[0-9]{3}|huge garbage value|uninitialized member|hasConfidence.*garbage|
```

## 根因分析
C++ 类的构造函数未初始化全部成员（如只初始化了 m_bUseConfidence 而未初始化

## 推荐方案
**方法**: initialize-all-members

**说明**: 在构造函数中显式初始化所有成员变量（浮点置 0.0、布尔置 false、整型置 0），

**修复命令**:
```
track-edit add ${SOFTWARE} ${VERSION} ${SOURCE_FILE} && \
```

**验证**:
```
grep -n "275541069870429653434368\|74107705259255264157978591232" \
```
