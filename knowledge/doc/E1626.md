# E1626: meson i18n.merge_file 合并 polkit policy 需注入 GETTEXTDATADIR 指向 polkit 包 its 目录

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, meson, nls
- **作者**: 8E00

## 错误特征
```
cannot locate ITS rules for .*\.policy\.in|msgfmt.*ITS rules
```

## 根因分析
对 .policy（polkit 策略）等 XML 文件做 i18n.merge_file 翻译合并时，msgfmt 需要 gettext ITS 定位规则（polkit.its/polkit.loc）。OHOS 工具链的 msgfmt 数据目录（usr/local/share/gettext/its）不含 polkit 规则，而 conan polkit 包将 ITS 规则装在包内 share/gettext/its/，默认搜索路径找不到

## 推荐方案
**方法**: conanfile 构建环境注入 GETTEXTDATADIR 指向 polkit 依赖包 package_folder/share/gettext（其下有 its/ 子目录）；或用 configure_file(copy:) 跳过翻译合并（accountsservice 0005 先例）

**说明**: 两条路径：注入 ITS 规则保留翻译（本方案），或退化无翻译安装（accountsservice 先例）；libmalcontent 0.10.2 注入方案实测通过

**修复命令**:
```
conanfile _build_environment(): environment.define_path('GETTEXTDATADIR', polkit_pkg/share/gettext)
```

**验证**:
```
GETTEXTDATADIR=/storage/.../polkit.../share/gettext ninja <policy 目标>（修复前 msgfmt: cannot locate ITS rules；注入后 Merging translations 通过）
```
