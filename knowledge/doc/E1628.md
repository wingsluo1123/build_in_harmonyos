# E1628: 新版 meson i18n.merge_file 不再接受位置参数 output（报 Function does not take positional arguments）

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, meson
- **作者**: D0BB

## 错误特征
```
Function does not take positional arguments|i18n.merge_file\('.*'
```

## 根因分析
上游元老式 meson.build 用 i18n.merge_file('out.policy', input:, output: ...) 的位置参数形式传入 output；新版 meson（≥1.12）不再接受位置参数，必须用 output: 关键字，否则配置阶段直接报错

## 推荐方案
**方法**: patch meson.build，将 i18n.merge_file('xxx', input:, output:...) 改为 i18n.merge_file(input:, output:...) 纯关键字形式（删除位置参数、保留 input/output 关键字）

**说明**: 位置参数只用于 output 文件名，删掉后 output 关键字仍提供同一值，行为不变；libmalcontent 0.10.2 accounts-service/meson.build 修复先例

**修复命令**:
```
sed -i 's/i18n.merge_file(.*\.policy./i18n.merge_file(/ ' accounts-service/meson.build 并删除位置参数行
```

**验证**:
```
meson setup builddir（配置阶段复现ERROR: Function does not take positional arguments）；改为 output: 关键字后配置通过
```
