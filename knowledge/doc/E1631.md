# E1631: C++17 结构化绑定不能在 lambda 捕获列表中使用（Clang 15 严格报错），需改用局部引用变量

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, clang, cpp
- **作者**: C584

## 错误特征
```
'[a-z_]+' in capture list does not name a variable|reference to local binding '[a-z_]+' declared in enclosing function
```

## 根因分析
C++17 标准不允许 lambda 捕获列表直接引用结构化绑定变量（如 for (const auto & [a, b] : map) 后 [&b]{}），Clang 15 严格按标准报 'capture list does not name a variable'（GCC 部分版本仅警告）；C++20 才放开此限制

## 推荐方案
**方法**: local-ref-capture

**说明**: 在结构化绑定变量所在作用域先声明一个局部引用变量（如 const xml::Element& ref = xml;），lambda 捕获该局部引用即可；语义不变，规避 C++17 限制

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
在 for (const auto& [tbd, xml] : vec) 体内先定义 const auto& ref = xml; 再 [&ref]{} 捕获，重新编译通过
```
