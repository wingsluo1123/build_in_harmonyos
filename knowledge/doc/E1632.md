# E1632: libxml2 2.15.x 的 xmlGetLastError() 返回 const xmlError*，老代码用非 const xmlErrorPtr 接收报 discards qualifiers

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, cpp, libxml2
- **作者**: 8F24

## 错误特征
```
assigning to 'xmlErrorPtr' from 'const xmlError \*' discards qualifiers|cannot initialize a variable of type 'xmlErrorPtr' with an rvalue of type 'const xmlError \*'
```

## 根因分析
libxml2 2.15 将 xmlGetLastError() 的返回值改为 const xmlError*（只读错误信息），老 C++ 代码（如 scram 0.16.2 src/xml.cc:31、src/xml.h:161）用非 const xmlErrorPtr 接收或赋值，Clang 报 discards qualifiers；xmlErrorPtr 是 _xmlError* 的非 const typedef

## 推荐方案
**方法**: const-qualifier-align

**说明**: 把接收 xmlGetLastError() 返回值的变量/参数类型改为 const xmlError*（或 const xmlErrorPtr），与 libxml2 2.15 API 一致；仅错误对象只读，不改变使用方式

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
sed -i 's/xmlErrorPtr xml_error = xmlGetLastError();/const xmlError *xml_error = xmlGetLastError();/' src/xml.cc && cmake --build build -j1 && ./scram_tests
```
