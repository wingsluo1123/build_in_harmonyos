# E1633: BOOST_THROW_EXCEPTION_CURRENT_FUNCTION 在 Boost≥1.73 移除，需替换为 BOOST_CURRENT_FUNCTION

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, boost, cpp
- **作者**: DBD0

## 错误特征
```
use of undeclared identifier 'BOOST_THROW_EXCEPTION_CURRENT_FUNCTION'|BOOST_THROW_EXCEPTION_CURRENT_FUNCTION.*undeclared
```

## 根因分析
Boost>=1.73 移除 BOOST_THROW_EXCEPTION_CURRENT_FUNCTION 宏（error.hpp 重构），老 C++ 项目（如 scram 0.16.2 src/error.h 的 SCRAM_THROW 宏）直接引用会编译报 undeclared identifier；官方替代为 BOOST_CURRENT_FUNCTION（boost/current_function.hpp）

## 推荐方案
**方法**: macro-rename-sed

**说明**: 把源码中的 BOOST_THROW_EXCEPTION_CURRENT_FUNCTION 直接替换为 BOOST_CURRENT_FUNCTION（Fedora 打包同样做法）；两者语义一致，仅宏名随 Boost 重构变化

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
sed -i 's/BOOST_THROW_EXCEPTION_CURRENT_FUNCTION/BOOST_CURRENT_FUNCTION/' src/error.h && cmake --build build -j1 && ./scram_tests
```
