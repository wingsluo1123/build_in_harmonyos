# E1636: llvm-lit 上游测试套件在源码构建下的两个隐式执行前提：构建目录须位于源码树内 + 测试工具目标（count/not/llvm-config/FileCheck）须一并构建

## 基本信息
- **严重度**: 2
- **类别**: detection, ohos, llvm, testing
- **作者**: 1D9F
- **来源 PR**: "!10604"

## 错误特征
```
fatal: Did not find (count|not|FileCheck) in|llvm-lit.*(cannot find|did not find)|map_config|Unable to find.*lit.*suite
```

## 根因分析
llvm-lit 以构建目录为基准解析测试套件（其 map_config 按 bdir/../<子项目> 定位源码目录），构建目录放在源码树外时套件无法定位；同时 lit 的 RUN 行依赖 count/not/FileCheck/llvm-config 等测试工具，未列入构建目标时 lit 直接 fatal 退出（Did not find count in .../bin）——两者都会让上游测试看似不存在或无法执行

## 推荐方案
**方法**: in-source-build-dir-with-test-tools-targets

**说明**: 把构建目录放在源码树内（如 source_folder/build-ohos），保证 llvm-lit 的 bdir/../<子项目> 可解析；构建目标列表必须包含测试工具 count/not/FileCheck/llvm-config 与单测目标（如 FormatTests）；随后单测与 lit 套件即可真实运行并回填通过率

**修复命令**:
```
cmake --build build-ohos --target clang-format FileCheck FormatTests count not llvm-config -j 4
```

**验证**:
```
ls build-ohos/bin/llvm-lit build-ohos/bin/FileCheck build-ohos/bin/count build-ohos/bin/not build-ohos/bin/llvm-config && cd build-ohos && bin/llvm-lit -sv ../clang/test/Format
```
