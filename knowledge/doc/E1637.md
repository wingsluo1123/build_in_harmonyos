# E1637: LLVM 家族源码构建 OHOS 路线：真机原生（不设 CMAKE_SYSTEM_NAME）使 llvm-tblgen 当轮原生编+跑，避免交叉构建期 host 工具不可执行

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, build-system, cmake, toolchain
- **作者**: 1D9F
- **来源 PR**: "!10604"

## 错误特征
```
llvm-tblgen.*(cannot execute|not found|Exec format error)|tablegen.*cross|LLVM.*host tool.*(cannot|failed)|交叉构建 LLVM 时构建期 host 工具无法运行
```

## 根因分析
LLVM 构建期必须运行 llvm-tblgen 等 host 工具生成 .inc；若按常规做法设 CMAKE_SYSTEM_NAME 触发交叉，host 工具需另建且在构建期无法执行。设备本身即 aarch64 OHOS，不设 CMAKE_SYSTEM_NAME 走原生编译即可当轮编+跑 tblgen（实测通过）；配套还需 config.guess stub（config-ix.cmake 无条件调用，uname -s=HarmonyOS 不认）与 Platform/HarmonyOS.cmake（cmake 无该平台模块，UNIX 变量未置），老版本 LLVM 另需 CMAKE_POLICY_VERSION_MINIMUM=3.5

## 推荐方案
**方法**: native-source-build-no-cross-toolchain

**说明**: 不设 CMAKE_SYSTEM_NAME（真机原生，不触发交叉）→ llvm-tblgen 当轮原生编+跑；build() 覆盖 llvm/cmake/config.guess 为 stub（echo aarch64-unknown-linux-ohos）；提供 Platform/HarmonyOS.cmake（include(Platform/Linux)）挂 CMAKE_MODULE_PATH；cmake 4.x 下注入 CMAKE_POLICY_VERSION_MINIMUM=3.5；只构建所需 target（clang-format + 测试基础设施）以控制耗时

**修复命令**:
```
cmake -S llvm -B build-ohos -G Ninja -DCMAKE_MODULE_PATH=$PWD/_cmake_modules -DCMAKE_BUILD_TYPE=Release -DLLVM_TARGETS_TO_BUILD=AArch64 -DLLVM_ENABLE_PROJECTS=clang -DLLVM_INCLUDE_TESTS=ON -DLLVM_ENABLE_TERMINFO=OFF -DLLVM_ENABLE_ZLIB=OFF -DLLVM_ENABLE_LIBXML2=OFF
```

**验证**:
```
cmake -S llvm -B build-ohos -G Ninja -DCMAKE_BUILD_TYPE=Release -DLLVM_TARGETS_TO_BUILD=AArch64 -DLLVM_ENABLE_PROJECTS=clang -DLLVM_INCLUDE_TESTS=ON && cmake --build build-ohos --target clang-format -j 4 && build-ohos/bin/clang-format --version
```
