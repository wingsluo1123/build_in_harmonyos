# E1638: 上游 Python 包/测试把临时文件路径硬编码 /tmp（OHOS 只读挂载）；setsid 仅以 busybox applet 存在需软链补齐

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, portability, test-framework
- **作者**: F158

## 错误特征
```
Read-only file system|Errno 30|/tmp/afl_multicore\.PGID|No such file or directory: 'setsid'|FileNotFoundError.*setsid
```

## 根因分析
OHOS/HarmonyOS PC 的 /tmp 为只读挂载（erofs, ro），而上游纯 Python 产品代码与测试把临时文件路径硬编码为 /tmp，写入即 OSError [Errno 30] Read-only file system；同环境未提供独立 setsid 可执行文件（仅 busybox applet），subprocess.Popen(['setsid',...]) 抛 FileNotFoundError

## 推荐方案
**方法**: tempfile-gettempdir-plus-busybox-shim

**说明**: 产品代码把硬编码 /tmp 改为 tempfile.gettempdir()（遵循 TMPDIR），并同步修改上游测试用例为同一口径；构建期生成私有 shim 目录，提供 setsid→busybox 软链（busybox 依 argv[0] 分派 applet）与 python→解释器软链，置于测试 PATH 最前

**修复命令**:
```
export TMPDIR=$HOME/tmp; SHIM=$TMPDIR/shim; mkdir -p $SHIM; ln -sf $(command -v busybox) $SHIM/setsid; ln -sf $(command -v python3) $SHIM/python; PATH=$SHIM:$PATH python3 -m pytest tests
```

**验证**:
```
python3 -m pytest <tests> -q 2>&1 | grep -E 'Read-only file system|No such file or directory: .setsid.'
```
