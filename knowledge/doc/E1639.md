# E1639: 上游测试脚本自身缺陷（赋值误写为命令替换）→ 不修上游、如实计数

## 基本信息
- **严重度**: 1
- **类别**: compat, limitation, testing
- **作者**: 3EF2

## 错误特征
```
get_diskguid|NEW_DISK_GUID=|SUCCESS.*GUID
```

## 根因分析
上游测试脚本把命令替换 $(...) 写成裸赋值（如 NEW_DISK_GUID=get_diskguid），比较对象恒为字面量/空串，相关断言恒真；属上游脚本缺陷。

## 推荐方案
**方法**: report-honestly-no-upstream-edit

**说明**: R51 口径如实申报（标注恒真项），保持上游测试原样运行；不修改上游测试来制造全绿假象

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
sh ./gdisk_test.sh 并逐行核对断言语义
```
