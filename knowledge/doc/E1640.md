# E1640: 普通文件镜像上 BLKSSZGET 失败（Error 13）为预期噪音，不影响 GPT 读写

## 基本信息
- **严重度**: 1
- **类别**: platform, compat, limitation
- **作者**: 0712

## 错误特征
```
Error 13 when determining sector size|BLKSSZGET|Setting sector size to 512
```

## 根因分析
对普通文件（非块设备）执行 ioctl(BLKSSZGET) 取扇区大小必然失败；gptfdisk 回退默认扇区大小 512 继续工作，功能完全正常。

## 推荐方案
**方法**: treat-as-expected-noise

**说明**: 测试断言 rc=0 与 GPT 结构（EFI PART/0x55AA），不因该提示判失败；测试镜像用普通文件是合法路径

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
sgdisk -p disk.img 观察提示且 rc=0
```
