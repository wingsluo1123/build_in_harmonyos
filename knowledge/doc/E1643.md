# E1643: Header using sig_atomic_t must include signal.h

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, libc, musl, headers
- **作者**: A54E

## 错误特征
```
ircd_signal\.h:.*unknown type name 'sig_atomic_t'|error: unknown type name 'sig_atomic_t'
```

## 根因分析
src/ircd_signal.h uses sig_atomic_t without including <signal.h>, the standard header that declares this type. An unrelated header may expose the typedef transitively on one libc or under one include order, masking the omission. The OHOS Clang build reached this header without that incidental declaration and failed with unknown type name 'sig_atomic_t'. A header must include the owner of each type it uses so it remains compilable when included first.

## 推荐方案
**方法**: include-type-owning-header-in-owner

**说明**: Add an unconditional #include <signal.h> to the header that uses sig_atomic_t, then compile that header as the first include in a minimal translation unit and rebuild the package.

**修复命令**:
```
Add #include <signal.h> to src/ircd_signal.h; run the OHOS Conan create command from verification_cmd.
```

**验证**:
```
conan create archives/i/ircd-hybrid/8.2.46-dfsg.1 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
