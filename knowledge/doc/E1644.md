# E1644: conan ncurses 平铺头缺 <ncursesw/ncurses.h>：私有 shim 头修复（不改上游源码）

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, headers, build-system
- **作者**: 8845

## 错误特征
```
ncursesw/ncurses\.h.{0,40}(file not found|No such file)
```

## 根因分析
conan 的 ncurses 包头文件平铺安装在 include/（curses.h、ncurses.h），不提供发行版常见的 include/ncursesw/ 子目录；源码包含 <ncursesw/ncurses.h> 时直接 file not found。

## 推荐方案
**方法**: private-build-folder-shim

**说明**: 在私有 build_folder 生成 ncursesw/ncurses.h shim（#pragma once + #include <curses.h>）并以 -I 注入（R49：不写共享前缀）

**修复命令**:
```
mkdir -p <build>/ncursesw-compat/ncursesw; printf '#pragma once\n#include <curses.h>\n' > <...>/ncurses.h; -I<build>/ncursesw-compat
```

**验证**:
```
ls <ncurses_pkg>/include；复现编译报错行
```
