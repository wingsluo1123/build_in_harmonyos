# E1645: Makefile 用 uname -s 选择平台分支：HarmonyOS 不命中，需显式 TARGET=linux（零补丁）

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, portability, build-system
- **作者**: BA2E

## 错误特征
```
undefined reference to .*uuid_|TARGET=linux|cannot find -luuid|uname -s
```

## 根因分析
上游 consolidated Makefile 以 uname -s 输出匹配平台分支（Linux/Darwin/FreeBSD/MinGW 等）；HarmonyOS PC 输出 HarmonyOS，不进入 Linux 分支，导致平台默认链接参数（gptfdisk 的 LDLIBS=-luuid、SGDISK_LDLIBS=-lpopt、CGDISK_LDLIBS=-lncursesw）不生效，链接期缺符号。

## 推荐方案
**方法**: upstream-target-var

**说明**: 优使用上游文档化的平台选择开关（gptfdisk 为 TARGET=linux），零补丁恢复 Linux 分支参数

**修复命令**:
```
make TARGET=linux -j1 CXX=<clang++> CXXFLAGS=<flags> LDFLAGS=<libdirs>
```

**验证**:
```
uname -s; 对比 make（不加 TARGET）与 make TARGET=linux 的链接命令输出
```
