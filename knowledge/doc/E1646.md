# E1646: C++ function definition repeats default arguments from its declaration

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability
- **作者**: 836F

## 错误特征
```
default argument specified for parameter|redefinition of default argument|findAffineGapScore
```

## 根因分析
A C++ function declaration introduces a default argument, then its later definition repeats that default. Default arguments may be specified only once in the same scope, so Clang rejects the definition.

## 推荐方案
**方法**: source-patch

**说明**: Keep default arguments on the first declaration and remove duplicate defaults from the later function definition.

**修复命令**:
```
Inspect the declaration and definition, then apply the minimal source patch to the definition.
```
