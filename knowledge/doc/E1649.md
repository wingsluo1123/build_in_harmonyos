# E1649: AppStream hard dependency made optional via meson feature + HAVE_APPSTREAM guard (libadwaita-1 on OHOS)

## 基本信息
- **严重度**: 2
- **类别**: platform, dependency-optionalization
- **作者**: 214F

## 错误特征
```
dependency('appstream')|Subproject appstream is buildable: NO|wrap-git|github.com|appstream.h file not found
```

## 根因分析
libadwaita/GTK-family GNOME libraries hard-require AppStream in meson.build (dependency('appstream', fallback: [appstream wrap])). OHOS PC has no AppStream library: no recipe published on ohpcd, and the upstream subproject wrap points at github.com which is unreachable from the OHOS build environment, so meson configure aborts (wrap-based subproject downloading disabled / repository unreachable).

## 推荐方案
**方法**: make-appstream-optional-meson-feature

**说明**: 一句话描述这个推荐方案

```
可选: 具体命令模板(${VAR}变量引用)
```

```
conan create archives/l/libadwaita-1/1.9.2 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
