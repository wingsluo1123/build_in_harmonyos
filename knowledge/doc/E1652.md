# E1652: nss 包 shared=False 时 cpp_info 给静态 coreconf 名（-lnss），静态归档不含 NSS API

## 基本信息
- **严重度**: 3
- **类别**: portability, linking, dependency-graph, nss
- **作者**: E7C2

## 错误特征
```
undefined symbol: CERT_|undefined symbol: PK11_|undefined symbol: NSS_|undefined symbol: SECITEM_
```

## 根因分析
nss 配方按 options.shared 选 libs：shared=False 时给 ['nss','ssl','smime',...] 这些名字只对应包内静态归档 libnss.a/libssl.a；NSS 的公开 API（CERT_GetDefaultCertDB、PK11_GetBestSlot…）只在共享的 libnss3.so/libssl3.so 里导出，且归档不含这些符号，链接即 undefined

## 推荐方案
**方法**: rewrite-dependency-libs

**说明**: 消费侧把 nss 的 cpp_info.libs 换成共享 coreconf 名：nss3, ssl3, smime3, nssutil3, softokn3, freebl3, nssckbi, nssdbm3, sqlite3

**修复命令**:
```
dep.cpp_info.libs=["nss3","ssl3","smime3","nssutil3","softokn3","freebl3","nssckbi","nssdbm3","sqlite3"]
```

**验证**:
```
llvm-nm -D --defined-only <nss>/lib/libnss3.so | grep CERT_GetDefaultCertDB；ls <nss>/lib | grep -E '^libnss(3)?\.'
```
