# E1653: glib 的 proxy-libintl 未被 .pc 暴露：g_libintl_* 未定义

## 基本信息
- **严重度**: 3
- **类别**: linking, dependency-graph, glib, i18n
- **作者**: E7C2

## 错误特征
```
undefined symbol: g_libintl_|libintl\.h|proxy-libintl
```

## 根因分析
<glib/gi18n-lib.h> 把 gettext()/dgettext() 等映射到 glib 自带 proxy-libintl 提供的 g_libintl_* 包装；conan glib 包安装的 glib-2.0.pc/gio-2.0.pc 的 Libs 未列 -lintl，-Wl,--no-undefined 链接共享库时报 undefined symbol: g_libintl_bindtextdomain

## 推荐方案
**方法**: augment-dependency-pkgconfig

**说明**: 消费侧给 glib 各组件 cpp_info.libs 追加 'intl'（或后处理 .pc 的 Libs 行补 -lintl）

**修复命令**:
```
for c in dep.cpp_info.components.values(): c.libs.append("intl")
```

**验证**:
```
nm -D <glib>/lib/libintl.so | grep g_libintl；grep -n '^Libs' <generators>/glib-2.0.pc（无 -lintl 即命中）
```
