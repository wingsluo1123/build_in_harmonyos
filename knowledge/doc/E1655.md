# E1655: CMake 无 Platform/HarmonyOS 模块 → 共享库没有 SONAME，消费者 NEEDED 记录构建树相对路径

## 基本信息
- **严重度**: 3
- **类别**: platform, cmake, linking
- **作者**: E7C2

## 错误特征
```
NEEDED.*\.\./|no SONAME|soname: 缺失|cmake.*HarmonyOS.*unknown
```

## 根因分析
conan 把 os=OHOS 映射为 CMAKE_SYSTEM_NAME=HarmonyOS，而 CMake 没有 Modules/Platform/HarmonyOS.cmake（configure 期打印 'System is unknown to cmake'），于是 Modules/Platform/Linux.cmake 提供的 CMAKE_SHARED_LIBRARY_SONAME_C_FLAG/-rpath 等变量全部缺失；CMake 不传 -Wl,-soname，链接器把同工程内共享库的构建树路径（如 ../../camel/libcamel-1.2.so）写进消费者 DT_NEEDED，安装后无法解析

## 推荐方案
**方法**: inject-platform-link-flags

**说明**: 配方 generate() 里把 Linux 平台的 SONAME 变量写进 CMake cache：CMAKE_SHARED_LIBRARY_SONAME_C_FLAG='-Wl,-soname,'（CXX 同名），产物即获得 libX.so.<SOVERSION>

**修复命令**:
```
tc.variables["CMAKE_SHARED_LIBRARY_SONAME_C_FLAG"]="-Wl,-soname,"
```

**验证**:
```
llvm-readelf -d <pkg>/lib/*.so | grep -E 'SONAME|NEEDED'（SONAME 缺失且 NEEDED 含 ../ 即命中）
```
