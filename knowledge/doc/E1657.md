# E1657: Autotools.install() 的 DESTDIR 与绝对 configure prefix 拼接，产物埋进 <pkg>/storage/... 嵌套路径

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, autotools, conan, packaging
- **作者**: E7E8

## 错误特征
```
inaccessible or not found|package_folder.*storage/|DESTDIR
```

## 根因分析
conan2 Autotools.install() 以 destination or self.package_folder 作 DESTDIR。若 generate() 里把 --prefix 配成 build_folder 下的绝对路径，make install 会把 DESTDIR 与绝对 prefix 直接拼接，得到 <pkg>/storage/Users/.../prefix/bin，包内标准 bindir 为空，test_package 与消费者都找不到可执行文件

## 推荐方案
**方法**: configure-prefix-root-for-destdir

**说明**: configure --prefix 配成根相对路径（/），让 conan 的 make install DESTDIR=<package_folder> 得到扁平的 <pkg>/bin；依赖注入仍留在 build_folder 内，不违反 R49

**修复命令**:
```
tc.configure_args.append('--prefix=/')  # 依赖注入仍留在 build_folder 内，不违反 R49
```

**验证**:
```
conan create 后 find <pkg>/bin -type f 命中目标可执行文件
```
