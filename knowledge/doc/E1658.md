# E1658: 依赖包共享库 SONAME 为相对路径 './libX.so'，消费者按 CWD 解析必然加载失败

## 基本信息
- **严重度**: 3
- **类别**: portability, cmake, linking
- **作者**: E7C2

## 错误特征
```
Error loading shared library \./lib|DT_NEEDED .*relative|soname: \[\./
```

## 根因分析
libical3/3.0.20 为规避 HMDFS 上绝对 soname/$ORIGIN 不稳定，注入 CMAKE_SHARED_LIBRARY_SONAME_C_FLAG=-Wl,-soname,./ ，使共享库 SONAME 变成相对路径 './libical-glib.so'；OHOS musl loader 对含 '/' 的 NEEDED 按当前工作目录解析，消费者 DT_NEEDED 变成 './libical-glib.so'，只要工作目录没有该文件就报 Error loading shared library

## 推荐方案
**方法**: link-static-archive

**说明**: 改为链接该包的静态归档（libical-glib.a/libicalvcal.a/libicalss.a/libical.a），把实现并入下游 .so，消除破损的运行时依赖

**修复命令**:
```
dep.cpp_info.libs=[]; dep.cpp_info.sharedlinkflags=[<pkg>/lib/libical-glib.a, ...]
```

**验证**:
```
llvm-readelf -d <libical3>/lib/libical-glib.so | grep SONAME；llvm-readelf -d <下游>.so | grep 'NEEDED.*\./libical'
```
