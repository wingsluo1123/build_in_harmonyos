# E1662: Makefile compiler defaults bypass the OHOS cross toolchain

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, build-system
- **作者**: AA66

## 错误特征
```
CC := gcc|CPP := g++
```

## 根因分析
The upstream Makefile assigns CC and CPP internally, so cross-build configuration is bypassed unless make receives command-line compiler variable overrides.

## 推荐方案
**方法**: compiler_override

**说明**: Pass cross compiler executable paths as command-line make variables; retain upstream linker options.

**修复命令**:
```
make -j1 CC="$OHOS_CC" CPP="$OHOS_CXX"
```

**验证**:
```
Inspect make output and confirm compile and link commands use the OHOS clang and clang++ executables.
```
