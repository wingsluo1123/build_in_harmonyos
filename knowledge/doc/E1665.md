# E1665: 上游 xode XML 解析器对无属性元素的空指针解引用（expat atts[0]==NULL）

## 基本信息
- **严重度**: 3
- **类别**: headers, runtime
- **作者**: 7C34

## 错误特征
```
Signal 11 (core dumped)|SIGSEGV.*xode|xode_from_str.*(crash|segv)|空指针.*atts|_xode_put_expatattribs
```

## 根因分析
expat 对无属性元素的 start 回调传入「非 NULL 数组且 atts[0]==NULL」（实测 expat 2.7.3 与 2.8.2 一致）；kamailio xode 的 _xode_put_expatattribs() 循环条件只判 atts==NULL、不判 atts[i]==NULL 即解引用 → 任何无属性元素（<body>/<status>）解析即 SIGSEGV。跨平台缺陷，与 OHOS 无关。

## 推荐方案
**方法**: define-guard

**说明**: 循环条件补判空：while(atts[i] != NULL && *(atts[i]) != '\0')。有属性元素行为不变；无属性元素不再崩溃。参考：archives/k/kamailio-xmpp/6.0.6/patches/0001-src-modules-xmpp-xode_from.c.patch

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
探针1：dlopen libexpat -> XML_SetElementHandler + XML_Parse("<a/>") 打印 atts/atts[0]（实测 非NULL + 0）；探针2：对模块 xode_from_str("<a/>") 装 SIGSEGV handler 定位 pc 落在 _xode_put_expatattribs 的 ldrb [x8]（x8=0）
```
