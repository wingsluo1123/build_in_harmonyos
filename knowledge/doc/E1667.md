# E1667: OHOS HMDFS Autotools temporary-file permissions and socket-header conflicts

## 基本信息
- **严重度**: 2
- **类别**: compat, hmdfs, ohos, headers, autotools
- **作者**: 4D4C

## 错误特征
```
'config\.status:.*Permission denied|subs1\.awk: Permission denied|sockaddr_storage.*redefinition'
```

## 根因分析
Autotools creates config.status temporary files with umask 077 on HMDFS, and OHOS exposes overlapping POSIX/Linux socket definitions.

## 推荐方案
**方法**: patch-source

**说明**: Apply a minimal configure umask patch and pass OHOS socket-header compatibility defines through the Conan toolchain.

**修复命令**:
```
sed -i 's/umask 077/umask 022/g' configure
```

**验证**:
```
OHC_W3_TIMEOUT=3600 zsh ci/conan/build_and_test.sh archives/l/libnftnl/1.3.1
```
