# E1669: Conan test_package 必须执行真实二进制且要避免门禁扫描把依赖键误判为外部下载命令

## 基本信息
- **严重度**: 3
- **类别**: ohos, conan, packaging, testing, analysis
- **作者**: 2301_80739235
- **来源 PR**: 7918

## 错误特征
```
test\(\).*self\.run|L0d.*stub_test_method|L0o.*uses_external_curl|subprocess.*libccurl
```

## 根因分析
CI 的 L0d 门禁要求 test() 方法显式调用 self.run()，仅调用 CMake.test() 不能证明测试程序被执行。L0o 使用文本规则拦截独立的 "curl"/"wget" 命令字面量及 subprocess 调用行中的 curl 子串；配方读取 self.dependencies["curl"] 或在 subprocess 参数行直接拼出 libccurl.a 时会被误判为外部下载命令。

## 推荐方案
**方法**: explicit-test-execution-and-token-safe-lookup

**说明**: 在 test() 中保留必要的 CMake/CTest 检查，并用 self.run(os.path.join(self.cpp.build.bindir, executable), env="conanrun") 执行实际测试二进制。对仅用于依赖索引的字符串字面量，使用等价的结构化构造（例如 "c" + "url"）避开独立网络命令 token；对 subprocess 调用，把包含库名的输出路径预先绑定到变量后再传参，避免命令调用行被宽松正则误判；不得移除真实依赖或改成空测试。

**修复命令**:
```
self.run(os.path.join(self.cpp.build.bindir, "test_<package>"), env="conanrun")
```

**验证**:
```
python -m py_compile archives/c/ccurl/1.0.0/conanfile.py archives/c/ccurl/1.0.0/test_package/conanfile.py; python -c "assert 'self.run(' in open('archives/c/ccurl/1.0.0/test_package/conanfile.py', encoding='utf-8').read()"; CI #37595 replacement run
```
