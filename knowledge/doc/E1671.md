# E1671: PkgConfigDeps 不生成 gmodule-no-export-2.0.pc 导致 meson configure 失败

## 基本信息
- **严重度**: 3
- **类别**: meson, pkg-config, glib
- **作者**: 23CE

## 错误特征
```
Could not get pkg-config variable and no default provided|gmodule-no-export-2.0
```

## 根因分析
PkgConfigDeps 只从依赖 recipe 的 package_info components 生成 .pc；glib recipe 只声明 gmodule-2.0，未声明 gmodule-no-export-2.0。gdk-pixbuf 等 GNOME 库 meson.build 用 dependency('gmodule-no-export-2.0') 且要 get_variable('gmodule_supported')，configure 直接失败

## 推荐方案
**方法**: 在 recipe 的 generate() 中手工合成 gmodule-no-export-2.0.pc 写入 generators_folder（指向 glib 包 lib/include，含 gmodule_supported=true、Requires: glib-2.0）

**说明**: 在 conanfile.py 的 generate() 中用 write_text 合成 gmodule-no-export-2.0.pc 到 generators_folder，prefix 指向 glib package_folder，声明 gmodule_supported=true 与 Requires: glib-2.0，使 meson dependency('gmodule-no-export-2.0').get_variable('gmodule_supported') 正常解析

**修复命令**:
```
def _write_gmodule_no_export_pc(self): 见 gdk-pixbuf 2.42.12 conanfile.py
```

**验证**:
```
conan create gdk-pixbuf/2.44.6.1 -o gdk-pixbuf:shared=True && grep -n "gmodule-no-export-2.0" ~/.conan2/p/gdk-pixbuf*/b/build-release/meson-info/intro-buildoptions.json
```
