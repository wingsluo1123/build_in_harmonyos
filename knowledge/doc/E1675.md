# E1675: frozen-closure-tool-resolution

## 基本信息
- **严重度**: 2
- **类别**: ohos, toolchain, security, task-owned-environment
- **作者**: 2301_80739235

## 错误特征
```
'/data/service/hnp/bin/(?:binary-sign-tool|llvm-objcopy): inaccessible or not found|Error 127 while executing.*sign'
```

## 根因分析
A recipe assumed signing utilities lived in a system HNP directory, but the target exposed the frozen compiler and signing tools only through the task-visible user-local bin directory. The build and compile phases therefore succeeded while package signing failed with shell status 127.

## 推荐方案
**方法**: frozen-closure-tool-resolution

**说明**: Resolve signing tools from the task's compiler configuration and environment before consulting system paths. Fail closed when either required tool is absent, and never copy a tool into a shared system directory. Bind the resolver and tool paths to the candidate recipe hash and verify the final package log.

**修复命令**:
```
'resolve llvm-objcopy and binary-sign-tool from conf/PATH/compiler-dir/task-home/system; fail if missing; sign package ELF outputs'
```

**验证**:
```
Resolve each tool from compiler conf, PATH, compiler directory, task home usr/local/bin, and system fallback; require executable files before package(); verify the emitted command path and signed output in the target log.
```
