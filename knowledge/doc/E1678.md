# E1678: Probe openat2 (or similar syscalls) in a child process; treat SIGSYS child death as "not supported"

## 基本信息
- **严重度**: 3
- **类别**: portability, runtime, syscall-probing
- **作者**: akajhsbnz
- **来源 PR**: 7006

## 错误特征
```
Signal 31|SIGSYS|openat2.*seccomp|core dumped
```

## 根因分析
A runtime capability probe calls the openat2 syscall to detect kernel support; on OHOS the syscall is absent and the seccomp policy terminates the whole process with SIGSYS (signal 31) instead of returning ENOSYS, so an errno-based fallback never runs and the process dies.

## 推荐方案
**方法**: child-process-probe

**说明**: Run the openat2 probe in a forked child process; in the child issue the syscall and _exit(fd >= 0 ? 0 : 1); in the parent waitpid() and treat WIFEXITED+WEXITSTATUS==0 as supported, WIFSIGNALED(SIGSYS) or non-zero exit as not supported (leave the capability flag false). This is pure POSIX, platform-macro-free, and never kills the caller (R8-compliant).

**修复命令**:
```
'const pid_t pid = fork(); if (pid == 0) { int fd = FileUtils::openat2(AT_FDCWD, ".", O_RDONLY, 0, OPENAT2_RESOLVE_IN_ROOT); _exit(fd >= 0 ? 0 : 1); } if (pid > 0) { int st = 0; waitpid(pid, &st, 0); d_enableOpenat2 = (WIFEXITED(st) && WEXITSTATUS(st) == 0); }'
```

**验证**:
```
Run the binary on the target; observe 'Signal 31 (core dumped)'. Confirm the probe is the crashing call, then switch to a child-process probe.
```
