# E1681: 原测试的零退出码必须与功能输出及数值 oracle 同时核验

## 基本信息
- **严重度**: 2
- **类别**: ohos, fortran, mpi, original-oracle, return-code
- **作者**: 2301_80739235

## 错误特征
```
Fortran STOP returns zero after an application ERROR RETURN; save/restore uses literal read-only tmp
```

## 根因分析
原Fortran程序把清理路径作为STOP出口而未传失败退出码，库错误可以产生RC0；测试驱动若只检查进程RC会把未到达求解结果的保存恢复失败误计PASS。硬编码/tmp则忽略目标沙箱真实可写目录。

## 推荐方案
**方法**: bounded-private-directory-and-functional-output-oracle

**说明**: 不删除原失败用例或矩阵。只让保存恢复目录读取经长度和STATUS校验的任务环境；变量缺失保留上游默认，其余错误闭锁。运行器同时要求真实RC0、无原错误输出、到达原功能标记并逐值验证真实数值；实例创建例与数值求解例分别计数。

**验证**:
```
preserve original case IDs and matrices; run original examples through real MPI; reject ERROR RETURN; verify real/complex expected solutions and actual save/restore; audit same-run receipts and original numerical output hashes
```
