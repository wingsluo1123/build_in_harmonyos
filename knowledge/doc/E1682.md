# E1682: 未知系统的编译器白名单不等于缺少语言能力

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, cmake
- **作者**: LWP2

## 错误特征
```
Your C\+\+ compiler does not support C\+\+17\.|requires actual C\+\+17 library/compiler support
```

## 根因分析
上游先以 compiler ID 与操作系统名称白名单拒绝未列出的平台，尚未执行任何真实语言能力探测；显式 -std 或未知系统警告不能证明标准库不支持。原 C++17 标准已启用且真实编译链接 optional/string_view/variant 可成功。

## 推荐方案
**方法**: real-capability-probe-for-unlisted-clang-system

**说明**: 保留已有平台分支与标准版本，仅在未知 Clang 系统路径运行包含 optional/string_view/variant 和 __cplusplus 静态断言的真实 check_cxx_source_compiles；探测失败原样 fail closed，再完整构建和运行未削减的原测试。

**修复命令**:
```
在未知 Clang 分支 include(CheckCXXSourceCompiles) 并进行实际 C++17 编译链接，失败立即 FATAL_ERROR；禁止预置探测缓存。
```

**验证**:
```
在真实目标编译器及标准库下运行原 CMake configure，核对 ANTLR_CXX17_CAPABILITY 实际编译链接及 CMakeConfigureLog；configure RC0 不能替代完整 build/test。
```
