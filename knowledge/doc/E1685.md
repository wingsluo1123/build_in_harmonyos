# E1685: 标量命令中的字面引号破坏数值输出与缓存失效

## 基本信息
- **严重度**: 2
- **类别**: shell-scalar-argv-portability
- **作者**: 4DA1

## 错误特征
```
arithmetic syntax error|syntax error in expression|cache.*not.*refresh
```

## 根因分析
Shell 参数展开不会重新解释变量值中的引号；把 stat -c 的格式写成内嵌单引号会将引号传给工具，后续 Toybox 管线可保留它，导致整数比较失败且缓存不刷新。

## 推荐方案
**方法**: preserve-token-boundaries-and-test-invalidation

**说明**: 对不含空格的格式 token 删除变量内部装饰引号；复杂参数改成实际 argv 数组。不得用 eval。通过真实工具链执行缓存三段式测试，外部业务命令可用确定性夹具，但不替换缓存产品或框架。

**验证**:
```
真实目标上依次验证首次生成、缓存复用、确定性 mtime 变更后重生成；保留原始输出与 RC。
```
