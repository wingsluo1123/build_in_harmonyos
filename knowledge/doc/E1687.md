# E1687: Conan 包装选项的布尔分支必须按值判定

## 基本信息
- **严重度**: 2
- **类别**: build-system, conan, runtime
- **作者**: A201

## 错误特征
```
_PackageOption|static package unexpectedly contains shared objects
```

## 根因分析
Conan shared 选项返回 _PackageOption 对象。False 配置的 bool(value) 为 False，但 value is False 为 False，value is not False 为 True；身份比较导致静态分支继续构建和复制共享库。

## 推荐方案
**方法**: boolean-value-branch-and-real-package-verification

**说明**: 用 if option 或 if not option 按布尔值分支；消费者按实际依赖 options 选共享对象或静态归档；保留共享运行时和真实目标测试。

**验证**:
```
构造实际 Conan Options(shared=False) 检查 bool 和 identity，再执行目标 shared/static 配置及产物清单与消费者
```
