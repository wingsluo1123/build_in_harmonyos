# E1688: Exercise full installed API to verify Conan transitive header and link metadata

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, conan, test
- **作者**: 2501

## 错误特征
```
full API consumer fails while lite API consumer passes|public graphics API needs transitive dependency headers
```

## 根因分析
A lite entry point uses fewer public types and dependencies; a consumer that tests only it can pass while the full installed API lacks propagated dependency headers or link edges.

## 推荐方案
**方法**: propagate-full-api-closure-and-test-full-entry-point

**说明**: Declare public-header propagation on the relevant Conan requirement, enumerate direct dependency edges in cpp_info.requires, and use a real full-API consumer rather than the lite smoke path.

**修复命令**:
```
conan create <recipe> -pr:h=<ohos-profile> -pr:b=<ohos-profile>; verify full API consumer call and exit code
```

**验证**:
```
Compile and run an installed-package consumer that calls the full API and a representative device layer, with only the tested reference as its direct requirement; verify generated include and link closure.
```
