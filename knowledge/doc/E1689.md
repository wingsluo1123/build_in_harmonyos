# E1689: Repair library-internal temporary path selection when it ignores POSIX TMPDIR

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, ohos, portability, test
- **作者**: 2501

## 错误特征
```
Read-only file system.*tmp|temporary output defaults to /tmp despite TMPDIR
```

## 根因分析
The build environment exports a writable TMPDIR, but library source checks only TEMP and TMP before hard-falling back to /tmp; the source never consumes the environment value expected by the test harness.

## 推荐方案
**方法**: add-tmpdir-before-system-fallback

**说明**: Preserve existing explicit overrides, then consult TMPDIR before the hard-coded system fallback; configure a writable per-task directory and run the real writer tests.

**修复命令**:
```
patch temporary-directory selection; export TMPDIR=<task-private-writable-dir>; ctest --output-on-failure
```

**验证**:
```
Run the full upstream test inventory under a writable task-private TMPDIR and verify output creation plus an installed-package consumer; inspect source precedence for TEMP, TMP, and TMPDIR.
```
