# E1691: Audit CMake test targets against CTest registration before claiming full upstream coverage

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, cmake, test
- **作者**: 2501

## 错误特征
```
set_property could not find TARGET|upstream test binary exists but CTest does not register it|CTest testlo bind Operation not permitted under inherited TMPDIR
```

## 根因分析
A project can configure target properties before add_library creates the target, and can build a test variant without add_test registration; a green ctest then covers only the registered subset.

## 推荐方案
**方法**: repair-target-order-and-complete-registration

**说明**: Move target properties after creation and register missing variants. Preserve network assertions with bounded waits. For AF_UNIX tests use a unique short native application-private files directory and set TMPDIR in the command after Conan activation; writable cache paths are not proof of bind capability. Clean the owned directory after CTest even on failure.

**修复命令**:
```
cmake -S <source> -B <build> -DWITH_TESTS=ON -DWITH_CPP_TESTS=ON; cmake --build <build>; ctest --test-dir <build> -N; ctest --test-dir <build> --output-on-failure
```

**验证**:
```
Compare source test targets and built test executables with ctest -N, then execute ctest --output-on-failure and require exact N/N with zero skipped tests.
```
