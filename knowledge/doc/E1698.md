# E1698: 选择性多组件包的 INTERFACE 目标必须同时交付头文件与真实编译依赖闭包

## 基本信息
- **严重度**: 3
- **类别**: cmake, conan, dependency, package-content
- **作者**: 2501_91199785

## 错误特征
```
fatal error.*boost/accumulators/accumulators.hpp.*file not found|Could not find.*Boost::accumulators
```

## 根因分析
多组件上游的选择性安装只交付被选组件及闭包；下游 include 根路径正确不证明目标头已入包。即使新组件本身是 INTERFACE，其官方 CMake target 仍可能公开链接一个已编译的同包组件；只补头文件或声明空的 Conan target 会留下后续链接故障。

## 推荐方案
**方法**: verify-component-content-and-transitive-target-closure

**说明**: 先证实编译命令已含正确 include 根，再检查实际包中的头和组件 config；从精确上游 tag 加入生产与测试选择列表，导出官方 CMake target，并在 Conan 组件 requires 中加入真实的已编译提供者。通过只查找顶层组件的消费者编译及运行验证传播链。

**修复命令**:
```
检查包内目标头、BoostConfig 和 Boost::accumulators 消费者，并运行完整上游 CTest 清单
```

**验证**:
```
conan create archives/b/boost/1.91.0.1.4 -pr:h ci/conan/profiles/ohos-aarch64 -pr:b ci/conan/profiles/ohos-aarch64 --build='boost/*'
```
