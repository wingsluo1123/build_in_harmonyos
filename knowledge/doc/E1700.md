# E1700: 纯 Python 依赖的 site-packages 布局三种并存，package_info 探测须逐一尝试

## 基本信息
- **严重度**: 2
- **类别**: detection, python, packaging
- **作者**: 43AA

## 错误特征
```
Package '.*' not found in the pkg-config search path|ModuleNotFoundError: No module named|expected str, bytes or os.PathLike object, not NoneType|PYTHONPATH.*(missing|empty)|site-packages.*not (found|exist)
```

## 根因分析
本仓库纯 Python 配方由不同来源生成，payload 目录布局不统一——lib/pythonX.Y/site-packages（packaging 风格）、lib/python/site-packages（pyserial/six 实测）、以及 flat 在包根——package_info() 里若只硬编码一种路径，其余依赖的 PYTHONPATH 静默为空，消费者 import 失败

## 推荐方案
**方法**: probe-all-python-dep-site-layouts

**说明**: 写一个 _dep_site() 探测器，按 lib/pythonX.Y/site-packages → lib/python/site-packages → 包根 顺序返回首个存在的目录；对每个依赖逐个调用，不要假设统一布局

**修复命令**:
```
for c in (f"lib/{py_tag}/site-packages", "lib/python/site-packages"): if isdir(join(folder,c)): return c
```

**验证**:
```
ls <dep_package_folder>/lib/*/site-packages <dep_package_folder>/lib/python/site-packages 2>/dev/null; conan test <test_package> <ref> -r=ohpcd
```
