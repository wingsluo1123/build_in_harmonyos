# E1701: A shipped file named install can suppress a legacy Make install recipe

## 基本信息
- **严重度**: 2
- **类别**: build-system, make, packaging
- **作者**: 2501

## 错误特征
```
make install.*up to date|expected installed artifact missing after make install
```

## 根因分析
GNU Make treats a target named install as a filesystem target unless it is declared phony. A release archive can contain an ordinary file named install; then make install exits successfully without executing the installation commands, leaving the Conan package empty or incomplete.

## 推荐方案
**方法**: mark-command-target-phony

**说明**: Match exactly one install rule in the temporary source copy, add .PHONY for that command target, run make install, then fail closed unless the expected library and header are present in the package folder.

**修复命令**:
```
Add .PHONY: install before the exact Makefile install rule; rerun make install -j1.
```

**验证**:
```
Run make install in the target Conan package() phase and assert the installed library and public header both exist.
```
