# E1702: 纯 Python 依赖未声明 run=True，被 conan 标 BINARY_SKIP，消费者运行期 import 失败

## 基本信息
- **严重度**: 3
- **类别**: python, dependency, packaging
- **作者**: E7F5

## 错误特征
```
BINARY_SKIP|Skipped binaries|binary.*[Ss]kip|ModuleNotFoundError: No module named '(serial|usb|six|intelhex)'|No module named .* (from conan dependency)
```

## 根因分析
Conan 2 对 python-require 依赖默认 run=False → Requirement.files 为 False → graph_binaries._skip_binaries() 将该节点标 BINARY_SKIP，节点无 package_folder、无 runenv PYTHONPATH；消费者 conan install 后 import 该依赖直接 ModuleNotFoundError

## 推荐方案
**方法**: pin-run-true-on-every-python-runtime-dependency

**说明**: 对每个纯 Python 运行时依赖显式声明 run=True（self.requires("pkg/ver", run=True)），使其 Requirement.files 为 True，节点保留 package_folder 与 runenv PYTHONPATH

**修复命令**:
```
self.requires("pyserial/3.5", run=True)
```

**验证**:
```
conan create <recipe> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 2>&1 | grep -E "BINARY_SKIP|Skipped"
```
