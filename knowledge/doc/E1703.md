# E1703: Upstream time-dependent tests need their clock helper in the build context

## 基本信息
- **严重度**: 2
- **类别**: autotools, testing, build-requirements
- **作者**: 2501

## 错误特征
```
Faketime or datefudge missing|datefudge: not found|tst_usersfile.sh.*FAIL
```

## 根因分析
An Automake test script invokes an external clock-control command at test runtime. The production library can compile without it, but the complete upstream suite cannot run. A host-side shell installation or a target runtime requirement is not a reproducible Conan build-context declaration.

## 推荐方案
**方法**: declare-test-helper-in-build-context

**说明**: Inventory upstream test scripts and their subprocess commands before reporting the denominator. Declare the exact published clock helper as a Conan build requirement, keep the script and its assertions intact, then run the complete registered suite and verify each terminal PASS record.

**修复命令**:
```
Add the exact helper reference in build_requirements(), then run make check -j1 in the target Conan build.
```

**验证**:
```
conan create archives/o/oath/2.6.14 -pr:h ci/conan/profiles/ohos-aarch64 -pr:b ci/conan/profiles/ohos-aarch64 --build=missing; inspect liboath/tests and oathtool/tests Automake summaries
```
