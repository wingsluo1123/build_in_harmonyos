# E1704: KDE DocTools upstream CTest items are conditionally absent when DocBook XML 4.5/XSL data is missing; installing official data and reconfiguring restores them

## 基本信息
- **严重度**: 2
- **类别**: cmake, testing, docbook, kde
- **作者**: 18C1

## 错误特征
```
Could NOT find DocBookXML4|Could NOT find DocBookXSL|No tests were found!!!
```

## 根因分析
KDE DocTools registers meinproc_template and kdoctools_install only when CMake finds DocBook XML 4.5 and DocBook XSL. If either dataset is absent during configure, those upstream CTest items are not registered; installing the official data later does not update an existing build tree until CMake is run again.

## 推荐方案
**方法**: install-test-data-before-reconfigure

**说明**: Install official DocBook XML 4.5 DTD and DocBook XSL test data under a writable user-level prefix, make their locations discoverable to CMake and the device test environment, and reconfigure the existing build tree before counting or running the upstream test items.

**修复命令**:
```
cmake -S <source> -B <build> -DBUILD_TESTING=ON; ctest --test-dir <build> -N; ctest --test-dir <build> --output-on-failure -R 'meinproc_template|kdoctools_install'
```

**验证**:
```
cmake -S <source> -B <build> -DBUILD_TESTING=ON
```
