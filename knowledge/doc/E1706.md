# E1706: OHOS staged 运行时闭包冒烟测试：musl ldso 不从默认路径解析 libc++_shared.so，LD_LIBRARY_PATH 需前置 /system/lib64 兜底

## 基本信息
- **严重度**: 2
- **类别**: ohos, runtime-resolution
- **作者**: calbee21

## 错误特征
```
Error loading shared library libc\+\+_shared\.so|exit code 127 running packaged binary|\.\/bin: not found \(127\)
```

## 根因分析
Conan 缓存包目录在 OHOS 上只读（HMDFS/E046）且 XPM 拒绝执行未签名 ELF，test_package 普遍把依赖 .so 闭包复制到可写目录再签名单跑；

## 推荐方案
**方法**: prepend-system-lib64-to-staged-closure

**说明**: test_package 的 self.run 在 OHOS 分支把 LD_LIBRARY_PATH 写成 "<staged 闭包目录>:/system/lib64"（staged 优先、系统运行时兜底）；

**修复命令**:
```
'LD_LIBRARY_PATH="$STAGED_DIR:/system/lib64" "$STAGED_BIN" -h; echo rc=$?'
```

**验证**:
```
cd <staged-bin 目录> && ./<binary>; echo rc=$?; 对比 LD_LIBRARY_PATH="<staged>:/system/lib64" ./<binary>
```
