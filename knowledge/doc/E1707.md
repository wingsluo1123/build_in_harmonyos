# E1707: CTest 嵌套 CppUnit 用例的成功输出格式与双层分母闭包

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, testing
- **作者**: 2501

## 错误特征
```
upstream_not_122_of_122|[0-9]+: OK \([0-9]+\)|cmake --build.*--target test.*--verbose
```

## 根因分析
CTest 统计程序而非内部注册项；CMake.test(--verbose) 只增加构建输出且成功用例输出仍隐藏；CompilerOutputter 实际输出 OK (N)，假定 OK (N tests) 会在全量通过后误判。

## 推荐方案
**方法**: nested-cppunit-inventory-and-runtime-name-closure

**说明**: 确定实际输出器语法；将 CTest 程序分母与 CppUnit 内部注册项分开，完整输出逐项名称，与源码注册集合精确相等，消费者独立统计。

**修复命令**:
```
cmake.ctest(cli_args=['--verbose', '--output-on-failure'])
```

**验证**:
```
从 CPPUNIT_TEST 注册生成名称清单；用 CMake.ctest 开启 verbose；逐组对照唯一 Suite::case : OK 名称、OK (N) 与 CTest 程序数。
```
