# E1713: 上游自带 Conan 1.x 配方向 Conan 2.x 重写：header-only 库保持官方源 + SHA-256 硬校验 + 消费者 test_package 验证的可复用边界

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, conan, packaging, headonly
- **作者**: pc3-40
- **来源 PR**: (未授权创建)

## 错误特征
```
from conans import|must be all lowercase|package_type|set_version|CMakeDeps.*target|BadZipFile|not a valid os
```

## 根因分析
upstream 自带的 Conan 1.x 配方（from conans import CMake, ConanFile, tools）与项目 OHOS 适配版 Conan 2.x（2.29.1）API 断裂：1.x 导入路径、tools.get_env、set_version 正则提取等模式在 2.x 无对应物；同时 header-only 库须按 2.x 语义声明 package_type="header-library"、空 cpp_info.libs、CMakeToolchain 注入 OHOS 平台（CMAKE_SYSTEM_NAME=Linux / CMAKE_SYSTEM_PROCESSOR=aarch64），并用 CMakeDeps imported target 让真实消费者验证 find_package + target_link_libraries。源码获取保持官方 URL（R39）不变并以归档 SHA-256 硬校验（get() 校验内容，镜像只是传输通道）。

## 推荐方案
**方法**: conan1-to-conan2-header-only-rewrite

**说明**: 按 Conan 2.x 重写配方骨架：from conan import ConanFile；cmake_layout；get(**conan_data["sources"], strip_root=True)（conandata 保持官方 URL + 归档 SHA-256）；generate() 对 OHOS/Linux 注入 CMAKE_SYSTEM_NAME=Linux + CMAKE_SYSTEM_PROCESSOR=aarch64；package_type="header-library"，cpp_info.set_property(cmake_file_name/cmake_target_name) 且 cpp_info.libs=[]；test_package 用 find_package(indicators) + indicators::indicators 真实调用 API（option::Stream 避免污染终端）。

**修复命令**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create archives/i/indicators/2.3.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 && python3 scripts/ohc-run.py conan-verify indicators 2.3.0 --profile ohos-aarch64 && file <build>/test_indicators
```
