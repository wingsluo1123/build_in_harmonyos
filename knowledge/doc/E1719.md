# E1719: summary.py 同一 manifest key 先标量后列表导致 str.append 崩溃

## 基本信息
- **严重度**: 2
- **类别**: framework, parsing, summary, yaml
- **作者**: junshi_liu <liujsh2023@lzu.edu.cn>

## 错误特征
```
AttributeError: 'str' object has no attribute 'append'|SUMMARY.md 生成失败|setdefault.*append
```

## 根因分析
scripts/ohc/summary.py 的 _parse_yaml_simple() 用 data.setdefault(current_list_key, []) 假定目标 key 首次出现即为列表；当同一 YAML key 先以标量（key: value）出现、后以列表项（- item）出现时，data[key] 已是 str，setdefault 不覆盖，随后对该 str 调用 .append() 抛 AttributeError: 'str' object has no attribute 'append'，导致 ohc summary / finish gen_summary 失败（R05 实测触发：archives/q/qpdf/12.3.2 与 12.3.2.1 的 manifest.yaml）。

## 推荐方案
**方法**: defensive-list-coercion-before-append

**说明**: 追加列表项前先取 data.get(current_list_key)，若非 list 则置空列表再 append；避免 setdefault 返回既有 str 后调用 .append 崩溃；语义仍按列表收集不变。

**修复命令**:
```
|
```

**验证**:
```
python3 scripts/ohc-run.py summary --project-dir <worktree>（修复前 rc=1 报 str append；修复后 rc=0，SUMMARY.md 生成成功）
```
