## 推荐方案
**方法**: keep-active-snapshot-preview-status-then-approve-continue

**说明**: 预览回报用 preview 状态（terminal=false）+ 完整字段，保持同一 task_id 活动快照；

**修复命令**:
```
<report preview with status=delivery_preview_awaiting_approval, terminal=false> && <await approval> && <execute authorized remote writes under same task_id>
```

```

```
