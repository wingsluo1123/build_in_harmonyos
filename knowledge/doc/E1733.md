# E1733: Feed the upstream CMake test framework in as a packaged dependency instead of a configure-time download

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan, testing
- **作者**: W082
- **来源 PR**: 7324

## 错误特征
```
By not providing "FindCatch2.cmake" in CMAKE_MODULE_PATH|Could not find a package configuration file provided by "(Catch2|GTest|doctest)"|Catch2Config.cmake.*not found
```

## 根因分析
Upstream CMake projects declare their test framework inside the test-option branch (FetchContent_Declare(Catch2 URL https://github.com/...) plus FetchContent_MakeAvailable), so merely enabling the upstream suite makes CMake configure depend on an external code host. The package repository already publishes those frameworks, but rewriting the fetch into find_package(Catch2 REQUIRED) is not sufficient on its own: Conan generates no Catch2Config.cmake unless the recipe calls CMakeDeps(self).generate(), so the rewritten configure fails with the error signature above.

## 推荐方案
**方法**: packaged-test-framework-with-cmadeps-generation

**说明**: Keep the upstream suite enabled and move the framework from a network fetch to a package input in three coupled steps: require the repository-published framework gated behind the same upstream-test option; patch only the fetch lines into find_package(<TestFramework> REQUIRED) through the recipe patch pipeline (refresh-patch --auto, no test-logic change); and generate the CMake config package with CMakeDeps(self).generate() before the toolchain. Gating the requirement on the option keeps the shipped package dependency-free, so a header-only cleared package_id stays unchanged and consumers never see a test dependency.

**修复命令**:
```
python3 scripts/ohc-run.py refresh-patch <name> <version> --auto; conanfile.py requirements(): self.requires("catch2/2.13.10-r0") when run_upstream_tests / generate(): CMakeDeps(self).generate(); conan create .
```

**验证**:
```
grep -RnE 'FetchContent_Declare|ExternalProject_Add' <source>/CMakeLists.txt <source>/test/CMakeLists.txt; conan create <recipe> 2>&1 | grep -E 'FindCatch2|Could not find a package configuration'; conan test test_package <reference>
```
