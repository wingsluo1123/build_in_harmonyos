# E1736: Eigen consumer tests should prove the packaged include path is required

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, testing, consumer-boundary, negative-test
- **作者**: C0DX

## 错误特征
```
negative include-path test|false-green|source tree headers|packaged include path
```

## 根因分析
A positive consumer build can accidentally succeed if headers are still visible from the source tree or

## 推荐方案
**方法**: positive-smoke-plus-negative-probe

**说明**: Keep a normal consumer smoke test, then remove the packaged include path and expect the build to fail.

**修复命令**:
```
conan create archives/e/eigen/3.4.1 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
CI_PACKAGES="archives/e/eigen/3.4.1" zsh ci/conan/build_and_test.sh
```
