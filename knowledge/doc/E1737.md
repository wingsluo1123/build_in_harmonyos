# E1737: Header-only eigen packages need include and consumer evidence when L5 has no binaries

## 基本信息
- **严重度**: 2
- **类别**: headers, conan, packaging, testing, artifact-validation
- **作者**: C0DX

## 错误特征
```
L2_RESULT=skip: no bin/ dir|L5_RESULT=warn: no artifacts found|no bin/ dir|no artifacts found
```

## 根因分析
Binary-oriented gates cannot validate a header-only package by finding bin/lib

## 推荐方案
**方法**: header-only-consumer-plus-negative-test

**说明**: Accept L2 skip and L5 warning only after verifying installed include/metadata

**修复命令**:
```
conan create archives/e/eigen/3.4.1 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
CI_PACKAGES="archives/e/eigen/3.4.1" zsh ci/conan/build_and_test.sh
```
