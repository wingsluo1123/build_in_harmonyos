# E1739: 库运行时硬编码 P_tmpdir/O_TMPFILE 无视 TMPDIR 时，用 LD_PRELOAD shim 重定向无名临时文件

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, testing, filesystem, ld-preload
- **作者**: ohpcd <ohpcd@localhost>
- **来源 PR**: 7647

## 错误特征
```
error creating or writing to a temporary file|
```

## 根因分析
上游 C 库创建临时文件时硬编码 P_tmpdir（"/tmp"）：open() 带

## 推荐方案
**方法**: ld-preload-unnamed-tmpfile-redirect

**说明**: 编译 LD_PRELOAD shim（-fPIC -shared，OHOS clang 工具链，产物经

**修复命令**:
```
clang -fPIC -shared ohos_tmpdir_shim.c -o ohos_tmpdir_shim.so &&
```

**验证**:
```
conan create archives/p/python3-cairo/1.29.1 --build=missing
```
