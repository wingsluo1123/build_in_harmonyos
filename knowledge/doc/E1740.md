# E1740: vector<bool> 迭代器代理引用必须在容器专用重载中转成 bool

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, cxx, libcxx, proxy-reference
- **作者**: ALPACA

## 错误特征
```
undefined symbol.*bit_const_reference|undefined symbol.*bit_reference|to_bytes.*__bit_const_reference
```

## 根因分析
std::vector<bool> 使用位压缩存储，其迭代器元素不是 bool，而是实现相关的代理引用类型。若通用容器循环把该代理直接送入仅声明的 class 序列化模板，编译可通过但链接阶段会留下未定义的代理类型 to_bytes 符号。

## 推荐方案
**方法**: vector-bool-specialized-value-routing

**说明**: 在 std::vector<bool> 专用序列化重载中先写入 size，再以 bool 值循环调用标量序列化路由，避免把实现相关代理引用暴露给通用 class 模板；反序列化仍按 bool 元素恢复。

**修复命令**:
```
for (const bool value : input) to_bytes_router<O>(value, bytes, byte_index)
```

**验证**:
```
cmake -S . -B build -DALPACA_BUILD_TESTS=ON && cmake --build build -j1 && ./build/test/tests --test-suite=vector
```
