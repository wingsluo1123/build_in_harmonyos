# E1751: Add -fno-optimize-sibling-calls and -fno-omit-frame-pointer 

## 基本信息
- **严重度**: medium
- **类别**: compiler, testing, optimization
- **作者**: unknown

## 错误特征
```
test failure: backtrace test functions optimized away despite __attribute__((noclone))
```

## 根因分析
Clang on OHOS aarch64 ignores GCC-specific __attribute__((noclone)), causing test functions (e.g., callback_one, callback_two in libbacktrace test suite) to be optimized via tail call elimination or frame pointer omission. This breaks backtrace stack frame tests that expect distinct function entries.

## 推荐方案
**方法**: Add -fno-optimize-sibling-calls and -fno-omit-frame-pointer to CFLAGS for test compilation targets only (not the library itself). In Makefile-based builds, use TEST_CFLAGS or target-specific CFLAGS; in CMake, set COMPILE_FLAGS on test targets.
