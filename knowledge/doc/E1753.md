# E1753: HarmonyOS/musl iconv 不识别 IBM437/IBM-437 别名，需回退 CP437 重试

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, python, iconv
- **作者**: pc2-5

## 错误特征
```
bytes_to_str error: unknown encoding: `IBM437`|
```

## 根因分析
glibc 系 iconv 同时登记 IBM437 与 CP437 两个别名，指向同一

## 推荐方案
**方法**: source-patch-encoding-alias-retry

**说明**: 在 bytes_to_str 的 iconv_open 失败分支（errno==EINVAL）中，

**修复命令**:
```
kaitai/kaitaistream.cpp bytes_to_str() 的 EINVAL 分支:
```

**验证**:
```
(cd build-dir/tests && LD_LIBRARY_PATH=.. ./unittest --gtest_filter='*ibm437*:*big_dest*')
```
