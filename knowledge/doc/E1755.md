# E1755: LD_PRELOAD interposition libraries on musl/OHOS hit LFS64 macro redefinitions, mmsg prototype mismatches, and lose DT_SONAME when cmake sees the host as HarmonyOS

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, libc, musl, cmake
- **作者**: unknown

## 错误特征
```
redefinition of 'fopen'|redefinition of 'open'|redefinition of 'openat'|
```

## 根因分析
Three independent musl/OHOS differences break glibc-oriented

## 推荐方案
**方法**: undef-lfs64-macros + prototype-detection + explicit-system-name

**说明**: (1) Add `#undef fopen64/open64/openat64` (guarded by __OHOS__)

**验证**:
```
/data/service/hnp/bin/llvm-readelf -d <pkg>/lib/lib<name>.so | grep SONAME; nm -D <pkg>/lib/lib<name>.so | grep -E "fopen64|recvmmsg"
```
