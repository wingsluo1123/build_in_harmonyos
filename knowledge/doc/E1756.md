# E1756: Conan PkgConfigDeps 生成的 glib-2.0.pc 缺 datadir/glib_mkenums

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, meson, pkg-config, .pc
- **作者**: ohpcd <ohpcd@localhost>

## 错误特征
```
Variable 'datadir' not defined in .*glib-2\.0\.pc|
```

## 根因分析
Conan 的 PkgConfigDeps 只从依赖包的 package_info 生成

## 推荐方案
**方法**: merge-missing-pc-vars

**说明**: 在 generate() 里读 glib 包原始 lib/pkgconfig/glib-2.0.pc，

**修复命令**:
```
(conanfile generate() 中)
```

**验证**:
```
conan create archives/p/polkit/127 --build=missing
```
