# E1757: OHOS libintl.h 为空 stub 不声明 gettext() 时，gi18n.h 的

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, compilation, nls, i18n
- **作者**: ohpcd <ohpcd@localhost>, pc1-2

## 错误特征
```
undeclared function 'gettext'|
```

## 根因分析
glib 的 gi18n.h 无条件定义

## 推荐方案
**方法**: gettext-identity-macro

**说明**: 在编译参数加 `-Dgettext(x)=(x)` 恒等宏：让 gi18n.h 里

**修复命令**:
```
(conanfile generate() 中)
```

**验证**:
```
conan create archives/p/polkit/127 --build=missing
```
