# E1758: configure 工具探测命中系统 curl-config 而非私有 prefix 时，用

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, autotools, configure, cache-variable
- **作者**: ohpcd <ohpcd@localhost>

## 错误特征
```
curl/curl\.h.*file not found|
```

## 根因分析
asterisk configure 的 AST_EXT_LIB_CHECK([CURL]) 经 AC_PATH_TOOL

## 推荐方案
**方法**: configure-cache-var-tool-override

**说明**: 在私有 prefix/bin 放 curl-config shim（--cflags/--libs 报 prefix

**修复命令**:
```
./configure ... --with-curl=<prefix> \
```

**验证**:
```
conan create archives/a/asterisk-curl/22.10.1 --build=missing
```
