# E1767: header-only CMake 库 conan create 需 BUILD_TESTING=OFF，避免 fuzzing 目标链接 libclang_rt.fuzzer.a 在 OHOS 上报 std::__h 符号缺失

## 基本信息
- **严重度**: 2
- **类别**: ohos, headers, build-system, cmake, toolchain
- **作者**: unknown

## 错误特征
```
ld\.lld: error: undefined symbol: std::__h::(ios_base::init|basic_streambuf|basic_iostream|basic_ios|basic_istream).*|libclang_rt\.fuzzer\.a|too many errors emitted, stopping now
```

>

## 推荐方案
**方法**: build-testing-off-in-conan-build

**说明**: conanfile.py 的 build() 中显式

**修复命令**:
```
conanfile.py build(): cmake.configure(variables={"BUILD_TESTING": "OFF"}); cmake.build()
```

**验证**:
```
grep -nE 'BUILD_TESTING|add_subdirectory\(.*fuzz' <source>/CMakeLists.txt; conan create . 2>&1 | grep -E 'undefined symbol: std::__h|libclang_rt.fuzzer'
```
