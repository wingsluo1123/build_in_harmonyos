# E1768: OHOS libc++ charconv 无浮点 from_chars，库的编译器版本判断宏需按平台关闭

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, charconv, libcxx
- **作者**: pc1-5, pc3-8

## 错误特征
```
call to deleted function 'from_chars'|
```

## 根因分析
OHOS SDK (26.0.0.18) 的 libcxx-ohos charconv 仅提供整型

## 推荐方案
**方法**: platform-gate-float-from-chars-macro

**说明**: 在库的配置头（如 cmake/bitserializerConfig.h.in 生成 config.h）的

**修复命令**:
```
在 config.h.in 的宏判断处按 __OHOS__ 关闭：
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
