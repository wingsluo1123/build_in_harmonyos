# E1769: libc++ SSO 下拥有字符串输入移动后 data() 地址变化，使解析器直读指针悬空（TablePull Move 用例返回 NUL）

## 基本信息
- **严重度**: 2
- **类别**: toolchain, libc++, move-semantics, parser, sso
- **作者**: unknown

## 错误特征
```
std::basic_string.*::__rep|owned_string_input|table_pull.*Move|CharsBufferSizes.*Move
```

## 根因分析
libc++ 的 SSO（小字符串优化）内联缓冲阈值约为 22 字符：短串数据存于 basic_string 对象内部。

## 推荐方案
**方法**: heap-stable-owned-input

**说明**: 将 owned_string_input 的内部字符串改为经堆间接层持有（如 std::unique_ptr<std::basic_string>），

**修复命令**:
```
git apply patches/0001-include-commata-char_input.hpp.patch
```

**验证**:
```
./build/src_test/test_commata --gtest_filter='CharsBufferSizes/TestTablePull*'
```
