# E1770: libc++ std::basic_string 无法搭配非平凡默认构造的 fancy-pointer 分配器（SSO union __rep 默认构造被隐式删除）

## 基本信息
- **严重度**: 2
- **类别**: toolchain, testing, memory, libc++, stl
- **作者**: unknown

## 错误特征
```
call to implicitly-deleted default constructor of .*::__rep|implicitly-deleted default constructor|fancy_ptr
```

## 根因分析
libc++（OHOS libcxx-ohos）的 std::basic_string 内部使用 SSO 布局，其 __rep 是含 __long/__short 变体的 union 且无用户提供的默认构造。

## 推荐方案
**方法**: libcxx-conditional-std-allocator

**说明**: 在测试/示例代码中用 `#if defined(_LIBCPP_VERSION)` 条件编译：libc++ 下改用标准分配器

**修复命令**:
```
#if defined(_LIBCPP_VERSION) ... #else ... #endif
```

**验证**:
```
clang++ -std=c++17 -Iinclude -Isrc_test src_test/TestRecordExtractor.cpp -c（OHOS clang 15, libcxx-ohos）
```
