# E1782: OHOS 下 GNUInstallDirs 选 lib64 导致 CMakeDeps "Library not found in package"

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, conan, packaging, libdir
- **作者**: tianyi

## 错误特征
```
Library '.*' not found in package|cmakedeps_macros\.cmake.*not found in package|
```

## 根因分析
上游 CMake 用 GNUInstallDirs，64 位平台上 CMAKE_INSTALL_LIBDIR

## 推荐方案
**方法**: cache-variables-force-libdir

**说明**: generate() 中用 tc.cache_variables["CMAKE_INSTALL_LIBDIR"]

**修复命令**:
```
tc.cache_variables["CMAKE_INSTALL_LIBDIR"] = "lib"
```

**验证**:
```
conan create <recipe> -pr:h=<ohos-profile> --build=missing
```
