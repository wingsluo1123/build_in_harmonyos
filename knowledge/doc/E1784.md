# E1784: Pass ADDITIONAL_CPPFLAGS as a make command-line argument; GNUstep make does not read it from the environment

## 基本信息
- **严重度**: 3
- **类别**: ohos, make, configure, compilation, environment
- **作者**: 7408
- **来源 PR**: 7408

## 错误特征
```
ADDITIONAL_CPPFLAGS|CPPFLAGS.*not.*used|GNUSTEP_BASE_HAVE_LIBXML=|undefined.*macro|header.*not found|clang.*error
```

## 根因分析
GNUstep make's build rules do not propagate

## 推荐方案
**方法**: make-command-line-flags

**说明**: Pass ADDITIONAL_CPPFLAGS (and any required LDFLAGS) directly on the

**修复命令**:
```
make ADDITIONAL_CPPFLAGS="-I<include> -DGNUSTEP_BASE_HAVE_LIBXML=0 ..."
```

**验证**:
```
Build gnustep-gui 0.31.1 with the flags passed on the make command
```
