# E1788: Makefile recipes on OHOS must bind the profile compiler and package with Conan copy

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, make, conan
- **作者**: unknown

## 错误特征
```
"make: cc: No such file or directory; install: No such file or directory"
```

## 根因分析
"Portable Makefiles often default to host command names such as cc and install. The OHOS Conan profile can provide a target clang path without changing those Makefile defaults, and the target environment may not provide a standalone install command."

## 推荐方案
**方法**: "read tools.build:compiler_executables, pass CC/CXX to make, and use Conan copy() for package layout"

**说明**: "Keep the toolchain boundary in the recipe: pass the profile compiler to upstream make and copy only verified library/header outputs in package(). Run the upstream test target with the same compiler and verify the package with a real consumer."

**修复命令**:
```
'compiler = (self.conf.get("tools.build:compiler_executables", default={}, check_type=dict) or {}).get("c", "cc"); self.run(f"make CC={compiler} test", cwd=self.source_folder)'
```

**验证**:
```
"conan create <archive> -pr:h=<ohos-profile> -pr:b=<ohos-profile> --build=missing; test_package must link and execute a real API consumer"
```
