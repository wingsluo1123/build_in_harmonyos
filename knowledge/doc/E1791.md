# E1791: Meson static_library 生成 thin archive 时的 Conan 自包含打包

## 基本信息
- **严重度**: 2
- **类别**: build-system, meson, conan, static-library, llvm-ar
- **作者**: unknown

## 错误特征
```
could not get the buffer for a child of the archive|No such file or directory.*\.a\.p/.*\.o
```

## 根因分析
Meson/LLVM 生成的静态归档可能是 thin archive；归档成员只保存相对构建目录的对象路径。

## 推荐方案
**方法**: rebuild-self-contained-archive

**说明**: package() 先定位唯一的 lib*.a 和其 .p/*.o 成员，将对象复制到临时目录，

**修复命令**:
```
llvm-ar rcs <package-tmp>/libcexception.a <package-tmp>/CException.c.o
```

**验证**:
```
conan create <archive> -pr:h=<ohos-profile> -pr:b=<ohos-profile> --build=missing
```
