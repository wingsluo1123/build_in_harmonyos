# E1795: CONFIG_SHELL=bash 时 configure 由老 ltmain.sh 生成 libtool 丢失引号转义,make 阶段 syntax error near `}'

## 基本信息
- **严重度**: 3
- **类别**: platform, autotools, toolchain
- **作者**: Awstme
- **来源 PR**: (本 PR)

## 错误特征
```
libtool: line \d+: syntax error near unexpected token `\}'|local: \*; \};.*ver
```

## 根因分析
OHOS 的 conan profile buildenv 将 CONFIG_SHELL 指向 hnp bash 并在 env 聚合顺序中

## 推荐方案
**方法**: config-shell-pin

**说明**: conanfile build() 内以命令行前缀赋值 `CONFIG_SHELL=/bin/sh <configure> <args>`

**修复命令**:
```
CONFIG_SHELL=/bin/sh ${SOURCE_FOLDER}/configure --build=<triplet> --host=<triplet> ...
```

**验证**:
```
grep -m1 'archive_expsym_cmds=' libtool | grep -c '\\"'  # 为 0 且含 ver~ 即命中
```
