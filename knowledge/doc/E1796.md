# E1796: hnp clang已内嵌codesign签名的共享库被binary-sign-tool selfSign重签后musl加载器SIGSEGV

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, musl, packaging, runtime
- **作者**: 3D26
- **来源 PR**: (PR 创建后回填,见关联路径 B Issue)

## 错误特征
```
Signal 11 \(core dumped\)|ConanException: Error 139 while executing
```

## 根因分析
hnp clang驱动在链接期已对输出ELF内嵌ad-hoc .codesign签名段(readelf -S在本地meson产物与Conan包产物均见该段);binary-sign-tool selfSign生成的重签段与本机musl加载器不兼容,加载重签产物即SIGSEGV core dump;对照实验:剥离重签产物的.codesign段后同一消费者二进制立即恢复可加载(40/40断言通过)

## 推荐方案
**方法**: no-re-sign

**说明**: 共享库不做二次签名:保留链接器内嵌.codesign签名,package()只做版本别名实体化

**修复命令**:
```
readelf -S /lib/libX.so* | grep -c codesign
```

**验证**:
```
readelf -S libcanfigger.so.0 | grep -c codesign; LD_LIBRARY_PATH=<pkg>/lib ./test_canfigger # 重签产物exit 139, 剥离.codesign后PASS assertions=40
```
