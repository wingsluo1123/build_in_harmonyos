## 推荐方案
**方法**: regen-pc-via-pkgconfigdeps-plus-path-injection

**说明**: >

**修复命令**:
```
PkgConfigDeps(self).generate(); env.prepend_path("PKG_CONFIG_PATH", self.generators_folder); env.vars(self, scope="build").save_script(...)
```

**验证**:
```
PKG_CONFIG_PATH="$(conan cache path 'cfitsio/4.6.4:<pkgid>')/lib/pkgconfig" pkg-config --variable=prefix cfitsio
```
