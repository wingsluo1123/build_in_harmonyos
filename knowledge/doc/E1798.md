# E1798: 上游 benchmarks 在 configure 期无条件 file(DOWNLOAD) 且无禁用开关时用补丁选项守卫

## 基本信息
- **严重度**: 2
- **类别**: network, build-system, cmake, conan
- **作者**: IUTF8

## 错误特征
```
file\(DOWNLOAD\).*github.*zip|import_dependency\(|add_subdirectory\(benchmarks\).*configure
```

## 根因分析
is_utf8 1.4.1 顶层 CMakeLists.txt 无条件 add_subdirectory(benchmarks)，其 cmake/import.cmake 的 import_dependency() 在 configure 阶段用 file(DOWNLOAD) 从 GitHub 拉 simdutf zip 并 add_subdirectory 进来；与 BUILD_TESTING 无关，也没有任何上游选项可关闭。干净 CI/离线环境在 configure 即触发外网下载，配方无法只靠 -D 变量规避。

## 推荐方案
**方法**: patch-add-option-and-guard-subdirectory

**说明**: 用最小补丁在上游顶层 CMakeLists 新增默认 OFF 的项目选项（如 IS_UTF8_BUILD_BENCHMARKS）并把对应 add_subdirectory 包进 if 守卫；配方显式传该选项为 OFF，保留 BUILD_TESTING=ON 让上游真实测试照常运行（与 E342 不同：本例下载源不在测试路径内，无需牺牲上游测试覆盖）。补丁不含平台条件宏，全平台语义一致。

**修复命令**:
```
refresh-patch --auto 生成 0001-CMakeLists.txt.patch；conandata.yml 声明 patch；tc.variables["IS_UTF8_BUILD_BENCHMARKS"]="OFF"；设备端 conan create 复验 ctest 1/1。
```

**验证**:
```
grep -RnE 'file\(DOWNLOAD|import_dependency' <src>/cmake <src>/*/CMakeLists.txt; cmake -S . -B build 2>&1 | grep -i downloading; conan create archives/i/is_utf8/1.4.1 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
