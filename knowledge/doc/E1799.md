# E1799: 制品仓 Boost 裁剪版配方缺失组件目标/头文件时选用完整配方版本 (cpp-rotor 0.35)

## 基本信息
- **严重度**: 3
- **类别**: ohos, cmake, conan, dependency, boost
- **作者**: unknown

## 错误特征
```
Target .* links to: Boost::[A-Za-z_]+ but the target was not found|boost/lockfree/.*file not found|Component 'boost::[a-z_]+' not found in 'boost' package requirement
```

## 根因分析
制品仓存在裁剪版 Boost 配方（如 1.90.0.4/1.91.0/1.91.0.1），_components 仅含编译组件子集（缺 date_time），且头文件按组件裁剪导出（缺 include/boost/lockfree、posix_time）；CMakeDeps 不生成对应 Boost::xxx 目标，下游配置期 target not found 或编译期头文件缺失。完整配方（如 1.84.0）导出全部组件与完整头文件。

## 推荐方案
**方法**: select-full-boost-recipe

**说明**: conanfile.py requirements() 选用制品仓完整配方 Boost 版本（本项目 boost/1.84.0）并声明 transitive_headers=True；generate() 输出 CMakeDeps + CMakeToolchain（BUILD_SHARED_LIBS 按 shared 选项）；package_info() 的 cpp_info.requires 使用 conan 组件名（boost::boost_date_time 等，非 CMake 目标名 Boost::date_time）

**修复命令**:
```
self.requires("boost/1.84.0", transitive_headers=True)  # + generate() CMakeDeps/CMakeToolchain
```

**验证**:
```
conan list "boost/<版本>/*" -r=ohpcd; conan install --requires=boost/1.84.0 -pr:a=ci/conan/profiles/ohos-aarch64 -g CMakeDeps; grep -c "COMPONENT Boost::date_time" Boost-Target-release.cmake
```
