# E1801: glib 产物 NEEDED libintl.so.8 + g_libintl_* UND 符号 → 机器 gettext(/usr/local/lib/libintl.so.8) 经 LD_LIBRARY_PATH 遮蔽 vendored proxy-libintl（环境陷阱，非配方缺陷）

## 基本信息
- **严重度**: 2
- **类别**: ohos, runtime, environment
- **作者**: unknown

## 错误特征
```
g_libintl_.*: symbol not found|Error relocating .*libglib-2.0\.so|NEEDED.*libintl\.so\.8|UND.*g_libintl_
```

## 根因分析
|

## 推荐方案
**方法**: env-specific-shadow-documented

**说明**: glib 配方不改、版本不升（2.84.0.1 保持）。文档化陷阱：构建/验证/运行必须在

**修复命令**:
```
env -u LD_LIBRARY_PATH conan create <pkg> ... ; env -u LD_LIBRARY_PATH LD_LIBRARY_PATH=$PACKAGE_LIB ./test_probe
```

**验证**:
```
readelf -d <pkg>/lib/libglib-2.0.so | grep NEEDED; readelf -Ws <pkg>/lib/libglib-2.0.so | grep -c 'UND.*g_libintl'; readelf -Ws <pkg>/lib/libintl.so.8 | grep -c g_libintl_gettext; env -u LD_LIBRARY_PATH LD_LIBRARY_PATH=<pkg>/lib ./test_probe; # 应 OK
```
