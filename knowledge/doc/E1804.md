# E1804: BSD sys/sysctl.h 在 OHOS/musl 上缺失时，把 include 与 sysctlbyname 调用收敛到 __APPLE__ 守卫

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, libc, headers, guard
- **作者**: pc1-12 <noreply@atomgit.com>

## 错误特征
```
sys/sysctl\.h.*file not found|fatal error:.*sys/sysctl\.h|sysctlbyname.*undeclared
```

## 根因分析
sys/sysctl.h 是 BSD/macOS 专有头文件，OHOS 使用 musl libc 不提供该头。

## 推荐方案
**方法**: apple-guard-bsd-header-include

**说明**: 把 BSD/macOS 专有头文件的 include 收敛到与 API 调用相同的平台守卫

**修复命令**:
```
sed -n '/sys\/sysctl.h/,+3p' src/xxx.c（确认 include 与调用分支是否对称）
```

**验证**:
```
conan create archives/c/chipmunk2d/7.0.3 -pr:h=ci/conan/profiles/ohos-aarch64
```
