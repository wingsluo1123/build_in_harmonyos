# E1805: Linux Kbuild 内核模块无法在 OHOS CI 构建时导出加固源码并做 fail-closed 契约验证

## 基本信息
- **严重度**: 2
- **类别**: ohos, kernel, conan, testing, kbuild
- **作者**: 6499
- **来源 PR**: 6499

## 错误特征
```
linux/module\.h.*No such file|linux/acpi\.h.*No such file|kernel headers.*not available|kernel build tree.*not found|KDIR.*not found|ConanInvalidConfiguration.*kernel|Cannot generate.*\.ko
```

## 根因分析
Linux Kbuild 外部模块依赖目标内核 configured build tree、内核头和导出符号；OHOS userspace sysroot 与共享 CI 不提供这些契约，普通交叉编译无法生成或验证可加载模块。

## 推荐方案
**方法**: pinned-hardened-source-package-with-fail-closed-contract

**说明**: >

**修复命令**:
```
sh test_package/check_source.sh "${package_src}/acpi_call.c"
```

**验证**:
```
CI_PACKAGES="archives/a/acpi_call/1.2.2" zsh ci/conan/build_and_test.sh
```
