# E1810: gtest 1.17.0.1 Conan CMake GTest 组件导出契约

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, dependency-contract
- **作者**: zxyAtom
- **来源 PR**: 8612

## 错误特征
```
GTest::gtest_main|GTest::gmock|cmake_file_name.*GTest|gtest::gtest
```

## 根因分析
Conan 的 CMakeDeps 导出若只声明 lowercase gtest::gtest，无法满足上游消费者通过 find_package(GTest CONFIG) 请求的 GTest 配置名和 gtest/gmock 四组件目标契约，导致依赖库虽已打包但消费者配置阶段不可用。

## 推荐方案
**方法**: export-upstream-GTest-components

**说明**: 在 package_info 中设置 cmake_file_name=GTest，并为 gtest、gtest_main、gmock、gmock_main 声明对应库、目标名和 requires 关系，使 CMakeDeps 输出与上游 GTest 配置契约一致；用真实消费者验证配置、链接和运行。

**验证**:
```
cmake -S test_package -B build -DCMAKE_PREFIX_PATH=<conan-package> && cmake --build build && ./build/test_gtest
```
