# E1813: Guard both linking and KLocalizedQmlContext use behind an optional KF6 I18nQml target

## 基本信息
- **严重度**: medium
- **类别**: build-system, dependency-resolution
- **作者**: zxyAtom
- **来源 PR**: 7399

## 错误特征
```
KF6::I18nQml|KLocalizedQmlContext|HAVE_KLOCALIZEDQMLCONTEXT
```

## 根因分析
KNewStuff unconditionally linked and used KLocalizedQmlContext even when the optional KF6::I18nQml target was absent, so guarding only the link leaves C++ references that cannot compile.

## 推荐方案
**方法**: couple-target-and-source-guards

**说明**: Use if(TARGET KF6::I18nQml) for the link, define a matching feature macro there, and compile-guard every KLocalizedQmlContext include, construction and use with that macro.

**验证**:
```
conan create archives/k/knewstuff/6.18.0 -pr:h ohos-aarch64
```
