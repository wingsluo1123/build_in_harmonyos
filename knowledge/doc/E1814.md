# E1814: Probe effective write denial before treating chmod read-only as a file-system contract

## 基本信息
- **严重度**: medium
- **类别**: filesystem, test-risk
- **作者**: zxyAtom
- **来源 PR**: 7430

## 错误特征
```
File system kept owner write permission|File system allows writes to the chmod read-only mbox test file
```

## 根因分析
A chmod request alone does not establish a read-only mbox on every OHOS-backed file system, so a permission assertion is invalid unless both the owner-write bit is cleared and an append open is denied.

## 推荐方案
**方法**: verify-effective-readonly-before-test

**说明**: Restore the original mode and QSKIP only when the post-chmod mode or append probe disproves the test precondition; continue the upstream read-only behavior test when both probes establish it.

**验证**:
```
conan create archives/k/kmbox/25.12.3 -pr:h ohos-aarch64
```
