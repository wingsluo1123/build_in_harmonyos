# E1815: lang_detect 全文件扫描命中测试目录内辅助 Cargo.toml（Rust 参考实现）→ C++ 库被误判 mixed(cargo)；按 R47"辅助工具不算主体"复核顶层 manifest 判 cpp

## 基本信息
- **严重度**: 3
- **类别**: build-system, language, preflight, tooling
- **作者**: unknown, AtomCode
- **来源 PR**: (同 PR 交付)

## 错误特征
```
lang-preflight.*detected_language.*mixed|build_system.*cargo|
```

## 根因分析
_manifest_scan 用全文件集合 rglob 检索 Cargo.toml（不限顶层），CMakeLists.txt 却只取顶层；

## 推荐方案
**方法**: top-level-manifest-and-body-share-judgement

**说明**: lang-preflight 输出 mixed 且任务语言为 c/cpp 时，先核对主库主体：①顶层 manifest（CMakeLists.txt/Makefile/configure.ac）；②主体源码占比（≥70%）；③辅助目录（android/、tests/ 参考实现等）不计入主体。主库为 c/cpp 时按 R47 D.4 边界规则判 detected=cpp（c↔cpp 兼容族不迁移），可复制源码到临时目录剔除辅助子目录后复跑 lang-preflight 取得工具自身 cpp 判定作为证据，记录证据后继续适配主流程；仅当主库主体确为非 c/cpp 时才走 env_unsupported/lang_hold。

**修复命令**:
```
复核优先级：①顶层 manifest（CMakeLists.txt/Makefile/configure.ac）；②主体源码占比（≥70%）；③辅助目录（test/*/rust_ref 等）不计入主体；判定成立则按 R47 继续 cpp 适配，实测不被工具 mixed 误判终态
```

**验证**:
```
python3 scripts/ohc-run.py lang-preflight emio 0.9.0 --src <src>；复核顶层 CMakeLists.txt + 源码统计占比
```
