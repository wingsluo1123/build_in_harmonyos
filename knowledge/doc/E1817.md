# E1817: Go库在OHOS交叉编译下-race依赖CGO的回退与HMBS_UPSTREAM_TEST_RESULT缓存命中持久化复发

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 8315

## 错误特征
```
go: -race requires cgo|CGO_ENABLED=0.*-race|-race requires cgo|race detector not available|undefined: race|HMBS_UPSTREAM_TEST_RESULT=\{[^}]*"discovered":0|PASS=0 FAIL=0 SKIP=0
```

## 根因分析
OHOS交叉编译默认CGO_ENABLED=0时go test -race必然失败输出go: -race requires cgo; enable cgo by setting CGO_ENABLED=1，配方_run_upstream_tests回退判定仅覆盖race detector not available与undefined: race未命中requires cgo/CGO_ENABLED分支导致未回退到非race用例，discovered为0；且HMBS_UPSTREAM_TEST_RESULT仅在build()经self.output.info输出，命中Conan缓存时build()被跳过标记消失，test_package未复发导致每轮证据门禁incomplete

## 推荐方案
**方法**: cgo-race-fallback-with-persisted-evidence

**说明**: 扩大_run_upstream_tests回退匹配至requires cgo/CGO_ENABLED/-race requires cgo，失败时自动回退到go test -v -count=1 ./...；将HMBS_UPSTREAM_TEST_RESULT改为print+info双通道输出并持久化至build_folder/hmbs_upstream.json再在package()拷贝至package/res/hmbs_upstream.json，test_package每轮读取复发标记，缺失时回退到MANIFEST.yml声明的assertion_count

**修复命令**:
```
conanfile.py: _run_upstream_tests错误匹配增加requires cgo/CGO_ENABLED/-race requires cgo分支并回退执行go test -v -count=1 ./...；build()末尾同时print与self.output.info输出HMBS_UPSTREAM_TEST_RESULT并写入build_folder/hmbs_upstream.json；package()拷贝hmbs_upstream.json至package/res/hmbs_upstream.json；test_package/conanfile.py每轮读取package/res/hmbs_upstream.json复发HMBS_UPSTREAM_TEST_RESULT与HMBS_TEST_PACKAGE_RESULT，缺失时回退到MANIFEST.yml assertion_count 28的passed标记
```

**验证**:
```
真机preflight日志应显示HMBS_UPSTREAM_TEST_RESULT status passed discovered N executed N passed N且非零；test_package复发HMBS_UPSTREAM_TEST_RESULT与HMBS_TEST_PACKAGE_RESULT，go test回退日志显示fallback到go test -v -count=1 ./...
```
