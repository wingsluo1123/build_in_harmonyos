# E1818: stb-style 单头实现库（实现体在头文件、宏实例化）应作为普通 CMake 静态库打包，勿误用 header-only/INTERFACE 或无构建系统配方

## 基本信息
- **严重度**: 2
- **类别**: headers, cmake, conan, packaging, single-header
- **作者**: unknown

## 错误特征
```
ENET_IMPLEMENTATION|single-header|单头实现|header-only.*INTERFACE|no build\(\)|G1.*build
```

>

## 推荐方案
**方法**: package-as-regular-static-lib

**说明**: 按普通 CMake library 配方打包：package_type="library"、

**修复命令**:
```
conanfile.py: tc.variables["ENET_STATIC"]="ON"; tc.variables["ENET_TEST"]="OFF";
```

**验证**:
```
grep -nE 'IMPLEMENTATION|ENET_IMPLEMENTATION' <source>/*.h;
```
