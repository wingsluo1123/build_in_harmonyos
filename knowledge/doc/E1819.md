# E1819: 同库大版本构建系统迁移（如 autotools→CMake）时 conan-init 依据旧版本历史生成过期模板，须按新版本实际构建系统重写配方并回填真实 sha256

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, autotools, conan, migration
- **作者**: unknown

## 错误特征
```
AutotoolsToolchain|configure_args|REPLACE_WITH_ACTUAL_SHA256|no CMakeLists|template.*autotools
```

## 根因分析
>

## 推荐方案
**方法**: rewrite-recipe-by-actual-build-system

**说明**: 以新版本源码实际构建系统为准重写 conanfile.py：CMake 库用

**修复命令**:
```
cp templates/conanfile-cmake.py.tmpl archives/<l>/<name>/<version>/conanfile.py;
```

**验证**:
```
ls <source>/CMakeLists.txt; grep -nE 'project\(|option\(' <source>/CMakeLists.txt;
```
