# E1820: libjpeg-turbo 3.0.4 工具用斜杠相对 NEEDED(../libjpeg.so) 链接，加载器按进程 cwd 解析，LD_LIBRARY_PATH 无效；ctest 全量运行需在父目录放置库符号链接

## 基本信息
- **严重度**: 2
- **类别**: platform, cmake, loading, test
- **作者**: pc2-3

## 错误特征
```
Error loading shared library \.\./libjpeg\.so|Error relocating .*symbol not found|NEEDED.*\.\./lib[a-z]+\.so|tests passed.*tests failed out of
```

## 根因分析
|

## 推荐方案
**方法**: parent-dir-symlink-for-slash-relative-NEEDED

**说明**: 在包含斜杠相对 NEEDED 的可执行文件的**父目录**（即 cwd 的上一级）放置指向真实 .so 的符号链接，

**修复命令**:
```
ln -sf build-native/libjpeg.so ../libjpeg.so; ln -sf build-native/libturbojpeg.so ../libturbojpeg.so; cd build-native && LD_LIBRARY_PATH=$PWD ctest --output-on-failure -j4
```

**验证**:
```
readelf -d build-native/djpeg | grep NEEDED; cd build-native && ctest -N; ln -sf ../build-native/libjpeg.so ../libjpeg.so && cd build-native && LD_LIBRARY_PATH=$PWD ctest
```
