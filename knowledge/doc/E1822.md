# E1822: header-only 库 .tpp 中的非模板自由函数需标 inline，否则多翻译单元包含时链接重复符号

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, linking
- **作者**: unknown

## 错误特征
```
ld.lld: error: duplicate symbol:|duplicate symbol .*::do_get_intersection|duplicate symbol .*::set_union|duplicate symbol .*::set_difference|multiple definition of
```

## 推荐方案
**方法**: source-patch

**说明**: 给 .tpp 中的非模板自由函数加 inline 关键字（或改为模板/

**修复命令**:
```
|
```

**验证**:
```
clang++ -std=c++20 a.cpp b.cpp -o out（a/b 均 include 同一头）
```
