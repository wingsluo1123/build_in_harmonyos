# E1825: C++17 移除 std::random_shuffle 导致老 C++ 代码 use of undeclared identifier

## 基本信息
- **严重度**: 2
- **类别**: compat, portability
- **作者**: opendesk-qa

## 错误特征
```
use of undeclared identifier 'random_shuffle'|random_shuffle.*was not declared|random_shuffle.*undeclared
```

## 根因分析
2000s-era 老 C++ 代码直接调用 std::random_shuffle（C++14 弃用、C++17 移除）。OHOS profile 以 -std=c++17 编译（compiler.cppstd=17）时符号不存在，报 use of undeclared identifier 'random_shuffle'，且 clang 在 make 子进程静默环境下该错误行是唯一线索。

## 推荐方案
**方法**: replace-with-std-shuffle

**说明**: 将 random_shuffle(begin,end) 替换为 std::shuffle(begin,end,std::mt19937(std::random_device{}()))，并确保源文件 include <algorithm> 与 <random>（老文件常依赖传递包含）。

**修复命令**:
```
content.replace('random_shuffle (b,e);', 'std::shuffle (b,e,std::mt19937(std::random_device{}()));')
```

**验证**:
```
grep -rn "random_shuffle" <src> 定位全部使用点；替换后 clang++ -std=c++17 -c 重编译验证。
```
