# E1836: E017 镜像注入恢复失败污染活文件 conandata.yml（url 标量→镜像列表）并被 submit 自动 git add 带入已推送提交：守卫仅匹配 ghfast.top 的白名单缺口、正确基线 preflight 捕获与事后修复

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, atomicity, e017, r39
- **作者**: wanderlust_0823/S8V1
- **来源 PR**: (创建后回填)

## 错误特征
```
PF7.*镜像前缀 gh-proxy\.com|"url":\s*$|url:\s*\n\s*-\s*"https://gh-proxy\.com|已恢复原始 conandata\.yml|git add ✅|conandata.*gh-proxy\.com/https://github\.com
```

## 根因分析
三段失效链：(1) conan_verify.py 的 E017 镜像注入在 github 拉源失败时把 conandata.yml 的 sources.url 从标量改写为 URL 列表（gh-proxy.com 包装 + 官方 URL），日志打印"已恢复原始 conandata.yml"但恢复实际失败——v12.17 的崩溃恢复守卫条件是"仅当前文件含 ghfast.top 才回滚"，本次注入域名是 gh-proxy.com，守卫不命中，活文件以镜像列表形态残留在工作区（非旁文件）；(2) 工作区污染后继续运行 finish/W4/submit，submit 的自动 git add 把污染的 conandata.yml 一并提交（"git add ✅ → git commit → git push"），污染进入远端分支；(3) 本地共享仓库的 main 分支落后上游 1646 个提交，JC6/W3 junk_check 与 create-pr 内嵌 preflight 的 origin/main...HEAD / main...HEAD 基线把上游存量数百个 conandata.yml 误算为"本次变更"，全量扫描既误报（31 个包/数百 PF7 违规）又超出 submit 30s 子进程超时，真实捕获手段是用正确基线直接调用 run_preflight(repo, "upstream/main", "HEAD")——以正确基线 PASS、以过期基线 FAIL，恰好隔离出本次真实变更里的唯一违规就是被注入污染的 conandata.yml。

## 推荐方案
**方法**: restore-guard-domain-set + correct-baseline-preflight + post-push-repair

**说明**: 三层处置：(a) 交付前守卫——提交前对本次变更文件运行"正确基线" preflight（upstream/main...HEAD，而非本地 main/origin/main），PF7 会精确指认活文件中的 gh-proxy.com 残留；改动过 conandata.yml 的每次 conan-verify 后用 git diff 核对 url 是否仍为官方标量形态；(b) 事后修复——git show <干净提交>:<path> > <path> 恢复官方形态，rm -rf .build-cache/，精确 git add 单文件（绝不 git add -A），新提交修复并 push（不 force-push 覆盖历史）；(c) 框架修复建议（主编/框架 PR 处理）——E017 恢复守卫的域名条件从 ghfast.top 扩展为注入域名集合（gh-proxy.com/ghfast.top/moeyy.cn 等），恢复后增加"恢复结果自检"（diff 回官方形态否则视为失败上抛），submit 自动 git add 前置正确基线 preflight。

**修复命令**:
```
git show <clean_sha>:<pkg>/conandata.yml > <pkg>/conandata.yml && rm -rf .build-cache && git add <pkg>/conandata.yml && git commit && git push && python3 -c "from ohc.preflight import run_preflight; print(run_preflight('<repo>','upstream/main','HEAD'))"
```

**验证**:
```
git show HEAD:archives/<l>/<pkg>/<ver>/conandata.yml | grep -c gh-proxy ; git -C <repo> diff --name-only upstream/main...HEAD ; python3 -c "import sys; sys.path.insert(0,'scripts'); from ohc.preflight import run_preflight; print(run_preflight('<repo>','upstream/main','HEAD'))"
```
