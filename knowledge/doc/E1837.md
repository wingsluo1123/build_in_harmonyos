# E1837: Unpublished test-only Conan dependency blocks the upstream suite

## 基本信息
- **严重度**: 3
- **类别**: build-system, conan, dependency, testing
- **作者**: wanderlust_0823
- **来源 PR**: OpenHarmonyPCDeveloper/build_in_harmonyos!7926

## 错误特征
```
Package libtheft was not found|theft.h: No such file or directory|Unable to find.*theft/0.4.5
```

## 根因分析
The production library builds without external packages, but its upstream test target requires theft/0.4.5 through pkg-config and theft.h; the exact test-only recipe is absent from the local cache and ohpcd, so the suite cannot compile in a clean OHOS environment.

## 推荐方案
**方法**: separate-production-build-from-unpublished-test-dependency

**说明**: Verify the missing exact dependency with build=never, build and package the independent production library with a real consumer test, and report the upstream suite as blocked. Publish the test dependency first before re-enabling the full upstream suite; never use build=missing, vendored copies, dummy packages, or print-only tests.

**修复命令**:
```
conan install --build=never --requires=theft/0.4.5@ohpcd/stable; make CC=/data/service/hnp/bin/clang library; conan create . --build=skiparray/*
```

**验证**:
```
conan install --build=never --requires=theft/0.4.5@ohpcd/stable; make CC=/data/service/hnp/bin/clang library; make CC=/data/service/hnp/bin/clang test
```
