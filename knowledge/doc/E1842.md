# E1842: OHOS 设备 Python 的 platform.system() 返回 "HarmonyOS"，上游按 OS 分支的 Python 自动检测脚本落空，用显式编译器参数绕过

## 基本信息
- **严重度**: 2
- **类别**: platform, build-system, python
- **作者**: unknown

## 错误特征
```
No compiler found!|KeyError.*Darwin|unknown platform|unsupported platform
```

## 根因分析
OHOS 设备全局 Python（3.12.8）的 platform.system() 返回发行版定制的 "HarmonyOS"，

## 推荐方案
**方法**: explicit-compiler-arg

**说明**: 优先用上游脚本自带的显式参数（如 -c/--compiler clang++）或环境变量（CC/CXX）

**修复命令**:
```
python3 scripts/compile_cpp.py tests/BS_thread_pool_test.cpp --run -c clang++ -s c++17
```

**验证**:
```
python3 -c "import platform; print(platform.system())"
```
