# E1846: C 头文件中的 GNU typeof 宏被 C++ 编译单元包含时 clang++ 报 undeclared identifier（改用 __typeof__）

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, compiler, cxx
- **作者**: unknown

## 错误特征
```
use of undeclared identifier 'typeof'|did you mean 'typeid'|typeof\(.*\) .* undeclared
```

## 根因分析
上游 C 头文件用 GNU 扩展 typeof(ptr) 写内存分配宏

## 推荐方案
**方法**: typeof-to-__typeof__

**说明**: 把宏定义中的 typeof(expr) 全部改写为 __typeof__(expr)。

**修复命令**:
```
refresh-patch --auto <lib> <version> && 更新 conandata.yml patches 列表
```

**验证**:
```
clang++ -std=gnu++11 编译包含该头的 C++ TU；修复后用
```
