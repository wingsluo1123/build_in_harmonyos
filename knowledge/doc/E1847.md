# E1847: OHOS sysroot stdio.h 定义 `stdout (stdout)` 递归宏 → 严格警告集构建被 -Wdisabled-macro-expansion 拦截

## 基本信息
- **严重度**: 3
- **类别**: ohos, headers, clang, runtime, werror
- **作者**: unknown

## 错误特征
```
disabled expansion of recursive macro \[-Werror,-Wdisabled-macro-expansion\]|error: disabled expansion of recursive macro
```

## 根因分析
OHOS SDK sysroot 的 stdio.h 将 stdout 定义为递归宏形式

## 推荐方案
**方法**: relax-wdisabled-macro-expansion-in-ohos-test-build

**说明**: 在 OHOS 上构建包含宏内 stdout/stdin 引用的测试套件时，

**修复命令**:
```
cmake -S tests -B build -DENABLE_CUDA=OFF \
```

**验证**:
```
echo '#define L(...) fprintf(stdout, __VA_ARGS__); L("x")' > t.c && /data/service/hnp/bin/clang -Werror -Wdisabled-macro-expansion -c t.c 2>&1 | grep -c 'disabled expansion of recursive macro'; cmake -S <tests> -B build -DCMAKE_C_FLAGS=-Wno-disabled-macro-expansion && cmake --build build && ctest
```
