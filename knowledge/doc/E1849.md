# E1849: 用绝对路径 -pr:h=<worktree>/ci/conan/profiles/ohos-aarch64

## 基本信息
- **严重度**: 2
- **类别**: conan, environment, profile
- **作者**: unknown

## 错误特征
```
Invalid: 'settings\.os\.version' value not defined|os=OHOS.*os\.version.*not defined|profile.*与文件内容不符|libcxx=libstdc\+\+11.*gnu14
```

## 根因分析
本机 ~/.conan2/profiles 下存在与 worktree 内 ci/conan/profiles/ohos-aarch64

## 推荐方案
**方法**: 用绝对路径 -pr:h=<worktree>/ci/conan/profiles/ohos-aarch64

**说明**: 绝对路径强制指定官方 OHOS profile，规避 home 同名副本遮蔽

**修复命令**:
```
conan create archives/e/elfio/3.9/conanfile.py --name=elfio --version=3.9 -pr:h=$(pwd)/ci/conan/profiles/ohos-aarch64 -pr:b=$(pwd)/ci/conan/profiles/ohos-aarch64 -s build_type=Release
```
