# E1850: Stage the upstream KDE Desktop Theme.qml at the Qt Quick CTest resource path

## 基本信息
- **严重度**: medium
- **类别**: packaging, testing, qt-qml
- **作者**: zxyAtom
- **来源 PR**: 7443

## 错误特征
```
tst_icon\.qml|Missing upstream test theme|org/kde/kirigami/Theme\.qml
```

## 根因分析
Kirigami's Qt Quick icon test resolves the KDE Desktop Theme.qml from the build-tree resource path, while ordinary QML import paths only expose installed modules and leave that test data unavailable.

## 推荐方案
**方法**: stage-upstream-qml-test-theme

**说明**: Before CTest, copy the upstream org.kde.desktop Theme.qml into build/bin/org/kde/kirigami/Theme.qml, then run the original Qt Quick test suite while explicitly excluding only tst_theme.qml when the OHOS runner lacks the required desktop platform plugin and font data.

**验证**:
```
conan create archives/k/kirigami/6.18.0 -pr:h ohos-aarch64
```
