# E1855: GTest 1.17 头文件需要 C++17（CTAD/if constexpr），C++11 时代上游测试需 -std=c++17 并同时链接 gmock

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, build-system, testing
- **作者**: unknown

## 错误特征
```
use of class template 'function' requires template arguments.*gtest-param-test\.h|
```

## 根因分析
GTest ≥1.14/1.17 头文件（gtest-param-test.h）使用 C++17 的

## 推荐方案
**方法**: test-compile-cxx17-plus-gmock

**说明**: 上游测试用 -std=c++17 编译（仅测试目标，不影响库本体 C++11）；

**验证**:
```
clang++ -std=c++17 -I include -I $GT/include 编译 test/src/*.cpp
```
