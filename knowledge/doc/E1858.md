# E1858: HMFS下Autoconf因umask 077与toybox mktemp导致config.status临时目录只读的通用修复

## 基本信息
- **严重度**: 3
- **类别**: platform, hmdfs, ohos, build-system, autotools
- **作者**: hmbs-executor
- **来源 PR**: 8618

## 错误特征
```
config\.status: error: could not setup config files machinery|HMBS_PLATFORM_CAPABILITIES=\{[^}]*"chmod":0
```

## 根因分析
HMFS上toybox mktemp -d按umask 077创建drwx--S---目录并拒绝后续写入，Autoconf AS_TMPDIR首选mktemp路径命中该受限目录即硬失败，config.status无法创建subs1.awk等临时文件

## 推荐方案
**方法**: remove-umask-redirect-tmpdir-chmod-tolerant

**说明**: 正则删除configure及内嵌config.status模板中umask 077，将TMPDIR/TMP/TEMP重定向到HMBS可写tmpdir，SHELL规范为/bin/sh且chmod容错

**修复命令**:
```
conanfile.py新增_patch_configure_umask()正则删umask 077及mktemp两处；build()首部TMPDIR/TMP/TEMP指向HMBS注入tmpdir，SHELL/CONFIG_SHELL=/bin/sh，chmod +x容错
```

**验证**:
```
真机preflight compile阶段不再报config.status错误并进入后续编译，temporary_directory_readonly消失
```
