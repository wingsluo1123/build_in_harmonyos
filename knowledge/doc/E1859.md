# E1859: 官方 release 分发物与 tag 归档内容差异：版本占位符与测试向量

## 基本信息
- **严重度**: 2
- **类别**: build-system, make, conan, source
- **作者**: unknown

## 错误特征
```
"Monocypher version __git__|I cannot perform the tests without the test vectors|tests/vectors.h: No such file or directory"
```

## 根因分析
"GitHub tag 归档由 git 树快照生成，未经过发布流水线：版本串保持 __git__ 占位符（发布时才替换），且不含发布时生成的 tests/vectors.h（需 libsodium 重新生成），导致 make check 无法构建；官方 release 分发物才是内容完整、版本串正确的正式产物。"

## 推荐方案
**方法**: "conandata.yml 使用官方 release 分发物 URL（releases/download/<ver>/<name>-<ver>.tar.gz），以其为 .orig/.work 基线；tag 仅核验存在性并记录 commit，不作为下载源。"

**说明**: "先核验 tag 归档与 release 分发物差异（版本串、测试向量、dist 目标），优先选择 release asset 作为 conan 源码源，保持 R39 官方源要求。"

**修复命令**:
```
"curl -fsSL -o <name>-<ver>.tar.gz https://github.com/<owner>/<repo>/releases/download/<ver>/<name>-<ver>.tar.gz && tar tzf <name>-<ver>.tar.gz | grep vectors.h"
```

**验证**:
```
"sha256sum <name>-<ver>-release.tar.gz; tar tzf <release.tar.gz> | grep tests/vectors.h; head -1 <extracted>/src/monocypher.c"
```
