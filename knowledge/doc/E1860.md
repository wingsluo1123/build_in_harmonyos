# E1860: On HMDFS, link(2)-based atomic lockfile creation fails with

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, conan, filesystem, atomic-lock, source-patch
- **作者**: unknown

## 错误特征
```
lockfile_create.*L_MAXTRYS|dotlockfile.*exit.*4|link.*Operation not permitted|ln.*Operation not permitted.*hard link|No rule to make target.*lockfile
```

## 根因分析
liblockfile's lockfile_create() uses a two-phase atomic lock

## 推荐方案
**方法**: runtime-link-eperm-oexcl-fallback

**说明**: Replace the plain link(tmplock, lockfile) with a runtime probe:

**修复命令**:
```
# lockfile.c lockfile_create_save_tmplock():
```

**验证**:
```
ln t1 locktest.lock 2>&1;   # expect Operation not permitted
```
