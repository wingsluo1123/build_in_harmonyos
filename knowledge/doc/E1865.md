# E1865: Perl >= 5.26 removed '.' from @INC — build-time perl generators that `do` a relative spec path fail

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, build-system, perl
- **作者**: PC39

## 错误特征
```
"'\\.' is no longer in @INC|did you mean do \"./|generate_emitter\.pl.*Fatal error|@INC.*generate_regalloc"
```

## 根因分析
Perl 5.26 removed the current directory '.' from @INC for

## 推荐方案
**方法**: export PERL_USE_UNSAFE_INC=1 in the build environment

**说明**: (待补充)

**验证**:
```
PERL_USE_UNSAFE_INC=1 make -j1 CC=clang LINK=clang
```
