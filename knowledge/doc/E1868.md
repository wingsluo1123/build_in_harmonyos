# E1868: header-only test_package 消费者源码须用 .cc 后缀（CXX-only 项目）；.c 后缀触发 CMake 链接语言错误

## 基本信息
- **严重度**: 2
- **类别**: headers, cmake, conan, packaging, testing
- **作者**: unknown

## 错误特征
```
Cannot determine link language for target .*|CMake can not determine linker language for target
```

## 根因分析
conan-init 为 C 类项目生成的 test_package 默认使用 test.c 与 project(... C)；把项目改为 CXX（C++ 消费者必须用 C++，R34 真实调用被测包 API）后，残留的 .c 源文件在 CXX-only 的 CMake 工程里被当作 C 源处理，而工程未启用 C 语言支持，CMake 无法确定该目标的链接语言，configure 阶段报 "Cannot determine link language for target"。C++ 消费者测试源必须使用 .cc/.cpp 后缀，且 CMakeLists 与 test_package/MANIFEST.yml 的 file 声明同步改名。

## 推荐方案
**方法**: cpp-source-suffix-for-consumer-test

**说明**: C++ 消费者测试源统一使用 .cc（或 .cpp）后缀；CMakeLists 中 project() 语言与 add_executable 源文件后缀保持一致；同步更新 test_package/MANIFEST.yml 的 file 字段与 command 字段。

**修复命令**:
```
git mv test_package/test.c test_package/test.cc && sed -i 's/test\.c/test.cc/' test_package/CMakeLists.txt test_package/MANIFEST.yml && 重新运行 conan-verify
```

**验证**:
```
cmake 配置与构建 test_package；成功路径为二进制可编译链接并通过 CTest
```
