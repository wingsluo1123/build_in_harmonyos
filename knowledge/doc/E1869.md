# E1869: Conan 2 copy() 在 package() 中的 dst 必须为 package_folder 绝对路径；相对路径按进程 CWD 解析导致空包

## 基本信息
- **严重度**: 2
- **类别**: headers, conan, packaging, copy, files
- **作者**: unknown

## 错误特征
```
package\(\).*WARN: No files in this package!|Imported target .* includes non-existent path .*\/include
```

## 根因分析
Conan tools.files.copy() 的 dst 相对路径按 Python 进程 CWD 解析，而 package() 执行时进程 CWD 是构建目录而非 package_folder；向 dst="include" 拷贝时文件实际落到 CWD/include，包目录为空。CMakeDeps 据此生成 INTERFACE_INCLUDE_DIRECTORIES=<pkg>/include，消费者配置时报 "includes non-existent path"，conan create 的 test_package 阶段失败。

## 推荐方案
**方法**: absolute-package-folder-dst

**说明**: package() 中 copy() 的 dst 一律使用 os.path.join(self.package_folder, <相对路径>) 绝对路径；pattern 与 src 不变。header-only 配方统一按 include/licenses 布局装入。

**修复命令**:
```
copy(self, "picojson.h", src=self.source_folder, dst=os.path.join(self.package_folder, "include"))；copy(self, "LICENSE", src=self.source_folder, dst=os.path.join(self.package_folder, "licenses"), keep_path=False)
```

**验证**:
```
conan create 后检查包目录存在 include/<header>；test_package 的 CMake find_package 配置不再报 non-existent path
```
