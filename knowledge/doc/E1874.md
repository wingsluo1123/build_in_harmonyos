# E1874: 上游测试源声明 void main() 且无显式 return，进程退出码未定义（OHOS aarch64 实测 7）；最小 portability 补丁改为 int main()+return 0 使稳定退出 0

## 基本信息
- **严重度**: 2
- **类别**: portability, testing, upstream
- **作者**: pc1-17
- **来源 PR**: (本 PR)

## 错误特征
```
exit code 7|void main\(\)|Segmentation|undefined exit|rc=7|退出码 7
```

## 根因分析
C 标准（C99+）要求 main 返回 int；上游以 `void main()` 声明且不写 return 时，进程

## 推荐方案
**方法**: portability-main-return-patch

**说明**: int main() + return 0 最小补丁，登记 conandata.yml patch_type=portability

**修复命令**:
```
patch 文件（void main→int main + 末尾 return 0）；conandata.yml patches 登记
```

**验证**:
```
clang -I src -o test/test_binn_json test/test_binn_json.c conversions/json/binn_json.c src/binn.c -L <jansson_lib> -ljansson && ./test/test_binn_json; echo $?  # 修复前 7，修复后 0
```
