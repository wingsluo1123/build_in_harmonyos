# E1876: CMake >= 4.0 移除 cmake_policy(SET CMP0037 OLD)，需按版本号守卫

## 基本信息
- **严重度**: 2
- **类别**: cmake, toolchain, conan
- **作者**: unknown

## 错误特征
```
Policy CMP0037 may not be set to OLD behavior because this version of CMake no longer supports it
```

## 根因分析
"CMake 4.x 移除了 CMP0037（target name 'test' 保留字）的 OLD 兼容模式；上游 CMake 辅助模块

## 推荐方案
**方法**: "if(CMAKE_VERSION VERSION_LESS 4.0) cmake_policy(SET CMP0037 OLD) endif()"

**说明**: "将 cmake_policy(SET CMP0037 OLD) 包在 CMAKE_VERSION 版本守卫内，CMake>=4 时跳过

**修复命令**:
```
"patch -p1 < patches/0002-cmake-c4Project-cmp0037.patch"
```

**验证**:
```
"grep -n 'CMP0037' CMakeLists.txt cmake/ 2>/dev/null; cmake --version"
```
