# E1877: c4core 系 CMake 辅助子模块在官方 tarball 中缺失（cmake/ 与 debugbreak/），需 export_sources 打包恢复

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan, source
- **作者**: unknown

## 错误特征
```
include could not find requested file: ./ext/c4core/cmake/c4Project.cmake|unknown platform. CMAKE_SYSTEM_NAME=HarmonyOS
```

## 根因分析
"GitHub source tarball 不含 git 子模块内容，只留空目录。rapidyaml 0.7.2 依赖 c4core v0.2.2

## 推荐方案
**方法**: "conan 配方 export_sources 打包子模块内容，build() 恢复后再 configure"

**说明**: "将 c4core 的 cmake/ 子模块 22 个 .cmake 模块与 debugbreak.h 放入配方 patches/ 目录，

**修复命令**:
```
"conan create archives/r/rapidyaml/0.7.2 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing"
```

**验证**:
```
"tar tzf <c4core-v0.2.2.tar.gz> | grep 'cmake/' ; ls ext/c4core/cmake/ 2>/dev/null"
```
