# E1880: OHOS musl declares POSIX getline in the default mode without any feature macro: legacy same-name definitions must be renamed, not warning-downgraded (strict ISO mode hides the declaration)

## 基本信息
- **严重度**: 2
- **类别**: platform, libc, posix, declarations, legacy-c
- **作者**: GoliWie

## 错误特征
```
conflicting types for 'getline'|static declaration of 'getline' follows non-static|conflicting types for 'getdelim'
```

## 根因分析
OHOS musl stdio.h declares

## 推荐方案
**方法**: rename-legacy-definition

**说明**: Rename the private definition (and its call

**修复命令**:
```
sed -i 's/\bgetline(/legacy_getline(/g' util.c  (word-boundary rename scoped to the owning file(s))
```

**验证**:
```
printf '#include <stdio.h>\nint getline(char*s,int n,FILE*f){return 0;}' | /data/service/hnp/bin/clang -xc - -c 2>&1 | grep -q "conflicting types for 'getline'" && printf '#include <stdio.h>\nint getline(char*s,int n,FILE*f){return 0;}' | /data/service/hnp/bin/clang -xc -std=c11 - -c && echo PROBE_OK
```
