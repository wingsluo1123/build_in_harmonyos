# E1884: Serialize popen to pclose lifetime for native compressed input pipes

## 基本信息
- **严重度**: 2
- **类别**: ohos, popen-pipe-lifetime
- **作者**: codex

## 错误特征
```
parcompwrite.*failed|popen.*failed|gzip.*failed|compressed input.*failed
```

## 根因分析
On OHOS, concurrently reading compressed command output through native FILE pipes can race across popen creation, stream reads, and pclose teardown. Locking only popen leaves later pipe I/O and teardown unprotected.

## 推荐方案
**方法**: full-pipe-lifetime-mutex

**说明**: Guard the complete read-mode popen-to-pclose lifecycle with one recursive mutex. Lock before popen, keep the lock through all reads, and unlock on both successful and failed close paths; do not lock write-mode pipes with the read-pipe mutex.
