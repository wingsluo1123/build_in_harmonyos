# E1885: OHOS(musl 加载器)下 CMake 动态插件必须构建为 SHARED 并显式链接依赖,否则 dlopen 时符号无法解析

## 基本信息
- **严重度**: 2
- **类别**: platform, cmake, toolchain, linking
- **作者**: unknown

## 错误特征
```
Error relocating .*\.so: .*symbol not found|undefined symbol: .*referenced by|Target ".*" of type MODULE_LIBRARY may not be linked
```

## 根因分析
OHOS 动态链接器为 musl,dlopen() 默认 BIND_NOW;corrade 2020.06 在非 Windows

## 推荐方案
**方法**: plugin-shared-explicit-link

**说明**: OHOS 下将 corrade_add_plugin 改为 SHARED 并显式链接插件依赖 + -Wl,-z,undefs

**修复命令**:
```
cmake -B build -DCMAKE_SHARED_LINKER_FLAGS="-Wl,-z,undefs" -DCMAKE_MODULE_LINKER_FLAGS="-Wl,-z,undefs" ...
```
