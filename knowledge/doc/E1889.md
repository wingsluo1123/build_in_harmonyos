# E1889: upgrade-cas-memory-order

## 基本信息
- **严重度**: 2
- **类别**: threading, memory, aarch64, memory-ordering
- **作者**: pc1-57 <executor@oh-runner>

## 错误特征
```
Memory leak detected.*rpmalloc_finalize: 3034|Assertion failed: .*_mapped_pages == 0|Linked list corrupted.*1105
```

## 根因分析
rpmalloc 1.4.5 的跨线程释放路径把完全释放的 span 以 relaxed CAS 推入 owner heap

## 推荐方案
**方法**: upgrade-cas-memory-order

**说明**: 把 deallocate_defer_free_span 入链使用的 atomic_cas_ptr 由

**验证**:
```
./bin/linux/release/arm64/rpmalloc-test 2>&1 | tail -3; echo $?
```
