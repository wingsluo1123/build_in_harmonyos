# E1890: OHOS上停用LD_PRELOAD改用内嵌DT_RPATH解析传递依赖并修复只读tmp与vendored定位，6/6验证通过真机证据门禁

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, musl, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 8623

## 错误特征
```
Error loading shared library libjpeg\.so\.62.*needed by.*libqpdf\.so|no such file or directory: '.*/e/vendored/paper\.c'|HMBS_UPSTREAM_TEST_RESULT=\{[^}]*"status": *"no_tests"
```

## 根因分析
OHOS musl loader忽略LD_LIBRARY_PATH且不从LD_PRELOAD其余条目解析被预载库自身的DT_NEEDED传递依赖，预载libqpdf必死于其DT_NEEDED libjpeg.so.62；兼有裸mktemp -d写只读/tmp、Conan2 exports_sources误当recipe_folder读取致e/vendored缺失、MANIFEST非空测试命令致no_tests误判为上游存在测试

## 推荐方案
**方法**: disable-ld-preload-embed-dt-rpath

**说明**: 主二进制经LDFLAGS/LDLIBS双通道嵌入-Wl,--disable-new-dtags加-Wl,-rpath指向各依赖libdir自带DT_RPATH解析qpdf及传递libjpeg；测试包彻底停用LD_PRELOAD并unset；test.sh改用TMPDIR模板mktemp并修正计数5到6；vendored改export_sources_folder定位；MANIFEST测试命令置空并结构化审计no_tests

**修复命令**:
```
conanfile.py: rpath_flags经LDFLAGS/LDLIBS传入make LDLIBS；test_package/conanfile.py: 删除LD_PRELOAD改为llvm-readelf/readelf -d诊断；test.sh: 顶部unset LD_PRELOAD加mktemp -d ${TMPDIR}/paperjam.XXXXXX加6项真实调用；MANIFEST.yml: upstream_check_command/upstream_test_command置空加upstream_test_audit结构化映射
```

**验证**:
```
真机preflight应显示RESULT: 6 passed, 0 failed与HMBS_TEST_PACKAGE_RESULT executed true passed true discovered 6 passedCount 6，且readelf -d显示DT_RPATH含conan依赖libdir
```
