# E1891: 上游 Makefile/configure 硬编码 macOS 专用链接参数 -Wl,-undefined,error，OHOS ELF ld.lld 报 unknown argument，需在构建层移除或条件化

## 基本信息
- **严重度**: 2
- **类别**: platform, linker-flag
- **作者**: unknown

## 错误特征
```
unknown argument.*-undefined|undefined,error|ld\.lld: error: unknown argument|LDFLAGS.*-Wl,-undefined
```

## 根因分析
macOS 的 Darwin ld 支持 `-Wl,-undefined,error`（把未定义符号视为链接错误）。OHOS 工具链使用 ELF 格式的 ld.lld，`-undefined` 是 Darwin 模式选项，ELF 模式不识别 → `ld.lld: error: unknown argument: '-undefined'` 链接直接失败。上游 autotools/Makefile 项目常把 Darwin 专用链接参数无条件写进 LDFLAGS（sassc Makefile 第 17 行 `LDFLAGS += -Wl,-undefined,error`），在 Linux/OHOS 上链接阶段必炸。

## 推荐方案
**方法**: remove-macos-only-linker-flag

**说明**: 配方 apply_conandata_patches 应用补丁移除/注释 LDFLAGS 中的 macOS 专用 `-Wl,-undefined,error`（或 make 命令行覆盖 LDFLAGS）。该参数仅对 Darwin ld 有意义；ELF lld 不需要它（未定义符号默认报错，或由 --no-allow-shlib-undefined / --unresolved-symbols 控制），移除不影响 Linux/OHOS 链接语义。

**修复命令**:
```
conan create archives/s/sassc/3.6.2 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create archives/s/sassc/3.6.2 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
