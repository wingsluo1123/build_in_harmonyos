# E1898: OHOS cross toolchain: CMake find_library(m) NOTFOUND, inject sysroot libm.a via CMakeToolchain variable

## 基本信息
- **严重度**: 3
- **类别**: ohos, cmake, toolchain, linking, cross-compile
- **作者**: unknown

## 错误特征
```
MATH.*NOTFOUND|find_library\(MATH m\)|linked by target.*NOTFOUND|libm\.a
```

## 根因分析
On OHOS cross builds the conan profile only injects

## 推荐方案
**方法**: sysroot-libm-cache-injection

**说明**: In conanfile.py generate(): when settings.os == "OHOS",

**修复命令**:
```
glob.glob("/data/service/hnp/ohos-sdk.org/*/ohos/native/sysroot") -> tc.variables["MATH"] = sysroot/usr/lib/<arch_dir>/libm.a
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
