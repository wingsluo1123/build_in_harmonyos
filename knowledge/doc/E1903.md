# E1903: cmocka 2.x 移除旧 API（UnitTest/unit_test/run_tests）后，面向旧 API 的上游测试 main 需迁移到 cmocka_unit_test + cmocka_run_group_tests_name

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, testing, api-migration, cmocka
- **作者**: CMP20

## 错误特征
```
undefined symbol: run_tests|expected '\)'|unit_test: use cmocka_unit_test instead|CMOCKA_DEPRECATION_WARNING|UNIT_TEST_FUNCTION_TYPE_TEST|implicit function declarations.*run_tests
```

## 根因分析
cmocka 2.0 起移除了旧 API（UnitTest 结构、unit_test() 宏、run_tests() 函数）。头文件中旧宏 unit_test() 仍在（deprecated），但在 clang 下展开 CMOCKA_DEPRECATION_WARNING 语句表达式需要 -DCMOCKA_DISABLE_DEPRECATION_WARNINGS，且 run_tests() 函数已彻底删除，链接时报 undefined symbol: run_tests。面向旧 API 编写的上游测试 main（如 cmp 20 的 test/test.c）在 OHOS PC 使用制品仓 cmocka 2.0.2 时无法编译/链接。

## 推荐方案
**方法**: migrate-to-modern-cmocka-api

**说明**: 将测试入口 main() 从旧 API 迁移到新 API：const struct CMUnitTest tests[] = { cmocka_unit_test(test_xxx), ... }; return cmocka_run_group_tests_name("group", tests, NULL, NULL);。编译时加 -DCMOCKA_DISABLE_DEPRECATION_WARNINGS 让头文件中残存的旧宏正常展开（仅当源码仍引用旧宏时需要）。迁移只涉及注册与运行机制，不改变测试函数实现本身，也无需引入平台宏。

**修复命令**:
```
sed 迁移 test.c 的注册数组与入口（示例见 archives/c/cmp/20/patches/0001-*），随后重新编译并完整运行上游测试
```

**验证**:
```
clang -c test/test.c -std=c99 -DCMOCKA_DISABLE_DEPRECATION_WARNINGS -I$CMO_INC && clang -o cmpunittest test/*.o cmp.o -lcmocka && ./cmpunittest
```
