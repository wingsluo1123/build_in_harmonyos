# E1909: libcheck 0.15.x 的 open_tmp_file 优先用固化 /tmp（P_tmpdir），设备 /tmp 只读时 check 测试报 Unable to create temporary file

## 基本信息
- **严重度**: 3
- **类别**: platform, hmdfs, test-framework
- **作者**: Awstme, KASUMIZAWA-MIYUU
- **来源 PR**: (本 PR)

## 错误特征
```
Unable to create temporary file for communication; may not have permissions to do so|check_msg\.c:317
```

## 根因分析
OHOS 设备 /tmp 为只读 root 目录（实测 drwxr-xr-x root root），而 musl/glibc 的

## 推荐方案
**方法**: promote-tmpdir-before-p_tmpdir

**说明**: 在测试框架私有副本 src/check_msg.c 的 open_tmp_file 中，将 getenv("TMPDIR")

**修复命令**:
```
sed 顺序调整后 make -C <check-build> && make install MAKEINFO=true，再重跑 make check
```

**验证**:
```
TMPDIR=<可写目录> make check 2>&1 | grep -c "check_msg.c:317"  # 仍>0 即命中
```
