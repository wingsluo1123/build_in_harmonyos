# E1911: patch-makefile-LDFLAGS-stdcxx-to-cxx

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, toolchain, linking
- **作者**: unknown

## 错误特征
```
unable to find library -lstdc\+\+|ld\.lld: error: unable to find library.*stdc\+\+|libstdc\+\+.*Makefile.*LDFLAGS
```

## 根因分析
OHOS 工具链（clang 15 + lld + libc++）不提供 libstdc++；

## 推荐方案
**方法**: patch-makefile-LDFLAGS-stdcxx-to-cxx

**说明**: 将 Makefile.am（源头）与 Makefile.in（tarball 模板）中 -lstdc++ 改为 -lc++，

**修复命令**:
```
sed 's/-lstdc++/-lc++/' cgicc/Makefile.am cgicc/Makefile.in
```

**验证**:
```
grep -n 'lstdc++' <src>/Makefile.am <src>/Makefile.in;
```
