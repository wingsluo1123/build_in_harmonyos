# E1914: HMDFS 大小写不敏感导致 conan source() 解压时 tarball 根级 PATCHES 文件与导出 patches/ 目录冲突 IsADirectoryError

## 基本信息
- **严重度**: 3
- **类别**: platform, conan, filesystem, case-insensitive
- **作者**: pc1-52
- **来源 PR**: (本 PR)

## 错误特征
```
IsADirectoryError: \[Errno 21\] Is a directory: '\./PATCHES'|Error in source\(\) method, line \d+
```

## 根因分析
HarmonyOS 设备文件系统 HMDFS 大小写不敏感。tarball 根级存在名为 PATCHES 的普通文件

## 推荐方案
**方法**: excludes-filter-in-get

**说明**: 在配方 source() 的 get() 调用中通过 excludes 参数排除 tarball 根级 PATCHES 文件,

**修复命令**:
```
'get(self, **self.conan_data["sources"], strip_root=True, excludes=["*PATCHES"])'
```

**验证**:
```
conan create . -pr:h=<ohos-profile> 观察 source() 报 IsADirectoryError './PATCHES'; 或
```
