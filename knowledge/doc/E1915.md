# E1915: OHOS musl 不提供 passwd/group/shadow 文件访问函数——musl

## 基本信息
- **严重度**: 2
- **类别**: ohos, musl, compilation, group, passwd
- **作者**: ohpcd <ohpcd@localhost>

## 错误特征
```
call to undeclared function 'getspnam|
```

## 根因分析
glibc 的 <pwd.h>/<grp.h>/<shadow.h> 声明 passwd/shadow/

## 推荐方案
**方法**: musl-userdb-file-stub

**说明**: 在 musl 兼容头（src/include/musl/pwd.h、grp.h、shadow.h）

**修复命令**:
```
(musl 兼容头 pwd.h/grp.h/shadow.h + userdb.c)
```

**验证**:
```
conan create archives/s/systemd/261 --build=missing
```
