# E1916: OHOS musl 的 ucontext.h 只定义 ucontext_t、不声明 ucontext

## 基本信息
- **严重度**: 2
- **类别**: ohos, musl, compilation, declaration, fiber
- **作者**: ohpcd <ohpcd@localhost>

## 错误特征
```
call to undeclared function 'getcontext'|
```

## 根因分析
glibc 的 <ucontext.h> 声明 getcontext/makecontext/

## 推荐方案
**方法**: musl-ucontext-decl

**说明**: 在 musl 兼容头（src/include/musl/ucontext.h）include_next

**修复命令**:
```
(musl 兼容头 ucontext.h + 依赖 libucontext)
```

**验证**:
```
conan create archives/s/systemd/261 --build=missing
```
