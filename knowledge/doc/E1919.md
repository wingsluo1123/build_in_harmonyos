# E1919: aarch64 上共享库缺失 __powidf2 等 compiler-rt builtins 辅助符号,运行时重定位失败(Error relocating ... symbol not found)

## 基本信息
- **严重度**: 2
- **类别**: ohos, compiler, clang, linking, runtime
- **作者**: oh-executor pc1-54
- **来源 PR**: (本 PR)

## 错误特征
```
Error relocating .*\.so\..*: __powidf2: symbol not found|__addtf3.*symbol not found|undefined reference to `__powidf2'
```

## 根因分析
OHOS aarch64 上 clang 把 long double/内置 pow 等运算编译为对 compiler-rt builtins

## 推荐方案
**方法**: link-compiler-rt-builtins

**说明**: 对 libtool 管理的 autotools 包,在 conan generate() 通过

**修复命令**:
```
tc.extra_ldflags.append("-lclang_rt.builtins")  # conanfile.py generate()
```

**验证**:
```
nm -D <built>.so | grep __powidf2;  # 缺失则确认;修复后 nm -D 应含该符号(来自 DT_NEEDED 的 clang_rt.builtins)
```
