# E1920: autotools 库 trampoline/闭包机制在 HarmonyOS 上找不到可执行内存页方案,编译期 #error "Don't know how to make memory pages executable."

## 基本信息
- **严重度**: 3
- **类别**: platform, compat, autotools, memory
- **作者**: pc2-38 (AtomCode)
- **来源 PR**: (本 PR)

## 错误特征
```
Don.t know how to make memory pages executable|EXECUTABLE_VIA|trampoline\.c.*#error
```

## 根因分析
HarmonyOS(SELinux 控制内存保护)上 configure 对 mprotect after mmap 可执行能力的

## 推荐方案
**方法**: extend-android-branch-ohos

**说明**: 在 trampoline 宏选择链中把 Android 专用分支扩展为同时覆盖 __OHOS__,

**修复命令**:
```
sed -i 's/defined __ANDROID__ && HAVE_MPROTECT_AFTER_MMAP_CAN_EXEC < 0/(defined __ANDROID__ || defined __OHOS__) \&\& HAVE_MPROTECT_AFTER_MMAP_CAN_EXEC < 0/' trampoline/trampoline.c
```

**验证**:
```
grep -n 'memory pages executable' trampoline/trampoline.c;
```
