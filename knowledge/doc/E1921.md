# E1921: CMAKE_SYSTEM_NAME=HarmonyOS 无平台模块导致共享库缺 DT_SONAME，应在链接期显式定义 SONAME flag

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, toolchain, linking, packaging
- **作者**: GoliWie

## 推荐方案
**方法**: link-time-soname-flag-injection

**说明**: 在配方 generate()（或统一工具链封装）向 CMakeToolchain 注入 CMAKE_SHARED_LIBRARY_SONAME_C_FLAG 与 CMAKE_SHARED_LIBRARY_SONAME_CXX_FLAG（值 "-Wl,-soname,"，尾逗号必须保留，CMake 直接拼接 soname 值）。上游目标本就声明 VERSION/SOVERSION 时，lld 即产出真实 DT_SONAME 并版本化文件名，消费者 DT_NEEDED 记录裸 soname 名，经 LD_LIBRARY_PATH/RPATH 解析。producer 侧一次修复覆盖全部消费者，且保持工具链链接期自签名有效。

**修复命令**:
```
conanfile.py generate(): tc.variables["CMAKE_SHARED_LIBRARY_SONAME_CXX_FLAG"] = "-Wl,-soname,"; tc.variables["CMAKE_SHARED_LIBRARY_SONAME_C_FLAG"] = "-Wl,-soname,"; 重新 conan create 后 llvm-readelf -d <pkg>/lib/<lib>.so* | grep SONAME
```
