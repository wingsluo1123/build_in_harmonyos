# E1930: OHOS 上 ECL(Embeddable Common-Lisp) 运行时落地:ECLDIR/SYS: 逻辑路径覆盖 + 模块符号链接 + include 软链

## 错误特征
```
Don't know how to REQUIRE (CMP|ASDF)|Cannot open "SYS:help\.doc"|Unable to find include directory|Error loading shared library libecl\.so
```

## 根因分析
conan 发布的 ECL 24.5.10 把 CI 编译机前缀(/devcloud/slavespace/.../out/sdk)烤死在

## 推荐方案
**方法**: ecl-runtime-bootstrap

**说明**: 通过 LD_LIBRARY_PATH + ECLDIR + 模块/头文件符号链接把 ECL 运行时"钉"到 conan 包前缀,使 REQUIRE/load-system 全链路可用

**修复命令**:
```
export LD_LIBRARY_PATH="$PREFIX/lib:$GMP/lib"; export ECLDIR="$PREFIX/lib/ecl-24.5.10"; ln -sfn ../include/ecl "$PREFIX/lib/ecl"; for f in "$PREFIX/lib/ecl-24.5.10/"*; do b=$(basename "$f"); [ -e "$PREFIX/lib/$b" ] || ln -s "ecl-24.5.10/$b" "$PREFIX/lib/$b"; done
```

**验证**:
```
LD_LIBRARY_PATH=$PREFIX/lib:$GMP/lib ECLDIR=$PREFIX/lib/ecl-24.5.10 $PREFIX/bin/ecl -norc -eval '(require :asdf)'   # 打印 ASDF 版本即命中
```
