# E1932: regenerate-cumulative-diff

## 基本信息
- **严重度**: 2
- **类别**: portability, conan, patch, multi-version
- **作者**: B4Q2
- **来源 PR**: #9036

## 错误特征
```
WARN: .*patches/.*hunk no\.[0-9]+ doesn't match source file at line [0-9]+|
```

## 根因分析
conan 2.x 的 apply_conandata_patches 使用内置 patcher，按补丁头行号

## 推荐方案
**方法**: regenerate-cumulative-diff

**说明**: 用"版本化重生成"取代直接借用：①取 pristine 源树；②依次应用既有补丁

**修复命令**:
```
diff -u --label a/connect.c --label b/connect.c base/connect.c work/connect.c > patches/000N-x.patch
```

**验证**:
```
对干净源按序 `patch -p1 --dry-run` 全部补丁仅是初筛；最终判据必须是
```
