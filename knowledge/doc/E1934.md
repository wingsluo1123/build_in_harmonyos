## 错误特征
```
Error relocating .*/binary-sign-tool:.*symbol not found|
```

## 根因分析
ohos-aarch64 profile 的 [buildenv] 将

## 推荐方案
**方法**: env-unset-library-path

**说明**: 配方内全部签名/objcopy 调用以 `env -u LD_LIBRARY_PATH` 前缀；并保持

**修复命令**:
```
env -u LD_LIBRARY_PATH /data/service/hnp/bin/binary-sign-tool sign -inFile "{f}" -outFile "{f}" -selfSign 1
```

**验证**:
```
env -u LD_LIBRARY_PATH /data/service/hnp/bin/binary-sign-tool sign -inFile <elf> -outFile <out> -selfSign 1（对照组：带 LD_LIBRARY_PATH 运行必报 relocating）
```
