# E1936: 自研 configure.py 生成 Makefile：OHOS 链接缺 libc++ 需 --ldflags 显式注入，且含空格值必须引号包裹

## 基本信息
- **严重度**: 2
- **类别**: compat, detection, build-system, make, linking
- **作者**: unknown

## 错误特征
```
undefined symbol: std::__n1::cerr|undefined symbol: std::__n1::ios_base::init|no such option: -l|configure.py: error: no such option
```

## 根因分析
(1) 自研 configure.py（Python argparse 配置脚本，非 autotools/cmake）生成 Makefile，

## 推荐方案
**方法**: ldflags-quoted-inject-libcxx

**说明**: configure 时用引号包裹含空格的 --ldflags 值注入 libc++：

**修复命令**:
```
./configure.py --cc=clang --cc-bin=${CC} --ldflags="-L/data/service/hnp/ohos-sdk.org/ohos-sdk_26.0.0.18/ohos/native/llvm/lib/aarch64-linux-ohos -lc++" --prefix=${PACKAGE_FOLDER}
```

**验证**:
```
make botan-test 2>&1 | grep "undefined symbol: std::__n1"; ./configure.py --ldflags="-L<dir> -lc++"
```
