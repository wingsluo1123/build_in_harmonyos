# E1943: conan配方settings缺compiler/build_type致L0p失败时补齐四项过门禁

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 9274

## 错误特征
```
\[fail\] L0p: settings缺少compiler/build_type|missing_setting_compiler|missing_setting_build_type
```

## 根因分析
ci/conan/build_and_test.sh L0p要求settings行同时包含os/compiler/build_type/arch四项，clipman配方只声明了os/arch两项

## 推荐方案
**方法**: complete-settings-to-four-items

**说明**: 将conanfile.py的settings由os/arch两项补齐为os/compiler/build_type/arch四项以满足L0p与profile兼容，新增compiler/build_type不被Go构建逻辑消费，不改变编译行为

**修复命令**:
```
archives/c/clipman/1.2.0-git20200218.39fd4fe/conanfile.py: settings由os/arch改为os, compiler, build_type, arch
```

**验证**:
```
CI conan-build-test步骤L0p通过且真机预检全部通过，原v2:unknown:unclassified_failure消失
```
