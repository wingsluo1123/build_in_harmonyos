# E1945: 上游假设 legacy System V termio ioctl 宏始终存在,musl/aarch64 等平台缺失时应编译期能力守卫而非伪造

## 基本信息
- **严重度**: 3
- **类别**: platform, portability, terminal
- **作者**: AWST
- **来源 PR**: (本 PR)

## 错误特征
```
error: use of undeclared identifier 'TC(GET|SET)A(W|F)?'|error: 'struct termio' has no member|TCGETA.*undeclared
```

## 根因分析
旧式 System V termio API(TCGETA/TCSETA/TCSETAW/TCSETAF、struct termio)

## 推荐方案
**方法**: termio-ioctl-macro-capability-guard

**说明**: 针对每个具体缺失宏加编译期能力守卫(#ifndef TCGETA 等),

**修复命令**:
```
patch -p1 < patches/0001-guard-termios-tcgeta-tcseta-musl.patch
```

**验证**:
```
grep -rn "define TCGETA\|define TIOCGETA" <sysroot>/usr/include/ ; echo '#include <termio.h>' | <cc> -E -x c - >/dev/null 2>&1 || echo "termio.h absent"
```
