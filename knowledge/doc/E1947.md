# E1947: cc-compile-S-with-integrated-as

## 基本信息
- **严重度**: 3
- **类别**: compiler, asm, dynarec, emulator
- **作者**: unknown

## 错误特征
```
Error: unknown mnemonic|unsupported relocation|file format not recognized|no such instruction|NEW_DYNAREC is not supported on this architecture|assembler command failed
```

## 根因分析
模拟器核心的动态重编译器（dynarec/JIT）后端是裸 ARM64 汇编（.S 文件，GAS 语法，含宏/链接符号），交叉工具链常见三类障碍：① 独立 as 不支持目标格式；② clang 默认调外部 GNU as 而系统无之；③ 运行时 mmap PROT_EXEC 生成可执行代码页被沙箱禁止。OHOS clang 15 的集成汇编器（integrated-as，clang 默认开启）原生支持 GAS 语法 ARM64 + 由 $(COMPILE.c)（C 编译器驱动）直接编译 .S；OHOS musl/沙箱对匿名 mmap PROT_EXEC 无限制（dlsym/mprotect 符号在导出表实测可用）。且「C 结构体偏移→汇编头」的生成管线（编译 asm_defines.c 后 grep 二进制中 '@ASM_DEFINE' 字符串生成 asm_defines_gas.h）跨平台可用，LTO bitcode 产物同样可 grep -a。
