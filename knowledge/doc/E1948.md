# E1948: 纯 Python 宿主缺失仓内无配方的运行依赖时，以固定 URL+SHA256 的官方 sdist vendor 进包内 site-packages 并用相对 sys.path 引导，不得把依赖 URL 放入 conandata.yml（dehydrated-hook-ddns-tsig 案例）

## 基本信息
- **严重度**: 2
- **类别**: python, conan, packaging, dependency-closure
- **作者**: sea_crab <sea_crab@atomgit.com>

## 错误特征
```
ModuleNotFoundError: No module named|ImportError
```

## 根因分析
设备 Python（3.12.9）缺失依赖模块（如 dnspython），而 ConanCenter 与仓 archives/ 均无配方：Conan 依赖图（R36 依赖须先发布制品仓）无法覆盖"无配方的运行时 Python 依赖"，archives/ 写边界又不允许为本库移植新建他库目录——conan create 可过，但任何真实调用在目标机必报 ModuleNotFoundError。解法：source() 以固定 URL+SHA256 拉取官方 PyPI sdist vendor 进 lib/python3.12/site-packages/；入口脚本用相对路径 sys.path 引导（os.path.dirname(os.path.realpath(__file__))/../lib/python3.12/site-packages，不写设备绝对路径）；package_info 同时设 runenv_info PYTHONPATH；py_compile 校验设 PYTHONPYCACHEPREFIX 指向 build 目录，防止 __pycache__/.pyc 被 copytree 打进包。依赖 URL/SHA256 写 conanfile.py 常量而非 conandata.yml——机理精确表述：CI 的 mirror-fallback 仅重写"已知域名的单值 url: 行"（且 files.pythonhosted.org 在镜像表中无镜像可加、行保持原样，pyvolumio/aiohttp-fast-zlib 的 pythonhosted 自定义 key URL 过 CI 为既有先例）；真正的任意改写者是 predl——其正则提取任意 https URL（含注释行与自定义 key，jwt-cpp 0.7.1 实证注释 URL 被子串 file:// 改写）。把依赖 URL 留在 conandata.yml 即与 CI 改写机制强耦合。

## 推荐方案
**方法**: vendor-sdist-pin-sha-syspath-bootstrap

**说明**: 在目标包 conanfile.py 常量里固定依赖官方 sdist 的 URL+SHA256，source() 用 get() 拉取，package() 装入包内 site-packages；入口脚本相对 sys.path 引导 + runenv_info PYTHONPATH 双保险；py_compile 用 PYTHONPYCACHEPREFIX 隔离 pycache。依赖元数据只放 conanfile.py，不放 conandata.yml。

**修复命令**:
```
conanfile.py: DNSPYTHON_URL/DNSPYTHON_SHA256 常量 + source() 内 get(self, URL, sha256=..., strip_root=True, destination="vendor/<dep>")；package() 内 shutil.copytree(..., ignore=shutil.ignore_patterns("__pycache__"))；package_info() 内 runenv_info.append_path("PYTHONPATH", os.path.join(package_folder, "lib", "python3.12", "site-packages"))
```

**验证**:
```
python3 -c "import dns" 2>&1 | grep -q ModuleNotFoundError && echo PRE_GAP_OK（适配前探针，期望命中）；ls <pkg>/lib/python3.12/site-packages/dns/__init__.py；python3 -c "import sys; sys.path.insert(0,'<pkg>/lib/python3.12/site-packages'); import dns; assert dns.__file__.startswith('<pkg>'); print('vendored', dns.version.version)"（期望输出 vendored 2.8.0）；<pkg>/bin/dehydrated-hook-ddns-tsig --help >/dev/null && echo HOOK_OK（期望 exit 0）
```
