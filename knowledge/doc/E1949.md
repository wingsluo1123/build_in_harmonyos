# E1949: 依赖包预编译构建期工具的 RUNPATH 指向已迁移的构建树时，消费方 make 执行该工具必须把其 DT_NEEDED 的 .so 所在依赖包 libdir 注入构建环境 LD_LIBRARY_PATH，否则加载失败构建中断（dbus-binding-tool/libexpat 实例）

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, toolchain, conan, loader
- **作者**: GoliWie
- **来源 PR**: pending（feat/cdemud-1.0.0 交付 PR）

## 错误特征
```
Error loading shared library lib<dep>.so.*needed by .*bin/<tool>（make/BUILT_SOURCES 阶段，工具进程 rc=127，紧跟 Error relocating .*: symbol not found 系列；实例：libexpat.so / dbus-binding-tool / XML_*）
```

## 根因分析
机理链（设备 dbus-glib/0.114 包实测，2026-09-09）：(1) OHOS 原生编译环境 host==target，dbus-glib 配方把 dbus-binding-tool 交付为 aarch64 OHOS ELF（llvm-readelf -h：dynamically tagged aarch64 /lib/ld-musl-aarch64.so.1），DT_NEEDED libexpat.so——expat 在 OHOS 只发布 .so（包 lib/ 内无 .a）；(2) 工具自带 RUNPATH=/storage/Users/currentUser/.cache/conan2/p/b/dbus-b2a06f5fb46b5/b/build-release/dependency-archives（llvm-readelf -d 实证），即生产该包时的临时构建目录，Conan 包落库/迁移后不存在——loader 无法再经 RUNPATH 解析 libexpat.so；(3) 消费方上游（如 cdemu-daemon 的 cdemud-service.xml）在 make/BUILT_SOURCES 经 PATH 裸名调用 dbus-binding-tool 生成 glue 头 → musl loader 报 "Error loading shared library libexpat.so: (needed by …/bin/dbus-binding-tool)" + XML_* symbol not found，进程 rc=127 → make 目标失败、构建中断。修复必须落在执行该工具的构建环境（把 expat 包 libdir 注入 build-scope LD_LIBRARY_PATH），工具制品与消费方链接面均无需改动

## 推荐方案
**方法**: dep-libdir-into-buildenv-ldlibrarypath

**说明**: 消费方配方 generate() 把工具所需 .so 的包 libdir 注入 build-scope 构建环境：env.append_path("LD_LIBRARY_PATH", os.path.join(self.dependencies["expat"].package_folder, "lib"))（dbus-glib 消费方必经传递依赖持有 expat），随 Environment build script 落盘；只在构建会话生效，不污染 test_package 与产物运行环境（对齐 P-ENV-001 的作用域纪律）

**修复命令**:
```
# conanfile.py generate() 内
```

**验证**:
```
# 自包含：任意新 shell 可跑，仅依赖设备 conan2 cache 与 llvm-readelf，不依赖本 run 日志
```
