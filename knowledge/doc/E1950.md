# E1950: Autotools doc target fails with "makeinfo: inaccessible or not found" (Error 127) on texinfo-less build env — fix by --disable-doc

## 基本信息
- **严重度**: 2
- **类别**: autotools, configure, toolchain, documentation
- **作者**: unknown

## 错误特征
```
makeinfo: inaccessible or not found|makeinfo: missing on your system|Error 127.*\.info|Cannot.*makeinfo|\bmissing\b.*makeinfo
```

## 根因分析
Autotools 项目的 doc/Makefile 在 make/make install 时会调用

## 推荐方案
**方法**: configure-disable-doc

**说明**: 在 configure 阶段显式禁用文档构建：

**验证**:
```
grep -n "MAKEINFO" doc/Makefile.in | head -3;
```
