# E1951: toybox diff 缺 -e（ed 脚本）输出，核心路径依赖 `diff -e` 的脚本必须让 GNU diffutils 先于 toybox 出现在 PATH

## 基本信息
- **严重度**: 2
- **类别**: platform, userland-gap
- **作者**: unknown

## 错误特征
```
Unknown option 'e'|Can't do diff -e|diff: Unknown option
```

## 根因分析
toybox (0.8.12) diff implements -u/-c style output only; `-e` (ed editor commands, required for replayable edit scripts) is unsupported. Failure point is a SILENT EMPTY ed script, not a crash: a consumer that resolves `diff` from ambient PATH gets toybox (/usr/bin/diff), `diff -e` prints "diff: Unknown option 'e'" to stderr, exits rc=2 with EMPTY stdout. changetrack 4.7 opens `diff -e "$yestfile" "$realfile"` as a pipe (changetrack source line 341); open() succeeds, so it collects an empty @ed and writes an empty `.ed` restore file — the recovery path is silently corrupted while the change log still records the edit. `die "Can't do diff -e:$!"` fires only when diff cannot be executed at all. Device default PATH resolves /usr/bin (toybox) before the toolchain userland dir carrying GNU diffutils 3.10.

## 推荐方案
**方法**: path-precedence-for-gnu-diffutils

**说明**: Ensure the runtime PATH puts the GNU userland dir (which provides GNU diffutils 3.10, archives/d/diffutils) before /usr/bin when executing such consumers; in Conan test_packages run under the profile buildenv (env="conanbuild") whose PATH already prepends that dir. In tests, assert on the ed-script content (e.g. contains the hunk header "2c") so shadowing by toybox fails loudly instead of silently. Design rationale: prefer PATH precedence over patching the consumer (patching only as fallback); trust behavioral evidence over assumptions (content assertions, not exit codes); keep delivered files relocatable (see forbid_1).

**修复命令**:
```
conan create archives/c/changetrack/4.7 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
printf 'a\nb\nc\n' > o; printf 'a\nX\nc\n' > n; diff -e o n   (ambient=toybox: "diff: Unknown option 'e'", rc=2, stdout empty); PATH=/data/service/hnp/bin:$PATH diff -e o n   (GNU diffutils 3.10: prints "2c"/"X"/".", rc=1) — PATH precedence alone fixes it
```
