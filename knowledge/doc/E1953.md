# E1953: 历史版本使用 Debian orig 归档时必须锁定 SHA256 并单独披露许可证变体

## 基本信息
- **严重度**: 2
- **类别**: conan, license, reproducibility, source-provenance
- **作者**: nicovideo-dl
- **来源 PR**: 9377

## 错误特征
```
Debian.*orig|hash mismatch|SHA256|Expat|X11|no-promotion|
```

## 根因分析
历史项目的官网或原始下载入口可能不再提供可稳定获取的指定版本，而 Debian 仍保存对应的 orig 源码归档；该归档可作为可复现来源，但它是发行版托管的下游来源，不能在元数据中冒充上游官网；同时 Debian copyright 的许可证分类与仓库实际 LICENSE 文本可能只在主许可证族上相同。nicovideo-dl 的归档由 Debian copyright 归类为 Expat，但 LICENSE 还包含禁止使用版权人姓名宣传或推广销售的附加条款，因此按 X11 变体记录比直接写 MIT/Expat 更诚实。

## 推荐方案
**方法**: pinned-downstream-source-with-license-disclosure

**说明**: >

**修复命令**:
```
conandata.yml: sources.url + sources.sha256；
```
