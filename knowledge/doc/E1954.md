# E1954: 无 setup.py 的单文件 Python CLI 应以 active sys.executable 验证并安装为 bin 命令

## 基本信息
- **严重度**: 2
- **类别**: portability, python, conan, packaging, cli
- **作者**: nicovideo-dl
- **来源 PR**: 9377

## 错误特征
```
command not found|Permission denied|No such file or directory.*nicovideo-dl|
```

## 根因分析
历史 Python CLI 可能只有一个无扩展名入口脚本，没有 setup.py、pyproject.toml 或 native build system；若配方假设存在标准 Python 构建流程，或只把脚本复制到非 bindirs 目录，Conan 包虽然生成成功，消费者却无法通过 PATH 发现命令；若直接依赖环境中的 python/python3 名称，还会把构建验证绑定到不稳定的解释器。nicovideo-dl 0.0.20190126 实证为单文件脚本，使用 Python 3 标准库，无上游测试套件，适合由 Conan 配方显式定义应用边界。

## 推荐方案
**方法**: active-python-script-application-packaging

**说明**: >

**修复命令**:
```
build(): self.run(f'"{sys.executable}" "{script}" --version');
```

**验证**:
```
>
```
