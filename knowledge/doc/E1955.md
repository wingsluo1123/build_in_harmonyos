# E1955: 远程 automake/1.18 二进制包 bin 目录丢失点文件（.aclocal-real）：conan remove + 本地 --build 重建规避半残缓存命中

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, conan, packaging, cache
- **作者**: ffieldd22_-

## 错误特征
```
Can't exec.*\.aclocal-real.*No such file or directory|
```

## 根因分析
远端 automake/1.18 预编译二进制包在打包/传输环节丢失 bin 目录点文件（.aclocal-real/.automake-real），conan 下载远端包只校验存在文件的 sha、清单缺项不阻断，半残包仍被当作有效缓存命中

## 推荐方案
**方法**: conan-remove-and-local-rebuild（清除半残远端包，--build 本地重建一次）

**说明**: >

**修复命令**:
```
conan remove "automake/1.18" -c && conan install --requires automake/1.18 --build="automake/*" -pr:h=~/.conan2/profiles/ohos-aarch64-local -pr:b=~/.conan2/profiles/ohos-aarch64-local
```

**验证**:
```
>
```
