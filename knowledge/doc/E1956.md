# E1956: 上游测试硬编码已被注册局下线（serverHold）的域名时，以本地 HTTP 等价数据源替代数据源，测试逻辑零改动

## 基本信息
- **严重度**: 2
- **类别**: ohos, network, testing, upstream
- **作者**: ffieldd22_-

## 错误特征
```
Download error|nxmle_new_data_from_url.*NULL|New data from url.*error|
```

## 根因分析
上游测试硬编码的固定域名被注册局 serverHold 强制下线（权威 NXDOMAIN rcode=3，不可恢复），外部数据源永久失效，而被测的 HTTP 下载 + XML 解析逻辑本身与域名无关

## 推荐方案
**方法**: local-http-equivalent-source（本地 HTTP 等价数据源替代，测试逻辑零改动）

**说明**: >

**修复命令**:
```
cd archives/l/libnxml/0.18.5 && conan create . -pr:h=~/.conan2/profiles/ohos-aarch64-local -pr:b=~/.conan2/profiles/ohos-aarch64-local --build=libnxml/* && grep 'PASS: 3' conan-build.log
```

**验证**:
```
>
```
