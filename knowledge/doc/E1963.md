# E1963: minitest 5.x 已移除 MiniTest 兼容别名，旧拼写 MiniTest::Test 在设备 ruby 3.4.5（minitest 5.25.4）下加载即 NameError，需大小写修正补丁

## 基本信息
- **严重度**: 2
- **类别**: dependency-closure-testsuite
- **作者**: unknown

## 错误特征
```
uninitialized constant MiniTest \(NameError\)|MiniTest::Test
```

## 根因分析
上游用 minitest 1.x~4.x 时代拼写写的测试类（`class X < MiniTest::Test`）依赖旧 camel-case 常量 MiniTest；minitest 5.x 起该兼容别名被移除，类定义加载时直接抛 uninitialized constant MiniTest (NameError)，rake test 立即中止，一个用例都没跑。设备 ruby 3.4.5 内置 minitest 5.25.4，命中该缺口。实例：reevoo/detenc 2.0.0（7 个 test_*.rb 全部使用旧拼写）；Alpine APKBUILD 对同一问题早有同名 minitest.patch 处理。修复为最小 sed 大小写修正：MiniTest::Test → Minitest::Test（不动测试语义）。

## 推荐方案
**方法**: sed-case-rename-patch

**说明**: 对全部 test_*.rb 执行 sed -i 's/MiniTest::Test/Minitest::Test/'，以 diff -u --label a/… --label b/… 生成 0001-*.patch 入库（记入 conandata.yml，含 sha256）；先在干净树上 patch -p1 复验再跑 make check 全量。判定要点：报错行指向 test 文件的 class 声明行且报 uninitialized constant MiniTest 即本条；注意裸 ruby -e 不自动加载 minitest，最小复现必须先 require "minitest/autorun"。

**修复命令**:
```
cd <解包源码> && for f in test/test_*.rb; do sed -i 's/MiniTest::Test/Minitest::Test/' $f; done && make check CC=clang CFLAGS="-Wall -O2" -j1
```

**验证**:
```
ruby -e 'require "minitest/autorun"; p MiniTest::Test' 2>&1 | head -1; ruby -e 'require "minitest/autorun"; p Minitest::Test' 2>&1 | head -1
```
