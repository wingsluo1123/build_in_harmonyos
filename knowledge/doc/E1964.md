# E1964: 三步——① 先判空值：`git config --file "$GIT_CONFIG_GLOBAL" --get-all

## 基本信息
- **严重度**: 2
- **类别**: configure, environment, git
- **作者**: unknown

## 错误特征
```
detected dubious ownership in repository at|to add an exception for this directory|safe.directory
```

## 根因分析
git 对 [safe] 段的 safe.directory 是「按读取顺序累积」求值：遇到空值条目会把当前

## 推荐方案
**方法**: 三步——① 先判空值：`git config --file "$GIT_CONFIG_GLOBAL" --get-all safe.directory

**说明**: 先判定空值条目再按读取顺序修复；不改共享配置时用命令行层注入

**修复命令**:
```
'git config --file "$GIT_CONFIG_GLOBAL" --get-all safe.directory | grep -n "^$" ; GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=safe.directory GIT_CONFIG_VALUE_0="$REPO" git -C "$REPO" rev-parse --short HEAD'
```

**验证**:
```
'git config --file "$GIT_CONFIG_GLOBAL" --get-all safe.directory | grep -n "^$" && echo "存在空值条目" || echo "无空值条目"'
```
