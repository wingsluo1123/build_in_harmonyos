# E1970: TUI 程序 FILE=- 的 stdin 内容与 /dev/tty 按键 freopen 冲突,测试须 pty 双通道

## 基本信息
- **严重度**: 2
- **类别**: runtime, testing, ncurses
- **作者**: AtomCode
- **来源 PR**: (本 PR)

## 错误特征
```
freope?n\("/dev/tty".*\) == NULL|Bad file descriptor|.*: cannot open /dev/tty|exit\(1\).*tty
```

## 根因分析
上游 mdp main() 在 FILE=-(或无参数)时置 noreload=1,解析完成后无条件

## 推荐方案
**方法**: pty-dual-channel-test

**说明**: python pty.fork() 起 pty,子进程 dup2(管道读端,0) 喂 stdin,父进程读 pty 输出、写 'q' 退出

**修复命令**:
```
python3 - <<'PYEOF' ... pty.fork() + os.dup2(r,0) + os.execvp ... PYEOF
```

**验证**:
```
printf '# t\n' | mdp -d - ; echo "rc=$? (无 tty 时 rc=1 属上游预期)"
```
