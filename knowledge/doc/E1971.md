# E1971: 上游 Makefile 反引号调用已被依赖库删除的 freetype-config → ft2build.h 找不到；改用 pkg-config 时必须用消费方 PkgConfigDeps 生成的 .pc（依赖包自带 .pc 的 prefix=/ 输出死路径）

- **类别**: platform, build-system, conan
- **作者**: Awstme

## 错误特征
```
freetype-config: inaccessible or not found|freetype-config: not found|freetype-config: command not found|ft2build.h' file not found
```

## 根因分析
|

## 推荐方案
**方法**: pkg-config-migration-with-consumer-pc

**说明**: 用正式补丁把上游 Makefile 的 *-config 反引号替换为 pkg-config 模块调用

**修复命令**:
```
make -j1 cube2font PLATFORM=aarch64-unknown-linux-ohos CXX=<clang++> PKG_CONFIG=<pkg-config> CXXFLAGS="$(pkg-config --cflags zlib) -O3" LDFLAGS="$(pkg-config --libs zlib)"
```

**验证**:
```
python3 -c "import subprocess,glob;p=glob.glob('/storage/Users/currentUser/.conan2/p/freet*/p')[0];print('config-script:',len(glob.glob(p+'/**/freetype-config*',recursive=True)));print(open(p+'/lib/pkgconfig/freetype2.pc').read().splitlines()[0])"  # 期望输出 config-script: 0 与 prefix=/
```
