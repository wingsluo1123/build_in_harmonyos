## 基本信息

## 错误特征
```
OSError: dlopen failed|cannot open shared object|code signature|HMDFS.*denied
```

## 根因分析
Conan 的 copy() 实现对 ELF 文件做字节级复制时会修改 ELF 头中的偏移量

## 推荐方案
**方法**: post-copy-elf-resign

**说明**: 在 package() 中 copy 完成后，对目标 .so 文件执行 llvm-objcopy 清除旧签名

**修复命令**:
```
for f in pkg/lib/python3.12/site-packages/gpg/_gpgme*.so; do
```
