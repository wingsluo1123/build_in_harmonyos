# E1983: googletest 1.6 CapturedStream 硬编码 /tmp/captured_stream.XXXXXX，OHOS /tmp 只读导致死亡测试父进程 GTEST_CHECK abort（exit 134），整个测试二进制被判 FAIL

## 基本信息
- **严重度**: 3
- **类别**: platform, hmdfs, test-framework
- **作者**: unknown

## 错误特征
```
Signal 6 \(core dumped\)|FAIL test_\w+ \(exit status: 134\)|Death tests use fork\(\), which is unsafe
```

## 根因分析
googletest 1.6 的 CapturedStream（src/gtest-port.cc）硬编码

## 推荐方案
**方法**: gtest-port-unconditional-tmpdir

**说明**: 在捆绑 googletest/src/gtest-port.cc 的 CapturedStream name_template

**修复命令**:
```
patch 后 make -C unit-tests && ./test_sccsdate  # 死亡测试 [ OK ]
```

**验证**:
```
grep -n '"/tmp/captured_stream.XXXXXX"' <src>/googletest/src/gtest-port.cc;
```
