# E1997: 无外部依赖 C CLI 工具在 OHOS 上应采用显式 sysroot 交叉编译和设备闭环验证

## 基本信息
- **严重度**: 2
- **类别**: ohos, cross-compile, conan, packaging, testing
- **作者**: codex

## 错误特征
```
missing sysroot|unable to execute binary format|commands_json_r38|test_package.*can_run|/data/service/hnp/bin
```

## 根因分析
传统 C CLI 归档可能只有源文件和可选的 Autotools 输入，没有生成构建文件、第三方依赖或自动化测试；DevEco clang 的绝对路径也不等于完整 OHOS 交叉编译环境。必须从 Conan profile 获取编译器，显式设置 OHOS target/sysroot/libc 宏，并将设备运行时检查与主机交叉编译检查分层。

## 推荐方案
**方法**: explicit-ohos-cross-build-and-runtime-gates

**说明**: 固定 URL/SHA256；使用 tools.build:compiler_executables；OHOS 编译传递 --target=aarch64-linux-ohos、SDK sysroot 和需要的 libc 宏；安装 bin、man、license；CLI 包在软件级目录声明 commands.json；test_package 用离线最小输入并通过 can_run()/shadow CI 分层验证。

**修复命令**:
```
conan create archives/m/metamath/0.198 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
zsh ci/conan/build_and_test.sh archives/m/metamath/0.198
```
