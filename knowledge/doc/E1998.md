# E1998: Metamath 多命令 test_package 必须显式 READ 并引用数据库路径

## 基本信息
- **严重度**: 2
- **类别**: ohos, conan, testing, cli-tool
- **作者**: codex

## 错误特征
```
Expected DBG.*READ|No source file has been read in|couldn't open the file "/"|The source has [0-9]+ statements
```

## 根因分析
Metamath v0.198 在同时传入多个命令行参数时会逐参数进入命令解析流程，不能依赖裸数据库路径的隐式读取行为；未引用的路径还可能被 READ 命令解析器按斜杠截断。旧版本读取摘要文案也不能作为 v0.198 的稳定断言。

## 推荐方案
**方法**: explicit-cli-command-sequence

**说明**: 使用离线最小数据库；多命令调用显式写 READ，并在命令字符串内部给数据库路径加双引号；只断言版本、语句数和证明验证成功文本。

**修复命令**:
```
output=$("$METAMATH_BIN" "READ \"$DATABASE\"" "VERIFY PROOF *" "EXIT")
```

**验证**:
```
output=$("$METAMATH_BIN" "READ \"$DATABASE\"" "VERIFY PROOF *" "EXIT")
```
