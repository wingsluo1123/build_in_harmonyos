# E2006: Perl 模块把函数定义在 __END__ 之后靠 AutoLoader 加载，却只把 AutoLoader 放进 @ISA、未 import 其 AUTOLOAD——现代 Perl 禁止「对非方法调用继承来的 AUTOLOAD」，模块能加载但函数全不可用

## 基本信息
- **严重度**: 2
- **类别**: perl, packaging, runtime, upstream-defect
- **作者**: ffieldd22_-
- **来源 PR**: 9708

## 错误特征
```
Use of inherited AUTOLOAD for non-method|
```

## 根因分析
AutoLoader 的工作方式是把 `__END__` 之后的 sub 拆到

## 推荐方案
**方法**: import-autoloader-autoload-and-ship-auto-tree

**说明**: >

**修复命令**:
```
sed -i 's|^@ISA = qw(Exporter AutoLoader);|use AutoLoader qw(AUTOLOAD);\n@ISA = qw(Exporter AutoLoader);|' OpaL/<part>/<part>.pm
```

**验证**:
```
>
```
