# E2009: In recipe generate(), drop the offending argument with the o

## 基本信息
- **严重度**: high
- **类别**: build-system, autotools, conan
- **作者**: unknown

## 错误特征
```
handwritten configure exits with "Unknown option --oldincludedir" (or other injected --*dir argument) during Conan AutotoolsToolchain configure step
```

## 根因分析
Upstream configure is a hand-written script (not autoconf-generated) that validates its argument whitelist and aborts on unrecognized options. Conan 2.x AutotoolsToolchain unconditionally injects standard GNU directory arguments (--prefix --bindir --sbindir --libdir --includedir --oldincludedir --datarootdir); any argument outside the handwritten whitelist (most commonly --oldincludedir) makes configure exit with Unknown option before compilation starts.

## 推荐方案
**方法**: In recipe generate(), drop the offending argument with the official Conan API tc.update_configure_args with value None before tc.generate(). Do not patch the configure script for this and do not hand-write an argument filter. Platform detection failures in the same handwritten configure are a separate concern handled by an E160-class platform patch.
