# E2010: OHOS/容器无 /etc/mtab 时 mountlist 为空：setmntent 回退

## 基本信息
- **严重度**: 2
- **类别**: filesystem, /etc/mtab, /proc/self/mounts, mountlist
- **作者**: unknown

## 错误特征
```
Could not open /etc/mtab: No such file or directory|
```

## 根因分析
libgtop linux sysdeps 的 mountlist 用

## 推荐方案
**方法**: mtab-proc-self-mounts-fallback

**说明**: setmntent(MOUNTED) 打开失败时回退 setmntent

**修复命令**:
```
(source patch sysdeps/linux/mountlist.c)
```

**验证**:
```
cd archives/l/libgtop/2.41.3 && conan create . -pr:h=<ohos-aarch64> -pr:b=<ohos-aarch64> （test_package 鸿蒙专项测试断言 mountlist 139 mounts）
```
