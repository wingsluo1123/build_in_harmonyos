# E2011: autotools 消费者链 conan glib 静态库时 g_libintl_ngettext

## 基本信息
- **严重度**: 3
- **类别**: ohos, autotools, linking, conan, glib
- **作者**: unknown

## 错误特征
```
undefined symbol: g_libintl_ngettext|
```

## 根因分析
conan glib 包内 libintl.h 无条件把 ngettext 宏映射为

## 推荐方案
**方法**: inject-intl-rpath

**说明**: 配方 generate() 用 configure_args 注入

**修复命令**:
```
(conanfile.py generate() 中)
```

**验证**:
```
cd archives/l/libgtop/2.41.3 && conan create . -pr:h=<ohos-aarch64> -pr:b=<ohos-aarch64>
```
