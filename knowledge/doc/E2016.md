# E2016: autotools configure 对 AS/AR/STRIP 用 ${VAR-default}——环境把变量导出成「空串」时取到空值（不同于「未设置」会回退），汇编检查退化为执行 conftest.S 文件，报出与 NEON 无关的误导性 "no NEON support" 并 exit 1

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, build-system, autotools, toolchain
- **作者**: ffieldd22_-
- **来源 PR**: 9815

## 错误特征
```
no NEON support, try adding -mfpu=neon to CFLAGS|
```

## 根因分析
上游 configure 用 ${VAR-default}（只认「未设置」，不认「已设置但为空」）

## 推荐方案
**方法**: pin-all-toolchain-vars-absolute

**说明**: >

**修复命令**:
```
CC=/data/service/hnp/bin/clang AS=/data/service/hnp/bin/clang AR=/data/service/hnp/bin/llvm-ar RANLIB=/data/service/hnp/bin/llvm-ranlib NM=/data/service/hnp/bin/llvm-nm STRIP=/data/service/hnp/bin/llvm-strip bash ./configure --host=aarch64-unknown-linux-gnu --enable-shared --enable-static --enable-pic
```

**验证**:
```
>
```
