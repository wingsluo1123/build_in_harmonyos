# E2017: test_package 就地构建（无 layout）→ test.sh 自建工作目录被误提交（对策：$TMPDIR + trap 清理）

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, testing, repo-hygiene
- **作者**: K4T9

## 错误特征
```
test_package/work/.*(Makefile|\.c|\.h)|Test package build folder:.*test_package$|git add.*test_package.*work
```

## 根因分析
test_package/conanfile.py 未定义 layout() 时，Conan 2 将 test package 的 build folder

## 推荐方案
**方法**: tmpdir-trap-cleanup

**说明**: 测试脚本统一用唯一临时目录 + 退出清理：

**修复命令**:
```
conan create archives/<l>/<name>/<ver> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing && ls -a archives/<l>/<name>/<ver>/test_package
```

**验证**:
```
conan create <pkg> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing; ls -a <pkg>/test_package; git status --short <pkg>/test_package
```
