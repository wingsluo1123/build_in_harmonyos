# E2019: E007 官方脚本产物含 __OHOS__ → 被 PF5 平台宏闸拦截，PR 无法创建（对策：删 libc 探针段 / R8 例外申报）

## 基本信息
- **严重度**: 3
- **类别**: patch, framework, review-gate
- **作者**: K4T9

## 错误特征
```
PF5.*__OHOS__|平台宏闸.*__OHOS__|patches/\*\.patch 新增行禁 __OHOS__|preflight.*fail.*platform macro|OS ohos not recognized|cannot guess build type
```

## 根因分析
scripts/patch-autotools-ohos.pl 第 36-48 行在 __ANDROID__ libc 探测后强制插入

## 推荐方案
**方法**: patch-minimization-drop-ohos-libc-probe

**说明**: 补丁只保留真正需要的 *:HarmonyOS:*:* 分支，删掉 __OHOS__ LIBC 探针段；

**修复命令**:
```
grep -nE '^\+.*__OHOS__' patches/*.patch || echo "无平台宏新增行"; sh config.guess; sh config.sub aarch64-linux-ohos; patch -p1 --dry-run < patches/0001-config.guess.patch
```

**验证**:
```
grep -nE '^\+.*__OHOS__' archives/*/*/*/patches/*.patch; sh <src>/config.guess; sh <src>/config.sub aarch64-linux-ohos
```
