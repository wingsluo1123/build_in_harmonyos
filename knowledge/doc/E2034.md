## 推荐方案
**方法**: source-patch-exclude-clang

**说明**: 补丁把条件改为 `__GNUC__ < 5 && !defined(__clang__)`，

**修复命令**:
```
sed -i 's/#if defined(__GNUC__) \&\& __GNUC__ < 5/#if defined(__GNUC__) \&\& __GNUC__ < 5 \&\& !defined(__clang__)/' <header>
```

**验证**:
```
grep -nE '__GNUC__ < 5|__has_trivial_copy' src/include/robin_hood.h
```
