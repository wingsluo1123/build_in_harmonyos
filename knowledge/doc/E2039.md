# E2039: On OHOS GLib only provides GDummyTlsBackend; install glib-networking's GIO TLS module (openssl backend) against a shared glib so g_tls_backend_get_default() returns a real backend and upstream TLS tests execute

## 基本信息
- **严重度**: 2
- **类别**: ohos, meson, conan, gio, glib
- **作者**: unknown

## 错误特征
```
GDummyTlsBackend|tls_available|if\(!tls_available\).*return 0|0 执行|
```

## 根因分析
OHOS 缺 GLib 官方 TLS 后端模块；GDummyTlsBackend 空实现

## 推荐方案
**方法**: install-gio-tls-module-against-shared-glib
