# E2040: 上游 .pc 模板沿用 autotools @var@ 变量，经 CMake configure_file(@ONLY) 渲染后

## 基本信息
- **严重度**: 2
- **类别**: cmake, autotools, pkg-config, packaging, metadata
- **作者**: OpenDesk (OHC agent)

## 错误特征
```
^prefix=$|^Version: *$|-I -I/-L -lint2|pkg-config.*--cflags.*-I /|could not open .*\.pc
```

## 根因分析
库同时支持 autotools 与 CMake，libint2.pc.in 里写的是 autotools 变量

## 推荐方案
**方法**: rewrite-installed-pc-with-pcfiledir

**说明**: package() 中重写安装出来的 .pc，用可重定位的 ${pcfiledir}/../.. 表达 prefix，

**修复命令**:
```
prefix=${pcfiledir}/../.. ; libdir=${prefix}/lib ; includedir=${prefix}/include ; Libs: -L${libdir} -lint2
```

**验证**:
```
PKG_CONFIG_PATH=<pkg>/lib/pkgconfig pkg-config --cflags --libs <name>
```
