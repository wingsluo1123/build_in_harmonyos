# E2041: 上游用 OUTPUT_NAME 改过产物名（lib<name> 与包名不一致）时，cpp_info.libs 必须写产物的

## 基本信息
- **严重度**: 2
- **类别**: cmake, linking, conan, packaging
- **作者**: OpenDesk (OHC agent)

## 错误特征
```
unable to find library -l.*|cannot find -l.*|ld: library not found for -l.*|defined in .* which is not a library
```

## 根因分析
上游 CMakeLists 用 set_target_properties(libint2 PROPERTIES ARCHIVE_OUTPUT_NAME int2)，

## 推荐方案
**方法**: cpp-info-libs-use-real-artifact-name

**说明**: package_info() 的 cpp_info.libs 填上游**产物**的实际名字（去掉 lib 前缀与扩展名），

**修复命令**:
```
self.cpp_info.libs = ["int2"]
```

**验证**:
```
ls <pkg>/lib （看真实产物名） + 消费者链接
```
