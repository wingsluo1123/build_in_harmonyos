# E2042: 上游把运行期数据目录编码成编译期宏（DATADIR/SRCDATADIR）+ 环境变量开关，

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, packaging, runtime, data-files
- **作者**: OpenDesk (OHC agent)

## 错误特征
```
could not open ".*(basis|share)/.*|system_error.*data_path|
```

## 根因分析
上游 basis.h 的数据路径判定顺序是：环境变量 LIBINT_DATA_PATH >

## 推荐方案
**方法**: cpp-info-defines-for-compile-time-data-dir

**说明**: package_info() 里把数据根目录以编译期宏形式传给消费者：

**修复命令**:
```
self.cpp_info.defines.append(f'DATADIR="{os.path.join(self.package_folder, "share", "libint", "2.7.2")}"')
```

**验证**:
```
BasisSet("<name>", atoms) 应得到正确 nbf；未知名 + throw_if_no_match=true
```
