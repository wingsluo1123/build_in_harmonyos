# E2046: Make 以字符串 "0" 传布尔开关给 shell 脚本时 `test -n "$VAR"` 恒为真——值语义被误当存在性语义，未启用的可选组件分支照样执行

## 基本信息
- **严重度**: 2
- **类别**: make, testing, shell, upstream
- **作者**: ffieldd22_-

## 错误特征
```
Cannot load plugin.*No such file or directory|
```

## 根因分析
Make 变量展开为**文本**：`HAVE_LZO=$(HAVE_LZO)` 传给 shell 是

## 推荐方案
**方法**: value-semantics-guard-for-make-injected-flags

**说明**: 把 shell 测试脚本中针对 Make 注入开关（`$(VAR)` 传入）的守卫由

**修复命令**:
```
sed -i 's|if test -n "\$HAVE_LZO"; then|if test "\$HAVE_LZO" = "1"; then|' test_crypt.sh
```
