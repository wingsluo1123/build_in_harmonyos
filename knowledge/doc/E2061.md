# E2061: 静态 Conan 包的鸿蒙特有测试：先对 .a 归档直接验证成员架构,再链接消费者 ELF 后对消费者产物断言 SONAME/INTERP/code_signature 并运行真实流程

## 错误特征
```
CONAN_LIB_DIRS_[A-Z0-9_]+: unbound variable|grep: INTERP: no match|cannot open.*libsvg-cairo\.a|svg_cairo symbols exported: 0|relocation R_AARCH64_.* cannot be used against symbol.*recompile with -fPIC|cannot link derived shared lib from package archive
```

## 根因分析
1) Conan 2.x VirtualRunEnv 生成的 conanrun 环境只有 PATH/LD_LIBRARY_PATH 等,

## 推荐方案
**方法**: archive-verify-then-consumer-link-assert

**说明**: test() 里以 package_folder 定位最终包静态归档,先直接验证归档身份与

**修复命令**:
```
env OHOS_PKG_LIBDIR=<pkg>/lib OHOS_PKG_INCDIR=<pkg>/include OHOS_DEP_LIBS=... OHOS_DEP_INCS=... bash test_ohos.sh
```

**验证**:
```
head -c 8 <pkg>/lib/libfoo.a; ar t <pkg>/lib/libfoo.a; ar p <pkg>/lib/libfoo.a <member>.o | readelf -h -; readelf -d <derived>.so.0 | grep SONAME; readelf --dyn-syms <derived>.so.0 | grep -c <pkg_prefix>; readelf -l <consumer-exe> | grep "Requesting program interpreter"
```
