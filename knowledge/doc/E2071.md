# E2071: 上游 CMakeLists 的 IF(UNIX) ADD_DEFINITIONS 在 OHOS 静默失效，C 源码落入 X11/GUI 分支报 libgimp/gtk 头缺失；conanfile 用 CMAKE_C_FLAGS 注入 -D__Ansi__ 切回 ANSI 分支

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, ohos, cmake, gui
- **作者**: OpenDesk

## 错误特征
```
sys_X11\.h.*libgimp/gimp\.h.*not found|sys_X11\.h.*gtk/gtk\.h.*not found|PTDialogs\.c.*fatal error|IF\(UNIX\).*ADD_DEFINITIONS|#if.*__Mac__.*__Win__.*__Ansi__
```

## 根因分析
CMake 在 OHOS 工具链下将 CMAKE_SYSTEM_NAME 设为 "HarmonyOS"，UNIX 变量为假，CMakeLists 里 `IF(UNIX) ADD_DEFINITIONS(-D__Ansi__)` 静默不生效、宏缺失；源码条件编译 `#if !__Mac__ && !__Win__ && !__Ansi__` 落入 X11 分支 include sys_X11.h（依赖 libgimp/gimp.h + gtk/gtk.h）→ fatal error。与 E532 同根（CMake UNIX 变量在 OHOS 为假），但 E532 是显式三分支 FATAL_ERROR，本条目是 IF(UNIX) 静默失效导致功能宏未定义、编译期 GUI 头报错。

## 推荐方案
**方法**: inject-ansi-macro-via-cmake-c-flags

**说明**: 在 conanfile.py build() 的 cmake 参数加 -DCMAKE_C_FLAGS=-D__Ansi__，

**修复命令**:
```
defs.append("-DCMAKE_C_FLAGS=-D__Ansi__")
```
