# E2074: HMFS 目录 listxattr 暴露 security.hmmac/security.selinux 但非特权 getxattr 失败（EACCES/EINVAL/EPERM），逐 xattr 读拷贝的构建工具需跳过不可读的 security.* 条目而不是中止整个目录扫描

## 基本信息
- **严重度**: 2
- **类别**: platform, limitation, hmdfs, testing
- **作者**: pc3-13
- **来源 PR**: feat/tar-1.35 (tar 1.35 R02, task tar-1.35-r02-pc3-13-20260913T113300Z)

## 错误特征
```
Cannot fgetxattr: Invalid argument|getxattr failed: Invalid argument|
```

## 根因分析
HMDFS 目录 listxattr 暴露 security.hmmac/security.selinux 等条目，

## 推荐方案
**方法**: 在支持完整 POSIX xattr 的文件系统（ext4/tmpfs）上重跑受影响入口；

**说明**: 在 read_xattrs 的 getxattr 失败分支中，对 security.* 前缀且 errno ∈ {EACCES, EINVAL, EPERM} 的条目 continue（跳过），而不是返回错误中止；其余属性仍按原逻辑读取。语义：内核托管的 security.* 不可读即不迁移，镜像不承载该条目（与 -Dskip-xattrs 对单条目的效果一致）。

**修复命令**:
```
patch read_xattrs: if (str_has_prefix(it,"security.") && (errno==EACCES||errno==EINVAL||errno==EPERM)) continue; 然后重跑 mkcomposefs/check-units
```

**验证**:
```
python3 -c 'import os; os.makedirs(d); print(os.listxattr(d));
```
