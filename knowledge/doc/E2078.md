# E2078: 无 patchelf 时置空 libtool hardcode_libdir_flag_spec，从链接源头消除 .so 的 DT_RUNPATH

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, toolchain, linking, libtool
- **作者**: unknown

## 错误特征
```
readelf -d.*RPATH|RUNPATH.*\.conan2|DT_RUNPATH.*libdir|libtool.*-rpath.*\$libdir|hardcode_into_libs
```

## 根因分析
libtool 脚本对共享库做安装链接时，通过 hardcode_libdir_flag_spec（展开为 $wl-rpath $wl$libdir）把 $libdir 的绝对路径写入 DT_RUNPATH。这是 libtool 的核心行为（hardcode_into_libs=yes 时 install 模式自动加 -rpath $libdir），LDFLAGS 控制不了。OHOS PC 环境常见消除手段全部不可用：patchelf 未安装；libosip2 的 configure 非自动生成、无 --disable-rpath 选项；lld 无 --no-rpath 选项；-Wl,-rpath,（空参数）被 lld 当输入文件导致链接失败；清空 LDFLAGS 无效。产物携带绝对 build 路径的 RUNPATH，违反无 RPATH 发布要求且不可重定位。
