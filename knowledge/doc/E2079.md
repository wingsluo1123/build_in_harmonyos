# E2079: 老版 install-sh（1991 X11R5）仅支持单文件安装，automake 批量调用下 make install rc=0 但每批仅第 1 个文件落盘

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, autotools, toolchain, install
- **作者**: unknown

## 错误特征
```
install-sh.*-c -m 644.*\.\.\.|make install.*exit 0|安装后头文件数与 install 日志不符|silently dropped|install-sh rc=0.*missing files
```

## 根因分析
OHOS PC 上 PATH 无 /usr/bin/install（精简 userland 不带 coreutils install），configure 探测失败后回退到 tarball 自带的老版 install-sh。libosip2-5.3.2 tarball 内 scripts/install-sh 为 1991 X11R5 时代版本（无 scriptversion 行），其参数处理循环注释明说 "can only install one file at a time"：src 只取第一个文件参数、其余全部静默丢弃、退出码仍为 0。automake-1.16 生成的 Makefile 用 am__base_list 每批最多 64 个文件一次调用 install-sh，于是每批只有第 1 个文件落盘。libosip 3 个头文件目录各 1 批 = 恰好 3 个头文件，其余 28 个静默丢失，无任何错误输出。与 hmdfs/hmfs 文件系统无关（tmpfs 上同样复现），目录覆盖说法不成立（单文件重复安装与批量安装下目标目录均完好）。
