## 推荐方案
**方法**: kf-skip-po-processing-flag

**说明**: 移植基线不做本地化交付时，配方显式 tc.variables["KF_SKIP_PO_PROCESSING"]="ON"（或 cmake -D），ki18n_install 在宏头守卫处直接 return，零目录标零工具依赖。诚实权衡：牺牲 .mo 翻译目录（运行时 i18n API 回退源文/英文），只适用于以"库能力可用"为目标的移植阶段。配方树 54 个 conanfile.py 同模式实践（grep archives --include=conanfile.py 实测），L2 第二实例成立。

**修复命令**:
```
conanfile.py generate(): tc.variables["KF_SKIP_PO_PROCESSING"]="ON"；或 cmake -DKF_SKIP_PO_PROCESSING=ON
```
