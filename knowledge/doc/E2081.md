## 推荐方案
**方法**: kf-ignore-platform-check-flag

**说明**: 显式设 KF_IGNORE_PLATFORM_CHECK=ON（CMakeToolchain 变量、cmake -D 或同名环境变量三者皆可，模块 :23-28 全认）。白名单是上游发行策略声明而非技术能力探测：OHOS 上 clang/ECM/KF6 全链路可用（libkomparediff2 26.04.0 上游 2/2 ctest 实证），放行后必须在 PR 适配路径披露白名单外平台身份并保留真实构建+上游测试证据。配方树 113 个 conanfile.py 同模式实践（grep archives --include=conanfile.py 实测），L2 第二实例成立。

**修复命令**:
```
conanfile.py generate(): tc.variables["KF_IGNORE_PLATFORM_CHECK"]="TRUE"；或 cmake -DKF_IGNORE_PLATFORM_CHECK=ON；或 env KF_IGNORE_PLATFORM_CHECK=ON
```
