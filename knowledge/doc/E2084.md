## 推荐方案
**方法**: env-injection

**说明**: 在配方 generate() 内注入 PATH/LD_LIBRARY_PATH/QML_IMPORT_PATH（不动上游文件）

**修复命令**:
```
env.prepend_path("PATH", <qtdeclarative>/bin);
```

**验证**:
```
conan create <recipe> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=... \
```
