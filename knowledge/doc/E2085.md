# E2085: 上游 CFLAGS 含 -g 时 DWARF comp_dir/头文件路径把构建机绝对路径嵌入二进制 → 需 -ffile-prefix-map 三重映射

## 基本信息
- **严重度**: 2
- **类别**: ohos, toolchain, packaging, recipe, reproducibility
- **作者**: AtomCode

## 错误特征
```
strings.*binary.*\|.*grep /storage|strings.*\|.*grep /home|
```

## 根因分析
上游 Makefile 自带 CFLAGS="-g -Wall ... -O3"。-g 生成 DWARF 调试信息时，DW_AT_comp_dir 记录编译时工作目录的绝对路径，#line 引用的系统头文件记录工具链 sysroot 的绝对路径（如 /storage/Users/<user>/usr/local/bin/../sysroot/usr/include）。Conan 构建目录（~/.conan2/p/b/<hash>/b）和本机工具链安装路径因此被永久嵌入产物二进制，strings 可直接看到机器特定路径。验收规则（无宿主路径泄漏）不区分 DWARF 段还是代码段——任何 /home/、/Users/、/storage/ 命中即失败。注意 make -C <source_folder> 时编译器 cwd 是 source_folder（不是 Conan build_folder），单映射 build_folder 无效。

## 推荐方案
**方法**: triple-ffile-prefix-map

**说明**: >

**修复命令**:
```
maps=["-ffile-prefix-map={}=/pkg-build".format(os.path.abspath(f))
```

**验证**:
```
strings <binary> | grep -E '^/storage|^/home|/Users/' —
```
