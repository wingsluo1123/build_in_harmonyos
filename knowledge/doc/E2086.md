# E2086: 纯 Perl/Tk GUI 脚本在 headless OHOS 的最小可用打包：配方内 shebang 重写 + BEGIN 块 --version + 上游无测试的诚实记录

## 基本信息
- **严重度**: 2
- **类别**: ohos, perl, packaging, testing, gui
- **作者**: sea_crab

## 错误特征
```
bad interpreter|/usr/bin/perl.*No such file|Can't locate Tk\.pm|MainWindow->new.*display|no upstream test suite
```

## 根因分析
三因叠加：1) 上游 shebang 指向不存在的解释器（E037）；2) GUI 依赖（Perl::Tk+X11）在 headless CI 不可行，属环境缺位而非代码缺陷；3) 上游从未提供测试套件，CI L1 只能依赖 test_package 真实执行判定

## 推荐方案
**方法**: recipe-shebang-rewrite-plus-begin-version-flag

**说明**: >

**修复命令**:
```
CI_PACKAGES='archives/d/divxcomp/0.1' ci/conan/build_and_test.sh
```

**验证**:
```
>
```
