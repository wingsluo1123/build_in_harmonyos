# E2098: automake 生成规则的并行 install 目录竞态（install-sh 对 EEXIST 直接报错）：install 阶段必须 -j1

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, ohos, autotools, make, automake
- **作者**: GoliWie

## 错误特征
```
make\[1\]: \*\*\* \[Makefile:.*: install-data-local\] Error 1|mkdir .*include.*: File exists|make: \*\*\* \[Makefile:.*: install-am\] Error 2  # 伴生信号、非致命根因: make: jobserver mkfifo: ...: Operation not permitted
```

## 根因分析
automake 1.11 时代生成的 Makefile.in 中，install-data-local

## 推荐方案
**方法**: serial-install-j1

**说明**: automake ≤1.11 / autoconf ≤2.65 谱系的老包，make 的 build/check/

**修复命令**:
```
autotools.make(args=["-j1"]); autotools.make(target="check", args=["-j1"]); autotools.install(args=["-j1"])
```

**验证**:
```
mkfifo /tmp/probe_fifo 2>&1; rm -f /tmp/probe_fifo  # [1] 背景条件探针，期望 Operation not permitted（E074 族）
```
