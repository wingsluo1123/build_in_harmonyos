# E2099: MesonToolchain 用 profile 的 cppstd=17 覆盖项目 meson.build 声明默认（c++11），需 tc.cpp_std 显式回退

## 基本信息
- **严重度**: 2
- **类别**: build-system, meson, toolchain, conan, cpp
- **作者**: unknown

## 错误特征
```
cpp_std='c\+\+17'|built-in options.*cpp_std|compiler.cppstd=17.*overrides
```

## 根因分析
Conan MesonToolchain 从 settings.compiler.cppstd（共享 OHOS profile 为 17）生成

## 推荐方案
**方法**: meson-toolchain-cppstd-rollback

**说明**: 在 generate() 中创建 MesonToolchain 后显式设置 tc.cpp_std = "c++11"

**修复命令**:
```
tc = MesonToolchain(self); tc.cpp_std = "c++11"; tc.generate()
```

**验证**:
```
conan create <archive> -pr:h=ci/conan/profiles/ohos-aarch64
```
