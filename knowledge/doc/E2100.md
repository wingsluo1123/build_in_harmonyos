# E2100: 纯 Python 包的可选 C 加速模块即使本机编译成功也不得随 python-require 配方交付

## 基本信息
- **严重度**: 2
- **类别**: portability, python, conan, packaging, runtime
- **作者**: 692D

## 错误特征
```
ImportError: .*\.so: wrong ELF class|
```

## 根因分析
`pip install`/`setup.py build_ext` 产出的扩展模块名带构建机解释器标签

## 推荐方案
**方法**: package-pure-python-fallback

**说明**: 只打包纯 Python 源码：package() 时跳过 `*.c/*.h/*.pyx` 与任何 `*.so`，

**修复命令**:
```
for entry in os.listdir(src): if entry.endswith((".c",".h",".so",".pyx")): continue
```

**验证**:
```
unzip -l <pkg>.whl | grep -E '\.(so|pyd)'   # 产物中不应有构建机 ABI 的扩展
```
