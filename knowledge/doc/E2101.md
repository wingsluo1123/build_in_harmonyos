# E2101: 宿主解释器的 pytest 插件自动加载与 py3.12 字节码不兼容时，上游测试须以

## 基本信息
- **严重度**: 2
- **类别**: compat, python, conan, testing, environment
- **作者**: 5B09

## 错误特征
```
TypeError: required field "lineno" missing from alias|
```

## 根因分析
目标机/构建机 site-packages 里装的 pytest 与其插件集合是按另一套解释器

## 推荐方案
**方法**: set-env-var

**说明**: 禁用 pytest 插件自动加载（PYTEST_DISABLE_PLUGIN_AUTOLOAD=1），并对无法

**修复命令**:
```
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest <tests> -q --assert=plain -p no:cacheprovider
```

**验证**:
```
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -m pytest --version
```
