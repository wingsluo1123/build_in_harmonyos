# E2102: OHOS clang cfg 注入 -Wl,--code-sign 破坏 Meson -Werror 编译探针 — -Qunused-arguments 对冲

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, meson, compiler, clang-wrapper
- **作者**: libsigc-2-adapter

## 错误特征
```
-Wl,--code-sign: 'linker' input unused|Werror,-Wunused-command-line-argument|gcc_template_specialization_operator_overload.*FAILED|SIGC_TEMPLATE_SPECIALIZATION_OPERATOR_OVERLOAD.*undefined
```

## 根因分析
OHOS SDK clang 包装脚本读取 aarch64-unknown-linux-ohos.cfg，将 -Wl,--code-sign 前置到每次 driver 调用；Meson 编译-only 探针带 -Werror=unused-command-line-argument，链接器专用旗标被判为错误，探针误败，上游按降级路径生成 sigc++config.h（SIGC_TEMPLATE_SPECIALIZATION_OPERATOR_OVERLOAD 未定义），模板代码编译失败。

## 推荐方案
**方法**: conanfile generate() 的 os==OHOS 分支给 tc.extra_cflags/extra_cxxflags 追加 -Qunused-arguments，仅对冲无法剥离的 OHOS cfg 注入；不作全局开关，能在工具链配置层分离编译/链接参数时优先配置层修复并移除本 flag。

**说明**: (待补充)

**修复命令**:
```
tc.extra_cflags.append("-Qunused-arguments"); tc.extra_cxxflags.append("-Qunused-arguments")
```

**验证**:
```
grep -c 'Qunused-arguments' meson-logs/meson-log.txt; readelf -SW libsigc-2.0.so.0.0.0 | grep .codesign; readelf -d libsigc-2.0.so.0.0.0 | grep -i 'soname\|needed'; meson test
```
