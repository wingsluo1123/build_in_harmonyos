## 推荐方案
**方法**: build-upstream-suite-with-O2-release-flags

**说明**: 编译运行 stb_ds 上游套件时显式带 -O2（或经 Conan Release 工具链），与包先例 stb_ds/0.67 一致；-O0 仅用于最小复现，不作为结论依据

**修复命令**:
```
clang++ -O2 -std=c++17 -DDS_TEST -I$SRC $SRC/tests/test_ds.c -o test_ds && ./test_ds
```

**验证**:
```
真机：clang++ -O2 -std=c++17 -DDS_TEST -I<src>
```
