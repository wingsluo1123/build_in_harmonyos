# E2105: stb 单头库消费者必须定义 STB_*_IMPLEMENTATION 宏才有实现：

## 基本信息
- **严重度**: 2
- **类别**: headers, packaging, testing, api-semantics, single-file-library
- **作者**: unknown

## 错误特征
```
ld\.lld: error: undefined symbol: stb_div_(trunc|floor|eucl)|
```

## 根因分析
>

## 推荐方案
**方法**: define-impl-macro-before-include-in-one-tu

**说明**: 消费 stb 头前在本 TU 顶部按矩阵逐个 #define STB_*_IMPLEMENTATION 再 include；宏与 include 必须成对出现在同一文件，多个宏同 TU 合法

**修复命令**:
```
#define STB_IMAGE_IMPLEMENTATION\n#include "stb_image.h"\n#define STB_DS_IMPLEMENTATION\n#include "stb_ds.h"\n#define STB_DIVIDE_IMPLEMENTATION\n#include "stb_divide.h"
```

**验证**:
```
真机（OHOS aarch64，ohos-aarch64 profile）conan create
```
