## 推荐方案
**方法**: explicit-root-file-manifest-copy

**说明**: 配方内维护显式安装清单列表（如 STB_FILES），package() 逐文件 copy；清单本身即包内容文档，且天然排除 deprecated/、tests/ 辅助文件

**修复命令**:
```
STB_FILES=["stb_image.h","stb_ds.h",...]\nfor f in STB_FILES: copy(self,f,src=self.source_folder,dst=...include)
```

**验证**:
```
conan create archives/l/libstb/0.0-git20250907.fede005
```
