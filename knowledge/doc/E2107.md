# E2107: c_check 平台探测不一致记 CROSS=1 时，GotoBLAS 系 Makefile 以 ifneq($(CROSS),1) 静默跳过全部就地测试执行，设备原生构建(构建机=目标机)的测试步骤需命令行显式 CROSS=0 覆盖

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, build-system, detect
- **作者**: GoliWie
- **来源 PR**: (本 PR)

## 错误特征
```
(静默型——无任何错误输出)特征=make lapack-test|test|ctest 数秒内"成功"退出且日志无 run_test/----- PASS -----块；make -n lapack-test CROSS=1 不展开 INSTALL/lapack_testing.py 执行行
```

## 根因分析
完整因果机理链(行号实测 0.3.30 构建树)：(1) CROSS=1 仅由 c_check 记录——c_check:4

## 推荐方案
**方法**: cross-zero-override

**说明**: 设备原生构建(构建机=目标机)时，测试步骤命令行显式 CROSS=0 覆盖 Makefile.conf 的

**修复命令**:
```
make -j1 -C test all CROSS=0 ...；make lapack-test CROSS=0 ...(测试步骤命令行追加 CROSS=0)
```

**验证**:
```
|
```
