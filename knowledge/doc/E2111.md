- **类别**: cmake, conan, environment, generator, silent-failure

## 推荐方案
**方法**: explicit-ninja-generator-plus-define-before-toolchain

**说明**: >

**修复命令**:
```
conan create <pkg> -pr:h ohos-aarch64 -pr:b ohos-aarch64（配方已显式 Ninja，3/3）
```

```
对比实验：conan create -c "tools.cmake.cmaketoolchain:generator=Ninja"
```
