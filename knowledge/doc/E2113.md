# E2113: musl stdint.h 的 INTxx_MIN/INTxx_MAX 宏与旧 C++ 代码

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, libc, musl, headers
- **作者**: pc4-3
- **来源 PR**: (lzham 1.0-stable1 知识库扩展 PR)

## 错误特征
```
expected unqualified-id.*INT32_MIN|
```

## 根因分析
OpenHarmony 的 musl stdint.h 将 INT8_MIN/INT16_MIN/

## 推荐方案
**方法**: undef-guard-extension

**说明**: 沿用上游既有模式，把平台守卫从

**修复命令**:
```
(lzham_types.h)
```

**验证**:
```
修复前: cmake --build <ohos-build> 报 lzham_types.h
```
