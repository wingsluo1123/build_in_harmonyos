# E2114: OHOS musl 极小 malloc/realloc 仅 8 字节对齐，破坏自定义

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, libc, musl, memory
- **作者**: pc4-3
- **来源 PR**: (lzham 1.0-stable1 知识库扩展 PR)

## 错误特征
```
lzham_realloc: bad ptr|
```

## 根因分析
OpenHarmony 的 musl 系运行时对极小尺寸（实测 2/3 字节）的

## 推荐方案
**方法**: aligned-allocator-patch

**说明**: 在分配器初始分配路径（非 WIN32）改用

**修复命令**:
```
(lzham_mem.cpp lzham_default_realloc)
```

**验证**:
```
实测触发前提: 编译小程序循环 malloc(1..16) 打印地址 mod 16
```
