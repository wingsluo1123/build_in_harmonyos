# E2121: OHOS clang 的 Blocks 是「编译期语言开关(-fblocks) + 链接期独立运行库」两半：

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, toolchain, compiler, clang
- **作者**: frj__
- **来源 PR**: (本分支 feat/libblocksruntime-0.4.1，关联 issue #3029)

## 错误特征
```
undefined symbol: _Block_copy|
```

## 根因分析
Clang 的 Blocks（^{...}）被拆成两个独立交付物：编译期由 -fblocks 触发

## 推荐方案
**方法**: package-standalone-blocks-runtime-and-propagate-fblocks

**说明**: 所属类别：编译器已实现的语言/代码生成特性（编译期开关）其独立运行库未随

**修复命令**:
```
conan create archives/l/libblocksruntime/0.4.1 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64
```

**验证**:
```
CC=<profile 指向的 SDK clang>
```
