# E2125: 上游库对依赖版本区间做硬断言而制品仓只有新版时，先实测断言是"仅告警"还是

## 基本信息
- **严重度**: 2
- **类别**: compat, python, dependency, packaging, version
- **作者**: 9C75

## 错误特征
```
RequestsDependencyWarning|
```

## 根因分析
上游包（如 requests 2.22.0）在 import 期用 assert 校验依赖版本区间

## 推荐方案
**方法**: use-prebuilt-package

**说明**: 采用制品仓已发布的新版依赖，用**实测**证明告警非致命：跑通真实调用路径

**修复命令**:
```
self.requires("urllib3/2.7.0")  # 而非降级适配 urllib3/1.25.3
```

**验证**:
```
PYTHONPATH=<deps> python3 -W error::UserWarning -c "import requests"
```
