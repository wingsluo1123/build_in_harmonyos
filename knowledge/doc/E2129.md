# E2129: 通用长选项探针失败时应按上游短选项契约验证 CLI

## 基本信息
- **严重度**: 1
- **类别**: compat, detection, runtime, testing
- **作者**: Windrel
- **来源 PR**: 3798

## 错误特征
```
L2_RESULT=skip: wdq2wav version/help failed
```

## 根因分析
wdq2wav 1.0.0 仅通过 getopt 注册 -h 与 -r 等短选项，而通用 L2 探针固定尝试 --help/--version，因此探针跳过不能等同于二进制不可运行或功能失败。

## 推荐方案
**方法**: validate-supported-upstream-option

**说明**: 保留上游短选项接口，在已安装包消费者测试中运行实际支持的 -h 并断言退出码及辨别性输出；将不支持的通用长选项探针记录为能力 skip，除非交付契约明确要求 GNU 长选项，否则不为迎合探针修改上游接口。

**修复命令**:
```
wdq2wav -h 2>&1 | grep -q 'usage:'
```

**验证**:
```
wdq2wav -h 2>&1 | grep -q 'usage:'
```
