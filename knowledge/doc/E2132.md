# E2132: OHOS 上 sbrk() 返回失败导致自研内存池分配器卡死重试——

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, portability, memory
- **作者**: unknown

## 错误特征
```
MEMORY WARNING|short on swap space|
```

## 根因分析
HarmonyOS 平台上 sbrk() 调用返回 SBRK_FAIL（实测 sbrk(0)

## 推荐方案
**方法**: getmorecore-malloc-branch

**说明**: 在 GetMoreCore 的编译条件中把 OHOS 并入已有 malloc 分支

**修复命令**:
```
修改 base/mem.c 条件宏后重新 configure/make，
```

**验证**:
```
编译并在 OHOS 上运行；或 python3 -c
```
