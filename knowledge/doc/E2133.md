# E2133: 无 X11/Tcl 环境构建图形类 autotools 软件时 configure 的

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, autotools, configure, graphics
- **作者**: unknown

## 错误特征
```
X11/Xlib.h.*file not found|
```

## 根因分析
autotools 图形软件（irsim 及其 magic 系工具）的 configure

## 推荐方案
**方法**: null-graphics-fallback

**说明**: ①configure（及 configure.in）在非 Tcl 非 X11 分支补

**修复命令**:
```
patch configure + 补全 noana.c 后 ./configure && make -j1
```

**验证**:
```
./configure --prefix=$PREFIX && grep -E 'GR_SRCS|gr_srcs' defs.mak;
```
