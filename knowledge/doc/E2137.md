# E2137: musl 的 libintl.h 是空壳（零函数声明）：bison 生成代码序言在 #ifdef __linux 下把 YY_ 映射为 dgettext，OHOS 编译期报隐式声明 + int→指针转换错误

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, musl, compilation, bison-generated-code
- **作者**: ffieldd22_-

## 错误特征
```
call to undeclared function 'dgettext'|
```

## 根因分析
musl 不实现 gettext API：libintl.h 为空壳头文件（存在但零声明），与"头文件缺失"（E531 类）和"符号未链接"（E015 类）均不同；bison 序言的 #ifdef __linux 无条件映射 YY_→dgettext 在 musl 目标上必然编译失败

## 推荐方案
**方法**: libc-capability-guard-bison-prologue（__GLIBC__ 能力守卫 + bison 恒等回退）

**说明**: >

**修复命令**:
```
cd archives/l/latino/1.4.4 && conan create . -pr:h=~/.conan2/profiles/ohos-aarch64 -pr:b=~/.conan2/profiles/ohos-aarch64 --build=missing
```
