# E2142: AC_CONFIG_FILES生成的公共头未被install时在package中补装通过真机编译门禁

## 基本信息
- **严重度**: 3
- **类别**: ohos, headers, build-system, autotools
- **作者**: hmbs-executor
- **来源 PR**: 10399

## 错误特征
```
fatal error: 'ndpi_define\.h' file not found|ndpi_main\.h:32.*ndpi_define\.h
```

## 根因分析
上游src/lib/Makefile.in的install规则只find top_srcdir下src/include/*.h，而ndpi_define.h由AC_CONFIG_FILES在top_builddir生成，源树仅有ndpi_define.h.in，导致包内缺失被ndpi_main.h无条件quote-include的同目录头

## 推荐方案
**方法**: package-install-generated-header

**说明**: 在package末尾补装构建树生成的公共头到package/include/ndpi，找不到则抛错，构建私有的ndpi_config.h保持不发布

**修复命令**:
```
conanfile.py新增_install_generated_headers并在package末尾调用，优先取build树src/include/ndpi_define.h并walk兜底拷贝到package/include/ndpi/ndpi_define.h
```

**验证**:
```
真机conan create的test_package编译通过且上游make check显示executed 2 passed 2
```
