# E2144: OHOS 上 CMake+Check 库的上游 CTest 树因 find_package(Subunit REQUIRED) 无法配置；libcheck 自包含时应去 REQUIRED 并条件链接，同时向 FindCheck 模块种子注入 CHECK_INCLUDE_DIR/CHECK_LIBRARY（禁用 CMakeDeps 以免 CONFIG 模式让 CHECK_FOUND 守卫失效）

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, cmake, conan, test-framework
- **作者**: pc2-25
- **来源 PR**: (本 PR)

## 错误特征
```
find_package\(Subunit REQUIRED\)|Could NOT find Subunit|Subunit.*not found|CHECK_FOUND.*never fires|CTest tree skipped
```

## 根因分析
OHOS 无独立 Subunit 制品，本项目 conan libcheck（check/0.15.2）自包含且官方测试程序

## 推荐方案
**方法**: relax-subunit-required-plus-findcheck-seed

**说明**: ①portability patch：find_package(Subunit REQUIRED)→find_package(Subunit)，

**修复命令**:
```
cmake .. -DBUILD_ORCANIA_TESTING=ON -DCHECK_INCLUDE_DIR=<pkg>/include -DCHECK_LIBRARY=<pkg>/lib/libcheck.a && cmake --build . --target <tests> -- -j1 && ctest --test-dir . --output-on-failure
```

**验证**:
```
ctest --test-dir build --output-on-failure 2>&1 | grep "tests passed"
```
