# E2152: Meson+check库在OHOS下pkgconf供给注入与用例级计数及消费者CMake平台别名回退

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, cmake, testing
- **作者**: hmbs-executor
- **来源 PR**: 10336

## 错误特征
```
Dependency lookup for check.*pkg-config.*failed|Pkg-config for machine host machine not found|CMake Error at CMakeLists\.txt.*project|System is unknown to cmake
```

## 根因分析
配方仅tool_requires pkgconf/3.0.5但未将其bindir前置到PATH且未向machine文件写入pkgconfig绝对路径，真机无系统pkg-config时Meson的pkg-config探测必然失败；meson默认隐藏通过用例stdout导致Checks行缺失而回退到7套件计数冒充44用例；cmake 4.4.3无Platform/HarmonyOS模块且worker缺profile绝对编译器路径导致消费者配置失败

## 推荐方案
**方法**: pkgconf-supply-injection-plus-verbose-count-cmake-alias

**说明**: 从conan dependencies.build解析pkgconf/meson bindir并前置到meson环境PATH，同时向conan_meson_native/cross.ini注入pkgconfig绝对路径；主包meson test加-v捕获44个用例级Checks行并以无Checks行直接判失败防止套件数冒充；test_package改显式CMakeToolchain强制CMAKE_SYSTEM_NAME为Linux并在profile编译器缺失时回退PATH clang

**修复命令**:
```
conanfile.py: build_requirements新增tool_requires meson/1.11.0+pkgconf/3.0.5与test_requires check/0.15.2，generate()新增PkgConfigDeps+_inject_pkg_config/_meson_environment PATH前置，build()以可写TEMP/TMP/TMPDIR运行meson test -v --print-errorlogs；test_package/conanfile.py: generate()导出可写TEMP/TMP/TMPDIR并用显式CMakeToolchain置CMAKE_SYSTEM_NAME=Linux加编译器回退
```

**验证**:
```
真机preflight日志应显示meson configure通过check探测且HMBS_UPSTREAM_TEST_RESULT status passed framework meson+check discovered 44 executed 44 passed 44，test_package显示HMBS_TEST_PACKAGE_RESULT通过且无System is unknown to cmake
```
