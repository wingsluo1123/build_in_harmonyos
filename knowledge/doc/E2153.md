# E2153: 上游 CMakeLists 用普通变量 set(CMAKE_CXX_STANDARD 17) 固定标准时，

## 基本信息
- **严重度**: 2
- **类别**: portability, cmake, toolchain, conan, cxx-standard
- **作者**: 4D18

## 错误特征
```
(unknown type name 'concept'|no template named 'remove_cvref_t')|
```

## 根因分析
CMakeToolchain 通过 cache 变量（native file 里的

## 推荐方案
**方法**: patch-upstream-standard-line

**说明**: 用补丁把上游 CMakeLists 里那一行普通变量直接改为所需标准

**修复命令**:
```
grep -rn "CMAKE_CXX_STANDARD\\|cxx_std_" <src>/CMakeLists.txt <src>/*/CMakeLists.txt
```

**验证**:
```
在 build 目录查看实际生效的标志：
```
