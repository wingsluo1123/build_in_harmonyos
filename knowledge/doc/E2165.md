# E2165: Qt 子模块基于非 SSL qtbase 编译时不导出 SSL API 符号

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, linking, conan, dependency
- **作者**: ohpcd <ohpcd@localhost>

## 错误特征
```
undefined symbol: QWebSocket::sslConfiguration|
```

## 根因分析
Qt 6 子模块（qtwebsockets 等）编译时按所依赖 qtbase 报告的

## 推荐方案
**方法**: dependency-contract-variant

**说明**: qtbase 侧新建 SSL 变体（FEATURE_openssl=ON，如

**修复命令**:
```
(conanfile.py requirements)
```

**验证**:
```
conan create archives/q/qtwebsockets/6.11.1.1.1
```
