## 推荐方案
**方法**: >

**说明**: conandata.yml 里只保留 sources.url 一处 URL：注释与描述性字段不写任何 http(s) 地址，尤其不写 sources.url 的前缀型地址；上游主页、镜像与来源核验信息移到软件级 README.md、版本级 manifest.yaml 与 notes.md（这些文件不被预下载解析）。文件顶部留下一行显式提醒，说明该约束的原因，避免后来者又把主页 URL 写回注释。

**修复命令**:
```
grep -cE 'https?://[^" ]+' archives/<l>/<pkg>/<ver>/conandata.yml   # 期望输出 1
```

**验证**:
```
grep -rE "file://|\.build-cache|predl_cache|currentUser" archives/l/<首字母>/<库名>/<版本>/conandata.yml; conan create archives/l/<首字母>/<库名>/<版本> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
