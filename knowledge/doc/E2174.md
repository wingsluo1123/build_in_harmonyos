# E2174: Python 级运行时依赖未发布 ohpcd conan 仓时，按上游 poetry.lock 锁定组合从 OHOS pypi 镜像 vendor 纯 wheel（py3-none-any）组装 PYTHONPATH；新版 habluetooth 带 OHOS 未签名 .so 必须 pin 回 lock 旧纯 Python 版

- **严重度**: 2
- **类别**: platform, python, packaging
- **作者**: unknown

## 根因分析
(1) BLE 解析库家族（Bluetooth-Devices/*-ble，kegtron-ble/bthome-ble/qingping-ble 等几十个同构包）的 Python 级依赖（sensor-state-data / bluetooth-data-tools / bluetooth-sensor-state-data / home-assistant-bluetooth）未发布到 ohpcd conan 仓——写 conan requires 会被 PF4 依赖闸拦截（R36 链断），完全不跑测试则违反 rule4 上游测试铁律；(2) 依赖解析的最新版陷阱：pip install home-assistant-bluetooth 解析到 2.0.0，其声明 habluetooth>=4.0，OHOS pypi 镜像只有 habluetooth 0.0.1/0.1.0/6.26.5，6.26.5 带 advertisement_tracker.cpython-312-aarch64-linux-ohos.so 未签名不可 dlopen（ImportError: Permission denied），habluetooth 0.1.0 又太老缺 monotonic_time_coarse——必须回退上游 poetry.lock 锁定的 home-assistant-bluetooth 1.4.0（不依赖 habluetooth，直接定义 BluetoothServiceInfo）；(3) HNP Python 怪癖：设置 PYTHONPATH 环境变量后默认 sys.path[0]（/data/storage/el2/base/files/interpreters/pip-global）会被移除——conan build() 沙箱跑 pytest 时 pytest 从 pip-global 找到但其 hypothesis/_native.abi3.so 同样未签名崩掉（rc=1），必须把 pytest/pluggy/iniconfig/packaging/pygments 纯 wheel 一并 vendor 进 PYTHONPATH 目录组成干净环境。

## 推荐方案
**方法**: pypi-wheel-vendor-lock-pinned-python-dep-closure

**说明**: 1) 主配方不写 conan requires（PF4 依赖闸禁止引用未发布依赖）——Python 级依赖在 notes.md/README 申报为 pypi 依赖表；2) 从上游仓库取 poetry.lock/uv.lock 锁定的版本组合（pip 解析最新版会踩 .so 签名坑）——kegtron-ble 1.0.2 lock 组合：sensor-state-data 2.19.0 / bluetooth-data-tools 0.3.1 / bluetooth-sensor-state-data 1.7.5 / home-assistant-bluetooth 1.4.0，全部 py3-none-any 纯 wheel；3) OHOS pypi 镜像（pypi.repo.openharmony.cn/artifactory/openharmony-pypi/）直链 wheel URL 硬编码进配方 _pypi_vendor()（urllib 下载 + zipfile 解压，--no-deps 语义），build() 跑上游 pytest 时 PYTHONPATH=[vendor, src]；4) pytest 自身也 vendor（pytest/pluggy/iniconfig/packaging/pygments 五 wheel）——避开 HNP Python PYTHONPATH 覆盖 pip-global 移除 + hypothesis .so 未签名双坑；5) test_package 消费验证复用同款 vendor（断言只测解析路径——解析层不触碰 bleak 扫描后端，实测移除 bleak 后 import 链与测试全通过）；6) 上游测试如实申报：tests/test_parser.py 3 用例 3/3 PASS（0.09s，纯数据解析无 BLE 硬件依赖）。

**验证**:
```
conan download sensor-state-data/2.19.0 -r=ohpcd --only-recipe 2>&1 | tail -2; PYTHONPATH=/path/to/vendor /data/app/bin/python3 -c "import home_assistant_bluetooth; print('OK')"; grep -A2 'name = "home-assistant-bluetooth"' poetry.lock | head -4
```
