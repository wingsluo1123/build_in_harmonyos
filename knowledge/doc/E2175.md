# E2175: 旧 C/C++ 代码 `strstr/strchr(...) > 0` 指针有序比较在 clang 15 下报 error，改 `!= NULL`

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, compiler, legacy
- **作者**: unknown

## 错误特征
```
ordered comparison between pointer and zero|
```

## 根因分析
gli 0.8.2.0（2016）测试代码用

## 推荐方案
**方法**: 指针有序比较改判空比较

**说明**: 将 `ptr > 0` / `ptr < 0` 改为 `ptr != NULL`（或 `!= nullptr`）；

**修复命令**:
```
|
```

**验证**:
```
make -j2 && ctest  # 修复后全量 0 错误，70/70 通过
```
