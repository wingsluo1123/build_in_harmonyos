# E2177: OHOS/musl 下 alloca() 需显式包含 <alloca.h>（glibc 由 stdlib.h 隐式声明，musl 不提供）

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, libc, musl
- **作者**: pc1-47 <noreply@atomgit.com>
- **来源 PR**: (pending — shoco master feat/shoco-master)

## 错误特征
```
call to undeclared function 'alloca'|
```

## 根因分析
glibc 的 <stdlib.h> 在 __GNUC__ 下隐式声明 alloca()，因此许多上游 C 程序

## 推荐方案
**方法**: explicit-alloca-h-include

**说明**: 在调用 alloca() 的源文件顶部显式 #include <alloca.h>。该头文件在 glibc 与

**修复命令**:
```
printf '#include <alloca.h>\n' | cat - <源文件> > tmp && mv tmp <源文件>  # 置于文件头
```

**验证**:
```
clang -std=c99 -O3 -Wall -fPIC shoco.o shoco-bin.c -o shoco 2>&1 | grep -E 'alloca|undefined symbol'
```
