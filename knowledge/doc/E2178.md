# E2178: Conan 2 apply_conandata_patches：conandata.yml patches 为 dict 时按 version 键查找，文件名键会静默不应用，必须用 list 格式

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, patch, conandata
- **作者**: pc1-47 <noreply@atomgit.com>
- **来源 PR**: (pending — shoco master feat/shoco-master)

## 错误特征
```
No patches defined for version master|
```

## 根因分析
Conan 2 的 apply_conandata_patches 对 dict 类型 patches 按

## 推荐方案
**方法**: conandata-patches-list-format

**说明**: conandata.yml 的 patches 一律用 list 格式：

**修复命令**:
```
"把 conandata.yml 中 'patches: {key: {patch_file: ...}}' 改写为 'patches:\n  - patch_file: ...'"
```

**验证**:
```
conan create ... 2>&1 | grep -E "Apply patch|No patches defined"
```
