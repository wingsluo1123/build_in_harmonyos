## 推荐方案
**方法**: check-hashmap-oom-after-set

**说明**: 消费者测试/业务代码中，hashmap_set() 后一律先调用

**修复命令**:
```
hashmap_set(map, &item); if (hashmap_oom(map)) { /* OOM */ }
```
