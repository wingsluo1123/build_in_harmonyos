# E2182: CPAN 发行版以 Module::Build（Build.PL）为构建系统而 OHOS 缺该模块时，

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, perl, conan, packaging
- **作者**: 1753

## 错误特征
```
Can't\ locate\ Module/Build\.pm\ in\ @INC|
```

## 根因分析
一部分 CPAN 发行版用上游 Module::Build（Build.PL，

## 推荐方案
**方法**: build-script-substitution

**说明**: 在 conanfile.py 的 build() 中，当源码根目录没有 Makefile.PL 时生成一个，

**修复命令**:
```
test -f Makefile.PL || write Makefile.PL (WriteMakefile NAME/VERSION_FROM/
```

**验证**:
```
perl -MModule::Build -e 'print $Module::Build::VERSION' 2>&1
```
