# E2187: 手写 Makefile.in autotools 库（qlibc 模式）的双重适配：构建期相对对象路径必须

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, autotools, conan
- **作者**: pc5-12
- **来源 PR**: （随 qlibc PR 提交，PR 链接以交付为准）

## 错误特征
```
No rule to make target '[a-z_]+/[a-z_]+\.o'.*Stop|Error loading shared library \.\./lib/[a-z]+\.so|needed by .*/lib/lib[a-z]+\.so
```

## 根因分析
(1) 上游手写 src/Makefile.in（非 automake 生成、无 VPATH、无 subdir-objects）

## 推荐方案
**方法**: in-source-layout-plus-static-only

**说明**: layout() 中 basic_layout(self) 后设 self.folders.build = "." 强制 in-source

**修复命令**:
```
def layout(self):\n    basic_layout(self)\n    self.folders.build = "."\n
```

**验证**:
```
conan create 报 "No rule to make target 'containers/qtreetbl.o'"；修布局后
```
