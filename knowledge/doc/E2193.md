# E2193: 兼容精简版ctest短格式汇总行的容错解析与LastTest.log交叉验证

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, build-system, cmake, testing
- **作者**: hmbs-executor
- **来源 PR**: 10653

## 错误特征
```
HMBS_UPSTREAM_TEST_RESULT=\{[^}]*exit 0 but no ctest summary line[^}]*|ctest file evidence:.*LastTest\.log bytes=
```

## 根因分析
真机shim-ctest输出短格式100% tests passed out of 7无0 tests failed中段且stdout仅876字节详情只落盘1.8MB LastTest.log，前两轮强制要求失败计数中段的摘要正则永不匹配致exit 0误判无摘要

## 推荐方案
**方法**: tolerant-short-summary-plus-lasttest-crosscheck

**说明**: 两处摘要正则失败计数改为可选组短格式以percent==100判零失败，字节捕获errors=replace剥ANSI回车空白容忍匹配，跑前清陈旧LastTest*.log并以LastTest.log逐用例Passed加LastTestsFailed为空加Total Test time大于0四重交叉验证，上游测试零改动

**修复命令**:
```
conanfile.py: 摘要正则失败组可选化+percent==100判零失败+LastTest.log交叉复核；跑前删除Testing/Temporary/LastTest*.log；test_package与上游tests零改动
```

**验证**:
```
真机preflight日志应显示HMBS_UPSTREAM_TEST_RESULT status passed且ctest summary-line长短格式兼容解析并附LastTest.log交叉证据
```
