# E2196: OHOS bash 5.3 下 { ... | awk 'print | "cat >&3"' } 3>log 管道元素拿不到 fd 3，

## 基本信息
- **严重度**: 3
- **类别**: platform, autotools, toolchain, test
- **作者**: AtomCode (glm-5.3)
- **来源 PR**: (本 PR)

## 错误特征
```
tap-driver\.sh: line \d+: \d+: Bad file descriptor|ERROR: .* - missing test plan|:test-result: ERROR
```

## 根因分析
OHOS PC 环境的 bash 5.3 (aarch64-unknown-linux-ohos 移植, /storage/.../usr/local/bin/bash)

## 推荐方案
**方法**: make-shell-override

**说明**: conanfile build() 的 make check 用命令行覆盖 SHELL=/bin/sh(mksh 系),

**修复命令**:
```
autotools.make(target="check", args=["-j1", "SHELL=/bin/sh"])
```

**验证**:
```
bash -c '{ echo y | cat >&3 2>&1; } 3>/tmp/fd3probe.log; test -s /tmp/fd3probe.log && echo OK || echo BASH-FD3-BROKEN'
```
