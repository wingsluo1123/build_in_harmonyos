# E2197: 上游测试以「存在 Makefile」为运行前提时只能走 make test——

## 基本信息
- **严重度**: 2
- **类别**: build-system, perl, conan, testing
- **作者**: 1753

## 错误特征
```
plan skip_all => 'This test requires a Makefile|
```

## 根因分析
一类 MakeMaker 生态的上游测试**故意以「构建产物存在」为运行

## 推荐方案
**方法**: run-via-generated-makefile

**说明**: 上游测试一律经 **`make test`** 运行（先在源码目录

**修复命令**:
```
perl Makefile.PL INSTALLDIRS=site && make && make test
```

**验证**:
```
ls Makefile 2>/dev/null || echo "no Makefile → 这些测试会整体 skip"
```
