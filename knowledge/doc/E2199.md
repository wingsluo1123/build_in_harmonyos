## 基本信息
- **严重度**: 2
- **类别**: portability, perl, testing, environment, task
- **作者**: 1753

## 错误特征
```
"\w+" is not exported by the Errno module|
```

## 根因分析
OHOS 上并存两套 perl：设备 perl（5.42.2，

## 推荐方案
**方法**: pin-interpreter

**说明**: 配方与 test_package 统一 pin /data/service/hnp/bin/perl

**修复命令**:
```
self.run("/data/service/hnp/bin/perl Makefile.PL INSTALLDIRS=site") …
```

**验证**:
```
/storage/Users/currentUser/usr/local/bin/perl -e 'use Errno qw(EWOULDBLOCK); print "ok\n"'
```
