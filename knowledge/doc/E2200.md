# E2200: 制品仓里的构建期工具链接了共享库、在 HMDFS 上无法执行时，

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, portability, build-system, toolchain, sandbox
- **作者**: 8D52

## 错误特征
```
cannot execute binary file|
```

## 根因分析
HMDFS（OHOS 的可写文件系统）对 Conan 缓存目录里的共享库

## 推荐方案
**方法**: build-static-tool-from-source

**说明**: 从上游源码静态编译一个等价工具，仅依赖 libc：

**修复命令**:
```
clang -o <gen>/<tool> -include config.h -I<src> -I<src>/src \
```

**验证**:
```
<pkg>/bin/<tool> --help 2>&1 | head -3
```
