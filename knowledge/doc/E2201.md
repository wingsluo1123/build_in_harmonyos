# E2201: 下游库构建系统里的版本门槛（dependency(..., version: '>=X')）

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, dependency, version, planning
- **作者**: 7E31

## 错误特征
```
Dependency .* found: NO\. Found .* but need: '>=.*'|
```

## 根因分析
被适配的下游库在其构建系统里对基础依赖声明**硬性最低版本**

## 推荐方案
**方法**: dependency-first

**说明**: 先量化再动手：①在被适配库的源码里枚举全部版本门槛

**修复命令**:
```
grep -rnE "dependency\([^)]*version" <src>/meson.build   # 枚举门槛
```

**验证**:
```
meson setup build <downstream-src>   # 用制品仓现有版本的真实 .pc
```
