# E2206: OHOS 拒绝执行经 ld -r + objcopy --keep-global-symbols 合并对象链接出的可执行文件

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, make, linking
- **作者**: E038

## 错误特征
```
Operation not permitted.*bin/base64|sh: .*Operation not permitted|ld -r.*objcopy --keep-global-symbols|exec.*EPERM.*merged object|test_base64: .*126
```

## 根因分析
上游 Makefile 用 $(LD) -r 合并各 codec 对象生成"合并可重定位对象"，再用

## 推荐方案
**方法**: cmake-path

**说明**: 配方优先走 CMake 构建路径（正常 add_library，无 objcopy 合并步骤），

**修复命令**:
```
cmake -DBASE64_BUILD_TESTS=ON -DBASE64_WERROR=OFF .. && make -j1 && ctest
```

**验证**:
```
make && make -C test 2>&1; ./test_base64 # -> sh: Operation not permitted (126);
```
