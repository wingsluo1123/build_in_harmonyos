# E2212: 上游只给 x86/PPC 提供 CPU 模式探测实现（cpu_mode_*.c）时，aarch64 落入空 MLIBS 分支导致链接期 undefined symbol: Cpu_mode/find_cpu_mode——新增恒 PORT 后端的 cpu_mode_arm64.c

## 基本信息
- **严重度**: 2
- **类别**: portability, autotools, aarch64
- **作者**: unknown

## 错误特征
```
undefined symbol: Cpu_mode|undefined symbol: find_cpu_mode|undefined reference to `find_cpu_mode`|undefined reference to `Cpu_mode`
```

## 根因分析
libfec 等库的 configure.in 仅为 i386/powerpc/x86_64 设置

## 推荐方案
**方法**: add-aarch64-port-cpu-mode-backend

**说明**: 新增 cpu_mode_arm64.c（镜像 cpu_mode_x86_64.c：Cpu_modes 名称表 +

**修复命令**:
```
编写 cpu_mode_arm64.c 并修改 configure.in 后 autoconf 重生成
```

**验证**:
```
make test; make; nm libfec.a | grep -c find_cpu_mode
```
