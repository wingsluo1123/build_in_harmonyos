# E2213: 只读/tmp下munit经tmpfile缓冲stderr失败时构建期-Dtmpfile重定向到TMPDIR兼容

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, libc, musl, posix
- **作者**: hmbs-executor
- **来源 PR**: 10635

## 错误特征
```
unable to create buffer for stderr: Permission denied \(13\)|tmpfile.*Permission denied
```

## 根因分析
OHOS libc tmpfile硬编码/tmp并忽略TMPDIR且真机/tmp只读报EACCES而munit每例调用tmpfile缓冲stderr失败即MUNIT_ERROR致32例全error

## 推荐方案
**方法**: tmpfile-redirect-to-tmpdir-shim

**说明**: 构建期生成TMPDIR感知的hmbs_tmpfile shim经mkstemp加unlink加fdopen实现仅对munit目标加-Dtmpfile等于hmbs_tmpfile重定向库源码与归档产物不动33/33通过验证为跨库可复用模式

**修复命令**:
```
conanfile.py新增_build_tmpfile_shim生成hmbs_tmpfile_shim.c并在_link_test仅对munit目标加-Dtmpfile=hmbs_tmpfile后链接该对象加notes.md记录
```

**验证**:
```
真机preflight日志应显示HMBS_UPSTREAM_TEST_RESULT status passed discovered 33 executed 33 passed 33 failed 0 skipped 0且command为./opaque-test && ./opaque-munit --fatal-failures
```
