# E2215: OHOS 受限 LLVM 工具链上自举型语言编译器的适配模式（LLVM_CONFIG 换制品仓 LLVM + per-target 初始化符号改 All 系列 + conanrun 注入运行期库路径）

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, autotools, toolchain, compiler
- **作者**: Hawkninja21
- **来源 PR**: #10021

## 错误特征
```
Unsupported LLVM version|Platform .* unsupported|Error loading shared library libLLVM|Error relocating .* LLVM.*: symbol not found
```

## 根因分析
以 LLVM 为后端的语言编译器把宿主 LLVM 工具链当成隐含前提（Odin 本体为 C++，但其交付面必须构成自举闭环：用本包产出的 odin 再编译并运行 Odin 程序；odinfmt/ols 等下游工具更是用 Odin 自写、离开可用 odin 无法构建），构建脚本在三处硬编码了这种耦合：①LLVM 版本门禁（build_odin.sh 只接受 17-22，而宿主 /data/service/hnp/bin/llvm-config 为 15.0.4，自动探测与强制指定均被拒）；②LLVM 目标初始化按 arch 分支直接调用 per-target 符号（src/llvm_backend.cpp L3065-3111），而制品仓 llvm/22.1.0 交付的是 AArch64-only 聚合库 libLLVM.so.22.1，llvm-c/Target.h 只声明 All 系列与 AArch64 子集，per-target 声明不存在 → 编译期 undeclared identifier；③平台识别 case "$OS_NAME" 无 HarmonyOS 分支，落 `*` 直接拒绝。运行期还有一层独立误诊：冒烟阶段用 conanbuild 环境只注入 SDK LLVM 15 的路径，LD_LIBRARY_PATH 未指向 llvm/22.1.0/lib，症状是动态库加载失败并连带上百条符号重定位失败，与 ABI 无关；把该症状当成"新版 LLVM ABI bad_cast"会得出"平台不可适配"的错误结论。

## 推荐方案
**方法**: upstream-patch+env-fix（五子模式组合：版本门禁替换 + All 系列符号 patch + conanrun 运行期注入 + uname 平台映射 + 离线源码校验）

**说明**: ①版本门禁：宿主 llvm-config 15.0.4 不在 build_odin.sh 的 17-22 白名单内，改用制品仓 llvm/22.1.0 作 tool_requires，并把 LLVM_CONFIG 指向其 llvm-config，不修改上游版本下限；②聚合库符号：把 src/llvm_backend.cpp 的 per-target LLVMInitialize* 调用改为 LLVMInitializeAll* 系列（X86/ARM/AArch64/WebAssembly/RISCV 各分支统一，patches/0001-llvm-backend-all-target-init.patch，sha256 c30f86e31791248b8a35ec70724c2c7942aa95a325a903138104e1cb4978bcf8），AArch64 语义等价，不改上游功能；③运行期环境：冒烟与 test_package 的 self.run 一律用 env="conanrun"（不是 "conanbuild"），让 LD_LIBRARY_PATH 指向 llvm/22.1.0/lib；④平台识别：build_odin.sh 的 OS 分支把 uname -s=HarmonyOS 映射为 Linux，保留 aarch64 目标语义；⑤源码获取：本机 github.com:443 不可达、gitcode 镜像无 tools/，用本地 tarball 双源 sha256 核对后经 file:// 离线源构建，提交前还原为官方 URL。

**修复命令**:
```
LLVM_CONFIG=<llvm-22.1.0>/bin/llvm-config ./build_odin.sh release  # 前置: conan install llvm/22.1.0 作 tool_requires；冒烟/test 用 conanrun env；patch 0001 覆盖 src/llvm_backend.cpp
```

**验证**:
```
conan create archives/o/odin/dev-2026-08 -pr:h= -pr:b= --build=odin/* && test_package/run_tests.sh
```
