# E2216: A plain non-header file named like a C++ standard header in a directory added with -I shadows the real standard header (<version>): rename or move the file out of the include root instead of adjusting standard-library includes

## 基本信息
- **严重度**: 2
- **类别**: header-shadowing
- **作者**: unknown

## 错误特征
```
expected unqualified-id|version:1:1: error
```

## 根因分析
C++17 added standard headers whose names are common English words (version, compare, concepts, coroutine, ...). Autotools projects routinely pass -I$(top_srcdir) so sources can include private headers as <odb/database.hxx>. libodb 2.4.0 ships a plain-text documentation file literally named "version" at the source root (listed in dist_doc_DATA). With the source root on the include path, the preprocessor resolves the transitive #include <version> (pulled in by libc++ headers such as <memory>/<new> under C++17) to that text file, parses it as a header, and the compiler dies inside it with "error: expected unqualified-id" at version:1:1 - in every C++17 translation unit. The toolchain is fine; the project's own include root shadows the standard library.

## 推荐方案
**方法**: remove-or-rename-shadowing-file-out-of-include-root

**说明**: Take the shadowing file out of the include search path instead of touching include flags: remove it from the source root (for autotools drop it from dist_doc_DATA and delete the file, or move it under a doc/ subdirectory, or rename it to version.txt / generate it into the build dir). The include graph stays intact, the root cause is removed, and the fix is upstreamable. In libodb/libodb-pgsql 2.4.0 the source-root "version" doc files were dropped from dist_doc_DATA and deleted in the OHOS patches, after which every C++17 TU compiled clean again.

**修复命令**:
```
apply the patch removing the source-root version file (dist_doc_DATA + file deletion) and rebuild: conan create archives/l/libodb-pgsql/2.4.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
d=$(mktemp -d) && printf 'text not C++\n' > "$d/version" && printf '#include <memory>\n#include <new>\nint main(){return 0;}\n' > "$d/tu.cxx" && { clang++ -std=c++17 -I"$d" -fsyntax-only "$d/tu.cxx" ; echo "expect FAIL: expected unqualified-id, error points inside $d/version" ; clang++ -std=c++17 -fsyntax-only "$d/tu.cxx" && echo "control without -I: clean" ; }
```
