# E2217: C++17-removed constructs (std::auto_ptr, dynamic exception specifications) should be compiled out behind feature macros derived from __cplusplus, not by lowering -std

## 基本信息
- **严重度**: 2
- **类别**: cxx17-migration
- **作者**: unknown

## 错误特征
```
no template named 'auto_ptr' in namespace 'std'|ISO C++17 does not allow dynamic exception specifications
```

## 根因分析
Code written against C++03/TR1 uses std::auto_ptr and dynamic exception specifications (throw(X)); both were removed by C++17. The OHOS toolchain's libc++ headers support C++17 and later only (see E130), so the platform-required -std=c++17 surfaces "no template named 'auto_ptr' in namespace 'std'" and "ISO C++17 does not allow dynamic exception specifications" (libodb 2.4.0: about 14 auto_ptr + 6 exception-spec = 20 errors across the core headers). Lowering -std is not available on this platform, so the removed constructs must be compiled out conditionally, deriving the condition from the language standard itself.

## 推荐方案
**方法**: feature-macro-compile-out-derived-from-cplusplus

**说明**: Derive a feature macro from the language standard and compile the removed constructs out - zero platform macros (R8): in a central config header `#if __cplusplus >= 201703L` / `#define ODB_NO_AUTO_PTR` / `#endif`, guard the auto_ptr specializations with `#ifndef ODB_NO_AUTO_PTR`, and drop or `#if __cplusplus < 201703L`-guard the throw(X) specifications. Behavior under older standards is unchanged, the fix is upstreamable, and the same technique generalizes to any C++17-removed construct. libodb 2.4.0 needed 20 errors removed this way and then compiled clean under C++17.

**修复命令**:
```
apply the feature-macro patch and rebuild: conan create archives/l/libodb-pgsql/2.4.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
d=$(mktemp -d) && printf '#include <memory>\nstruct X{};\nint f() throw(X){return 0;}\nstd::auto_ptr<int> g(){return std::auto_ptr<int>();}\nint main(){return f()==0;}\n' > "$d/tu.cxx" && { clang++ -std=c++17 -fsyntax-only "$d/tu.cxx" ; echo "expect FAIL: no template named 'auto_ptr' + dynamic exception specification" ; clang++ -std=c++14 -fsyntax-only "$d/tu.cxx" && echo "control c++14: clean" ; }
```
