# E2223: CMake 无 install 规则的小型 C 库：package() 手动装配 include/<subdir> 头与静态库

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, packaging, static-library, c-library
- **作者**: AtomCode Executor <noreply@atomgit.com>

## 错误特征
```
fatal error: 'Fusion\.h' file not found|Packaged 0 files|install rule|cmake\.install\(\).*nothing|no install rules
```

## 根因分析
部分上游 CMake 工程只提供 add_library 与 target_include_directories，

## 推荐方案
**方法**: manual-package-header-subdir

**说明**: build() 只构建库目标（cmake.build(target=["<TargetName>"]）跳过示例；

**修复命令**:
```
conanfile.py: cmake.build(target=["Fusion"]); copy(self,"*.h",
```

**验证**:
```
conan create archives/f/fusion/1.3.3 -pr:h=ci/conan/profiles/ohos-aarch64 \
```
