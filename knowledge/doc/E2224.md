- **严重度**: 2

## 错误特征
```

```

## 根因分析
库默认开启异步输出（elog_output() 先入环形缓冲，独立线程 sem_wait

## 推荐方案
**方法**: test_package/test.c 在 log_* 全部输出后 usleep(1000 * 1000)（1s，

**说明**: easylogger 2.2.0 实测：默认 elog_cfg.h 开 ELOG_ASYNC_OUTPUT_ENABLE，

**修复命令**:
```
"test.c: log_a(...); ...; elog_raw(...); usleep(1000*1000); assert(strstr(captured, marker) != NULL);"
```
