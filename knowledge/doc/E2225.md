# E2225: automake test-suite汇总双空格对齐解析修复与XFAIL计入通过，真机rc=0时避免零计数误判failed

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, autotools, testing
- **作者**: hmbs-executor
- **来源 PR**: 10893

## 错误特征
```
\[upstream\] # FAIL:  \d+|HMBS_UPSTREAM_TEST_RESULT=\{[^}]*"status":\s*"failed"[^}]*"passed":\s*0
```

## 根因分析
conanfile.py _run_upstream_tests用单空格正则解析automake test-suite汇总，automake对个位数用双空格对齐导致PASS/FAIL等行漏匹配，total累加但passed/failed为0而误判failed，且XFAIL未计入通过

## 推荐方案
**方法**: fix-automake-summary-spacing-and-count-xfail

**说明**: 将汇总解析两处正则分隔符由单空格改为\s+兼容单双空格，并将XFAIL计入passed以反映预期失败非失败语义

**修复命令**:
```
archives/l/liborcus/0.21.0/conanfile.py _run_upstream_tests内summaries与finditer两处正则改为# (TOTAL|PASS|FAIL|SKIP|ERROR|XFAIL|XPASS):\s+(\d+)并将XFAIL累加到passed
```

**验证**:
```
真机preflight日志应显示HMBS_UPSTREAM_TEST_RESULT status passed discovered 39 executed 39 passed 39 failed 0，且[upstream]汇总行无漏计
```
