# E2227: Test-framework self-test suites deliberately include negative-path cases that exit non-zero: the recipe build() upstream-test gate must follow the upstream harness semantics (compile failures are the hard gate; a run is fine if the framework printed its report, whatever the exit code)

## 基本信息
- **严重度**: 2
- **类别**: testing, gating, test-framework, upstream-tests
- **作者**: junshi_liu

## 错误特征
```
1 failed of [0-9]+ run|FAILURE$|assertion in 'failure' failed|negative path
```

## 根因分析
A unit-testing framework's own test suite MUST

## 推荐方案
**方法**: harness-semantics-test-gate

**说明**: In the recipe build(), compile every upstream test

**修复命令**:
```
clang -D_POSIX_C_SOURCE=200112L -I . -o <prog> -w tests/<name>.c && <prog> -s
```

**验证**:
```
cd <src>; for i in tests/*.c; do cc -I . -o /tmp/t -w "$i" || exit 1; /tmp/t -s; done; echo "all files compiled and produced a framework report"
```
