# E2229: OHOS 静态 glib(shared=False)嵌入 .so 时消费者形成双实例 GObject 类型系统,unref 库内对象 SIGSEGV

## 基本信息
- **严重度**: 2
- **类别**: ohos, runtime, glib, gobject
- **作者**: pc2-20
- **来源 PR**: (本 PR)

## 错误特征
```
Signal 11 \(core dumped\)|g_object_unref.*SIGSEGV|G_IS_FILE.*incompatible|assertion 'G_IS_FILE\(file\)' failed|xb_builder_source_load_file.*G_IS_FILE
```

## 根因分析
glib/2.88.0 制品为静态库(shared=False)时,libxmlb.so 在链接期把 glib/gio 静态嵌入自身

## 推荐方案
**方法**: skip-cross-library-unref

**说明**: 消费者测试不 unref 库内 GObject/GPtrArray(进程退出回收),只释放自有分配

**修复命令**:
```
(测试源码 out 段仅 g_free 自有字符串 + g_error_free,不 g_ptr_array_unref/g_object_unref)
```

**验证**:
```
nm -D libxmlb.so.2.0.0 | grep -c " U g_".*(0 = glib 被静态嵌入);
```
