# E2231: meson dependency('liblzma') not found:PkgConfigDeps 按组件名生成 xz.pc,liblzma.pc 缺失

## 基本信息
- **严重度**: 2
- **类别**: build-system, meson, conan, pkg-config
- **作者**: pc2-20
- **来源 PR**: (本 PR)

## 错误特征
```
Dependency "liblzma" not found \(tried pkg-config\)|liblzma not found
```

## 根因分析
conan PkgConfigDeps 按依赖包组件 pkg_config_name 生成 .pc 文件名(xz 组件 → xz.pc),

## 推荐方案
**方法**: generate-pc-shim

**说明**: 在 generate() 内为 meson 期望的上游 .pc 名生成 shim,内容指向依赖真实 libdir/includedir

**修复命令**:
```
(配方内 _fix_xz_pc_files():xz∈self.dependencies 时写 liblzma.pc 到 generators_folder)
```

**验证**:
```
grep -n "liblzma" build/meson-logs/meson-log.txt 确认失败;生成 shim 后
```
