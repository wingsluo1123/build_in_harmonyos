## 推荐方案
**方法**: no-build-direct-compile-stage-headers

**说明**: build() 内用 conf/环境 CC 直编各 TU 生成 .o，llvm-ar 打包为

**修复命令**:
```
for s in *.c; do ${CC:-clang} -fPIC -O2 -I${SRC}/easyflash/inc -c ${SRC}/easyflash/src/$s -o $s.o; done && ${AR:-llvm-ar} rcs libeasyflash.a *.o && mkdir -p include && cp ${SRC}/easyflash/inc/*.h include/
```

**验证**:
```
grep -cE 'EF_ERASE_MIN_SIZE|ENV_AREA_SIZE' <patched>/ef_cfg.h;
```
