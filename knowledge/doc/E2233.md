# E2233: Remove shared .cmake include from EA-family CMakeLists when the module lives in an omitted submodule

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan, source
- **作者**: unknown

## 错误特征
```
could not find requested file: CommonCppFlags|CMake Error at CMakeLists\.txt:.*\(include\)|include\(CommonCppFlags\)
```

## 根因分析
EA 系库（EAMain/EAStdC 等）顶层 CMakeLists 通过 CMAKE_MODULE_PATH 指向

## 推荐方案
**方法**: "移除 include(CommonCppFlags) 与 CMAKE_MODULE_PATH 指向（补丁 0001）；等价编译标志由 Conan toolchain（CMakeToolchain + CMAKE_CXX_FLAGS 依赖注入）提供"

**说明**: "不需要下载 submodule（E150 方案，unpinned 且非确定性）；直接删除对缺失模块的引用，标志等价项交给 toolchain"

**修复命令**:
```
"patch 0001-remove-submodule-commoncppflags.patch：删除 set(CMAKE_MODULE_PATH ...)/include(CommonCppFlags) 两行"
```

**验证**:
```
"conan create <archive> -pr:h=<ohos-profile> --build=missing && cmake configure 通过 && libEAMain.a 构建成功"
```
