# E2234: libbz3 高层 API bz3_compress/bz3_decompress 的 *out_size 是 in/out 参数：调用前必须初始化为输出缓冲区容量，否则返回 BZ3_ERR_DATA_TOO_BIG(-6)

## 基本信息
- **严重度**: 2
- **类别**: runtime, testing, api, consumer-test
- **作者**: unknown

## 错误特征
```
bz3_compress failed|BZ3_ERR_DATA_TOO_BIG|rc=-6
```

## 根因分析
bz3_compress/bz3_decompress 的函数签名把 *out_size 设计为 in/out 参数：进入时表示输出缓冲区容量，返回时回写实际输出大小（libbz3.h 98-99/108 行明确 "Make sure to set out_size to the size of the output buffer before the operation"）。调用者若按惯例初始化为 0，函数内部以 buf_max=0 与 13/bz3_bound(in_size) 比较直接返回 BZ3_ERR_DATA_TOO_BIG(-6)。这是 API 契约细节，不是库缺陷或平台问题。

## 推荐方案
**方法**: preinit-out-size-to-buffer-capacity

**说明**: 遵循头文件文档把输出大小参数预置为容量；不要当作纯 out 参数。

**修复命令**:
```
鸿蒙专项测试 ohos_bzip3_roundtrip.c 修复前后对比：pre 为 comp_size=0 → rc=-6；post 为 comp_size=bound → PASS（payload1 65536B→131B，payload2 262144B→264082B，解压后 memcmp 一致）
```

**验证**:
```
size_t comp_size = bz3_bound(in_size); rc = bz3_compress(16, in, comp, in_size, &comp_size); size_t decomp_size = in_size + 4096; rc = bz3_decompress(comp, decomp, comp_size, &decomp_size);
```
