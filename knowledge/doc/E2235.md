# E2235: CMake release tarball 打包遗漏被 CMakeLists.txt 引用的 .cmake.in 模板时 configure_file 直接失败，从上游 git tag 还原单文件即可

## 基本信息
- **严重度**: 3
- **类别**: cmake, packaging, source-download
- **作者**: unknown

## 错误特征
```
bzip3-config\.cmake\.in does not exist|CMakeLists\.txt:.*\(configure_file\): configure_file Problem configuring file
```

## 根因分析
上游在 git 仓库中存在 bzip3-config.cmake.in（CMakeLists.txt 第 102 行 configure_file 必须读取它），但 release tarball 打包流程遗漏该文件，导致解包后 configure 立即报 "File ... does not exist" 而失败。这是上游打包流程缺陷，不是 OHOS 平台问题。

## 推荐方案
**方法**: restore-missing-template-from-upstream-git-tag

**说明**: 用补丁从上游 git tag 还原被遗漏的模板文件，保持官方 URL 不变（R39），避免改写 conandata.yml 源。

**修复命令**:
```
patches/0001-bzip3-config.cmake.in.patch 新增文件内容与上游 git tag 1.5.4 完全一致（5 行: if(@BZIP3_ENABLE_PTHREAD@) include(CMakeFindDependencyMacro) find_dependency(Threads) endif() include("${CMAKE_CURRENT_LIST_DIR}/bzip3-targets.cmake")）
```

**验证**:
```
cmake -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF -DBZIP3_ENABLE_PTHREAD=ON && cmake --build build -j2; conan create archives/b/bzip3/1.5.4 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
