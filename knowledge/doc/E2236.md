# E2236: lang-preflight 将"单头文件库"误判为 mixed（库主体 .h 被统计跳过，仅剩 .c/.cpp 测试 50%）

## 基本信息
- **严重度**: 2
- **类别**: headers, lang-preflight, language-detection, mixed-misdetect, r47
- **作者**: unknown

## 错误特征
```
detected_language:\s*mixed|源文件 \d+ 个.*主体占比 50%|无 manifest 且主体占比 < 70% -> mixed|env_unsupported
```

## 根因分析
scripts/ohc/lang_detect.py _source_stats 将 .h 视为中立头文件完全不参与统计；对单头文件库

## 推荐方案
**方法**: manual-boundary-rule-override

**说明**: mixed 判定后按 D.4 边界规则人工复核：单头文件库主体语言由 .h 内容决定（C11/C++），

**修复命令**:
```
（人工复核继续）; python3 scripts/ohc-run.py conan-verify <pkg> <ver> && finish <pkg> <ver> built
```

**验证**:
```
python3 scripts/ohc-run.py lang-preflight verstable 2.2.1 --src <源码目录>
```
