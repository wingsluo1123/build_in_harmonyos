```
fail checksum rand|checksum.*Failed.*tests|NEON.*wrong.*(high|upper).*(16|half)|fail end test

## 根因分析
汇编文件常用 `.section .rodata.cst16,"aM",@progbits,16` 存放 SIMD 常量表

## 推荐方案
**方法**: drop-merge-flag-use-plain-rodata

**说明**: 把常量段的 merge 属性去掉：`.section .rodata,"a",@progbits`

**修复命令**:
```
sed/patch 将 `.section\t.rodata.cst16,"aM",@progbits,16` 改为
```

```
