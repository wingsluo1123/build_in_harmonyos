# E2244: GitHub tag 源码包无 configure 且 tool_requires automake/autoconf/libtool 在 HMDFS 真机自身构建即挂（configure 直接 exec EACCES=126 + conan perl Cwd.so dlopen 失败 + ohpcd 无预构建），应改用上游自带的 Makefile.unx/make.inc 免 autotools 构建系统

```
Permission denied.*configure|Error 126 while executing|Cwd\.so.*dlopen|error:not found.*automake
```

## 根因分析
1) 上游 release 只挂 tag 无 dist 资产，官方源码包没有 configure，

## 推荐方案
**方法**: use-upstream-makefile-unx

**说明**: libisal 的 Makefile.unx + make.inc include 与 autotools 完全

**修复命令**:
```
make -f Makefile.unx arch=aarch64 host_cpu=aarch64
```

**验证**:
```
ls Makefile.unx make.inc；grep "include.*Makefile.am" Makefile.unx；
```
