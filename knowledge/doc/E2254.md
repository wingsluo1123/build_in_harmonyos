# E2254: 宏模板容器头（ctl 型）须每个模板头独立定义 T，非模板头包含前必须 undef

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, conan, packaging, testing
- **作者**: AtomCode/oh-executor pc4-10

## 错误特征
```
Template type T undefined for <|Template type T defined for <|#undef T|undefined symbol: .*_size
```

## 根因分析
宏模板容器库（如 rurban/ctl）以 `#define P` + `#define T <type>`

## 推荐方案
**方法**: per-header-template-define

**说明**: 每个模板容器头在 include 前单独 `#define P` + `#define T <type>`；

**修复命令**:
```
#define P\n#define T int\n#include <vec.h>\n#undef T\n#undef P\n#include <str.h>
```

**验证**:
```
aarch64-unknown-linux-ohos-clang -std=c11 -I<ctl/ 头目录> test.c -o test && ./test
```
