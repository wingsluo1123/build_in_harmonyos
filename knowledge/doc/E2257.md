# E2257: 纯 Python 包缺少 `__main__.py` 时 `python3 -m` 入口不可执行、pip console script shebang 内嵌构建机解释器绝对路径，CLI wrapper 应改写为自解析 `/bin/sh` 并 `import 包; 包.main()`（kernel-hardening-checker 0.6.17.1 案例）

## 基本信息
- **严重度**: 2
- **类别**: portability, python, conan, packaging
- **作者**: sea_crab <sea_crab@atomgit.com>

## 错误特征
```
No module named .*__main__.*cannot be directly executed|bad interpreter:.*No such file or directory
```

## 根因分析
（机理链，pip/setuptools/CPython 三处稳定语义，非单库 quirk）(1) 包以 pyproject `[project.scripts] <cli> = "<pkg>:main"` 声明 CLI 入口且包内无 `__main__.py`；(2) CPython `-m` 语义要求包可执行模块 `__main__.py`——真机实测报 `No module named <pkg>.__main__; '<pkg>' is a package and cannot be directly executed`，照抄 py-cpuinfo 形态的 `exec python3 -m <pkg>` wrapper 整体不可用（kernel-hardening-checker 0.6.17.1 设备探针实测）；(3) pip 安装器生成的 console script shebang 内嵌安装解释器绝对路径（设备私有路径，py-cpuinfo 9.0.0 manifest.yaml:79 既有知识："pip 生成的 console script shebang 指向构建机 Python 路径，不可迁移"），跨机即 `bad interpreter`，违反不硬编码设备私有绝对路径基线；(4) conanrun 环境非必然在场（CI L2 裸跑 bin/），wrapper 必须按自身位置自解析 `$PREFIX/lib/<pyX.Y>/site-packages` 设 PYTHONPATH。正确形态与上游 bin/ 免安装 launcher（直接 import 后调 main()）同型。

## 推荐方案
**方法**: self-resolving-sh-wrapper-import-main

**说明**: 按包入口形态选 wrapper（三形态判定树）：(i) 包含 `__main__.py` → `exec python3 -m <pkg> "$@"`（py-cpuinfo 9.0.0）；(ii) 入口为模块 `<pkg>.<mod>` → `exec python3 -m <pkg>.<mod> "$@"`（adb-enhanced 2.8.0 `-m adbe.main`）；(iii) 入口为 `pkg:main` 且包内无 `__main__.py` → `/bin/sh` wrapper 按自身位置自解析 `$PREFIX/lib/<pyX.Y>/site-packages` 设 PYTHONPATH 后 `exec python3 -c 'import <pkg>; <pkg>.main()' "$@"`（与上游 bin/ 免安装 launcher 同型，kernel-hardening-checker 0.6.17.1）。一律不保留 pip console script 原 shebang（内嵌构建机解释器绝对路径）、不依赖 conanrun 环境。

**修复命令**:
```
wrapper 模板：`#!/bin/sh` + `WRAPPER_DIR="$(cd "$(dirname "$0")" && pwd)"` + `PREFIX_DIR="$(cd "$WRAPPER_DIR/.." && pwd)"` + `SITE_PKG="$PREFIX_DIR/lib/<pyX.Y>/site-packages"` + `PYTHONPATH="$SITE_PKG${PYTHONPATH:+:$PYTHONPATH}"` + `exec python3 -c 'import <pkg>; <pkg>.main()' "$@"`；`<pyX.Y>` 由配方 `sys.version_info` 推导；完整实例见 archives/k/kernel-hardening-checker/0.6.17.1/conanfile.py package()
```
