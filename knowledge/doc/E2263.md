# E2263: macOS 本机验证 makefile 系 OHOS 包时，ld64 不认上游 -soname/-Wl,-z,defs，需以 -install_name 替代并置空 PLATFORM_LDFLAGS

## 基本信息
- **严重度**: 1
- **类别**: build-system, make, linking, conan, macos
- **作者**: unknown

## 错误特征
```
ld: unknown option: -soname|unknown argument.*-soname|unrecognized option.*-z defs|ld: unknown option: -z|install_name
```

## 根因分析
>

## 推荐方案
**方法**: macos-link-flag-override

**说明**: 仅在 macOS 本机验证路径上，以 make 命令行变量覆盖上游链接参数：

**修复命令**:
```
make SONAME_FLAG=-install_name PLATFORM_LDFLAGS= MASTER_CC=<cc> MASTER_CXX=<cxx> MASTER_LINKER=<cxx> MASTER_LIB=<ar> -j1
```

**验证**:
```
make MASTER_LINKER=clang++ -j1 2>&1 | grep -E 'unknown option|-soname|-z defs'
```
