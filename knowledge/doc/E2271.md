## 错误特征
```
no member named 'onStep' in 'tweeny::tween<float>'|during() parameters must be of type uint32_t|during() must have one frame count per tween component|static assertion failed.*is_same_v
```

## 根因分析
tweeny v4（tag v4.1.0）相对 v3（tag v3）为破坏性 API 升级：1) 事件接口由成员方法 onStep(cb) 改为 t.on(event::step, cb)，回调签名为 event::response(tween&)，返回 event::response::ok/unsubscribe；2) during() 参数强约束为 uint32_t（int 字面量触发 static_assert 'std::is_same_v<int, unsigned int>'），且多值 tween 的 during() 帧数必须与组件数一一对应（'sizeof...(FrameCountsType) == value_count'）；3) seek()/peek() 帧参数由 float 改为 uint32_t。沿用 v3 API 编写的消费者测试在 v4 下编译失败，错误在 conan create test_package 阶段（G2）暴露。
