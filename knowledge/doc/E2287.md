# E2287: Conan get(destination=...) 不剥离归档根目录（strip_root 不作用于 destination），多源码配方解压到子目录需先 strip_root 解包再 copy

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, filesystem, destination, source
- **作者**: unknown

## 错误特征
```
Error in source\(\) method|fatal error: '.*\.h' file not found|NotADirectoryError.*destination|Uncompressing.*to .*deps.*<repo>-<ver>|get.*destination.*strip_root
```

## 根因分析
Conan tools.files.get() 的 destination 参数只指定解压目标目录，与 strip_root 独立：destination 生效时归档根目录不被剥离，文件落在 destination/<repo>-<ver>/xxx，与 Makefile/include 期望的 destination/xxx 层级不符 → 编译头文件找不到或路径错误。

## 推荐方案
**方法**: strip-root-then-copy-to-deps

**说明**: 依赖 tarball 用 get(..., strip_root=True) 解到 source 根（此时 strip_root 生效），再 copy() 把需要的 .h/.c 放入 deps/<dep>/ 目标子目录；不要用 destination 直接解压。

**修复命令**:
```
get(self, url=info["url"], sha256=info["sha256"], strip_root=True); copy(self, f, self.source_folder, os.path.join(self.source_folder, "deps", dep_dir))
```

**验证**:
```
conan create <recipe> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing && find <build>/source -path '*deps*' -name '*.h'
```
