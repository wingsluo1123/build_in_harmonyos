# E2290: legacy poetry后端缺失时纯Python包免构建直拷打包与wrapper注入PYTHONPATH

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, python, packaging
- **作者**: hmbs-executor
- **来源 PR**: 11149

## 错误特征
```
BackendUnavailable.*poetry\.masonry\.api|Cannot import 'poetry\.masonry\.api'|pip\._vendor\.pyproject_hooks\._impl\.BackendUnavailable
```

## 根因分析
vfit 2.1.0 的 pyproject.toml 声明 legacy 构建后端 poetry.masonry.api，真机仅提供现代 pip 未安装 poetry，即使附加 --no-build-isolation 仍需导入该后端，pip._vendor.pyproject_hooks 抛出 BackendUnavailable 导致 package() 直接失败

## 推荐方案
**方法**: pure-python-copytree-with-wrapper

**说明**: 放弃依赖 poetry.masonry.api 的 pip 构建安装，改为纯Python源码直拷至 site-packages 并自生成 bin/vfit wrapper 动态注入 PYTHONPATH；build() 中运行时依赖安装改为 best-effort 警告模式，保持幂等与重入，可跨同类 legacy poetry 纯Python库复用

**修复命令**:
```
archives/v/vfit/2.1.0/conanfile.py package(): 删除 self.run pip install --prefix，改为 shutil.copytree(os.path.join(self.source_folder,"vfit"), os.path.join(self.package_folder,"lib/pythonX.Y/site-packages/vfit"))；自生成 os.path.join(self.package_folder,"bin/vfit") 写入 #!/usr/bin/env python3 + sys.path.insert + from vfit.app import main；build(): pip install fonttools/tqdm/brotli 用 try/except 包裹失败仅 self.output.warning
```

**验证**:
```
真机 conan create 日志不再出现 BackendUnavailable/poetry.masonry.api；检查 package_folder/lib/pythonX.Y/site-packages/vfit 已通过 shutil.copytree 拷贝且 bin/vfit wrapper 运行时将 ../lib/pythonX.Y/site-packages 插入 sys.path 后 from vfit.app import main 调用成功
```
