# E2297: Exclude static-library symbols (e.g. libdrm.a) from a shared library's dynamic export table so upstream ABI checks pass on OHOS

## 基本信息
- **严重度**: 2
- **类别**: ohos, linking, static-library, abi, symbol-export
- **作者**: unknown

## 错误特征
```
unknown symbol exported: drm|gbm-symbols-check|exclude-libs|libgbm.*symbols
```

## 根因分析
OHOS ohpcd 制品以纯静态形态提供依赖（如 libdrm/2.4.133 仅 libdrm.a）。mesa -Dgbm=enabled 时 libgbm 以 shared_library 链接 dep_libdrm，静态库对象符号（drm*）随链接合并进 libgbm.so 动态导出表，导致上游 gbm-symbols-check（按 gbm-symbols.txt 白名单校验 gbm_* 导出）报大量 "unknown symbol exported: drm*" 失败。

## 推荐方案
**方法**: portability-patch

**说明**: 在共享库目标的 link_args 中加入 -Wl,--exclude-libs,ALL，使链接器把静态库（.a）符号排除出动态导出表，仅保留目标自身源码显式导出的符号；恢复上游 ABI 契约（如 gbm_* 白名单）并使对应 symbols-check/ABI 测试通过。仅需对链接了静态形态依赖的共享库目标生效，不污染系统 PATH 或全局 linker 配置。

**修复命令**:
```
src/gbm/meson.build: link_args : [ld_args_gc_sections, '-Wl,--exclude-libs,ALL']  (meson shared_library 目标)
```
