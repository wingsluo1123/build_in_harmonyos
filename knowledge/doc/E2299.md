## 推荐方案
**方法**: header-only-source-substance-judgement

**说明**: lang-preflight 输出 other/none 且任务语言为 c/cpp 时，不要直接接受工具

**修复命令**:
```
grep -nE "namespace|template|#include <(string|vector|memory)>" <src>/*.h | head;
```

**验证**:
```
python3 scripts/ohc-run.py lang-preflight serializer 0.5 --src <src>；
```
