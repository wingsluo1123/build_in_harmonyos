## 基本信息
- **严重度**: 2
- **类别**: ohos, headers, consumer-test, dual-backend, game-library
- **作者**: unknown

## 错误特征
```
windows\.h.*file not found|
```

## 根因分析
单头文件库可能含多条产品线（如 GameLib.h=Win32 GDI、GameLib.SDL.h=SDL2）。

## 推荐方案
**方法**: dual-backend-product-line-selection + header-only-recipe + sdl2-transitive + static-api-consumer-test

**说明**: (1) 识别库的多产品线头文件（grep -n "windows.h\|SDL" 头文件顶部），确认 OHOS 可用

**修复命令**:
```
conan create archives/g/gamelib/1.9.9 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64
```
