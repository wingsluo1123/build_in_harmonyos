# E2301: 上游测试在 Release(NDEBUG) 下 assert 被编译为空导致 -Werror 报 unused variable：需用 Debug 构建实际运行上游用例

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, testing, upstream-test
- **作者**: unknown

## 错误特征
```
error: unused variable '[a-z0-9_]+' \[-Werror,-Wunused-variable\]|
```

## 根因分析
上游 CMake 测试目标常带 -Wall -Wextra -Wshadow -Werror；Release 构建注入

## 推荐方案
**方法**: debug-build-run-upstream-tests

**说明**: (待补充)

**修复命令**:
```
上游测试用 Debug 构建实际运行（-DCMAKE_BUILD_TYPE=Debug，assert 生效）：
```

**验证**:
```
cmake -DCMAKE_BUILD_TYPE=Debug -D<UPSTREAM_TESTS>=ON && cmake --build . && ctest --output-on-failure
```
