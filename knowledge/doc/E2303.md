# E2303: profile compiler_executables 指向的编译器路径在本机不存在，配方须回退 PATH 解析

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, toolchain, conan
- **作者**: AtomCode

## 错误特征
```
make: /data/service/hnp/bin/clang: No such file or directory|make\[.*\]: .*clang: No such file or directory|make.*Error 127
```

## 根因分析
ci/conan/profiles/ohos-aarch64 的 tools.build:compiler_executables 硬编码

## 推荐方案
**方法**: isfile-check-plus-path-fallback

**说明**: 读取 conf 后校验路径存在性：os.path.isfile(cc) 不成立时用

**修复命令**:
```
cc = compilers.get("c", "clang")
```

**验证**:
```
ls /data/service/hnp/bin/clang 2>/dev/null || echo "profile CC path absent on this machine"; which clang
```
