# E2310: 交互型被测程序（cdebconf/debconf 状态机等）在 test() 里直接运行时，CI buildbot

## 基本信息
- **严重度**: 1
- **类别**: environment-dependent, hang, stdin, test-harness
- **作者**: (choose-mirror)
- **来源 PR**: 9740

## 错误特征
```
command timed out: 14400 seconds without output|program finished
```

## 根因分析
测试结论依赖父进程 stdin 的偶然状态：本地 OHOS shell stdin 已关闭 EOF →

## 推荐方案
**方法**: child-stdin-devnull-plus-sigalrm-bounded-wait

**说明**: 子进程 /dev/null 强制 EOF + 父进程 SIGALRM 有界等待双重防护：

**修复命令**:
```
harness 子进程分支 open("/dev/null")+dup2(z,0)+execl；等待侧
```

**验证**:
```
sleep infinity | conan test <profile> <pkg> test_package/  # 复现 CI：修复前挂死，修复后立即出结果
```
