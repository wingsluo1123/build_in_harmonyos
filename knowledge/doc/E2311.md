# E2311: conan build() 用 self.run 传 -DXXX='"C字符串"' 宏时，内层双引号被 /bin/sh 吃掉变裸标识符（use of undeclared identifier），或反斜杠转义 \\\" 经 conan 命令包装变成 \" 原样进编译器（missing terminating '"'）

## 基本信息
- **严重度**: 2
- **类别**: build-system, conan, shell, quoting
- **作者**: (choose-mirror)
- **来源 PR**: (本 PR)

## 错误特征
```
use of undeclared identifier '\w+'|expanded from here.*-D\w+ \w+|missing terminating '"'.*character.*-Winvalid-pp-token
```

## 根因分析
conan 的 ConanFile.run(shell=True) 经 /bin/sh -c 执行，命令字符串先被

## 推荐方案
**方法**: single-quote-shell-wrap-cstring-macro

**说明**: 在 conan self.run 的编译命令里，把含 C 字符串字面量的 -D 宏值用单引号壳

**修复命令**:
```
在 conanfile build() 编译行把 -DARCH_TEXT="aarch64"（裸）或 -DARCH_TEXT=\\\"aarch64\\\"
```

**验证**:
```
grep -nE "use of undeclared identifier|missing terminating" <conan-create.log>  # >0 且上下文是 -D 宏展开即命中
```
