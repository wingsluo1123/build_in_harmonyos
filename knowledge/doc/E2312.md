# E2312: OHOS 无 libatomic（原子操作内置于编译器运行时）时，meson 构建需按平台条件跳过 cc.find_library('atomic')

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, libc, meson, conan
- **作者**: unknown

## 错误特征
```
ERROR: C shared or static library 'atomic' not found|libatomic dependency is missing|find_library\('atomic'\)
```

## 根因分析
OHOS sysroot（musl）不提供 libatomic.a/libatomic.so，aarch64 原子操作由 clang

## 推荐方案
**方法**: meson-condition-branch-skip-find-library

**说明**: 在 meson 条件分支中把 host_machine.system() != 'harmonyos' 加入守卫，

**修复命令**:
```
|
```

**验证**:
```
meson setup builddir && ninja -C builddir
```
