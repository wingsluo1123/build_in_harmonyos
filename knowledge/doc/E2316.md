```
tests:.*[1-9][0-9]* \| [1-9][0-9]* failed|asserts:.*failed|libc\+\+abi: terminating|cfg<.*override|fake_cfg
```

## 推荐方案
**方法**: test-framework-self-test-semantics

**说明**: (1) 运行测试框架库自测二进制时，以退出码与 ctest 判定为唯一通过依据；

**修复命令**:
```
cmake -S . -B build-ctest -DBOOST_UT_BUILD_TESTS=ON -DBOOST_UT_ENABLE_RUN_AFTER_BUILD=NO && cmake --build build-ctest && ctest --test-dir build-ctest --output-on-failure
```

**验证**:
```
./test/ut/ut_test; echo $?   # 期望 0；ctest 期望 100% passed
```
