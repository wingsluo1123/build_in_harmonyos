# E2318: Conan os=OHOS 映射出 CMAKE_SYSTEM_NAME=HarmonyOS 而 CMake 无该 Platform 模块，SONAME 标志不定义，共享库须显式注入 -Wl,-soname 并关闭版本化软链，测试期须显式注入 LD_LIBRARY_PATH

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, toolchain, linking, shared-library
- **作者**: GoliWie

## 错误特征
```
System is unknown to cmake|create: Platform/HarmonyOS|DT_SONAME|IMPORTED_NO_SONAME|Error loading shared library|symbol not found
```

## 根因分析
OHOS 适配版 conan 的 CMakeToolchain 将 os=OHOS 映射为 CMAKE_SYSTEM_NAME=HarmonyOS（ci/conan/profiles/ohos-aarch64 自身注释文档化），而设备 CMake 4.1.2 只有 Platform/OHOS.cmake（内容仅 include(Platform/Linux)）、无 Platform/HarmonyOS.cmake，configure 逐字报 "System is unknown to cmake, create: Platform/HarmonyOS" → Platform/Linux.cmake 不加载，其中定义的 CMAKE_SHARED_LIBRARY_SONAME_{C,CXX}_FLAG 与 rpath 规则全部缺位：① 产物 ELF 无 DT_SONAME，CMake 导出 target 带 IMPORTED_NO_SONAME，下游链接器把 Conan 包缓存绝对路径写进 DT_NEEDED（不可重定位，缓存清理/revision 变更/换机即断，CI SONAME 门禁拦截）；② 链接行无 -rpath/-rpath-link，且 conanbuild 聚合 env 不下传 ctest，构建树测试可执行运行期加载不到本包与依赖 .so（E135 动态链接器错误族）。

## 推荐方案
**方法**: explicit-soname-flag-no-versioned-symlink-plus-runtime-ld-library-path

**说明**: ① SONAME 主案（构建语义层）：recipe CMakeToolchain 显式设 CMAKE_PLATFORM_NO_VERSIONED_SONAME=ON（同时规避 HMDFS 路径版本化软链受限）并保留 CMAKE_SHARED_LIBRARY_SONAME_{C,CXX}_FLAG="-Wl,-soname,"，产物为带可重定位 ELF SONAME 的非版本化 lib<name>.so，导出 target 不再 IMPORTED_NO_SONAME，下游 DT_NEEDED 记 SONAME 而非包缓存绝对路径。② 运行期闭包主案（测试阶段）：recipe build() 内用 Environment() 显式 prepend LD_LIBRARY_PATH（构建树 lib 输出目录 + 依赖包 lib 目录）后再跑 ctest，不依赖 lld/加载器隐式解析、设备默认搜索路径或 conan 聚合 env 隐式下传；不要把 rpath 烧进安装产物（安装期 ELF 修改需按 E077 重签名）。机理在工具实现层（conan 系统名映射 × CMake 平台模块表不匹配），与具体库无关；第二次独立命中（首次 expat #1912，本条为 kcolorpicker 消费路线，非 Qt platform patch 路线）。

**修复命令**:
```
tc.cache_variables["CMAKE_PLATFORM_NO_VERSIONED_SONAME"]="ON"; tc.cache_variables["CMAKE_SHARED_LIBRARY_SONAME_C_FLAG"]="-Wl,-soname,"; tc.cache_variables["CMAKE_SHARED_LIBRARY_SONAME_CXX_FLAG"]="-Wl,-soname,"; test_env.prepend_path("LD_LIBRARY_PATH", "<build_tree>/lib"); test_env.prepend_path("LD_LIBRARY_PATH", "<qtbase_package>/lib"); 复验: llvm-objdump -p <package>/lib/lib<name>.so | grep SONAME
```

**验证**:
```
ls /data/service/hnp/cmake.org/cmake_4.1.2/share/cmake-4.1/Modules/Platform | grep -i harmonyos（空=模块缺失）；grep -n HarmonyOS /storage/Users/currentUser/build_in_harmonyos/ci/conan/profiles/ohos-aarch64（conan 映射证据）；最小共享库探针两遍：不带修复标志构建 → llvm-objdump -p libfoo.so | grep -c SONAME 得 0，带 CMAKE_PLATFORM_NO_VERSIONED_SONAME=ON + CMAKE_SHARED_LIBRARY_SONAME_{C,CXX}_FLAG=-Wl,-soname, → 得 1；llvm-objdump -p libX.so | grep DT_NEEDED（确认无包缓存绝对路径）；ctest 阶段以显式 LD_LIBRARY_PATH 运行测试可执行确认 .so 加载
```
