# E2319: OHOS qtbase 的 Qt6DBus 运行时 dlopen libdbus-1 共享库而制品生态仅静态库，应为 dlopen 消费方提供（vendored）共享 libdbus-1

## 基本信息
- **严重度**: 2
- **类别**: dependency, dbus, qt6, runtime-loading
- **作者**: unknown

## 错误特征
```
DBus session bus not found|Cannot find libdbus-1 in your system|Cannot resolve .* in your libdbus-1
```

|

## 推荐方案
**方法**: vendored-shared-libdbus-for-dlopen-consumer

**说明**: dlopen 消费方场景下，为消费链提供共享 libdbus-1：消费方 recipe 内以官方 dbus 源码（URL+SHA256 固定）构建客户端共享库（BUILD_SHARED_LIBS=ON、仅 dbus-1 target、CMAKE_SYSTEM_NAME=OHOS 走 UNIX 分支），随包发布至 lib/ 并入 LD_LIBRARY_PATH；等制品仓发布 shared dbus 包后改用制品。kglobalacceld-6.7.2 实证（ci10 起 3/3 PASS、test_ohos_daemon 7 断言全过）。

**修复命令**:
```
conan create archives/k/kglobalacceld/6.7.2 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
