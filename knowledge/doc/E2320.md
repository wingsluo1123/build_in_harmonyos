# E2320: Release -DNDEBUG吞掉assert副作用致autotools代码生成器签名漂移的外移修复

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, libc, musl, build-system
- **作者**: hmbs-executor
- **来源 PR**: 11288

## 错误特征
```
conflicting types for .*_marshal|duplicate symbol[: ]+output_package|redefinition of 'sockaddr_storage'
```

## 根因分析
Release默认-DNDEBUG把assert编译为空而上游把type_to_const与nih_strdup等副作用写在assert内导致生成点c签名与签入头const不一致

## 推荐方案
**方法**: assert-side-effect-hoist

**说明**: 将生成器assert内副作用移出无条件执行后仅用assert校验结果并同步修正indent指针类型与-fcommon与socket守卫与install-sh绕行

**修复命令**:
```
archives/l/libnih/1.0.3/conanfile.py新增_fix_factory_ndebug改nih-dbus-tool生成器共4处加generate加tc.extra_cflags加-fcommon加source直改nih/tests/test_io.c加_patch_install_sh遍历Makefile改INSTALL为install-sh
```

**验证**:
```
真机保留make check编译报错与HMBS_UPSTREAM_TEST_RESULT实计数41项全编出后按PASS与FAIL如实上报
```
