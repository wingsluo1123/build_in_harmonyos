# E2324: 上游 bundled FindSodium.cmake 用非数值 EQUAL 看门狗在每次 configure 时 unset 全部 sodium_* CACHE 变量，-Dsodium_LIBRARY_RELEASE 等命令行预置被静默删除，find_library 回落默认搜索路径找不到 conan 依赖

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan, dependency, cache
- **作者**: gcw_6YxinkyD <m13307644603@163.com>
- **来源 PR**: (本 PR)

## 错误特征
```
Could NOT find Sodium|sodium_LIBRARY_RELEASE-NOTFOUND|CMake Error.*Sodium REQUIRED
```

## 根因分析
libxeddsa 自带的 FindSodium.cmake（很多上游 vendor 的 Find 模块同款写法）

## 推荐方案
**方法**: feed-cmake-include-library-path

**说明**: 不与看门狗对抗：把 conan 依赖包目录喂给 find_path/find_library 的

**修复命令**:
```
tc.variables["CMAKE_INCLUDE_PATH"] = <dep>/include；
```

**验证**:
```
在 CMakeLists 的 find_package 前后 message 打印
```
