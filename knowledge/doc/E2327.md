# E2327: Makefile 通过 -D b64_malloc=custom_malloc 做标识符替换时，

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, make, clang, runtime
- **作者**: unknown

## 错误特征
```
call to undeclared function 'custom_malloc'|
```

## 根因分析
clib 风格项目（如 b64.c）支持自定义分配器：Makefile 用

## 推荐方案
**方法**: sync-extern-guard-with-substituted-macro

**说明**: 把 .c 里的 extern 声明守卫从独立的 #ifdef b64_USE_CUSTOM_MALLOC

**修复命令**:
```
grep -n "defined(b64_malloc)" archives/b/b64.c/0.1.0/patches/0001-buffer.c.patch
```

**验证**:
```
make test USE_CUSTOM_MALLOC=true && ./test   (b64.c 0.1.0, clang 15)
```
