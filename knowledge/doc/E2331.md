# E2331: 上游 gyp 构建生成器是 Python 2 时代代码（print 语句），OHOS 环境仅 Python 3 时

## 基本信息
- **严重度**: 2
- **类别**: build-system, legacy-tooling
- **作者**: unknown

## 错误特征
```
env: exec python: No such file or directory|
```

## 根因分析
deps/run_gyp shebang 为 `#!/usr/bin/env python`（环境只有 python3，报

## 推荐方案
**方法**: gyp-equivalent-compile-flags

**说明**: 不移植/不修复 gyp（其 Python 2 语法面太广，修复收益低），改为按

**修复命令**:
```
clang++ -std=c++11 -Wall -Wextra -Wshadow -fno-rtti -fexceptions -g -O0 \
```

**验证**:
```
clang++ -std=c++11 -Wall -Wextra -Wshadow -fno-rtti -fexceptions -g -O0 \
```
