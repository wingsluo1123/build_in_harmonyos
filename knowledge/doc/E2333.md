# E2333: lang_detect 的语言枚举与扩展名表都没有 ada/.adb/.ads，Ada 项目被按少量 C 胶水文件误判为 c 并放行（R47 语言门静默失效）

## 基本信息
- **严重度**: 3
- **类别**: ada, gnats, language, preflight, tooling
- **作者**: ohpcd

## 错误特征
```
lang-preflight.*语言匹配.*task=c.*detected=c|detected_language.*c.*source_stats.*c:4|
```

## 根因分析
scripts/ohc/lang_detect.py:40 的 LANG_ENUM 只有 c/cpp/rust/python/go/perl/lua/nodejs/java/bash/mixed/other，

## 推荐方案
**方法**: verify-detected-language-against-source-extension-census

**说明**: 把 lang-preflight 的结论与"源文件扩展名普查"交叉验证；未被枚举覆盖的语言（Ada/D/Nim/Zig 等）

**修复命令**:
```
语言门不能只看 detected_language 是否落在 _COMPAT_FAMILY；对返回 build_system=none 或 source_stats 主体极小的项目，
```

**验证**:
```
python3 scripts/ohc-run.py lang-preflight libncursesada 6.3.20211021 --src <src>；
```
