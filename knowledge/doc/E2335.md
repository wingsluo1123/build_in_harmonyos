# E2335: Ada/GNAT 在 ohpcd 只有 OHOS/armv8 制品（gcc-ada、binutils、gcc 同）；交叉构建必然在依赖解析或链接阶段失败，应尽早 validate 拒绝并改用原生两 profile

## 基本信息
- **严重度**: 3
- **类别**: ohos, toolchain, cross-compile, dependency, ada
- **作者**: ohpcd

## 错误特征
```
gcc-ada.*native OHOS build only|The OHOS GCC Ada package supports AArch64|
```

## 根因分析
制品的 settings 就把语言钉死在目标平台上（用 R35 允许的方式取证：

## 推荐方案
**方法**: reject-cross-early-and-build-with-native-two-profiles

**说明**: 把"工具链只有 OHOS 原生制品"当成一等约束处理：先看清 settings，再尽早 validate 拒绝交叉，

**修复命令**:
```
①在 build_requirements() 里 tool_requires("gcc-ada/<ver>") 与 tool_requires("binutils/<ver>")；
```

**验证**:
```
conan download "gcc-ada/9.5.0" -r=ohpcd（R35：判断远端 binary 存在性禁止用 conan list/conan search，必须用 download）；
```
