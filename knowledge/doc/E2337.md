# E2337: 显式设置 cpp_info.requires 后，Conan 2 要求每个"可见且非 override"直接依赖都必须列入，否则 package_info() 抛异常

## 基本信息
- **严重度**: 2
- **类别**: configure, conan, dependency, packaging
- **作者**: unknown

## 错误特征
```
package_info\(\): The direct dependency '[^']+' is not used by any '\(cpp_info/components\)\.requires'|The direct dependency .* is not used by any
```

## 根因分析
Conan 2 在 `cpp_info.check_component_requires()` 里做一致性校验：一旦配方**显式**

## 推荐方案
**方法**: list-all-visible-non-override-direct-deps

**说明**: 把每个"可见且非 override"的直接依赖都列进 cpp_info.requires；组件名先核验依赖包
