## 基本信息
- **严重度**: 2
- **类别**: cmake, linking, conan, pkg-config, nls
- **作者**: OHC-Agent

## 错误特征
```
undefined reference due to --no-allow-shlib-undefined: g_libintl_ngettext|
```

## 根因分析
glib 配方 package_info 导出的 glib-2.0.pc（PkgConfigDeps

## 推荐方案
**方法**: exe-linker-flags-lintl

**说明**: generate() 里给 CMAKE_EXE_LINKER_FLAGS 追加 -lintl

**修复命令**:
```
见 conanfile.py generate()（主包 EXE flags）+ test_package
```

**验证**:
```
nm -D <glib_pkg>/lib/libintl.so | grep g_libintl_ngettext
```
