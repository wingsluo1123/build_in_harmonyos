# E2369: Conan 2 配方 package() 中 conan.tools.files.copy 不接受 keep_perm 参数——直接 copy 即可（源文件权限自动保留）

## 基本信息
- **严重度**: 2
- **类别**: build-system, conan, packaging
- **作者**: pc2-20

## 错误特征
```
"copy\\(\\) got an unexpected keyword argument 'keep_perm'|TypeError: copy\\(\\) got an unexpected keyword argument"
```

## 根因分析
>

## 推荐方案
**方法**: remove-keep-perm-copy

**说明**: 删除 copy() 的 keep_perm=True 参数，直接 copy(self, pattern, src, dst)；Conan 2 拷贝自动保留源文件权限位（可执行位/模式）。

**修复命令**:
```
copy(self, "exifprobe", self.source_folder, os.path.join(self.package_folder, "bin"))
```
