## 推荐方案
**方法**: sim-hal-with-fixed-low-address-mmap

**说明**: ① 新增 main.h 模拟 STM32 HAL：定义 __IO、HAL_StatusTypeDef/HAL_OK、

**修复命令**:
```
mmap((void*)0x20000000UL, 16384, PROT_READ|PROT_WRITE, MAP_PRIVATE|MAP_ANONYMOUS, -1, 0)
```

**验证**:
```
clang -O2 -std=c11 -I<prefix>/include smoke_test.c -L<prefix>/lib -lee -o smoke_test && ./smoke_test
```
