# E2377: "上游消费者形态测试直编源码并 -l<dep> 链接系统库，Conan 环境下报 fatal error（dep 头文件不存在）或 cannot find -l<dep>（注入 CPATH/LIBRARY_PATH 修复）"

## 基本信息
- **严重度**: 2
- **类别**: build-system, dependency, test-framework
- **作者**: Awstme
- **来源 PR**: (本 PR)

## 错误特征
```
fatal error:\s+\S+\.(h|hh)\s+No such file or directory|cannot find\s+-l\S+
```

## 根因分析
Conan 依赖的头文件与库文件位于 conan cache 的 package_folder，不进入

## 推荐方案
**方法**: env-inject-cpath-library-path

**说明**: 在配方 build() 调用该 make 前注入 CPATH/LIBRARY_PATH（冒号分隔

**修复命令**:
```
env CPATH="$(pkg-config --cflags-only-I json-c | tr -d -I)" LIBRARY_PATH="$(pkg-config --libs-only-L json-c | sed s/-L//g)" make -C test6 test
```

**验证**:
```
env CPATH=<dep-include> LIBRARY_PATH=<dep-lib> make -C test6 test  # 注入后 rc=0 即修复
```
