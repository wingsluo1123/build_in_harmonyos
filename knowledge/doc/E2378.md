# E2378: 上游 meson test 条目不带数据参数时测试可执行文件空跑返回 0（mustach specs 套件形态：CI 日志显示 PASS 但 spec 用例一个都没跑）

## 基本信息
- **严重度**: 2
- **类别**: build-system, false-green, test-framework
- **作者**: Awstme
- **来源 PR**: (本 PR)

## 错误特征
```
summary:\s+error\s+0\s+differ\s+0\s+success\s+0
```

## 根因分析
meson test() 只注册"可执行文件 + 环境"，不校验该可执行文件在给定

## 推荐方案
**方法**: audit-test-entry-args-and-main

**说明**: 逐条核对 meson test() 注册的 args 与被注册 main() 对空参数表的

**修复命令**:
```
meson test -C <build_dir> -v 2>&1 | grep -B2 "success   0$"  # 列出全部空跑条目
```

**验证**:
```
meson test -C <build_dir> -v "specs cjson" 2>&1 | tail -6  # summary 全 0 即空跑
```
