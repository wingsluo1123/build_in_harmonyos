# E2379: 上游 C++ 库测试套件大量 skip（C++17/20 头/特性"not available"）的根因常是测试模块按编译器

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, cmake, toolchain, c++
- **作者**: pc1-3

## 错误特征
```
SKIPPED.*no <ranges>|SKIPPED.*no <optional>|SKIPPED.*no <string_view>|
```

## 根因分析
测试模块编译时未显式设置 -std（flags.make 无 CXX_STANDARD），clang 15 默认按 gnu++14

## 推荐方案
**方法**: test-build-standard-escalation

**说明**: 遇到上游测试大量 "no <头文件>/feature not available" skip 时，先检查测试模块编译

**修复命令**:
```
cmake -S <src> -B <build> -DPYBIND11_TEST=ON -DCMAKE_CXX_STANDARD=20 -DCMAKE_CXX_STANDARD_REQUIRED=ON
```

**验证**:
```
grep CXX_FLAGS <build>/CMakeFiles/<tgt>.dir/flags.make（无 -std 即默认标准）；
```
