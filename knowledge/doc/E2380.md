# E2380: OHOS musl 下 O_CREAT/O_RDWR 报 use of undeclared identifier：上游缺 <fcntl.h>（glibc 从 <sys/file.h> 传递引入，musl 不传递），补一行 #include <fcntl.h> 即修复

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, musl, headers, build-system
- **作者**: 1F22

## 错误特征
```
"error: use of undeclared identifier 'O_CREAT'|error: use of undeclared identifier 'O_RDWR'|error: use of undeclared identifier 'O_RDONLY'|error: use of undeclared identifier 'O_WRONLY'|error: use of undeclared identifier 'O_TRUNC'"
```

|

## 推荐方案
**方法**: add-fcntl-include

**说明**: 在使用 open 标志的源文件补一行 #include <fcntl.h>（纯可移植性修复，无需平台宏，对上游是明确的改进）

**修复命令**:
```
"在 <file>.c 的 #include <sys/file.h> 后补一行：#include <fcntl.h>"
```

**验证**:
```
"grep -n 'O_CREAT' <src> && grep -n '#include <fcntl.h>' <src> # 有 O_CREAT 用法且无 fcntl.h 包含 → 必然踩坑"
```
