# E2381: Makefile 用 $(wildcard *.c) 取源文件的库在 conan out-of-source 构建下 json.o 缺失，需配方侧强制源内构建（folders.build = "."）

## 基本信息
- **严重度**: 3
- **类别**: build-system, autotools, make, conan
- **作者**: unknown

## 错误特征
```
llvm-ar: error: .*\.o: No such file or directory|ar: .*\.o: No such file|.*\.o: No such file or directory
```

## 根因分析
Makefile.in 用 $(wildcard *.c) 在 make 当前工作目录展开取源；Conan 默认 out-of-source 构建（build-release/ 子目录）使 make 运行目录无 .c 文件，SRCS/OBJS 为空，归档规则中的字面量 .o 从未编译，llvm-ar/ar 报缺文件

## 推荐方案
**方法**: recipe layout() 中设置 self.folders.build = "."（源内构建），使 wildcard 在 source 目录展开；与 abc/abduco 等既有配方一致

