# E2382: 包内同时含 .a/.so 时 CMakeDeps find_library 误选 .so 导致消费者运行期 symbol not found，需按 shared 选项只保留一种库形态

## 基本信息
- **严重度**: 3
- **类别**: cmake, conan, packaging, runtime, link
- **作者**: unknown

## 错误特征
```
Error loading shared library lib.*\.so\.[0-9]+|Error relocating .*: .*: symbol not found|error while loading shared libraries.*lib.*\.so
```

## 根因分析
构建系统无条件同时产出/安装 .a 与 .so（含 soname）；CMakeDeps 的 find_library 在包 lib 目录 .a/.so 并存时按查找顺序选中 .so，二进制 NEEDED 变成 .so.1.0，运行期 conanrun 环境加载到旧/坏 .so.1.0，符号重定位失败（symbol not found），即使配方默认 shared=False 且 LIBRARY_TYPE 标 STATIC

## 推荐方案
**方法**: package() 中按 self.options.shared 只保留一种库形态（默认 shared=False 仅留 .a），并先 conan remove 清理该库陈旧本地包缓存
