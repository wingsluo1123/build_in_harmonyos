# E2397: HarmonyOS 下 AT&T AST bin/package 构建系统适配：HMDFS 禁止 mkfifo 与符号链接

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, build-system
- **作者**: Rain-Chime

## 错误特征
```
mkfifo: .*make\.out\.fifo.*Operation not permitted|ConanException: Error 1 while executing|ln: cannot create symbolic link.*Permission denied|mamake \[lib/libast\]: .*exit code 1|panic: process substitution: FIFO creation failed
```

## 根因分析
AT&T AST 自带构建系统 bin/package 基于 Mamfile，不使用 Meson/CMake/Autotools。默认模式下 bin/package make 会调用 mkfifo 创建 make.out.fifo 用于 tee 输出捕获；链接动态库后会调用 ln -s 创建 libast.so.6、libast.so 等版本化符号链接。HarmonyOS 的 HMDFS 禁止用户进程创建 FIFO，HarmonyOS 安全策略禁止第三方应用调用 symlink(2)，mkfifo(2) 返回 EPERM (Operation not permitted)，symlink(2) 返回 EACCES (Permission denied)，导致构建在链接阶段失败。同时 ksh93 的进程替换 <() / >() 也依赖 FIFO，在运行时测试中同样失败。
