# E2399: "五步配方骨架（一次掌握、全族复用）：① 设 CMAKE_POLICY_VERSION_MINIMUM=3.5；② 从 

## 基本信息
- **严重度**: P1
- **类别**: build-system
- **作者**: unknown

## 错误特征
```
"The imported target \"bpp-(core|seq|phyl|raa|seq-omics)-(shared|static)\" references the file .* but this file does not exist|cmake_minimum_required \(VERSION 2\.8\.11\)|is incompatible with aarch64linux|Error loading shared library \\.\\./src/libbpp"
```

## 根因分析
"Bio++ 家族(libbpp-core/seq/phyl/raa/seq-omics 等)共享同一套 CMake 骨架，在 OHOS/Conan 交叉编译下集中触发四类问题：(1) 顶层 cmake_minimum_required(VERSION 2.8.11) 被新版 CMake 策略拒绝；(2) 上游直接 set(CMAKE_CXX_FLAGS) 覆盖 Conan 注入的 --target/--sysroot，静默产出宿主架构；(3) 依赖包按 shared=False 裁剪了 .so 却保留指向它们的 CMake 导出，下游 find_package 报 imported target 文件缺失；(4) 构建树 shared 库的 DT_NEEDED 为斜杠相对路径，OHOS/musl 加载器按字面解析，测试进程起不来。"

## 推荐方案
**方法**: "五步配方骨架（一次掌握、全族复用）：① 设 CMAKE_POLICY_VERSION_MINIMUM=3.5；② 从 tools.build:cxxflags 解析 --target/--sysroot 改注入 CMAKE_<LANG>_COMPILER_TARGET/CMAKE_SYSROOT（E543）；③ generate() 里把依赖包复制到构建目录、剔除导出文件里的 shared imported target 并重定向 BPP_LIBS_SHARED 到 static（不改依赖缓存）；④ testing 补丁让测试可执行文件改链静态归档；⑤ find_package 名与 CMakeDeps 产物不匹配时显式注入 bpp-*_DIR。"
