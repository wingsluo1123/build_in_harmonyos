# E2409: shadow CI 隔离 job 的 conan-home 缺 ohpcd remote 时，依赖解析回落 conancenter 源码构建失败

## 基本信息
- **严重度**: 2
- **类别**: conan, dependency-resolution, remote, shadow-ci
- **作者**: codex

## 错误特征
```
cmake: inaccessible or not found|Error in build\(\).*cmake\.configure|Error 127 while executing|Not found in local cache, looking in remotes|Checking remote: conancenter
```

## 根因分析
ohos-prepare-isolated-conan-job.sh 从已有 job 复制 repo 时，新 job 的 conan-home/remotes.json 可能只含默认 conancenter（无 ohpcd）。conan create 解析 self.requires() 依赖时只查 conancenter，命中其同名配方（如 zlib/1.3.1 用 CMake 构建），真机无 cmake，依赖从源码构建失败。全局 conan 配了 ohpcd 也不生效——隔离 job 用独立 CONAN_HOME，不继承全局 remote。

## 推荐方案
**方法**: add-ohpcd-remote-to-job-conanhome

**说明**: 创建隔离 job 后、跑 runner 前，给 job 的 conan-home 添加 ohpcd remote 并禁用 conancenter，使依赖解析命中 ohpcd 预编译包（R36 依赖先发布）。

**修复命令**:
```
export CONAN_HOME="$JOB/conan-home"; conan remote add ohpcd https://conan.cnb.cool/OpenHarmonyPCDeveloper/Conan/-/packages/; conan remote disable conancenter
```

**验证**:
```
grep -c ohpcd "$JOB/conan-home/remotes.json"    # 期望 >=1；为 0 即触发此问题
```
