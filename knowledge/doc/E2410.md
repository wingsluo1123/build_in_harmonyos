# E2410: Conan test_package 的 test() 在 OHOS 需用绝对路径 bash（run 环境 PATH 无 bash）

## 基本信息
- **严重度**: 2
- **类别**: ohos, packaging, runtime, testing, shell-path
- **作者**: codex

## 错误特征
```
/system/bin/sh: bash: inaccessible or not found|Error in test\(\) method|Error 127 while executing
```

## 根因分析
OHOS profile 的 [buildenv] 里 CONFIG_SHELL 与 PATH（含 /data/service/hnp/bin）只在 conan 的 build 阶段生效；test_package 的 test() 用 env="conanrun" 时，run 环境 PATH 只含 VirtualRunEnv 注入的 package bindirs，不含 /data/service/hnp/bin，故 self.run('bash ...') 找不到 bash（/system/bin/sh: bash: inaccessible or not found，Error 127）。

## 推荐方案
**方法**: ohos-absolute-bash-path

**说明**: test() 中按 settings.os 选择 shell：OHOS 用 /data/service/hnp/bin/bash，其它平台用 bash；优先 CONFIG_SHELL 环境变量；显式声明 generators = "VirtualRunEnv" 确保 conanrun 生成。

**修复命令**:
```
shell = "/data/service/hnp/bin/bash" if str(self.settings.os) == "OHOS" else "bash"; shell = os.environ.get("CONFIG_SHELL", shell); self.run(f'{shell} "{script}"', env="conanrun")
```

**验证**:
```
grep -n "bash" test_package/conanfile.py
```
