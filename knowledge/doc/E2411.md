# E2411: 无 vendor/ 的 Go 模块在 conan/OHOS CI 构建必须显式拉取模块闭包（GOPROXY+-mod=mod），否则 import 解析硬失败

## 基本信息
- **严重度**: 3
- **类别**: network, build-system, go, dependency
- **作者**: GoliWie

## 错误特征
```
module lookup disabled by GOPROXY=off|
```

## 根因分析
Go 1.16+ 默认 -mod=readonly 且编译需要完整模块图;

## 推荐方案
**方法**: fetch-module-closure-goproxy

**说明**: conan 配方 build() 内先显式拉取模块闭包再构建:

**修复命令**:
```
conanfile.py build():
```
