# E2415: "三步判读序：①clang -static hello 探针取证工具链能力；②逐依赖 ls package_folder

## 基本信息
- **严重度**: P3
- **类别**: linking
- **作者**: unknown

## 错误特征
```
"cannot find -l(curl|nettle|json-c|uv)|No such file or directory.*lib(curl|nettle|json-c|uv)\\.a|undefined reference to `curl_|skipping incompatible"
```

## 根因分析
"上游 Makefile.am 硬编码 -static 整体静态链接时，失败面通常不在 OHOS 工具链（llvm 15.0.4/ohos-sdk 26.0.0.18 实测 clang -static 可产出可运行的 ELF EXEC，静态 musl + libclang_rt 齐备），而在 conan 依赖制品是否带 .a——ohpcd 远程 libcurl/8.5.0 的 p/lib 只有 .so，静态模式 -lcurl 必失败；各依赖归档形态不一（nettle/libmicrohttpd 仅 .a，libuv/json-c 双形态）。"

## 推荐方案
**方法**: "三步判读序：①clang -static hello 探针取证工具链能力；②逐依赖 ls package_folder/lib/*.a 查归档；③任一依赖只有 .so 时只删上游 -static（补丁），库本体仍 R26 静态优先，不为凑 -static 改依赖 shared 选项触发闭包源码重编。"
