# E2416: "不改源码：驱动 make check 时同时注入 TMPDIR（测试程序读它定位上传源文件目录）与 STORJ_TEM

## 基本信息
- **严重度**: P2
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"File encryption error|Can't create file for encrypted data \\[/tmp/|STORJ_FILE_ENCRYPTION_ERROR|Failed to encrypt data"
```

## 根因分析
"上游库内部临时目录选择链里 TMPDIR 分支是死代码（env->tmp_path 刚置 NULL 又判自己），环境覆盖只认 STORJ_TEMP，否则兜底到字面量 /tmp；OHOS 设备 /tmp 存在但只读（HMDFS），fopen(\"w+\") 创建加密临时文件必失败，上传状态机重试 6 次后以语义错误码 File encryption error 收场，与文件系统毫无关联词。"

## 推荐方案
**方法**: "不改源码：驱动 make check 时同时注入 TMPDIR（测试程序读它定位上传源文件目录）与 STORJ_TEMP（库读它定位 .crypt/.parity 临时目录），两者指向同一可写目录；判读时先用日志全开重链测试二进制（log_options.level 0→4）拿库内部日志，再按真实失败点处置。"
