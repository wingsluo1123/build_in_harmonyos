# E2417: 为绕过老 config.guess 而把 --build 写成 gnu、--host 写成 ohos，会让 autoconf 判 cross_compiling=yes，包内 AC_TRY_RUN 运行探测随即硬失败；本机即目标机时应让 build 与 host 一致

## 基本信息
- **严重度**: 2
- **类别**: autotools, cross-compile, autoconf-probe, triplet
- **作者**: QC-10

## 错误特征
```
"configure: error: cannot run test program while cross compiling（前一行是包自身的运行型探测，如 checking for BPF device sending support...）"
```

## 根因分析
autoconf 的 cross_compiling 判定只看 build 三元组与 host 三元组是否相同，与"实际能否执行"

## 推荐方案
**方法**: align-build-triplet-with-host-on-ohos-native-target

**说明**: generate() 内两个三元组都写 OHOS（`--build=aarch64-unknown-linux-ohos` 与

**修复命令**:
```
配方 generate()：`tc.configure_args.append("--build=aarch64-unknown-linux-ohos")`
```

**验证**:
```
改前（build=gnu）日志出现 `checking whether we are cross compiling... yes` 之外的
```
