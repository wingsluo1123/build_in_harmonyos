# E2419: OHOS 真机 /dev/hidraw* 节点存在（内核 hidraw 已绑定设备）但用户态 open(O_RDWR)=EACCES，且上游靠 udev 规则放权而 OHOS 无 udev——HID 数据面包在鸿蒙的确定性收口签名（枚举恒 0、无崩溃、不谎报功能可验证）

## 基本信息
- **严重度**: 2
- **类别**: compat, limitation, ohos, kernel, posix
- **作者**: hw-4 <hw-4@local>

## 错误特征
```
/dev/hidraw\d+ open=-1 errno=13\(Permission denied\)|cannot open hidraw|unable to open HID device: Permission denied
```

## 根因分析
三层事实叠加（逐层实测、勿跳层归因）：OHOS 内核 hidraw 已启用且节点真实存在，但用户态 open(O_RDWR) 被拒 EACCES，且上游放权依赖的 udev 机制在 OHOS 整体不存在。
