# E2421: OHOS 的 libGLESv2.so 只导出 OES 后缀的 VAO 入口名，核心 ES3 名（glGenVertexArrays/glBindVertexArray/glDeleteVertexArrays）只在 libGLESv3.so 里 —— 用核心名的库必须同时链 GLESv3，否则加载期重定位即报 symbol not found

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, linking, gfx
- **作者**: hw-3

## 错误特征
```
Error relocating .*: glGenVertexArrays: symbol not found|Error relocating .*: glBindVertexArray: symbol not found|Error relocating .*: glDeleteVertexArrays: symbol not found
```

## 根因分析
OHOS 的 GL 运行库是分层 + 转发结构，同一族符号在两个库里并不重叠。

## 推荐方案
**方法**: link-glesv3-alongside-glesv2

**说明**: 在原有 GLESv2 之外同时链上 GLESv3（-lGLESv3，或 target_link_libraries 追加

**修复命令**:
```
-DCMAKE_SHARED_LINKER_FLAGS="-lEGL -lGLESv3 -lhilog_ndk.z -lace_ndk.z -lace_napi.z"
```

**验证**:
```
SYS=<ohos sysroot>/usr/lib/aarch64-linux-ohos; llvm-nm -D --defined-only $SYS/libGLESv2.so | awk '$3=="glGenVertexArrays"'; llvm-nm -D --defined-only $SYS/libGLESv2.so | awk '$3=="glGenVertexArraysOES"'; llvm-nm -D --defined-only $SYS/libGLESv3.so | awk '$3=="glGenVertexArrays"'; llvm-readelf -d <产物>.so | grep NEEDED
```
