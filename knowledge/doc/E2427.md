# E2427: 制品仓发布的 Qt 构建可能裁剪公开 API（头文件与 .so 双缺），依赖该 API 的运行时探测代码在编译期即失败，能力选择应上移为编译期选项门控

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, cmake, conan, qt6
- **作者**: unknown

## 错误特征
```
no member named '.*' in 'QQuickStyle'|error: no member named|undefined reference to '.*availableStyles.*
```

## 根因分析
OHOS 制品仓的 qtdeclarative/6.11.1 发布构建相对上游 Qt6 公开 API 存在

## 推荐方案
**方法**: compile-time-option-gating

**说明**: 把能力选择上移到编译期：CMake option（保持上游默认，如

**修复命令**:
```
target_compile_definitions(<target> PUBLIC KLEVER_NO_QQC2_DESKTOP_STYLE)（option 关闭分支）
```

**验证**:
```
grep -c availableStyles /storage/Users/currentUser/.conan2/p/qtdec*/p/include/QtQuickControls2/qquickstyle.h
```
