# E2428: KF6 发布包未随附 QML 绑定模块时，可选功能的 import 应隔离到叶子文件并以 Component 状态探测降级，不得静态 import 于共享/启动路径 QML 文件

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, dependency, qml
- **作者**: unknown

## 错误特征
```
module "org\.kde\.[a-z]+" is not installed|QML module not installed|Cannot load library
```

## 根因分析
OHOS 制品仓发布的 KF6 库普遍只含 C++ 库与头文件，不构建不发布 QML

## 推荐方案
**方法**: qml-import-isolation-runtime-probe

**说明**: 三步：(1) 把缺失模块的 import 连同该模块组件的使用隔离到一个叶子

**修复命令**:
```
Qt.createComponent("org.kde.klevernotes", "KIconDialog") 后判 component.status === Component.Ready
```

**验证**:
```
find /storage/Users/currentUser/.conan2/p/kicon*/p -name qmldir | wc -l
```
