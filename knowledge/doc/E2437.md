## 推荐方案
**方法**: disable-strip-on-install

**说明**: 适用**支持 $(DESTDIR) 的包**：package() 用 autotools.install(args=["STRIP="])

**修复命令**:
```
仅适用支持 $(DESTDIR) 的包：autotools.install(args=["STRIP="])；本包零 $(DESTDIR) 故 package() 改用 copy 收产物
```

**验证**:
