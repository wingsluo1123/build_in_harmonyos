## 推荐方案
**方法**: suppress-narrowing-warning-keep-cppstd

**说明**: 在配方 generate() 中通过 tc.extra_cxxflags 注入 -Wno-c++11-narrowing，

**修复命令**:
```
def generate(self):\n    tc = AutotoolsToolchain(self)\n    tc.extra_cxxflags.append("-Wno-c++11-narrowing")\n    tc.generate()
```
