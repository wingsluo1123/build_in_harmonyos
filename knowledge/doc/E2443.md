# E2443: 配方 get() 源码离线种子必须用 core.sources:download_cache 键与 s/<sha256> 布局，配错键会静默直连不报错

## 基本信息
- **严重度**: 3
- **类别**: ohos, conan, device, download-cache, offline
- **作者**: 9685
- **来源 PR**: 9685

## 错误特征
```
Calling source\(\).*\n.*（长时间无输出）|Error downloading file.*github|curl.*exit 60|connection reset.*github|Can't connect to HTTPS
```

## 根因分析
Conan 2 下载缓存有两个易混键——core.download:download_cache（远端工件缓存，c/<url-hash> 布局）与 core.sources:download_cache（配方 get() 源码备份，s/<sha256> 布局）；配方源码下载只查后者，配错键时 conan 不报错、静默跳过缓存直连 origin URL。

## 推荐方案
**方法**: sources-cache-key-and-layout

**说明**: >

**修复命令**:
```
curl -L -o <dl>/s/<sha256> "https://ghfast.top/https://github.com/<org>/<repo>/archive/refs/tags/<tag>.tar.gz" && sha256sum <dl>/s/<sha256>
```

**验证**:
```
CONAN_HOME=<isolated> conan create <recipe> -pr ohos-aarch64-fixed
```
