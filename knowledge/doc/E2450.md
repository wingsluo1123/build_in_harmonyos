# E2450: Conan 2.x 中 cmake_layout 只定义目录布局、不产出 CMakePresets.json，CMake(self) 构建前必须在 generate() 显式 CMakeToolchain().generate()；OHOS 目标按 E092 设 CMAKE_SYSTEM_NAME=Linux（库名仅括号案例：kicad-library-symbols 10.0.5 首报）

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, toolchain, conan, packaging
- **作者**: why6666666
- **来源 PR**: pending（本 run 单提交随分支交付，未推送）

## 错误特征
```
CMakePresets\.json was not found.*generators folder|Check that you are using CMakeToolchain as generator
```

## 根因分析
Conan 2.x 的配方生成管线是 layout() → generate() → build() 三段：layout() 阶段的 cmake_layout(self) 只计算 build/ generators/ 目录布局（build/<build_type> 与 build/<build_type>/generators），本身不生成任何工具链文件；CMakePresets.json 由 CMakeToolchain 在 generate() 阶段写入 generators 目录。若配方只写了 cmake_layout 而没有 generate()（或 generators 属性）产出 CMakeToolchain，conan 2.x 不会隐式补生成任何 generator，随后 build() 里 CMake(self) 初始化时按约定到 <build>/Release/generators 目录找 CMakePresets.json，找不到即抛 ConanException: CMakePresets.json was not found ... Check that you are using CMakeToolchain as generator。这是配方作者把 cmake_layout 误当"完整 CMake 集成"的语义错位：layout 解决"文件放哪"，generate 解决"工具链从哪来"，二者缺一不可。

## 推荐方案
**方法**: generate-cmaketoolchain-with-ohos-platform-guard

**说明**: 在配方中显式补 generate()：实例化 CMakeToolchain 并调用其 generate()，使 conan 在 generate 阶段把 conan_toolchain.cmake 与 CMakePresets.json 写入 cmake_layout 约定的 generators 目录，CMake(self) 即可正常初始化；OHOS 目标按 E092 的平台语义（CMake 无 HarmonyOS 平台模块）以 cache_variables 设 CMAKE_SYSTEM_NAME=Linux、CMAKE_SYSTEM_PROCESSOR 按 armv8→aarch64 映射（conan settings 的 armv8 即 64 位 ARM，CMake 侧名称为 aarch64），对 project(... NONE) 的纯数据工程与 POSIX 纯库均无副作用。

**修复命令**:
```
from conan.tools.cmake import CMake, CMakeToolchain, cmake_layout; def layout(self): cmake_layout(self); def generate(self): tc = CMakeToolchain(self); (tc.cache_variables.__setitem__("CMAKE_SYSTEM_NAME", "Linux"), tc.cache_variables.__setitem__("CMAKE_SYSTEM_PROCESSOR", "aarch64" if str(self.settings.arch) == "armv8" else str(self.settings.arch)) if self.settings.os in ("Linux", "OHOS") else None); tc.generate(); def build(self): cmake = CMake(self); cmake.configure(); cmake.build()
```
