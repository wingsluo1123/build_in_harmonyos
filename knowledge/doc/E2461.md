# E2461: 上游 CMakeLists 的 add_test 注册引用一个官方任何 tag/分支都未提供的测试包装脚本（ctest 报 No such file）：在当前库配方允许范围内以最小补丁补齐同名包装脚本（运行被测二进制并透传退出码），使 ctest 注册项真实可执行，不得以"上游缺陷"跳过台账

## 基本信息
- **严重度**: 2
- **类别**: cmake, packaging, testing, ctest, upstream-tests
- **作者**: unknown

## 错误特征
```
can't open file .*\.py.*No such file|
```

## 根因分析
上游 CMakeLists.txt 注册 add_test 时引用一个测试包装脚本

## 推荐方案
**方法**: minimal-patch-test-helper-wrapper

**说明**: 确认脚本在官方所有分支均缺失后，在当前库配方允许范围内新增

**修复命令**:
```
ctest --test-dir ${BUILD_DIR} --output-on-failure
```

**验证**:
```
补齐包装脚本后 ctest --output-on-failure 1/1 Passed
```
