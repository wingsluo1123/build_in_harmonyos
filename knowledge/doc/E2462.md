# E2462: C-API C++ 静态库的 test_package 消费者工程必须用 CXX（C 工程链接会缺 C++ 运行时符号）

## 基本信息
- **严重度**: 2
- **类别**: linking, conan, packaging, testing, libcxx
- **作者**: unknown

## 错误特征
```
undefined symbol: __cxa_begin_catch|undefined symbol: std::terminate|undefined symbol: __gxx_personality_v0|linker command failed with exit code 1
```

## 根因分析
库导出 C API（ethash.h/keccak.h 等），但实现（libethash.a/libkeccak.a 内的 .cpp/.c

## 推荐方案
**方法**: test-package-cxx-project

**说明**: test_package 的 CMakeLists.txt 用 project(<name> CXX)，测试源用 .cpp

**修复命令**:
```
# test_package/CMakeLists.txt
```

**验证**:
```
cd $REPO_DIR && python3 scripts/ohc-run.py conan-verify ethash 1.1.0
```
