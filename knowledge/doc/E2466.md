# E2466: ohpcd 制品仓 FFTW3 只有双精度构建，上游依赖单精度 fftw3f 的包在 configure 报 No package 'fftw3f' found

## 基本信息
- **严重度**: 1
- **类别**: autotools, dependency, pkg-config, fftw, precision
- **作者**: minimodem-0.24 task agent

## 错误特征
```
Package\s+'fftw3f',\s+required\s+by\s+'virtual:world',\s+not\s+found|
```

## 根因分析
FFTW3 是同一份源码按精度分别构建的：单精度要 configure

## 推荐方案
**方法**: mechanical-precision-swap-patch

**说明**: 机械精度替换补丁（本条实证：minimodem 0.24，src/fsk.c

**修复命令**:
```
grep -rn "fftwf_" <src>/ | grep -v Binary; conan list -r=ohpcd "fftw/*"
```

**验证**:
```
conan list -r=ohpcd "fftw/*"
```
