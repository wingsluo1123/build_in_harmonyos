# E2469: 纯 Python unittest out-of-proc 子进程包导入失败 → 注入精确 PYTHONPATH 重跑（运行时环境恢复，非修改上游测试）

## 基本信息
- **严重度**: 2
- **类别**: python, runtime, testing
- **作者**: AtomCode
- **来源 PR**: feat/pyjson5-0.15.0

## 错误特征
```
ModuleNotFoundError: No module named 'json5'|python -m <pkg>: exit 1|Can't open file|no module named
```

## 根因分析
子进程 cwd 为临时目录且未被安装到解释器环境；上游 CI 的

## 推荐方案
**方法**: pythonpath-inject-rerun

**说明**: 记录子进程实际探测的包/路径 → 注入精确 PYTHONPATH（源码根或

**修复命令**:
```
cd <src> && PYTHONPATH=<src> TMPDIR=<writable> python3 -m unittest discover -p '*_test.py' -v
```
