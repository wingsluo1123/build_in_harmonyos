# E2470: Conan test_package 显式调用 conan python 解释器二进制时，必须把 python 依赖包 cpp_info.libdirs 注入 LD_LIBRARY_PATH（设备端隐式加载器可解析 ≠ CI worker 可解析）

## 基本信息
- **严重度**: 2
- **类别**: linking, python, conan, runtime
- **作者**: AtomCode
- **来源 PR**: feat/pyjson5-0.15.0

## 错误特征
```
Error loading shared library libpython3.12.so.1.0: (needed by .*bin/python3.12)|
```

## 根因分析
conan python 依赖包的 bin/python3.12 动态链接

## 推荐方案
**方法**: test-package-inject-python-libdirs

**说明**: test() 中按 self.dependencies["python"].cpp_info.libdirs 构造

**修复命令**:
```
env -u LD_LIBRARY_PATH conan create archives/p/pyjson5/0.15.0
```
