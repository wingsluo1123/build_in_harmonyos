# E2474: lock-free 队列 "single consumer 立即 free(head)" 与并发多生产者 tail-CAS 竞态：多生产者+单消费者压测挂起及最小修复补丁（Taymindis lfqueue 1.2.2，修复前 5/5 挂起 → 修复后 5/5 通过）

## 基本信息
- **严重度**: 2
- **类别**: portability, threading, runtime, lock-free
- **作者**: unknown
- **来源 PR**: #12046 (lfqueue-1.2.2，R02 更新)

## 错误特征
```
lfqueue-example hang in one_deq_and_multi_enq|one_deq_must_and_multi_enq|liveness|Test\ Pass|timeout.*lfqueue|process sleeps waiting for dequeued item
```

## 根因分析
lfqueue.c::_single_dequeue() 在 CAS(head→next) 成功后立即 free(head)，

## 推荐方案
**方法**: deferred-node-reclamation-aligned-with-existing-multi-consumer-path

**说明**: ① 首选修复（本库已实施，patch 0002）：把 _single_dequeue() 出队节点的

**修复命令**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 --build=missing  # conan create 内 test_package 自动运行；补丁经 conandata.yml 应用
```

**验证**:
```
修复前（复现）: cd build && timeout 60 ./lfqueue-example ; echo $?  # 5/5 挂起返回 124
```
