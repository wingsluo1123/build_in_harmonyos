# E2475: OHOS 适配版 conan (2.29.1) 的 Meson helper 缺 meson_layout 与 compile()，需用 basic_layout/build()

## 基本信息
- **严重度**: 2
- **类别**: platform, build-system, meson, conan, api-surface
- **作者**: pc1-17

## 错误特征
```
cannot import name 'meson_layout' from 'conan\\.tools\\.meson'|
```

## 根因分析
OHOS 社区适配版 conan（基线 2.29.1，私有 PyPI 提供）的

## 推荐方案
**方法**: ohos-conan-meson-compat-imports

**说明**: conanfile.py 中 layout() 用 from conan.tools.layout import basic_layout

**修复命令**:
```
python3 scripts/ohc-run.py conan-verify <name> <ver>  # G2 PASS 为验收
```

**验证**:
```
python3 -c "import conan.tools.meson as m; print([x for x in dir(m) if not x.startswith('_')])";
```
