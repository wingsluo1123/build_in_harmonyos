# E2483: toybox base64 默认 76 列换行且 sed -i 替换符号链接本体——静默数据损坏需输出规整与解析目标编辑

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, libc, musl, runtime
- **作者**: unknown

## 错误特征
```
base64 输出多行致下游 token 断裂(rc=0 无报错)|
```

## 根因分析
toybox 与 GNU coreutils 的差异除"Unknown option 显式

## 推荐方案
**方法**: normalize-output-and-resolved-target-edit

**说明**: (1) 单行 token 场景在 base64 后接 tr -d '\n' 做输出

**修复命令**:
```
patch: printf '%s' "$PWD" | base64 | tr -d '\n';
```

**验证**:
```
head -c 100 /dev/zero | tr '\0' 'a' | base64 | wc -l   # toybox=2(GNU=1), 首行 77 字节
```
