# E2495: CMake 工程上游仅装库不装头：补 INSTALL(DIRECTORY include/ DESTINATION include) 且必须保留尾斜杠

## 基本信息
- **严重度**: 3
- **类别**: headers, cmake, install, consumer-packaging
- **作者**: unknown

## 错误特征
```
make\s+install.*后\s+include/.*为空|
```

## 根因分析
老式单库 CMake 工程（如 libbig_int）只写

## 推荐方案
**方法**: cmake-install-directory-headers

**说明**: 在上游 CMakeLists 补一行

**修复命令**:
```
sed -i '/^INSTALL(TARGETS/a INSTALL(DIRECTORY include/ DESTINATION include)' CMakeLists.txt
```

**验证**:
```
make install DESTDIR=$(pwd)/inst 2>&1 &&
```
