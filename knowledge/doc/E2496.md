# E2496: bignum 库算术结果长度不自动规范化：导出为 int 前必须先调用 clear_zeros 规范化长度，否则溢出误判

## 基本信息
- **严重度**: 2
- **类别**: api-contract, bignum, consumer-test, libbig-int
- **作者**: unknown

## 错误特征
```
big_int_to_int.*return\s+1|
```

## 根因分析
libbig_int 的 addsub/mul 保持 answer 的 len 为创建值

## 推荐方案
**方法**: bignum-clear-zeros-before-export

**说明**: 消费者把 bignum 算术结果导出为 int（或任何按 len 判溢出的

**修复命令**:
```
big_int_add(a, b, r); big_int_clear_zeros(r); big_int_to_int(r, &v);
```

**验证**:
```
消费者用例对 add/mul/div 结果先调用 big_int_clear_zeros(r)
```
