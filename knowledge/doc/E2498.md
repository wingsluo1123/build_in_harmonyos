# E2498: 已发布 openssl 包内二进制的 OPENSSLDIR 被烧成构建期 conan 包目录绝对路径，换 CONAN_HOME 或换机器后该路径不存在，消费方调用打包版 openssl req 因默认 openssl.cnf 缺失而失败

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, testing, security, relocatability
- **作者**: QOD-BE7
- **来源 PR**: (本 PR)

## 错误特征
```
"Can't open \"<OPENSSLDIR>/openssl.cnf\" for reading, No such file or directory|error:80000002:system library:BIO_new_file|error:10000080:BIO routines:BIO_new_file:no such file"
```

## 根因分析
openssl 在 Configure 阶段把 --openssldir 解析成一个编译期就写死进二进制的绝对路径

## 推荐方案
**方法**: seed-openssl-conf-for-packaged-cli

**说明**: 在调用打包版 openssl 的消费者脚本顶部显式导出 OPENSSL_CONF 指向一个存在的

**修复命令**:
```
export OPENSSL_CONF=/dev/null（放在消费者测试脚本里所有 openssl 调用之前）
```

**验证**:
```
cd <test_package> && . ./conanrun.sh && openssl version -d（比对内嵌 OPENSSLDIR 与包实际目录）；OPENSSL_CONF=/dev/null openssl req -x509 -newkey rsa:2048 -keyout k.pem -out c.pem -days 1 -nodes -subj '/CN=t' -batch（修后通过）
```
