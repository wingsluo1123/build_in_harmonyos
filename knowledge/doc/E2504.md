# E2504: HarmonyOS CMake feature probes and upstream runtime golden values need separate gates

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, toolchain, conan, testing
- **作者**: unknown

## 错误特征
```
isnanl|isinfl|finitel|exp10|golden value|hash mismatch
```

## 根因分析
OHOS libc++ and runtime ABI do not provide all glibc long-double symbols or host-generated numeric golden values.

## 推荐方案
**方法**: cache_variables plus static-library try_compile and an installed-package consumer gate
