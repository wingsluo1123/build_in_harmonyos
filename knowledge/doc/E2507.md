# E2507: Conan CMakeDeps 重建依赖配置不携带上游 INTERFACE_COMPILE_DEFINITIONS，消费方应显式补齐模块编译定义（Qt5 QT_*_LIB 家族 / xdelta3 SIZEOF_* / pinocchio BOOST_MPL_LIMIT_*）

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan, compile-definition
- **作者**: oh-device-porting-v2 builder (kwidgetsaddons5-5.116.0 run)
- **来源 PR**: (本 PR 提交后回填)

## 错误特征
```
no member named 'keyClick' in namespace 'QTest'|no member named 'qWaitForWindowExposed' in namespace 'QTest'|variable has incomplete type 'QWindow'|unknown type name 'usize_t'|mpl::non_sequence_tag.*no member named 'apply'|using declaration refers into 'Base::'.*which is not a base class
```

## 根因分析
Conan CMakeDeps 以依赖配方的 cpp_info 为唯一真源再生 CMake 配置，不继承该包安装树内原生配置的接口属性。机理链（Qt5 案例，一手核实）：(1) 工具实现证据——qt5-qtbase 原生配置硬编码模块定义，lib/cmake/Qt5Core/Qt5CoreConfig.cmake:149 置 INTERFACE_COMPILE_DEFINITIONS QT_CORE_LIB，Qt5GuiConfig.cmake:149=QT_GUI_LIB，Qt5WidgetsConfig.cmake:149=QT_WIDGETS_LIB，Qt5TestConfig.cmake:149=QT_TESTLIB_LIB；(2) 生成器行为——CMakeDeps 再生的 generators/Qt5-Target-release.cmake 中同名属性取值来自 cpp_info：set_property(TARGET Qt5::Gui APPEND PROPERTY INTERFACE_COMPILE_DEFINITIONS $<$<CONFIG:Release>:${qt5-qtbase_Qt5_Gui_COMPILE_DEFINITIONS_RELEASE}>)，而 qt5-qtbase 配方未声明 defines → 变量为空，对生成文件 grep QT_GUI_LIB 为 0 命中；(3) 失败点——QtTest 头按宏分派（qt5-qtbase src/testlib/qtest.h:460-504）：#if defined(QT_WIDGETS_LIB) → 含 qtest_widgets.h 且 QTEST_MAIN_IMPL 用 QApplication，#elif defined(QT_GUI_LIB) → qtest_gui.h + QGuiApplication，#else → 仅 QCoreApplication 且不含任何 GUI 测试 API；宏缺失 → QTEST_MAIN 退化 QCoreApplication、qtest.h 不含 qtest_gui.h → QTest::keyClick/qWaitForWindowExposed 不存在 → autotests 整类目标编译失败（触发：conan create BUILD_TESTING=ON）；(4) 归类——构建系统语义（Conan 生成器契约 vs 上游安装配置契约），非库内 quirk。同族先例（树内，跨库同根因）：xdelta3 3.2.0 上游 xdelta3lib 的 INTERFACE_COMPILE_DEFINITIONS（SIZEOF_SIZE_T=8/SIZEOF_UNSIGNED_LONG=8/XD3_USE_LARGESIZET=1 等）不被传播，缺则 xdelta3.h 无法 typedef usize_t/xoff_t（SIZEOF_* 全按 0 求值）；pinocchio 4.1.0/4.1.0.2 上游 pinocchioTargets.cmake 的 BOOST_MPL_LIMIT_LIST_SIZE=30/BOOST_MPL_LIMIT_VECTOR_SIZE=30/BOOST_MPL_CFG_NO_PREPROCESSED_HEADERS/PINOCCHIO_ENABLE_TEMPLATE_INSTANTIATION 不被传播，缺则报 mpl::non_sequence_tag 无 'apply'、"using declaration refers into 'Base::', which is not a base class"。合计树内 4 处同模式实践（含本 run 消费端修复）。

## 推荐方案
**方法**: consumer-toolchain-append-compile-definitions

**说明**: 消费端配方 generate() 在 CMakeToolchain.generate() 之后向生成的 conan_toolchain.cmake 追加 add_compile_definitions(<上游原生宏集>)（本 run 先例：kwidgetsaddons5 5.116.0）。不动共享基础包（如 qt5-qtbase），作用域=整个 build（该项目所有目标本就链接对应 Qt5 模块，与原生 INTERFACE 传播语义等价）。宏名必须用上游原生名（Qt5Test 是 QT_TESTLIB_LIB；本 run 配方误写 QT_TEST_LIB 无害——QTEST 分派只检查 QT_WIDGETS_LIB/QT_GUI_LIB——但知识沿用原生名）。探针实测：原生宏集追加后编译通过且测试真实执行（QApplication 分支）。

**修复命令**:
```
toolchain_file = os.path.join(self.generators_folder, "conan_toolchain.cmake"); with open(toolchain_file, "a", encoding="utf-8") as f: f.write("add_compile_definitions(QT_CORE_LIB QT_GUI_LIB QT_WIDGETS_LIB QT_TESTLIB_LIB)\n")
```

**验证**:
```
三段自包含（Qt5 案例，设备端任一新 shell 可复现）：(a) qt5p=$(ls -d ~/.conan2/p/qt5-*/p | head -1); for m in Core Gui Widgets Test; do grep -n INTERFACE_COMPILE_DEFINITIONS $qt5p/lib/cmake/Qt5$m/Qt5${m}Config.cmake | head -1; done → 四个文件各 :149 命中 QT_CORE_LIB/QT_GUI_LIB/QT_WIDGETS_LIB/QT_TESTLIB_LIB（原生配置硬编码证据）；(b) 任一 CMakeDeps 消费构建：grep -c QT_GUI_LIB <build>/<BT>/generators/Qt5-Target-*.cmake → 0，且 grep -A1 "APPEND PROPERTY INTERFACE_COMPILE_DEFINITIONS" Qt5-Target-release.cmake 显示取值为 cpp_info 变量（qt5-qtbase 未声明 → 空）；(c) 定向复现（探针源码与实录见 .md §Verification）：最小 conan 消费者（conanfile.py requires qt5-qtbase/5.15.2.2 + CMakeToolchain/CMakeDeps + set_property cmake_file_name=Qt5；CMakeLists find_package(Qt5 COMPONENTS Core Gui Widgets Test)；qtestmain_probe.cpp 用 QTEST_MAIN + QTest::qWaitForWindowExposed/QTest::keyClick）→ conan install . -pr:h ci/conan/profiles/ohos-aarch64 -pr:b 同 --build=missing && cmake --preset conan-release && cmake --build --preset conan-release → 失败：error: no member named 'qWaitForWindowExposed'/'keyClick' in namespace 'QTest'（RC=2）；向 build/<BT>/generators/conan_toolchain.cmake 追加一行 add_compile_definitions(QT_CORE_LIB QT_GUI_LIB QT_WIDGETS_LIB QT_TESTLIB_LIB) 后重配重编 → Built target（RC=0），QT_QPA_PLATFORM=offscreen 运行 → 3 passed, 0 failed（QTEST_MAIN 走 QApplication 分支）。同族复现对照：xdelta3.h 在无 SIZEOF_* 定义时 usize_t/xoff_t typedef 失败。
```
