# E2509: C 库加载器（from_file 类）错误路径早退返回未初始化结构体，消费者调 destroy/close 时 free(垃圾指针) 崩溃

## 基本信息
- **严重度**: 3
- **类别**: memory, error-path, loader
- **作者**: pc4-45 <noreply@atomgit.com>

## 错误特征
```
Signal 5|Signal 11|core dumped|Incoherent header|reading filter file|Cannot load bitarray
```

## 根因分析
加载类函数（fleur_bloom_filter_from_file 等）在错误路径

## 推荐方案
**方法**: zero-initialize-struct-at-entry

**说明**: 加载函数入口整体零初始化结构体（`BloomFilter bf = {0};`），

**修复命令**:
```
sed -n '/fleur_bloom_filter_from_file/,/^}/p' fleur/fleur.c
```
