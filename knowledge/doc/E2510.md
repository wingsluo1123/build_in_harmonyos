# E2510: conan-init 可能按 URL/注册表误判构建系统为 autotools, 而项目实为 CMake: 生成前必须核验源码根目录是否存在 CMakeLists.txt, 误判时改用手动 CMake 模板重写配方

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, cmake, autotools, conan
- **作者**: unknown

## 错误特征
```
AutotoolsToolchain|conanfile.py.*Autotools|configure.*not found|
```

## 根因分析
init-build/conan-init 的构建系统推断主要依据 URL 后缀与注册表(本任务 URL 为 github 归档, 被猜为 autotools), 未实际检查源码根目录的 CMakeLists.txt; 生成的 conanfile.py 使用 AutotoolsToolchain, 对 CMake 项目必然失败

## 推荐方案
**方法**: 生成配方后核对源码根目录构建文件(CMakeLists.txt/Makefile/configure): 存在 CMakeLists.txt 时改用 templates/conanfile-cmake.py.tmpl 手动重写配方 (CMakeToolchain + cmake_layout), 再 conan-verify
