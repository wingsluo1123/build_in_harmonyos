## 错误特征
```
The protoc-c program was not found|
```

## 根因分析
ohpcd 发布的 protobuf-c/1.5.1 配方的 package() 显式 shutil.rmtree(bin/)，

## 推荐方案
**方法**: author-time-pregen-pb-c-and-drop-protoc-requirement

**说明**: ① 作者期用 protobuf-c 1.5.1 的 protoc-gen-c 插件（protoc 驱动，

**修复命令**:
```
protoc --plugin=protoc-gen-c=$GEN --c_out=$OUT -I $PROTO_DIR $PROTO \\
```

**验证**:
```
conan create archives/d/dnstap-ldns/0.2.1
```
