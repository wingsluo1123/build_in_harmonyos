# E2514: python 包经 ctypes 按 platform.system() 分支选 .so/.dylib/.dll 后缀时，OHOS 平台名 "HarmonyOS" 无分支命中直接抛 ValueError

## 基本信息
- **严重度**: 2
- **类别**: platform, python, runtime
- **作者**: unknown

## 错误特征
```
ValueError: Platform\[harmonyos\] is not support
```

## 根因分析
OHOS 设备 Python 的 platform.system() 返回发行版定制的 "HarmonyOS"（实测 platform.system().lower()=='harmonyos'）。

## 推荐方案
**方法**: source-patch

**说明**: 补丁把 HarmonyOS 与 linux 同判 `.so`（ELF 动态库形态一致）：elif system in ('linux', 'harmonyos'):

**修复命令**:
```
sed -i "s/elif system == 'linux':/elif system in ('linux', 'harmonyos'):/" python/audioflux/fftlib.py
```

**验证**:
```
python3 -c "import platform; print(platform.system())" && python3 -c "import audioflux; print(audioflux.__version__)"
```
