# E2515: OHOS/沙箱无 passwd 库条目时 getpwuid() 返回 NULL，展开 ~ 路径的代码必须判空并 fallback $HOME，否则解引用 pw_dir 即崩溃

## 基本信息
- **严重度**: 3
- **类别**: libc, musl, posix, runtime, environment
- **作者**: pc2-16

## 错误特征
```
Signal 11|Segmentation fault|core dumped|getpwuid.*NULL|
```

## 根因分析
getpwuid() 在无 passwd 库条目的 OHOS/沙箱环境返回 NULL，

## 推荐方案
**方法**: getpwuid-null-check-with-home-fallback（getpwuid 判空 + getenv("HOME") fallback）

**说明**: >

**修复命令**:
```
struct passwd *p = getpwuid(getuid()); char *home = p ? p->pw_dir : NULL; if (!home) home = getenv("HOME"); if (!home) return NULL;
```

**验证**:
```
>
```
