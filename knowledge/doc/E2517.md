# E2517: git-archive 型 autotools 库（tag 无 release dist 资产）必须用 conan tool_requires automake+libtool 在 build() 内自举 autoreconf，而不是依赖环境或手改生成文件

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, conan
- **作者**: pc2-16

## 错误特征
```
Can't exec "libtoolize"|libtoolize failed|configure: No such file|
```

## 根因分析
上游未为 tag 生成 dist 资产，git archive 不含 autotools 生成文件；

## 推荐方案
**方法**: autotools-bootstrap-via-tool-requires（conan tool_requires automake+libtool 自举 git-archive autotools 包）

**说明**: >

**修复命令**:
```
tool_requires automake/1.18 + libtool/2.5.4; build(): autogen.sh (autoreconf -fi) 若无 configure
```

**验证**:
```
>
```
