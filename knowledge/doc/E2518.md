# E2518: OHOS procfs 不提供 /proc/<pid>/fdinfo，运行期解析 fdinfo 的工具核心功能结构性降级，应先做能力探测并诚实收窄输出

## 基本信息
- **严重度**: 2
- **类别**: platform, runtime, detect, procfs
- **作者**: sea_crab（不知对不队，oh-device-porting-v2 run inotify-info-0.0.4）

## 错误特征
```
fdinfo.*No such file or directory|fopen /proc/.*/fdinfo.*NULL|watch.*恒为 0
```

## 根因分析
OHOS 内核 procfs 不实例化 fdinfo 节点（探针：自身 ENOENT，非权限拒绝，区别 E031 的"有节点读不了"）→ fopen("/proc/<pid>/fdinfo/<fd>") 恒 NULL（inotify-info.cpp:329 guard 静默吞掉）→ watch 计数与 inode/sdev→路径反查恒空 → 实例计数同 uid 经 readlink anon_inode:inotify 仍可用（:356-372）、跨 uid EPERM → 限额 /proc/sys/fs/inotify/* 完全可读 → 归类：平台能力缺失（内核 procfs 语义），非 musl 差异、非 SELinux、非代码 bug

## 推荐方案
**方法**: fdinfo-capability-probe-degrade

**说明**: 运行期先对自身 pid 探测 fdinfo 节点存在性（一次判定全平台），缺失时收窄输出到可用子集并显式标注（对齐 g_kernel_provides_watches_info 式守卫）；测试侧只断言可用子集

**修复命令**:
```
[ -e /proc/self/fdinfo ] && echo fdinfo-PRESENT || echo fdinfo-ABSENT
```

**验证**:
```
cd $(mktemp -d) && ls /proc/self/fd >/dev/null && echo A1-fd-dir-present && r=$(readlink /proc/self/fd/0) && echo A2-readlink-ok:$r && { [ -e /proc/self/fdinfo ] && echo A3-fdinfo-PRESENT || echo A3-fdinfo-ABSENT; }; ls /proc/1/fdinfo 2>&1 | head -1; cat /proc/sys/fs/inotify/max_user_watches; printf '%s\n' '#include <stdio.h>' '#include <fcntl.h>' '#include <sys/inotify.h>' 'int main(void){int i=inotify_init();inotify_add_watch(i,"/tmp",1);int f=open("/etc/passwd",0);char p[64];snprintf(p,64,"/proc/self/fdinfo/%d",f);FILE* x=fopen(p,"r");printf("inotify_fd=%d open_fd=%d fdinfo_probe=%s\n",i,f,x?"PRESENT":"NULL(ABSENT)");return x==NULL;}' > probe.c && /data/service/hnp/bin/clang probe.c -o probe && ./probe
```
