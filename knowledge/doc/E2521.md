# E2521: 上游 CMake 无条件构建共享库、其静态依赖归档非 PIC 时，aarch64 链接失败；消费侧按 BUILD_SHARED_LIBS 门控共享库为可迁移解

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, linking, shared-library
- **作者**: unknown

## 错误特征
```
relocation R_AARCH64_ADR_PREL_PG_HI21 cannot be used against symbol|R_AARCH64_ADD_ABS_LO12_NC|cannot be used against symbol.*recompile with -fPIC|lib\.a.*Linking CXX shared
```

## 根因分析
上游 src/CMakeLists.txt 无条件 add_library(<lib> SHARED ...) 并链接

## 推荐方案
**方法**: gate-shared-lib-on-build-shared-libs

**说明**: 在补丁/配方中把 add_library(<lib> SHARED ...)、其 set_target_properties、

**修复命令**:
```
if(BUILD_SHARED_LIBS) add_library(x_dynamic SHARED ...) ... target_link_libraries(bin x_dynamic) install(.*x_dynamic) else() target_link_libraries(bin x_static) endif()
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing（链接后 test_package ctest 1/1 Passed）
```
