# E2524: OHOS musl 应用 uid 无 passwd 条目：getpwuid() 恒 NULL，依赖它的工具链路（锁文件/用户名诊断/HOME 推断）直接致命退出

## 基本信息
- **严重度**: 2
- **类别**: platform, musl, runtime, app-uid, dotlock
- **作者**: sunjunyang
- **来源 PR**: 本 PR（mairix 0.24 配方 PR，合并后回填编号）

## 错误特征
```
getpwuid.*Not supported|
```

## 根因分析
OHOS 上应用进程跑在专用 app uid（如 20020100）下，

## 推荐方案
**方法**: static-fallback-struct-on-null

**说明**: 最小侵入补丁：getpwuid 返回 NULL 时不退出，构造

**修复命令**:
```
补丁骨架：static struct passwd fb; static char n[]="unknown";
```

**验证**:
```
id -u   # 应用 uid（非 passwd 条目）
```
