# E2526: 手写多级 Makefile 工程的“架构二元分支 + 平台专属子项目”：非 x86 目标误加 -m32/-march=i686 或编到 x86 内联汇编，需按 TARGET_ARCH 三态剔除

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, make, patch, architecture
- **作者**: unknown

## 错误特征
```
unsupported argument 'i686' to option '-march='|
```

## 根因分析
上游手写 Makefile 常用 TARGET_ARCH ?= $(shell uname -m | sed …) 做二元分支

## 推荐方案
**方法**: source-patch

**说明**: 在 Makefile 层把“架构二元分支”改为三态，并对仅平台专属的子项目/目标做条件剔除（x86 目标行为保持不变）

**修复命令**:
```
|
```

**验证**:
```
make CC=clang -j1 2>&1 | head -20（看首个错误落在哪个子项目）；
```
