# E2527: 上游代码用 tmpfile()/硬编码 /tmp 建临时文件：在只读 /tmp 的平台上功能静默失效，需改走 $TMPDIR

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, runtime, environment, filesystem
- **作者**: unknown, frj__
- **来源 PR**: (本分支 feat/retroarch-1.22.2，PR #14934，关联 B issue)

## 错误特征
```
creating a temporary file to uncompress.*failed|
```

## 根因分析
libc 的 tmpfile() 固定使用 P_tmpdir（OHOS 即 "/tmp"），不读 TMPDIR 环境变量；

## 推荐方案
**方法**: source-patch

**说明**: 把 tmpfile() 换成在 $TMPDIR 下 mkstemp()+unlink() 的匿名临时流（$TMPDIR 未设置时回落 "/tmp"，与原行为一致）

**修复命令**:
```
tmpdir = getenv("TMPDIR")（为空回落 "/tmp"）→ snprintf(path, "%s/xxx-XXXXXX", tmpdir)
```

**验证**:
```
TMPDIR=/tmp <tool> … | grep -i "temporary file"（复现失败）；
```
