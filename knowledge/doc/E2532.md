# E2532: 上游自带 Find 模块的单复数变量错配只在非系统前缀下暴露；静态 libreadline.a 必须并链 ncurses terminfo 后端

## 基本信息
- **严重度**: 3
- **类别**: cmake, toolchain, find-module, link, readline
- **作者**: awstme-executor

## 错误特征
```
readline\.h.*(No such file|file not found)|undefined reference to `(tgetent|tgetflag|tgoto|tputs)'|Found candidate FindReadline
```

## 根因分析
>

## 推荐方案
**方法**: fix-find-module-plural-and-chain-ncurses

**说明**: Find 模块在 FIND_PATH 后补 set(READLINE_INCLUDE_DIRS ${READLINE_INCLUDE_DIR}) 对齐消费方变量名；READLINE_FOUND 分支内 find_library(NCURSES_LIBRARY NAMES ncursesw ncurses) 并链到 target_link_libraries，条件存在才链（conan toolchain 已把依赖包目录前置进 CMAKE_LIBRARY_PATH，find_library 直接命中）

**修复命令**:
```
set(READLINE_INCLUDE_DIRS ${READLINE_INCLUDE_DIR}) && find_library(NCURSES_LIBRARY NAMES ncursesw ncurses) && target_link_libraries("sjaakii" ${READLINE_LIBRARY} ${NCURSES_LIBRARY})
```

**验证**:
```
nm -g <conan>/p/readl*/p/lib/libreadline.a | grep -E 'U (tgetent|tgoto|tputs)' ; nm -g --defined-only <conan>/p/ncur*/p/lib/libncursesw.a | grep ' T tgetent'
```
