# E2533: OHOS 工具链全局注入的 -Wl,--code-sign 在编译阶段被 clang 判为 unused 告警，上游强制 -Werror 的工程把它升级成硬 error（每个源文件首行即炸）——首选上游自带的 warnings 降级 option，其次显式 -Wno-error=unused-command-line-argument；与 E063（源码告警×-Werror）签名与解法均不同

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, toolchain, compiler, warnings
- **作者**: hw-4 <hw-4@local>

## 错误特征
```
error: -Wl,--code-sign: 'linker' input unused \[-Werror,-Wunused-command-line-argument\]|argument unused during compilation: '-Wl,--code-sign'
```

## 根因分析
HarmonyOS PC 的编译 wrapper 为产物签名要求全局注入 -Wl,--code-sign（链接期必需，不能删）。

## 推荐方案
**方法**: use-upstream-warnings-off-option

**说明**: 优先查找并使用上游自带的警告降级开关（本工程为 option(UTPP_AMPLIFY_WARNINGS)；

**修复命令**:
```
cmake -DUTPP_AMPLIFY_WARNINGS=OFF ..（conan 内：tc.cache_variables["UTPP_AMPLIFY_WARNINGS"]="OFF"）
```

**验证**:
```
cmake --build . 2>&1 | grep -m1 "code-sign.*unused\|linker' input unused"
```
