# E2540: stock CMake未知HarmonyOS致UNIX为假时改用NOT MSVC守卫注入whole-archive保留静态注册

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, cmake, testing
- **作者**: hmbs-executor
- **来源 PR**: 11927

## 错误特征
```
93% tests passed, 27 tests failed out of 387|Error relocating|TVMFFIError.*symbol not found|fatal.*unable to access.*github.com.*googletest.git
```

## 根因分析
stock CMake 4.4.3无Platform/HarmonyOS模块致UNIX变量为假，if(UNIX AND NOT APPLE)守卫静默跳过--whole-archive，静态归档丢弃TVM_FFI_STATIC_INIT_BLOCK字符串查表注册；上游FetchContent写死GIT_REPOSITORY github克隆在无直连worker必然超时失败

## 推荐方案
**方法**: not-msvc-whole-archive-static-link

**说明**: 经replace_in_file将测试链改为静态并以if(NOT MSVC)守卫注入LINKER whole-archive同时拉入tvm_ffi_static与tvm_ffi_testing保留STATIC_INIT注册；另以vendored googletest tarball加FETCHCONTENT_SOURCE_DIR_GOOGLETEST离线化FetchContent跳过github克隆

**修复命令**:
```
conanfile.py: 三次replace_in_file静态化加if(NOT MSVC) whole-archive块；conandata.yml: 新增googletest tarball镜像有序列表；generate(): 置FETCHCONTENT_SOURCE_DIR_GOOGLETEST与INSTALL_GTEST=OFF
```

**验证**:
```
真机预检以ctest -N取discovered加逐行Test #N计数双源核对387/389通过，readelf验证测试二进制NEEDED仅libc，前后两轮失败名单字节级对比确认守卫生效，加构建日志确认FETCHCONTENT_SOURCE_DIR_GOOGLETEST跳过克隆
```
