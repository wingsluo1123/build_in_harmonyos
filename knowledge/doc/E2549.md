# E2549: ctypes/dlopen 型包的库路径类环境变量常指「库文件」而非目录（传目录会 dlopen 目录并报 Permission denied），且 LD_LIBRARY_PATH 必须覆盖整条依赖链而非只有直接依赖

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: 12208

## 错误特征
```
Error loading shared library .*/lib.*Permission denied|Error loading shared library libgio-2\.0\.so\.0|needed by .*libenchant-2\.so|errors during collection
```

## 根因分析
(A) enchant/_enchant.py 的 from_env_var() 对 PYENCHANT_LIBRARY_PATH 只做 assert os.path.exists() 后原样返回，随后 ctypes.cdll.LoadLibrary(path)；传目录即 LoadLibrary(目录) -> Error loading shared library <dir> Permission denied。另一变量 PYENCHANT_ENCHANT_PREFIX 走 from_prefix()，但那是 Windows 布局（<prefix>/bin/libenchant-2.dll），Linux 不适用。(B) libenchant-2.so 自身 NEEDED libgio-2.0.so.0 / libglib-2.0.so.0（enchant/2.8.2 的 conaninfo requires glib/2.84.Z）；只把 enchant 的 lib/ 前置进 LD_LIBRARY_PATH，加载 libenchant-2.so 时其 NEEDED 解析不到 -> Error loading shared library libgio-2.0.so.0 (needed by .../libenchant-2.so)。两层共同表现：测试在**收集期**整片失败（N 个文件 ERROR during collection）。

## 推荐方案
**方法**: pass-library-file-and-whole-dep-chain-libdirs

**说明**: 库路径类环境变量传**文件**（<dep>/lib/libenchant-2.so，优先无版本后缀 .so）；LD_LIBRARY_PATH 用**整条依赖链**（遍历 self.dependencies 收各自 cpp_info.libdirs 绝对路径一并前置，勿硬编码 <pkg>/lib）；同一套环境同时给 build()、test_package 与 package_info() 的 env_info。

**修复命令**:
```
PYENCHANT_LIBRARY_PATH=<enchant>/lib/libenchant-2.so LD_LIBRARY_PATH=<enchant>/lib:<glib>/lib <python> test
```

**验证**:
```
readelf -d <dep>/lib/libenchant-2.so | grep NEEDED; python3 -c "import os;print(os.path.isfile('<env-value>'))"
```
