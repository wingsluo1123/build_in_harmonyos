# E2551: OHOS 上 XDP/AF_XDP 上游测试不可执行的三条并列判据（无 bpffs / SELinux 拒 netlink / BPF 执行 EPERM）

## 基本信息
- **严重度**: 2
- **类别**: platform, kernel, testing
- **作者**: staralsnow

## 错误特征
```
Unable to mount /sys/fs/bpf|can.t talk to rtnetlink: Permission denied|Operation not permitted
```

## 根因分析
XDP/AF_XDP 类上游测试需要三项内核能力——挂 bpffs、建 veth(rtnetlink)、加载 BPF 程序；OHOS 内核未提供 bpffs/BPF syscall，SELinux 又拒绝 netlink 与 BPF 程序执行，故分别报 Unable to mount /sys/fs/bpf、ip: can t talk to rtnetlink: Permission denied、Operation not permitted(126)。

## 推荐方案
**方法**: declare-environment-blocked

**说明**: 按 R51 逐条如实申报"环境阻塞"并附原始报错，不写 PASS、不为凑数改上游测试；把"可执行子集"（如纯编译+链接检查）与"环境阻塞"分开列，并注明非适配缺陷。

**修复命令**:
```
grep -E "Unable to mount /sys/fs/bpf|rtnetlink: Permission denied|Operation not permitted" ~/libxdp-upstream.log
```

**验证**:
```
sudo env DID_UNSHARE=1 PATH=... make -C lib/libxdp test V=1 2>&1 | grep -E "Unable to mount /sys/fs/bpf|rtnetlink: Permission denied|Operation not permitted"
```
