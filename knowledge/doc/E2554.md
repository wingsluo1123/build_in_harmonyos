# E2554: invert-platform-branch-darwin-whitelist

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, make, linking, cross-compile
- **作者**: unknown

## 错误特征
```
ld\.lld: error: unknown argument '-dead_strip'|dead_strip.*unknown argument|linker command failed with exit code 1
```

## 根因分析
raw GNU Makefile 用 `ifeq ($(UNAME_S),Linux)` 二分支区分平台，else 分支堆入 macOS 专属 `-Wl,-dead_strip`；HarmonyOS 的 `uname -s` 返回 `HarmonyOS` 而非 `Linux`，落入 else 分支吃到 macOS 专属链接参数，ld.lld 不识别报 unknown argument。上游把平台假设建模为"Linux / 其他"，而"其他"分支隐含 macOS 专属 flag。
