# E2558: GitHub 上游 tag 带 v 前缀时 conandata.yml 必须写 refs/tags/v<ver>，写 refs/tags/<ver> 会 NotFoundException 404

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, github, source-url, tag-naming
- **作者**: pc4-37

## 错误特征
```
NotFoundException: Not found: .*refs/tags/[0-9]+\.[0-9]+|
```

## 根因分析
部分 GitHub 仓库（ionescu007/minlzma 等）的 release tag 名为

## 推荐方案
**方法**: conandata-tag-v-prefix-fix

**说明**: conandata.yml（及外层 URL）的 sources.url 改为官方 tag 全名：

**修复命令**:
```
curl -sS https://api.github.com/repos/<owner>/<repo>/tags | head -20 && \\
```

**验证**:
```
curl -sS https://api.github.com/repos/<owner>/<repo>/tags \\
```
