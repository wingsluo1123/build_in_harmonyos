## 推荐方案
**方法**: pin-serial-make

**说明**: 配方 build() 固定 `autotools.make(args=["-j1"])`（及 `make target="check"`

**修复命令**:
```
autotools.make(args=["-j1"]); autotools.make(target="check", args=["-j1"])
```

**验证**:
```
cd "$WORKSPACE_ROOT/tmp/builds/genders-1.27-3.work" && rm -f src/libgenders/genders_query.tab.c src/libgenders/genders_query_parse.c && make -j4 > "$TASK_DIR/explore-logs/j4.log" 2>&1; grep -c 'bison -y' "$TASK_DIR/explore-logs/j4.log"; grep -c 'exit code 135' "$TASK_DIR/explore-logs/j4.log"; make -j1; echo "j4 必现 + j1 rc=0 即复现"
```
