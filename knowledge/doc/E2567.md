## 推荐方案
**方法**: exclude-binding-dirs-and-inject-task-lang

**说明**: 按停点交接包下一步（R47 附录 D.4「语言绑定目录是已知误判源」）：①把绑定子目录

**修复命令**:
```
OHPCD_LANG=c python3 "$WORKSPACE_ROOT/framework/run-ohc.py" lang-preflight genders 1.27-3 --src "$WORKSPACE_ROOT/tmp/builds/genders-1.27-3.work" --lang c --project-dir "$WORKSPACE_ROOT/worktrees/genders-1.27-3"
```

**验证**:
```
mv "$TASK_DIR/lang-exclude/src/extensions" "$WORKSPACE_ROOT/tmp/builds/genders-1.27-3.work/src/extensions" && python3 "$WORKSPACE_ROOT/framework/run-ohc.py" lang-preflight genders 1.27-3 --src "$WORKSPACE_ROOT/tmp/builds/genders-1.27-3.work" --lang cpp --project-dir "$WORKSPACE_ROOT/worktrees/genders-1.27-3"; echo "rc=2 且 detected=perl 为复现；还原：mv 回 $TASK_DIR/lang-exclude/src/extensions"
```
