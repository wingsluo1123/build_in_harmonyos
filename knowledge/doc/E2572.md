# E2572: 构建目录路径含空格时 autotools Makefile 的未加引号 $(abs_builddir) 被 make 拆词，把路径前缀当目标反复构建

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, make, configure, filesystem
- **作者**: ATOMCODE

## 错误特征
```
overriding recipe for target .*build_in_harmonyos|
```

## 根因分析
autotools 生成的 Makefile 里 `abs_builddir` 是**未加引号**的

## 推荐方案
**方法**: build-in-space-free-directory

**说明**: 把源码/构建目录放到**不含空格**的路径下再构建。

**修复命令**:
```
mkdir -p ~/builds && tar xf pkg.tar.gz -C ~/builds && cd ~/builds/pkg-1.0 && ./configure && make
```

**验证**:
```
# 观察伪目标告警即可确认
```
