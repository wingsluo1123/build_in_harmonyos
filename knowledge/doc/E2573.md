## 推荐方案
**方法**: portable-recipe-three-fixes

**说明**: 配方三改：generate() 注入 CC_FOR_BUILD + 剔除 autosetup 不认的注入参数；两份 portability 补丁注入 HarmonyOS/ohos 分支（conandata 登记 patch_type=portability，refresh_patch 两面同步）

**修复命令**:
```
"grep -q 'autosetup-config.guess' \"$PACKAGE_DIR/conandata.yml\" && conan create \"$PACKAGE_DIR\" -pr:h=\"$HOST_PROFILE\" -pr:b=\"$HOST_PROFILE\" -c tools.build:jobs=4  # rc=0 即三改齐备"
```
