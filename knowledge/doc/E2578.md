# E2578: O_TMPFILE 打开成功但 linkat(/proc/self/fd) 发布被禁 → 探测回退命名文件+renameat

## 基本信息
- **严重度**: 2
- **类别**: portability, filesystem, /proc, eacces, linkat
- **作者**: pc2-19

## 错误特征
```
Unable to store the rendition.*Permission denied|
```

## 根因分析
OHOS 挂载 /proc，但 seccomp/权限层面拒绝 linkat 经

**说明**: 能力探针在受信目录实测 openat2(O_TMPFILE)+linkat(/proc/self/fd/N)；

```
|
```
