# E2583: OHOS toybox tar 不支持 GNU 长选项（--no-xattrs/--no-acls）——移除并保留安全子集

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, build-system, tar, tooling
- **作者**: pc2-19

## 错误特征
```
Unknown option 'no-xattrs'|
```

## 根因分析
toybox tar 仅实现 GNU tar 长选项子集，未知长选项直接报错；

## 推荐方案
**方法**: tar-longopts-subset

**说明**: 保留 toybox 支持的 --no-same-owner/--no-same-permissions 与安全

**修复命令**:
```
|
```

**验证**:
```
conan create archives/a/appstream/1.2.0 -pr:h=<abs>/ci/conan/profiles/ohos-aarch64 -pr:b=<abs>/ci/conan/profiles/ohos-aarch64 --build=missing; meson test as-test_basic
```
