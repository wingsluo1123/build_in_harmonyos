# E2586: meson 源硬编码 include_directories(['/usr/include']) 在 OHOS 构建机（无 /usr/include）配置期直接报错

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, build-system, meson
- **作者**: pc2-19

## 错误特征
```
Include dir /usr/include does not exist|
```

## 根因分析
OHOS 构建机不存在 /usr/include 目录（工具链 sysroot 布局不同）；

## 推荐方案
**方法**: remove-hardcoded-usr-include-patch

**说明**: 最小补丁移除 meson.build 中硬编码的 include_directories(['/usr/include'])

**修复命令**:
```
tc.extra_cflags.append(f"-I{os.path.join(dep_pkg, 'include')}")
```

**验证**:
```
conan create archives/a/appstream/1.2.0 -pr:h=<abs>/ci/conan/profiles/ohos-aarch64 -pr:b=<abs>/ci/conan/profiles/ohos-aarch64 --build=missing
```
