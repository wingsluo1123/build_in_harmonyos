# E2587: meson i18n.itstool_join 无条件要求 itstool 程序（OHOS 无此程序）——find_program(required:false) 回退

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, build-system, meson
- **作者**: pc2-19

## 错误特征
```
Program 'itstool' not found or not executable|
```

## 根因分析
meson i18n 模块的 itstool_join 无条件 find_program('itstool')

## 推荐方案
**方法**: itstool-join-optional-fallback

**说明**: 补丁把 itstool_join 改为 find_program('itstool', required:false) 门控：

**修复命令**:
```
|
```

**验证**:
```
conan create archives/a/appstream/1.2.0 -pr:h=<abs>/ci/conan/profiles/ohos-aarch64 -pr:b=<abs>/ci/conan/profiles/ohos-aarch64 --build=missing
```
