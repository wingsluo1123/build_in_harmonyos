# E2589: GFileMonitor 事件顺序差异（ATTRIBUTE_CHANGED 先于 CREATED）——同批 added 去重

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, filesystem, event-ordering, gio
- **作者**: pc2-19

## 错误特征
```
cnt_changed == 0.*1 == 0|
```

## 根因分析
process_pending 先发 changed 后发 add；部分文件系统事件序

## 推荐方案
**方法**: filemonitor-batch-dedup

**说明**: 发 changed 前检查路径是否在 queue_add（将 as added 发出）或

**修复命令**:
```
|
```

**验证**:
```
conan create archives/a/appstream/1.2.0 -pr:h=<abs>/ci/conan/profiles/ohos-aarch64 -pr:b=<abs>/ci/conan/profiles/ohos-aarch64 --build=missing; meson test as-test_pool
```
