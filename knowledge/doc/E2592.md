# E2592: retype-container-to-real-pointer-and-follow-all-sizes

## 基本信息
- **严重度**: 2
- **类别**: portability, runtime, memory, 'lp64, consumer-test'
- **作者**: hw-2
- **来源 PR**: (本 PR)

## 错误特征
```
'rc=139|Segmentation fault \(core dumped\)|signal 11 \(SIGSEGV\)|analysis run failed rc=139'
```

## 根因分析
'LP64 上 sizeof(int)=4 而 sizeof(指针)=8，老代码把指针当整数搬运会在解引用时命中未映射地址；窄化若写成显式 (int) 则编译器不报（1) 2000 年前后的自建数据结构（排序表、索引数组、哈希桶）常把元素声明成 int*/long*，写入时 (int)ptr、读回时 (T*)value，两步都是"合法"的强制转换，-Wall 与 -Wextra 都不告警（能被编译器拦下的是另一类形态：隐式转换或指针与整数的有序比较，如 DRAFT-gli-0.8.2.0-strstr-pointer-compare-clang15 的 int p = strstr(...) 后 p > 0，clang 15 直接拒绝编译，两者形态与可发现性完全不同）。 (2) aarch64/musl 设备上 malloc 返回的堆地址量级远超 32 位：真机 /proc/self/maps 两次取样 native_heap:jemalloc 段为 6377001000-6377201000 与 6386a01000-6386c01000，恒在 0x63_xxxxxxxx 量级（ASLR 让每次具体值不同，但从未回到 32 位以内；取证日志 ~/tmp/uc2/hw-2/isoqlog-2.2.1/heapaddr-evidence.log）。 (3) 截断只剩低 32 位（以 6377001000 那次为例：0x77001000），int → 指针按符号扩展成 0xFFFFFFFF_77001000，该地址未映射，解引用第一个字段即 SIGSEGV，进程没有任何输出可 grep。 (4) 触发条件是"表里至少有一条记录"：容器为空时排序循环一次都不执行、不解引用任何指针，所以空输入必跑通——这既是判别特征，也是"用空数据做冒烟测试会假绿"的坑。 (5) ILP32（32 位 x86/ARM）两型同宽，同一份代码永不触发，故上游可能几十年都没发现。'

## 推荐方案
**方法**: retype-container-to-real-pointer-and-follow-all-sizes

**说明**: '把容器元素类型改成它真正承载的类型，并让所有 sizeof 与交换变量跟着变；逐个消灭窄化点，改一处不够。 (1) 字段声明：int *allusers → user **allusers（或 void **，若能确定统一类型则优先真实类型，可读性更好）。 (2) 写入点：allusers[n] = (int)usr → allusers[n] = usr，同时 malloc/realloc 的 sizeof(int *) → sizeof(user *)。 (3) **排序/交换过程的临时变量同样在 int 里搬指针**（本例 8 个 sort*() 的 int tmp），漏改则症状一模一样（swap 中二次窄化）。 (4) 读回点的 (T*) 强转可以保留（类型已一致，无害），但必须逐个确认没有别处再经 int 中转。 (5) 验证必须用真实数据集（≥1 条记录），空数据集验证会给出假绿。'

**修复命令**:
```
'见 archives/i/isoqlog/2.2.1/patches/0001-isoqlog-Data.h.patch 与 0002-isoqlog-Data.c.patch（逐文件、a/ b/ 前缀、10 行上下文，由框架自身差分函数 ohc.refresh_patch._diff_files 对 pristine/已改两份树生成；conandata.yml 两条均显式 strip: 1，依据=在 pristine 树上实测 patch -p1 --dry-run rc=0 而 -p0 与 -p2 均 rc=1，取证 ~/tmp/uc2/hw-2/isoqlog-2.2.1/strip-evidence.log） # 要点（isoqlog 2.2.1）： # Data.h:  - int *allusers;              + user **allusers; # Data.c:  - int *u;                     + user **u; #          - (int *)malloc(NVINIT * sizeof(int *))   + (user **)malloc(NVINIT * sizeof(user *)) #          - (int *)realloc(..., NVGROW*max*sizeof(int *)) + (user **)realloc(..., NVGROW*max*sizeof(user *)) #          - allusers[nval] = (int)usr;            + allusers[nval] = usr; #          - int tmpnval, i, j, max, tmp;          + int tmpnval, i, j, max; 加 user *tmp;（8 个 sort*()）'
```
