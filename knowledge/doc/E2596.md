# E2596: tarball 缺 autotools 生成产物时单文件 mtime 对齐不足: 须全套前置文本携带 + 剥离外部工具规则 + os.utime 钉全部输入 mtime

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, build-system, autotools, conan
- **作者**: AtomCode (qwen3.8) <noreply@atomgit.com>
- **来源 PR**: !11680

## 错误特征
```
automake-[0-9.]+: command not found|WARNING.*automake.*missing on your system|Must remake target '(configure|config.status|Makefile)'|Error 127.*Makefile|missing.*automake
```

## 根因分析
上游发行 tarball 不含预生成 autotools 产物 (configure/Makefile.in/aclocal.m4/m4/*.m4), 而 CI worker 仅有部分 autoconf 工具、无 automake/aclocal, 配方必须随附本地预生成产物。此场景下 E248 式"单文件 mtime 对齐"不足: 完整输入集 (configure, configure.ac, aclocal.m4, m4/*.m4, 各 Makefile.am/Makefile.in, config.h.in) 与多条 make 规则 (Makefile:, $(top_builddir)/config.status:, $(srcdir)/Makefile.in:, $(top_srcdir)/configure:, $(ACLOCAL_M4):, $(srcdir)/config.h.in:, stamp-h1:) 相互作用; conan export/copy2 流水线 mtime 偏斜 (缓存时间与写入时间混杂)、configure 就地改写 (如 E114 式 umask replace_in_file) 在 configure 运行后改变 mtime、make 把"前置文件缺失"视为"刚更新", 任一成立都会触发 $(AUTOMAKE)/$(AUTOCONF)/$(ACLOCAL)/$(AUTOHEADER) recipe, 在缺工具的 worker 上必然 exit 127 崩溃。另本机 shell touch -t 存在 8 小时时区偏移 (实测 1577808000 vs 期望 1577836800), 基于 touch 的修复不可靠。

## 推荐方案
**方法**: prebuilt-text-ship-plus-rule-strip-plus-utime-pin

**说明**: 三段组合: (1) 全套前置以文本形式携带 (12 顶层文件 + m4/*.m4 + 全部 Makefile.in, 共 31 项; GitCode PR diff 不携带二进制文件内容, 且 JC3/PF2 制品闸禁止 tar.gz); (2) 从 prebuilt Makefile.*.in 剥离调用外部工具的 4 类规则块 ($(srcdir)/Makefile.in: $(AUTOMAKE), $(top_srcdir)/configure: $(AUTOCONF), $(ACLOCAL_M4): $(ACLOCAL), $(srcdir)/config.h.in: $(AUTOHEADER)); 保留自修复的 Makefile:/config.status: 规则与空规则 $(am__aclocal_m4_deps):; (3) 全部源码修改完成 (patches/install/就地改写之后)、configure 运行之前, 用 os.utime 把依赖链全部输入 (configure/configure.ac/aclocal.m4/config.h.in/Makefile.in/*.m4/*.am, 共 33 项) 钉到 2020-01-01 (1577836800), 逐文件 stat 校验, 任一未生效即 raise ConanException 快速失败。

**修复命令**:
```
conanfile.py build(): apply_conandata_patches -> _install_prebuilt_autotools (copy2+chmod +x) -> replace_in_file (configure 就地改写) -> _pin_autotools_input_mtimes (os.utime(path,(1577836800,)*2) + int(os.stat(p).st_mtime) 校验) -> Autotools.configure(); 规则剥离: Python 逐行删掉 4 类规则头及其 \t 开头 recipe 行
```

**验证**:
```
conan create 成功后: 日志应出现 "mtime 钉扎: 33 个 autotools 输入文件 -> 2020-01-01"; make -d -n all (顶层+各子目录) 危险目标 (configure/config.status/Makefile/Makefile.in/aclocal.m4) remake 为 0; conan-verify G2 + W3 本地 CI 全部 PASS。
```
