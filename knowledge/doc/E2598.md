# E2598: autotools 手写 Makefile.in（无 Makefile.am）install 规则以裸名引用头文件时，

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools, conan, packaging, in-source
- **作者**: pc2-34 <noreply@atomgit.com>
- **来源 PR**: (待 PR 编号)

## 错误特征
```
install: bad '.*\.hpp': No such file or directory|
```

## 根因分析
上游发布 tarball 只含手写 Makefile.in（无 Makefile.am，

## 推荐方案
**方法**: in-source-layout

**说明**: layout() 中 basic_layout(self) 后追加 self.folders.build = "."

**修复命令**:
```
def layout(self):\n    basic_layout(self)\n    self.folders.build = "."
```

**验证**:
```
conan create（OHOS profile）→ package() 报 install: bad '<h>':
```
