# E2601: HarmonyOS HMFS 对 FS_IOC_MEASURE_VERITY ioctl 返回 EACCES（Linux 为 ENODATA/ENOTTY/EOPNOTSUPP），composefs 类库把该 errno 当"意外错误"中止构建——需把 EACCES/EINVAL 归一化为 ENOVERITY 回退进程内摘要计算

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, filesystem, aarch64, fs-verity
- **作者**: unknown

## 错误特征
```
error accessing .*: Invalid argument|FS_IOC_MEASURE_VERITY|measure_fsverity|EACCES|Permission denied.*verity|lcfs_fd_get_fsverity|ENOVERITY
```

## 根因分析
HMFS 内核文件系统对 FS_IOC_MEASURE_VERITY 返回 EACCES（探针实测 errno=13），而 Linux ext4/overlayfs 对未启用 fs-verity 的文件返回 ENODATA、对不支持该 ioctl 的文件系统返回 ENOTTY/EOPNOTSUPP。composefs lcfs_fd_measure_fsverity 仅把 ENODATA/EOPNOTSUPP/ENOTTY 归一化为 ENOVERITY，EACCES 落入"意外错误"分支（lcfs_fd_get_fsverity 不回退），导致 mkcomposefs/lcfs_build 对整个目录树扫描失败并报 "error accessing <path>: Invalid argument"。

## 推荐方案
**方法**: ioctl-errno-canonicalization

**说明**: 把 FS_IOC_MEASURE_VERITY 返回的 EACCES（以及 EINVAL，HMFS 用 EINVAL 表达同类语义的变体）与 ENODATA/EOPNOTSUPP/ENOTTY 一并归一化为 ENOVERITY，让调用方进入"内核无 fs-verity"分支，回退到进程内 fs-verity 摘要计算（composefs 已内置该回退，见 lcfs_fd_get_fsverity）。归一化位置应集中在 measure 函数内，使 get/measure 两条调用链同时受益。

**修复命令**:
```
sed -i "s/errno == ENODATA || errno == EOPNOTSUPP || errno == ENOTTY/errno == ENODATA || errno == EOPNOTSUPP || errno == ENOTTY || errno == EACCES/" libcomposefs/lcfs-writer.c；make && ./tests/test-lcfs
```

**验证**:
```
ioctl 探针（clang 编译, 打开普通文件后 ioctl(FS_IOC_MEASURE_VERITY) 打印 errno=13 EACCES）；补丁后 lcfs_fd_measure_fsverity 返回 -ENOVERITY(=-25)，lcfs_fd_get_fsverity 返回 0 且摘要确定（同内容同摘要、异内容异摘要）；mkcomposefs 目录扫描通过（check-units test_objects OK）
```
