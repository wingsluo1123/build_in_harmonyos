# E2605: 发行 tarball 自带旧-era 预生成 parser/lexer 且目标无 bison/yacc——播种自带旧件并把 .y/.l mtime 调旧阻止空 YACC 重生成，编译器语法覆盖面停在旧 era 须按平台受限逐项申报

## 基本信息
- **严重度**: 3
- **类别**: ohos, autotools, bison, flex, parser
- **作者**: 0
- **来源 PR**: pending（随 feat/intercal-0.30 分支交付）

## 错误特征
```
No rule to make target.*parser\.c|YACC = :$|ICL99[0-9]I|syntax error near new keyword|empty yacc rule|mv cannot stat y\.tab\.c
```

## 根因分析
release tarball 惯例由维护者在打包机上预生成 parser/lexer 的 .c 随包发布，生成物冻结在打包当时的 grammar 版本（intercal 0.30 的 prebuilt/{parser.c,lexer.c,oil-oil.c} 时间戳为 2010 年）。OHOS 目标无 bison/yacc/flex，configure 的 AC_PROG_YACC/AC_PROG_LEX 探不到工具，YACC/LEX 被置空；且随包 .y/.l 语法源比预生成 .c 更新（含 2010 后 ICL997I 等新语法）。make 因 .y/.l mtime 更新而尝试用空 $(YACC) 重生成，规则空转或报 No rule to make target；即使锁定旧 .c 编过，构建出的 ick 语法覆盖面被钉死在 2010 era，喂新语法程序报 ICL99xI 拒绝。根因是预生成物 era 旧于随包语法源且无法重生成，覆盖面缺口属目标缺 bison 的平台能力缺失而非配方 bug。

## 推荐方案
**方法**: seed-shipped-prebuilt-and-backdate-grammar-sources

**说明**: build() 内 configure 之后、make 之前：(1) 把上游随包发布的 prebuilt/{parser.c,lexer.c,oil-oil.c} 拷进源码树它们应在的位置（intercal 需同时喂 ./ 与 ./src/ 两份拷贝点）；(2) 对每个 .y/.l 用 os.utime(fp,(atime,mtime-10)) 把 mtime 调到比刚拷入的 .c 更旧，使 make 判定 .c 已最新、不再触发空 $(YACC)/$(LEX) 的重生成规则；(3) 诚实申报语法覆盖面缺口，旧 parser 不认的新语法 PIT 用例逐个归为平台受限·跳过，写进 test_package/MANIFEST.yml 的 platform_limited 与 N_skipped，绝不为凑通过率静默删用例或缩分母（AGENTS §10 / SKILL R34/R51）。只用上游随包那份旧件，不自造 parser.c。

**修复命令**:
```
import os; from conan.tools.files import copy; [copy(self, gen, os.path.join(src,"prebuilt"), src, keep_path=False) for gen in ("parser.c","parser.h","lexer.c","oil-oil.c")]; [copy(self, gen, os.path.join(src,"prebuilt"), os.path.join(src,"src"), keep_path=False) for gen in ("parser.c","parser.h","lexer.c","oil-oil.c")]; [os.utime(os.path.join(src,newer), (os.stat(os.path.join(src,newer)).st_atime, os.stat(os.path.join(src,newer)).st_mtime-10)) for newer in ("parser.y","lexer.l","oil.y","src/parser.y","src/lexer.l","src/oil.y") if os.path.isfile(os.path.join(src,newer))]
```

**验证**:
```
command -v bison yacc flex（预期三者全空）；configure 后 grep -E "^YACC" Makefile 预期为空或 ":"；播种后 cp -f prebuilt/parser.c prebuilt/lexer.c prebuilt/oil-oil.c . && cp -f prebuilt/parser.c prebuilt/lexer.c prebuilt/oil-oil.c src/ && touch -d "10 seconds ago" parser.y lexer.l oil.y src/parser.y src/lexer.l src/oil.y && make -j1（预期不再触发 .y 到 .c 重生成，ick 编译成功）
```
