# E2608: "①表定义与 extern 声明一并去掉 const（只改声明不改逻辑，写法见 archives/m/mppenc/1.

## 基本信息
- **严重度**: P1
- **类别**: portability
- **作者**: unknown

## 错误特征
```
'Segmentation fault (core dumped).*(Init_FastMath|tabatan2|tabcos|tabsqrt)|fatal error: .*fpu_control\.h.*file not found'
```

## 根因分析
"上游把运行时填充的查找表声明为 const（无初始化器的 tentative definition）；老 gcc 将其放入可写 .bss，clang 将全零 const 表优化进只读 .rodata，运行期首次写入即 SIGSEGV。伴生问题：bionic 定义 __linux__ 但没有 glibc 专有头 fpu_control.h，而使用点早已被 __i386__ 宏守卫（aarch64 不编译）。"

## 推荐方案
**方法**: "①表定义与 extern 声明一并去掉 const（只改声明不改逻辑，写法见 archives/m/mppenc/1.16/patches/0001-src-fastmath.c.patch）；②glibc 专有头 include 条件加 defined __GLIBC__ 判别（现 patches/0002-src-mppdec.h.patch，refresh-patch --auto 重生成名）；定位手段：ptrace 受限时用 fprintf 插桩二分代替 gdb。"
