# E2610: Do not rm -rf conan2 p/b/*; package lives beside build and orphaned sqlite rows corrupt the cache

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, ohos, conan, cache
- **作者**: AtomCode

## 错误特征
```
os.utime.*FileNotFoundError|Corrupted package|conaninfo.txt|Already installed
```

## 根因分析
In Conan 2.x the package folder is p/b/<hash>/p/ and the build folder is p/b/<hash>/b/ — same parent. Deleting p/b/*/ removes the package too, while cache.sqlite3 keeps a row pointing at the deleted base_folder; the next install hits os.utime(base_folder) -> FileNotFoundError.

## 推荐方案
**方法**: use-conan-remove

**说明**: To free space on the device, prefer `conan remove "<name>/<ver>" -c` (removes recipe+binary+sqlite rows) or delete only the build child p/b/<hash>/b/, never the whole p/b/<hash>/.

**修复命令**:
```
conan remove "qtbase/6.11.1" -c
```

**验证**:
```
conan list "qtbase/*:*"; a corrupted package prints "without conaninfo.txt in .../p/b/<hash>/p/conaninfo.txt".
```
