# E2611: 'sysfs 整树 readdir 对非特权进程返回 EACCES 而 stat 成功——按"权限策略"归因，别写成"子树不存在"，消费者断言只能主张自行降级'

## 基本信息
- **严重度**: '2'
- **类别**: ohos, selinux, kernel, testing, 'platform
- **作者**: '主理-32'

## 错误特征
```
'opendir  : EACCES \(13\)|access_R : EACCES|open /sys/class O_DIRECTORY : fd=-1 errno=EACCES\(13\)|raw-read-on-sysfs-dir'
```

## 根因分析
'HarmonyOS PC 上 /sys、/sys/class、/sys/class/net、/sys/class/backlight、 /sys/class/leds、/sys/power 的 stat 全部成功（mode 0555/0755，是目录），但同一进程的 opendir 与 O_DIRECTORY open 一律 EACCES；连"应当成功"的一般 sysfs 对照臂也同症状 ⇒ 拒点在 MAC/挂载策略 层（world-readable 的 mode 位满足不了它），不是 backlight 子树缺失，也不是内核缺 syscall （read/write/stat 本身可用）。与之相对，/sys/bus/hid/drivers/razerkbd、/etc/udev、/run/udev 的 stat 直接 ENOENT，那才是"不存在"。四件事必须分开归因。W4R1 一手加强（本棒输出件 probe-out.txt 第 67 69 71-75 行）：/sys 挂载参数为 rw,relatime,hmmac=genfs,seclabel（排除只读挂载假说）、本进程安全上下文 u:r:hishell_hap:s0、且直读已知节点 /sys/class/net/lo/ifindex 连 stat 都 Permission denied ⇒ 拒点确在 MAC 层，且拒面宽于仅 readdir [W4R1/P3-3]。'

## 推荐方案
**方法**: 'positive-control-probe-and-degradation-assertion'

**说明**: '先用带正对照的一手探针定性（同一次实验里既探应成功的臂又探待判定臂）， 再把 test_package 写成"只主张能主张的"：ELF 架构回读、选项文案面、错误路径退出码、 以及能力缺失时的自行降级（枚举为空 + 有诊断文案 + 不被信号杀死；退出码 0 与非 0 都可能，本包 light -L 一手实测 rc=0（输出件 ~/tmp/uc2/z32-light-fix1/probe-out.txt 第 1 行起带时间戳，读数见 notes），断言必须按实测分支写）， 两分支都收但都要求诊断，静默成功与崩溃一律 FAIL。'

**修复命令**:
```
'/usr/bin/timeout 30 light -L（实测 rc=0 + 零个 /sys/class 目标 + 有诊断文案即判诚实降级；rc 非 0 时同样须匹配到工具自身诊断；静默成功、被信号杀死、零诊断一律 FAIL）'
```

**验证**:
```
'在本机用 C 探针同时探 stat 与 opendir 并对一般 sysfs 面做正对照： 预期 stat=OK + opendir=EACCES；再探 /sys/bus/hid/drivers/razerkbd 与 /etc/udev 应得 ENOENT'
```
