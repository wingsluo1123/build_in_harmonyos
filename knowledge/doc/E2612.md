# E2612: test_package 的 .sh 依赖闭合检查用了 bash 数组语法（read -a/<<</${arr[@]}），conan 用 /bin/sh 执行时被 toybox 静默拆分失败，误报 "NEEDED lib not resolvable"

## 基本信息
- **严重度**: 2
- **类别**: ohos, posix, linking, conan, packaging
- **作者**: unknown

## 错误特征
```
ERROR\(HarmonyOS\): NEEDED lib not resolvable: lib[a-zA-Z0-9_.-]+\.so(\.\d+)*|
```

## 根因分析
conan test_package 的 conanfile.py 用 self.run('"{}" ...'.format(shell, ...))，

## 推荐方案
**方法**: posix-sh-only-test-scripts

**说明**: test_package 的 .sh 必须写成 POSIX sh 兼容（conan 用

**修复命令**:
```
OLDIFS=$IFS; IFS=':'; set -- ${LD_LIBRARY_PATH:-}; IFS=$OLDIFS;
```
