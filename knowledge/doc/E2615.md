# E2615: replace-gcvt-with-portable-snprintf

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, musl, gnu-extensions
- **作者**: unknown

## 错误特征
```
undefined symbol: gcvt|call to undeclared function 'gcvt'|implicit declaration of function 'gcvt'|implicit-function-declaration.*gcvt
```

## 根因分析
gcvt() 是 glibc 遗留扩展函数（SVID/XPG，非 C 标准），musl/OHOS libc 不声明也不导出该符号。上游 jsonParse (liufeigit/jsonParse v1.00) 在 object.c 的 __toFloatString() 中用 gcvt(d, 30, str) 做 double→字符串，OHOS aarch64 下编译产生 implicit-function-declaration 警告、链接直接 undefined symbol: gcvt 失败。

## 推荐方案
**方法**: replace-gcvt-with-portable-snprintf

**说明**: 用 C99 标准 snprintf 无条件替换 gcvt：snprintf(str, 30, "%.17g", d)。"%.17g" 是 double 往返保真（round-trip）的 C 标准最短可靠格式，任何 libc 通用，无需平台条件编译（符合 R8：补丁默认禁止 __OHOS__ 宏；本方案为纯可移植替换，无平台宏）。若上游 gcvt 依赖其 30 位有效数字语义，可用 "%.*g" 保留有效位需求，但 %.17g 已满足 IEEE-754 double 无损往返。
