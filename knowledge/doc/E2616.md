# E2616: refresh-patch 规则回退分支用「生成物名单」分类已存在文件，改过的 Makefile 被判生成物而静默丢弃，工具报无差异且 rc=0

## 基本信息
- **严重度**: 2
- **类别**: build-system, conan, patch, tooling
- **作者**: 主理-64

## 错误特征
```
"无差异，保留现有补丁|无编辑追踪器，使用排除规则扫描差异|无法定位源码目录: orig=None"
```

## 根因分析
'scripts/ohc/refresh_patch.py:22 的注释写着名单适用面「only used for NEW files in right_only」，但 :23-26 的 _GENERATED_NAMES 集合里含 Makefile、config.h、libtool、stamp-h1、stamp-h、config.cache、config.h.in~、configure.lineno；消费它的 _is_likely_generated（:46 定义，:59-60 命中名单即 return True）经由 _classify（:184 定义，:186-188 把 generated 翻成 False=不要这个文件）在两个分支被调用。right_only（新文件）分支符合注释语义，但 :215 的 `for f in dcmp.diff_files:`（两边都存在但内容不同 = 被修改的源文件）分支 :220 也执行 `verdict = _classify(mod_file)`，:221-222 `if verdict is False: continue` 直接跳过——于是被改过的上游 Makefile 连进 diff_pairs 的机会都没有。auto_mode（:370）在无编辑追踪器时（:386 use_tracker 为假 → :416 打印「⚠️ 无编辑追踪器，使用排除规则扫描差异...」→ :418 _find_differences）走这条规则路径，diff_pairs 为空 → :430-432 打印「无差异，保留现有补丁」并 return 0。工具以成功退出码收尾，补丁里不含任何 Makefile 改动，磁盘上的旧补丁原样留着，看起来「已生成」，实际内容与被改后的 work 树无关。'

## 推荐方案
**方法**: create-edit-tracker-baseline-via-module-api-then-precise-mode

**说明**: '绕开规则回退分支，把运行逼进精准模式（:390-413，该分支不做 classify）。追踪器基线只能由模块级 API 建立，CLI 没有重置基线入口（scripts/ohc/edit_tracker.py:256-280 的子命令只有 scan（:263）/ add（:269）/ list（:275），没有 snapshot），所以正确姿势是——手工准备纯净 .orig 与改过的 .work 两棵树，然后在小驱动脚本里 import 并调用 edit_tracker.snapshot(work_dir, software="", version="")（edit_tracker.py:73 定义，init_build.py:337 内部调的就是它）建基线，再跑 refresh-patch --auto，此时输出变为「追踪到 N 个文件变更」+「精准模式: 只对 N 个追踪文件生成补丁」。生成后必须用 git diff / grep 逐行核对补丁正文（本包为 +5/-5，去 -march=native 与 install→$(INSTALL)），确认改动真进了补丁再入库。'

**修复命令**:
```
python3 -c "import sys; sys.path.insert(0,'scripts'); from ohc.edit_tracker import snapshot; snapshot('<work 目录绝对路径>', software='', version='')" && python3 scripts/ohc-run.py refresh-patch --auto <pkg> <ver> && grep -n '^[-+]' archives/<l>/<pkg>/<ver>/patches/*.patch
```

**验证**:
```
'python3 scripts/ohc-run.py refresh-patch --auto <pkg> <ver>; git -C <wt> diff --stat -- archives/<l>/<pkg>/<ver>/patches   # 判据：git diff 有改动而 refresh-patch 报「无差异」即命中本机制'
```
