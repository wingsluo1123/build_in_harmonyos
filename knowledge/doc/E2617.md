# E2617: Zig 0.16 OHOS native 目标宿主 libc 探测注入不完整 sysroot 时用 -Dtarget=aarch64-linux-musl 全局绕过，test_server spawn 受限用 access→statFile

## 基本信息
- **严重度**: 3
- **类别**: ohos, libc, musl, headers, build-system
- **作者**: hmbs-executor
- **来源 PR**: 12308

## 错误特征
```
'bits/alltypes.h' file not found|sysroot/usr/include/stdlib.h:.*include 'bits/alltypes.h' not found|error: .* compilation errors.*install transitive failure|HMBS_UPSTREAM_TEST_RESULT=\{[^}]*"skipped":8
```

## 根因分析
zig/0.16.0.1 在 OHOS 以 native(.{}) 目标编译 C 依赖时，宿主 libc 探测无条件注入 OHOS SDK sysroot include（其 stdlib.h/stdint.h 依赖 musl bits/alltypes.h，而 sysroot 不含该头）；该注入与 CC/CXX/CFLAGS/CPATH 环境无关（清理 env、env=None 均无效），module.addIncludePath 只作用到库自身模块，无法覆盖以独立 compile step 构建的 C 子库（jpeg/zlib/zstd 等报 155/15/32 errors）；另 test_server 存在性探测用 access（faccessat）在 OHOS 受限，spawn 子进程又有签名要求

## 推荐方案
**方法**: global-musl-target-bypass

**说明**: 在 conanfile 的 build() 中让 zig build 与 zig build test-all 在 OHOS 下统一加 -Dtarget=aarch64-linux-musl，使 zig 全程使用自带完整 musl 头、绕开不完整 sysroot 探测，全局覆盖所有模块与独立 C 编译 step；宿主同 arch/os 时 is_cross_compiling 仍为 false，上游用例照常执行

**修复命令**:
```
conanfile.py: build() 内 `self.run(f"zig build -Dtarget=aarch64-linux-musl ...", env=...)`（test-all 同）；test_server.zig 存在性探测 access→std.Io.Dir.cwd().statFile(io,...) 并加 `_ =` 丢弃非 void 成功值；test-all 前对 zig-out/bin/odiff 先 chmod+_sign_elf 预签名
```

**验证**:
```
真机日志确认 zig build 命令行出现 -target aarch64-linux-musl 且无 bits/alltypes.h 报错、Build Summary 全成功；zig build test-all 用 statFile 补丁后 server 用例 executed 40→48、skipped 8→0 且 passed==discovered
```
