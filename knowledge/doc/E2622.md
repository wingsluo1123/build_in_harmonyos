# E2622: pip 构建隔离 overlay 在 inode 受限 worker 上触发 Errno 28：纯 Python 包配方 pip install 须加 --no-build-isolation 复用已装 build backend

## 基本信息
- **严重度**: 2
- **类别**: ohos, python, packaging, environment, fs
- **作者**: pc1-15

## 错误特征
```
Could not install packages due to an OSError: \[Errno 28\]|
```

## 根因分析
>-

## 推荐方案
**方法**: pip-install-no-build-isolation

**说明**: conanfile.py build() 中 pip 命令加 --no-build-isolation：

**修复命令**:
```
python3 -m pip install --no-deps --no-build-isolation --target="<install>" "<source_folder>"
```

**验证**:
```
df -i /storage/Users/currentUser | tail -1（IUse%=100）；
```
