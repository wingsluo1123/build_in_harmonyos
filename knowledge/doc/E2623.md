# E2623: OHOS toybox/busybox tools reject GNU long options (--lines etc.) in upstream test scripts; rewrite to POSIX short options or prepend GNU coreutils to PATH (coreutils-fmt pattern)

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability, toolchain, testing
- **作者**: Ember5843
- **来源 PR**: 12349

## 错误特征
```
Unknown option '--|invalid option -- '|unrecognized option' (test script runtime)
```

## 根因分析
OHOS 用户空间命令由 toybox（部分环境叠加 busybox）提供，仅实现 POSIX/常用短选项子集，不识别 GNU coreutils 长选项与 GNU 特有行为。上游测试脚本按 Linux/glibc 习惯写 GNU flag，构建期可过、测试运行期一调用即报 Unknown option 非零退出，上游测试假失败。

## 推荐方案
**方法**: posix-rewrite-or-gnu-coreutils-path

**说明**: 先逐命令对照 toybox --help 收集缺口清单；缺口少（1-2 处）脚本侧改写为 POSIX 等价短选项（wc --lines→wc -l）；缺口多或无法等价改写时按设备已验证的 coreutils-fmt/9.11 模式打包 GNU 工具到 /data/service/hnp/bin/ 并在测试 job 前置 PATH。禁止超出选项等价改写范围篡改上游脚本。

**修复命令**:
```
N=$(wc -l < "$f")  # 或 job 脚本: export PATH=/data/service/hnp/bin:$PATH
```

**验证**:
```
conan create . --user=ohpcd --channel=stable -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
