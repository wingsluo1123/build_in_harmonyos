# E2624: Never put conan package lib dirs on LD_LIBRARY_PATH during OHOS builds; bake -Wl,-rpath into test executables instead

## 基本信息
- **严重度**: 1
- **类别**: musl, toolchain, conan, ld-library-path, libxml2
- **作者**: Ember5843

## 错误特征
```
Error relocating .*llvm/bin/lld: xml[A-Z][a-zA-Z]*: symbol not found|
```

## 根因分析
SDK lld 链接 libxml2 + musl 先查 LD_LIBRARY_PATH 后查 DT_RUNPATH + conan libxml2 缺 LLVM 内部符号，三者叠加

## 推荐方案
**方法**: no-ld-during-build-plus-rpath-on-test-exes

**说明**: >

**修复命令**:
```
grep -n "LD_LIBRARY_PATH" archives/*/*/*/conanfile.py
```

**验证**:
```
>
```
