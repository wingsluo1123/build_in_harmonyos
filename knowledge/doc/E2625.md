# E2625: conan Meson helper 硬编码 `meson <args>`，OHOS 沙箱 exec bin/meson（#!/bin/sh shebang）必报 Permission denied；配方 run() 内改写为 `<python> <meson.py> <args>` 即通过

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, meson, conan, shebang
- **作者**: SunShine_06 <apYppkJJLBwLbnc6.SunShine_06@noreply.gitcode.com>
- **来源 PR**: playerctl 2.4.1 PR（待提交）

## 错误特征
```
/system/bin/sh: .*meson: Permission denied|
```

## 根因分析
conan 的 Meson helper（conan/tools/meson/meson.py）把命令硬编码为裸名 `meson <args>`。meson 包的 bin/meson 是 `#!/bin/sh` 脚本，而 OHOS 沙箱的 execve() 不接受 system shell 作 shebang 解释器（#!/bin/sh、#!/data/service/hnp/bin/bash 全部 EACCES；实测唯一可用解释器是 conan 侧 python3，errno=13 而非 8）。helper 无官方挂钩可注入绝对解释器。另注意 Meson helper 方法集为 configure()/build()/install()，不存在 compile()（调用即 AttributeError）。

## 推荐方案
**方法**: recipe-run-rewrite-python-meson

**说明**: 在配方中覆写 run()：仅当 settings.os == "OHOS" 且命令以 `meson ` 开头时，把 `meson <args>` 改写为 `<python 绝对路径> <site-packages>/mesonbuild/core.py <args>` 形式（仓库既有惯用法见 archives/a/abx/0.1）。不修改 conan 框架与 meson 包本体。

**修复命令**:
```
self.run(cmd) 覆写示例见 archives/p/playerctl/2.4.1/conanfile.py 的 run() 覆写
```

**验证**:
```
conan create archives/p/playerctl/2.4.1 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
