# E2636: Replace the %q-capable printf used by meson-wrapped custom commands on OHOS

## 基本信息
- **严重度**: 2
- **类别**: ohos, meson, toolchain, testing
- **作者**: unknown

## 错误特征
```
printf: bad %q|bad %q@20|systemd-runtest\.env|meson_exe_printf_|custom command .*newlines
```

## 根因分析
meson configure 时 find_program('printf') 在 OHOS 默认 PATH 中

## 推荐方案
**方法**: path-priority-coreutils-printf

**说明**: configure 前把 coreutils printf 目录置于 PATH 前端（或显式

**验证**:
```
/system/bin/printf 'A=%q\n' "x y" ; echo rc=$?
```
