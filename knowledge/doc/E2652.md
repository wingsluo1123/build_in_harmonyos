# E2652: ncurses --enable-widec 库名 libncursesw.a 与 configure 探测 -lcurses 不匹配，需符号链接桥接

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools, linking, dependency
- **作者**: AtomCode (qwen38) <noreply@atomgit.com>
- **来源 PR**: 11418

## 错误特征
```
checking for initscr in -lcurses\.\.\. no|AC_CHECK_LIB.*curses.*initscr|initscr.*not found|ncurses.*widec.*libname
```

## 根因分析
ncurses --enable-widec 编译后库名为 libncursesw.a（w=wide char），

## 推荐方案
**方法**: ncurses-widec-symlink-bridge

**说明**: 在 conanfile build() 入口（configure 之前）创建 libcurses.a → libncursesw.a 符号链接，

**修复命令**:
```
os.symlink(os.path.join(libdir, "libncursesw.a"), os.path.join(libdir, "libcurses.a"))
```

**验证**:
```
conan create <lib> -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 2>&1 | grep "checking for initscr"
```
