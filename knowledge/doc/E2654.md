# E2654: Environment.save_script("conanbuild") 与 AutotoolsToolchain 聚合产生递归 source，导致 printenv Argument list too long

## 基本信息
- **严重度**: 3
- **类别**: ohos, autotools, conan, environment
- **作者**: unknown

## 错误特征
```
printenv: Argument list too long|conanautotoolstoolchain\.sh.*printenv|make: \*\*\* No targets specified and no makefile found
```

## 根因分析
OHOS 配方在 generate() 里先 AutotoolsToolchain(self).generate()，再用

## 推荐方案
**方法**: inline-export-instead-of-save-script

**说明**: 不要用 Environment.save_script("conanbuild") 追加工具链变量；改为在

**修复命令**:
```
self.run(f'export LD=/data/service/hnp/bin/ld; export AR=/data/service/hnp/bin/ar; make -j1', env="conanbuild", cwd=self.source_folder)
```

**验证**:
```
grep -n "conanbuild.sh" <build>/build-release/conan/conanbuild.sh   # 观察是否递归 source 自身
```
