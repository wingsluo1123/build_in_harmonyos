# E2655: CMake include 模块内无条件 set() 回置会静默丢弃 -D 命令行 cache 覆盖，需 if(NOT DEFINED) 守卫尊重显式输入

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, testing
- **作者**: why6666666
- **来源 PR**: 交付 PR 后回填

## 错误特征
```
CMake Error at .*AddLLVM\.cmake:.*\(add_dependencies\)|The dependency target .* does not exist
```

## 根因分析
被 include() 的 CMake 模块在文件级无条件 set(<VAR> <默认值>) 时，会在当前目录作用域创建同名的普通变量并**遮蔽**同名的 -D 命令行 cache 输入——用户的显式覆盖被静默丢弃，且无任何警告。完整因果链（LLVM 18.1.8 实例）：openmp/cmake/OpenMPTesting.cmake 第 2 行 set(ENABLE_CHECK_TARGETS TRUE) 在每次 include 时无条件回置 → 上游文档推荐的 -DENABLE_CHECK_TARGETS=OFF（本包不构建 in-tree clang 时关闭 lit 测试套件的唯一正规途径）失效 → construct_check_openmp_target（openmp/CMakeLists.txt:154）→ add_openmp_testsuite（OpenMPTesting.cmake:243）→ add_lit_testsuite（OpenMPTesting.cmake:220）仍创建 check-openmp/check-libomp 等 check-* 目标并经 add_lit_target 调 add_dependencies(clang)（AddLLVM.cmake:1962）→ "The dependency target \"clang\" of target \"check-openmp\" does not exist" → configure 致命错误。工具实现证据：CMake 普通变量在目录作用域内遮蔽同名 cache 条目；触发命令：cmake ... -DENABLE_CHECK_TARGETS=OFF；失败点：AddLLVM.cmake:1962 add_dependencies；归类：构建系统变量作用域语义（include 内普通变量遮蔽 cache 输入），非平台问题。

## 推荐方案
**方法**: not-defined-guard-in-include-module

**说明**: 把 include 模块内的无条件 set(<VAR> TRUE) 改为 if(NOT DEFINED <VAR>) set(<VAR> TRUE) endif()：默认行为对全部默认构建零变化（变量仍未定义时照常赋默认值），而显式 -D cache 输入得以存活。这是对上游语义的正确修复——"命令行显式覆盖优先于模块默认值"，补丁最小、可向上游提交（先例：补丁 0001 对 OpenMPTesting.cmake 第 3 行加守卫）。

**修复命令**:
```
补丁内容：-set(ENABLE_CHECK_TARGETS TRUE) 改为 if(NOT DEFINED ENABLE_CHECK_TARGETS)/  set(ENABLE_CHECK_TARGETS TRUE)/endif()（上游原版该 set 位于 OpenMPTesting.cmake 第 2 行）；验证：带 -DENABLE_CHECK_TARGETS=OFF 的 configure 通过、无 check-* 目标创建错误；不带该开关的 configure 行为与上游完全一致。
```

**验证**:
```
任意 llvm-project checkout 定位无条件回置：grep -n -A3 'Keep track if we have all dependencies' openmp/cmake/OpenMPTesting.cmake（预期：set(ENABLE_CHECK_TARGETS TRUE) 无 if(NOT DEFINED) 守卫）；定向复现（monorepo、从 llvm/ 父目录、不构建 clang 的上下文）：cmake -B /tmp/ovr-probe -S <llvm-project>/llvm -DLLVM_ENABLE_PROJECTS=openmp -DENABLE_CHECK_TARGETS=OFF -G Ninja → 预期 CMake Error at cmake/modules/AddLLVM.cmake:1962 (add_dependencies)：The dependency target "clang" of target "check-openmp" does not exist（调用栈经 OpenMPTesting.cmake:220/243，即 -D 覆盖已被回置丢弃）；应用 if(NOT DEFINED) 守卫补丁后同命令 configure 通过且不再创建依赖 clang 的 check-* 目标
```
