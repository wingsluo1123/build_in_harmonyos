# E2658: When an upstream CLI tool has no argument parser, smoke-test it with a bounded run instead of --help

## 基本信息
- **严重度**: 2
- **类别**: conan, runtime, testing
- **作者**: unknown

## 错误特征
```
conan create 卡在 test_package 不返回|--help 无任何输出且进程常驻|test 阶段超时被 KILL|g_main_loop_run 阻塞
```

## 根因分析
上游工具集项目里，很多 CLI 的 main() 根本没有参数解析

## 推荐方案
**方法**: bounded-run-assert-clean-exit

**说明**: application 型包（产物是 bin/ 下可执行文件）的

**修复命令**:
```
bash -c '"$BIN" & p=$!; sleep 3; if kill -0 $p 2>/dev/null; then kill -TERM $p; fi; wait $p; exit $?'
```
