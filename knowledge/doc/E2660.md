# E2660: 宿主工具链环境变量与构建工具同名变量静默错配：AR=llvm-ar 顶掉 Jam 的 `AR ?= ar rusc`，归档命令缺操作符导致全部 .a 失败

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, build-system, toolchain, conan
- **作者**: unknown

## 错误特征
```
llvm-ar: error: unknown option [a-zA-Z]|
```

## 根因分析
构建工具会把宿主环境里的同名工具链变量读成自己的配置，而宿主导出的

## 推荐方案
**方法**: sanitize-host-toolchain-env-vars

**说明**: 构建前剔除构建工具会隐式读取的宿主工具链变量

**修复命令**:
```
python: for v in ("AR","RANLIB","NM","STRIP","AS","LD","CFLAGS",
```

**验证**:
```
env | grep -E '^(AR|RANLIB|NM|STRIP|AS|LD|CFLAGS|LDFLAGS|CPPFLAGS)=' ;
```
