# E2661: Makefile 生成器把 per-target flags.make 随源码子目录分层存放，ABI 关键编译标志自检必须递归定位（单层 glob 漏检子目录目标 → 假阴性失败/假阳性放行）

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, make, fortran, conan
- **作者**: sea_crab（不知对不队）

## 错误特征
```
Fortran 编译标志中未见|flags.*未见|ILP64.*分支未生效|
```

## 根因分析
CMake Unix Makefiles 生成器为每个 target 生成

## 推荐方案
**方法**: target-whitelist-recursive-glob-fail-closed

**说明**: 按被审计目标白名单递归 glob **/CMakeFiles/<tgt>.dir/flags.make

**修复命令**:
```
blobs = {}
```

**验证**:
```
最小机理探针（任意临时目录，bash）：mkdir -p sub && cd 该目录；
```
