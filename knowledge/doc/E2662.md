# E2662: Poco 1.15 的 getChannel()/getFormatter() 返回 AutoPtr，static_cast 需先 .get()

## 基本信息
- **严重度**: 2
- **类别**: portability, conan, testing, cxx, poco
- **作者**: unknown

## 错误特征
```
cannot cast from type 'Channel::Ptr'|cannot cast from type 'Formatter::Ptr'|getChannel\(\)|getFormatter\(\)|static_cast<.*FormattingChannel\*>|static_cast<.*PatternFormatter\*>
```

## 根因分析
Poco 1.15 把 Logger::getChannel()、FormattingChannel::getChannel()、FormattingChannel::getFormatter() 的返回类型从裸指针改为 AutoPtr<T>（Channel::Ptr / Formatter::Ptr）。依赖旧版裸指针返回值的上游测试代码直接 static_cast<T*> 编译失败，属 Poco API 演进导致的消费者源码兼容问题，非平台缺陷。

## 推荐方案
**方法**: autoptr-return-value-dot-get-before-cast

```
cmake -S . -B build -DENABLE_TESTS=ON -DCMAKE_TOOLCHAIN_FILE=generators/conan_toolchain.cmake && cmake --build build -j4 && ./build/bin/easyhttp-UnitTestRunner
```
