# E2663: OHOS libc++ 不导出 LONG_LONG_MIN/MAX 传统宏，需从 <climits> 标准宏派生

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, testing, cxx, libcxx
- **作者**: unknown

## 错误特征
```
use of undeclared identifier 'LONG_LONG_MIN'|use of undeclared identifier 'LONG_LONG_MAX'|use of undeclared identifier 'ULONG_LONG_MAX'|LONG_LONG_MIN|LONG_LONG_MAX|ULONG_LONG_MAX
```

## 根因分析
上游测试代码使用 LONG_LONG_MIN/LONG_LONG_MAX/ULONG_LONG_MAX 传统宏（原代码仅对 Windows 分支定义）。OHOS libc++（musl 系）不在全局命名空间默认导出这组宏，与 glibc 行为不同，导致编译失败。C 标准规定名称是 LLONG_MIN/LLONG_MAX/ULLONG_MAX（<climits>）。

## 推荐方案
