# E2671: CMake find_package(X11) 在 OHOS 上需注入 4 制品 include 拼接与 .so 文件路径

## 基本信息
- **严重度**: 3
- **类别**: ohos, cmake, conan, dependency-injection, x11
- **作者**: unknown

## 错误特征
```
ld.lld: error: undefined symbol: XOpenDisplay|
```

## 根因分析
上游 CMakeLists.txt 用 find_package(X11 REQUIRED) 并消费

## 推荐方案
**方法**: cmake-x11-variable-injection

**说明**: conanfile.py generate() 中用 CMakeToolchain 注入：

**修复命令**:
```
conan create archives/c/clipboard_lite/3.4 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```

**验证**:
```
conan create archives/c/clipboard_lite/3.4 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
