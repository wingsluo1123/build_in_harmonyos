# E2677: 旧版 mapbox feature::value 按值访问器与 mapbox-geometry 2.x shared_ptr 语义不兼容的适配迁移

## 基本信息
- **严重度**: 3
- **类别**: compat, headers, build-system, conan, cxx
- **作者**: hmbs-executor
- **来源 PR**: pending

## 错误特征
```
no matching member function for call to 'is'|no matching member function for call to 'get'|variable 'valueObject' with type 'auto \*' has incompatible initializer|no matching function for call to object of type 'mapbox::geojson::to_value'
```

## 根因分析
geojson-cpp 0.5.1 面向旧版 mapbox-geometry（value 按值存 std::vector/unordered_map，variant is<T>()/get<T>() 可直用），而 ohpcd 已发布的 mapbox-geometry/2.0.3 将 value_base 的数组/对象改为 std::shared_ptr<std::vector<value>>/std::shared_ptr<std::unordered_map>（const_array_ptr_type/const_object_ptr_type），旧代码的 val.is<value::array_type>()、auto *valueObject = getObject()、to_value 访问器按值形参与 recursive_wrapper 断言全部失效

## 推荐方案
**方法**: mapbox-value-sharedptr-accessor-migration

**说明**: 对源码做最小访问器迁移：数组/对象存在性判断改用 val.getArray()/val.getObject() != nullptr；解引用 shared_ptr 取内容；to_value/convert 访问器形参改接 const_array_ptr_type/const_object_ptr_type；test.cpp 中旧 recursive_wrapper<values>/get<values> 断言改用 getArray()/getObject() 访问器（断言语义不变）

**修复命令**:
```
patches/0001-adapt-mapbox-geometry-2-value-abi.patch：改 include/mapbox/geojson_value_impl.hpp、include/mapbox/geojson_impl.hpp、test/test.cpp 三处访问器
```

**验证**:
```
conan create 通过 G2；build() 内上游 test_geojson(16)/test_geojson_value(14) 全过；test_package 消费者 4 断言过
```
