# E2678: flat conanfile 配方缺失 cpp_info.requires 转发导致下游 CMakeDeps 不生成传递依赖配置、消费者编译缺头文件

## 基本信息
- **严重度**: 2
- **类别**: headers, build-system, conan, packaging
- **作者**: hmbs-executor
- **来源 PR**: pending

## 错误特征
```
fatal error: 'mapbox/geometry.hpp' file not found|fatal error: '.*\.hpp' file not found|FIND_DEPENDENCY_NAMES.*empty|no matching package.*transitive
```

## 根因分析
配方 requirements() 声明了 mapbox-geometry/mapbox-variant/rapidjson 等头文件依赖，但 package_info() 未通过 cpp_info.requires 转发依赖目标；下游 test_package/消费者使用 CMakeDeps 时，geojson-cpp-config.cmake 的 FIND_DEPENDENCY_NAMES 为空，未 find_dependency(mapbox-geometry)，generators 目录甚至不生成 mapbox-geometry-config.cmake，消费者编译期无依赖 include 路径

## 推荐方案
**方法**: cppinfo-requires-forwarding-plus-explicit-test-requires

**说明**: package_info() 增加 self.cpp_info.requires = ["mapbox-geometry::mapbox-geometry", "mapbox-variant::mapbox-variant", "rapidjson::rapidjson"]（依赖的 cmake 包名::目标名），使 CMakeDeps 生成传递配置；test_package 同时显式 find_package 并链接全部传递依赖（与 mapbox-geometry 自身 test_package 同模式）

**修复命令**:
```
conanfile.py package_info() 声明 cpp_info.requires；test_package/CMakeLists.txt 显式 find_package(mapbox-geometry/mapbox-variant/RapidJSON) + target_link_libraries
```

**验证**:
```
conan create 内 test_package 编译通过；generators/ 目录出现 mapbox-geometry-config.cmake 与 FIND_DEPENDENCY_NAMES 非空
```
