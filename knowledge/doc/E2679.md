# E2679: ohpcd openssl 配方只导出 openssl::openssl，上游 find_package(OpenSSL)/OpenSSL::Crypto 消费者需在 generate() 先重映射组件再生成 CMakeDeps

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, cross-compile, conan, security
- **作者**: pc3-7

## 错误特征
```
Target "\S+" links to:\s*\n?\s*OpenSSL::Crypto|Target "\S+" links to:\s*\n?\s*OpenSSL::SSL|OpenSSL::Crypto.*target was not found|OpenSSL::SSL.*target was not found|FATALCannot find OpenSSL|Cannot find OpenSSL, please check environment
```

## 根因分析
ohpcd openssl 配方的 package_info() 只声明包级目标 openssl::openssl（cmake_file_name=openssl），

## 推荐方案
**方法**: remap-openssl-components-before-cmakedeps

**说明**: 在 conanfile.py generate() 中，先把 openssl 依赖的 cpp_info 重映射为

**修复命令**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
