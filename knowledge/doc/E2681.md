# E2681: 单头文件 C 库把公开函数声明包在 `#if !defined(STATIC) || defined(IMPLEMENTATION)` 保护内，消费者测试若定义 STATIC 宏则声明区整体被隐藏，出现 implicit-function-declaration 警告仍可链接；消费者应直接 include 头文件并链接预编译库，不定义 STATIC/IMPLEMENTATION 宏

## 基本信息
- **严重度**: 3
- **类别**: portability, headers, api-visibility, single-header
- **作者**: unknown

## 错误特征
```
warning: call to undeclared function 'ClownResampler_.*'|implicit-function-declaration.*ClownResampler_|defined\(CLOWNRESAMPLER_STATIC\).*defined\(CLOWNRESAMPLER_IMPLEMENTATION\)
```

## 根因分析
单头文件库用 STATIC/IMPLEMENTATION 宏控制"声明 vs 定义"与符号可见性；

## 推荐方案
**方法**: consumer-include-without-config-macros（消费者仅 include 公开头、不定义内部配置宏）
