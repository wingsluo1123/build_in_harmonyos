# E2682: zmk 构建系统 OS.mk 用 uname -s 探测内核，HarmonyOS 未列入 ELF 内核列表，任何库在 make configure/make 阶段直接报 "unsupported operating system kernel HarmonyOS"；修复为把 HarmonyOS 加入 ELF 内核列表（或配方绕开 zmk 直接编译）

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, build-system, make, toolchain
- **作者**: pc2-7

## 错误特征
```
unsupported operating system kernel HarmonyOS|OS\.ImageFormat \?= \$\(error unsupported
```

## 根因分析
zmk（zyga/zmk，libzt 上游的定制 make 构建系统，GNUmakefile

## 推荐方案
**方法**: zmk-osmk-harmonyos-elf

**说明**: 将 HarmonyOS 加入 zmk/OS.mk 的 ELF 内核列表

**修复命令**:
```
sed -i 's/Linux FreeBSD NetBSD OpenBSD GNU GNU\/kFreeBSD SunOS
```

**验证**:
```
make configure 2>&1 | grep -E "unsupported operating system
```
