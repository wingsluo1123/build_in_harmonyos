# E2685: conan 2.x 在包根写入 conaninfo.txt/conanmanifest.txt 簿记文件，探针全树文件计数必须排除（真机 2 内容文件 + 2 簿记 = 4 ≠ 2 FAIL）

## 基本信息
- **严重度**: 1
- **类别**: ohos, conan, packaging, testing, probe
- **作者**: unknown

## 错误特征
```
conaninfo.txt|conanmanifest.txt|包全树恰.*文件.*FAIL
```

## 根因分析
conan 2 create 会在 package_folder 根目录写入 conaninfo.txt 与 conanmanifest.txt 两个簿记文件；对包根做全树精确文件计数的消费者探针把簿记文件计入上游内容清单 → 计数偏大 FAIL。手工搭建的本机模拟包根没有簿记文件，所以本机全过、真机才暴露——「本机过、真机挂」的经典环境差。

## 推荐方案
**方法**: exclude-bookkeeping-in-count

**说明**: 探针递归计数函数跳过 conaninfo.txt/conanmanifest.txt（与配方 build() 防漂移计数口径一致）；completions/doc 等子目录本身不含簿记文件，子目录断言无需改变。

**修复命令**:
```
grep -n 'is_bookkeeping' test_package/*.cpp && conan create . --build=missing
```

**验证**:
```
conan create . --build=missing  # 真机 probe: [FAIL] 包全树恰 2 文件（4!=2）；计数排除簿记后 all assertions passed
```
