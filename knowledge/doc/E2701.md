## 基本信息
- **严重度**: P0

- **作者**: unknown

## 错误特征
```
"fft_backward.*FFT_SCALED_OUTPUT|roundtrip.*maxerr|forward.*backward.*n \\*|y\\[0\\]=1024"
```

## 根因分析
"FFTPACK rfftb 是非归一逆变换（rfftb(rfftf(x))==n*x），上游 fft-c 的 fft_backward 又在 SCALED 模式对结果乘 n，与前向除 n 叠加成双重缩放，往返放大 n 倍"

## 推荐方案
**方法**: "删除 fft_backward 中 SCALED 分支的 input[i]*=n；反向不做缩放（rfftb(rfftf(x)/n)==x），并加注释记录 FFTPACK 非归一约定"
