## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, runtime, application, data-files
- **作者**: unknown

```
cannot open database.*food\.db|unable to open database file|
```

## 根因分析
上游 main.c 用编译期宏 GNUTRITION_DATADIR（= $datadir/gnutrition，

## 推荐方案
**方法**: in-app-env-override-with-default-fallback

**说明**: 应用源码里把数据路径改为：getenv("GNUTRITION_DATADIR") 非空则用之，

**修复命令**:
```
|
```

**验证**:
