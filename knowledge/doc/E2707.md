# E2707: dotted-name-test-package-class-sanitize

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, testing
- **作者**: unknown

## 错误特征
```
SyntaxError: invalid syntax|class Levenshtein\.CTestConan|Unable to load conanfile.*test_package.*SyntaxError
```

## 根因分析
conan-init 的配方模板把包名中的 '.' 原样带入 Python 类名占位

## 推荐方案
**方法**: dotted-name-test-package-class-sanitize

**说明**: conan-init 后检查 test_package/conanfile.py 类名，若类名含点号

**修复命令**:
```
手动编辑 test_package/conanfile.py，类名替换 '.' → ''；随后重跑
```
