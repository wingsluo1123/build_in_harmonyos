# E2712: 上游头文件无条件 include Windows 专用 sal.h 时，非 MSVC 工具链用条件包含 + 就地 SAL 注解空宏 shim

## 基本信息
- **严重度**: 3
- **类别**: platform, portability, headers, annotation, windows-sdk
- **作者**: unknown

## 错误特征
```
fatal error: 'sal.h' file not found|DirectXMath\.h:[0-9]+:.*sal\.h
```

## 根因分析
上游 C/C++ 头文件把 Windows SDK 专属注解头（sal.h，Microsoft Source Annotation Language）作为必选 include 无条件引入，未提供非 MSVC 工具链替代路径；clang/gcc（Linux/OHOS）include 路径无 sal.h 即编译失败。官方 README（DirectXMath）亦要求非 Windows 平台自行提供 sal.h。

## 推荐方案
**方法**: conditional-include-plus-inline-sal-shim

**说明**: 补丁把 `#include "sal.h"` 改为 `#if defined(_MSC_VER)` 才 include，否则就地定义库内实际用到的全部 SAL 注解宏为空宏（纯注解无代码生成语义，空展开等价）；宏清单按库实际用法枚举（directxmath 3.21 共 10 个：_In_/_In_reads_/_In_reads_bytes_/_Out_/_Out_opt_/_Out_writes_/_Out_writes_bytes_/_Success_/_Use_decl_annotations_/_Analysis_assume_）。

**修复命令**:
```
patch: #if defined(_MSC_VER) #include "sal.h" #else #define _In_ ... #endif；conanfile.py build() 用 apply_conandata_patches；conandata.yml 声明 patches 条目（patch_type: portability）
```

**验证**:
```
conan create -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing 退出码 0；test_package 消费者编译链接运行通过（4 项公开 API 断言）；test_ohos 5 项鸿蒙检查（ELF64 AArch64/musl/.codesign/无宿主路径/真实 SIMD 计算）全过。
```
