# E2713: 真机 shadow CI G0e 按 git 索引（`git ls-files`）查根目录白名单：--repo-source 连带继承上游 repo 的暂存文件，工作区干净仍被拦

## 基本信息
- **严重度**: 2
- **类别**: environment, g0e, git-index, shadow-ci, whitelist
- **作者**: unknown

## 错误特征
```
G0e:.*根目录存在非白名单文件|
```

## 根因分析
build_and_test.sh 的 G0e 门禁用 `git ls-files --full-name |

## 推荐方案
**方法**: git-rm-cached-in-job-copy

**说明**: 在 job 的 repo 副本里把残留条目从索引摘除（只动本地副本，

**修复命令**:
```
export PATH=/data/service/hnp/bin:$PATH; cd <job_repo_root> && git rm --cached <file> && git ls-files --full-name | grep -v '/'
```
