# E2715: "Precheck right after job creation and before the first run:

## 基本信息
- **严重度**: P2
- **类别**: conan\, device-ci\, shadow-ci\, workflow
- **作者**: unknown

## 错误特征
```
"can't open input file.*ci/conan/build_and_test|exit-code.txt: 127|zsh.*can't open input file"
```

## 根因分析
"ohos-prepare-isolated-conan-job.sh --repo-source copies the source repo AS-IS into the new job. If the chosen source job's repo was pruned (some device jobs keep only root md files + archives/, without ci/ scripts/ knowledge/ etc.), the new job's repo lacks ci/conan/build_and_test.sh. The runner then fails before doing any real work: run-conan-heavy.sh → zsh ci/conan/build_and_test.sh <package> → 'can't open input file' → exit 127 with empty client stdout, after the device lock was already acquired."

## 推荐方案
**方法**: "Precheck right after job creation and before the first run: 'ls <ci_repo_root>/ci/conan/build_and_test.sh'. If missing, copy the missing top-level dirs (ci config docs knowledge references scripts templates) device-side with cp -r from a job whose repo is known-complete, without touching archives/<own package>, then rerun the same run-conan-heavy.sh. Related ops traps: background device loops via 'nohup ... >/dev/null 2>&1 &' still hold the ssh channel open unless stdin is redirected with </dev/null; after pkill the ssh client may return 255 with no output even though the kill succeeded — confirm with a fresh ps instead of re-killing."
