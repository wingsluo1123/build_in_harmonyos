# E2717: libtool 1.5.22 生成脚本在 OHOS bash 缺 $echo / $tool_oldlib 导致 make 失败

## 基本信息
- **严重度**: 2
- **类别**: autotools, toolchain, conan, libtool
- **作者**: unknown

## 错误特征
```
X--tag=CC: command not found|libtool: ignoring unknown tag|ranlib.*Usage: ranlib|cannot infer operation mode from.*clang|tool_oldlib
```

## 根因分析
2005 年 libtool 1.5.22 ltmain.sh 生成的 libtool 脚本大量使用

## 推荐方案
**方法**: patch-generated-libtool

**说明**: 对生成的 libtool 加 echo='echo'、sharedlib_from_linklib_cmd=echo、

**修复命令**:
```
|
```

**验证**:
```
conan-verify <pkg> <ver>  G2 conan create 通过;
```
