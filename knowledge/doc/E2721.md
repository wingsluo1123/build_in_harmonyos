# E2721: "Gate the x86 SIMD code behind `#if defined(__SSE2__)` and p

## 基本信息
- **严重度**: P1
- **类别**: compat, asm, simd
- **作者**: unknown

## 错误特征
```
"This header is only meant to be used on x86 and x64 architecture"
```

## 根因分析
"Vendored C sources include x86-only SIMD headers (<emmintrin.h>/<xmmintrin.h>/<mmintrin.h>) unconditionally, so on aarch64 (OHOS/HarmonyOS PC) the compiler stops with 'This header is only meant to be used on x86 and x64 architecture' before any source error appears. Here ksw.c (fermi-lite 0.1 bundled klib ksw, 2011 Attractive Chaos code) has no portable fallback at all: the whole alignment kernel is SSE2-only."

## 推荐方案
**方法**: "Gate the x86 SIMD code behind `#if defined(__SSE2__)` and provide portable scalar implementations of the same kernel for the `#else` branch (ksw_qinit/ksw_u8/ksw_i16 in this case). Keep the original SSE2 code untouched under the guard so x86 builds stay identical. Verify by building libfml.a and running the upstream sample (fml-asm test/MT-simu.fq.gz) plus the conan create test_package that actually calls fml_assemble()."
