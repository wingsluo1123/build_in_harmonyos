# E2722: "Change the header to a pure declaration (`extern const uint

## 基本信息
- **严重度**: P1
- **类别**: headers, linking, c
- **作者**: unknown

## 错误特征
```
"ld.lld: error: duplicate symbol: rle_auxtab"
```

## 根因分析
"A header file declares a non-static const array as a tentative definition (`const uint8_t rle_auxtab[8];` in rle.h). Every translation unit that includes the header emits its own common symbol; with modern Clang's default -fno-common the linker sees multiple strong definitions and fails with `duplicate symbol`. In fermi-lite 0.1 the symbols collide when linking fml-asm (misc.o/rope.o/rle.o all include rle.h)."

## 推荐方案
**方法**: "Change the header to a pure declaration (`extern const uint8_t rle_auxtab[8];`) and keep the single definition in exactly one .c file (rle.c). No ABI or behavior change; the object layout stays identical."
