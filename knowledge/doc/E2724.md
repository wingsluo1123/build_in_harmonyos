# E2724: 公开头文件在平台宏（#ifdef LINUX/UNIX）下才定义类型，消费者 include 无宏报 unknown type name；需 cpp_info.defines 导出与库编译一致的宏

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, build-system, conan, flags
- **作者**: pc4-4
- **来源 PR**: TBD

## 错误特征
```
error: unknown type name '[A-Za-z_][A-Za-z0-9_]*'|
```

## 根因分析
1990s-2000s 老式 C/C++ 库的公开头文件习惯用

## 推荐方案
**方法**: cpp-info-defines-export

**说明**: 配方 package_info() 用 self.cpp_info.defines 导出与库编译一致的

**修复命令**:
```
self.cpp_info.defines = ["UNIX", "LINUX"]
```

**验证**:
```
conan create archives/f/fyba/4.1.1 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
