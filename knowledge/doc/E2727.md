# E2727: OHOS libc++ 无 std::execution 并行执行策略：C++17 header-only 库

## 基本信息
- **严重度**: 2
- **类别**: ohos, headers, compiler, conan, libcxx
- **作者**: pc7-10
- **来源 PR**: <ctrack-1.1.0-pr-number>

## 错误特征
```
no member named 'execution' in namespace 'std'|
```

## 根因分析
OHOS SDK（ohos-sdk_26.0.0.18）自带的 libc++ 实现

## 推荐方案
**方法**: upstream-official-disable-macro-via-cpp_info-defines

**说明**: 检查上游是否已有官方禁用宏（ctrack 为

**修复命令**:
```
self.cpp_info.defines = ["CTRACK_DISABLE_EXECUTION_POLICY"]
```

**验证**:
```
cd <build> && clang++ -std=c++17 -O2 \
```
