# E2728: "test_package 等 shell 测试脚本避免一切进程替换：哈希比对改为「命令替换取哈希列 + 纯字符串比较」

## 基本信息
- **严重度**: 2
- **类别**: ohos, testing, shell, test-infrastructure
- **作者**: unknown

## 错误特征
```
"cat: /dev/fd/[0-9]+: Permission denied|/dev/fd/[0-9]+: Permission denied|diff: .*No such file or directory"
```

## 根因分析
"bash 进程替换 <(...) 依赖重开 /dev/fd/N 匿名管道描述符；OHOS 的 /dev/fd 仅 0/1/2 等常规描述符可重开，高编号管道 fd 的重开被沙箱/文件系统拒绝（Permission denied 而非 ENOENT）。这与 operations/filesystem-analysis.md 中 '/dev/stdin, /dev/fd | ✅ | 一致' 的记录矛盾——该结论未覆盖进程替换产生的高编号管道 fd 场景。"

## 推荐方案
**方法**: "test_package 等 shell 测试脚本避免一切进程替换：哈希比对改为「命令替换取哈希列 + 纯字符串比较」——ACTUAL=$( (cd \"$D\" && sha256sum f1 f2 ...) | awk '{print $1}' )；[ \"$ACTUAL\" = \"$EXPECTED\" ]，不依赖 diff、不依赖 <(...)（临时文件可写入可写 cwd 亦可，但字符串比较最简）。Windows GNU sha256sum 的 * 前缀与 OHOS 无前缀差异均经 awk '{print $1}' 归一。"
