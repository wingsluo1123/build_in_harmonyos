# E2734: Conan 2 CMake.build() 不支持 jobs 关键字：用 CMAKE_BUILD_PARALLEL_LEVEL 控制并行度

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan
- **作者**: unknown

## 错误特征
```
TypeError: CMake\.build\(\) got an unexpected keyword argument 'jobs'|cmake\.build\(jobs
```

## 根因分析
Conan 2 的 conan.tools.cmake.CMake.build() API 不接受 jobs 参数

## 推荐方案
**方法**: cmake-toolchain-parallel-level

**说明**: build() 移除 jobs 关键字，仅 cmake.build()；并行度在 generate() 的

**修复命令**:
```
conanfile.py: generate() 中 tc.variables["CMAKE_BUILD_PARALLEL_LEVEL"]="1"；
```

**验证**:
```
conan create archives/l/lsd2/1.9.9 -pr:h=ci/conan/profiles/ohos-aarch64 \
```
