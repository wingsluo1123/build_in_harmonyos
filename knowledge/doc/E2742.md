# E2742: 头文件门控的 inline 公开 API：库头文件在 #ifdef <宏> 内才声明函数，

## 基本信息
- **严重度**: 2
- **类别**: headers, conan, defines, fixed-point, inline
- **作者**: pc4-47

## 错误特征
```
implicit declaration of function.*f_add|
```

## 根因分析
公开 API 的存在性由编译宏门控（fixed_point.h 仅在 FXP_C99_INLINE 定义时

## 推荐方案
**方法**: inline-gated-api-defines-injection

**说明**: 在 package_info() 中注入与上游默认一致的门控宏:

**修复命令**:
```
self.cpp_info.defines = ["FXP_C99_INLINE"]
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
