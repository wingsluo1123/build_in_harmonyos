# E2746: 制品仓家族版本离散时：在售低版本配方（kio/6.14.0）+ 其依赖族全量 override=True 升钉统一家族（KF6 6.18.0）——升钉方向为唯一安全方向（已安装 configs 的 find_dependency 请求 <= 图内实际版本），反向降钉 configure 必败

## 基本信息
- **严重度**: 3
- **类别**: conan, packaging, dependency-closure, versioning
- **作者**: GoliWie
- **来源 PR**: 未合并（分支 feat/kjumpingcube-26.04.0，run kjumpingcube-26.04.0）

## 错误特征
```
Version conflict: Conflict between .*/.* and .*/.* in the graph|Conflict originates from
```

## 根因分析
制品仓（ohpcd）各包版本演进不同步：目标家族统一版本未必存在（kio 只有 6.14.0/6.26.0，KF6 闭包锁 6.18.0——kconfigwidgets/kiconthemes 等无 6.26.0 在售，6.26.0 不可选）。两阶段失败面：(1) 图解析期——消费方配方与在售低版本配方对同一包声明不同精确版本时 conan 直接报 "Version conflict: Conflict between kitemviews/6.18.0 and kitemviews/6.14.0 in the graph"，不自动择优；(2) 配置期——即便绕过 (1)，被消费包已安装 CMake config 内嵌 find_dependency(KF6Xxx <构建时 KF_DEP_VERSION>)，方向判据：请求 ">= 6.14" 而图内 6.18.0 → 满足（升钉安全）；请求 6.26 而图内只有 6.18 → configure 失败（降钉不可行）。KF6 大版本内 ABI 稳定是升钉前提，跨大版本不得升钉

## 推荐方案
**方法**: direct-require-in-sale-version-and-override-its-family-pins-up-to-uniform-family

**说明**: 三步法（升钉方向为唯一安全方向）：(1) 选基础版本——候选家族版本里取"在售且其传递闭包可被钉齐"的版本（kio/6.14.0 而非 6.26.0），判据=对每个二级依赖问"升钉目标家族是否有售"；(2) 全族 override——消费方配方对该低版本配方钉扎的每一个家族包显式 self.requires("<pkg>/<统一版本>", override=True)，override=True 语义为"整图强制此版本"，压过任意下游/传递的精确声明（本例 18 个包升至 6.18.0；仅被低版本配方独占、无对撞的传递依赖如 libxml2/2.15.3 留在原版本）；(3) 方向校验——逐个核对被消费包已安装 configs 的 find_dependency 版本请求全部为 ">= 升钉前版本"（KF 框架 config 以构建时 KF_DEP_VERSION 请求下限），跨大版本不得升钉。另注：同版本多 revision 在制品仓不支持（R37/409），配方内容变更必须递增版本号后缀（libkdegames/26.04.0.1 即此规则产物），与本条的家族钉扎正交

**修复命令**:
```
冲突面定位（不设 override 时）：conan graph info <consumer_recipe_dir> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 | grep -E "Version conflict|Conflict originates"；修复后图核对：conan graph info 同参数 | grep -oE "(kio|kservice|solid|kbookmarks|kwindowsystem|kauth)/[0-9.]+" | sort -u（应单版本化）；钉扎面核对：grep -c "override=True" <consumer_recipe_dir>/conanfile.py
```

**验证**:
```
在不含 override 的消费者配方副本上 conan graph info（同 profile）应复现 "ERROR: Version conflict: Conflict between kitemviews/6.18.0 and kitemviews/6.14.0"；补齐 override=True 钉扎后重跑 graph info 应无 Version conflict 且二级家族包版本全部归一到统一版本；grep -c "override=True" conanfile.py 应等于家族钉扎数（本例 18）；conan create --build=missing 全图构建通过
```
