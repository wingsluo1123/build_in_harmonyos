# E2747: make.sh 系 uname 平台探测在 HarmonyOS 落空——配方内显式

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, ohos, portability, make
- **作者**: pc2-15

## 错误特征
```
uname -s.*HarmonyOS.*OS_UNKOWN|
```

## 根因分析
FastDFS 家族的 make.sh 用 `uname -s` 做平台分支枚举

## 推荐方案
**方法**: replicate-makesh-render-in-recipe

**说明**: 不直接运行 make.sh：在 conanfile.py build() 中①显式生成

**修复命令**:
```
save(src/_os_define.h, _OS_DEFINE_H)
```

**验证**:
```
conan create archives/l/libfastcommon/1.0.88
```
