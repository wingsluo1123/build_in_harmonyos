# E2748: glibc 专有 struct stat 纳秒字段在 OHOS musl 缺失——

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, musl, glibc-isms, struct-stat
- **作者**: pc2-15

## 错误特征
```
no member named 'st_atimensec'|
```

## 根因分析
glibc 的 struct stat 提供 st_atimensec/st_mtimensec/

## 推荐方案
**方法**: use-posix-tv-nsec

**说明**: 将 glibc 专有字段 st_atimensec/st_mtimensec/st_ctimensec

**修复命令**:
```
st.st_atim.tv_nsec  # 替代 st.st_atimensec
```

**验证**:
```
clang -c test.c  # 含 st_atimensec 的源码 → no member named
```
