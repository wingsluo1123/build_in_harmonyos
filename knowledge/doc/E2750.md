# E2750: 上游测试脚本 file(DOWNLOAD) 固定 SHA-256 过期导致 cmake configure 失败——用双路径交叉验证更新 pin

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan, testing, download
- **作者**: unknown
- **来源 PR**: (pending) feat/c89stringutils-0.0.2

## 错误特征
```
SHA256 hash verification failed for .*\.h|greatest\.h|file\(DOWNLOAD\).*sha256|hash verification failed.*!=
```

## 根因分析
上游项目在测试 CMakeLists 里用 file(DOWNLOAD) 拉取测试专用头文件

## 推荐方案
**方法**: update-stale-pin-with-cross-verified-hash

**说明**: 先用至少两条网络路径（官方直连 + 镜像）下载同一文件并比对 SHA-256，

**修复命令**:
```
patches/0001-*-CMakeLists.txt.patch 更新 GREATEST_SHA256 等固定值；
```

**验证**:
```
curl -fsSL <URL> | sha256sum    # 至少两条网络路径（直连+镜像）比对
```
