# E2752: conan 2 在 build() 前向 source folder 注入 6 个聚合环境文件（conanbuild.sh/conanrun.sh/conanbuildenv-*.sh/conanrunenv-*.sh/deactivate_*.sh），配方内文件计数类漂移守卫必须排除 .sh 与簿记文件（真机 G2 首验 FAIL：23 != 17 实证）

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, conan, drift-guard, pure-data
- **作者**: unknown

## 错误特征
```
total file count N != M (N = M + 6)
```

## 根因分析
conan 2 执行 build() 前在 source folder 根生成聚合环境文件（conanbuild.sh、conanrun.sh 及 conanbuildenv-*/conanrunenv-*/deactivate_* 变体，共 6 个，日志可见 "Generated aggregated env files"）。纯数据包范式（kicad-demos 先例）常用「全树文件总数 == 上游 tarball 计数」的防漂移守卫，该守卫把注入文件也计入 → 真机计数 = 上游数 + 6，误报 Invalid configuration。本机 conan 同样注入，但纯数据包常在本机用「手工模拟源目录」预演（无 conan 构建），故守卫本机不炸、真机必炸——典型环境差。

## 推荐方案
**方法**: exclude-env-and-bookkeeping

**说明**: 计数守卫排除 conan 注入物：排除 *.sh（注入的环境文件全部是 .sh）+ conaninfo.txt/conanmanifest.txt 簿记；同时保留「载荷文件在位」存在性检查（防漂移的主体仍是载荷文件本身）。fabric-completion 先例即此口径。

**修复命令**:
```
total = sum(1 for _,_,fs in os.walk(self.source_folder) for f in fs if not f.endswith('.sh') and f not in ('conaninfo.txt','conanmanifest.txt'))
```

**验证**:
```
conan create archives/…/<pkg>/<ver> -pr:h … -pr:b … --build=missing  # 真机复现：source folder 17 文件 + 6 注入 = 23；修复后重验八门禁全绿
```
