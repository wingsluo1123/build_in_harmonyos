# E2756: HarmonyOS Python 3.12+ CLI ports must replace removed APIs and verify the installed entry point

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability, python, testing
- **作者**: 328

## 错误特征
```
No module named ['"]imp['"]|AttributeError: .*readfp|ModuleNotFoundError: No module named ['"]jinja2['"]|j2 --version
```

## 根因分析
Python 3.12 removes the legacy imp module, while older CLIs can also rely on removed ConfigParser.readfp

## 推荐方案
**方法**: python-cli-runtime-and-entrypoint-contract

**说明**: Replace imp.load_source with importlib.util.spec_from_file_location/module_from_spec/exec_module;

**修复命令**:
```
python3 -m unittest <upstream test module>; <package>/bin/j2 --version; <package>/bin/j2 --format=json <template> <data>
```

**验证**:
```
python3 -c 'import imp' should fail on CPython 3.12+; after port run the complete upstream unittest suite,
```
