# E2761: A PyPI wheel can omit the upstream suite that is present in the same version's sdist

## 基本信息
- **严重度**: 1
- **类别**: portability, python, packaging, testing
- **作者**: 328

## 错误特征
```
collected 0 items|tests not found|source distribution.*tests
```

## 根因分析
PyPI wheel and source distribution are separate artifacts built with different inclusion rules; choosing the runtime wheel as the only test input can remove the upstream suite.

## 推荐方案
**方法**: inspect-sdist-before-test-accounting

**说明**: Inventory the exact source archive and run its upstream tests before packaging runtime-only module files.

**修复命令**:
```
sha256sum package.tar.gz; tar -tzf package.tar.gz | grep '/tests/'; python -m pytest tests/ -q
```

**验证**:
```
python -c "import zipfile,tarfile; print('wheel tests', ...); print('sdist tests', ...)"; python -m pytest tests/ --collect-only -q
```
