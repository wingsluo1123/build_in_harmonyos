# E2764: Meson 在 OHOS 无头设备上缺 meson 可执行入口与 pkgconf 二进制名差异的修复模式

## 基本信息
- **严重度**: 3
- **类别**: ohos, meson, conan, pkg-config, headless-toolchain
- **作者**: gcw_6YxinkyD
- **来源 PR**: TBD

## 错误特征
```
meson: inaccessible or not found|Found pkg-config: NO|Pkg-config for machine host machine not found|unable to make temporary file: Read-only file system
```

## 根因分析
OHOS 构建机只把 meson 装成 python 模块（无 console script meson），且系统不带 pkg-config 二进制；PkgConfigDeps 只在 generators/ 生成 .pc 并设 PKG_CONFIG_PATH，并不提供 pkg-config 可执行程序；ohpcd 的 pkgconf/3.0.5 包提供的二进制名为 pkgconf 而非 pkg-config，meson 默认按 pkg-config 查找，必须用 PKG_CONFIG 环境变量显式指向；另 OHOS /tmp 只读，clang 写临时文件失败需 TMPDIR 指向 $HOME/tmp。

## 推荐方案
**方法**: tool-requires-pkgconf-plus-PKG_CONFIG-env

**说明**: build_requirements() 里 tool_requires("pkgconf/<ver>") 提供 pkg-config 二进制；generate() 里 PkgConfigDeps + MesonToolchain 后设 os.environ["PKG_CONFIG"]="pkgconf"；设备 PATH 上补 meson 包装（exec python3 -m mesonbuild.mesonmain "$@"）；构建时 export TMPDIR=$HOME/tmp 并限 NINJAFLAGS=-j<N>。

**修复命令**:
```
self.tool_requires("pkgconf/3.0.5"); PkgConfigDeps(self).generate(); MesonToolchain(self).generate(); os.environ["PKG_CONFIG"]="pkgconf"; export TMPDIR=$HOME/tmp
```

**验证**:
```
conan create 成功（meson setup + ninja + install）；test_package 两个 C 消费者真机运行通过（init 版本串断言 + 查询 API 优雅降级）；libtypec.so 加载器接受。
```
