# E2765: Meson未安装静态库默认thin归档致消费者链接断裂的install:true根治与ar重打兜底

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 13083

## 错误特征
```
could not get the buffer for a child of the archive|Unknown option: b_thin_archives
```

## 根因分析
Meson大于等于0.60对未安装静态库默认产出thin归档成员为相对引用配方仅拷贝单文件进包致消费者ld.lld引用悬空属构建系统通用行为缺陷非单库源码问题

## 推荐方案
**方法**: install-true-plus-ar-repack

**说明**: 补丁给static_library加install:true使Meson直接产出完整归档package以8字节魔数判定thin命中则收集同级目标对象目录用已探测archiver执行ar重打完整包后拷贝到lib

**修复命令**:
```
patches/0001-use-prebuilt-flash-driver.patch追加install:true第二hunk；conanfile.py删除b_thin_archives下发保留魔数判定加ar重打兜底；manifest.yaml同步知识条目
```

**验证**:
```
真机conan create全链路验证由62231的ld.lld断裂推进到62646编译通过test_package进入后续ctest阶段确认完整归档产出
```
