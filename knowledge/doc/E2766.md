# E2766: protobuf 33.x 将 JsonPrintOptions::always_print_primitive_fields 更名为 always_print_fields_with_no_presence — 下游源码需同步改名

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, api-rename, protobuf, source-patch
- **作者**: unknown

## 错误特征
```
no member named 'always_print_primitive_fields' in 'google::protobuf::json::PrintOptions'|PrintOptions.*always_print|json_util.h
```

## 根因分析
上游业务代码（此处 src/client.cpp）在构造 google::protobuf::util::JsonPrintOptions 时设置 always_print_primitive_fields = true。protobuf 33.x 的 json/json.h 中该字段已不存在，改名为 always_print_fields_with_no_presence（语义等价：始终打印无 presence 语义的字段，包括零值与空列表/映射）。google/protobuf/util/json_util.h 只是 using 别名转发到 google::protobuf::json::PrintOptions，因此编译期直接报 "no member named ..."。制品仓 protobuf/33.6 即该版本，且 grpc/1.84.0 精确 pin 33.6（33.6.1 会版本冲突），无法回避。

## 推荐方案
**方法**: portability-patch

**说明**: 以补丁把旧字段名替换为新名（options.always_print_fields_with_no_presence = true）。语义一一对应，不改变输出行为；保持补丁可移植、不引入平台宏（R8）。

**修复命令**:
```
sed 语义等价替换: options.always_print_primitive_fields -> options.always_print_fields_with_no_presence
```

**验证**:
```
conan create archives/k/kylin-ai-document-service/1.2.0.0 --build=kylin-ai-document-service/*
```
