# E2767: Release/NDEBUG 下 test_package 测试仅靠 assert 承载正确性被剥离成空壳校验

## 基本信息
- **严重度**: 3
- **类别**: cmake, conan, testing, quality-gate
- **作者**: pc2-23-executor
- **来源 PR**: 11991

## 错误特征
```
NDEBUG.*assert.*stripped|assert_only_vacuous_check|Release.*build_type.*Release.*test.*return 0|test_package.*assert.*no.*fail.*path|checks=.*failures=0
```

## 根因分析
测试入口唯一正确性校验由 assert 承载, Release(-DNDEBUG) 构建下 assert 被编译剥离, 校验失败静默通过, main() 恒 return 0, 等同伪造通过; test_package/CMakeLists.txt 无 -UNDEBUG/target_compile_options 补偿。

## 推荐方案
**方法**: unconditional-check-nonzero-exit

**说明**: 用不随 NDEBUG 失效的 CHECK(cond,what,expected,actual) 宏替代 assert, 校验失败打印 FAIL: <字段> expected=... actual=... 并累计失败数, main() 末尾 failures!=0 时 return 1; 校验结果必须被分支依赖防优化器消除; 字节完整性按序列化实际写入字节(逐字段 sizeof 之和)而非 sizeof(结构体); 覆盖项数不得少于改造前。

**修复命令**:
```
'#define CHECK(cond,what,e,a) do { ++g_checks; if (!(cond)) { ++g_failures; std::cerr << "FAIL: " << what << " expected=" << e << " actual=" << a << "\\n"; } } while (0)'
```

**验证**:
```
grep -c 'assert(' <test>.cpp; 负向对照: 复制源码注入错误期望值用 -O3 -DNDEBUG 编译运行须 exit 1 且 stderr 输出 FAIL:; 正向对照: 修复版同配置 exit 0 且日志打印 checks=N failures=0。
```
