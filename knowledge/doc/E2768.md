# E2768: use-sysroot-uapi-directly

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, headers, input
- **作者**: unknown

## 错误特征
```
fatal error: 'linux/uinput\.h' file not found|
```

## 根因分析
预期层知识(非缺陷): 迁移 uinput/evdev 类库时通常

## 推荐方案
**方法**: use-sysroot-uapi-directly

**说明**: 直接 #include <linux/uinput.h>(或让上游原样编译),

**修复命令**:
```
clang++ --target=aarch64-linux-ohos --sysroot=<sysroot> \
```

**验证**:
```
ls <sysroot>/usr/include/linux/{uinput,input,input-event-codes}.h
```
