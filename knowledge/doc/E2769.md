# E2769: 'ohc refresh-patch 重生成的补丁头路径深度随盘外探索目录布局在 a/Makefile 与 a/src/Makefile 之间翻转，且会把上一轮已正确的补丁覆盖成错的那一枚 ⇒ 探索目录须与目标树同构、让渡前须复验 head -2'

## 基本信息
- **严重度**: 2
- **类别**: conan, patch, harness, tooling
- **作者**: unknown

## 错误特征
```
'Apply patch.*Hunk FAILED|source/target file does not exist:|cannot find the file .*Makefile'
```

## 根因分析
refresh-patch 以「探索目录(工作副本) vs .orig」两棵树做 diff 来生成

## 推荐方案
**方法**: keep-explore-tree-isomorphic-and-recheck-header-before-handoff

**说明**: ①探索目录必须与目标 tarball 解包后的布局**同构**（目标在 `src/Makefile`

**修复命令**:
```
'python3 scripts/ohc-run.py finish <pkg> <ver> built && head -2 archives/<l>/<pkg>/<ver>/patches/*.patch && git ls-files -o --exclude-standard -- archives/<l>/<pkg> | wc -l'
```

**验证**:
```
'head -2 archives/<l>/<pkg>/<ver>/patches/*.patch   # 两行路径深度须与目标树一致'
```
