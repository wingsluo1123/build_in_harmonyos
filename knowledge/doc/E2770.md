# E2770: "Conan 配方 generate() 中从 self.dependencies['openssl'].cpp_inf

## 基本信息
- **严重度**: P1
- **类别**: build-system, cmake, conan
- **作者**: unknown

## 错误特征
```
"openssl/ssl.h: No such file or directory|OPENSSL_INCLUDE_DIR.*empty|pkg_check_modules.*OPENSSL|Select OpenSSL as the SSL backend.*fatal error"
```

## 根因分析
"上游 CMake 用 pkg_check_modules(OPENSSL openssl) 探测 OpenSSL 时, pkg-config 只设置复数变量 OPENSSL_INCLUDE_DIRS/OPENSSL_LIBRARIES, 但代码/子模块读取单数变量 OPENSSL_INCLUDE_DIR/OPENSSL_LIBRARIES（FindOpenSSL.cmake 风格）, 单数变量始终为空 → 编译缺头文件。"

## 推荐方案
**方法**: "Conan 配方 generate() 中从 self.dependencies['openssl'].cpp_info 显式注入单数变量: tc.variables['OPENSSL_INCLUDE_DIR']=include 目录, 同时注入 OPENSSL_LIBRARIES 指向 lib 目录, 再配合 CMAKE_INCLUDE_PATH/CMAKE_LIBRARY_PATH 供模块查找器使用。"
