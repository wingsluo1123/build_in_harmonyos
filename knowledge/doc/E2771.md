# E2771: "事件循环服务器库的 L1 消费者测试: ①服务器在主线程创建并 ev_run, 客户端请求放进独立 pthread（l

## 基本信息
- **严重度**: P1
- **类别**: testing
- **作者**: unknown

## 错误特征
```
"test hang|no output.*timeout|client.*recv.*block|EVBREAK|watchdog timeout fired|Server: .*Transfer-Encoding: chunked"
```

## 根因分析
"libuhttpd 类基于单线程事件循环（libev/libuv）的服务器库, test_package 若在主线程先发起客户端 HTTP 请求再 run loop, 客户端 recv 阻塞时会卡死事件循环无法 accept, 形成死锁; 且 chunked + Connection: close 响应在 recv 端可能不返回 EOF（连接保持打开）, 无 SO_RCVTIMEO 时 recv 无限期阻塞。"

## 推荐方案
**方法**: "事件循环服务器库的 L1 消费者测试: ①服务器在主线程创建并 ev_run, 客户端请求放进独立 pthread（libev 允许跨线程 ev_break）; ②connect 前对候选端口循环重试; ③socket 设 SO_RCVTIMEO 5s, recv 遇 EAGAIN/EWOULDBLOCK 视为响应已收完; ④ev_run 前挂 20s watchdog 定时器, 未通过即 ev_break 并报 watchdog 超时, 防测试无限挂起。"
