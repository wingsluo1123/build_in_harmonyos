# E2774: 静态 ncurses 应用仍需把 terminfo 数据依赖标为 Conan 运行依赖

## 基本信息
- **严重度**: 2
- **类别**: ohos, conan, application, runtime-resource, terminfo
- **作者**: tank_you

## 错误特征
```
TERMINFO is required for the ncurses termcap database|tinyirc: no termcap entry
```

## 根因分析
tinyirc 静态链接 libncursesw.a 只消除了动态库加载需求；终端能力仍从 ncurses 包的 share/terminfo 数据读取。Conan 应用默认依赖特性让下游测试图跳过 ncurses 包二进制，导致其 runenv_info 中的 TERMINFO 未注入。

## 推荐方案
**方法**: mark-static-dependency-runtime-when-it-owns-data

**说明**: 确认依赖包提供运行时数据库及 runenv_info；对应用显式 self.requires("ncurses/6.6", run=True)，让消费者图保留依赖包并由 VirtualRunEnv 注入 TERMINFO。再用安装后的包运行真实终端能力测试，而非只检查静态链接成功。

**修复命令**:
```
conan create archives/t/tinyirc/1.1.dfsg.1 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 -r=ohpcd --build=tinyirc/1.1.dfsg.1
```

**验证**:
```
conan create archives/t/tinyirc/1.1.dfsg.1 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 -r=ohpcd --build=tinyirc/1.1.dfsg.1
```
