# E2779: "worktree add --no-checkout 后，向 $(git rev-parse --git-dir)/i

## 基本信息
- **严重度**: P2
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"unable to create file .*\\?\\?: Invalid argument|Could not reset index file to revision 'HEAD'|sparse-checkout list shows C:/Program Files/Git/ prefix"
```

## 根因分析
"① origin/main 存在文件名含 \\r 控制字符的文件，Windows API 禁止创建，worktree 检出中途失败回滚；② Git Bash MSYS 路径转换把 sparse-checkout 的 / 开头排除模式改写成 C:/Program Files/Git/... 使规则失效。"

## 推荐方案
**方法**: "worktree add --no-checkout 后，向 $(git rev-parse --git-dir)/info/sparse-checkout 写入 /* 与 !/非法目录/（注意 worktree 的 .git 是文件，真实路径在主仓库 .git/worktrees/<名>/ 下），再 sparse-checkout reapply + checkout；给 git 传 / 开头参数时前置 MSYS_NO_PATHCONV=1 或直接写文件绕开命令行。"
