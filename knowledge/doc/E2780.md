# E2780: "直接 sh run-conan-heavy.sh，不再外包 runner/锁；监控与读日志用 codex-*<库名>*

## 基本信息
- **严重度**: P3
- **类别**: process
- **作者**: unknown

## 错误特征
```
"ls ohos-test-runs/codex-<lib>-*/ returns empty while a codex-<version>-<lib>-* run exists"
```

## 根因分析
"run-conan-heavy.sh 用 --lib $(basename CI_PACKAGES) 取到版本号，run 目录实为 codex-<版本>-<库名>-<task>-<时间戳>-<pid>；按 codex-<库名>-* 匹配扑空导致误诊。另：run-conan-heavy.sh 已内置 heavy 模式全局锁，外面包一层 ohos-test-runner.sh --lock 会双层加锁。"

## 推荐方案
**方法**: "直接 sh run-conan-heavy.sh，不再外包 runner/锁；监控与读日志用 codex-*<库名>* 宽匹配（ls -dt … | grep <库名>）；runner 级参数改 job 本地 env.sh/run-conan-heavy.sh 传入。"
