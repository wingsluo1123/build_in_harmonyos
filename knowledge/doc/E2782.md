## 基本信息
- **严重度**: P1
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"ci/conan/build_and_test.sh:[0-9]+: permission denied: git"
```

## 根因分析
"隔离 job 的 env.sh 把 $HOME/ohpc-ci-shadow/python-user/bin 放 PATH 首位，其 git shim 位于 /storage（HMDFS），分区不允许执行（避坑清单：HMDFS 无执行位），git 被 shim 遮蔽且 exec 被拒，G0e 的 git ls-files 直接失败。"

## 推荐方案
**方法**: "只改本 job 的 env.sh：export PATH=/data/service/hnp/bin:$PATH（非 HMDFS 分区，自带 git 2.45.x 可执行）；并确认 repo 带 .git。验证 command -v git 指向 /data/service/hnp/bin/git。"
