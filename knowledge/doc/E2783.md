# E2783: "OHOS 无需补丁（libc++ 不受影响）；libstdc++ 环境验证用 g++ -include cstdint

## 基本信息
- **严重度**: P2
- **类别**: portability
- **作者**: unknown

## 错误特征
```
"error: 'uint8_t' is not a member of 'std'; did you mean 'wint_t'?"
```

## 根因分析
"shrinkwrap 1.2.0 头文件使用 std::uint8_t/std::uint64_t 但不 include <cstdint>；libc++（OHOS）经 <array>/<vector>/<iostream> 传递引入所以能编译，libstdc++（g++）无传递包含直接失败。"

## 推荐方案
**方法**: "OHOS 无需补丁（libc++ 不受影响）；libstdc++ 环境验证用 g++ -include cstdint 绕过；根治为 5 个头文件各加 #include <cstdint>（可直接上游）。"
