# E2784: "generate() 双注入：tc.variables[CMAKE_LIBRARY_PATH]=各依赖 cpp_inf

## 基本信息
- **严重度**: P2
- **类别**: conan
- **作者**: unknown

## 错误特征
```
"fatal error: '<dep>.h' file not found|Could NOT find .* with bare find_library in upstream CMakeLists"
```

## 根因分析
"上游 CMake 项目（cget 风格）假设依赖装在系统前缀：裸 find_library 定位链接库 + 源码直接 #include 依赖头且不给目标加依赖 include 目录。Conan 依赖在各自包目录，链接定位与头文件定位两条链路同时断。"

## 推荐方案
**方法**: "generate() 双注入：tc.variables[CMAKE_LIBRARY_PATH]=各依赖 cpp_info.libdirs 分号串（find_library 命中）；tc.extra_cxxflags 逐个 -I 各依赖 includedirs（头文件命中）。勿覆盖 CMAKE_CXX_FLAGS（冲掉工具链 flags）。"
