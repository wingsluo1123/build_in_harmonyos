# E2785: "git worktree add --no-checkout 先建不检出的 worktree；sparse-check

## 基本信息
- **严重度**: P2
- **类别**: platform, git, msys, worktree
- **作者**: unknown

## 错误特征
```
"unable to create file.*Invalid argument|Could not reset index file to revision|\\\\r\\\\r|error: unable to create file.*patch"
```

## 根因分析
"origin/main 树上存在文件名含 CR 控制字符（\\r\\r）的 blob（archives/g/gama/2.29/patches/0002-dataparser-ungated.patch\\r\\r）。NTFS 文件名禁止 0x00-0x1F，Windows 全量检出在任何 git 版本/权限配置下都必败（unable to create file ... Invalid argument → fatal: Could not reset index file），主工作区 status 里该路径的常驻 ' D' 是同一根源。与磁盘、权限无关。"

## 推荐方案
**方法**: "git worktree add --no-checkout 先建不检出的 worktree；sparse-checkout set --no-cone '/*' '!archives/g/gama/2.29/patches/'（排除模式不要以 / 开头——Git Bash 的 MSYS 路径转换会把前导 / 改写成 Git 安装路径导致静默失效，同类坑还有 grep -v '/'，可用 awk -F/ 'NF==1' 替代）；再 git checkout 完成检出。sparse-checkout 是本地工作区过滤，不影响提交树与 PR。连带：失败重试前先 worktree prune + 删残留分支；libXext/libxext 大小写变体目录在不区分大小写文件系统上产生常驻伪 modified，提交时用显式 pathspec（git add archives/<首字母>/<库>）避免混入。"
