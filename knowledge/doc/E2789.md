# E2789: timeout 包装带变量赋值的 shell 测试命令时经 env 传递

## 基本信息
- **严重度**: 3
- **类别**: portability, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 13380

## 错误特征
```
timeout: failed to run command 'INSPIRCD_BIN=.*No such file or directory
```

## 根因分析
test_package 把 VAR=val 前缀直接拼在 timeout 之后，GNU timeout 直接 exec 首参而不理解 shell 变量赋值语义，把 INSPIRCD_BIN=...当可执行文件名；无 timeout 时 shell 可解析所以本地不易复现

## 推荐方案
**方法**: timeout-env-passthrough

**说明**: 拆分 env_prefix 与 shell 命令，有 timeout 时拼为 timeout 300 env VAR=... /bin/sh 脚本，无 timeout 时保持 VAR=... /bin/sh 原语义，仅改变命令转义方式不改变用例计数与断言

**修复命令**:
```
test_package/conanfile.py: 有 timeout 时拼为 timeout 300 env VAR=... /bin/sh test_inspircd.sh，timeout 路径优先 shutil.which 回退到 /data/service/hnp/bin/timeout 并做 shlex.quote
```

**验证**:
```
真机日志 timeout: failed to run command 行消失且 test()输出 RESULT 行，gate 通过；同一日志中 Package built 证明编译打包已过
```
