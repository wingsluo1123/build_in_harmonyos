# E2790: OHOS clang/libc++ 无 C++ TR1 头：pre-C++11 源码报 fatal error: 'tr1/xxx' file not found

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, compiler, c++11, libcxx
- **作者**: 主理-73

## 错误特征
```
fatal error: 'tr1/[a-z_]+'. file not found|
```

## 根因分析
2011 年前后（C++11 之前）的 C++ 源码常使用 TR1 扩展

## 推荐方案
**方法**: tr1-to-std-cpp11-modernization

**说明**: 纯文本语义等价替换（TR1 组件即 C++11 std 对应组件的

**修复命令**:
```
sed -i 's|std::tr1::|std::|g; s|tr1::|std::|g; s|<tr1/unordered_map>|<unordered_map>|g; s|<tr1/memory>|<memory>|g; s|<tr1/tuple>|<tuple>|g' <files...>
```

**验证**:
```
grep -rn "tr1" <src> --include=*.cpp --include=*.hpp | wc -l
```
