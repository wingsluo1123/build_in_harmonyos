# E2791: Makefile 顶层 SHELL 经 `command -v sh` 解析在 OHOS runner 上得到 `alias sh=sh`，导致所有 recipe 以非法 alias 前缀执行失败

## 基本信息
- **严重度**: 2
- **类别**: ohos, make, shell, build-env
- **作者**: unknown

## 错误特征
```
/bin/sh: alias: -c: invalid alias name|alias: -c: invalid alias name|SHELL := alias sh=sh|command -v sh.*alias
```

## 根因分析
部分上游 Makefile 用 `SHELL := $(shell env sh -c '...' command -v sh)`

## 推荐方案
**方法**: override-shell-at-invocation

**说明**: 构建/配方调用 make 时显式传 `SHELL=/bin/sh`，绕过 Makefile 内的

**修复命令**:
```
make -j1 SHELL=/bin/sh all
```

**验证**:
```
make -n 2>&1 | head -3   # 出现 alias: -c: invalid alias name 即命中；
```
