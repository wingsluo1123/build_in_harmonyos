# E2797: "In recipe generate(), explicitly bridge the old-style varia

## 基本信息
- **严重度**: P1
- **类别**: build-system
- **作者**: unknown

## 错误特征
```
"glib.h not found.*CMakeDeps|find_package.*GLIB2.*variable empty|glib2-config.*intercept"
```

## 根因分析
"CMakeDeps config package (glib2-config.cmake) intercepts find_package(GLIB2); the upstream old-style Find-module variables (GLIB2_INCLUDE_DIR/GLIB2_LIBRARIES) stay empty, so the build fails with glib.h not found."

## 推荐方案
**方法**: "In recipe generate(), explicitly bridge the old-style variables from the dependency cpp_info: aggregate glib include dirs into GLIB2_INCLUDE_DIR, set GLIB2_LIBRARIES=glib2::glib2 (INTERFACE target); for static deps set full archive paths (DB_INCLUDE_DIR/DB_LIBRARY=libdb.a). Same pattern applies to any upstream using old-style Find modules with CMakeDeps."
