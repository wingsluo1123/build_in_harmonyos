# E2798: "Use strip-level APIs for JBIG both ways: set TIFFTAG_ROWSPE

## 基本信息
- **严重度**: 2
- **类别**: testing, codec, consumer-api, libtiff
- **作者**: unknown

## 错误特征
```
"ISO JBIG scanline encoding is not implemented|ISO JBIG scanline decoding is not implemented|Unknown pseudo-tag 65538|Unknown pseudo-tag.*JPEGCOLORMODE"
```

## 根因分析
"libtiff's JBIG codec registers only strip-level entry points: tif_jbig.c installs encodestrip/decodestrip but leaves encoderow NULL, so TIFFWriteScanline falls into the _TIFFNoRowEncode fallback (tif_compress.c); decoderow keeps the _TIFFNoRowDecode stub from TIFFDefaultDirectory. The JBIG encoder additionally requires the whole image in exactly ONE strip (JBIGSetupEncode checks rowsperstrip==height). JPEG's JPEGCOLORMODE is a pseudo-tag registered by the JPEG codec itself, so it is unknown to the directory machinery until the codec is attached (write) or the directory is read (read); the error string is 'Unknown %stag' (tif_dir.c), so the literal tag number never appears in the message."

## 推荐方案
**方法**: "Use strip-level APIs for JBIG both ways: set TIFFTAG_ROWSPERSTRIP=height (single strip), allocate rowbytes*height, write with TIFFWriteEncodedStrip(t, 0, buf, n) and read with TIFFReadEncodedStrip(t, 0, buf, n). Set TIFFTAG_JPEGCOLORMODE AFTER TIFFTAG_COMPRESSION on write, and after the first TIFFGetField (which triggers the directory read) on read."
