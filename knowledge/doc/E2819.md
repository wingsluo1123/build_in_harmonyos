# E2819: OHOS toybox xargs 不按 POSIX 剥离参数引号，Gradle 官方 bin/gradle 启动脚本必然把 "-Xmx64m" 当主类名而无法启动——应绕过 shell 包装，直接 java -classpath <GRADLE_HOME>/lib/* org.gradle.launcher.GradleMain 启动

## 错误特征
```
Could not find or load main class.*"-Xmx|ClassNotFoundException: "
```

## 根因分析
Gradle 官方发行版 bin/gradle 的 JVM 参数重组管道在 OHOS 上被

## 推荐方案
**方法**: java-classpath-gradlemain-direct-launch

**说明**: 绕过 shell 包装，直接以 java 启动 GradleMain：

**修复命令**:
```
$JAVA_HOME/bin/java -Dorg.gradle.appname=gradle -classpath "$GRADLE_HOME/lib/*" org.gradle.launcher.GradleMain --no-daemon <tasks...>
```

```
# ① 症状复现（自包含，新 shell 可跑）
```
