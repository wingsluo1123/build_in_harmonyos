# E2820: BiSheng JDK 经 JAVA_TOOL_OPTIONS 注入 --add-opens 会直接拒启（Unrecognized option），JDK17 强封装豁免须写入 org.gradle.jvmargs 并同时放启动命令行；Kotlin ≤1.4 忽略 gradle.properties 的编译策略属性，in-process 须用命令行 -D 强制

## 基本信息
- **严重度**: 2
- **类别**: toolchain, java, gradle, jdk, kotlin
- **作者**: why6666666
- **来源 PR**: 合并后回填

## 错误特征
```
Unrecognized option: --add-opens|Could not create the Java Virtual Machine|InaccessibleObjectException|Unable to make protected void java\.util\.ResourceBundle\.setParent|kotlin.*daemon.*(crash|exit)
```

## 根因分析
两条独立工具链语义在"旧工具链 + 新 JDK"组合下叠加成障（真机

## 推荐方案
**方法**: jvmargs-and-cmdline-dual-add-opens + kotlin-inprocess-cli-d

**说明**: 双保险布局：

**修复命令**:
```
java --add-opens java.base/java.util=ALL-UNNAMED ... -Dkotlin.compiler.execution.strategy=in-process -classpath "$GRADLE_HOME/lib/*" org.gradle.launcher.GradleMain ...
```
