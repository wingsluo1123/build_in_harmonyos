# E2827: "将相关 Makefile.in 的 INCLUDES 改为 -I.. -I$(top_srcdir)（在生成的 Mak

## 基本信息
- **严重度**: P1
- **类别**: portability
- **作者**: unknown

## 错误特征
```
"fatal error: 'gsmlib/gsm_nls.h' file not found|INCLUDES = -I..|top_srcdir"
```

## 根因分析
"autotools 多目录工程（gsmlib/apps/tests/ext）的 Makefile.in 用 INCLUDES = -I..，in-tree 构建可解析自引用头 <lib/xxx.h>；但 Conan/out-of-tree（VPATH）构建时编译目录位于 build-release/<subdir>，-I.. 指向 build 而非源码根，导致 #include <gsmlib/...> 找不到。"

## 推荐方案
**方法**: "将相关 Makefile.in 的 INCLUDES 改为 -I.. -I$(top_srcdir)（在生成的 Makefile 中 top_srcdir 指向源码根），使 out-of-tree 构建下 <lib/...> 自引用头可解析。"
