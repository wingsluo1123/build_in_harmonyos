# E2828: "源码将标量 delete 改为 delete[]（配对修复）；用 ASAN/valgrind 复现定位；修复后重跑受影

## 基本信息
- **严重度**: P1
- **类别**: portability
- **作者**: unknown

## 错误特征
```
"alloc-dealloc-mismatch|operator delete\(void\*\).*operator new\[\]|delete _p;"
```

## 根因分析
"老 C++ 库（2003 年前后）用 new[] 分配数组却用标量 delete 释放（SMSDecoder 的 unsigned char* _p），在 clang/libc++ 下 ASAN 报 alloc-dealloc-mismatch；Release/NDEBUG 构建下此类错误表现为 SMS 解码测试运行期 SIGSEGV（139）。"

## 推荐方案
**方法**: "源码将标量 delete 改为 delete[]（配对修复）；用 ASAN/valgrind 复现定位；修复后重跑受影响测试。"
