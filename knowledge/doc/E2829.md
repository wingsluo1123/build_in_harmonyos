# E2829: "Runtime capability probe (PF5-compliant, no platform macro)

## 基本信息
- **严重度**: P1
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"os.mkfifo.*PermissionError.*EPERM.*HMDFS|mkfifo.*Operation not permitted.*storage"
```

## 根因分析
"HMDFS does not support POSIX named pipes (FIFO): os.mkfifo() raises EPERM on /storage HMDFS paths regardless of mode/permissions; upstream tools using mkfifo for inter-process streaming crash at startup."

## 推荐方案
**方法**: "Runtime capability probe (PF5-compliant, no platform macro): wrap mkfifo in try/except EPERM->fallback to plain temp files with equivalent data flow (extract fully first, then feed consumer); probe once per run and cache the decision. Reference impl: megahit 1.2.9 patch 0003 wrapper script."
