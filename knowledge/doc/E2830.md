# E2830: Automake联网阻塞测试超时124转FAIL保.trs落盘与动态定位install-sh覆盖残缺系统install

## 基本信息
- **严重度**: 3
- **类别**: ohos, network, build-system, autotools, testing
- **作者**: hmbs-executor
- **来源 PR**: 13393

## 错误特征
```
ftp-list\.log\] Error 124|install-sh not found|install-man1.*Error 64
```

## 根因分析
Automake并行harness对timeout kill的exit 124不写.trs致回退漏计，缺-k首FAIL即停无test-suite.log汇总；ftp-cls-l/ftp-list/http-get直连mirror.yandex.ru等公网无超时离线hang至Signal 9；OHOS toybox install缺-c致man页install-man1 Error 64且install-sh仅顶层查找未命中实际位置

## 推荐方案
**方法**: timeout-124-to-fail-with-trs-fallback-keep-going-and-install-sh-override

**说明**: 超时包装脚本将124转为普通FAIL保.trs落盘，-k跑完7项后优先test-suite.log无汇总时回退解析tests/*.trs的:test-result:行诚实记gaps继续打包；_find_install_sh多候选加浅层递归定位后以INSTALL覆盖残缺系统install

**修复命令**:
```
conanfile.py新增sh调用超时包装经TESTS_ENVIRONMENT挂载timeout 60转124为exit 1；make check改为-j1 -k；无汇总时解析tests/*.trs；_find_install_sh多候选查找后configure期export INSTALL与make install时INSTALL覆盖
```

**验证**:
```
真机make check -j1 -k日志含Error 124转FAIL且tests/*.trs落盘，test-suite.log或.trs回退按:test-result:计数并诚实记录gaps继续打包；make install无Error 64且INSTALL已覆盖为源码install-sh
```
