# E2842: Asterisk stdtime 通过 TZDIR 注入 HarmonyOS 可访问的 IANA 时区目录

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, runtime, nls
- **作者**: gcw_hL6s3dcK
- **来源 PR**: https://gitcode.com/OpenHarmonyPCDeveloper/build_in_harmonyos/merge_requests/9563

## 错误特征
```
TZDIR|tzload.*zoneinfo|GMT.*timezone|Cannot.*timezone
```

## 根因分析
Asterisk stdtime 默认使用编译期 TZDIR 拼接时区文件路径，而 HarmonyOS runner 的标准 IANA 数据可能位于其他可访问目录，固定路径找不到数据时会使时区逻辑回退或加载失败。

## 推荐方案
**方法**: runtime-tzdir-override

**说明**: 读取非空 TZDIR 作为运行时目录并在未设置时保留原编译期默认值，使时区加载和 watcher 共用同一可配置路径而不嵌入设备路径。

**修复命令**:
```
git apply --check --ignore-whitespace archives/a/asterisk/22.10.1/patches/0015-main-stdtime-tzdir-env.patch
```

**验证**:
```
git apply --check --ignore-whitespace archives/a/asterisk/22.10.1/patches/0015-main-stdtime-tzdir-env.patch
```
