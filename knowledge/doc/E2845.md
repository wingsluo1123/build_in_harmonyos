## 推荐方案
**方法**: asan-option-disable-container-overflow

**说明**: 复跑命令前置 ASAN_OPTIONS=detect_container_overflow=0。

**修复命令**:
```
export ASAN_OPTIONS=detect_container_overflow=0
```

**验证**:
```
ASAN_OPTIONS=detect_container_overflow=0 ./<gtest_binary>；
```
