# E2847: OHOS 上编译器工具链路线选型：SDK ld.lld 链接产物自动带

## 基本信息
- **严重度**: 2
- **类别**: ohos, toolchain, linking, conan, codesign
- **作者**: ohpcd <ohpcd@localhost>

## 错误特征
```
exec.*rc=126|Permission denied.*executable|
```

## 根因分析
OHOS 内核只加载带 .codesign 节的 ELF。SDK ld.lld 每次链接

## 推荐方案
**方法**: lld-baked-default-linker

**说明**: 1) configure 加 `--with-ld=<SDK ld.lld realpath>`（顶层会

**修复命令**:
```
../gcc-src/configure --with-ld=<SDK>/native/llvm/bin/ld.lld \
```

**验证**:
```
# all-gcc 后 fail-fast 断言（配方内建）
```
