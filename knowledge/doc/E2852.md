# E2852: autoconf 交付脚本的 `#! @VAR@` shebang 模板被 configure 填成构建机绝对解释器路径——只有上游用 `if test "x$VAR" = x` 守住探测块的变量才钉得住（本例 SH 生效、AWK 被无条件重算、PERL 无 FHS 目标可钉），故须以交付期 basename 归一为主案并配全量 shebang 扫描验收

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, build-system, autotools, shell
- **作者**: 7A2B

## 错误特征
```
^#! /storage/|^#! /data/service/|^#! .*\-posix$|#! @SH@|#! @PERL@|#! @AWK@|bad interpreter.*/data/service/|shell-init: error retrieving current directory|env: .*perl: No such file
```

## 根因分析
上游把命令面脚本以 `*.in` 模板分发，首行写成 `#! @SH@` / `#! @PERL@` /

## 推荐方案
**方法**: package-time-basename-shebang-normalization-plus-scan-assertion

**说明**: 三层，**主次不能颠倒**——

**修复命令**:
```
# (1) conanfile.py package() 内，对每个交付脚本取 basename 映射
```

**验证**:
```
grep -rl '^#! *@[A-Z0-9_]*@' <src>/*.in | wc -l
```
