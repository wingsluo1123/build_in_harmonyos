# E2854: "① 用最小补丁为上游 CMakeLists.txt 添加 GNUInstallDirs install() 规则（in

## 基本信息
- **严重度**: P1
- **类别**: cmake, packaging, cli-tool
- **作者**: unknown

## 错误特征
```
"Error in test\\(\\) method|inaccessible or not found|command not found|Error 127 while executing"
```

## 根因分析
"CMake 构建的 header-only INTERFACE 库 + CLI 工具包：上游 CMakeLists.txt 没有任何 install() 规则时，conan create 的 cmake.install() 不会安装任何头文件或可执行文件；同时 CLI 可执行文件若未通过 package_info() 的 runenv_info.prepend_path('PATH', bin) 注入 PATH，test_package 的 conanrun 阶段无法解析该 CLI（/system/bin/sh: Matrix_Hub_v2_0_cli: inaccessible or not found, Error 127）。"

## 推荐方案
**方法**: "① 用最小补丁为上游 CMakeLists.txt 添加 GNUInstallDirs install() 规则（install(DIRECTORY include/ ...) + install(TARGETS <cli> RUNTIME DESTINATION bin)）；② conanfile.py package_info() 中 self.runenv_info.prepend_path('PATH', os.path.join(self.package_folder, 'bin'))，使 conanrun 阶段可找到 CLI；③ test_package 用 self.run('Matrix_Hub_v2_0_cli script.m', env='conanrun') 显式运行已验证的 CLI 入口。"
