# E2856: 鸿蒙 PC 真机 /tmp 只读：测试探针写 /tmp 临时文件（sh 烟测 rc/输出重定向）静默失败，断言全挂；临时目录必须做写权限实测选取并回落当前目录

## 基本信息
- **严重度**: 2
- **类别**: ohos, device, temp-dir, test-probe
- **作者**: unknown

## 错误特征
```
行为烟测 rc 文件为空 / /tmp: Read-only file system
```

## 根因分析
鸿蒙真机（HarmonyOS PC，/storage 用户态系统）根文件系统只读：`ls -ld /tmp` 为 root 属主、`mkdir /tmp/ik-test` 报 "Read-only file system"。探针把 sh 干跑的 rc/输出重定向到 /tmp/installkernel-probe/，目录创建失败 → 重定向失败 → rc 文件为空 → 三个行为烟测断言（sh -n 零告警/干跑 exit 1/Usage 输出）全挂；脚本本体与 sh 环境其实完全正常（手动 sh -n=0、干跑打印 Usage 实证）。

## 推荐方案
**方法**: writable-temp-probe

**说明**: 探针临时目录不要硬编码 /tmp：依次探测 TMPDIR/TMP/TEMP 环境变量，每个候选做「创建子目录→删除」写权限实测，全不可写则回落当前工作目录（测试期 cwd 必然可写）；子目录名带时间戳/pid 避免多会话并发碰撞。

**修复命令**:
```
mkdir /tmp/probe-w-test 2>&1  # 探测用；探针内置 pick_temp_dir() 自动完成
```

**验证**:
```
ls -ld /tmp && mkdir /tmp/probe-w-test 2>&1  # 真机报 Read-only file system；Linux CI 成功
```
