# E2858: C++ 模板非类型参数以 char 声明并带负默认值（-1）时，在 plain char 无符号的 AArch64/OHOS 目标上编译期 -Wc++11-narrowing 硬错误

## 基本信息
- **严重度**: 2
- **类别**: portability, char-signedness, cpp, template
- **作者**: unknown

## 错误特征
```
non-type template argument evaluates to -1, which cannot be narrowed to type 'char'|char multiplication_strategy=-1|no matching function.*Q<.*char
```

## 根因分析

## 推荐方案
**方法**: template-param-signed-char-source-patch

**说明**: 将模板非类型参数类型从 char 改为 signed char（仅改变类型宽度语义，不影响

**修复命令**:
```
sed 类最小补丁：`-        char multiplication_strategy=-1>` → `+        signed char multiplication_strategy=-1>`
```

**验证**:
```
clang++ -std=c++11 -I <include> -c <consumer>.cpp 观察 -Wc++11-narrowing；修复后
```
