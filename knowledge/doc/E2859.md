# E2859: C++ 头文件直接使用 placement new（new (ptr) T）但未 #include <new>，libc++ 下报 no matching operator new

## 基本信息
- **严重度**: 2
- **类别**: portability, cpp, header-self-containment, standard-library
- **作者**: unknown

## 错误特征
```
no matching 'operator new' function for non-allocating placement new expression; include <new>|allocate_and_construct.*placement new|new \(mem\+ix\)
```

## 根因分析
上游头文件（如 include/microgl/bitmaps/buffer.h 的

## 推荐方案
**方法**: add-standard-new-include

**说明**: 在直接使用 placement new / 显式构造的头文件顶部补 `#include <new>`（标准头，

**修复命令**:
```
在 buffer.h 的 #pragma once 之后加入 `#include <new>`
```

**验证**:
```
clang++ -std=c++11 -I <include> -c <consumer>.cpp 观察 no matching operator
```
