# E2860: 上游 CMake 测试套件硬编码 win32 系统端口（测试配置无条件 include windows.h）：在 Linux/OHOS 上关闭测试配置的 OS 支持即可运行

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, cmake, testing, embedded
- **作者**: pc2-48-executor
- **来源 PR**: feat/lwmem-2.2.4（待创建）

## 错误特征
```
fatal error: 'windows\.h' file not found|
```

## 根因分析
>

## 推荐方案
**方法**: test-config-disable-os-support

**说明**: 把每个测试子目录 lwmem_opts.h 的 LWMEM_CFG_OS 由 1 改为 0、

**修复命令**:
```
for d in tests/*; do sed -i 's/#include "windows.h"/#include <stddef.h>/; s/LWMEM_CFG_OS              1/LWMEM_CFG_OS              0/; s/LWMEM_CFG_OS_MUTEX_HANDLE HANDLE/LWMEM_CFG_OS_MUTEX_HANDLE void*/' "$d/lwmem_opts.h"; done
```

**验证**:
```
cmake -S . -B build -DTEST_CMAKE_FILE_NAME=tests/<name>/cmake.cmake
```
