# E2861: Conan2 AutotoolsToolchain.environment() 是即时快照——其后 append 的 extra_cflags/extra_ldflags 不再被合并，且 generate(env=) 不会二次计算，依赖 -I/-L 全程不进 configure，探测退化为搜 /usr/include

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, build-system, autotools, conan
- **作者**: unknown

## 错误特征
```
"checking for ltdl.h... no|libextractor requires libltdl|CPPFLAGS='-DNDEBUG'|LDFLAGS 为空且无依赖 -I -L"
```

## 根因分析
conan 2.29.1 的 conan/tools/gnu/autotoolstoolchain.py 中，environment()（:277）

## 推荐方案
**方法**: define-cppflags-ldflags-in-env-or-set-extra-flags-before-environment
