# E2862: GPGME multi-binding package exports relocatable CMake configs after DESTDIR installation

## 基本信息
- **严重度**: high
- **类别**: cmake, autotools, conan, relocatability
- **作者**: zxyAtom
- **来源 PR**: 7424

## 错误特征
```
(gpgmeConfig|GpgmeppConfig|QGpgmeQt6Config).*(/lib|/include|NOTFOUND)
```

## 根因分析
Upstream GPGME CMake package metadata retains /lib and /include after DESTDIR installation, so consumers need package-local configs whose import locations are derived from CMAKE_CURRENT_LIST_DIR.

## 推荐方案
**方法**: package_local_relocatable_cmake_configs

**说明**: Generate gpgme, Gpgmepp, and QGpgmeQt6 configs under lib/cmake, derive the package prefix from CMAKE_CURRENT_LIST_DIR, and preserve the C to C++ to Qt6 target dependency chain.

**验证**:
```
conan create archives/g/gpgme/1.24.0.1 -pr:h=<ohos-aarch64> -pr:b=<ohos-aarch64> --build="gpgme/*"
```
