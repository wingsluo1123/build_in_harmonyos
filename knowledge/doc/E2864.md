# E2864: meson 内置选项 b_ndebug 不能只靠 project_options 设置——conan 传 --buildtype=release 后 meson 会重新推导为 true，上游断言被编译掉致测试「假通过」，须 configure 后钉正并用 introspect 实测校验

## 基本信息
- **严重度**: 2
- **类别**: build-system, meson, conan, testing, upstream-test
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: 13394

## 错误特征
```
check_ndebug.*FAIL|NDEBUG is defined, cannot run tests|Ok:\s+[0-9]+\s+Fail:\s+1|b_ndebug\s*=\s*'true'|Summary of Failures:.*check_ndebug
```

## 根因分析
b_ndebug 是 meson 的**内置（built-in）选项**，其值可由 buildtype 推导。

## 推荐方案
**方法**: pin-b-ndebug-after-configure-and-verify-by-introspect

**说明**: 在 meson.configure() **之后**、meson.build() 之前显式执行

**修复命令**:
```
meson configure "$build_dir" -Db_ndebug=false
```

**验证**:
```
meson configure <build_dir> -Db_ndebug=false
```
