# E2867: 鸿蒙 PC 未提供上游 -pg 默认选项所需的性能分析启动运行库

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, autotools, clang, linking
- **作者**: iKalous_OscarP
- **来源 PR**: 13501

## 错误特征
```
cannot open gcrt1\.o|cannot find gcrt1\.o
```

## 根因分析
RPGE 0.0.3 的 Automake 源文件无条件将 -pg 加入 AM_CFLAGS；在 OHOS 上，Clang 驱动会把该性能分析请求传给 ld.lld，链接器随后查找鸿蒙 SDK 运行环境未提供的 gcrt1.o。所有 C 翻译单元均可编译，但最终可执行文件链接失败。

## 推荐方案
**方法**: 移除平台不支持的性能分析选项

**说明**: 当产品不需要性能分析时，从生成的目标 Makefile 中移除上游无条件添加的 -pg，然后重新构建并确认最终链接不再请求 gcrt1.o。

**修复命令**:
```
sed -i 's/ -pg//g' src/Makefile.in && make
```

**验证**:
```
grep -n -- '-pg' src/Makefile.am；clang --target=aarch64-unknown-linux-ohos -pg <objects> -o app；检查链接器输出中的 gcrt1.o；只移除性能分析选项后重新链接。
```
