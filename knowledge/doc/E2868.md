# E2868: std::iterator C++17 弃用（libc++ 标 deprecated）打断 header-only 库的 -Werror 构建

## 基本信息
- **严重度**: 2
- **类别**: ohos, libc, headers, toolchain, compiler
- **作者**: SunShine_06
- **来源 PR**: 13207

## 错误特征
```
is deprecated \[-Werror,-Wdeprecated-declarations\]|has been explicitly marked deprecated here|_LIBCPP_DEPRECATED_IN_CXX17 iterator|public std::iterator<
```

## 根因分析
fatal/string/rope.h 的 const_iterator 继承 std::iterator<...>，而 std::iterator 自 C++17 起弃用，libc++ 将其展开为 _LIBCPP_DEPRECATED_IN_CXX17 → __attribute__((deprecated))。上游 harness 带 -Wall -Werror -Wextra，弃用告警被升级为硬错误，rope_test.cpp 整个 TU 无法编译（47 个用例全部无法执行）。rope.h 是安装头文件，消费者以 -Werror 使用时同样失败。

## 推荐方案
**方法**: replace-base-class-with-explicit-typedefs

**说明**: 移除 std::iterator 基类，改为语义等价的 5 个显式成员 typedef（iterator_category/value_type/difference_type/pointer/reference，其中 pointer=value_type*、reference=value_type&）；类内自引用须限定外层类名（rope::value_type）。

**修复命令**:
```
struct const_iterator {\n  using iterator_category = std::bidirectional_iterator_tag;\n  using value_type = rope::value_type;\n  using difference_type = rope::difference_type;\n  using pointer = rope::value_type *;\n  using reference = rope::value_type &;\n
```

**验证**:
```
打补丁后 clang++ -Wall -Werror -Wextra -O0 -g -pthread -ftemplate-depth-1024 -std=c++17 -I . fatal/string/test/rope_test.cpp 应编译成功且输出 "succeeded: passed 47/47"；消费者侧 static_assert(std::is_same<std::iterator_traits<const_iterator>::iterator_category, std::bidirectional_iterator_tag>::value) 应成立。
```
