# E2873: 纯Fortran包因L0c后缀白名单报no_test_sources时补充Shell消费者入口并打平.mod

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, cmake, testing
- **作者**: hmbs-executor
- **来源 PR**: 11799

## 错误特征
```
L0c: No test source files in test_package/|no_test_sources|Cannot parse module file for module 'gridxc'|gridxc\.mod.*was not found
```

## 根因分析
ci/conan/build_and_test.sh的L0c仅find统计.c/.cpp/.cc/.cxx/.sh/.py致纯.f90包误报no_test_sources；叠加上游将.mod装入include/libgridxc编译器版本子目录而CMakeDeps仅-I include致gridxc.mod not found

## 推荐方案
**方法**: add-shell-consumer-entry-and-flatten-mod

**说明**: 新增test_package/test.sh真实运行lda_contract与gga_contract并断言PASS标记由conanfile test()签名后经self.run调用；主配方package()将include树下全部.mod复制打平到include根并保留版本子目录

**修复命令**:
```
test_package/test.sh新增并由conanfile.py exports_sources与test() self.run调用；test_package/MANIFEST.yml同步command；conanfile.py package()新增_flatten_fortran_modules复制*.mod到include/
```

**验证**:
```
本地模拟L0c/L0d/L0e检查通过且conanfile语法解析通过；真机预检test_package经sh执行test.sh断言GRIDXC_TEST PASS且不再报gridxc.mod缺失
```
