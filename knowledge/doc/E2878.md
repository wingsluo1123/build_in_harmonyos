# E2878: Rust/cargo 项目在 OHOS 无 linux-ohos 官方工具链端口且 hmmac 封锁预构建 ELF——选型阶段即判不可适配（adguardhome/illuminanced 先例）

## 基本信息
- **严重度**: 3
- **类别**: ohos, toolchain, rust, selection
- **作者**: unknown

## 错误特征
```
rustc.*not found|cargo.*not found|No matching toolchain.*rust|rust-unsupported-platform
```

## 根因分析
OHOS 沙箱无 linux-ohos 官方 Rust 工具链端口（rustc/cargo 目标 triples 不含 OHOS，与 Go 相同），ohpcd 制品仓亦无 Rust 工具链包；且 hmmac MAC 安全策略封锁"下载来的预构建静态 ELF"执行（execve errno=13，官方 Go 工具链先例）——Rust 项目（cargo build，依赖 crates.io）在 OHOS 上无任何可编译路径。

## 推荐方案
**方法**: reject-at-selection

**说明**: contrib 候选评估阶段即检测语言：Rust/cargo 项目（有 Cargo.toml）直接判不可适配，同 Go 项目先例；不必创建纯净分支/四件套/消费者用例（无法本地/CI 构建验证）。可选走路径 B 沉淀"不可适配原因"知识。

**修复命令**:
```
选型检查：上游仓库根目录存在 Cargo.toml → 判 Rust；沙箱 which rustc/cargo 无结果 → 不可适配
```

**验证**:
```
which rustc cargo 2>/dev/null；ls /data/service/hnp/bin | grep -iE 'rust|cargo'；conan search rust -r=ohpcd
```
