# E2881: 制品仓 LLVM dylib 聚合包无组件导入目标 + 真机 uname=HarmonyOS 无 cmake Platform 模块：LLVM 系编译器在 OHOS 上的 configure 双失效与回退（libLLVM.so 直链 + Platform 桩）

## 基本信息
- **严重度**: 2
- **类别**: portability, cmake, toolchain, llvm
- **作者**: Hawkninja21
- **来源 PR**: 0

## 错误特征
```
Could NOT find TARGET LLVMCore|llvm_map_components_to_libnames.*(empty|not found)|LLVMConfig.cmake.*not found|FATAL_ERROR.*(UNIX|Unix)|LFortran.*only supports (Unix|Linux)|LLVM_TARGETS_TO_BUILD.*not.*built
```

## 根因分析
子模式 A（LLVM 组件目标缺失）：制品仓 clang/22.1.8 包以 LLVM_BUILD_LLVM_DYLIB=ON 构建，交付 LLVMConfig.cmake（LLVM_TARGETS_TO_BUILD=AArch64）+ 聚合 libLLVM.so，但不导出 LLVMCore 等 per-component 导入目标。上游 lfortran 的 LLVM 链接检测用 llvm_map_components_to_libnames 求组件库列表，dylib 模式下组件目标缺失即得空 → 传统组件链接路径失效（configure 期报 Could NOT find TARGET LLVMCore 或链接期空列表）。上游已内置 #34593 workaround 分支（检测 TARGET LLVMCore 缺失 → 回退链接 libLLVM.so 聚合库），因此适配动作=①LLVM_DIR 指向包内 lib/cmake/llvm（而非 SDK /data/service/hnp 的 LLVM 15，版本/布局均不同）②WITH_LLVM=yes + WITH_TARGET_AARCH64 与包 LLVM_TARGETS_TO_BUILD=AArch64 对齐（x86/wasm 全关，请求包未构建的后端会 configure/链接失败）。子模式 B（Platform 模块缺失）：真机 uname -s=HarmonyOS，cmake Modules/Platform 无 HarmonyOS 条目 → 原生编译（不设 CMAKE_SYSTEM_NAME，CMAKE_CROSSCOMPILING=FALSE）时 UNIX 等变量未置 → 上游 `if(NOT UNIX)` 判错 FATAL。修复=CMAKE_MODULE_PATH 注入配方生成的 Platform/HarmonyOS.cmake 桩（单行 include(Platform/Linux)，置 UNIX=1 与 Linux 链接/rpath 规则），与 clang/22.1.8 真机构建同款路线。

## 推荐方案
**方法**: dylib-fallback+platform-stub

**说明**: 不改上游源码，配方级两动作：①LLVM_DIR 指向依赖包 clang 的 lib/cmake/llvm；后端开关与包 LLVM_TARGETS_TO_BUILD 严格对齐（本库=AArch64，WITH_TARGET_AARCH64=yes、x86/wasm=no）；链接靠上游 #34593 回退分支（TARGET LLVMCore 缺失 → 直链 libLLVM.so），保证 LLVMConfig 版本/布局与二进制同源。②build_folder 下生成 Platform/HarmonyOS.cmake 桩（include(Platform/Linux)）挂 CMAKE_MODULE_PATH，让原生编译的 UNIX 判定成立；不设 CMAKE_SYSTEM_NAME（避免交叉编译误判与 R26 静态系统库规则误触发）。运行期 libLLVM.so 解析见 [[DRAFT-lfortran-nested-cmake-bootstrap]]。

**修复命令**:
```
cmake -B build-ohos -S <src> -DLLVM_DIR=<clang-pkg>/lib/cmake/llvm -DWITH_LLVM=yes -DWITH_TARGET_AARCH64=yes -DWITH_TARGET_X86=no -DWITH_TARGET_WASM=no -DCMAKE_MODULE_PATH=<bdir>/_cmake_modules（Platform/HarmonyOS.cmake 桩）
```

**验证**:
```
①核对包 LLVMConfig：grep -E 'LLVM_TARGETS_TO_BUILD|add_library\(LLVM' <clang-pkg>/lib/cmake/llvm/LLVMConfig.cmake（AArch64-only、无 LLVMCore 组件目标、有聚合 LLVM 目标）；②configure 复验：conan create 日志 grep -E 'LLVM_CONFIG|TARGET LLVMCore|LLVM_DIR'（出现上游 #34593 回退分支消息且无 FATAL）；③产物复验：llvm-nm -D <pkg>/bin/lfortran | grep -c _ZN4llvm（libLLVM.so 符号解析正常）与 ldd/NEEDED 含 libLLVM.so
```
