# E2884: 滚动 URL 且含非自由子集的数据包：以 Debian dfsg 重打包 orig 归档为 conan 钉死源（.dsc sha256 互证 + 双镜像）

## 基本信息
- **严重度**: 2
- **类别**: conan, debian, licensing, recipe, sourcing
- **作者**: LIMInGZE666 <LIMInGZE666@noreply.gitcode.com>
- **来源 PR**: 0

## 错误特征
```
sha256.*(not match|不匹配)|滚动 URL|updates\?latest|Files-Excluded|CC BY 2\.0 and CC BY 4\.0|dfsg
```

## 根因分析
上游以滚动 URL 发布（LDraw complete.zip = library.ldraw.org/updates?latest，每次更新覆写），无法取固定版本 sha256；且发行内容含非自由子集（约 3200 个 CC-BY-2.0-only/双许可零件 + 样例模型），不能整体进入 Debian main 或自建合规源。Debian 维护者用 repack.sh + gendfsgsrc.py 产出独立源码包 X+dfsg-1（只含自由子集），其 orig.tar.xz 在 Debian main 池中按版本号永久留存、sha256 记于同名 .dsc——这正是可钉死的固定版本自由子集归档。

## 推荐方案
**方法**: pin-debian-dfsg-orig

**说明**: conandata sources.url 指向 Debian main 池的 X+dfsg.orig.tar.xz（例：mirrors.ustc.edu.cn/debian/pool/main/l/ldraw-parts-free/ldraw-parts-free_2602+dfsg.orig.tar.xz），sha256 取同名 .dsc 的 Checksums-Sha256 字段（绝不取自滚动 URL 的当前快照）；url 列表主镜像 + 备镜像（aliyun 等）成对提供。配方 build() 以 dfsg 重打包清单做防漂移校验（目录精确计数 + 被剔内容负向断言），package() 用 copy("*") + excludes pattern 列表整树复制（禁止目录级 copy——真机空操作）。注意：dpkg-source 生成的条目带 ./ 前缀，conan get(strip_root=True) 不剥离顶层目录（真机 2.29.1 实证）——get() 原样解压 + _src_root() 按固定顶层目录名显式下钻，勿依赖 strip 语义。

**修复命令**:
```
curl -sI <debian-pool-url> | grep -E "^HTTP.*200"; curl -s <pool>/<pkg>_<ver>+dfsg.orig.tar.xz | sha256sum
```

**验证**:
```
本机：curl -sI 双镜像 URL 均 200 + sha256sum 与 .dsc 记录一致；conan create 时 get() 实测下载成功（真机 USTC/aliyun 镜像通）。
```
