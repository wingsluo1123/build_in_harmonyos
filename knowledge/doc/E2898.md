# E2898: readline 老式 typedef「Function」默认不再从公开头导出（8.3 起收进 WANT_OBSOLETE_TYPEDEFS 守卫），用作 hook 变量类型即编译失败；改用公开的 rl_hook_func_t

## 基本信息
- **严重度**: 3
- **类别**: compat, headers, api, third-party-library
- **作者**: Z71
- **来源 PR**: feat/pal-0.4.3

## 错误特征
```
use of undeclared identifier 'Function'|expected expression.*Function|rl_pre_input_hook.*Function
```

## 根因分析
「Function / VFunction / CPFunction / CPPFunction」是 readline 早期的函数指针 typedef，从来不是它对外承诺的稳定 API。

## 推荐方案
**方法**: use-public-readline-hook-typedef

**说明**: 把私有/老式类型换成 readline 公开的 hook 函数指针类型 rl_hook_func_t，只改类型名，不改回调实现与注册时序

**修复命令**:
```
以 portability 补丁改出错行的强转类型名，本包即 src/manage.c:406 由 Function 指针改为 rl_hook_func_t 指针
```

**验证**:
```
RLDIR=$(find "$CONAN_HOME/p" -path "*/include/readline/rltypedefs.h" | head -1); grep -nE "WANT_OBSOLETE_TYPEDEFS|typedef int Function|rl_hook_func_t" "$RLDIR" ; grep -rn "WANT_OBSOLETE_TYPEDEFS" "$CONAN_HOME/p" | grep -v "rltypedefs.h" ; echo 守卫之外无人定义该宏即命中本条
```
