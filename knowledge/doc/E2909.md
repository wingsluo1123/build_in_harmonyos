# E2909: 滑动窗口中值滤波器 warmup 语义——窗口未满时槽位按 0 参与中值，独立编写的测试/消费者断言必须显式复刻该约定，否则 warmup 输出被误判为失败

## 基本信息
- **严重度**: 2
- **类别**: testing, algorithm, c, embedded
- **作者**: unknown

## 错误特征
```
output\[0\]=0 expected 5|median of first full window|window not full|warmup|expected [0-9]+ got [0-9]+
```

## 根因分析
滑动窗口实现为固定容量环形缓冲，窗口未满时未使用槽位以 0 值初始化并参与中值计算（warmup 语义）。上游自带测试已按该语义建模（reference_median 显式把未满槽位填 0），但独立撰写的测试/消费者断言若不复制该约定，就会把 warmup 输出（如 w=3 序列 {5,5,100,...} 首输出 median(0,0,5)=0 而非 5）误判为失败。

## 推荐方案
**方法**: align-assertions-with-warmup-zero-fill

**说明**: 对窗口大小 N 的滑窗：前 N-1 个输出按 median(0,...,0,s1..sk) 显式推导（示例：w=3 首输出 median(0,0,5)=0、次输出 median(0,5,5)=5），满窗后进入常规滑窗中值；C++ 模板的 0 填充以 T(0) 为准。先核对库文档是否声明"未满不输出/哨兵填充"约定，再决定断言口径。
