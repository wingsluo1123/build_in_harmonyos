# E2911: Single-header graphics/game-engine library with no native window backend on OHOS: use the upstream headless compile mode (OLC_PGE_HEADLESS) rather than writing a backend, runtime dummy drivers, or reclassifying display tests

## 基本信息
- **严重度**: 2
- **类别**: ohos, graphics-headless-mode
- **作者**: unknown

## 错误特征
```
X11/X.h.*No such file|Xlib.h.*No such file|OLC_PLATFORM.*not defined|Package type is 'library', but no 'shared' option declared|no member named 'Resize' in 'olc::Sprite'
```

## 根因分析
The OHOS PC platform has no native windowing backend for windowed graphics engines (upstream olcPixelGameEngine covers only Win32/X11/GLUT/Emscripten). Compiling the header without a platform selection fails (missing X11 headers or no platform defined). Upstream DOES ship a real headless mode switched by a compile-time macro (OLC_PGE_HEADLESS -> OLC_PLATFORM_HEADLESS/OLC_GFX_HEADLESS/OLC_IMAGE_HEADLESS, upstream implementations, not stubs). The adaptation mistake is to write a new OHOS window backend, add runtime dummy drivers, or reclassify tests.

## 推荐方案
**方法**: use-upstream-headless-compile-mode-with-consumer-macro

**说明**: Do not write a window backend, do not stub the platform, do not reclassify upstream tests. Prefer the upstream-supported headless/offscreen compile mode: the recipe must not patch the header; the consumer compiles with the headless macro defined (e.g. -DOLC_PGE_HEADLESS -DOLC_PGE_APPLICATION). Package header-only (package_type=header-library, copy headers into package_folder/include, no build artifact), validate with (1) a real consumer test in test_package that defines the macro and calls public APIs with observable results, and (2) a dedicated test_ohos case compiled directly with the OHOS toolchain running headless engine APIs. Report the 9 upstream missing-override warnings as upstream-fidelity noise.

**修复命令**:
```
target_compile_definitions(test PRIVATE OLC_PGE_HEADLESS OLC_PGE_APPLICATION); CXX_STANDARD 17; CONSUMER defines OLC_PGE_HEADLESS before OLC_PGE_APPLICATION before #include "olcPixelGameEngine.h"
```

**验证**:
```
clang++ -std=c++17 -O2 -fPIC -I<src> -pthread ohos_pge_test.cpp -o ohos_pge_test && ./ohos_pge_test   (headless: Sprite gradient fill/sample, headless Construct, vi2d ops, Pixel constants; exit 0)
```
