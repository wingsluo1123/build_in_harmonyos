- **类别**: python, conan, testing, environment
- **作者**: unknown

## 根因分析
上游 pytest 自带套件里有两处会主动破坏"靠环境变量传依赖"的做法：

## 推荐方案
**方法**: stage-suite-root-and-supply-via-pythonuserbase

**说明**: build() 铺 <root>/lib/pythonX.Y/site-packages：被测包模块 + dist-info +

**修复命令**:
```
site_dir=<build>/suite-root/lib/python3.12/site-packages;
```

**验证**:
```
conan create . 观察 build() 中套件汇总行：PYTHONPATH 方案会出现
```
