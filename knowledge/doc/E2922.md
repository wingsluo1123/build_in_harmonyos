# E2922: "测试脚本里优先完全不用 mktemp：tmpdir=${TMPDIR:-.}; tmpin=\"$tmpdir/<li

## 基本信息
- **严重度**: P2
- **类别**: compat, ohos, packaging, testing, shell
- **作者**: unknown

## 错误特征
```
"mktemp: need XXXXXX|mktemp.*invalid.*template|mktemp.*template.*suffix|No such file or directory.*mktemp"
```

## 根因分析
"OHOS 设备的 mktemp 是 toybox 实现，模板语法比 GNU coreutils 窄：至少 6 个连续 X 必须出现在模板【结尾】，不允许 '前缀-XXXXXX.后缀' 这种带扩展名的中间 X 形态。test_package 的 shell 冒烟测试里最常见的写法 mktemp /tmp/foo-XXXXXX.txt 会直接报 'mktemp: need XXXXXX' 退出 1（不是权限问题）。此外 /tmp 在 OHOS 上可能只读（E002），双坑叠加：即使模板合法，路径选 /tmp 也会失败。"

## 推荐方案
**方法**: "测试脚本里优先完全不用 mktemp：tmpdir=${TMPDIR:-.}; tmpin=\"$tmpdir/<lib>-test-$$.txt\"，配 trap 'rm -f ...' EXIT 清理；$$ 保证并发唯一且 toybox 兼容。若必须用 mktemp，用 X 结尾模板 mktemp \"$TMPDIR/foo.XXXXXX\"（无扩展名）。修复后必须重传 test 脚本到设备 job 并重跑 run-conan-heavy.sh 验证。注意与 E011/E060/E118/E125/E129/E136/E175 区分：那些是 HMDFS 上 mktemp -d ./confXXXXXX 的权限/umask 问题，本条是 toybox 模板语法限制，报错文本不同（need XXXXXX vs Permission denied）。"
