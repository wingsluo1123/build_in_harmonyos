No tests were found!+|100% tests passed, 0 tests failed out of 0|test cases: 0|assertions: 0|CROSS=1

判定口径错误是根，两类机制是表：把“构建或测试命令的退出码为 0”“粗扫输出没看到 FAIL”当作“测试通过”的证据，

## 推荐方案
**方法**: prove-execution-then-fix-the-gate

**说明**: 三步固定动作，顺序不可颠倒：

**修复命令**:
```

```

**验证**:
```
# 1) 先量化“到底有没有用例”（通用第一步）
```
