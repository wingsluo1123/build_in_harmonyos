# E2932: OHOS/musl 下 __GLIBC__/__GLIBC_MINOR__ 未定义（在 #if 中按 0 参与运算），

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, libc, headers, guard
- **作者**: GaoPengqiang <GaoPengqiang@noreply.gitcode.com>

## 错误特征
```
sys/sysctl\.h.*file not found|use of undeclared identifier 'cpu_set_t'|use of undeclared identifier 'cpu_set'|__GLIBC__.*undefined
```

## 根因分析
OHOS 使用 musl libc，clang 预定义 __linux__ 但**不定义** __GLIBC__ /

## 推荐方案
**方法**: capability-probe-instead-of-glibc-version-gate

**说明**: (a) 头文件存在性：把 include 换成能力探测而不是版本判断——

**修复命令**:
```
diff -u src/platform.h.orig src/platform.h; diff -u src/threadpool.c.orig src/threadpool.c
```

**验证**:
```
CC='clang -I<gmp>/include -L<gmp>/lib' bash makemake.sh nosimd
```
