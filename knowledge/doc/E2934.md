# E2934: 顶层 CMake 无条件 set() 含 windows.h 的 win32 专用配置头（configure_file 生成）导致 OHOS 编译失败；上游 %p 断言按 32 位指针假设在 64 位目标失败

## 基本信息
- **严重度**: 3
- **类别**: platform, cmake, testing, configuration-header, pointer-width
- **作者**: unknown

## 错误特征
```
lwprintf_opts\.h.*fatal error.*windows\.h|set\(LWPRINTF_OPTS_FILE.*dev.*opts\.h|%.*p.*32-bit.*system|Test error on line.*%p
```

## 根因分析
部分嵌入式 C 库把开发/测试用的 win32 专用配置头（如 dev/lwprintf_opts.h，

## 推荐方案
**方法**: win32-config-header-conditional-guard

**说明**: 对顶层 CMake 的平台专用配置头选择加正向 WIN32 守卫：仅 WIN32 才 set 含

**修复命令**:
```
CMakeLists.txt: set(LWPRINTF_OPTS_FILE ...) 与 win32 源文件/宏/include
```

**验证**:
```
conan create . -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
