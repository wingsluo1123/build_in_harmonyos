# E2937: hippomocks CFUNC 打桩在 aarch64/OHOS 不可用：上游 ARM 路径仅写 32 位 ARM 指令，且文本页 mprotect RWX 被 OHOS W^X 拒绝（EINVAL）；应禁用该特性，虚拟函数打桩不受影响

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, portability, memory, aarch64
- **作者**: unknown

## 错误特征
```
conflicting types for '__clear_cache'|
```

## 根因分析
hippomocks 5.0 的 CFUNC 打桩 Replace 类在 SOME_ARM 分支

## 推荐方案
**方法**: source-code-patch

**说明**: 在 hippomocks.h 中把 _HIPPOMOCKS__ENABLE_CFUNC_MOCKING_SUPPORT

**修复命令**:
```
apply patches/0001-HippoMocks-hippomocks.h.patch && cmake --build build-ohos -j4 && ./build-ohos/HippoMocksTest/HippoMocksTests
```

**验证**:
```
cmake -S . -B build-ohos -DCMAKE_CXX_COMPILER=clang++ -DCMAKE_POLICY_VERSION_MINIMUM=3.5 && cmake --build build-ohos -j4 && ./build-ohos/HippoMocksTest/HippoMocksTests
```
