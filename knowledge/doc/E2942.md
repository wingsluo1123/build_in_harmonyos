# E2942: libcdio-paranoia OHOS Autotools、HMDFS 与 BIN/CUE fixture 适配

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, ohos, autotools, conan, testing
- **作者**: xiaoliu66666_
- **来源 PR**: none

## 错误特征
```
cannot guess build type|OS.*ohos.*not recognized|could not setup config files machinery|BOING\.BIN.*No such file|//lib/.*\.la|start track.*not one
```

## 根因分析
旧版 Autotools helper 不识别 OHOS；HMDFS 不接受 configure 的私有 umask 临时目录；发布 CUE fixture 引用缺失 BIN；libcdio BIN/CUE 驱动会从 image entry 1 重新编号；依赖 .la 携带构建机绝对路径。

## 推荐方案
**方法**: ohos-autotools-triplet-hmdfs-fixture-and-private-dependency-prefix

**说明**: 对 config.guess/config.sub/configure 做最小 OHOS/HMDFS 补丁，修复实际随包发布的 CUE 文件名和 endian 生成 CUE，使用六个 data entry 保持音频轨道 7/8/9，并把静态 libcdio 归档注入 build_folder 私有前缀以绕过 .la 绝对路径。

**修复命令**:
```
zsh ci/conan/build_and_test.sh archives/l/libcdio-paranoia/10.2-2.0.2
```

**验证**:
```
conan create archives/l/libcdio-paranoia/10.2-2.0.2 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
