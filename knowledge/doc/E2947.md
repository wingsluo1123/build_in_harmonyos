# E2947: "On OHOS (__OHOS__) allocate the JIT code cache with MAP_ANO

## 基本信息
- **严重度**: P0
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"SIGSEGV|SIGILL during JIT execution.*memfd_create.*PROT_EXEC|mmap.*Permission denied|MapFailed"
```

## 根因分析
"On OHOS, mmap() of a memfd_create()'d file with PROT_EXEC fails with EACCES (W^X policy), so an LLVM/MCJIT-style JIT whose code cache uses the memfd path gets mapping==MAP_FAILED and crashes when writing/executing generated code. Plain anonymous mmap(PROT_READ|PROT_WRITE|PROT_EXEC, MAP_PRIVATE|MAP_ANONYMOUS) is permitted and executable."

## 推荐方案
**方法**: "On OHOS (__OHOS__) allocate the JIT code cache with MAP_ANONYMOUS instead of memfd (drop REACTOR_ANONYMOUS_MMAP_NAME semantics on OHOS); guard the now-unused memfd helpers with !defined(__OHOS__) to avoid -Wunused-function -Werror. Verify first with a 3-case probe: (1) anon RWX mmap + execute, (2) memfd_create + mmap(PROT_EXEC), (3) RW mmap + mprotect RX."
