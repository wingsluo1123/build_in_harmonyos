# E2948: "Prefer the POSIX/musl-available equivalent: replace pthread

## 基本信息
- **严重度**: P1
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"use of undeclared identifier 'pthread_(get|set)affinity_np'|use of undeclared identifier 'RTLD_DI_ORIGIN'"
```

## 根因分析
"OHOS uses musl libc, which does not provide several glibc-only extensions. Upstream code often guards them with `#if defined(__linux__) && !defined(__ANDROID__) && !defined(__BIONIC__)`, which is TRUE on OHOS (clang defines __linux__), so the glibc-only branch is compiled and fails: pthread_{get,set}affinity_np (glibc-only) and dlinfo(RTLD_DI_ORIGIN) (glibc extension)."

## 推荐方案
**方法**: "Prefer the POSIX/musl-available equivalent: replace pthread_{get,set}affinity_np with sched_{get,set}affinity(0, ...) (musl provides the cpu_set_t + CPU_* macros and sched_*affinity in <sched.h>). For APIs with no equivalent, guard with `#if defined(__GLIBC__)` (affinity) or `#if defined(RTLD_DI_ORIGIN)` (dlinfo) so musl skips the block. Do NOT rely on `defined(__linux__)` to mean glibc."
