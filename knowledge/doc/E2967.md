## 推荐方案
**方法**: shrink-workspace-plus-regenerated-lock-plus-locked

**说明**: 三件套缺一不可：①补丁把 workspace 缩容到目标切片

**修复命令**:
```
cargo check --locked -p <crate> && cargo update -p <pkg> --precise <ver>
```

**验证**:
```
①失配检测：对补丁后的树跑 cargo metadata --locked
```
