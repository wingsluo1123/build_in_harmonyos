## 错误特征
```
"cannot open file.*Read-only file system|LegalLogMgrError|cannot open file.*reason:|EROFS|EACCES.*open|ofstream.*is_open.*false"
```

## 根因分析
"The HarmonyOS PC app sandbox mounts system directories such as /tmp read-only, while upstream code (written for glibc/Linux) assumes /tmp is writable. File-backed log components open their configured path directly at backend construction: kea-hook-legal-log's RotatingFile::openInternal() does file_.open(file_name_, ofstream::app) and throws LegalLogMgrError on failure. With KEA_LEGAL_LOG_DIR=/tmp the open fails with EROFS ('cannot open file:/tmp/kea-legal.<date>.txt reason: Read-only file system') and the upstream test LegalLogMgrTest.pathEnvVarOverride fails at addBackend. Two constraints shape the fix: (1) the configured path string must stay untouched — upstream tests assert the BadValue message 'invalid path specified: <x>, supported path is <configured>' which embeds getLogPath(); (2) the redirect therefore has to live at the FILE-OPEN layer (not in path resolution/validation), where it can change where the bytes land without changing what the configuration says. This is the same sandbox constraint that makes conan need pick_temp_dir on the device."

## 推荐方案
**方法**: "Under a musl-Linux compile guard (#if defined(__linux__) && !defined(__GLIBC__)), when the open fails and errno is EROFS or EACCES, retry in a writable scratch location under $HOME: scratch = $HOME/.kea-legal-log/<configured-path-with-/→_> (slash-to-underscore encoding prevents collisions, mkdir(0755) is idempotent, and the stream needs clear() before reopening after a failed open). Keep the configured path in all configuration strings and validation messages — the upstream BadValue-message assertions keep passing. The deterministic mapping (same configured path → same scratch file) keeps rotation reopens consistent across openInternal() calls. Triggering only on EROFS/EACCES means writable configured paths behave exactly as upstream; glibc/Linux keeps the original code path via the guard. Verify with the upstream test that sets the env var to /tmp (KEA_LEGAL_LOG_DIR=/tmp), not just a compile."
