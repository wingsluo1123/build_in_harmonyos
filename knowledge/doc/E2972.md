# E2972: Conan 上下文 LibEdit find 模块落空（网络 FS stat 假阴性）回退 CMakeDeps，目标名 libedit::libedit 与 lldb 源硬引用 LibEdit::LibEdit 不匹配

## 基本信息
- **严重度**: high
- **类别**: cmake, dependency
- **作者**: ''

## 错误特征
```
'Target "lldbHost" links to: LibEdit::LibEdit but the target was not found'
```

## 根因分析
预编译包 LLVMConfig.cmake 第 11 行自载自身 lib/cmake/llvm 到 CMAKE_MODULE_PATH，FindLibEdit.cmake find 模块本可找到；但 find 模块文件在 pkgRedirects 网络 FS 上 stat 假阴性（间歇，本地正常/CI 偶发）时 CMake 判定模块不存在，回退 config 模式命中 CMakeDeps 生成的 libedit-config.cmake（generators 目录，其 <pkg>_DIR 变量指向 generators 是判别证据）。CMakeDeps 目标名由 libedit 配方 package_info 决定（libedit::libedit），而 lldb 源 Host/CMakeLists.txt 硬引用 LibEdit::LibEdit；CMakeDeps 置 LibEdit_FOUND=TRUE 使 LLDB_ENABLE_LIBEDIT 为真 → 链接期目标缺失报错。本地构建（健康 FS）stat 命中走模块路径（PC_LIBEDIT_FOUND=1 为判别证据）故本地过、CI 偶发挂。

## 推荐方案
**方法**: explicit-cache-variables-bridge-alias

**说明**: 四层确定性注入：①显式 LibEdit_INCLUDE_DIRS/LibEdit_LIBRARIES 缓存变量（find 模块预置跳过搜索，FS 免疫）；②CMakeDeps libedit-config.cmake 尾部桥接别名 LibEdit::LibEdit→libedit::libedit（config 回退兜底）；③CMAKE_MODULE_PATH 双副本（shim+源树模块目录，stat 冗余）；④同一 libedit-config.cmake 后处理（glob+regex）清除 libedit SYSTEM_LIBS 中的 tinfo——libedit.so 的 NEEDED libtinfo.so.6 由动态链接器运行期解析（设备 /usr/lib/libtinfo.so.6 实证存在），消费方链接期无需 -ltinfo，不清除则缺 libtinfo.a 链接硬失败

**修复命令**:
```
tc.cache_variables["LibEdit_INCLUDE_DIRS"] = <libedit_pkg>/include; tc.cache_variables["LibEdit_LIBRARIES"] = <libedit_pkg>/lib/libedit.so; 见 archives/l/lldb/0.0.1/conanfile.py generate()
```

**验证**:
```
grep -E 'LibEdit_DIR|LibEdit_FOUND|PC_LIBEDIT_FOUND' <build>/CMakeCache.txt
```
