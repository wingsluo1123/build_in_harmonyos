# E2982: refresh-patch --auto 删除 _is_likely_generated 判定为生成物的补丁（configure），conandata.yml 引用悬空导致 G2 失败

## 基本信息
- **严重度**: 3
- **类别**: toolchain, workflow
- **作者**: unknown, M1R0

## 错误特征
```
patch file not found|patches/0006-configure-umask.patch|Copied 0 '.patch' files
```

## 根因分析
refresh_patch._is_likely_generated() 通过文件头（如 "Generated by GNU

## 推荐方案
**方法**: --auto 只删「本次再生且内容过期」的补丁，不可再生补丁输出 [warn] 保留；

**说明**: 优先把新增代码内联进既有文件，使全部补丁都是修改型（clean-verify 只需 tarball+补丁即可配置）；必须新增文件时走 export_sources 导出并在 source() 拷贝；GENERATED 文件（configure/config.guess/sub）的改写放配方 build() 内

**修复命令**:
```
patches/ 只放修改型补丁；新增文件在 conanfile.py 的 export_sources() 里导出、source() 里 copy；configure 的 umask 077 改写放 build()（如 `_drop_umask_077(self, os.path.join(self.source_folder, "configure"))`）
```

**验证**:
```
conan create 报 `source/target file does not exist`（或补丁应用失败）；对照 `grep -n "^--- " patches/*.patch`——新增文件若显示 `--- a/<path>` 而非 `/dev/null` 即命中；`grep -n "GENERATED" reports/*.log` 可看补丁工具对 configure 的排除判定
```
