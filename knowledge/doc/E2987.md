# E2987: autotools 项目的发布 tarball 缺 configure/config.h 时的直编方案

## 基本信息
- **严重度**: 2
- **类别**: compat, build-system, autotools, packaging
- **作者**: OpenHarmonyPCDeveloper <ohpcd@localhost>

## 错误特征
```
use of undeclared identifier 'PACKAGE_VERSION'|use of
```

## 根因分析
AC_INIT 的 PACKAGE_NAME/PACKAGE_VERSION/PACKAGE_STRING 只经

## 推荐方案
**方法**: direct-clang

**说明**: 小型 C 项目跳过 autotools：复用上游手写 config.h.static 作为

**修复命令**:
```
cp src/config.h.static src/config.h && clang --std=gnu99 -O2 -Wall
```

**验证**:
```
ls <srcdir>/configure <srcdir>/src/config.h <srcdir>/src/config.h.static
```
