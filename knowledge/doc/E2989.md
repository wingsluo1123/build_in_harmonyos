# E2989: OHOS musl libc 直接导出 crypt/daemon/syslog/mlockall/setpriority 且有 libcrypt.a：libxcrypt 类用户零补丁，勿因无 libcrypt.so 误判依赖缺失

## 基本信息
- **严重度**: 1
- **类别**: ohos, libc, musl, linking, dependency
- **作者**: unknown

## 错误特征
```
-lcrypt.*not found|libcrypt\.so.*missing|undefined reference.*crypt|syslog.*undefined reference|daemon.*undefined reference
```

>

## 推荐方案
**方法**: nm-verify-then-link-as-is

**说明**: >

**修复命令**:
```
llvm-nm -D "$OHOS_SYSROOT/usr/lib/aarch64-linux-ohos/libc.so" | grep -E ' crypt$| daemon$| syslog$| mlockall$| setpriority$'; ls "$OHOS_SYSROOT/usr/lib/aarch64-linux-ohos/libcrypt.a"
```
