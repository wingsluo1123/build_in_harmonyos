# E2990: application 包产物须放 Conan 标准 bin/ 而非上游 sbin/：L5 只扫 bin/lib（warn 非 fail 易误判），L1e 破坏性验证会因无标准目录被静默跳过

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, application
- **作者**: unknown

## 错误特征
```
L5: No bin/ or lib/ content found|L5_RESULT=warn: no artifacts found|L1e: No standard artifact dirs found to sabotage
```

## 根因分析
>

## 推荐方案
**方法**: package-to-conan-standard-bindir

**说明**: >

**修复命令**:
```
copy(self, "sysrqd", src=src, dst=os.path.join(self.package_folder, "bin")); os.chmod(os.path.join(self.package_folder, "bin", "sysrqd"), 0o755); self.cpp_info.bindirs = ["bin"]
```

**验证**:
```
grep -n 'RESULT=' <stdout.log> | grep -E 'L5|L1e'   # 期望 L5_RESULT=pass: bin/ has content 且 L1e 为 Negative test confirmed
```
