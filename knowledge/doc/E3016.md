# E3016: ohpcd 的 gcc-ada/9.5.0 不含 gprbuild/gprinstall；凡上游用 GPR 工程（.gpr）驱动构建与安装的 Ada 库，均需退化为 gnatmake 直编 + 显式安装布局

## 基本信息
- **严重度**: 3
- **类别**: toolchain, ada, build-driver, gcc-ada, gnat
- **作者**: ohpcd

## 错误特征
```
gprbuild: (command )?not found|gprinstall: (command )?not found|Error 127.*gprbuild|No such file or directory.*gprinstall
```

## 根因分析
gcc-ada/9.5.0 的 bin/ 实测只有 gnatbind、gnatchop、gnatclean、gnatlink、

## 推荐方案
**方法**: replace-gpr-driver-with-gnatmake-plus-explicit-layout

**说明**: 不要试图用 tool_requires 补 gprbuild（ohpcd 没有该包，且其依赖

**修复命令**:
```
①库编译：gnatmake -c -f -gnat95 -gnatp -O2 -Dobj \
```

**验证**:
```
ls <gcc-ada包>/bin | grep -cE '^gpr(build|install)$'   # 期望 0
```
