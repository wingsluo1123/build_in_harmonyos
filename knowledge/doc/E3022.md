# E3022: Belledonne 栈库在 OHOS 上的 crypto 后端缺口：制品仓 bctoolbox 为 ENABLE_MBEDTLS=OFF，优先复用已发布 bzrtp 包内的私有 crypto 后端，而不是每个库各写一遍 mbedtls vendoring

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, dependency, link
- **作者**: unknown

## 错误特征
```
bctoolbox/crypto.h file not found|undefined reference to .*bctbx_ssl_context_new|undefined reference to .*bctbx_rng_context_new|undefined reference to .*bctbx_sha256|find_package\(BCToolbox 5.3.0 REQUIRED\)
```

## 根因分析
belle-sip / lime 等 Belledonne 栈库的源码无条件 include bctoolbox/crypto.h 并调用 bctbx_* 加解密与 TLS API（SSL 上下文、RNG、SHA256/MD5、base64、签名密钥）。制品仓发布的 bctoolbox/5.3.115 是 ENABLE_MBEDTLS=OFF 构建：既没有 include/bctoolbox/crypto.h，也没有这些符号。实测（OHOS aarch64 真机）：belle-sip 5.3.105 引用 181 个 bctbx_* 符号，其中 bctbx_ssl_context_new/config_*、bctbx_rng_context_new/free/get、bctbx_sha256、bctbx_md5、bctbx_base64_encode、bctbx_signing_key_* 等在内的一大批符号在 libbctoolbox.a 中缺失（nm 逐符号比对），编译期先报 bctoolbox/crypto.h file not found，补上头文件后链接期报 undefined reference。

## 推荐方案
**方法**: reuse-published-private-crypto-backend-before-revendoring

**说明**: (1) 先查制品仓是否已有同族包发布过该私有后端：bzrtp/5.3.105 为同样的缺口 vendored 了 mbedtls 3.6.5 + bctoolbox 5.3.115 crypto 对象，并把它们随包发布（include/bctoolbox/crypto.h、lib/libbctbx-crypto-priv.a、libmbedcrypto.a、libmbedtls.a、libmbedx509.a），且已用 objcopy 把与 bctoolbox 重名的回退符号本地化，因此与已发布的 bctoolbox 并存不产生重复定义——直接 requires 该包比自己重写一遍几百行 vendoring 管线更轻、更可复现；(2) 头文件：编译期加 -isystem <bzrtp 包>/include（crypto.h 只在那里），并把它随自己的包一起安装到 include/bctoolbox/（CMakeDeps 不向"间接"消费者导出 bctoolbox 的 include 目录——实测 bctoolbox_INCLUDE_DIRS 为空，经 bzrtp 间接依赖同样为空，所以依赖 bctoolbox 头的包必须自带这些头，belr/5.3.105 与 bzrtp/5.3.105 同款做法）；(3) 链接：把 -lbctbx-crypto-priv -lmbedcrypto -lmbedtls -lmbedx509 追加到 target_link_libraries（源码补丁或 add_library 处），不要只靠 CMAKE_EXE/SHARED_LINKER_FLAGS——链接器标志会排在对象之前，符号仍会 undefined；(4) 依赖声明用 requires bzrtp/5.3.105 + cpp_info.requires 传递，消费者链接即可用；(5) 上游 tester 若同时依赖系统资源（/etc/nsswitch.conf、回环 SIP/HTTP 服务），按"可运行套件全跑 + 逐套件豁免说明"申报（见 test_package/MANIFEST.yml）。

**修复命令**:
```
conan create archives/b/belle-sip/5.3.105 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create archives/b/belle-sip/5.3.105 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 && ./test_belle_sip
```
