# E3023: "最小修改：在派生类模板内对该基类成员调用加 `this->` 限定（或 `Base<keytype_t>::membe

## 基本信息
- **严重度**: P1
- **类别**: cpp
- **作者**: unknown

## 错误特征
```
"explicit qualification required to use member .* from dependent base class"
```

## 根因分析
"C++ 模板两阶段名字查找：派生类模板中访问【依赖基类】的成员时，非限定名不会在实例化时查找基类作用域（clang/GCC 现代标准模式）。2000 年代的 C++ 代码（如 maq 0.7.1 stdhash.hh）在旧 GCC 默认宽松模式下可编译，换 clang 15 / C++17 报 error 而非 warning。"

## 推荐方案
**方法**: "最小修改：在派生类模板内对该基类成员调用加 `this->` 限定（或 `Base<keytype_t>::member`）。不要用 -fpermissive / -Wno- 类开关绕过。"

**说明**: (待补充)

**修复命令**:
```
"sed -i 's/\\bdirect_insert_aux(/this->direct_insert_aux(/g' <header>   # 逐处核对后使用"
```
