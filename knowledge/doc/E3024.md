# E3024: "config.guess 用 `*:HarmonyOS:*)` 三段模式 + `echo ${MACHINE}-unk

## 基本信息
- **严重度**: P1
- **类别**: autotools
- **作者**: unknown

## 错误特征
```
"cannot guess build type.*config.guess timestamp = 200[0-9]|unable to guess system type.*HarmonyOS"
```

## 根因分析
"老版（2006-2008）config.guess 的 HarmonyOS 分支有两个坑：①补丁常写成 `*:HarmonyOS:*:*` 四段模式，但 OHOS 的 uname -v 形如 `#1 SMP Wed Apr 29 10:16:03 UTC 2026`（含冒号），case 字符串被拆成 5+ 段导致模式不匹配；②老版 config.guess 不通过变量输出，而是每个分支 `echo <triplet>; exit 0`，只赋值 GUESS 不 echo 会继续走兜底 CC 探测并最终 `unable to guess system type`（rc=1）。"

## 推荐方案
**方法**: "config.guess 用 `*:HarmonyOS:*)` 三段模式 + `echo ${MACHINE}-unknown-linux-ohos; exit 0`；同时在 config.sub 侧补齐 linux-ohos*（maybe_os 列表）、aarch64（CPU 列表）、aarch64-*（cpu-company 列表）、-linux-ohos（os 分支），否则 host 校验报 `machine aarch64-linux not recognized`。"

