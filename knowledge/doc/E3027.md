# E3027: Launchpad dbus-test-runner 测试 harness 未鸿蒙化：用配方生成的 POSIX-sh shim 把 --task/--parameter 调用翻译为 dbus-run-session + 并行任务脚本（单任务 gtester 形态与多任务 client/server 形态通吃，--ignore-return 语义如实实现），libdbusmenu 16.04.0 上游 8 测试真机 8/8

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, testing, dbus, launchpad
- **作者**: unknown

## 错误特征
```
dbus-test-runner.*not found|command not found.*dbus-test-runner|
```

## 根因分析
Launchpad 生态（libdbusmenu、libindicator、ayatana-indicator-*、indicator-*）的 automake TESTS 是生成的 wrapper 脚本，内部调用 dbus-test-runner——该工具属 Launchpad autobuilder 工具链，从未移植、制品仓无。缺失时 make check 的每个测试目标 Error 127，整个上游测试子集无法运行。wrapper 有两种调用形态：(1) 单任务 gtester 形态 `dbus-test-runner --task gtester --task-name test --parameter ... --parameter ./prog`；(2) 多任务形态 `dbus-test-runner --max-wait=0 --task ./client --task-name Client --task ./server --task-name Server --ignore-return`（client/server 共享同一条会话总线，谁先谁后不确定，必须并行启动）。dbus-test-runner 退出语义：默认任一任务非零退出则整体失败；--ignore-return 下全部任务退出即成功（各任务退出码忽略）。另一隐含依赖：测试需要 D-Bus session bus——OHOS 沙箱默认 EXTERNAL 认证起不了总线（无 passwd DB），必须用匿名 TCP 会话配置（见 DRAFT-dbus-1.14.10.1-ohos-session-bus-runtime，运行时前置组件）。

## 推荐方案
**方法**: harness-translation-shim-parallel-tasks

**说明**: 配方 build() 内生成两个文件：(a) dbus-test-runner shim（POSIX sh，/bin/sh）：逐参数解析 --task/--task-name/--parameter/--ignore-return，把任务串以换行分隔存入 DBUS_TR_TASKS（--parameter 追加到最近任务后），最后 `exec dbus-run-session --config-file=<匿名TCP conf> -- sh run-tasks.sh`；(b) run-tasks.sh：按换行拆分 DBUS_TR_TASKS，`sh -c "exec <task>" &` 并行启动全部任务后 wait——无 --ignore-return 时逐 job wait 累计 rc，有则全部退出即 exit 0。配套四件（均为已知模式，见关联）：dbus 工具包 bin/ 手动入 PATH（tool 型包不经 VirtualRunEnv 暴露）；TESTS 参数整体加引号（否则 make 把 8 个测试名拆成独立目标）；LOG_COMPILER=$(SHELL) + wrapper shebang 改 /system/bin/sh（直接 shebang 执行被拒）；匿名 TCP 会话配置文件由配方写入构建树。注意：sh 中 $'\n' 语法 OHOS /system/bin/sh (mksh) 支持（真机实证）；参数假定不含空格/换行（构建树路径满足）。

**修复命令**:
```
make check -j1 TESTS="test-glib-objects-test test-glib-events test-glib-events-nogroup test-glib-layout test-glib-properties test-glib-proxy test-glib-simple-items test-glib-submenu"
```

**验证**:
```
真机（MateBook，OHOS aarch64）：conan create 前把 dbus/1.14.10.2 tool 包 bin/（dbus-run-session、dbus-daemon）加入 PATH；配方 build() 检测到 dbus-run-session 后生成 shim 与 run-tasks.sh 并把 shim 目录前置 PATH，运行 `make check -j1 TESTS="<8 个 glib 测试>"` → gtester XML 全部 status="0"，8/8 PASS（其中 test-glib-events / test-glib-events-nogroup 走多任务并行形态，其余 6 个走单任务 gtester 形态）。消费者测试 14/14（child_find 断言暴露上游 menuitem.c:929 循环条件写反，补丁 0005 修复）。
```
