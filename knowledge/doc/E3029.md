## 推荐方案
**方法**: use-shared-variant-of-that-dependency

**说明**: Switch the offending dependency to its shared variant.

**修复命令**:
```
cmake -S <src> -B <build> -o numactl/*:shared=True   # or conan -o numactl/*:shared=True
```

**验证**:
```
make -j4 LIBS=-lnuma 2>&1 | grep -c "undefined version"
```
