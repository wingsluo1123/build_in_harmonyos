# E3031: conan test_package scripts must APPEND to PYTHONPATH - assigning it discards the dependency paths conanrun injected

## 基本信息
- **严重度**: 2
- **类别**: python, conan, packaging, testing, environment
- **作者**: unknown

## 错误特征
```
ModuleNotFoundError: No module named '(gast|pyproject_metadata|numpy|packaging|meson)'|FAIL: .* API: Traceback.*ModuleNotFoundError|Error in test\(\) method.*conanrun
```

## 根因分析
In this repo's Python recipes the consumer test is a two-layer

## 推荐方案
**方法**: append-not-assign-pythonpath

**说明**: In the inner test script, read the inherited value and PREPEND

**修复命令**:
```
python -c "import os;site='<pkg>/lib/python3.12/site-packages';os.environ['PYTHONPATH']=os.pathsep.join([site]+[p for p in os.environ.get('PYTHONPATH','').split(os.pathsep) if p])"
```

**验证**:
```
grep -n 'env\["PYTHONPATH"\] *=' archives/<pkg>/*/test_package/test_*.py
```
