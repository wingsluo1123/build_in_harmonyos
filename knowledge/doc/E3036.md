# E3036: WCDHOME 只迁移状态而非扫描根；go 脚本写入失败仍可能返回零

## 基本信息
- **严重度**: 2
- **类别**: state-directory-permission
- **作者**: tank_you

## 错误特征
```
Unable to write file .*bin/wcd.go: Permission denied
```

## 根因分析
受限账户 HOME 不可写，WCD 不能生成供父 shell source 的 wcd.go；CLI 版本输出仍返回 0，且 WCDHOME 从 5.1.5 起不改变默认扫描根。

## 推荐方案
**方法**: separate-writable-state-and-bounded-scan-roots

**说明**: 设置应用私有 WCDHOME，另用 -S 或 WCDSCAN 控制扫描，检查 stderr、go 脚本内容及调用 shell 的最终目录。

**修复命令**:
```
export WCDHOME=<writable-private-dir>; wcd -S <tree>
```

**验证**:
```
WCDHOME=<private> wcd -S <tree>; WCDHOME=<private> wcd <name>; source packaged wcd.sh; pwd
```
