# E3037: CLI 工具仅有 $ORIGIN RUNPATH 时，bin/lib 分目录打包会丢失共享库

## 基本信息
- **严重度**: 2
- **类别**: elf-runtime-path
- **作者**: tank_you

## 错误特征
```
Error loading shared library libkuroko.so|RUNPATH [$ORIGIN]
```

## 根因分析
上游工具的 DT_RUNPATH 仅搜索其可执行文件所在的 bin 目录；Conan 包将所需 libkuroko.so 放在兄弟 lib 目录，动态加载器不会自动搜索该目录。

## 推荐方案
**方法**: export-conan-runenv-library-path

**说明**: 对照 ELF 的 RUNPATH/NEEDED 和实际包目录；在 Conan package_info 导出 LD_LIBRARY_PATH 或在链接期生成正确的相对 RUNPATH，并以最终包外部运行验证，不只运行构建树产物。

**修复命令**:
```
self.runenv_info.prepend_path("LD_LIBRARY_PATH", os.path.join(self.package_folder, "lib"))
```

**验证**:
```
readelf -d bin/krk-demo; LD_LIBRARY_PATH= bin/krk-demo; LD_LIBRARY_PATH=lib bin/krk-demo
```
