# E3038: 选择格式串时须同步选择独立的类型匹配变参调用，避免条件表达式混合指针和整数

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, build-system
- **作者**: C02D
- **来源 PR**: 12447

## 错误特征
```
error: pointer/integer type mismatch in conditional expression
```

## 根因分析
诊断代码分别选择%s或%d格式串，却把char*与运行期int放入同一个条件表达式作为变参实参；该表达式违反C类型约束，严格构建报pointer/integer mismatch。选择格式串不会使实参在每次调用恢复对应类型。

## 推荐方案
**方法**: split-format-and-typed-varargs-calls

**说明**: 按同一判据拆成两条完整decode_error调用：字符串分支使用msg1与TAB[policy]，整数分支使用msg2与policy；保留原格式串、错误条件和退出语义。

**修复命令**:
```
schedtool -M -1 0; schedtool -N -p 1 0
```

**验证**:
```
make -j1 CC=cc 'CFLAGS=-O2 -Wall -Wextra -Werror'
```
