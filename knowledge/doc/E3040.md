# E3040: OHOS GTK3 仅 broadway 后端：依赖 <gdk/gdkwayland.h> 的 Wayland GTK 客户端无法编译，需自建 gdkwayland 访问器兼容层

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, meson, display, gtk
- **作者**: OpenDesk
- **来源 PR**: -

## 错误特征
```
gdk/gdkwayland\.h.*(No such file|file not found)|
```

## 根因分析
OHOS 制品仓的 gtk/3.24.43 以 broadway(HTML5) 后端构建，

## 推荐方案
**方法**: wayland-client-backed-gdkwayland-shim

**说明**: 在配方补丁里新增一个极小的兼容层（.h/.c），用

**修复命令**:
```
patches/000X-src-gdkwayland-compat.{c,h}.patch +
```

**验证**:
```
pkg-config --variable=targets gdk-3.0   # OHOS 输出 broadway
```
