# E3043: 可选 PCRE2 关闭后，悬空 if 分号会把 POSIX 正则模式一并拒绝

## 基本信息
- **严重度**: 2
- **类别**: optional-feature-guard
- **作者**: tank_you

## 错误特征
```
Support for Perl regular expressions not compiled in
```

## 根因分析
上游 src/misc.c 的 if (regextype == REGEX_PERL); 以分号结束条件语句，后续报错块无条件执行；未定义 HAVE_LIBPCRE2 时，选择 -E/-G 也会退出 2。

## 推荐方案
**方法**: narrow-condition-fix-plus-positive-and-negative-consumer-tests

**说明**: 删除 if 条件后的多余分号；用最终安装包分别断言 POSIX -E 成功及不可用的 -P 仍明确拒绝，避免仅凭 make 成功断言基础能力正常。

**修复命令**:
```
conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing
```

**验证**:
```
mboxgrep -E -c 'Alpha|Beta' two-messages.mbox; mboxgrep -P -c Alpha two-messages.mbox
```
