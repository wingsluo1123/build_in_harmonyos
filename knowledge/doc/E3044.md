# E3044: OHOS 设备 JVM user.home 为 "?"：Maven/Gradle 用户级缓存落到 cwd 相对 "?/.m2"，缓存失效且污染源码树

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, java, environment, maven
- **作者**: GoliWie

## 错误特征
```
user\.home\s*=\s*\?|\.m2/wrapper/dists|/\?/\.m2|
```

## 根因分析
OpenJDK 在 Linux 上由 getpwuid_r(getuid()) 取

## 推荐方案
**方法**: pin-user-home-and-cache-dir-explicitly

**说明**: 构建命令显式指定全部用户级路径，不依赖 user.home：

**修复命令**:
```
java -Duser.home=<build_dir> -classpath .mvn/wrapper/maven-wrapper.jar -Dmaven.multiModuleProjectDirectory=<src_dir> org.apache.maven.wrapper.MavenWrapperMain -Dmaven.repo.local=<build_dir>/m2-repository clean verify
```

**验证**:
```
java -XshowSettings:properties -version 2>&1 | grep user.home
```
