# E3047: 纯 Python 包安装成功不等于目标解释器可用 SQLite

- **严重度**: 2
- **类别**: portability, python, runtime

## 错误特征
```
No module named ['"]?_sqlite3|No module named ['"]?sqlite3|sqlite3\.OperationalError
```

## 根因分析
Python 的 sqlite3 高层模块依赖 CPython 可选构建的原生 _sqlite3 扩展。复制纯 Python 模块或

## 推荐方案
**方法**: 使用消费者解释器验证 SQLite 运行时

**说明**: 在与消费者相同的 Python 可执行文件中检查 sqlite3 导入、真实连接与 SQL 往返，再执行被测包 API；确认运行时闭合后再判断包可用。minidb 2.0.8 的目标机消费者测试现已覆盖实际内存 SQL 往返。

**修复命令**:
```
python3 -c 'import sqlite3; c=sqlite3.connect(":memory:"); assert c.execute("select 1").fetchone()==(1,)'
```

**验证**:
```
python3 -c 'import sys,sqlite3; print(sys.executable, sqlite3.__file__, sqlite3.sqlite_version); c=sqlite3.connect(":memory:"); assert c.execute("select 1").fetchone()==(1,)' && python3 -c 'import minidb; d=minidb.Store(); d.close()'
```
