# E3048: 编译器 TMPDIR 修复不保证 C 库 tmpfile() 可写

## 基本信息
- **严重度**: 2
- **类别**: environment
- **作者**: tank_you

## 错误特征
```
tmpfile failed: errno=13 (Permission denied)
```

## 根因分析
在所测 HarmonyOS PC 环境中，Clang 的临时文件位置可由 TMPDIR 移到可写目录，但 libc tmpfile() 在同一环境仍返回 EACCES；前者通过不等于后者通过。

## 推荐方案
**方法**: distinguish-compiler-temp-from-libc-tmpfile

**说明**: 先独立验证 Clang 临时文件与 libc tmpfile()；仅对测试临时输入，改用可写工作目录中的 fopen(...,"w+") 并清理。若生产代码依赖 tmpfile()，须单独设计可配置目录或平台实现，不能把测试绕过冒称为生产修复。

**修复命令**:
```
fopen("vnlog-test-input.vnl", "w+")
```

**验证**:
```
TMPDIR=<writable-dir> ./probe-tmpfile; conan create archives/v/vnlog/1.42 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 -c tools.build:jobs=1
```
