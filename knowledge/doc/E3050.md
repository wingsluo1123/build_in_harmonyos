# E3050: libwayland sun_path 108 字节硬限 × conan 缓存深路径 → 短路径候选探测 + 失败即抛（DRAFT-10004 的跨机通用化）

## 基本信息
- **严重度**: 2
- **类别**: limitation, ohos, socket
- **作者**: unknown
- **来源 PR**: https://atomgit.com/OpenHarmonyPCDeveloper/build_in_harmonyos/merge_requests/13869

## 错误特征
```
socket path .*exceeds 108|plus null terminator exceeds 108|sun_path
```

## 根因分析
libwayland 在 bind 前对解析后 socket 全路径校验 ≤108 字节（POSIX sun_path 上限）；conan 缓存构建树路径深（实例 69+ 字符前缀）+ XDG_RUNTIME_DIR 前缀 + 测试最长 50 字符 socket 名 → 超限 → display.start() 直接失败（bind 前的库内校验，LD_PRELOAD 拦不到）

## 推荐方案
**方法**: short-xdg-candidate-probe

**说明**: 测试环境 XDG_RUNTIME_DIR/TMPDIR 用短路径候选按序探测（/tmp/<name> → $HOME/.kf5/<name>，可写探测首个胜出；OHOS /tmp 只读（E002）时自然落到 $HOME/.kf5）+ 长度断言（len(xdg)+1+最长 socket 名 ≤108）失败即 RuntimeError fail-fast——不让错误深到 libwayland 层变成晦涩的 socket path 报错

**修复命令**:
```
候选探测 + 断言参考 kf5wayland/5.116.0 conanfile _short_dir；实例取值 $HOME/.kf5/xfullxdg（38 字符，+1+50=89≤108）
```

**验证**:
```
[ $(( ${#XDG_RUNTIME_DIR} + 1 + 50 )) -le 108 ] && echo OK  # 长度预算断言
```
