# E3051: 制品仓 .so 无 DT_SONAME → 下游 DT_NEEDED 烙上 conan 缓存绝对路径；package() 同长度 .dynstr 原位归一化 + 重签修复

## 基本信息
- **严重度**: 2
- **类别**: ohos, linking, conan
- **作者**: unknown
- **来源 PR**: https://atomgit.com/OpenHarmonyPCDeveloper/build_in_harmonyos/merge_requests/13869

## 错误特征
```
\(NEEDED\)\s+/.*\.conan2/p/.*\.so|DT_NEEDED 含绝对路径|soname_gate_failed|L5b
```

## 根因分析
部分制品仓二进制包（实例 expat）.so 无 DT_SONAME → 链接器把链接期缓存绝对路径记为 DT_NEEDED → CI L5b 门禁 fail + 跨机/跨用户消费者按路径解析必败（绝对路径不可移植）；--as-needed 不可行（下游直接引用符号无法剔除，实例：kf5wayland 两 .so 各 ~16 个未定义 XML_* 符号）

## 推荐方案
**方法**: dynstr-inplace-basename-resign

**说明**: package() 签名前对打包 .so 字节级原位补丁：NUL 结尾、/ 开头、basename 匹配 lib*.so(\.N)* 的字符串 → basename + NUL 补零（同长度，DT_NEEDED 偏移不变，dynamic section 结构不动，仅 .dynstr 内容变化）；随后按生态惯例重签（objcopy 去旧 .codesign + binary-sign-tool）；验证 = readelf 全按名 + test_package 真实 dlopen 加载（证明补丁后重签 .so 可被平台加载）

**修复命令**:
```
字节补丁参考 kf5wayland/5.116.0 conanfile _normalize_dyn_needed_paths；验证：readelf -d pkg/lib/*.so | grep NEEDED  # 应全为库名
```

**验证**:
```
readelf -d <dep>.so | grep -E 'SONAME|NEEDED'  # 依赖无 SONAME 行 + 下游 NEEDED 为绝对路径 = 命中
```
