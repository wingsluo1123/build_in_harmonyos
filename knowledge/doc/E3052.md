# E3052: "链接行显式加全路径 $OHOS_SDK/llvm/lib/aarch64-linux-ohos/libc++_shar

## 基本信息
- **严重度**: P1
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"undefined (reference|symbol).*_Znwm|undefined (reference|symbol).*_Zdl"
```

## 根因分析
"OHOS SDK 的 libc++.so 是 20 字节 linker-script 桩（INPUT(-lc++_shared)），非真实实现。裸 clang++ 会自动链接 libc++_shared.so，但 CMake/ccache 链接行不会自动带上，C++ 目标出现 undefined _Znwm/_Zdl（operator new/delete）。"

## 推荐方案
**方法**: "链接行显式加全路径 $OHOS_SDK/llvm/lib/aarch64-linux-ohos/libc++_shared.so（conan 配方：extra_exelinkflags + extra_sharedlinkflags）；先验证运行时可解析（实测：链接它的 trivial 程序无 LD_LIBRARY_PATH 可运行，用于 configure 探测程序也安全）。"
