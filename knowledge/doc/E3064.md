# E3064: kamailio（自有 make 体系）在 OHOS 上模块与 core 构建口径必须一致：OS=linux 且编译标志集合相同，否则加载被拒

## 基本信息
- **严重度**: P1
- **类别**: platform, ohos, build-system, make
- **作者**: KML-LUA

## 错误特征
```
module version mismatch|
```

## 根因分析
kamailio 的 OS 判定为 `OS := $(shell uname -s | sed ...)`（Makefile.defs:125），

## 推荐方案
**方法**: module-build-parity-with-core

**说明**: 模块的 make 变量与 OHOS 上 core 的构建口径**逐项对齐**：

**修复命令**:
```
make cfg OS=linux SCTP=0 DEFS_RM="-DHAVE_RESOLV_RES"
```

**验证**:
```
conan create archives/k/kamailio-lua/6.0.6 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --user=ohpcd --channel=stable
```
