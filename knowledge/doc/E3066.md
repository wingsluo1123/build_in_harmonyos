# E3066: 原生测试工具与语料驱动分离时，联合核查构建目标、非空发现和实际调用数

## 基本信息
- **严重度**: 2
- **类别**: portability, cmake, conan, testing
- **作者**: orrkri
- **来源 PR**: 12588

## 错误特征
```
No files to test|upstream driver failed; see|binary calls, expected|total mismatch: discovered=
```

## 根因分析
上游CMake默认只建原生库，语料测试依赖的CLI未进入构建图；Python驱动迁移后仍可能在glob空匹配时显式返回0。仅检查脚本兼容性或退出码无法证明语料被执行。

## 推荐方案
**方法**: connect-test-tools-corpus-execution

**说明**: 以可选CMake开关接入上游测试CLI并在Conan测试构建显式开启；保持语料与断言语义迁移驱动，必需语料为空时返回非零；按固定上游分组核对发现输入数、实际/预期调用数和预期输出，区分合法往返与非法输入预期拒绝。

**修复命令**:
```
conan create archives/l/libncl/2.1.21-git20210811.b1213a7 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```

**验证**:
```
python3 test/roundTripNCLTest.py <existing-executable> <empty-input-directory> <empty-output-directory>
```
