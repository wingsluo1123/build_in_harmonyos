# E3067: "official-github-archive-url-for-tagless-commit"

## 基本信息
- **严重度**: P1
- **类别**: conan, source-download, tagless
- **作者**: unknown

## 错误特征
```
"BadZipFile: File is not a zip file.*codeload.github.com/.*/tar.gz/[0-9a-f]{40}"
```

## 根因分析
"Upstream repo has no git tag/release (tagless); conandata uses a bare codeload commit URL https://codeload.github.com/<owner>/<repo>/tar.gz/<sha> whose basename has no .tar.gz extension, so Conan tools.files.get() mis-detects the format and tries to unzip -> BadZipFile. Use the official GitHub archive URL https://github.com/<owner>/<repo>/archive/<sha>.tar.gz which ends in .tar.gz, 302-redirects to the identical codeload commit archive, and carries the same SHA-256."
