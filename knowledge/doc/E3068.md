# E3068: "cmake-build-build-tool-args"

## 基本信息
- **严重度**: P1
- **类别**: cmake, conan, recipe
- **作者**: unknown

## 错误特征
```
"TypeError: CMake.build() got an unexpected keyword argument 'args'"
```

## 根因分析
"Conan 2.x CMake.build() has no 'args' parameter; its signature is build(build_type, target, cli_args, build_tool_args, stdout, stderr, subfolder). Recipes migrated from autotools-style intuition call cmake.build(args=['-j1']) which raises TypeError. Tool args (e.g. -j1 for make) must go through build_tool_args; cmake --build args through cli_args."
