# E3081: architecture-gated-dev-port-byte-stream-backend

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, musl, 'platform, headers'
- **作者**: Rz114514
- **来源 PR**: (本 PR)

## 错误特征
```
'sys/perm\.h.*file not found|asm/io\.h.*file not found|use of undeclared identifier ''(ioperm|outb|inb)''|''bits/io\.h'' file not found'
```

## 根因分析
'x86 用 ioperm()+inb/outb 内联汇编访问 ISA 端口空间，aarch64/riscv 等架构根本不存在该指令与地址空间，且 OHOS/musl 连相关头文件都不提供（sys/perm.h 缺失、asm/io.h 缺失、sys/io.h 是空壳）。（1）编译期第一错是 fork 中第一个 #include <sys/perm.h> 或 <asm/io.h> 报 file not found；（2）即使把头文件问题绕开，outb/inb 在 aarch64 上无对应指令；（3）用 __has_include(<sys/io.h>) 探测会假阳性（OHOS 的 sys/io.h 只 include features.h 与空的 bits/io.h），必须按架构判（__i386__/__x86_64__）。'

## 推荐方案
**方法**: architecture-gated-dev-port-byte-stream-backend

**说明**: '按架构分派端口后端：x86（__i386__/__x86_64__）保留原生 sys/io.h + ioperm() + outb/inb；其余架构（含 OHOS aarch64）改用 /dev/port 的字节流接口——/dev/port 是字节可寻址字符设备，文件偏移即端口号，用 pread/pwrite 单字节即完成端口读写，无需任何内联汇编或架构宏。Set()/初始化阶段用 open("/dev/port", O_RDWR) 的成败作为“端口能力/权限”探测，失败时按原有错误码（如 CRIO_ERROR_IOPRERM）上报并给出 strerror() 文案；设备不可用时必须优雅降级（清晰诊断 + 正常退出），不得崩溃或挂死。'
