## 推荐方案
**方法**: cargo-config-multiplexing-false-http1

**说明**: .cargo/config.toml [http] multiplexing=false 强制

**修复命令**:
```
printf '[http]\nmultiplexing = false\ncainfo = "/storage/Users/currentUser/usr/local/ssl/cert.pem"\n' >> .cargo/config.toml
```
