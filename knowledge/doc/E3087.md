# E3087: OHOS denies pathname AF_UNIX bind(2) for unprivileged processes on every writable filesystem (tmpfs EPERM / hmfs EACCES; abstract namespace works), which crashes server-suite gtest fixtures through the Sandbox mkdtemp(P_tmpdir="/tmp" read-only) NULL → std::string(NULL) → loader strlen(0) path; exclude the environment-limited cases with GTEST_FILTER propagated through "meson test" inherited environment instead of patching upstream tests

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, testing, environment-limits, gtest
- **作者**: 2404

## 错误特征
```
killed by signal 11 SIGSEGV$|Error loading shared library libc\+\+_shared\.so|
```

## 根因分析
OHOS (verified on HarmonyOS PC 6.0 aarch64, 2026-10) blocks bind(2) of a pathname UNIX domain socket for an unprivileged process on every filesystem the process may write: tmpfs (/storage/Users/...) returns EPERM, hmfs (/data/service/hnp, /data/app) returns EACCES, /dev and /dev/shm also deny; only the abstract namespace (sun_path[0]=='\0') succeeds. Kea (and any server suite using pathname control sockets) therefore cannot run its control-channel tests. Compounding it, the upstream test Sandbox fixture builds its directory with mkdtemp(P_tmpdir "/kea-XXXXXX") where /tmp is READ-ONLY on OHOS, so mkdtemp returns NULL and std::string(NULL) crashes inside the musl loader (SIGSEGV addr=0, PC=strlen+0x10 — verified with a ucontext SIGSEGV backtrace probe since ptrace/gdb is denied). Deeper Conan build trees additionally exceed sockaddr_un::sun_path (107 chars) giving ENAMETOOLONG in parser/config-write tests, and four more OHOS semantic deltas (read-only /tmp CSV open, death-test message not relayed to parent, chmod(S_IRUSR) not blocking owner writes, virtual interface inventory ip6_vti0/ip6tnl0) fail individual cases.

## 推荐方案
**方法**: gtest-filter-env-injection-for-ohos-unix-socket-limits

**说明**: OHOS 上路径式 AF_UNIX bind 被全面禁止（实测 tmpfs EPERM/hmfs EACCES、抽象命名空间可用），服务器类 gtest 套件经 Sandbox mkdtemp(只读 /tmp) NULL → std::string(NULL) → musl 加载器 strlen(0) 崩溃；用 GTEST_FILTER 环境注入（meson test 透传父环境）按 fixture 粒度排除六类环境限制用例，零上游改动，非 OHOS 平台全量执行

**修复命令**:
```
grep -n "GTEST_FILTER" archives/i/isc-kea/3.0.3/conanfile.py && grep -n "_ohos_gtest_filter" archives/i/isc-kea/3.0.3/conanfile.py
```
