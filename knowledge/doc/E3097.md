# E3097: 动态文件与目录插件迁移 importlib 时验证加载生命周期

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, python
- **作者**: orrkri
- **来源 PR**: 14350

## 错误特征
```
ModuleNotFoundError: No module named '_yapsy_screen_package'
```

## 根因分析
只创建 spec 和模块再执行不足以证明包上下文、执行前模块身份和执行失败后的自身缓存键正确；目录插件需要包上下文，执行前登记新模块，捕获 Exception 后清理自身键。

## 推荐方案
**方法**: source-patch

**说明**: 按目录/文件建立 spec；目录保留搜索路径；exec_module 前登记当前模块；Exception 后移除自身键并重抛，分别验证相对 helper、执行中身份与失败后状态。

**修复命令**:
```
按配对 MD 的准确补丁和隔离诊断步骤人工核对；不自动改源码或 sys.modules。
```

**验证**:
```
python yapsy_loader_probe.py /path/to/patched/yapsy/PluginManager.py（脚本和固定来源取得方法见配对 MD）
```
