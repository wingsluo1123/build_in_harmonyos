# E3100: clang 不定义 __FLOAT_WORD_ORDER__（gcc 定义），据此选择字序的代码在 clang 下静默退化为"非小端"，__signbit{l,d} 读到尾数位而非符号位，使复数例程把普通有限输入当成"负无穷/特殊值"处理并段错误

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, clang, byte-order, legacy-c
- **作者**: unknown
- **来源 PR**: PENDING

## 错误特征
```
__signbitl|__signbitd|__signbitf .* wrong|
```

## 根因分析
上游代码用编译器内建宏 `__FLOAT_WORD_ORDER__` 判断浮点数的

## 推荐方案
**方法**: fallback-float-word-order-to-byte-order

**说明**: 不要依赖单一编译器内建宏；给出**带回退的派生宏**，优先专用宏、

**修复命令**:
```
clang -dM -E -x c /dev/null | grep FLOAT_WORD_ORDER
```

**验证**:
```
# 1) 免费信号：确认目标编译器是否定义该宏
```
