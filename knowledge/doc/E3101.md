# E3101: aarch64 编译器不定义 32 位 ARM 宏 __VFP_FP__/__ARMEB__，软浮点库据此选中的 FPA 字交换分支被误入，所有 double 位模式前后 32 位对调（单精度与比较函数恰好幸存），表现为双精度算术静默返回垃圾值

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, aarch64, abi, softfloat
- **作者**: unknown
- **来源 PR**: PENDING

## 错误特征
```
addsf3 OK but adddf3 wrong|
```

## 根因分析
某些为 32 位 ARM 编写的软浮点实现，用 `__VFP_FP__`（VFP 浮点

## 推荐方案
**方法**: treat-arm32-word-order-macros-as-absent-on-aarch64

**说明**: 修复方式是**把 __aarch64__ 显式加入"自然序（不做 FPA 字交换）"

**修复命令**:
```
clang -dM -E -x c /dev/null | grep -E "__VFP_FP__|__ARMEB__"
```

**验证**:
```
# 1) 确认目标编译器不定义这两个宏（免费信号）
```
