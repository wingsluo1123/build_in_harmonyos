# E3102: 传递共享库导出同名符号导致链接顺序抢占与未签名 NEEDED 依赖，需要把静态提供者前置并用 --as-needed

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, runtime, link
- **作者**: songzhenyan
- **来源 PR**: 14051

## 错误特征
```
Error loading shared library libpulse-simple\.so\.0.*needed by.*yatm|Error relocating.*yatm: sf_open_fd: symbol not found|Error relocating.*yatm: sf_seek: symbol not found|Error relocating.*yatm: sf_readf_float: symbol not found
```

## 根因分析
Conan 依赖图把传递共享库 libpulsecommon-17.0.so 放在静态 libsndfile.a 之前，且该共享库导出了 sf_* 符号；链接器按首次命中解析，导致本应由静态归档提供的符号被共享库抢占，未使用的 pulse 依赖也被写入 NEEDED，运行期因未签名共享库加载失败

## 推荐方案
**方法**: static-first-as-needed

**说明**: 把真正提供符号的静态依赖放在传递共享库之前，并追加 -Wl,--as-needed 剔除未被引用的共享库

**修复命令**:
```
target_link_libraries(yatm ${SNDFILE_LIBRARIES} ${MAD_LIBRARIES} ${OGG_LIBRARIES} ${SLANG_LIBRARIES} ${SOUNDTOUCH_LIBRARIES} ${SPEEX_LIBRARIES} ${AO_LIBRARIES}); toolchain.extra_exelinkflags.append("-Wl,--as-needed")
```

**验证**:
```
BIN=$(find "$HOME/.conan2/p" -path "*/yatm*/p/bin/yatm" -type f | sort | tail -1); PULSE=$(find "$HOME/.conan2/p" -name "libpulsecommon-17.0.so" | head -1); readelf -d "$BIN" | grep NEEDED; nm -D "$PULSE" | grep -E "sf_open_fd|sf_seek|sf_readf_float"
```
