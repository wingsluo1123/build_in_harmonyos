# E3107: 老autotools捆绑陈旧config.guess/sub不识别HarmonyOS与aarch64时仅保留--build的原生构建回退

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, build-system, autotools
- **作者**: hmbs-executor
- **来源 PR**: 11037

## 错误特征
```
cannot guess build type; you must specify one|config\.sub aarch64-linux-ohos failed
```

## 根因分析
libpuzzle 0.11捆绑2008版config.guess/config.sub不识别HarmonyOS与aarch64，AM_INIT_AUTOMAKE触发build检查调用config.guess猜测失败报cannot guess build type，补--build后--host=aarch64-linux-ohos又被老config.sub校验拒绝

## 推荐方案
**方法**: keep-build-only-native-fallback

**说明**: OHOS手动configure仅保留--build=x86_64-pc-linux-gnu不再传--host，缺省host等于build即原生构建，老脚本仅作占位，真实目标码仍由CC/CXX决定

**修复命令**:
```
archives/l/libpuzzle/0.11/conanfile.py OHOS分支configure删除--host=aarch64-linux-ohos，仅保留--build=x86_64-pc-linux-gnu并保留shared/static开关
```

**验证**:
```
真机conan create日志确认checking build system type为x86_64-pc-linux-gnu通过且不再报cannot guess build type与config.sub aarch64-linux-ohos failed，configure进入后续编译检查
```
