# E3108: HMDFS 上 autoconf AS_TMPDIR 用 mktemp -d ./conf* 生成的暂存目录不可写（chmod 0/umask 077）时以 mkdir fallback 或 umask 022 修复

## 基本信息
- **严重度**: 3
- **类别**: compat, hmdfs, ohos, build-system, autotools
- **作者**: hmbs-executor
- **来源 PR**: 15124

## 错误特征
```
can't create ./conf[^*]*/subs1\.awk: Permission denied|could not setup config files machinery|config\.status: error: could not setup config files machinery|(umask 077 && mktemp -d "./confXXXXXX")
```

## 根因分析
autoconf 的 AS_TMPDIR 在 configure/config.status 中默认用 (umask 077 && mktemp -d "./confXXXXXX") 在构建目录创建暂存目录；在 HMDFS 上该目录落盘后 owner 不可写（chmod 能力为 0、HMBS_CAP_CHMOD=0 无法 chmod 修正，或 setgid 目录在 umask 077 下生成 owner 不可写），导致 config.status 向 ./conf*/subs1.awk 写入时 Permission denied

## 推荐方案
**方法**: patch-asm-tmpdir-mkdir-umask-022

**说明**: 不再依赖 mktemp(1) 及 chmod/symlink，确定性改走 autoconf 自带的 (umask 022 && mkdir "$conf$$-$RANDOM") mkdir fallback，保证 HMDFS 上产 owner 可写暂存目录

**修复命令**:
```
patches/0003-configure-as-tmpdir-mkdir.patch: 修改生成 configure 的 AS_TMPDIR 分支，去掉 mktemp 分支、恒定走 (umask 022 && mkdir "$tmp")；conanfile.py build() 用 umask 022 前缀运行 configure、make 追加 SHELL=/bin/sh；conandata.yml/notes.md 登记补丁并记录决策
```

**验证**:
```
真机 configure 阶段日志不再出现 Permission denied/could not setup config files machinery；生成配置完成后 config.status 可向 ./conf* 暂存目录正常写入并产出 Makefile
```
