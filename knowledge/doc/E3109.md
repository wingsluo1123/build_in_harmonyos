# E3109: meson 把手册和翻译工具标成 required 时，用 feature auto 跳过缺失工具

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, build-system, meson
- **作者**: iKalous_OscarP

## 错误特征
```
Program asciidoctor found: NO|Program po4a found: NO
```

## 根因分析
上游 meson.build 对 asciidoctor 与 po4a 使用 find_program required true，设备没有这两个程序。改成 feature 选项且值为 auto 后，配置继续，日志只记录 found NO。

## 推荐方案
**方法**: meson-feature-auto

**说明**: 增加 man 与 nls 两个 feature 选项，默认 auto；find_program 的 required 改为 get_option；只有 found 才进入 man 或 po 子目录。enabled 时工具缺失仍然失败。

**修复命令**:
```
meson setup build -Dman=auto -Dnls=auto
```

**验证**:
```
meson setup 的日志同时出现 Program asciidoctor found NO 与 Program po4a found NO，并且仍然打印 Build targets
```
