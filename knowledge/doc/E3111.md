# E3111: Python 新版对正则字符串的无效转义警告会使旧测试的 stderr 断言失败

## 基本信息
- **严重度**: 2
- **类别**: portability, python, testing
- **作者**: iKalous_OscarP
- **来源 PR**: 13550

## 错误特征
```
SyntaxWarning:.*invalid escape sequence|assertEqual\(stderr, ''\)|FAIL: test_nonexistent_operation|FAIL: test_patch_dir|FAIL: test_patch_file
```

## 根因分析
普通 Python 字符串中的正则转义（例如点号的 \.) 在较新解释器上触发 SyntaxWarning。若上游测试通过子进程运行模块并要求 stderr 为空，导入时警告会污染 stderr，使功能行为正确的用例失败。

## 推荐方案
**方法**: use-raw-string-for-regex-literals

**说明**: 将仅用于正则表达式的普通字符串字面量改为原始字符串，保持传给正则引擎的字符序列不变并消除词法层警告；随后重跑完整上游测试并检查 stderr。

**修复命令**:
```
python3 -Werror::SyntaxWarning -m py_compile sixer.py && python3 tests.py
```

**验证**:
```
python3 tests.py; python3 -Werror::SyntaxWarning -m py_compile sixer.py
```
