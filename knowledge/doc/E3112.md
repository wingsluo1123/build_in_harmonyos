# E3112: Header-only trait algorithms need a concrete backend consumer test

## 基本信息
- **严重度**: 1
- **类别**: headers, conan, testing, cxx
- **作者**: iKalous_OscarP

## 错误特征
```
no upstream build or test target|test_package.*only includes.*template headers
```

## 根因分析
SymFPU core algorithms are class/function templates parameterized by a traits type. The pinned 2019-05-17 source archive contains the generic core and utility headers but no concrete baseTypes backend, build system, or test suite; including headers alone does not instantiate or execute the floating-point algorithms.

## 推荐方案
**方法**: instantiate-template-api-with-test-only-backend

**说明**: Compile a test-only concrete backend alongside the consumer, link the package's public headers through CMakeDeps, and call the actual generic unpack, arithmetic, and pack APIs with known bit patterns. Keep the backend out of the published package.

**修复命令**:
```
conan create archives/s/symfpu/0.0-git20190517.8fbe139 -pr:h ohos-aarch64 -pr:b ohos-aarch64 --build=missing
```

**验证**:
```
conan create archives/s/symfpu/0.0-git20190517.8fbe139 -pr:h ohos-aarch64 -pr:b ohos-aarch64 --build=missing
```
