# E3114: 真实文件缓冲写入须传播 fflush 提交失败，并限定新建残件清理

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, libc, posix
- **作者**: 4CC1
- **来源 PR**: 12590

## 错误特征
```
failed to flush
```

## 根因分析
业务写函数返回成功不包含 FILE 缓冲提交结果；原 xmlcatmgr 2.2 忽略关闭结果，在文件增长受限时可能漏报延迟写入失败，这是源码推导；修后目标日志直接证明 fflush 失败报告和 CLI 退出 1。

## 推荐方案
**方法**: manual-patch

**说明**: 在解除保护前检查 fflush(f)==EOF，保留失败结果到 CLI；继续处理关闭与资源释放而不覆盖先前错误；仅清理本轮排他新建且失败的文件。已有文件更新只准确报错，不声称回滚。

**修复命令**:
```
在 xmlcatmgr 2.2 固定来源树中核对原适配 PR #12590 的 0001-validate-errors-and-locking.patch，参考配套 MD 的提交点片段并按目标库实际错误契约人工移植。
```

**验证**:
```
使用配套 MD 的独立子进程示例；仅在子进程忽略 SIGXFSZ 并设置 RLIMIT_FSIZE=(0,0)，在自建临时目录核四条命令 rc=1/failed to flush/File too large，正常 create rc=0 且 stderr 为空。
```
