# E3115: LLVM 22 llvm-lit stops falling back to PATH when resolving tools, so clang/test/lit.cfg.py use_clang(required=True) aborts the whole suite with a first-line fatal and 0 tests executed

## 基本信息
- **严重度**: 2
- **类别**: test-harness-platform
- **作者**: unknown

## 错误特征
```
could not find clang program|couldn't find 'clang' program|fatal:*lit*|Did not find * in *bin
```

## 根因分析
In LLVM 22 lit.llvm.config.LLVMConfig.use_llvm_tool(name, search_env, required, search_paths, use_installed) searches only search_paths (clang_tools_dir + llvm_tools_dir) and then, only when use_installed=True, the environment PATH. clang/test/lit.cfg.py calls llvm_config.use_clang() which uses the default required=True, so if no `clang` driver binary exists in the build tree the lit_config.fatal path fires while the suite configuration is loaded, before any test runs (the run reports 0 passed). LLVM 11's use_llvm_tool searched config.environment['PATH'] unconditionally, which is why the clang-format-11 11.1.0 recipe worked on the same device (the hnp clang on PATH was picked up by accident). A recipe that builds only clang-format (target `clang-format`, not the `clang` driver) therefore regresses from ~30 passed to 0 passed purely from the toolchain upgrade.

## 推荐方案
**方法**: export-clang-via-search-env-override

**说明**: Before invoking llvm-lit, set the environment variable CLANG to the toolchain clang driver (for OHOS take it from the conan profile conf tools.build:compiler_executables["c"], never a hardcoded shell variable - R33). use_llvm_tool reads search_env="CLANG" first and, per its own docstring, "If the override is specified in the environment, use it without validation", so the fatal is bypassed. This is correct for suites that exercise tools other than the driver: clang/test/Format only ever invokes clang-format, and FileCheck/count/not are separate required tools that are built explicitly.

**修复命令**:
```
build(); before self.run("... bin/llvm-lit ...") do os.environ["CLANG"] = <conf tools.build:compiler_executables.c>
```

**验证**:
```
cmake --build build-ohos --target clang-format FileCheck FormatTests count not llvm-config && bin/llvm-lit -sv clang/test/Format   (without CLANG: fatal, 0 passed; with CLANG: 32/32)
```
