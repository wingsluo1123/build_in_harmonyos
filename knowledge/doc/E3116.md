# E3116: 1994 年 autoconf configure 拒绝 Conan AutotoolsToolchain 追加的 --bindir/--libdir 等现代选项

## 基本信息
- **严重度**: 2
- **类别**: autotools, conan
- **作者**: 9DB5
- **来源 PR**: feat/rsynth-2.0

## 错误特征
```
--bindir=${prefix}/bin: invalid option|invalid option; use --help|configure: error: --.*: invalid option
```

## 根因分析
1994 年 autoconf 2.0 生成的 configure 只支持 --prefix/--srcdir 等少量选项；Conan AutotoolsToolchain 默认追加 --bindir=${prefix}/bin --sbindir --libdir --includedir --oldincludedir --datarootdir 等现代选项，configure 无法识别直接 abort（error: invalid option）。

## 推荐方案
**方法**: prune-toolchain-flags

**说明**: conanfile.py generate() 中裁剪 AutotoolsToolchain 自动追加的 install flags，仅保留 --prefix=/：遍历 tc.configure_args 删除以 --bindir/--sbindir/--libdir/--includedir/--oldincludedir/--datarootdir 开头的项，再 tc.generate()。

**修复命令**:
```
for flag in ('--bindir','--sbindir','--libdir','--includedir','--oldincludedir','--datarootdir'): tc.configure_args=[a for a in tc.configure_args if not a.startswith(flag)]
```

**验证**:
```
conan create ... | grep 'configure.*--prefix=/'
```
