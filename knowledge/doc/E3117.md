# E3117: autotools 栈 OHOS 真机平台微载适配：ohos 三元组缺失、HMDFS 只读/tmp 与 mktemp fork 不可用、CONFIG_SHELL getcwd 失败、install shim 多源 EX_USAGE 统一修复

## 基本信息
- **严重度**: 3
- **类别**: compat, limitation, hmdfs, ohos, portability
- **作者**: hmbs-executor
- **来源 PR**: 14971

## 错误特征
```
Invalid configuration .* system `ohos' not recognized|config.status: error: could not setup config files machinery|working directory cannot be determined|can't fork - try again|Error 64|EX_USAGE|install-dist_exampleDATA
```

## 根因分析
autotools 系配置链在 OHOS 真机的 HMDFS/受限 shell 上逐环暴露四个平台微载缺口：(1) config.guess/sub 的 KERNEL-OS/OS 后缀表缺 ohos 三元组判 Invalid configuration；(2) configure/config.status 以 umask 077 + mktemp 建的临时目录在 HMDFS 只读/tmp 与 fork 不可用下不可写；(3) 前导 CONFIG_SHELL 重执行把进程切到 getcwd 失败的 hnp bash 致 working directory cannot be determined；(4) HMBS 注入的 install shim 只收单文件两参，automake 批量多源安装 exit 64 (EX_USAGE)

## 推荐方案
**方法**: unified-autotools-ohos-platform-adaptation

**说明**: 组合补丁 + env 直驱 + 本地 shim 的统一套路：config.guess/sub 补 ohos 三元组、configure 临时目录 mkdir fallback + umask 022、CONFIG_SHELL/SHELL 强制 /bin/sh 跳过 hnp bash 重执行、package 内写 cp/mkdir install shim 并递归重定向生成 Makefile 的 INSTALL 变量

**修复命令**:
```
patches/0001-config.guess-ohos.patch + 0002-config.sub-ohos.patch 补 linux-ohos*/ -linux-ohos*；0003-configure-hmdfs-umask.patch 把 mktemp→false 强制 mkdir fallback 且 umask 077→022；build() 用 CONFIG_SHELL=/bin/sh SHELL=/bin/sh sh configure 并 _setup_fs_env() 置可写 TMPDIR/PWD/SHELL；make/install 追加 SHELL=/bin/sh；package() 写 cp/mkdir install shim 并递归重定向 build-release/ 各 Makefile 的 INSTALL 路径
```

**验证**:
```
真机日志保留 configure/compile/package 全阶段真实结果：config.sub 对 aarch64-unknown-linux-ohos RC=0 原样输出；configure/config.status 无 Permission denied；CONFIG_SHELL/SHELL=/bin/sh 直驱无 working directory cannot be determined；make install 走 cp/mkdir shim 全量安装无 EX_USAGE
```
