# E3118: 上游 README 宣称的 SIMD 开关选项（PFFFT_USE_SIMD_NEON）在 CMake 实现中不存在，且 PFFFT_ENABLE_NEON 宏的唯一注入路径（TARGET_C_EXTRA=neon_*）仅在 armv7l 分支提供 —— 非 Apple aarch64 Linux/OHOS 构建成功但 SIMD 静默退化为标量路径；识别特征是编译日志 pragma "building float with simd disabled !"；修复用 CMAKE_C_FLAGS 注入 -DPFFFT_ENABLE_NEON=1 并以 pffft_simd_size()==4 断言收口
