# E3120: tag archive + git-version-gen 上游的 version 文件钉版法

## 基本信息
- **严重度**: 1
- **类别**: portability, cmake, conan, version-provenance
- **作者**: 0AE8

## 错误特征
```
version.*GIT|0\.8\.0\.GIT|soname.*GIT|Unknown version
```

## 根因分析
git-version-gen 系脚本按"源根 version 文件→git describe→DEF_VER 默认值"三级取版;tag archive 无 .git 时回退默认脏版本(如 0.8.0.GIT),污染 ONION_VERSION/soname/pkg-config Version。脚本第一优先级本就是读源根 version 文件——发布工程自带的钉版接口,tag archive 只是没带上。

## 推荐方案
**方法**: version-file-pin-before-configure

**说明**: (1) 读上游 git-version-gen 头 40 行确认取版优先级与钉版文件名(version 或 .tarball-version);(2) build() 在 configure 前写该文件,内容=任务版本号(脚本自剥 v 前缀);(3) WSL 预验证核 soname/pc Version 干净;(4) 属配方资产注入(构建输入),非改上游文件字节。

**修复命令**:
```
echo "0.8" > "$SRC/version" && cmake -S "$SRC" -B build && grep "version is" build/CMakeCache.txt
```

**验证**:
```
echo "<任务版本>" > "$SRC/version";configure 日志核版本打印;ls lib/ 核 soname 干净命名;cat lib/pkgconfig/*.pc 核 Version 字段
```
