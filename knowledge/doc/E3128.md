# E3128: 自研 shell 构建系统用 `uname -s` 做平台探测、未识别值走默认分支（常为

## 基本信息
- **严重度**: 3
- **类别**: platform, detection, ohos, portability, build-system
- **作者**: frj__
- **来源 PR**: (本分支 feat/retroarch-1.22.2，PR #14934，关联 B issue)

## 错误特征
```
Checking operating system \.\.\. Win32|
```

## 根因分析
OHOS 真机 `uname -s` 返回 `HarmonyOS`（内核 sysname），不在

## 推荐方案
**方法**: merge-harmonyos-into-linux-branch

**说明**: 把 `'HarmonyOS'` 并入既有 Linux 分支（`'Linux'|'HarmonyOS') OS='Linux';;`）。

**修复命令**:
```
sed -i "s/'Linux') OS='Linux';;/'Linux'|'HarmonyOS') OS='Linux';;/" qb/qb.system.sh
```

**验证**:
```
uname -s                       # -> HarmonyOS（真机）
```
