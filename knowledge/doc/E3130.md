# E3130: 优化构建会静默改变后端机器码（VEX/EVEX 编码错误）；须靠字节级上游对照发现

## 基本信息
- **严重度**: 2
- **类别**: toolchain, compiler, testing
- **作者**: frj__
- **来源 PR**: 14452

## 错误特征
```
c4 e2 59 8c f0 00|c4 e2 69 45 d6 00|-O2.*(VEX|EVEX)|optimized build emits wrong machine code
```

## 根因分析
codegenv2.c 中的类型双关/共用体别名等在 aarch64 clang23 -O2 下被优化器

## 推荐方案
**方法**: byte-exact-upstream-oracle

**说明**: 以定向上游“期望产物”做逐字节 oracle，对后端/编码类工具在 aarch64 上先用 -O0

**修复命令**:
```
make CFLAGS="-O0 ..."; <runner> <bin> <upstream-exp-dir> ; cmp each output
```

**验证**:
```
printf '    .x64\\n    .model flat\\n    .code\\n    vpmaskmovd xmm6,xmm4,OWORD PTR [rcx]\\nend\\n' > v.asm;
```
