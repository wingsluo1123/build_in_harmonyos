# E3131: LP64 平台上用 (unsigned long) 实现 32 位语义（位移/掩码）会静默算错

## 基本信息
- **严重度**: 2
- **类别**: portability, compiler, architecture
- **作者**: frj__
- **来源 PR**: 14452

## 错误特征
```
-1 SHR|\(unsigned long\).*>>|0xffffffff.*(>>|SHR)|sizeof\(long\).*8
```

## 根因分析
源码用 (unsigned long) 表达“32 位 MASM/win32 语义”的位移与掩码；

## 推荐方案
**方法**: fixed-width-cast

**说明**: 用定宽无符号类型（uint_32/uint32_t）替换语义上要求 32 位的 unsigned long

**修复命令**:
```
define uint_32 as unsigned int; cast (uint_32)value before shift/mask
```

**验证**:
```
printf 'int main(){long v=-1; printf("%%llx/%%x\\n",(unsigned long)v>>4,(unsigned)((unsigned long)v>>4)); return 0;}' > p.c;
```
