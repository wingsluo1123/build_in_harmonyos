# E3140: "1) 目标库改 STATIC（BUILD_SHARED_LIBS=OFF / add_library 去 SHARED

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, build-system, cmake
- **作者**: unknown

## 错误特征
```
"relocation R_AARCH64_ADR_PREL_PG_HI21 cannot be used against symbol .* recompile with -fPIC|Could NOT find GLIB \\(missing: GLIB_GIO_UNIX_INCLUDE_DIR\\)|_qt5_Core_check_file_exists|Target \"?Qt5::Svg\"? .*not found|'gio/gio\\.h' file not found"
```

## 根因分析
"OpenHarmony 制品仓的 zlib/glib 只有非 PIC 静态归档，无法链进 .so；且 qt5-qtbase 包内原生 Qt5 umbrella cmake 配置烘焙了构建机路径（不可重定位），Conan CMakeDeps 又不产出 Qt5 宏/私有头/大写 GLIB_* 变量。"

## 推荐方案
**方法**: "1) 目标库改 STATIC（BUILD_SHARED_LIBS=OFF / add_library 去 SHARED）；2) 生成 CMAKE_PROJECT_INCLUDE shim 补齐 moc/qdbusxml2cpp/私有头/qt5_add_dbus_interface 并把 zlib::zlib 置空；3) deps.set_property('glib','cmake_find_mode','none') 让 FindGLIB 走 module 模式；4) 生成 gio-unix-2.0.pc；5) 把 glib 传递静态归档注入 PUBLIC 接口。"
