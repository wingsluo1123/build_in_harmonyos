# E3142: conan 配方消费 zig/ 工具包的完整模式：tool_requires 按上游 minimum_zig_version 硬 pin + build() 清 CC/CXX 系规避 0.15.x sysroot 探测 + wrapper 自动签名/AccessDenied 重试 + package() _sign_elf + zon 依赖 vendored 本地 .path 零网络构建

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, toolchain, conan, code-signing
- **作者**: hmms-builder
- **来源 PR**: pending

## 错误特征
```
failed to spawn .*AccessDenied|minimum_build_zig_version|minimum_zig_version|@compileError|'bits/alltypes\.h' file not found|Downloaded 0 of .*bytes|unable to unpack tarball|error: the following build command failed with exit code
```

## 根因分析
OHOS 上（1）每个被执行的 ELF 必须携带有效签名——zig 构建期反复生成/派生宿主可执行（build runner、gen exe、测试二进制），最终产物还需打包后签名；（2）zig 在 OHOS 的宿主 libc 探测会 consult 系统 OHOS SDK clang 并注入不完整 sysroot（其 stdint.h 依赖 musl bits/alltypes.h 而该 sysroot 不含此头）——zig/0.15.x 下清空 CC/CXX/CFLAGS/CPPFLAGS/LDFLAGS/CPATH/C_INCLUDE_PATH 即可让 zig 回落自带头，zig/0.16.x 探测通道与 env 无关须换 -Dtarget 或文件级 vendor（见 odiff 条）；（3）上游 build.zig.zon 的 url 依赖在 zig build 期网络抓取，runner/worker 网络（github 直连/代理）不可控；（4）上游以 minimum_build_zig_version/minimum_zig_version 硬 pin zig major.minor，跨 pin 版本直接 @compileError

## 推荐方案
**方法**: zig-toolchain-consumption-pattern

**说明**: 五件套范式（全部经真机验证）：① tool_requires 严格按上游 minimum_zig_version 选包：0.15.x pin 用 zig/0.15.2，0.16.x pin 用 zig/0.16.0.1，禁止跨 pin（zls 0.15.1 在 0.16.x/0.14.x 直接 @compileError；minizign/odiff 为 0.16 专用）；② build() 先清 CC/CXX/CFLAGS/CPPFLAGS/LDFLAGS/CPATH/C_INCLUDE_PATH/CPLUS_INCLUDE_PATH（zig/0.15.x 有效路径，flow-control 21/21 步、zls 49/49 步实证），并把 ZIG_GLOBAL_CACHE_DIR/ZIG_LOCAL_CACHE_DIR 钉进 build_folder、ZIG_OHOS_SIGN_ROOTS 覆盖双缓存+zig-out（wrapper 据此自动签名构建期产物；每次 zig build 首轮对新建宿主可执行报 failed to spawn ... AccessDenied 属预期，wrapper 签名后自动重跑同一命令成功，勿当失败处理、勿重写重试）；③ build.zig.zon 非 lazy 依赖在 source() 以 pinned tarball（conandata 固定 URL+SHA256，附 gh-proxy 回退）vendored 到 deps/ 并 patch 成本地 .path 引用，实现零网络构建（minizign/zls 实证；lazy 依赖如 tracy 不启用即不抓取）；④ 产物在 package() 内 _sign_elf（llvm-objcopy --remove-section .codesign 后 binary-sign-tool sign -selfSign 1）；⑤ 上游测试 zig build test 直接内嵌 build() 真实执行，host 目标下 build-runner 类步骤照常运行（wrapper 路径作为 b.graph.zig_exe 传递，签名覆盖缓存根即可）

**修复命令**:
```
conanfile.py: build_requirements(){ self.tool_requires("zig/<upstream-pin>") }; build(){ pop CC/CXX/CFLAGS/CPPFLAGS/LDFLAGS/CPATH/C_INCLUDE_PATH/CPLUS_INCLUDE_PATH; export ZIG_GLOBAL_CACHE_DIR/ZIG_LOCAL_CACHE_DIR=<build_folder>/…; export ZIG_OHOS_SIGN_ROOTS="<global> <local> <source>/zig-out"; self.run('zig build -Doptimize=ReleaseSafe --summary all', env="conanbuild"); self.run('zig build test …', env="conanbuild") }; source(){ get(主源码, filename=显式.tar.gz, strip_root=True); get(各依赖, sha256=…, destination=deps/<name>) }; package(){ copy zig-out/bin/<exe>; if OHOS: _sign_elf }
```

**验证**:
```
conan create archives/<X>/<pkg>/<ver> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=<pkg>/*；日志核验：zig version 行、Build Summary 全成功（AccessDenied 后 wrapper 自动重跑的两次 Build Summary 属预期）、上游测试计数、package() 内 "add codesign section success"
```
