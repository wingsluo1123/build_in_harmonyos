# E3143: pkg-config 消费链上 cpp_info.requires 的 include 传递不可达：X11 协议头断层必须显式 requires xorgproto 并在 pc 检测名声明 xproto（NOLINK 只取 Cflags），两处缺一不可

## 基本信息
- **严重度**: 2
- **类别**: headers, conan, pkg-config, consumer-chain, x11
- **作者**: unknown

## 错误特征
```
fatal error: .X11/X\.h. file not found|X11/Xatom\.h.*file not found|X11/Xmd\.h.*file not found|X11/keysym\.h.*file not found|X11/Xproto\.h.*file not found
```

## 根因分析
PkgConfigDeps 生成的 x11.pc 只含 libx11 自身 include，Requires 链仅 xcb——xorgproto 未声明 pkg_config_name，既不被代生成 .pc 也不进上游 pc 的 Requires；于是以 pc 检测名取头的消费方（juce_add_module linuxPackages、PKG_CHECK_MODULES）拿不到协议头 include，而配方 cpp_info.requires（含 transitive_headers）只保证图内存在性并对 CMakeDeps/targets 传播，对 pkg-config 消费链不可达。X11/X.h、Xatom.h、Xmd.h、keysym.h、Xproto.h 均由 xorgproto 制品提供，不在 libx11 包内。

## 推荐方案
**方法**: explicit-xorgproto-requires-plus-pkgconfig-detection-name

**说明**: (1) 消费配方 self.requires("xorgproto/2025.1", transitive_headers=True)，版本与 libx11 依赖一致（2024.1/2025.1 图内冲突先例）；(2) pc 检测名声明 xproto（juce: linuxPackages "NOLINK x11 xproto"；autotools: PKG_CHECK_MODULES 列表加 xproto）；(3) xorgproto 自带真实 .pc（share/pkgconfig，${pcfiledir} 相对前缀）且依赖 buildenv_info 的 PKG_CONFIG_PATH 会传播进消费方 conanbuild 环境；(4) 用三态探针验收（缺 requires 挂、缺检测名挂、双修过），不得以 vendor 头或越界改上游配方替代。

**修复命令**:
```
self.requires("xorgproto/2025.1", transitive_headers=True)  +  linuxPackages: NOLINK x11 xproto
```

**验证**:
```
sh -c "pkg-config --cflags xproto >/dev/null && printf \x27#include <X11/Xlib.h>\nint main(void){return 0;}\x27 | clang -x c - -fsyntax-only \$(pkg-config --cflags x11 xproto) && echo TRIPLE_PROBE_PASS"
```
