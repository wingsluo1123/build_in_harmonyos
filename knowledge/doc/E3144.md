# E3144: RubyGems 应用适配 OHOS 的打包与上游执行范式：未发布 ruby 包走系统 Ruby、离线自证 gem 闭包、预编译平台 gem 的 stub 重标、上游测试入口的隐藏硬依赖

## 根因分析
把 RubyGems 应用（纯 Ruby，无 C/C++ 主程序）适配到 OHOS 时，六件事连环：① 语言运行时的仓内依赖不可消费——ruby/3.4.10 已在本仓适配但未发布到 ohpcd，配方若 tool_requires 它就直接卡死（R36），正确做法是走构建环境自带的系统 Ruby（HNP，/data/service/hnp/bin/ruby|gem），这也是本仓 Ruby 软件的既有范式；② 构建期不能靠 bundler/rubygems 联网解析依赖——必须离线把整棵 gem 闭包固定成 url+sha256，用 gem install --local --ignore-dependencies 安装，闭包完整性由本仓自证；③ 含 C 扩展/预编译二进制的 gem 必须在目标平台上落到正确的那份二进制：OHOS 是 musl，nokogiri/ffi/google-protobuf/sass-embedded 都有 aarch64-linux-musl 变体，但 RubyGems 只在 Gem::Platform.local 与 spec 记录的 platform 完全一致时才激活它，而设备上的 HNP ruby 报出的平台字符串未必等于该名字，于是需要重标 gem 身份；④ 重标必须同时改四处，只改 s.platform 不够——spec 文件首部的 `# stub: <name> <version> <platform> <require_paths>` 注释才是 RubyGems 快速查找（stubs_for / find_by_path）的依据，漏改会导致 require 无法自动激活（本地实测：require 失败但 gem 'x'; require 成功）；⑤ 上游测试入口往往有隐藏的硬依赖：jekyll 的 test/helper.rb 无条件 require nokogiri，且用 minitest-reporters/minitest-profile/rspec-mocks/shoulda-context/simplecov，所以『只 vendor 运行期闭包』跑不了任何一个上游用例；⑥ 上游 gem 与 tag archive 内容不同：gemspec 常只把 (exe|lib|rubocop)/ 打进 gem，gem 里没有 test/，跑上游测试必须另取 tag archive。此外 test/fixtures 下的 path gem（主题 fixture）不能用 gem build——它们 gemspec 里 s.files 会声明不存在的文件，RubyGems 直接拒绝，应按 bundler 的 path gem 语义手工放置 gem 目录 + 最小 specification；上游用例还可能联网（jekyll new 会 bundle install）必须逐用例加超时。

## 推荐方案
**方法**: offline-self-proven-gem-closure-with-platform-gem-retargeting

**说明**: 七步：① 用 rubygems.org API 离线 BFS 解析出完整 gem 闭包（含上游测试入口 require 的开发期 gem），对每个 gem 的每一条约束做交叉校验，0 冲突才继续；② conandata 里把每个 .gem 的 url + sha256 固定，含 C 扩展的 gem 同时 vendor 目标平台的预编译变体（OHOS→aarch64-linux-musl）与 ruby 平台源码；③ build() 用系统 Ruby（HNP）gem install --local --ignore-dependencies 装进包内 gem home，构建期绝不联网解析依赖；④ 变体选择按目标 settings 显式决定（不看 Gem::Platform.local）；⑤ 选中预编译变体后重标 gem 身份四处：gems/<name>-<ver>(去掉平台后缀)、specifications/<name>-<ver>.gemspec、文件里的 s.platform=Gem::Platform::RUBY、以及首部 # stub: 行的 platform 字段；⑥ 上游测试另取 tag archive（gem 里没有 test/），path gem fixture 按 bundler 语义手工放置目录+最小 spec，每个测试文件加超时（subprocess timeout，conan 的 self.run 不支持）；⑦ test_package 用真实最小工程（jekyll build 一个站点并断言渲染结果）。

**修复命令**:
```
python3 draft-closure.py（离线解析+约束校验）; conandata: rubygems.org/downloads/<name>-<ver>[-<plat>].gem + sha256; GEM_HOME=... gem install --local <gem> --install-dir ... --ignore-dependencies; GEM_HOME=... ruby -Ilib -Itest test/test_x.rb（subprocess timeout=300）
```
