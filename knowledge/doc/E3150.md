# E3150: CMake 裸名链接改 pkg_check_modules + Boost 缺组件时裁剪目标

## 基本信息
- **严重度**: 2
- **类别**: cmake, cross-compile, conan, boost
- **作者**: 2301_80739235

## 错误特征
```
"cannot find -l|undefined reference to|Could NOT find Boost|interprocess|cmake_minimum_required.*3\\.0|CMAKE.*3\\.0.*no longer"
```

## 根因分析
CMake 的 target_link_libraries 用裸库名(evdev/udev/yaml-cpp)时,链接器只在系统默认路径搜索,conan 依赖库不在其中(CMakeDeps 只产出 target);上游把需要 Boost.Interprocess 的可选目标(mux)硬编进主构建并对 Boost 用 REQUIRED,而仓库 boost 配方组件集不含 interprocess;cmake_minimum 3.0 低于现代 CMake 下限。

## 推荐方案
**方法**: pkg-check-modules-plus-target-trim

**说明**: 补丁三合一:cmake_minimum 升 3.10;udev/yaml-cpp 改 pkg_check_modules 并以 ${*_LIBRARIES} 链接(与上游已内置的 libevdev 同法);移除 Boost 依赖与 mux 目标的 add_executable/链接/install 四行。依赖改由 conan requires + PkgConfigDeps 供给。

**修复命令**:
```
pkg_check_modules(UDEV REQUIRED udev); pkg_check_modules(YAMLCPP REQUIRED yaml-cpp); target_link_libraries(udevmon ${LIBEVDEV_LIBRARIES} ${UDEV_LIBRARIES} ${YAMLCPP_LIBRARIES})
```
