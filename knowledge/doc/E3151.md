# E3151: Autotools 安装钩子会在 DESTDIR 打包时执行系统级副作用

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, autotools, packaging
- **作者**: iKalous_OscarP

## 错误特征
```
chown:.*Operation not permitted|install-sh:.*does not exist|DESTDIR.*setuid
```

## 根因分析
DESTDIR 只重定向安装路径，不会自动屏蔽 install-exec-hook 中的 chown/setuid 或 Linux init 子目录安装

## 推荐方案
**方法**: source-patch

**说明**: 将仅供系统部署的权限变更限制在 DESTDIR 为空或根路径时，并从目标子目录中排除 Linux 专用服务安装

**修复命令**:
```
if test -z "$(DESTDIR)" -o "$(DESTDIR)" = "/"; then chown root:root ...; chmod u+s ...; fi
```

**验证**:
```
grep -nE 'install-exec-hook|chown|chmod|SUBDIRS' Makefile.am; conan create <recipe> --profile:host=<target> --profile:build=<build>
```
