# E3153: GitHub tag tarball 只有 autotools 输入时的配方自带 CMake 包装(单翻译单元 C 库)

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, cmake, autotools, conan
- **作者**: 0AE8

## 错误特征
```
configure: No such file or directory|autoreconf: not found|autoconf: not found|AC_CONFIG_SRCDIR.*missing|CMake Error.*no CMakeLists
```

## 根因分析
codeload 的 tag 归档是否含 configure 取决于上游是否提交生成物，不能一概断言不含。本次绑定归档只有 autotools 输入，目标构建环境缺少再生成工具链；本配方用内嵌 CMake 包装对应 C 组件，并通过真实原始 C/Check 用例验证该组件。

## 推荐方案
**方法**: recipe-contributed-minimal-cmake-wrapper

**说明**: (1) 当前 build() 写出配方内嵌 CMake 包装，cmake/CMakeLists.txt 仅为可读对照而非 export_sources 输入；(2) 原始 C 源码不改，构建 shared/static；(3) basic_layout(src_folder=".")；(4) 消费者逐字节验证 test:/success: 协议，不误写 ok:；(5) 已发布 Check 编译并运行原 C 六例，任务私有 TEMP/TMPDIR、清除继承选择器并核对原注册集合与成功 XML，不再豁免上游测试。此历史包装说明不替代 E2026100501 必交配对草稿（补充 PR 9499/E571）。

**修复命令**:
```
conan create archives/s/subunit/1.4.5 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```

**验证**:
```
conan create archives/s/subunit/1.4.5 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
