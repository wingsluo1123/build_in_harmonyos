# E3156: "OHOS sysroot 的 libintl.h 是 353 字节空壳（零函数声明）且 SDK 链接桩 libc.so 只有 1592 符号、不含 gettext；系统 musl loader /lib/ld-musl-aarch64.so.1（SONAME libc.so）却导出 gettext 与 textdomain —— 私有声明头前置于 sysroot，再加 LDFLAGS=-L/lib -l:ld-musl-aarch64.so.1 即取到真符号，零 conan 依赖、零补丁、非恒等宏"

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, linking, nls, header-stub
- **作者**: "链主-cpufrequtils (主理-2)"
- **来源 PR**: "待建（本轮终点在 W4 审计前）"

## 错误特征
```
"call to undeclared function 'gettext'|incompatible integer to pointer conversion passing 'int' to parameter of type 'const char *'|undefined symbol: gettext|undefined reference to `gettext`"
```

## 根因分析
"两层根因，2026-10-06 在 HarmonyOS PC aarch64（ohos-sdk_26.0.0.18）逐条实测。①头文件层：sysroot 的 usr/include/libintl.h 只有 353 字节，仅定义 __USE_GNU_GETTEXT、__GNU_GETTEXT_SUPPORTED_REVISION 与 __fa（且随后 __fa 被 undef），不声明任何函数，于是源码里对 libintl.h 的包含之后 gettext 与 textdomain 落成隐式 int，clang 15 把 Wint-conversion 判为 error（不是 warning），make 在 utils/info.c 中断。②链接层：SDK 的链接桩 sysroot/usr/lib/aarch64-linux-ohos/libc.so 大小 79424 字节、只导出 1592 个动态符号，llvm-nm -D 对 gettext、dgettext、textdomain、bindtextdomain、ngettext 全部 0 命中，所以只补声明会立刻换成 ld.lld 的 undefined symbol gettext。③反转证据（本条与既有条目的分水岭）：设备运行时的系统 musl loader /lib/ld-musl-aarch64.so.1 大小 2185824 字节、SONAME 就是 libc.so，实测导出 gettext 0x180a1c、dgettext、ngettext、textdomain 0x180974、bindtextdomain，即链接桩没有不等于运行时没有；把 -L/lib 加上 -l:ld-musl-aarch64.so.1 放进链接行，ld 把它解析成普通 libc.so，readelf -d 的 NEEDED 不新增任何条目。"

## 推荐方案
**方法**: "private-libintl-header-plus-system-musl-link"

**说明**: "两步，均落在 conanfile 的 build() 内，不产生任何补丁文件。(1) 声明层：save() 一份按 musl 公开 libintl.h 逐字补齐 9 个函数声明的私有头到 build_folder 下的 ohos-compat-include 目录，并把该目录的 -I 放进 CPPFLAGS，使源码对 libintl.h 的包含命中私有头而先于 sysroot 空壳头。(2) 符号层：仅当 settings.os 为 OHOS 时把 LDFLAGS 置为 -L/lib 加 -l:ld-musl-aarch64.so.1，从系统 musl loader 取真实 gettext 符号。两者通过 make 的环境变量注入（上游 Makefile 对 CPPFLAGS 用 +=、对 LDFLAGS 不做赋值，环境变量形态会与上游旗标叠加而不整体覆盖）。修后 DT_NEEDED 不新增依赖，消费者的 21 条断言全过。"

**修复命令**:
```
"conan create archives/c/cpufrequtils/008 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing"
```

**验证**:
```
"conan create archives/c/cpufrequtils/008 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing"
```
