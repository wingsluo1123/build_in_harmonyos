# E3157: Conan 2.29 里 tc.generate() 放在 build() 会让工具链环境静默失效，

## 基本信息
- **严重度**: 3
- **类别**: toolchain, cross-compile, conan, silent-misbuild
- **作者**: wzp780028 <wang780028@qq.com>

## 错误特征
```
AttributeError: 'AutotoolsToolchain' object has no attribute
```

## 根因分析
Conan 2.29 的 Environment 只有 vars()（返回 EnvVars），没有

## 推荐方案
**方法**: toolchain-in-generate-method

**说明**: 把工具链生成放进配方的 generate() 方法（此时 EnvVars 有完整的

**修复命令**:
```
def generate(self):
```

**验证**:
```
conan create <recipe> -pr:h=<profile> -pr:b=<profile>
```
