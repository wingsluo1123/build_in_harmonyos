## 根因分析

## 推荐方案
**方法**: after-last-prev-ascending

**说明**: 升序遍历用 iwkv_cursor_open(db,&cur,IWKV_CURSOR_AFTER_LAST)

**修复命令**:
```
iwkv_cursor_open(db,&cur,IWKV_CURSOR_AFTER_LAST); while(iwkv_cursor_to_prev(cur,&k,&v)==0){ /* ascending */ iwkv_kv_dispose(db,&k,&v); }
```
