# E3161: OHOS CPython subprocess 裸命令名不可 spawn（posix_spawnp 无 PATH 查找）——Python 包上游测试的"环境性"失败根因

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, python, shell, pytest
- **作者**: lyl_ling

## 错误特征
```
FileNotFoundError.*Errno 2.*No such file or directory: '(echo|ls|sha1sum|cat)'|subprocess.*posix_spawn
```

## 根因分析
本平台（OHOS PC, CPython 3.12.9）的 subprocess 按 PATH 解析

## 推荐方案
**方法**: report-as-platform-env-limitation-and-use-absolute-paths

**说明**: 结论层面：把此类失败如实归类为平台环境限制（非库缺陷），

**修复命令**:
```
python3 -c "import shutil,subprocess; p=shutil.which('echo'); subprocess.run([p,'hi'])"
```

**验证**:
```
python3 -c "import subprocess; subprocess.run(['echo','hi'])"
```
