# E3162: OHOS CPython 平台标识为 'ohos'：Python 包装配后平台分派必须覆盖/退化为 POSIX，并遵循沙箱 XDG 路径

## 基本信息
- **严重度**: 1
- **类别**: platform, ohos, python, environment, xdg
- **作者**: lyl_ling

## 错误特征
```
sys\.platform.*ohos|Unknown Platform.*ohos|NotImplementedError.*Platform
```

## 根因分析
本平台 CPython 报告 sys.platform == 'ohos'（非 'linux'）。纯

## 推荐方案
**方法**: posix-builtin-module-platform-dispatch

**说明**: 平台分派用 POSIX 判据而非 sys.platform 白名单；用户目录统一

**修复命令**:
```
python3 test_package/test_ohos_ubelt.py <site-packages>
```

**验证**:
```
python3 -c "import sys; print(sys.platform)"   # 期望 ohos
```
