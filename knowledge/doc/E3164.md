# E3164: "Convert the awk script into a single-file sh+awk polyglot: 

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, shell
- **作者**: unknown

## 错误特征
```
"awk: Unknown option 'q' (see \"awk --help\") when running '#!/usr/bin/awk -f' scripts with dash-prefixed script arguments"
```

## 根因分析
"toybox 0.8.12 awk violates POSIX argument parsing: after the first operand it still parses dash-prefixed arguments as awk's own options instead of passing them to the script's ARGV. Upstream awk scripts with shebang '#!/usr/bin/awk -f' that accept flags like -q silently break on OHOS. env -S is unavailable so shebang tricks don't help."

## 推荐方案
**方法**: "Convert the awk script into a single-file sh+awk polyglot: shebang #!/bin/sh, then 'exec awk -f /dev/fd/3 -- \"$@\" 3<<'QUOTED_EOF'' followed by the original awk program body and the terminator line. The '--' stops option parsing so dash-prefixed script arguments reach ARGV untouched; quoting the heredoc delimiter prevents shell expansion of the program body (important for scripts emitting \\$ escapes); keeping everything in one file preserves rset's remote-staging distribution model (rset copies renv to the target host as a single file)."
