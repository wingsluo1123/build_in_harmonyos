- **类别**: build-system, cmake, testing
- **作者**: unknown

```
No tests were found|ctest.*No tests|CTestTestfile\.cmake.*no such
```

## 根因分析
>

## 推荐方案
**方法**: ctest-subdir-test-dir

**说明**: conanfile.py build()/本地验证里用

**修复命令**:
```
ctest --test-dir $BUILD/tests --output-on-failure
```

**验证**:
```
find <build> -name CTestTestfile.cmake；若只在
```
