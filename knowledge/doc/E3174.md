# E3174: viewnior 1.8 以 force=True 收敛 glib 到 2.84.0.1，使 ohpcd 已发布的 shared-mime-info/2.5.1 二进制（基于 glib/2.84.0 构建）package_id 失效 → 被迫源码构建 → 撞 shared-mime-info 配方注入的 tree-magic 测试目标链接缺陷（只链 glib-2.0 却引用 GIO/GObject 符号）

## 基本信息
- **严重度**: 2
- **类别**: ohos, conan, dependency-graph, force, glib
- **作者**: 856F
- **来源 PR**: 15134

## 错误特征
```
No compatible configuration found|Main binary package .* missing|undefined symbol: g_file_|undefined symbol: g_object_ref|Error in build\(\) method.*ninja -C|Linking target tree-magic|ld\.lld: error: undefined symbol
```

## 根因分析
viewnior 依赖图同时含 gtk2 链（pin glib/2.84.0.1）与 shared-mime-info/2.5.1（pin glib/2.84.0），配方用 self.requires("glib/2.84.0.1", force=True) 收敛。conan 的 package_id 含直接依赖版本，shared-mime-info 的 glib 依赖被 force 到 2.84.0.1 后 package_id 从 ohpcd 已发布的 2b6465ed（requires glib/2.84.0#f67d9941…）变为 0079104f，CI 查 `No compatible configuration found` → 被迫源码构建。而 ohpcd 官方 shared-mime-info 配方（build-tests=true）在 build() 中往根 meson.build 注入 `test_tree_magic = executable('tree-magic', 'src/test-tree-magic.c', dependencies: [dependency('glib-2.0')], install: false)`，test-tree-magic.c 实际使用 GIO（g_file_*）与 GObject（g_object_ref）符号，链接命令只带 -lglib-2.0 缺 gio-2.0/gobject-2.0 → ld.lld undefined symbol → ninja 失败 → conan create 失败。本地通过是假象：本地 conan 缓存 e73f7b6a 配方为 LOCAL ONLY 修改版（glib/2.84.0.1 + build-tests=false + 跳过 tree-magic 注入），本地 viewnior 构建复用其产物，CI 用 ohpcd 官方配方必然失败。

## 推荐方案
**方法**: drop-pkgconfig-probe-only-requires

**说明**: application 若对某依赖仅需 meson 版本探测且 generate() 已合成 .pc（version only, nothing linked），则从 requirements() 移除该 requires：合成 .pc 已满足 `dependency('xxx', version: '>= X.Y')`，依赖图不再包含该包 → 不触发其二进制解析/源码构建。viewnior 对 shared-mime-info 正是此情形（_synthesize_shared_mime_info_pc 合成 Version 2.5.1 的 .pc），GTK+2 消费者先例（xsane/ant-phone）均不 requires shared-mime-info。

**修复命令**:
```
在 viewnior conanfile.py requirements() 删除 self.requires("shared-mime-info/2.5.1") 一行；保留 generate() 中 _synthesize_shared_mime_info_pc；本地用 CI 同款 profile（ci/conan/profiles/ohos-aarch64）跑 conan create 验证
```

**验证**:
```
conan list 'shared-mime-info/2.5.1:*' -r ohpcd 查已发布二进制的 requires glib 版本；对比 viewnior force 后依赖图计算出的 package_id（0079104f）与 ohpcd 已发布（2b6465ed）；源码构建段看 tree-magic 链接命令行缺 -lgio-2.0/-lgobject-2.0
```
