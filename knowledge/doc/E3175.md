# E3175: OHOS 动态链接器对 dlopen(RTLD_GLOBAL) 模块的符号不做跨模块重定位解析（dlsym(RTLD_DEFAULT) 却可见），后续 dlopen 依赖方必失败：跨 dlopen 模块符号依赖必须构建期挂 DT_NEEDED 或启动期 LD_PRELOAD

## 推荐方案
**方法**: build-time-dt-needed-explicit-link

**说明**: 把跨模块符号依赖前移到构建期：依赖方 .so 链接期显式挂被依赖库（-lA / libtool 下模块间 -la 互链），使 NEEDED 表在加载期由链接器按常规依赖链解析。上游若按"允许未定义符号 + 运行期 GLOBAL 解析"建模（libtool 组 118 的 moddepend 即此模型），不改上游源码时按 R51 如实记录该测试组平台性失败；可修改场景优先给依赖方补 -la（保守、可移植，glibc 上无副作用）或将依赖双方合并为单一 .so / 改用 dlpreopen（上游 libpreload 静态预载在同测试中通过，可作旁证）。

**修复命令**:
```
clang -fPIC -shared -o libb_needed.so b.c -L. -la -Wl,-rpath,. && ./probe（P4 = OK）
```

**验证**:
```
自包含探针见本条目 .md 附录 A（a.c/b.c/probe.c/probe2.c 四个源文件 + 4 条 clang 命令 + 2 条运行命令，任何 OHOS 设备开新 shell 可复跑）；设备固化副本 tmp/oh-device-porting-v2/lib32-rtld-probe/，本机镜像 runs-v2/lib32-2.6.2/builder/probe/。关键判据：P1b FAIL(dlerror=Error relocating ./libb.so: a_f: symbol not found) 且 P6 dlsym(RTLD_DEFAULT,a_f)=OK 同时成立即为阳性；P4/P5 为文本对照与绕行验证。
```
