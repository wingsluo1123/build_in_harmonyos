# E3178: "Run the test with the interpreter's shared library preloade

## 基本信息
- **严重度**: P1
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"ImportError: Error relocating .*: PyMem_Free: symbol not found"
```

## 根因分析
"CPython extension modules built on this device do not record libpython in DT_NEEDED, and the interpreter binary is not linked with -export-dynamic so its CPython symbols are not in the global scope; the dynamic loader therefore cannot resolve the CPython API symbols used by the extension."

## 推荐方案
**方法**: "Run the test with the interpreter's shared library preloaded: LD_PRELOAD=<prefix>/lib/libpython3.12.so. Only needed while the extension's DT_NEEDED lacks libpython3.12.so.1.0 — extensions that do link it (e.g. PyQt6-sip) load fine without the preload. Check with `llvm-readelf -d` before adding it."
