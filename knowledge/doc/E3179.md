# E3179: "Export CXXFLAGS with -Wno-c++11-narrowing when running the 

## 基本信息
- **严重度**: P2
- **类别**: toolchain
- **作者**: unknown

## 错误特征
```
"error: non-constant-expression cannot be narrowed from type 'signed char' to 'char' in initializer list.*\\[-Wc++11-narrowing\\]"
```

## 根因分析
"clang 15 turns -Wc++11-narrowing into a hard error for the C++ that sip generates for test/module_attrs (it initialises char from a signed-char expression). Upstream targets GCC/MSVC where this is only a warning, so the generated code is valid there but rejected here."

## 推荐方案
**方法**: "Export CXXFLAGS with -Wno-c++11-narrowing when running the upstream test suite: `CXXFLAGS='-Wno-c++11-narrowing' python3 -m pytest test/`. This only relaxes the diagnostic for the test build; the packaged module is unaffected. Alternative if it ever matters for a shipped artifact: const_cast to unsigned char in the .sip — but do not patch upstream for a diagnostic-only difference."
