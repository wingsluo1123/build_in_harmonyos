# E318: Source-only bootstrap for self-hosted compiler packages

> **Contributor**: asp1r1n1 | **Status**: DRAFT | **Created**: 2026-07-23
> **Severity**: high | **Category**: build bootstrap

## Error Signature

Self-hosted compilers often build in several stages:

```text
git clone https://github.com/<project>/bootstrap-source bootstrap/
cc bootstrap/compiler.c -o stage1
./stage1 -o stage2 cmd/compiler
./stage2 -o compiler cmd/compiler
```

In CI or OHOS packaging, the first line is a problem: builds should be
deterministic and should not clone or pull from the network after `source()`.

## Root Cause

The release tarball contains the high-level compiler source but omits the C
bootstrap snapshot. Upstream Makefiles solve that for developers by cloning a
separate bootstrap repository during the build. That is convenient upstream,
but it breaks package reproducibility and offline CI.

## Solution

Download the release tarball and bootstrap-source tarball as separate entries in
`conandata.yml`. In `source()`, extract both archives, copy the bootstrap file
into the exact location expected by the upstream build, and run only the local
bootstrap target in `build()`.

```python
def source(self):
    get(self, **self.conan_data["sources"], strip_root=True)
    get(self, **self.conan_data["bootstrap_sources"],
        destination=bootstrap_tmp, strip_root=True)
    copy(self, "compiler.c", src=bootstrap_tmp, dst=bootstrap_dir)

def build(self):
    self.run('make -j1 compiler')
```

Avoid calling the default target if it always refreshes the bootstrap repository.

## Verification

- Hash both source archives.
- Check that the build log does not contain `git clone`, `git pull`, `curl`, or
  `wget` after `source()`.
- Run a `test_package` that uses the installed compiler to compile and execute
  a small program, not just `--version`.

## Known Instance

- `vlang/0.5.2`: packages the V compiler for the `v` contest issue. The recipe
  downloads `vlang/v` and `vlang/vc`, injects `vc/v.c`, builds `v`, then wraps
  the installed compiler so it can find `vlib`, `cmd`, and `thirdparty`.
