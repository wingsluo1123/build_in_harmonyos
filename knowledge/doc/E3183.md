# E3183: conan --prefix=/ 把资源目录固化为 //share/... 绝对路径；用上游官方环境变量经 runenv_info.define 覆盖

## 基本信息
- **严重度**: 3
- **类别**: autotools, conan, packaging, runtime, environment
- **作者**: E7AA
- **来源 PR**: 14088

## 错误特征
```
hardcoded .* (path|dir).*//(share|lib)|Unable to locate .* on load path|//(share|lib)/[a-z].*No such file
```

## 根因分析
conan 打包约定 configure --prefix=/（DESTDIR 分离打包根），

## 推荐方案
**方法**: upstream-envvar-runenv-override

**说明**: 上游官方文档化的资源路径环境变量（slrn: SLRN_SLANG_DIR）在

**修复命令**:
```
self.runenv_info.define("SLRN_SLANG_DIR", os.path.join(self.package_folder, "share", "slrn", "slang"))
```

**验证**:
```
conan create 后在 test_package（env="conanrun"）中执行进入
```
