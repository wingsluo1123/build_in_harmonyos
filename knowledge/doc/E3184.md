# E3184: 库以 g_get_application_name() 作为子进程 argv 元素时，未设置应用名会让 argv 提前截断

## 基本信息
- **严重度**: 2
- **类别**: runtime, testing, glib, gtk
- **作者**: unknown
- **来源 PR**: ""

## 错误特征
```
assertion failed: \(argc >= 3\)|RetroRunner:ERROR.*argc|usage: .*<core>.*missing|Gtk-WARNING.*cannot open display.*SIGTRAP
```

## 根因分析
retro-gtk 的 RetroCore 在启动 retro-runner 时执行

## 推荐方案
**方法**: consumer-sets-application-name

**说明**: 消费者侧在创建对象前调用 g_set_application_name("...")（真实应用通常由 GTK/GApplication

**修复命令**:
```
g_set_application_name ("my-frontend");  // 之后再做 retro_core_new/boot
```

**验证**:
```
消费者最小程序：不调用 g_set_application_name() 时 retro-runner 报
```
