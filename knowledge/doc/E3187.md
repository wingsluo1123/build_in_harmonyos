# E3187: vendored meson 子项目按 wrap 的 directory 字段对齐解压目录并给 vendored 头文件 stdint typedef 加守护宏，python 注入调用 meson 时其 set_meson_command 记录命令与 PYTHONPATH 子进程继承需适配

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, headers, build-system, cmake
- **作者**: hmbs-executor
- **来源 PR**: 15416

## 错误特征
```
Subproject .* is buildable: NO|Automatic wrap-based subproject downloading is disabled|typedef redefinition with different types|'unsigned int' vs 'unsigned long'|ModuleNotFoundError: No module named 'mesonbuild'|<build-dir>/meson: inaccessible or not found|Errno 12|can't fork
```

## 根因分析
上游源码包自带 .wrap（directory=xxx）而配方把 vendored 子项目解到不匹配目录，meson 在 wrap_mode=nodownload 下判定 buildable: NO；vendored 头文件兜底 uintptr_t typedef 与 OHOS sysroot alltypes.h 已定义的 uintptr_t 冲突触发 typedef redefinition；python3 -c 注入调用 mesonmain.main() 时用占位符 sys.argv[0] 使 set_meson_command 记录不存在的 build-dir/meson 路径；ninja 派生全新 python 子进程运行内部工具时默认拿不到指向 vendored meson 的 PYTHONPATH 导致 ModuleNotFoundError；另外真机 fork OOM（Errno 12/can't fork）属环境资源故障须与配方方案严格区分

## 推荐方案
**方法**: align-wrap-directory-and-guard-vendored-typedef

**说明**: 按上游 wrap 的 directory 字段把解压的子项目目录命名对齐（如 subprojects/cmocka-1.1.2），使 meson _resolve() 直接命中 meson.build 而不触发 nodownload 下载拒绝；给 vendored 头文件的 stdint 兜底 typedef 增加 !defined(_UINTPTR_T)&&!defined(_UINTPTR_T_DEFINED)&&!defined(__UINTPTR_TYPE__) 守护；python 注入调用 meson 时把 sys.argv[0] 设为 vendored mesonmain.py 绝对路径使 set_meson_command 记录 [python,'-m','mesonbuild.mesonmain']；在 ninja 命令串内显式 export PYTHONPATH 使内部 python 子进程继承；对 fork OOM/can't fork 等真机资源故障按守则记录证据不改配方

**修复命令**:
```
conanfile.py: source() 中把 vendored cmocka 目标目录改为 subprojects/cmocka-1.1.2；新增 patches/0001-cmocka-uintptr_t-guard.patch 并接入 conandata.yml patches；_meson_cmd 的 sys.argv[0] 改为 vendored mesonmain.py 绝对路径；build() ninja 命令串显式 export PYTHONPATH="<meson-vendor>:$PYTHONPATH"; notes.md 记录每轮根因证据
```

**验证**:
```
真机日志保留每步真实编译输出；ninja 内部 symbolextractor 等规则命令须为可执行的 python -m mesonbuild.mesonmain 并成功输出符号文件；PYTHONPATH 显式 export 后 python -m 子进程不再 ModuleNotFoundError；编译与链接零 typedef redefinition；子项目目录名与 wrap 的 directory 字段一致使 meson 直接命中 meson.build
```
