# E3192: 三层处理：

## 基本信息
- **严重度**: 2
- **类别**: headers, conan, packaging, khronos, versioning
- **作者**: unknown

## 错误特征
```
404.*archive/refs/tags/v3.0.tar.gz|Cannot find.*tag.*v[0-9.]+|任务版本.*无对应 tag|spec version.*no tag
```

## 根因分析
Khronos 系列头文件库（OpenCL-Headers 等）的 git tag 采用日期型命名（v2026.05.29），而 OpenCL API 规范版本（3.0）是规范代号而非发布 tag。任务系统按规范版本命名任务（opencl 3.0）时，直接拼接 v3.0.tar.gz 会 404。若强行以规范版本号匹配 tag 会造成货源不可得；若直接丢弃任务版本号又违背任务身份。CMake 工程内 project(OpenCLHeaders VERSION 3.0) 恰好是任务版本号的官方佐证，可作为映射依据。
