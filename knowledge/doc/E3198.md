# E3198: 构建子进程取不到 HOME 且无 passwd 条目时 user.home 回退字面 '?'，工具状态目录散射进构建目录：显式 HOME + 工具原生仓库旗标钉绝对路径（Maven .m2，zt-exec 1.12 案例）

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, build-system, java, environment
- **作者**: unknown

## 错误特征
```
\?/\.m2/repository|\?/\.gradle|not found in local Maven repo|user\.home[^\n]*\?
```

## 根因分析
OpenJDK 系 unix 实现 user.home 取 HOME 环境变量，取不到时回退字面

## 推荐方案
**方法**: explicit-home-env-plus-tool-native-repo-pin

**说明**: 配方 build() 内显式 os.environ["HOME"]=os.path.expanduser("~")

**修复命令**:
```
bash -c "cd {src} && sh {maven_home}/bin/mvn -B clean package -Dmaven.repo.local={home}/.m2/repository"
```

**验证**:
```
env -u HOME ~/bishengjdk17/bin/java -XshowSettings:properties -version 2>&1 | grep user.home
```
