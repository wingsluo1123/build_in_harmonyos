# E3207: CLI 同时具有交互与批处理路径时按模式获取控制终端，避免无 TTY 环境提前退出

## 基本信息
- **严重度**: 2
- **类别**: runtime, cli, headless, mode-selection, terminal
- **作者**: 2301_81187298
- **来源 PR**: 15167

## 错误特征
```
/dev/tty.*(No such device or address|ENXIO|cannot open)|open\("/dev/tty".*< 0
```

## 根因分析
程序在判断本次命令是否需要交互之前无条件打开 /dev/tty，失败即退出；

## 推荐方案
**方法**: select-terminal-input-by-command-mode

**说明**: 先由命令参数和业务语义确定本次是否需要键盘交互；需要时打开

**修复命令**:
```
"setsid <program> <batch-args> <fixture-input> >result; test -s result; script -qec '<program> <interactive-args>' /dev/null"
```

**验证**:
```
"cc -Wall -Wextra -Werror -o /tmp/tty-mode-fixture knowledge/drafts/fixtures/tty_mode_fixture.c && python3 knowledge/drafts/fixtures/tty_mode_fixture_test.py"
```
