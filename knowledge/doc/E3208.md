# E3208: 消费者 CLI 测试的三种假绿：错误旗标静默失效（rc=99 被 || true 吞掉）、成功退出但零产出文件、重定向先建文件导致存在性断言恒真

## 基本信息
- **严重度**: 2
- **类别**: consumer-test, false-green, test-framework
- **作者**: ohpc-worker
- **来源 PR**: 15012

## 错误特征
```
(无编译错误；测试日志显示 PASS 但断言从未真正生效)
```

## 根因分析
三层叠加。①同族工具旗标不同源：poppler 的 pdfimages 有 -png，xpdf 的没有

## 推荐方案
**方法**: calibrate-assertions-against-real-build

**说明**: 消费者测试定稿前，先在真实构建产物上实跑整条测试并逐条核对断言

**修复命令**:
```
<bin> -h 2>&1 | head -20 && <bin> <real-fixture> <out-root> && ls -la <out-root>* && head -3 <out-root>*000
```

**验证**:
```
pdfimages -h 2>&1 | head -20   # 先读该二进制真实支持的旗标
```
