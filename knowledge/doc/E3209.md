# E3209: 受限网络下的换源判据：官方发行版缓存里的 pristine 快照 ≠ dist tarball（须同时校验“生成物”与官方记录的强哈希）

## 基本信息
- **严重度**: 2
- **类别**: ohos, offline-source-substitution
- **作者**: unknown

## 错误特征
```
urlopen error \[Errno 110\]|Connection refused|Operation timed out|configure script is missing|http://download\.[a-z0-9.]+/.*301.*Location
```

## 根因分析
上游发布位可能整体不可达（GitHub 超时、sourceforge 连接被拒、官方站 301 Location 畸形或 TLS 不兼容），

## 推荐方案
**方法**: upstream-release-then-distro-cache-with-content-and-hash-check

**说明**: ①优先上游**官方发布位**（download.samba.org / download.gnome.org / x.org / videolan 等本轮均可达）；

**修复命令**:
```
'curl -sSL -o cand.tar.gz <url> && sha256sum cand.tar.gz && rm -rf /tmp/chk && mkdir /tmp/chk && tar -xf cand.tar.gz -C /tmp/chk && ls /tmp/chk/*/ | head && [ -f /tmp/chk/*/configure ] && echo "dist-tarball OK"'
```

**验证**:
```
curl -sSL -o cand.tar.<ext> <url> && sha256sum cand.tar.<ext> && tar -tf cand.tar.<ext> | head -3
```
