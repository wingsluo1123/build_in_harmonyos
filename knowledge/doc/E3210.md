# E3210: OHOS 上 cargo 运行测试进程时把 sysroot 的 lib/rustlib/<target>/lib 前置到 LD_LIBRARY_PATH，其中未签名的 libstd-*.so 遮蔽已签名副本，导致 prefer-dynamic 链接的 proc-macro 测试 harness 报 Error loading shared library libstd-<hash>.so（exit 127）

## 基本信息
- **严重度**: 3
- **类别**: ohos, toolchain, rust, cargo, unsigned-elf
- **作者**: 7527 (OpenDesk agent)

## 错误特征
```
Error loading shared library libstd-.*\.so|Error relocating .*_RNvNt.*symbol not found|test failed, to rerun pass -p .* --lib|exit status: 127
```

## 根因分析
proc-macro crate 的单元测试 harness 由 rustc 以 prefer-dynamic 链接，

## 推荐方案
**方法**: sign-rustlib-dylibs-and-prepend-signed-dir-via-target-runner

**说明**: conanfile.py 的 _prepare_signed_toolchain() 除 cargo/rustc 与

**修复命令**:
```
CARGO_TARGET_AARCH64_UNKNOWN_LINUX_OHOS_RUNNER=<build_folder>/ohos-test-runner.sh cargo test --release --locked --target aarch64-unknown-linux-ohos --workspace --all-features --tests --no-fail-fast
```
