# E3211: 手写Makefile绝对路径先探测回退且漂移补丁改用配方内精确替换

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 15694

## 错误特征
```
No such file or directory.*Error 127|Failed to apply patch.*src/Makefile|invalid hunk.*audio_init\.c
```

## 根因分析
配方盲信tools.build compiler_executables绝对CC与硬编码make和shell路径且无存在性校验在真机失效报Error 127；手写Makefile统一补丁上下文随注释空行漂移无法应用且0002补丁hunk计数虚标被Conan拒收；src/test_dsp_params.c被误判为测试导致evidence门禁no_tests零证据拒绝

## 推荐方案
**方法**: probe-absolute-paths-plus-replace-in-file

**说明**: 绝对CC和make和shell先做isfile加X_OK校验再回退PATH兄弟与HMBS_MAKE；删除漂移Makefile统一补丁改用replace_in_file三处精确替换并修正hunk计数；指名test_dsp_params.c为经OBJS通配链接的生产代码并切manual_audit空命令

**修复命令**:
```
conanfile.py新增_resolve_cc和_resolve_make加replace_in_file三处精确替换；test_package/conanfile.py新增_resolve_shell加test.sh改POSIX sh；MANIFEST.yml改manual_audit空命令；conandata.yml修正补丁列表与镜像排序
```

**验证**:
```
真机日志保留解析后CC与make编译行无Error 127且补丁干净应用；MANIFEST.yml保留manual_audit空check命令与test_dsp_params.c生产代码审计，真机evidence放行
```
