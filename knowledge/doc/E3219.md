# E3219: conan 纯 Python 依赖制品的 site-packages 布局**不统一**（python3.12/ 有版本号 与

## 基本信息
- **严重度**: 2
- **类别**: python, conan, packaging, runtime, testing
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: 10408

## 错误特征
```
ModuleNotFoundError: No module named 'pygments'|
```

## 根因分析
用 tool_requires 引入 pytest 后，配方需把 build 上下文各依赖的

## 推荐方案
**方法**: glob-python-star-site-packages

**说明**: 用 glob 同时覆盖两种布局，并把一个依赖的**全部**命中目录加入：

**修复命令**:
```
_sites = sorted(glob.glob(os.path.join(pf, "lib", "python*", "site-packages")))
```

**验证**:
```
for pf in <各依赖 package_folder>; do find "$pf" -maxdepth 3 -type d -name site-packages; done
```
