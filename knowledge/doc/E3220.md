# E3220: conan 2 的 self.dependencies.<context>.items() 返回的键是 Requirement

## 基本信息
- **严重度**: 2
- **类别**: python, conan, api, recipe
- **作者**: AtomCode <noreply@atomgit.com>
- **来源 PR**: 10408

## 错误特征
```
TypeError: '<' not supported between instances of 'Requirement' and 'Requirement'|
```

## 根因分析
conan 2 的 UserRequirementsDict（conan/internal/model/dependencies.py）

## 推荐方案
**方法**: sort-by-require-ref-name

**说明**: 需要确定性顺序时，先取出重名再排：

**修复命令**:
```
sorted(((r.ref.name, d) for r, d in self.dependencies.build.items()), key=lambda kv: kv[0])
```

**验证**:
```
python3 -c "import conan,os;print(conan.__file__)"
```
