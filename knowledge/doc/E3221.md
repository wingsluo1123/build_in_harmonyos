# E3221: OHOS 无任何带 WebAssembly 后端的编译器：自举静态 Zig 为 wasm32-wasip1 交叉工具链，双面包装器分派编译（zig cc）与链接（SDK clang 驱动 + LLD19 wasm-ld shim）

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, libc, build-system, toolchain
- **作者**: frj__
- **来源 PR**: 15084

## 错误特征
```
No available targets are compatible with triple "wasm32|__heap_end.*undefined symbol|unable to parse target query.*UnknownOperatingSystem|relocation R_WASM_MEMORY_ADDR_SLEB.*__heap_end|entry symbol not defined.*_start|ld-linux-aarch64.so.1.*No such file|unsupported linker arg: --allow-undefined-file
```

## 根因分析
harmonybrew clang 23.1.1 与 OHOS SDK clang 15.0.4 均未编入 WebAssembly 后端（--print-targets 无 wasm）；官方 wasi-sdk arm64-linux 为 glibc 动态链接（/lib/ld-linux-aarch64.so.1）在 OHOS musl 用户态不可执行；SDK 自带 LLD 15.0.4 缺 __heap_end 链接器伪符号（需 >=15.0.7）；LLVM 15 驱动对 -shared 用 command crt，把静态 dlmalloc 拖进共享库，其 __heap_end 数据引用无法成为 wasm import

## 推荐方案
**方法**: dual-face-wrapper-toolchain-bootstrap

**说明**: 下载官方静态 Zig 0.14（内嵌 clang+LLVM 19 全目标），binary-sign-tool 自签名后可执行；写双面 clang 包装器：编译作业（-c/-E/-S）走 zig cc——--target=wasm32-wasip1 译为 -target wasm32-wasi -D__wasip1__（zig 的 target 查询只认 wasi；LLVM19 将其映射为同一 triple，宏须补回），剪除 zig 自带 wasm-wasi-musl/generic-musl 等 libc 头目录（zig 注入的 isystem 先于用户 -isystem，会遮蔽目标 sysroot），-mllvm -wasm-enable-sjlj 附加 -mexception-handling（__builtin_wasm_throw 需该特性），argv 用计数 shift/append 队列逐字保留（带空格的 -D 定义不得拆分）；链接作业走 OHOS SDK clang 驱动 + -B 目录提供 wasm-ld shim（exec zig wasm-ld，LLD 19），-shared 链接加 -mexec-model=reactor 对齐 LLVM19 驱动行为，应答 --print-libgcc-file-name/-print-resource-dir 时给一致的绝对路径对使 compiler-rt builtins 拷贝落位

**修复命令**:
```
配方内生成包装器（见 archives/w/wasi-libc/0.0-git20260129.ec0effd/conanfile.py 的 WRAPPER_CLANG/WRAPPER_WASM_LD）；cmake 传 -DCMAKE_TRY_COMPILE_TARGET_TYPE=STATIC_LIBRARY、-DBUILTINS_LIB=<wasi-sdk-25 官方 builtins>、-DFETCHCONTENT_SOURCE_DIR_LIBC-TEST=<预取>、-DENGINE="node;<wasi-run.mjs>"（Node WASI 引擎替换 wasmtime，兼容 --dir HOST::GUEST/--env CLI）
```

**验证**:
```
conan create rc=0；上游 ctest（Node.js WASI preview1 引擎替代 wasmtime）>=90% 且失败项均有引擎缺口分类；test_package 消费者编译为 wasm 并执行输出 CONSUMER_PASS
```
