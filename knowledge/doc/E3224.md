# E3224: 老代码用 `#elif(__cplusplus == 201103L)` 精确匹配 C++11 ⇒ C++14/17 编译时精确相等为假、掉进 `<tr1/...>` fallback，libc++ 无 tr1 报 file not found

## 基本信息
- **严重度**: 2
- **类别**: c++, cppstd-17, legacy-code, stdlib-libcxx
- **作者**: 2301_76770579
- **来源 PR**: (关联 limonp 0.6.1 PR)

## 错误特征
```
'(tr1/unordered_map).*file not found|no member named .ptr_fun.|no member named .bind2nd.'
```

## 根因分析
2000-2016 年代的 C++ 头文件常用

## 推荐方案
**方法**: widen-exact-match-to-gte

**说明**: 把 `#elif(__cplusplus == 201103L)` 放宽为

**修复命令**:
```
sed 或最小 patch：s/(__cplusplus == 201103L)/(__cplusplus >= 201103L)/；
```

**验证**:
```
grep -n '__cplusplus' 头文件检查精确相等分支；
```
