# E3225: Autotools强制工具缺失时运行时探针钉选与vendor自举三通道接线通用范式

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, autotools, testing
- **作者**: hmbs-executor
- **来源 PR**: 14002

## 错误特征
```
configure: error: missing required tool: flex|configure: error: missing required tool: help2man|configure: error: Required tool not found: libtool|configure: error: Required tool not found: GNU bash >= 4.0|/bin/bison: inaccessible or not found|m4sugar\.m4: cannot open|C compiler cannot create executables
```

## 根因分析
profile预设CC与CONFIG_SHELL在沙箱不可见且tool_requires只装包不进自定义configure PATH，叠加flex包无bin与bison硬编码与重定位数据目录丢失与ncurses缺头与多PATH前缀覆盖丢失垫片，使configure逐项报强制工具缺失

## 推荐方案
**方法**: runtime-probe-pin-plus-vendor-bootstrap-tri-channel

**说明**: 按conf到环境到PATH到已知路径到SDK顺序三重验证钉选CC并内联覆盖CONFIG_SHELL，对每项强制工具做tool包优先到设备候选的真实执行探针，胜出者经进程环境加conanbuild.sh加configure内联前缀三通道预设，无胜出者用官方源码vendor到私有prefix并以冒烟验收后钉选

**修复命令**:
```
conanfile.py generate显式前置bindir并定义FLEX加BISON加YACC加M4加BASH加PKG_CONFIG加BISON_PKGDATADIR；build加真实探针并三通道钉选；缺失时vendor构建flex加help2man加libtool与补齐panel头并加文档熔断
```

**验证**:
```
真机config.log见编译器段全过后失败点逐轮后移，探针HMBS_DIAG报胜出者真实执行通过且LIBS与BISON_PKGDATADIR随摘要保留，消费者烟囱4过4且腐烂套件转证据口径上报真实计数
```
