# E3227: 上游Makefile多源install被install_shim拒绝时改用copy直拷与CLI上游测试加固

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 12791

## 错误特征
```
make: .*\[Makefile:.*install\] Error 64|FATAL - bgzip compression failed
```

## 根因分析
上游Makefile install目标多源install -c形式不被HarmonyOS install垫片支持而报Error 64；并存上游CLI测试诊断被&&吞掉、缺LD_LIBRARY_PATH与未自签，以及test_package隐式依赖远端包未提供的bgzip/tabix CLI

## 推荐方案
**方法**: copy-replace-install-plus-cli-hardening

**说明**: 删除package()中make install调用改用conan copy()复刻上游同布局并复用自签；同步加固_run_upstream_test常显日志+LD_LIBRARY_PATH+自签+非零判failed；test_package夹具改用BGZF/tbx C API现场生成

**修复命令**:
```
conanfile.py: package()用copy()复制tabix++、*.hpp、libtabix.a、libtabix.so*与LICENSE到bin/include/lib/licenses并_sign_binary自签；_run_upstream_test用; rc=$?; cat; exit $rc并注入_dep_libdirs到LD_LIBRARY_PATH；test_package/test_tabixpp.cpp用bgzf_open/bgzf_write/tbx_index_build替代std::system bgzip
```

**验证**:
```
真机package()无Error 64；HMBS_UPSTREAM_TEST_RESULT保持status passed/discovered 1/executed 1；test_package 8断言口径不变全过；HMBS_PLATFORM_CAPABILITIES记录install_shim=true备查
```
