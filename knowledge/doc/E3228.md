# E3228: 上游自带 ENABLE_SHARED/ENABLE_STATIC 覆盖 BUILD_SHARED_LIBS 时改用原生选项强制静态并加安装后校验

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, portability, build-system, cmake
- **作者**: hmbs-executor
- **来源 PR**: 15475

## 错误特征
```
Error loading shared library libtoxcore\.so|symbol not found|stale_runtime_library
```

## 根因分析
c-toxcore 用自己的 CMake 选项控制库类型（cmake/ModulePackage.cmake 中 option(ENABLE_SHARED ON)、option(ENABLE_STATIC ON)，默认都开），CMake 通用变量 -DBUILD_SHARED_LIBS=OFF 对它无效，故同时产出 libtoxcore.so 与 libtoxcore.a；tuntox 链接 -ltoxcore 挑中共享库，生成对 libtoxcore.so 的动态依赖；真机 OHOS loader 优先加载系统旧版 libtoxcore.so，导致 tox_* 符号 reloc 全部失败（stale_runtime_library）。

## 推荐方案
**方法**: force-static-via-native-options

**说明**: 改用项目原生选项强制只产静态库（-DENABLE_SHARED=OFF -DENABLE_STATIC=ON），并在安装后加防御校验确认产物不对目标 .so 形成动态依赖

**修复命令**:
```
toxcore CMake 配置追加 -DENABLE_SHARED=OFF -DENABLE_STATIC=ON；安装后校验 test_package 二进制无 libtoxcore.so 的 NEEDED
```

**验证**:
```
真机 test_package 执行 tuntox -h 输出 help banner 与选项；readelf -d 检查产物无 libtoxcore.so 的 NEEDED；日志无 tox_* symbol not found
```
