# E3230: 平台专属前端包名不等于整包不可适配——同源多前端 tarball 的可构建子集判定

## 基本信息
- **严重度**: 2
- **类别**: portability, buildsystem, triage
- **作者**: unknown

## 错误特征
```
OS `ohos' not recognized|Kernel `linux' not known to work with OS `ohos'|configure: error: No pinentry enabled|The curses library is required
```

## 根因分析
上游 pinentry 用**同一个源码树**交付多个平台前端，`SUBDIRS`（`Makefile.am:120`）

## 推荐方案
**方法**: 遇到「平台任务名指向某平台专属前端」的包，先做**可构建子集**四步勘察，

**说明**: (待补充)

**修复命令**:
```
for d in */; do printf '%-12s .c=%s .m=%s\n' "$d" "$(find $d -maxdepth 1 -name '*.c'|wc -l)" "$(find $d -maxdepth 1 -name '*.m'|wc -l)"; done; grep -nE 'SUBDIRS|AM_CONDITIONAL' Makefile.am configure.ac
```
