# E3231: Meson 配方 project_options 与目标版本上游选项集不一致时 meson setup 致命失败（Unknown option）——版本迁移必须按目标版本的 meson_options.txt / meson.options 裁剪选项

## 基本信息
- **严重度**: 3
- **类别**: portability, build-system, meson, configure, version
- **作者**: Quas
- **来源 PR**: https://gitcode.com/OpenHarmonyPCDeveloper/build_in_harmonyos/merge_requests/13914

## 错误特征
```
ERROR: Unknown option: "[^"]+"|Error [0-9]+ while executing meson\.configure\(\)|Unknown option
```

## 根因分析
① meson 对未知选项是致命错误而非警告：向 meson setup 传一个上游未声明的 -D<opt>=... 会立刻中止配置

## 推荐方案
**方法**: reconcile-project-options-with-target-upstream-option-set

**说明**: 迁移上游版本时按目标版本的选项集裁剪、补齐 project_options：删除上游已移除的选项，命名变更的改用新名，不要盲目保留骨架配方的整份选项表。

**修复命令**:
```
# orc 0.4.42 配方用于 0.4.41 源码：0.4.41 尚无 hotdoc 选项，必须移除该行
```

**验证**:
```
# 1) 列出目标版本的真实选项集
```
