# E3236: Autotools noinst_DATA 规则用 $@.in 读模板，out-of-tree（Conan 构建目录）构建失败

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools, conan, out-of-tree, vpath
- **作者**: AtomCode (deepseek-v4-flash) <noreply@atomgit.com>

## 错误特征
```
Makefile\.conf\.in: No such file or directory|make.*\*\*\* \[Makefile:.*: Makefile\.conf\] Error 1|No rule to make target 'Makefile\.conf\.in'
```

## 根因分析
Automake 生成的规则把模板文件写成 $@.in（= 构建目录下的目标名），而模板实际位于 $(srcdir)。Shell 不会跟随 VPATH，因此只在源码树内（srcdir=.）构建可行；Conan 的 build folder 与 source folder 分离（out-of-tree），规则找不到 Makefile.conf.in 直接失败。

## 推荐方案
**方法**: patch-rule-to-srcdir-template

**说明**: 把规则的输入与前置条件都改成 $(srcdir)/$@.in 与 $(srcdir)/Makefile.conf.in（Makefile.in 与 Makefile.am 同步改），并登记为 conandata patch。$(srcdir) 在 in-tree 构建下为 "."，两种构建方式同时成立。

**修复命令**:
```
|
```

**验证**:
```
在 Conan build folder（≠ source folder）执行 make，观察 Makefile.conf: No such file or directory；打补丁后同一命令通过，且 in-tree 构建仍正常。
```
