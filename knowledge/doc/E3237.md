# E3237: setuid 投递型包在 OHOS 的四重安装墙（install 命令缺失/非 root/mail 组不存在/setuid-setgid 位被剥离）叠加 /var ENOENT 与 /etc 只读、非 root 运行期不进入 setuid 降权块 —— 处置=编译照交 + self.copy 自装 + 消费者断言只打参数期 + 能力面逐字披露

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, ohos, packaging, security, capabilities
- **作者**: unknown
- **来源 PR**: dma 0.14 适配

## 错误特征
```
install: command not found|No such file or directory.*install|KeyError.*getgrnam.*mail|setuid=False|setgid=False|/var.*ENOENT|Read-only file system.*etc|cannot drop root privileges
```

## 根因分析
上游按 BSD/Linux root+mail 组 + setuid/setgid 特权投递模型设计安装与运行路径；

## 推荐方案
**方法**: appres-ddccontrol-mode-disclosure-with-copy-install-and-argument-stage-assertions

**说明**: 能力墙属平台事实而非配方缺陷 —— 编译照交；package() 用 self.copy 自装并

**修复命令**:
```
copy(self, "dma", src=self.source_folder, dst=bindir, keep_path=False)
```

**验证**:
```
command -v install; id; python3 -c "import grp;print(grp.getgrnam('mail'))";
```
