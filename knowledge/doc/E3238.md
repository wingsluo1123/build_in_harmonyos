# E3238: Conan2 Meson测试兼容与计数：直调meson test替代test(args)、testlog.json JSONL单源计数与外部工具可选门控

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 13256

## 错误特征
```
meson-logs/testlog.txt not found|Program 'samtools' not found or not executable|Extra data: line 2 column 1|patch stream is incomplete|no member named 'contains' in 'std::set
```

## 根因分析
Conan develop2源码Meson.test(self)无args形参，配方meson.test(args)抛TypeError被吞致meson test零执行无日志；meson1.11 testlog.json为每行一对象的JSONL整读必报Extra data；tools/meson.build对仅测试需的samtools用无required:false硬查找缺二进制即configure失败；ohos profile下发c++17覆盖上游cpp_std=c++20致contains编译错；手写补丁hunk头行号计数偏离git容忍offset但Conan严格校验拒绝

## 推荐方案
**方法**: direct-meson-test-jsonl-single-source-optional-gate

**说明**: build直调meson test替代Meson.test(args)，计数器以testlog.json逐条name/result为唯一单源做整文档加逐行双模式解码，外部二进制改required:false加found守卫按缺失excluded，工具链恢复上游cpp_std并用difflib重生成标准hunk头

**修复命令**:
```
conanfile.py build改self.run(meson test -v --print-errorlogs); generate设tc.cpp_std=c++20并注入缺失宏; tools/meson.build补丁加required:false; marker改testlog.json单源双模式计数
```

**验证**:
```
真机conan create跑meson test -v --print-errorlogs后检查meson-logs/testlog.json双模式解码计数恒等式与meson-log.txt外部工具记录，保留真实上游结果与HMBS_TEST_PACKAGE_RESULT
```
