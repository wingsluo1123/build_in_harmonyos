# E3240: 上游 Makefile.am 仅声明 check_PROGRAMS 而无 TESTS 时 make check 只编译不运行，需显式执行测试二进制并产出确定性上游回归计数

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, autotools, testing
- **作者**: hmbs-executor
- **来源 PR**: 15432

## 错误特征
```
HMBS_UPSTREAM_TEST_RESULT=\{[^}]*"discovered":0[^}]*"executed":0|discovered:0, executed:0|no_tests/0
```

## 根因分析
autotools 库的 LibDsk/tools/Makefile.am 声明 check_PROGRAMS = check1 check2 check3 却没有 TESTS = $(check_PROGRAMS)，automake 生成的 make check 只把 check_PROGRAMS 编译出来而不执行，配方因此拿不到任何 # TOTAL/PASS 行，上游测试统计恒为 discovered:0/executed:0；证据门禁拒绝零证据放行，必须在配方内显式运行测试二进制并自行汇总确定性计数

## 推荐方案
**方法**: explicitly-run-check-programs

**说明**: 构建后解析 Makefile.am 的 check_PROGRAMS，显式逐个执行对应测试二进制，按退出码汇总 passed/failed 与 discovered/executed，产出确定性上游回归计数；同时补齐 autotools 构建依赖旗标与 *-config shim 使 configure 探针可过

**修复命令**:
```
archives/j/joyce/2.4.2/conanfile.py: generate() 增 AutotoolsDeps(self).generate()；_run_upstream_check() 构建后显式运行 LibDsk/tools/check1..check3；_xml2_config_shim()/_sdl_config_shim() 生成带 -I 前缀与传递 -L/-l 的 shim
```

**验证**:
```
真机日志中上游 make check 段须出现真实执行的测试程序输出与由配方汇总的确定性计数（discovered/executed 均大于 0），并与 test_package 的 HMBS_TEST_PACKAGE_RESULT 分列，不得互相替代
```
