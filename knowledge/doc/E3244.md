# E3244: 纯 Makefile（无 configure）项目在 14 步驱动 Step5 必报「安装无产物」：上游 prefix ?= /usr/local 与驱动 staging_prefix=$DESTDIR/$DEFAULT_PREFIX 不一致，且 install(1) 不在 PATH —— 环境变量 prefix 注入 + PATH 垫 install shim + 配方 package() 手工 copy 三步修

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, build-system, packaging
- **作者**: unknown

## 错误特征
```
安装无产物.*staging|No rule to make target 'install-binPROGRAMS'|make: install: No such file or directory|Error 127|staging_prefix
```

## 根因分析
驱动的 Step5 是为 autotools 设计的：configure --prefix=$DEFAULT_PREFIX（展开成 /storage/Users/currentUser/usr/local 这样的绝对路径）把运行期前缀烧进二进制，安装时 DESTDIR+prefix 恰好落在 staging_prefix = test_prefix/<DEFAULT_PREFIX 去掉前导/>。而纯 Makefile 项目没有 configure，`make install` 用上游自带的 `prefix ?= /usr/local` ⇒ 产物落在 $DESTDIR/usr/local/bin，驱动检查的却是 $DESTDIR/<HOME>/usr/local/bin，于是 bin=0 lib=0 → 「❌ 安装无产物」→ RuntimeError。第二层：GNUmakefile 的 `$(INSTALL) -d …` 需要 install(1)，但本平台 PATH 不含 /bin（toybox 的 install 只在 /bin/install），驱动 _find_tool 依次查 ~/usr/local/bin/install、test_prefix/bin/install、`which install` 全落空后返回裸名 "install" ⇒ `make: install: No such file or directory` + `GNUmakefile:NN: install Error 127`；两层叠加时第一层 fallback（install-binPROGRAMS）也会先打出 `No rule to make target` 的干扰信息。

## 推荐方案
**方法**: env-prefix-injection-plus-install-shim-plus-manual-package-copy

**说明**: (1) 起驱动前 `export prefix=$DEFAULT_PREFIX`：GNU make 对来自环境的变量视为「已定义」，上游的 `prefix ?= /usr/local` 不再覆盖 ⇒ DESTDIR+prefix 与驱动 staging_prefix 对齐，Step5 立刻 bin=1；(2) PATH 最前置一个任务级 shim 目录并 `ln -s /bin/install <shim>/install`，让 _find_tool 的 `which install` 命中（⛔ 不要动 ~/usr/local/bin —— 那是基础设施区）；(3) 配方 package() 不要依赖 install(1)：CI worker 与本机同样没有它，直接 copy 构建产物到 bin/ 与 share/man/ 并 chmod 0755（本 PR 的 conanfile 即此写法），这样 L2 冒烟与 L1e 破坏性反向验证都能过；(4) 同时显式传 CC（裸 make 的 CC 解析成 make 内建 cc，本机无 cc —— 该坑已有 M18/E 族条目，此处只做引用）。

**修复命令**:
```
export prefix=$DEFAULT_PREFIX; export PATH=$HOME/tmp/uc2/<task>/bin:$PATH; python3 scripts/ohc-run.py build <pkg> <ver>
```

**验证**:
```
sh 经验文档/tools/build-slot.sh --kind short --mem 2500 -- make -C ~/builds/dte-1.9.1.work install DESTDIR=$HOME/test-install-dte-1.9.1 INSTALL=$(which install) prefix=$HOME/usr/local && ls $HOME/test-install-dte-1.9.1$HOME/usr/local/bin/dte
```
