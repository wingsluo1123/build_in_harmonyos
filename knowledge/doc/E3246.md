# E3246: OHOS 上 go test 的嵌套 go build 产物需签名；PATH wrapper 与 toolexec 均不可靠，须改 $GOROOT/bin/go 为签名 shim

## 基本信息
- **严重度**: 3
- **类别**: ohos, toolchain, go, testing, security
- **作者**: OpenDesk

## 错误特征
```
fork/exec .*: permission denied.*(go test|\.test)|
```

## 根因分析
上游测试常自行 `exec.Command("go","build","-o",<tmp>/<cli>,...)`

## 推荐方案
**方法**: goroot-bin-sign-shim

**说明**: 两层签名：①`go test -exec=<sign-wrapper>` 在 execve 前给测试 ELF

**修复命令**:
```
conanfile.py build(): 安装 shim 后
```

**验证**:
```
# PROBE1(预期失败): 仅用 -exec 签名、不处理嵌套 build
```
