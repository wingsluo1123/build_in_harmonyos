# E3248: bash 脚本把 /tmp 写死不止一处：只改 workdir 赋值会漏掉 --keep 分支的 cd /tmp 与 tar 打包

## 基本信息
- **严重度**: 2
- **类别**: platform, shell, tmpdir
- **作者**: RFC1

## 错误特征
```
Failed to create temporary directory '/tmp/|tar: .*/tmp.*(Read-only|Cannot open)|mkdir: cannot create directory '/tmp/.*Read-only
```

## 根因分析
鸿蒙 /tmp 只读（E002）。rfcdiff 这类 bash 工具除了 workdir=/tmp/$name-$$ 外，保留现场分支还写死 cd /tmp; tar czf $name-$$.tgz，只把 workdir 改成 ${TMPDIR:-/tmp}/… 时，--keep 仍会 cd 到只读的 /tmp 并打包失败（目录名相对 cwd 解析）。

## 推荐方案
**方法**: patch-all-tmp-literals

**说明**: 先 grep 出脚本里全部 /tmp 字面量逐处归类：工作目录赋值改为 ${TMPDIR:-/tmp}/…；依赖该目录的后续 cd/tar/mv 改为相对工作目录父目录 cd "${workdir%/*}"，不要再出现独立的 /tmp。保留 $TMPDIR 显式设置时的原有语义（不可用即报错）。

**修复命令**:
```
sed -i 's#workdir="/tmp/#workdir="${TMPDIR:-/tmp}/#; s#^\(\s*\)cd /tmp$#\1cd "${workdir%/*}"#' <script>
```

**验证**:
```
grep -n '/tmp' <script>；用 TMPDIR=<可写目录> 跑 --keep 之类的保留现场选项，断言产出落在 $TMPDIR；再设 TMPDIR=<不存在目录> 断言脚本报错而非静默回退 /tmp
```
