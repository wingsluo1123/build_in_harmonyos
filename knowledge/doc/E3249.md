# E3249: ELF AArch64 FFI aggregate calls and callbacks need one symmetric PCS contract

## 基本信息
- **严重度**: 3
- **类别**: platform, compat, portability, testing
- **作者**: D014

## 错误特征
```
aggregate support missing|result: call_suite_aggrs: 0|result: callback_suite_aggrs: 0
```

## 根因分析
Scalar register support does not implement aggregate PCS. HFA classification, atomic register-bank exhaustion, caller-owned large argument copies and the independent x8 result pointer must agree across VM marshalling, assembler entry, callback frame and return capture; fixing only a signature or recipe leaves the other direction inconsistent.

## 推荐方案
**方法**: symmetric-aapcs64-aggregate-pcs

**说明**: Classify actual nested member offsets and union overlap; marshal HFA as 1-4 FP registers, small generic composites wholly in GPR or wholly on stack, large composites through owned copies; pass x8 without consuming x0 and symmetrically capture callback metadata and x0/x1/d0-d3 results.

**修复命令**:
```
Implement the matching VM, assembler, callback-frame and result-decoder paths together; assert C/assembler offsets; run unmodified aggregate grids plus explicit spill and x8 consumers.
```

**验证**:
```
Run compiler-generated native aggregate call and callback grids; then test whole-stack spills with 7 GPR or 6 FP arguments, large private copies and x8 returns, and a separately linked signed package consumer.
```
