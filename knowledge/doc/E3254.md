# E3254: 非阻塞发送队列保留短写尾部仍不足以保证活性：积压队列需要按需写就绪推进

## 基本信息
- **严重度**: 2
- **类别**: portability, socket, network, runtime, testing
- **作者**: 6F91

## 错误特征
```
(?:queued|pending|outlen).*(?:bytes|data).*(?:timeout|stalled|never sent)|
```

## 根因分析
非阻塞 send() 短写或返回 EAGAIN 后，生产代码虽然把未发送尾部保存在

## 推荐方案
**方法**: on-demand-writable-queue-drain

**说明**: 入队时保留一次乐观发送；若短写或 EAGAIN 留下尾部，仅在队列非空

**修复命令**:
```
add pending-length-gated write interest and call the same queue flush routine
```

**验证**:
```
conan create archives/m/mvdsv/1.11 -pr:h=ci/conan/profiles/ohos-aarch64
```
