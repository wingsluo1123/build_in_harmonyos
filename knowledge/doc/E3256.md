# E3256: 宽字符缓冲区强转不等于编码转换：保持公共 ABI 并用真实元素类型计算长度

## 基本信息
- **严重度**: 3
- **类别**: portability, libc, conan
- **作者**: 2501

## 错误特征
```
numeric conversion.*SIG|Chinese.*normalization|wide.*buffer.*truncated
```

## 根因分析
LP64 的 unsigned long 元素与平台 wchar_t 元素宽度不同；wcslen/wcscpy 等忽略指针强转背后的布局差异，将一个码点的高半部零误认为结束，导致规范化缓冲区长度错误及越界。

## 推荐方案
**方法**: typed-wide-operations-preserve-abi

**说明**: 保持现有公共字符类型，在内部按实际元素实现长度、复制、连接和查找；审计所有调用者及新分配的容量，明确空串和未找到字符语义，并检查和释放规范化临时堆缓冲区。

**修复命令**:
```
先证明元素宽度差异；用类型一致的操作替换强转 wcs*；从干净源码重建库与消费者，运行原始全部入口及多字符/扩张/长整数回归。
```

**验证**:
```
对照公共 typedef 与 sizeof，跟踪规范化长度/分配/遍历链；以原始全量脚本、长输入、会扩张的规范化输入及安装消费者验证修复。; installed file consumer must reject diagnostics and compare complete multi-process UTF-8 roundtrip bytes beyond initial input capacity; count the full workflow once.
```
