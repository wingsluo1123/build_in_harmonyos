# E3257: 重定位 Perl 的核心搜索根与模块安装根必须分离

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, runtime
- **作者**: IOSTRING

## 错误特征
```
PERL_LIB.*does not exist|PERL_ARCHLIB.*does not exist|Can't locate .* in @INC
```

## 根因分析
发布包中的 Perl 被恢复到新的隔离缓存后，Config.pm 可能仍包含构建时前缀；运行时核心模块搜索、MakeMaker 核心目录输入和下游模块安装根是三个不同契约，不能只设置 INSTALL_BASE 或用目标模块目录覆盖 PERL5LIB。

## 推荐方案
**方法**: separate-core-arch-install-runtime-roots
