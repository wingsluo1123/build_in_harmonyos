# E3260: 经典 Autotools 用嵌套 AC_CHECK_LIB 链逐项探测 termcap/termlib/curses/xtermcap 的 tgetent，链中没有 -lncursesw；OHOS 的 ncurses/6.6 包只交付 libncursesw.a（tgetent/tinfo 已并入），configure 四项全 miss 后 AC_MSG_ERROR "i can not find tgetent" 硬失败

## 基本信息
- **严重度**: 3
- **类别**: detection, ohos, portability, build-system, autotools
- **作者**: songzhenyan <apVBMI1DvwCqWTll.songzhenyan@noreply.gitcode.com>

## 错误特征
```
i can not find tgetent|checking for tgetent in -l(termcap|termlib|curses|xtermcap)\.\.\. no|cannot find the curses library
```

|

## 推荐方案
**方法**: patch-autotools-chain-insert-ncursesw

**说明**: |

**修复命令**:
```
patch -p1 < patches/0001-tgetent-ncursesw.patch && bash -n configure && sh -n configure && ./configure ac_cv_lib_termcap_tgetent=no ac_cv_lib_termlib_tgetent=no ac_cv_lib_curses_tgetent=no ac_cv_lib_xtermcap_tgetent=no LDFLAGS="-L<ncurses>/lib"
```

**验证**:
```
bash -n configure && sh -n configure && grep -q "tgetent in -lncursesw" configure && ./configure ac_cv_lib_termcap_tgetent=no ac_cv_lib_termlib_tgetent=no ac_cv_lib_curses_tgetent=no ac_cv_lib_xtermcap_tgetent=no LDFLAGS="-L<ncurses>/lib" 2>&1 | grep "checking for tgetent in -lncursesw... yes"
```
