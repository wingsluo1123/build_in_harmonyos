# E3261: 共享包装库链接系统依赖先满足符号导致内置图像编解码 ABI 不匹配

## 基本信息
- **严重度**: 3
- **类别**: linking, dependency, runtime, testing, static-library
- **作者**: 6C2B

## 错误特征
```
Wrong JPEG library version.*library is 62.*caller expects 90|JPEG encoder failed|jpeg_CreateCompress.*LIBJPEG_6.2
```

## 根因分析
共享wxcore使用内置JPEG90头，但GTK依赖链接项先于libwxjpeg.a；系统JPEG62先满足未定义符号，静态归档成员没有被选入，产生编译头与运行实现ABI不一致。

## 推荐方案
**方法**: prefer-selected-builtin-codec-at-shared-link

**说明**: 在共享wrapper目标链接时将明确选用的builtin JPEG/PNG归档移至toolkit依赖前，保留依赖闭包；核验shared产物和真实codec往返，不仅检查初始化符号。

**验证**:
```
核对实际jpeglib.h JPEG_LIB_VERSION、link.txt库顺序和nm -D符号版本；执行真实JPEG编码/解码往返，比较RED1/GREEN0及尺寸。
```
