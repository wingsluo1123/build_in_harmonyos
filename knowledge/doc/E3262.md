# E3262: 已连接 GTK 后端返回空监视器和未设置 DPI 时的能力值校验

## 基本信息
- **严重度**: 3
- **类别**: platform, compat, detection, runtime, testing
- **作者**: 6C2A

## 错误特征
```
PANGO_SIZE_NEGATIVE|pango_font_description_set_size.*size >= 0|Invalid display geometry
```

## 根因分析
GTK显示连接成功并不保证每项后端能力有效：sole monitor geometry可为0x0，screen resolution的-1表示未设置；上层若直接用于默认窗口或DPI比例，会形成零窗口尺寸和负Pango字号。

## 推荐方案
**方法**: validate-backend-values-before-gui-scaling

**说明**: 在几何查询、点到显示映射和Cairo缩放共同入口校验后端值；无效单monitor用真实GDK screen尺寸回退，未设置DPI用比例1；用真实窗口、文本测量及错误处理器验证。

**验证**:
```
比较实际GDK screen/monitor尺寸与resolution；运行test_wxgtk3_gui并要求工作区、窗口、文字尺寸为正且Pango critical=0；保留RED/GREEN退出码。
```
