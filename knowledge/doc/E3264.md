# E3264: Setuptools C++ extensions need an independent LDCXXSHARED override

## 基本信息
- **严重度**: 1
- **类别**: build-system, python, cpp
- **作者**: PV51

## 错误特征
```
invalid linker name in argument.*fuse-ld=bfd|LDCXXSHARED|linker_so_cxx
```

## 根因分析
New setuptools configures separate C and C++ extension shared-link commands. Overriding LDSHARED controls linker_so but leaves linker_so_cxx sourced from the interpreter LDCXXSHARED, including stale linker and dependency paths.

## 推荐方案
**方法**: configure-c-and-cxx-extension-linkers

**说明**: Set both LDSHARED and LDCXXSHARED from the current Conan compiler configuration, retain required dependency libdirs and explicit interpreter linking, then verify actual C++ link command, signed extension imports and unchanged semantic tests.

**修复命令**:
```
LDSHARED="<current C compiler> -shared" LDCXXSHARED="<current C++ compiler> -shared" python3 setup.py build
```

**验证**:
```
Inspect Compiler.configure_system and linker_so/linker_so_cxx; build and import the extension using pinned Conan dependencies; inspect DT_NEEDED and run the original test suite.
```
