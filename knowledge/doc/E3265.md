# E3265: meson 的 `glib_compile_schemas: true` 只在源码树内生效，打包场景**永远不会**产出 `gschemas.compiled`——消费者首次触发 GSettings 即 `GLib-GIO-FATAL-ERROR` + SIGTRAP；必须在 package() 阶段用 glib 包自带的 `glib-compile-schemas` 补编译并校验产物

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, packaging
- **作者**: unknown

## 错误特征
```
GLib-GIO-FATAL-ERROR: No GSettings schemas are installed on the system|gschemas\.compiled|glib_compile_schemas|SIGTRAP|abort\(\)|org\.gnome\.[A-Za-z0-9]+\.gschema\.xml
```

## 推荐方案
**方法**: compile-schemas-in-package-phase-and-fail-if-missing

**说明**: >-

**修复命令**:
```
glib-compile-schemas "$PKG/share/glib-2.0/schemas" && test -f "$PKG/share/glib-2.0/schemas/gschemas.compiled"
```

**验证**:
```
find <package>/share/glib-2.0/schemas -name '*.gschema.xml' | head; test -f <package>/share/glib-2.0/schemas/gschemas.compiled && echo SCHEMA_COMPILED_OK || echo SCHEMA_MISSING; glib-compile-schemas <package>/share/glib-2.0/schemas && test -f <package>/share/glib-2.0/schemas/gschemas.compiled && echo OK
```
