# E3266: OHOS 上 PyGObject 是**构建期不可用**而不是「没装」：meson 的 `find_installation('python3', modules:['gi'])` 直接让 setup 失败、数据生成器 `from gi.repository import GLib` 让 ninja 中止——装 pygobject 包也救不了（目标 CPython 3.12 ABI 不匹配），要 `required: false` + 纯标准库/ctypes 生成器

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, toolchain
- **作者**: unknown

## 错误特征
```
Could not find valid Python installation|find_installation.*modules.*gi|No module named 'gi'|from gi\.repository import GLib|Error relocating .*_gi\.cpython.*PyType_Ready: symbol not found|ModuleNotFoundError: No module named 'gi'
```

## 推荐方案
**方法**: drop-gi-hard-requirement-plus-pure-python-generator-with-cross-check

**说明**: >-

**修复命令**:
```
grep -rn "find_installation" --include=meson.build . && grep -rn "from gi.repository" --include=*.py . && python3 -c "import gi" || echo PYGOBJECT_UNUSABLE
```

**验证**:
```
python3 -c "import gi" ; python3 -c "import ctypes, ctypes.util; print(ctypes.util.find_library('glib-2.0'))"; grep -rn "find_installation" --include=meson.build .; grep -rn "from gi.repository" --include=*.py .
```
