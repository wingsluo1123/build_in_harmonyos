# E3269: Unicode CLI选项同时支持反斜杠转义时须保持文本层

## 基本信息
- **严重度**: 3
- **类别**: portability, runtime
- **作者**: 9336

## 错误特征
```
PAWK_UNICODE_DELIMITER_MISMATCH
```

## 根因分析
pawk0.8.1将已经Unicode的-F/-O/-L选项直接交unicode_escape，隐式UTF8转换后再次解码使非ASCII字面文本损坏。

## 推荐方案
**方法**: preserve-unicode-before-escape-decoding

**说明**: 将已Unicode选项先encode(raw_unicode_escape)，再decode(unicode_escape)，同时验证Unicode和ASCII转义消费者。

**修复命令**:
```
应用0001-pawk.py.patch，并通过Conan构建中九原函数及test_package安装包消费者验证。
```

**验证**:
```
python3.12 -B archives/p/pawk/0.8.1/test_package/consumer.py --package-folder <Conan-package-folder>
```
