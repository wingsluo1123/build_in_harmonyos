# E3270: OHOS loader 校验 .codesign 摘要：meson install 改写 .dynstr(RUNPATH) 使 lld 生成的摘要失配 → dlopen Permission denied；须从 build 树恢复 pristine .so

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, portability, build-system, codesign
- **作者**: 856F
- **来源 PR**: 14631

## 错误特征
```
dlopen.*Permission denied.*codesign.*meson install.*Error loading shared library.*symbol not found
```

## 根因分析
OHOS loader 在 dlopen 时校验 .codesign digest（由 lld -Wl,--code-sign 生成）是否与当前文件内容一致。(1) OHOS 适配版 'meson install' 会把已安装副本 .dynstr 中的绝对构建路径（RUNPATH 字符串如 /storage/.../.conan2/.../p/lib）改写成 'X'，使摘要失配；(2) 配方在链接后再用 binary-sign-tool -selfSign 重签同样破坏摘要。结果 loader 拒绝加载（'Permission denied' / 级联 'Error relocating ... symbol not found'）。build 树里链接时刻的原始 .so（pristine lld 签名）可正常加载。

## 推荐方案
**方法**: restore-pristine-so-after-install

**说明**: package() 中 Meson(self).install() 之后，从 meson build 树找回同名原始 .so（walk self.build_folder 匹配 basename），用 shutil.copy2 覆盖包内被改写/重签的副本，恢复 lld 生成的 .codesign 摘要；不要用 binary-sign-tool 重签（CI 在 release 阶段用 ci/artifacts/sign.sh 统一签名）。

**修复命令**:
```
def _restore_pristine_shared_libraries(self):\n    for root,_,files in os.walk(self.build_folder):\n        for f in files:\n            if f.endswith('.so') and not os.path.islink(...):\n                src=os.path.join(root,f); dst=os.path.join(self.package_folder,'lib',f)\n                if os.path.exists(dst): shutil.copy2(src,dst)
```

**验证**:
```
对比 build 树原始 .so 与包内 .so 的字节（cmp 应有差异且集中在 .dynstr/RUNPATH）；或 conan create 后直接运行 test_package 观察 dlopen Permission denied / symbol not found。
```
