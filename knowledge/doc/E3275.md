# E3275: freedesktop 守护进程型组件（ModemManager/NetworkManager 同族）做 library-only 交付时：上游 meson 无 -Ddaemon 开关且测试目录挂在 src/ 内部依赖上，须用中性布尔门控补丁裁剪 daemon 侧目录（含 test/ 与 tools/tests/），并把测试申报改为"全仓 N 口径分口径"（离线真跑 + daemon 环境逐类定性豁免），否则 rule4 少报打回

## 基本信息
- **严重度**: 2
- **类别**: build-system, packaging, testing
- **作者**: unknown
- **来源 PR**: 14799

## 错误特征
```
ERROR:.*Unknown options.*daemon|subdir.*src.*Dependency.*libhelpers_dep.*not found|meson.*configure.*failed.*daemon|ERROR:.*dependency.*libgudev|.*polkit.*not found|.*D-Bus system bus.*not available|test-wrapper\.sh.*dbus-daemon.*not found
```

## 根因分析
freedesktop 系的"守护进程+客户端库"双层组件（ModemManager=daemon+libmm-glib、NetworkManager=daemon+libnm）在 OHOS 上只能交付客户端库：daemon 运行期硬依赖 D-Bus 系统总线、udev+libgudev 内核设备跟踪、可选 libmbim/libqmi/libqrtr、systemd journal/suspend-resume、polkit 与厂商插件栈，OHOS PC 均无此系统环境。但上游 meson.build 无条件 subdir('src')/subdir('cli')，没有开关可关。且上游测试套件结构与 daemon 耦合：顶层 test/ 程序链接 src/meson.build 内部声明的 libhelpers_dep/libkerneldevice_dep/libport_dep（library-only 构建下这些变量未定义，-Dtests=true 直接 configure 报错）；tools/tests 经 test-wrapper.sh 在 meson test 阶段拉起 D-Bus 会话总线跑 stub。若因此把 -Dtests 整体置 false 并在 PR 正文只申报"子集 N"，审查复扫按全仓 g_test_add_func 注册数实测（ModemManager 1.24.2 = 377：libmm-glib/tests 69 + src/tests 143 + src/plugins 165）就会命中 rule4 少报（实测 N > 声明 N）。

## 推荐方案
**方法**: neutral-bool-gate-patch-plus-tests-split-census

**说明**: (1) 写中性 portability 补丁给顶层 meson.build 加 -Ddaemon 布尔选项（默认 true，上游行为不变），-Ddaemon=false 时跳过 src/、cli/、examples/ 子目录，并在顶层生成原本由 src/meson.build 生成的 headers-only pkg-config（ModemManager.pc——libmm-glib.pc 的 requires 引用它，不补则下游 pkg-config 解析断链）；(2) 关键增量：把顶层 enable_tests 块里的 test/ 与 tools/tests/ 一并门控进 enable_daemon（test/ 引用 src/meson.build 未定义变量，不门控则 -Dtests=true 在 library-only 下 configure 直接崩），使 -Dtests=true 在 library-only 构建可用，只配置离线套件（libmm-glib/tests、libqcdm/tests）；(3) conanfile 里 -Dtests=true + build() 阶段调 Meson(self).test()（"meson test -v"），并为测试注入运行环境：LD_LIBRARY_PATH 前置 build_folder/libmm-glib（刚构建的 libmm-glib.so）+ 依赖 libdirs（conan glib so），否则测试二进制起不来；(4) PR 正文统计表改"全仓 N 分口径"：N=全仓 g_test_add_func 注册数（与审查同口径），分解为"可离线 X + 需 daemon 环境 Y"，X 真跑 PASS、Y 逐类定性豁免（src/tests 链 daemon 内部静态库+需 PTY/udev、src/plugins 厂商插件栈随 daemon 裁剪、test/ 需真实 TTY、tools/tests 需 dbus-daemon），合计行+鸿蒙特有测试行（test_package 消费者用例即鸿蒙特有测试，rule12 过闸）；(5) 验证结果段同口径：上游通过率 X/N（离线子集 X/X=100% + 豁免说明带"环境限制"关键词）。

**修复命令**:
```
grep -rhoE 'g_test_add_func[[:space:]]*\(' <src> --include='*.c' | wc -l   # 全仓 N 清点（审查 rule4 同口径）；分目录：libmm-glib/tests / src/tests / src/plugins
```

**验证**:
```
conan create archives/m/<pkg>/<ver> -pr:h=~/.conan2/profiles/ohos-aarch64 --build=missing -c tools.build:jobs=2   # 观察 "meson test -v" 段：Ok: 3 Fail: 0（离线套件真跑）+ test_package 13/13
```
