# E3279: mode-bound-original-oracles

## 基本信息
- **严重度**: 1
- **类别**: perl, testing, runtime-state
- **作者**: A139

## 错误特征
```
inflection mode oracle mismatch|classical.*formula|TAP plan mismatch
```

## 根因分析
词形API的classical状态改变同一输入的正确结果；原程序的模式与进程边界及早期/尾部TAP计划不能用版本横幅或单一默认模式替代。

## 推荐方案
**方法**: mode-bound-original-oracles

**说明**: 保留每项原模式、输入和预期及原Harness进程边界，分别核验原程序和TAP，安装消费者调用真实API并确认来源。

**修复命令**:
```
make test TEST_VERBOSE=1; run installed PL_N and NUMWORDS consumers
```

**验证**:
```
运行原make test TEST_VERBOSE=1，核对每个源程序的哈希、原模式期望、全部TAP计划和结果，再执行真实安装API。
```
