# E3284: "OHOS 上 /dev/i2c-* 与 /sys/class/i2c-dev 不存在（ENOENT）、内核无 i2c 模块 ⇒ 依赖 i2c-dev 的用户态工具（DDC/CI、i2c-tools 族）运行期打不开设备；这是 open() 期能力面、不是编译墙（linux/i2c-dev.h 头存在、编译照常通过）"

## 基本信息
- **严重度**: "2"
- **类别**: platform, detection, runtime, device-node, i2c
- **作者**: "主理-2 <主理-2@local>"
- **来源 PR**: "(本 PR)"

## 错误特征
```
"/dev/i2c-[0-9]+.*No such file or directory|No such file or directory.*/dev/i2c|/sys/class/i2c-dev.*(No such file|ENOENT)|Unable to open i2c|No such device.*i2c|ddc.*device.*not found"
```

## 根因分析
"OHOS 设备未启用/未暴露 i2c-dev 字符设备与 drm 设备节点，内核也未加载任何 i2c/drm/smbus 模块（/proc/modules 实测为无）；/sys/class/drm 目录虽存在但对本进程 EACCES。属平台运行期能力缺口，与被适配包的代码无关"

## 推荐方案
**方法**: "errno-probe-declare-runtime-capability-and-test-text-paths"

**说明**: "以 open() errno 实测落运行期能力面结论（ENOENT=不存在 / EACCES=存在不可访问，均记『打不开』），编译照常交付；test_package 断言 -h/-V 等文本路径（appres 模式），notes.md 逐条披露不可用节点与 errno；⛔ 不 mock 设备、不谎称可用；披露文字与测试口径三处同源（notes / test_package MANIFEST / PR 正文）"

**修复命令**:
```
"真机逐项: ls -l /dev/i2c-* /sys/class/i2c-dev /dev/dri /sys/class/drm + open() 看 errno + grep -E 'i2c|drm|smbus' /proc/modules；test_package 用 -h/-V 输出文本断言（不碰设备）"
```

**验证**:
```
"ls -l /dev/i2c-* /sys/class/i2c-dev /dev/dri /sys/class/drm; 以 open() 实测取 errno（⚠ 不要用 exists() 判）；grep -E 'i2c|drm|smbus' /proc/modules; 有 ddccontrol 时 ddccontrol -h（参数解析面、不碰设备）"
```
