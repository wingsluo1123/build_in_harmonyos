# E3288: 上游 pytest 套件取离线子集应以其自身 marker 为准；并先核对 sdist 的测试落点（包内 vs 顶层）

## 基本信息
- **严重度**: 1
- **类别**: compat, portability, build-system
- **作者**: 19CA

## 错误特征
```
file or directory not found: tests/|requests.exceptions.ConnectTimeout|@pytest.mark.network|deselected|No module named
```

## 根因分析
两个高频坑：①**测试落点**——不少库把测试放在**包内**（pooch 即 `pooch/tests/`），官方 sdist 没有顶层 `tests/`，照抄 `tests/` 会 `file or directory not found: tests/`（首轮本地 CI 即如此），应先 `find <sdist> -maxdepth 2 -name 'test_*.py'` 核对落点再定 test_path；②**网络用例**——上游常用 `@pytest.mark.network` 标注需要真实外网的用例（pooch 源码内实测 38 处），本环境直跑会 `requests.exceptions.ConnectTimeout`，个别用例还会**挂住不返回**（日志零增长、被 timeout 截断）；正确做法是用**上游自己的标记**取离线子集 `-m 'not network'`，而不是私自挑文件或整批跳过。
