# E3290: Cython 跨包 cimport 只吃声明文件——构建期依赖（SciPy/numpy）缺失时 vendored .pxd + 把上游 run_command 版本探测改成非致命

## 基本信息
- **严重度**: 2
- **类别**: build-system, python, dependency, packaging, compilation
- **作者**: 9DB5
- **来源 PR**: feat/scikit-learn-1.6.1

## 错误特征
```
sklearn/meson\.build.*ERROR: Command .*import (numpy|scipy).*returned non-zero exit status|
```

## 根因分析
两个独立的构建期陷阱，都源于把「运行期依赖」当成「构建期依赖」。

## 推荐方案
**方法**: vendored-declaration-only-pxd

**说明**: 把需要的那几个 `.pxd` 从与运行期同族的 SciPy 版本逐字取出来放进配方目录（scikit-learn 1.6.1 用

**修复命令**:
```
export CYTHON_INCLUDE="--include-dir $PWD/pxds"; cython --include-dir pxds sklearn/utils/_cython_blas.pyx
```

**验证**:
```
grep -rn "^\s*from scipy.*cimport\|cimport scipy" sklearn/**/*.pyx       # 直接 cimport 的源文件清单
```
