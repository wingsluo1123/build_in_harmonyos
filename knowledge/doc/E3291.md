## 根因分析
Cython 官方 CHANGES 在 3.1.0rc1（2025-05-01）明写「Named "cpdef enums" no longer copy

## 推荐方案
**方法**: republish-enum-members-in-pyx

**说明**: 在被打补丁的 .pyx 末尾按 Cython 官方建议显式把成员回填进模块字典，值与语义都不变：

**修复命令**:
```
printf 'for _e in (BLAS_Order, BLAS_Trans):\n    globals().update({_m.name: _m for _m in _e})\ndel _e\n' >> sklearn/utils/_cython_blas.pyx
```

**验证**:
```
# 1) 命中判据：源码用具名 cpdef enum（不是 cdef enum / 匿名 enum）
```
