# E3296: "配方侧按 probe-first 位置链逐级探测（override CONAN_EL2_TEST_ROOT → /da

## 基本信息
- **严重度**: P1
- **类别**: platform
- **作者**: unknown

## 错误特征
```
"Error loading shared library /storage/.*: Permission denied|Can't load .*/blib/.*\.so.*Permission denied|Non-zero exit status: 13|exit status: 22|Tests: 0.*No plan found|Permission denied at .*DynaLoader.pm line 206"
```

## 根因分析
"hnp 打包的解释器（python3/node/perl）的加载器按命名空间只信任 hnp 树内的库（类似 Android linker namespace），与路径分区和签名均无关——五位置终局实证（2026-10-15 CI）：① 解释器自身 site-packages/conan-build-deps 槽位 EACCES（槽位已预留唯权限未开）；② /data/app（HNP_PRIVATE_HOME）EACCES；③ /data/service/el2/100 EACCES；④ /data/storage/el2/base/cache（el2 沙箱）可写可装但 loadable=False，binary-sign-tool 重签后仍拒；⑤ build-local（/storage，conan 缓存）同拒。重签四案并案（brotlicffi/leapp-cli/pyqt6-sip/perl-berkeleydb）全部无效。"

## 推荐方案
**方法**: "配方侧按 probe-first 位置链逐级探测（override CONAN_EL2_TEST_ROOT → /data/app → /data/service/el2/100 → el2 内 TMPDIR → 字面 el2 → build-local），全部拒绝即按 TEST_QUALITY_SPEC §3.3 落实测豁免（rule hnp_loader_gate_test_load / hnp_loader_gate_build_deps，五位置日志行即证据），dev box 真实执行为主证据；唯一根治路径是平台侧（issue #4056）：① 预置 hnp 包内 site-packages/conan-build-deps 槽位并赋 CI worker 写权限（命名空间天然信任该树，五包配方零改动即恢复），或 ② 对 worker 放开 /data/app 或 /data/service/el2/100 写权限。配套：找解释器实际在用的库读其 /proc/self/maps（sysconfig 在多用户 hmdfs 沙箱下说谎）；musl 链 libpython 必配 -Wl,-rpath；conan env='conanrun' 整表替换环境；perl 侧 errno 形态退出码需捕获式 make test + 首个失败 .t 复跑拿 die 原文。"
