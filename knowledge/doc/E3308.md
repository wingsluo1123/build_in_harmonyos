# E3308: test_package/消费性测试的断言必须放在 API 成功分支内：失败路径不得读取未初始化的输出参数

## 基本信息
- **严重度**: 2
- **类别**: conan, testing, c-language, review
- **作者**: tianyi_wang <tianyi@noreply.gitcode.com>

## 错误特征
```
FAIL: lwdtc_cron_next|FAIL: next <= now|uninitialized.*read|未初始化.*读取|test_package.*未初始化
```

## 根因分析
test_package/test.c 等消费性测试在调用带输出参数的 API 后，

## 推荐方案
**方法**: assert-inside-success-branch

**说明**: 修复 test_package 失败路径未初始化读：①把输出参数断言

**修复命令**:
```
/data/service/hnp/bin/clang -I <src>/lwdtc/src/include -I <opts> -Wall -Wextra -Werror -Wno-unused-parameter -o $TMPDIR/test_package_fixed <src>/lwdtc/src/lwdtc/lwdtc.c archives/l/lwdtc/1.0.0/test_package/test.c && $TMPDIR/test_package_fixed
```

**验证**:
```
<clang> -Wall -Wextra -Werror -o test_package_fixed lwdtc.c test_package/test.c && ./test_package_fixed && <clang> -o test_negative lwdtc.c test-negative.c && ./test_negative
```
