# E3309: OHOS musl 无 localtime_s：MaJerle 系库用户 opts 头默认绑定 Windows API，注入 localtime_r 用户配置即可

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, libc, opts-header
- **作者**: tianyi_wang <tianyi@noreply.gitcode.com>

## 错误特征
```
call to undeclared function 'localtime_s'|implicit declaration.*localtime_s|LWDTC_CFG_GET_LOCALTIME|localtime_s\(
```

## 根因分析
MaJerle 系列库（lwdtc 等）把平台相关行为放进用户可覆盖的 opts 头：

## 推荐方案
**方法**: user-opts-inject-localtime-r

**说明**: 不修改上游源码，用 lwdtc 官方用户配置机制注入 OHOS 适配头：

**修复命令**:
```
conan create archives/l/lwdtc/1.0.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create archives/l/lwdtc/1.0.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
