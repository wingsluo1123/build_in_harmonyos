# E3315: rwlock-demote-to-recursive-mutex

## 基本信息
- **严重度**: 2
- **类别**: 
- **作者**: unknown

## 错误特征
```
kdump_open_fdset 成功后 checkattr/dumpdata 在 FUTEX 永久等待|test: 4: unexpected operator/operand 等伪失败后仍挂起|r03 45 项 wchan=do_rt_sigsuspend/FUTEX
```

## 根因分析
src/kdumpfile 使用 pthread_rwlock（context.c rwlock_init），open.c uts_name_from_init_uts_ns()/update_linux_utsname() 采用"持锁->unlock->回调(get_symbol_val 内部 rdlock 同一把锁)->重取 wrlock"的放锁-重取模式；musl rwlock 的写者-读者唤醒顺序使同线程重入永久等待（父 sh do_rt_sigsuspend、子 checkattr FUTEX）。src/addrxlat 零锁，故未打开 dump 的 116 项全过、打开 dump 的 76 项全挂。
