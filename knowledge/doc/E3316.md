# E3316: autotools 项目在 OHOS 上 configure 生成的 libtool 脚本存在两个缺陷：小写 echo 变量未定义（X--tag=CC: inaccessible or not found）与 old_archive_cmds/old_postinstall_cmds 引用未赋值的 tool_oldlib（ranlib 无参调用），需在 build() 内联修补生成物

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, autotools, libtool
- **作者**: unknown

## 错误特征
```
X--tag=CC: inaccessible or not found|
```

## 根因分析
configure 生成的 libtool 脚本在 config 段只定义了大写 ECHO

## 推荐方案
**方法**: patch-generated-libtool-inline

**说明**: conanfile.py build() 在 autotools.configure() 之后、make 之前

**修复命令**:
```
# conanfile.py build() 内联（见 libkdumpfile 0.5.5 配方）：
```

**验证**:
```
grep -c "echo=\$ECHO" <build_dir>/libtool;
```
