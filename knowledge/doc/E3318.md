# E3318: Clang malloc/calloc builtins distort libklibc allocator tests; disable only those builtins for upstream test compilation

## 基本信息
- **严重度**: 2
- **类别**: ohos, libc, compiler, clang, testing
- **作者**: iKalous_OscarP <iKalous_OscarP@noreply.gitcode.com>
- **来源 PR**: 15878

## 错误特征
```
upstream tests: .*failed.*malloctest3|malloctest3.*assert.*p == NULL|malloctest3.*assert.*calloc
```

## 根因分析
Clang recognizes malloc/calloc as builtins while compiling malloctest3. On HarmonyOS AArch64 this changes the behavior observed by the test's zero-size malloc and overflow-calloc assertions, so the test exercises compiler assumptions rather than the built libklibc allocator. Disabling only the two builtins makes the unchanged upstream test pass.

## 推荐方案
**方法**: disable-malloc-calloc-builtins-for-upstream-tests

**说明**: Add -fno-builtin-malloc and -fno-builtin-calloc only to the upstream test build flags so tests call the target allocator and preserve every upstream assertion.

**修复命令**:
```
MAKEFLAGS= make -j1 test EXTRA_KLIBCCFLAGS="<target flags> -fno-builtin-malloc -fno-builtin-calloc"
```

**验证**:
```
MAKEFLAGS= make -j1 test EXTRA_KLIBCCFLAGS="<target flags> -fno-builtin-malloc -fno-builtin-calloc"; execute all 39 usr/klibc/tests programs and require passed=39, failed=0, not_built=0, skipped=0
```
