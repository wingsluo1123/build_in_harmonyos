# E3319: recognize-autotools-source-manifest

## 基本信息
- **严重度**: 3
- **类别**: autotools, toolchain, framework
- **作者**: C659

## 错误特征
```
嵌套源码检测: 找到源码在 .*，正在提升|源码目录仅剩少量文件|configure\.ac 缺失
```

## 根因分析
init-build 的 build-root 探测器只把 configure/CMakeLists.txt/Makefile/meson.build 当构建标志，不认 autotools 源码清单 configure.ac+Makefile.am；源码包不含生成的 configure 时它会继续下钻，命中任意含纯 Makefile 的子目录（如 c++_ext）并把整棵树提升成该子目录，导致源码树被毁

## 推荐方案
**方法**: recognize-autotools-source-manifest

**说明**: 探测器应把 configure.ac/Makefile.am 纳入构建标志（与 lang_detect 的 manifest 判定对齐），且只在顶层无任何标志时才允许下钻一级

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
提升后核对 .work/configure.ac 与顶层目录数量；git archive 解压对比文件数
```
