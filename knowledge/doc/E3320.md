# E3320: patch-cpp-to-clang-E

## 基本信息
- **严重度**: 2
- **类别**: platform, autotools, testing
- **作者**: A394

## 错误特征
```
sh: cpp: inaccessible or not found|Preprocessing .*\.as
```

## 根因分析
OHOS 设备不提供 cpp 可执行文件（hnp/bin 只有 clang 家族）；上游把预处理器命令硬编码为 #define CPP "cpp -xc++ -P -Wall" 并经 system() 调用

## 推荐方案
**方法**: patch-cpp-to-clang-E

**说明**: 补丁把命令改为 clang -E -xc++ -P -Wall（clang 自带预处理器，-P 去 linemarker 语义等价）

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
command -v cpp || echo missing；改后 make check 中该用例组 PASS
```
