# E3321: inject-without-quotes

## 基本信息
- **严重度**: 3
- **类别**: autotools, conan, dependency
- **作者**: 6061

## 错误特征
```
checking for .* in -l.*\.\.\. no|checking for gif_lib\.h\.\.\. no|checking for png\.h\.\.\. no
```

## 根因分析
注入依赖路径时写成 f"-L\"{lib}\""（自带双引号），引号被当成路径字面量的一部分，-L 指向不存在的目录 → configure 把可选库判为不存在；系统自带同名库（如 zlib）会掩盖问题，让人误以为注入已生效

## 推荐方案
**方法**: inject-without-quotes

**说明**: env.append("LDFLAGS", f"-L{lib}")（不加引号）；诊断时不要以 zlib 通过为准，它可能是系统库

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
grep -o "export LDFLAGS=\"[^\"]*\"" conanautotoolstoolchain.sh 确认路径无内嵌引号；再看 configure 输出里目标库为 yes
```
