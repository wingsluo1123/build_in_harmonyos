# E3322: Conan适配版本与Perl XSLoader模块版本分别绑定

## 基本信息
- **严重度**: 2
- **类别**: compat, perl, runtime
- **作者**: A139

## 错误特征
```
XS object version does not match bootstrap parameter|adaptation version differs from module VERSION
```

## 根因分析
Conan包版本是适配制品身份，Perl模块VERSION同时参与XSLoader引导契约；二者不能因包后缀递增而机械同步。

## 推荐方案
**方法**: preserve-original-language-runtime-contract

**说明**: 保留官方PM与XS来源及模块VERSION；只递增真实Conan适配版本，核对实际安装PM哈希及XSLoader调用，再执行原测试和真实泄漏/非泄漏API。

**修复命令**:
```
make test TEST_VERBOSE=1
```

**验证**:
```
同源未改模块与完整原make test，实际Conan安装消费者和目标运行语义分别核验。
```
