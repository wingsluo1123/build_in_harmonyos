# E3327: semantic-and-byte-revision-separate-binding

## 基本信息
- **严重度**: 1
- **类别**: conan, metadata, revision
- **作者**: A139

## 错误特征
```
declaration-only change gives different recipe revision|settings AST equal RREV differs
```

## 根因分析
Conan实际配方修订受导出字节影响；settings AST值相同不能保证RREV相同，旧PID不能替代新精确发布身份。

## 推荐方案
**方法**: semantic-and-byte-revision-separate-binding

**说明**: 分别绑定settings语义、导出字节和实际RREV/PID/PREV，新制品接受独立证明。

**修复命令**:
```
conan export recipe; conan install --build=never
```

**验证**:
```
两个隔离CONAN_HOME同名同版本conan export，逐字节单变量比较并读取实际RREV；再核对精确下载图。
```
