# E3331: keycloak-config-cli 6.4.0 起 KeycloakConfigProperties 无 realm 字段，旧版 --keycloak.realm 调用触发 ignoreUnknownFields=false 的 left unbound 绑定失败；必填仅 keycloak.url + keycloak.version

## 基本信息
- **严重度**: 3
- **类别**: compat, limitation
- **作者**: AA01

## 错误特征
```
left unbound|Binding to target.*KeycloakConfigProperties.*failed
```

## 根因分析
6.4.0 的 KeycloakConfigProperties（构造器绑定）字段集为 loginRealm(默认 master)/clientId(默认 admin-cli)/version(@NotNull 无默认)/url(@NotNull)/user(默认 admin)/password/clientSecret/grantType(默认 password)/sslVerify(默认 true)/httpProxy/connectTimeout/readTimeout/availabilityCheck——没有 realm 字段。类注解 ignoreUnknownFields=false，因此传入旧文档/旧脚本的 --keycloak.realm=xxx 时，Spring 绑定引擎把该属性判为 unknown 且拒绝忽略，抛出 "Binding to target [...KeycloakConfigProperties...] failed: Property: keycloak.realm ... Reason: The elements [keycloak.realm] were left unbound"，应用启动即失败。realm 概念在 6.x 已移入每个 import 配置文件内部的 "realm" 字段（如 contrib/example-config/moped.json）。

## 推荐方案
**方法**: drop-realm-pass-version

**说明**: 删除 --keycloak.realm 参数（loginRealm 默认 master 即登录用 realm；目标 realm 在 import 配置文件内声明），并补上必填的 --keycloak.version=<目标 Keycloak 版本>

**修复命令**:
```
java -jar keycloak-config-cli.jar --keycloak.url=$URL --keycloak.version=$KC_VERSION --keycloak.user=admin --keycloak.password=$PASS --import.files.locations=$CFG
```

**验证**:
```
无 realm 参数启动：java -jar keycloak-config-cli.jar --keycloak.url=http://127.0.0.1:<封闭端口> --keycloak.user=admin --keycloak.password=x --import.files.locations=<有效文件> → 应越过绑定阶段进入 Keycloak 连接阶段（Connection refused 签名）
```
