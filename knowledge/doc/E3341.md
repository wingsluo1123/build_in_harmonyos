# E3341: Verify authentication failure does not consume replay state on the same session

## 基本信息
- **严重度**: 2
- **类别**: runtime, testing, security
- **作者**: A714

## 错误特征
```
auth_fail|replay_fail|tamper rejection without replay-state corruption
```

## 根因分析
Roundtrip-only tests and negative tests on fresh receiver contexts cannot detect whether an authentication failure wrongly updates anti-replay state and rejects the subsequent authentic packet.

## 推荐方案
**方法**: negative-positive-replay-on-one-session

**说明**: On one receiver session submit a mutated authenticated packet, then the untouched packet with the same sequence number, then its replay; assert authentication failure, successful recovery and replay failure respectively.
