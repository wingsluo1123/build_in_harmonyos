# E3343: conan CMakeDeps 下 FindOpenSSL/FindZLIB 的模块变量为空、目标名不同，须按 imported target 分支并补 BUILD_INTERFACE 头传播

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, cmake, conan
- **作者**: 23D9

## 错误特征
```
'openssl/bio.h' file not found|OPENSSL_INCLUDE_DIR-NOTFOUND|Target "ZLIB::ZLIB" of type .* does not exist|Target "openssl::openssl" of type
```

## 根因分析
conan 2 的 CMakeDeps 不执行 CMake 内置 Find 模块逻辑：${OPENSSL_LIBRARIES}/${OPENSSL_INCLUDE_DIR}/${ZLIB_LIBRARIES} 为空，且 zlib 的导出目标是 zlib::zlib（小写）而非 ZLIB::ZLIB；而 openssl 包提供 openssl::openssl imported target。沿用上游的模块变量写法会静默丢 include/lib，公共头（如 IXSocketOpenSSL.h 含 <openssl/*.h>）在消费方编译失败。

## 推荐方案
**方法**: imported-target-branch

**说明**: 在上游 CMake 里加 if (TARGET openssl::openssl)（或检测 zlib::zlib）分支走 conan imported target，else 保留原模块变量路径；PRIVATE 链接的依赖若被公共头引用，用 $<BUILD_INTERFACE:$<TARGET_PROPERTY:dep,INTERFACE_INCLUDE_DIRECTORIES>> 传播头文件。

**修复命令**:
```
if (TARGET openssl::openssl)\n  target_link_libraries(ixwebsocket PRIVATE openssl::openssl)\n  target_include_directories(ixwebsocket PUBLIC $<BUILD_INTERFACE:$<TARGET_PROPERTY:openssl::openssl,INTERFACE_INCLUDE_DIRECTORIES>>)\nelse()\n  # 原模块变量路径
```

**验证**:
```
conan create archives/w/ws/11.4.6 -pr:h ci/conan/profiles/ohos-aarch64 --build=missing --user=ohpcd --channel=stable
```
