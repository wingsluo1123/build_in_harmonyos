# E3344: conan skip_shared_packages 之下，shared 包（如 spdlog）的传递依赖（如 fmt）cpp_info 为空，需声明为直接依赖

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, cmake, conan
- **作者**: 6A11

## 错误特征
```
Could not find a package configuration file provided by "fmt"|'fmt/core.h' file not found|fmt_INCLUDE_DIRS_RELEASE|Undefined symbols.*fmt::
```

## 根因分析
本制品仓 CI profile 启用 skip_shared_packages：当依赖图中存在 shared 包（spdlog/1.11.0 为 shared）时，conan 跳过其传递依赖的 cpp_info 聚合，于是 fmt/8.1.1 虽在依赖图中且已安装，但 CMakeDeps 拿到的 fmt 配置为空（fmt_INCLUDE_DIRS_RELEASE/fmt_LIBS_RELEASE 空），编译期报 'fmt/core.h' file not found、链接期报 Undefined symbols: fmt::。

## 推荐方案
**方法**: declare-direct-requirement

**说明**: 把传递依赖提升为配方直接 requires（self.requires("fmt/8.1.1")），其 cpp_info 即完整生成；并在上游 CMake 用 find_package(fmt CONFIG REQUIRED) + target_link_libraries(... fmt::fmt) 显式消费。

**修复命令**:
```
self.requires("fmt/8.1.1")  # + patch: find_package(fmt CONFIG REQUIRED); target_link_libraries(ws spdlog::spdlog fmt::fmt)
```

**验证**:
```
conan graph info --requires=ws/11.4.6@ohpcd/stable -pr:h ci/conan/profiles/ohos-aarch64 | grep -A2 fmt
```
