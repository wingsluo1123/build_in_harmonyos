# E3346: 手写 Makefile 的 uname 平台闸不识别 HarmonyOS：用 UNAME=<平台> 构建变量选中上游 Linux 分支（零补丁），并注意命令行 CFLAGS 会静默丢弃分支宏

## 基本信息
- **严重度**: 2
- **类别**: platform, detection, portability, build-system, make
- **作者**: A7D7

## 错误特征
```
Makefile:[0-9]+: \*\*\* Operating System not supported|Operating System not supported\.\.  Stop\.|\$\(error Operating System not supported|UNAME:=\$\(shell uname\)
```

## 根因分析
手写 Makefile 在解析期用 UNAME:=$(shell uname) 取得系统名，再与作者写死的

## 推荐方案
**方法**: make-platform-variable-override

**说明**: 在 recipe 的 build() 中用命令行 make 变量覆盖上游的平台判定变量

**修复命令**:
```
make -j1 UNAME=Linux CC=<conan tools.build:compiler_executables:c> \
```

**验证**:
```
1) sed -n '1,40p' Makefile | grep -nE "uname|\\$\\(error"  定位平台闸与行号;
```
