# E3349: 解释器旧模式策略断言与当前并发后端功能覆盖

## 基本信息
- **严重度**: 2
- **类别**: threading, perl, test-applicability
- **作者**: A139

## 错误特征
```
Only verifiable on Perl < 5.10|Only verifiable on MSWin32
```

## 根因分析
原测试同时注册旧解释器和其它系统的模式选择策略，真实当前后端运行与这些分支适用条件并非同一结论。

## 推荐方案
**方法**: separate-mode-policy-predicates-from-live-backend

**说明**: 保留原注册及3项原skip，只按同版本明确谓词区分旧Perl/Windows断言；当前fork和ithreads完整执行，root降权单独披露。

**修复命令**:
```
make test TEST_VERBOSE=1
```

**验证**:
```
原make test TEST_VERBOSE=1，逐程序与TAP身份核对原源码，再分别验证并发socket往返和非root非法UID变更检测。
```
