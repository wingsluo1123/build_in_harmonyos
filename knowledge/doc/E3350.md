# E3350: 共享对象重新bless后的每引用重载状态刷新

## 基本信息
- **严重度**: 2
- **类别**: compat, perl, runtime
- **作者**: A139

## 错误特征
```
SvAMAGIC reference versus referent|overloaded alias rebless state
```

## 根因分析
Perl重载标志是引用的属性，修改共享对象的blessing不能据此推断每个别名引用缓存的重载状态已经同步。

## 推荐方案
**方法**: preserve-original-language-runtime-contract

**说明**: 保留原overload.t所有12断言和上游重新bless步骤；分别核对实际字符串化值、对象类型、第二引用刷新及最终引用地址，不删掉重载场景或仅用标量相等替代。

**修复命令**:
```
make test TEST_VERBOSE=1
```

**验证**:
```
同源未改模块与完整原make test，实际Conan安装消费者和目标运行语义分别核验。
```
