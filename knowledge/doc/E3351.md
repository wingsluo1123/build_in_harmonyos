# E3351: 宿主程序脚本插件包/纯数据包形态三方库无 C/C++ 交付物，选型即 env_unsupported（lang_hold），禁止硬适配

## 基本信息
- **严重度**: 2
- **类别**: limitation, detection, conan, packaging
- **作者**: li_shuo <ls.fr@qq.com>

## 错误特征
```
no compilable source|no Makefile|no CMakeLists.txt|\
```

## 根因分析
交付物是宿主应用程序（Prosody/Asterisk/Jitsi 等服务端）的运行时脚本插件或静态数据文件（Lua/Python/Perl 模块、conf、service 单元），不含任何可编译 C/C++ 翻译单元与库产物；conan C/C++ 流水线无对应包模型，CI 也无对应解释器/宿主运行时，编译通过概念不成立

## 推荐方案
**方法**: lang-preflight-early-disposition

**说明**: 选型/立项阶段（下载源码后立即）运行 lang-preflight + 插件包特征探测，判定为非 C/C++ 交付物即用 result 命令上报 env_unsupported（带 detected_language 与 language_evidence 三字段），释放任务——平台转 lang_hold 挂起等生态，不算失败

**修复命令**:
```
python3 $SKILL_ROOT/scripts/ohc-run.py lang-preflight <name> <ver> --src $BUILD_SRC_DIR && \
```

**验证**:
```
find <src> -name "*.lua" -o -name "*.py" -o -name "*.pl" | wc -l; \
```
