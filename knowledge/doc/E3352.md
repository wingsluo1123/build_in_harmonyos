# E3352: aarch64 上负数 double 直接转 uint32/int32 为 C 标准 UB——

## 基本信息
- **严重度**: 2
- **类别**: portability, compilation, aarch64, c-language, runtime-safety
- **作者**: ohpcd-pc2
- **来源 PR**: archives/m/mjs/2.9.0

## 错误特征
```
\(0-14\) >>> 2.*expected 1073741820|mjs_get_int.*-14|
```

## 根因分析
C11 6.3.1.4 规定实浮点转整型时若值无法表示行为未定义；负数

## 推荐方案
**方法**: int64-trampoline-narrow

**说明**: 负数/越界 double 先转 int64_t（值域内定义良好，IEEE double

**修复命令**:
```
(mjs.c)
```

**验证**:
```
conan create archives/m/mjs/2.9.0 --build=missing
```
