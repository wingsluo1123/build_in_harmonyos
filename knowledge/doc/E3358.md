# E3358: OHOS CI worker 进程争用：测试阶段 fork(2) EAGAIN（瞬时）→ 有界重试

## 基本信息
- **严重度**: P3
- **类别**: platform, ohos
- **作者**: 75DA

## 错误特征
```
fork: retry: Resource temporarily unavailable|cannot fork|Resource temporarily unavailable.*fork
```

## 根因分析
OHOS CI worker 在构建/测试阶段进程或资源瞬时紧张，bash 启动子进程时 fork(2) 返回 EAGAIN，报 'fork: retry: Resource temporarily unavailable'；紧随其后的同类命令往往成功（瞬时性）。本地开发机通常无此限制，故本地 W3 不复现。注意与 exec/shebang 失败（E165/E430）区分：本条是 fork 失败，子进程日志为空。

## 推荐方案
**方法**: 对测试/构建子进程做有界重试：仅在『子进程未产出日志』或输出命中 Resource temporarily unavailable/cannot fork/Cannot allocate memory 时重试（≤3 次，退避）。切勿对真实测试失败也重试（会掩盖）。同时用 --ignore-scripts 等方式降低进程 churn。

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
观察子进程是否未产出日志且出现 fork: retry；重试后若成功即为瞬时；本地一般不复现
```
