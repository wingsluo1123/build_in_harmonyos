# E3359: OHOS：hnp node.org 自带 bin/npm 是残缺 stub（MODULE_NOT_FOUND）→ 用真实 npm-cli.js

## 基本信息
- **严重度**: P2
- **类别**: ohos, node-runtime, package-manager
- **作者**: 86A1

## 错误特征
```
Cannot find module '\.\./lib/cli\.js'|Require stack:.*/bin/npm|npm: not found|npm run build.*MODULE_NOT_FOUND
```

## 根因分析
hnp node.org 安装里的 <node>/bin/npm 内容是 '#!/bin/env node\nrequire(\'../lib/cli.js\')(process)'，其相对路径解析到 <node>/lib/cli.js —— 该文件不存在（npm 真实入口在 <node>/lib/node_modules/npm/bin/npm-cli.js）。因此 PATH 上的 npm 一执行即 MODULE_NOT_FOUND。上游 make-npm.sh / 任何 Unknown command: "..."

## 推荐方案
**方法**: 不要用 PATH 上的 npm；用 node 直接执行真实入口："" "<node>/lib/node_modules/npm/bin/npm-cli.js" <args>；或在 build 目录生成指向真实 npm-cli.js 的 npm shim 并置于 PATH 首位。配方应探测 (node, npm-cli.js) 组合（node 需支持 WebAssembly 等实际能力）。

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
head -3 <node>/bin/npm   # 应为 require('../lib/cli.js') 的 stub；"$(which node)" <node>/lib/node_modules/npm/bin/npm-cli.js --version  # 应输出版本号
```
