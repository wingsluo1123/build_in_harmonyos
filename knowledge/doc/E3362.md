# E3362: STARTTLS 原地传输升级只切换描述符而未撤销握手前事务、身份与授权状态，

## 基本信息
- **严重度**: 3
- **类别**: socket, network, runtime, testing, security
- **作者**: 4F37

## 错误特征
```
STARTTLS.*(?:success|complete).*(?:DATA|AUTH|RCPT).*(?:accepted|already authenticated)|
```

## 根因分析
长连接协议在当前进程内把明文输入输出描述符替换为 TLS 端点，

## 推荐方案
**方法**: atomic-security-boundary-reset-after-transport-upgrade

**说明**: 建立独立于普通事务 reset 的安全边界入口：先完成 TLS 描述符切换，

**修复命令**:
```
after successful STARTTLS descriptor replacement and before the next command,
```

**验证**:
```
run the installed server through a real STARTTLS descriptor transition;
```
