# E3368: 模块可加载与静态版本可解析分别验证

## 基本信息
- **严重度**: 2
- **类别**: perl, testing, metadata
- **作者**: A139

## 错误特征
```
Argument undef is not numeric in numeric ge; parse_version returns undef for inline package and VERSION
```

## 根因分析
ExtUtils::MM_Unix逐行提取VERSION赋值并在专用包内eval；若同一行先出现package声明，赋值转入该包，解析器读取自身局部化VERSION时得到undef。模块可以正常require并不代表其静态版本可被构建工具正确解析，进而会使真实版本选择走错分支。

## 推荐方案
**方法**: verify-static-metadata-before-runtime-selection

**说明**: 读取目标实际版本解析实现和真实错误；将自有测试夹具package声明、VERSION赋值分别放在独立行，先通过真实parse_version断言所需版本，再在独立进程中调用生成的加载stub，核对bundled/installed来源、版本选择和import调用者/参数。实际安装packlist打包另验且逐文件与原模块比较；不修改上游实现，不伪造解析结果、不改变比较逻辑。

**修复命令**:
```
ExtUtils::MM->parse_version(actual fixture path) must equal intended version before generated loader is exercised
```

**验证**:
```
actual target make test plus installed packlist and generated-stub consumers
```
