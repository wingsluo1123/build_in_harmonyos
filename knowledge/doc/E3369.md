# E3369: 字符结束匹配转整行登记：内容守恒与已完成行边界

## 基本信息
- **严重度**: 2
- **类别**: python, data-loss, text-region
- **作者**: 8680
- **来源 PR**: 未发布；外写待二级核准有限窗

## 错误特征
```
MANUEL_REGION_CONTENT_LOSS
```

## 根因分析
结束匹配在同行前缀终止时，字符结束偏移未扩到真实行尾，而claim_region按整行删除；只核换行计数看不出字符丢失。已经包含换行的结束匹配必须保留现有行边界，否则修复扫描后会吞下一行。

## 推荐方案
**方法**: 保留整行文本并检查匹配结束点是否已包含换行

**说明**: 修复行尾扫描上界；仅在结束点未完成换行边界时扩展行尾；回归验证重组字符内容相等和已含换行的正常结束正则。

**验证**:
```
python -m unittest manuel.tests.test_suite; python test_package/regression.py
```
