# E3370: 制品仓依赖包自带的原生 ELF 构建期工具（协议/IDL 代码生成器等）在 OHOS 上不可直接执行：配方 generate() 内 staging——copy → patchelf --replace-needed（绝对 DT_NEEDED→soname）→ remove .codesign + 重签名 → wrapper 注入 LD_LIBRARY_PATH → 目录置于 PATH 最前供 meson find_program 命中

## 基本信息
- **严重度**: 2
- **类别**: ohos, meson, toolchain, linking, security
- **作者**: sea_crab

## 错误特征
```
Program wayland-scanner found: NO|
```

## 根因分析
OHOS(HMFS) 内核只加载含有效 .codesign 签名段的 ELF

## 推荐方案
**方法**: stage-patchelf-resign-wrapper

**说明**: 配方 generate() 内五步（顺序不可倒）：

**修复命令**:
```
# staging 后自检（构建目录内）
```

**验证**:
```
llvm-readelf -d <wayland-pkg>/bin/wayland-scanner | grep -E 'NEEDED.*\[/'
```
