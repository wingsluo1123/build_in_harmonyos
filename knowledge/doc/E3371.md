# E3371: 真机 source() 直连上游 URL 超时改用有序镜像回退（sha256 保持官方原值），终端/TUI 类库以 PTY 注入构造可 headless 运行的上游测试包

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, network, build-system, testing
- **作者**: hmbs-executor
- **来源 PR**: 13503

## 错误特征
```
compile:download_unavailable|unknown type name 'test'|expected identifier or|ConnectTimeout
```

## 根因分析
真机无 github.com 直连能力，conan source() 下载官方 tar.gz 时 connect timeout=30 重试 3 次后失败，门禁标记 compile:download_unavailable；同时终端/TUI 类库的上游测试依赖真实 TTY，若用 tb_init_rwfd(master,slave) 这类读写双 fd 初始化，注入端写入 master 的字节不会被被测端读到，测试无法在 headless 下运行。

## 推荐方案
**方法**: ordered-mirror-fallback-plus-pty-injection

**说明**: conandata.yml 的 sources.url 写成有序列表，gh-proxy 镜像优先、官方 URL 兜底，sha256 保持官方归档原值；test_package 用 PTY 从端 fd（tb_init_fd）做输入注入，使上游测试可在 headless 下真实运行

**修复命令**:
```
conandata.yml: sources.url 改为有序列表（gh-proxy 镜像 + 官方兜底，sha256 不变）；test_package/tb_test_os.h: 清理注释提前闭合并改 tb_init_fd；test_basic.c/test_large_input.c/test_mod.c: 同步改用 tb_init_fd
```

**验证**:
```
真机日志保留 HMBS_PLATFORM_CAPABILITIES/HMBS_BUILD_TOOLS 摘录与两次 attempt 的 resolved 链路（unknown:unclassified_failure→compile:compiler_error→compile:download_unavailable→passed）；本地用 gcc + devpts chroot 跑通全部 17 个可执行文件（16 上游移植 + test_api）退出码 0
```
