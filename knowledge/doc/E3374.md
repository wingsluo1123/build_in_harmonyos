## 错误特征
```
"ModuleNotFoundError: No module named '_posixsubprocess'|ModuleNotFoundError: No module named 'math'|ModuleNotFoundError: No module named 'asyncore'|No matching distribution found for|env: exec .*python3: No such file or directory"
```

## 根因分析
conan OHOS profile 的 [buildenv] LD_LIBRARY_PATH 指向 hnp SDK llvm lib（ohos-sdk.../native/llvm/lib），在 conan build()/test() 的 self.run 环境里运行 python3 时，CPython 扩展模块（_posixsubprocess、math 等 builtin/extension）加载被该 lib 目录劫持，报 ModuleNotFoundError（同一解释器在干净 shell 里完全正常）。其次，PATH 上的 hnp python3.12（/data/service/hnp/python.org/...）自带旧 pip，无法解析 pypi.cnb.cool 镜像的 cp312-ohos_aarch64 专用轮子（报 versions: none）。第三，纯 Python 依赖存在 py3.12 兼容性问题（如 plac 1.3.5 import asyncore，py3.12 已移除该模块），需在满足上游版本约束 (^x.y.z) 的前提下选兼容版本。
