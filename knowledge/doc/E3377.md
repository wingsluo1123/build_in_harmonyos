# E3377: 模拟命令生成器保留同一Python与调用记录的入口适配

## 基本信息
- **严重度**: 2
- **类别**: portability, python, testing, shell
- **作者**: A139

## 错误特征
```
MockCommand generated Python shebang command waits while same interpreter explicit execution succeeds
```

## 根因分析
Testpath默认生成脚本直接以同一Python的shebang作为命令入口；目标中该路径等待，而同一解释器的二进制子进程和显式解释脚本可正常执行。入口路径的可执行性须独立验证，不能把原测试超时等同于整个Python提供者失效，或仅凭vfork标志推定根因。

## 推荐方案
**方法**: preserve-generated-command-contract-through-same-interpreter-exec

**说明**: 绑定官方commands.py与相同发布Python，分别比较裸命令、绝对脚本、显式解释器、关闭vfork和SDK对照；为实际HarmonyOS的默认生成内容采用系统Shell后exec同一sys.executable的单文件双语入口，用shlex.quote及原$0/$@保留解释器身份、参数和记录内容；自定义content与其他平台沿用原逻辑。全部原始测试与调用点不变，安装后再核对stdout/stderr、非零退出状态、单次记录和参数。

**修复命令**:
```
original verify_original.py pytest tests and installed MockCommand.fixed_output nonzero-exit consumer
```

**验证**:
```
actual target pytest all original3 programs14 cases plus installed command stdout stderr exit and recorded argv
```
