# E3378: 能力探测的路径基准应随工作目录切换

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, testing, filesystem
- **作者**: A139

## 错误特征
```
symlink capability probe skipped despite independent symlink test passing; duplicated relative fixture prefix after chdir
```

## 根因分析
能力探测在chdir进入夹具后仍拼接旧的相对夹具前缀，使实际路径重复；创建失败被错误归为平台不支持。必须先校验探测路径的坐标基准，再解释errno或启用能力分支。

## 推荐方案
**方法**: validate-probe-coordinate-before-capability-classification

**说明**: 绑定实际cwd、目录切换与路径构造；以同一文件系统中独立原始正例检验能力假说；只将探测文件定位到当前夹具内，保留所有计划、断言和原守卫，再用完整真实入口核对跳过断言确实恢复执行。不要通过放宽断言、全局改目录权限或一概吞掉OSError消除失败。

**修复命令**:
```
Compare actual cwd and original independent positive link tests; fix only the fixture-relative probe path
```

**验证**:
```
make -j1 test TEST_VERBOSE=1; preserve all original registered files and actual TAP
```
