# E3379: 扩展 MRT 时间前缀必须在真实载荷层消费一次

## 基本信息
- **严重度**: 2
- **类别**: network
- **作者**: 78B3

## 错误特征
```
self.mrt.micro_ts = self.val_num(4)
```

## 根因分析
mrtparse 1.6 BGP4MP_ET uses Reader.val_num(4) while Reader.buf is None; feeding the unsliced prefix to Bgp4Mp also misaligns AS/IP/BGP decoding.

## 推荐方案
**方法**: consume-et-prefix-at-payload-owner

**说明**: Validate payload length >=4, decode micro_ts with struct.unpack(>I,data[:4]), and pass only data[4:] to Bgp4Mp; retain raw Mrt.buf and Type16 behavior.

**修复命令**:
```
apply_conandata_patches(self)
```
