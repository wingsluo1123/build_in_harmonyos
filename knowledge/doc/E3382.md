# E3382: 制品仓依赖 recipe revision 漂移: 已发布 libhinawa/4.0.2 改用 glib2/2.88.0 (zlib/1.3.1), 与 libhinoko 直接依赖的 glib/2.84.0.2 (zlib/1.3.1.1) 双 glib 系同图冲突, 本地旧缓存 recipe 掩盖 → 本地过 CI 挂

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, conan, dependency, version
- **作者**: 856F
- **来源 PR**: 14435

## 错误特征
```
Version conflict: Conflict between zlib/1\.3\.1 and zlib/1\.3\.1\.1 in the graph|Conflict originates from glib2/2\.88\.0
```

## 根因分析
libhinoko/1.0.3 配方 requirements() 直接声明 self.requires("glib/2.84.0.2", transitive_headers=True, transitive_libs=True) (用于 gobject-2.0 头/库 + glib-genmarshal/mkenums 工具) 与 self.requires("libhinawa/4.0.2", transitive_headers=True, transitive_libs=True)。构建 #90910 时 ohpcd 制品仓的 libhinawa/4.0.2 recipe 已被更新为 revision 1231852695264209158e5d43444262ee (2026-10-14 01:19:54 UTC 发布), 其 requirements() 改为 self.requires("glib2/2.88.0", transitive_headers=True) — 即 libhinawa 已完成 glib→glib2 迁移。glib2/2.88.0 配方 requires zlib/1.3.1, glib/2.84.0.2 配方 requires zlib/1.3.1.1; 两个不同 glib 系包同入依赖图, 各自对 zlib pin 不同精确版本 → conan 2 图解析期硬冲突 (不自动择优)。本地缓存里的 libhinawa/4.0.2 仍是旧 recipe revision d00a6765ba368e28ae83339d4f5c0f57 (依赖 glib/2.84.0.2, 无 glib2), 故本地 conan create 依赖图只有 glib/2.84.0.2→zlib/1.3.1.1 单 glib 系, 无冲突 → 本地过、PR 挂。根因是"制品仓已发布 recipe revision 与本地缓存漂移" (上游依赖包完成 glib→glib2 迁移), 而非配方自身 bug。

## 推荐方案
**方法**: align-direct-glib-dep-with-published-dependency

**说明**: 当 CI 报 "Version conflict between zlib/1.3.1 and zlib/1.3.1.1, originates from glib2/2.88.0" 且本地同配方 conan create 通过时: ① 下载制品仓版本核对 recipe revision (conan download libhinawa/4.0.2 -r=ohpcd --only-recipe, 对比本地 cache path 的 manifest) 确认是漂移而非本地配方问题; ② 把本配方对 glib 的直接依赖从 glib/2.84.0.2 切换为 glib2/2.88.0 (与制品仓已发布依赖包的依赖一致; main 生态 74 个配方已用 glib2/2.88.0 vs 8 个用 glib/2.84.0.2, glib2 是主流); ③ 同步更新配方内所有 self.dependencies["glib"] 引用为 ["glib2"] (generate() 里 gobject-2.0.pc wrapper、glib-2.0.pc 追加 glib_genmarshal/glib_mkenums 变量、PATH/LIBRARY_PATH 注入等), glib2/2.88.0 的 bin/ 亦含这些工具 (E348/gssdp 先例); ④ 用临时干净 CONAN_HOME 复现 CI 图确认无冲突后推送 + /rebuild。

**修复命令**:
```
conan download "libhinawa/4.0.2" -r=ohpcd --only-recipe && conan cache path libhinawa/4.0.2  # 对比 revision; 配方里 requires("glib/2.84.0.2") → requires("glib2/2.88.0"), 全部 dependencies["glib"] → dependencies["glib2"], 再 conan graph info 验证无 Conflict
```

**验证**:
```
cd archives/l/libhinoko/1.0.3 && conan graph info . -pr=ohos-aarch64 -pr:b=... ; conan download "libhinawa/4.0.2" -r=ohpcd --only-recipe (对比本地 conan cache path libhinawa/4.0.2 的 recipe revision)
```
