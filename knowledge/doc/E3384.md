# E3384: 跨包精确钉版冲突的依赖侧解法：为冲突方递增一个“只改钉版”的版本，而不是用 override 逼已发布依赖源码重建

## 基本信息
- **严重度**: 2
- **类别**: ohos, cross-compile, package-version-lines
- **作者**: unknown

## 错误特征
```
Version conflict: Conflict between [a-z0-9._+-]+/[0-9][^ ]* and [a-z0-9._+-]+/[0-9][^ ]* in the graph
```

## 根因分析
两条已发布依赖对**同一传递依赖**钉了不同的精确版本时，消费者图直接报 Version conflict，例如本轮：

## 推荐方案
**方法**: increment-conflicting-package-with-pin-only-change

**说明**: ①先查两边钉版是否存在**已发布的第三版本**可同时满足（零重建最优）；

**修复命令**:
```
'conan create archives/p/pango/1.50.14.1.1.2 -pr:h=ci/conan/profiles/ohos-aarch64 --build=missing && conan create archives/g/gdk-pixbuf/2.44.6.1.1.1 … && conan create archives/g/gtk2/2.24.33.1 …'
```

**验证**:
```
conan graph info <probe>.py -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 2>&1 | grep -E "Version conflict"
```
