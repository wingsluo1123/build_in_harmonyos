# E3386: conan test_package（test_type="explicit"）的构建目录就是归档 test_package/：KF/Qt 应用把 HOME 指向它会写 .local/state/*staterc，污染归档树——必须把 HOME/XDG_* 指向源码树外

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, testing, environment
- **作者**: DRAFT

## 错误特征
```
test_package/\.local/state/.*staterc|
```

## 根因分析
conan 对 `test_type = "explicit"` 且未定义 layout 的 test_package，

## 推荐方案
**方法**: isolate-home-xdg-outside-source-tree

**说明**: test_package 里把 HOME 与全部 XDG_* 指向**源码树外**的固定目录

**修复命令**:
```
runtime_home = os.path.join(os.environ.get("TMPDIR", tempfile.gettempdir()),
```

**验证**:
```
cd archives/k/kcharselect/26.04.0/test_package && ls -a | grep -F .local
```
