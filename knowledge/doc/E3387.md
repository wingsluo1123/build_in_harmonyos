# E3387: Conan 配方设置 CMAKE_BUILD_RPATH/CMAKE_INSTALL_RPATH 并不保证产物带 RPATH：依赖以绝对路径入链时链接行无 -rpath，安装期 CMake 只在"已有 RPATH"时改写 → 产物 .dynamic 无 RPATH，运行期必须走 Conan runenv

## 基本信息
- **严重度**: 2
- **类别**: cmake, linking, conan, dependency, runtime
- **作者**: DRAFT

## 错误特征
```
cannot open shared object file: No such file or directory|
```

## 根因分析
(1) CMake 的安装期 RPATH 处理是 `file(RPATH_CHANGE OLD_RPATH NEW_RPATH)`

## 推荐方案
**方法**: measure-rpath-then-rely-on-conan-runenv

**说明**: 先实测产物是否有 RPATH（readelf -d），再用实测结论写文档/断言；

**修复命令**:
```
readelf -d "$(conan cache path $PKG/$VER:$PKGID)/bin/$APP" | grep -E 'RPATH|RUNPATH' || echo "NO RPATH in artifact"
```

**验证**:
```
grep -c rpath <build>/CMakeFiles/<target>.dir/link.txt
```
