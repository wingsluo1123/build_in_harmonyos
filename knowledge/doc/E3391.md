# E3391: 必需checkpoint header前的EOF必须传播为错误，并保留fscanf遗留LF消费合同

## 基本信息
- **严重度**: 2
- **类别**: runtime, testing, filesystem, api
- **作者**: 1306

## 错误特征
```
Could not read required checkpoint header.
```

## 根因分析
skip_line只等待LF且不检查EOF或读错，空/截断checkpoint进入无限循环；普通skip-line替换会在fscanf遗留LF处过早返回，下一次数值读取撞到header。

## 推荐方案
**方法**: reject-required-checkpoint-eof-preserve-fscanf-header-contract

**说明**: 初次fgetc及找LF循环都检查EOF并沿原terminate非0退出；两个reader只增加fscanf成功字段数为1的检查，保留消费顺序和合法末数值后EOF。

**修复命令**:
```
在固定原源仅修改solvate.c，使用官方refresh-patch生成交付补丁，再通过实际Conan包运行原发行命令与checkpoint回归。
```

**验证**:
```
python3 archives/s/solvate/1.0/test_package/verify_checkpoint.py --binary "$SOLVATE_PACKAGE_ROOT/bin/solvate" --data "$SOLVATE_PACKAGE_ROOT/share/solvate" --output "$SOLVATE_TEST_OUTPUT" --environment OHOS-native
```
