# E3393: Embedded OpenSSL requires both ELF symbol isolation and fork-time key ownership

## 基本信息
- **严重度**: 3
- **类别**: portability, threading, linking
- **作者**: TL60

## 错误特征
```
SSL_CTX.*[Ff]ail|qm_free.*bad pointer|FOREIGN_STATE.*preserved=0
```

## 根因分析
Function-only binding leaves archive data preemptible; a numeric pthread-key cleanup range also clears unrelated libraries after fork even when symbols are local.

## 推荐方案
**方法**: archive-symbol-locality-and-owned-key-detachment

**说明**: First prove archives are PIC; hide only libssl.a/libcrypto.a symbols while preserving plugin ABI, wrap linked key create/delete references, track opaque key ownership, detach only live owned values in a synchronized atfork handler.

**修复命令**:
```
Use the documented TLSA Makefile/key-ownership patches, then run the real-core consumer with normal, preinitialized peer and 64 earlier-key cases.
```

**验证**:
```
conan create archives/k/kamailio-tlsa/6.0.6 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
