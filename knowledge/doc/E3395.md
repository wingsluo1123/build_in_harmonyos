# E3395: 原生生成词法提示与实际Perl运行时绑定

## 基本信息
- **严重度**: 2
- **类别**: configure, perl, testing
- **作者**: A139

## 错误特征
```
generated lexical hints must match the actual target Perl runtime
```

## 根因分析
sense.pm.PL在活动Perl中捕获$^H、WARNING_BITS及%^H并写出import实现，归档本身不含sense.pm。安装模块必须绑定实际目标生成器输出和架构安装根，不能与不存在的上游模块文件比较，也不能用异构主机预生成字节替代。

## 推荐方案
**方法**: bind-native-generator-output-and-installed-lexical-behavior

**说明**: 使用已发布的匹配目标Perl执行原MakeMaker及生成器；保持原生成器和2个源测试字节，记录生成器/实际生成文件/安装文件三方SHA256；执行真实安装模块消费者，验证strict-subs负例、UTF8和state正例，再在数字UID自有Harmony目录中验证实际Unicode文件与清理。

**修复命令**:
```
make -j1 test TEST_VERBOSE=1
```

**验证**:
```
make -j1 test TEST_VERBOSE=1
```
