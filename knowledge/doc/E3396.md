# E3396: 持久字节流一次正数短读不是完整应用消息，客户端必须按终止符或

## 基本信息
- **严重度**: 2
- **类别**: socket, network, runtime, testing, api
- **作者**: 58E6

## 错误特征
```
(?:SCPI|RAW|TCP).*(?:response|reply).*(?:truncated|partial|incomplete)|
```

## 根因分析
字节接收 API 只保证返回当前已取得的正数字节数，不保证一次调用

## 推荐方案
**方法**: protocol-boundary-stream-framing

**说明**: 将应用消息完成条件与单次 read/recv 返回解耦。文本响应持续累积至

**修复命令**:
```
implement an incremental framing state machine for terminator or declared
```
