# E3398: set-temp-env-var-writable-dir

## 基本信息
- **严重度**: 2
- **类别**: environment, framework, test
- **作者**: tianyi_wang <pc2-44>
- **来源 PR**: 13551

## 错误特征
```
Unable to create temporary file for communication|check_msg\.c:317|/tmp.*read-only|mkstemp.*Read-only file system
```

## 根因分析
Check 0.15.2 open_tmp_file()(HAVE_MKSTEMP 分支)按固定顺序选择 IPC 临时目录:

## 推荐方案
**方法**: set-temp-env-var-writable-dir

**说明**: 设置 TEMP 环境变量(优先级最高)指向实测可写目录后运行 make check；

**修复命令**:
```
mkdir -p $HOME/tmp && TEMP=$HOME/tmp make check
```

**验证**:
```
env -u TEMP -u TMPDIR ./minrepro（无 TEMP→errno=30 exit 2；仅 TMPDIR→errno=30 exit 2；TEMP=可写→exit 0）; TEMP=$HOME/tmp make check（8/8 PASS exit 0）
```
