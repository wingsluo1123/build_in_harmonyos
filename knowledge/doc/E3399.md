# E3399: GraphBase CWEB generation with long Conan paths

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system
- **作者**: A103

## 错误特征
```
Filename too long|ctangle failed for gb_flip
```

## 根因分析
ctangle has bounded filename buffers; long Conan cache input and output paths exceed them. GraphBase masters must remain unmodified under the upstream license.

## 推荐方案
**方法**: Use short relative filenames in a private generated directory and preserve upstream change files

**说明**: Copy original CWEB modules and upstream PROTOTYPES unchanged into a private input directory. Run ctangle with short relative input/change/output names; retain all official tests and exact golden comparisons.

**修复命令**:
```
ctangle input/gb_flip.w input/PROTOTYPES/gb_flip.ch sgb_gb_flip.c
```

**验证**:
```
conan create archives/s/sgb/20210202 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing
```
