# E3403: 原测试收集器的同名源码漂移与真实输出验收

## 基本信息
- **严重度**: 3
- **类别**: perl, testing, source-provenance
- **作者**: A139

## 错误特征
```
unchanged test filenames and TAP counts accept stale output for mutated source bytes
```

## 根因分析
原收集器只比较文件名、TAP计划和断言数，未在消费结果前比较实际测试文件与官方归档逐文件哈希，因此同名源码漂移仍可接受旧真实输出。

## 推荐方案
**方法**: bind-consumed-test-bytes-before-accepting-real-output

**说明**: 对原测试收集器增加实际消费文件的逐文件SHA256锁；在六个文件名和43条原断言均不改变的受控副本中，复用本次真实原生日志，对照证明旧收集器接受源码漂移而新收集器拒绝。保留原测试和IO::String1.08实现；两次正式create各原6程序43断言、C3/H1。发布元数据规范化沿用已有知识，不冒充新的解析器根因。

**修复命令**:
```
compare exact actual test path set and each official member SHA256 before accepting TAP; reject same-name source mutation with unchanged real stdout
```

**验证**:
```
make -j1 test TEST_VERBOSE=1; independent real-output old/new collector control
```
