# E3407: 固定宽度样本流的读取边界不是记录边界：跨 read() 保存残余字节

## 基本信息
- **严重度**: 2
- **类别**: portability, runtime, testing, io, multimedia
- **作者**: 6F91
- **来源 PR**: https://gitcode.com/OpenHarmonyPCDeveloper/build_in_harmonyos/merge_requests/16165

## 错误特征
```
noninteger number of samples read|truncated 16-bit sample|fragmented pipe changed the decoded sequence
```

## 根因分析
流式 read() 只保证返回当前可用字节数，不保证停在 16 位样本或其他固定宽度

## 推荐方案
**方法**: carry-incomplete-record-across-reads

**说明**: 读取到字节缓冲；只把 floor(total/record_width)*record_width 个字节交给解析器，

**修复命令**:
```
preserve total % record_width bytes before the next read and compare regular-file and fragmented-stream outputs
```

**验证**:
```
conan create archives/m/multimon/1.0 -pr:h=ci/conan/profiles/ohos-aarch64
```
