# E3408: "conan 制品仓提供的构建期 ELF 工具在 OHOS 构建机上双向不可执行：①未签名 ⇒ 执行报 EPERM（Operation not permitted，rc=126）；②binary-sign-tool sign -selfSign 1 自签后越过 EPERM，却因 NEEDED 里记录的是构建机的 Conan 缓存绝对路径（不是 soname）而 dlopen 失败、加 LD_LIBRARY_PATH 也无效 ⇒ 唯一稳定处方是从上游源码静态重建该工具，并把工具路径写进一份 .pc 顶到 PKG_CONFIG_PATH 最前"

## 基本信息
- **严重度**: "2"
- **类别**: build-system, autotools, linking, cross-compile, conan
- **作者**: "主理-5 <主理-5@local>"
- **来源 PR**: "(本 PR)"

## 错误特征
```
"Operation not permitted|/bin/sh: [0-9]+: .*/bin/wayland-scanner: Operation not permitted|Error loading shared library /.*conan2?/p/[^ ]*\\.so|Error relocating .*?: .*symbol not found|cannot execute binary file|wayland-scanner: not found"
```

## 根因分析
"两条独立的平台约束叠加。①OHOS 对可执行 ELF 有签名闸：制品仓里由别的构建机产出的二进制没有本机认可的签名 ⇒ 内核/加载器直接 EPERM（这不是文件权限，chmod 无效、换目录无效）。②制品的 DT_NEEDED 里存的是**构建期**Conan 缓存中的依赖绝对路径（`/…/.cache/conan2/p/expat<hash>/p/lib/libexpat.so` 一类），而非 soname；该路径在本机不存在，且因为不是 soname，LD_LIBRARY_PATH/ld.so.conf 都无处插入 ⇒ 即使签了名也无法加载。两者叠加 ⇒ 该工具在本机**没有可用路径**。"

## 推荐方案
**方法**: "static-rebuild-buildtime-tool-and-prepend-its-pc"

**说明**: "在配方的 build() 里、早于 configure 之前，从上游同版本源码手工命令行静态编译该生成器（只编 scanner.c + wayland-util.c 这类真正需要的翻译单元，第三方依赖取宿主 SDK 的静态库；版本头由 *.h.in 模板手工替换），产出放到 build_folder/<tool>-bin/；同时写一份同名 .pc（写入工具变量，如 wayland_scanner=${bindir}/<tool>）到 generators_folder/fixed_pkgconfig/，并在 AutotoolsToolchain 的 env 里 prepend_path('PKG_CONFIG_PATH', 该目录)。meson 消费方（find_program(dependency('wayland-scanner').get_variable(pkgconfig:'wayland_scanner'))）同款可用（lavalauncher/2.1.1 先例）。⛔ 不要用 stub/空实现糊过去，也不要直接改制品仓包。"

**修复命令**:
```
"见 archives/g/gammastep/2.0.9/conanfile.py 的 _build_static_scanner() + _write_scanner_pc() + generate() 第 (4) 步；meson 版见 archives/l/lavalauncher/2.1.1/conanfile.py 的 _build_static_scanner()"
```

**验证**:
```
"现场三步：printf 'int main(void){return 0;}\\n' > t.c && clang t.c -o t && ./t; echo rc=$?（对照，应 0）；<工具> --version; echo rc=$?（未签名，应 126 + Operation not permitted）；cp <工具> u && chmod +x u && binary-sign-tool sign -inFile u -outFile s -selfSign 1 && ./s --version（应报 Error loading shared library <绝对路径> / Error relocating）；再 LD_LIBRARY_PATH=<真实 libdir> ./s --version（若仍报同一绝对路径 ⇒ NEEDED 非 soname、动态不可救）；重建后：<自编译工具> --version 应正常输出，且 configure 日志里 PKG_CHECK_VAR 解析到的路径指向自编译目录。"
```
