# E3410: 串行harness老automake无test-suite.log时落盘逐行计数替代新式汇总

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, autotools, testing
- **作者**: hmbs-executor
- **来源 PR**: 15241

## 错误特征
```
test-suite\.log not found; searched:|install-man3.*Error 64|PASS: errorcheck
```

## 根因分析
xdffileio 0.3为2012年生成的serial-harness Makefile，make check只逐TEST打印PASS:/FAIL:行而不写test-suite.log，配方只认新式汇总块而错配抛错；同包doc/install-man3多源一次调用设备install装23个手册页返回EX_USAGE64，属同族老autotools形态问题

## 推荐方案
**方法**: serial-log-file-line-count

**说明**: POSIX可移植重定向落盘upstream-check.log并回显保留预检日志，单正则逐行匹配PASS/FAIL/XFAIL/XPASS/SKIP/ERROR并做恒等式自检；test-suite.log存在仍优先用它，不存在且串行日志一致才用串行计数

**修复命令**:
```
conanfile.py: 新增_parse_serial_check_log与落盘upstream-check.log的_run_upstream_tests分支；MANIFEST.yml/notes.md: 记录串行口径与6个TESTS来源
```

**验证**:
```
真机make check打印PASS行且upstream-check.log落盘计数total=6 passed=6，test-suite.log存在时仍优先使用它，0行匹配时如实失败并列出搜索路径
```
