# E3415: OHOS /etc/hosts has no '::1 localhost' alias: restore dual-stack loopback at the resolver layer

## 基本信息
- **严重度**: 2
- **类别**: platform, ipv6, quirk, resolver, test-harness
- **作者**: 6CE6

## 错误特征
```
"Resolving IPv6 host: localhost failed|Name does not resolve|\[Errno -2\]|getaddrinfo.*AF_INET6.*localhost"
```

## 根因分析
The OHOS runtime /etc/hosts maps only '127.0.0.1 localhost' and '::1 ip6-localhost ip6-loopback'; there is no '::1 localhost' alias, so socket.getaddrinfo('localhost', p, AF_INET6) raises gaierror even though the literal '::1' resolves, binds and connects normally. Upstream pwncat's own GitHub CI works around this by rewriting /etc/hosts (sudo tee with '::1 localhost ip6-localhost ip6-loopback'); /etc is a symlink to a read-only backing file on OHOS and there is no sudo/unshare, so that workaround cannot be reproduced.

## 推荐方案
**方法**: resolver-layer-ipv6-localhost-alias-shim

**说明**: Do not modify the package source. Inject a sitecustomize.py via PYTHONPATH (test scaffolding only) that wraps socket.getaddrinfo: on gaierror with host in {localhost, localhost.localdomain}, retry with the alias the hosts file already provides (ip6-localhost -> ::1) and then with the literal ::1, and re-raise otherwise. Critically, skip the fallback when flags & AI_NUMERICHOST so --no-dns semantics are preserved (a numeric-only lookup must still fail for a hostname).

**修复命令**:
```
PYTHONPATH=<shim-dir> python3 -m py_compile <shim-dir>/sitecustomize.py && PYTHONPATH=<shim-dir> python3 -c "import socket;print(socket.getaddrinfo('localhost',4444,socket.AF_INET6)[0][4])"
```

**验证**:
```
python3 -c "import socket; print(socket.getaddrinfo('localhost',4444,socket.AF_INET6,socket.SOCK_STREAM))"  # gaierror without the shim, ('::1',4444,0,0) with it
```
