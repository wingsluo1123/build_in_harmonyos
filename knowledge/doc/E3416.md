# E3416: config.guess 运行期 umask 077 临时目录在 HMDFS 下不可写

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, autotools, filesystem
- **作者**: M1R0

## 错误特征
```
config.guess 运行期报 can't create $TMPDIR/cgXXXXXX/dummy.c: Permission denied，随后 unable to guess system type
```

## 根因分析
E114/E110 的 HMDFS 权限归一化不只影响 configure 生成的 config.status，config.guess 运行期自身也用 (umask 077 && mktemp -d "$TMPDIR/cgXXXXXX") 建临时目录再写 dummy.c；0700 目录属主被归一化为其他 uid 后本进程无写权限

## 推荐方案
**方法**: 与 E114 同口径：把 config.guess 中三处 umask 077 去掉（三行 fallback 链都要改），再自测 sh admin/config.guess 能输出三元组

**说明**: 去掉 config.guess 里所有 `(umask 077 && mktemp -d ...)` 的 umask 077（改为 umask 022 或直接用默认 umask），使它在 HMDFS 上也能自建可写探测目录

**修复命令**:
```
sed/grep 定位：`grep -n "umask 077" admin/config.guess`；三处 fallback 链（mktemp -d 的每个候选路径分支）都需改
```

**验证**:
```
cd <源码根> && sh admin/config.guess 2>&1 | tail -5（命中时先报 can't create $TMPDIR/cgXXXXXX/dummy.c: Permission denied，再报 unable to guess system type）；对照 ls -ld $TMPDIR/cg* 2>/dev/null | grep "drwx--S---"
```
