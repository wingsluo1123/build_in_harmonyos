# E3421: conan 反激活脚本切 function 形态消除共享 worker fork EAGAIN，make 加指纹门控有界重试

## 基本信息
- **严重度**: 3
- **类别**: ohos, kernel, syscall, network, build-system
- **作者**: hmbs-executor
- **来源 PR**: 16294

## 错误特征
```
ConanException: Error while running cmd|\[Errno 11\] Resource temporarily unavailable|fork: retry: Resource temporarily unavailable|somagic-init --skip-check.*rc=139
```

## 根因分析
conan 默认反激活模式（tools.env:deactivation_mode 未设）在 conanbuildenv/conanrunenv 脚本顶部逐变量 fork printenv（每次 self.run 前十余次 fork），共享 worker 的 fork/进程资源瞬时耗尽，报 Errno 11 Resource temporarily unavailable（与源码、工具链、依赖无关）；同配方上游四个程序（somagic-init/somagic-capture/somagic-both/somagic-audio-capture）在调用 libusb_init(NULL) 后忽略返回值，OHOS 沙箱 netlink/sysfs 不可用致 init 失败，随即用未初始化句柄 find_device/libusb_open 触发 SIGSEGV（exit 139 = Signal 11）

## 推荐方案
**方法**: conan-function-deactivation-plus-fork-retry

**说明**: generate()/configure() 注入 tools.env:deactivation_mode=function 消除逐变量 fork EAGAIN；build() 中 make 以 fork 指纹门控做有界退避重试（真实编译错误立即抛出）；新增 0001-guard-libusb-init-failure.patch 为四个 libusb_init(NULL) 调用点补返回值守卫（失败打印 Failed to initialize libusb 并退出）；test.sh 断言改 exit 1 且非信号；no_tests 标记与 MANIFEST 审计对齐

**修复命令**:
```
archives/s/somagic/1.1/conanfile.py 新增 generate() 注入 tools.env:deactivation_mode=function；test_package/conanfile.py 在 configure() 注入同一 conf（显式 VirtualRunEnv 早于 generate 运行）；build() 的 make 改走 _make_with_fork_retry()；新增 archives/s/somagic/1.1/patches/0001-guard-libusb-init-failure.patch 并经 export_sources()/source() 应用；test_package/test.sh 断言 exit 1 且非信号并强化临时目录探测；MANIFEST.yml 填 upstream_test_total: 0、count_method: none（计数口径不动）
```

**验证**:
```
查真机预检日志：conf 注入 tools.env:deactivation_mode=function 后反激活前导块呈 function 形态、不再逐变量 fork printenv；make 命中 fork 指纹时仅做有界退避重试且真实错误立即抛出；test_package 断言 exit 1 且非信号、临时目录探测通过；no_tests 审计与 MANIFEST（upstream_test_total: 0、count_method: none）对齐
```
