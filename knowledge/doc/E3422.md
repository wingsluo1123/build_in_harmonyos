# E3422: Qt6 qmake 工程 OHOS 构建：QMAKE_LRELEASE 显式指向 qttools 的 lrelease + host 工具运行期注入 SDK libc++_shared.so

## 基本信息
- **严重度**: 2
- **类别**: build-system, qmake, toolchain, conan, runtime
- **作者**: 7494

## 错误特征
```
No such file or directory.*lrelease|Error loading shared library libc\+\+_shared\.so|Error relocating.*_ZTISt12length_error|libc\+\+_shared\.so.*symbol not found|_ZdlPv.*not found
```

## 根因分析
qtbase 包不含 LinguistTools 工具（lrelease 由 qttools 提供），qmake 生成 Makefile 时默认取 $[$QT_INSTALL_BINS]/lrelease 不存在；qtbase/qttools 的 host 工具（qmake6/lrelease/moc）是 OHOS 本机 ELF，DT_NEEDED 含 libc++_shared.so，仅 OHOS SDK llvm/lib/aarch64-linux-ohos/ 提供

## 推荐方案
**方法**: explicit-lrelease-and-sdk-libcxx-injection

**说明**: qmake 命令行传 QMAKE_LRELEASE=<qttools>/bin/lrelease 覆盖默认路径；generate()/build()/test() 中用 Environment 把 SDK libc++ 目录与 qtbase/qttools lib 注入 LD_LIBRARY_PATH（fingerterm 同款）

**修复命令**:
```
qmake -config release QMAKE_LRELEASE=$QTT/bin/lrelease; env LD_LIBRARY_PATH=...make -j1
```

**验证**:
```
QT_QPA_PLATFORM=offscreen ./qabc --version && echo OK; conan create ... -pr:h=ohos-aarch64
```
