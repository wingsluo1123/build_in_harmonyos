# E3431: 长生命周期外部计算进程的请求必须共享单调总截止时间

## 基本信息
- **严重度**: 2
- **类别**: runtime, testing, shell, ipc, protocol
- **作者**: 6F91

## 错误特征
```
External function response exceeded the transaction deadline|helper keeps process alive without DONE|per-wait timeout is refreshed
```

## 根因分析
把进程启动、请求写入和多轮响应读取分别交给默认或固定的逐次超时，

## 推荐方案
**方法**: monotonic-transaction-deadline-and-process-discard

**说明**: 在事务入口启动单调计时器，把 remaining=deadline-now 传给启动、

**修复命令**:
```
use one monotonic deadline across start, write, frame assembly and completion, then kill and reap on failure
```

**验证**:
```
conan create archives/q/qsoas/3.3 -pr:h=ci/conan/profiles/ohos-aarch64
```
