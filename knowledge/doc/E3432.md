## 错误特征
```
"config.status: error: could not setup config files machinery|subs1.awk: Permission denied|failed to load external entity.*docbookx.dtd|install-sh.*can't execute: Permission denied|make.*Error 126"
```

## 根因分析
四个独立机制叠加：(1) /usr/bin/awk 是指向 toybox 的坏符号链接（exec 被拒），configure 把它缓存进 config.status 的 $AWK，subs1.awk 处理直接 Permission denied——E060 的 tmpfs 方案解决不了这一层；(2) 上游 `%: %.in %.txt` 生成规则是 `awk | sed > $@` 与 `sh ./$@ --help | grep | sed -e '$d' >> $@.txt` 的管道链，并行 make（-jN）下 sed 进入自读自写循环，KB 级脚本文件膨胀至 ~35GB（xdg-utils 2026-10-14 实证，10 个 sed 并行，合计 ~350GB）；(3) scripts/Makefile 的 all 目标含 html/man，xmlto 联网拉 docbookx.dtd 在沙箱不可达；(4) make install 走上游 install-sh，其复制的新建可执行文件触发 hishell_hap MAC "can't execute: Permission denied"（G17 同源）。
