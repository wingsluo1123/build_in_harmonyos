# E3434: 并行阶段吞吐必须先归约关键路径耗时，不能取最大或平均局部速率

## 基本信息
- **严重度**: 2
- **类别**: runtime, testing, filesystem, architecture
- **作者**: 2789
- **来源 PR**: 16184

## 错误特征
```
(?:rank|worker).*(?:rate|throughput).*(?:MPI_MAX|max(?:imum)?)|
```

## 根因分析
屏障协调的并行阶段在每个 rank 先用总操作数除以本地耗时，再对

## 推荐方案
**方法**: reduce-time-then-compute-rate

**说明**: 保留每个阶段的开始/结束或 elapsed，在参与同一阶段的 communicator

**修复命令**:
```
replace reduction(local_rate) with reduction(elapsed_time), then compute total_ops/max_elapsed
```

**验证**:
```
conan create archives/m/mdtest/1.9.3 -pr:h=ci/conan/profiles/ohos-aarch64
```
