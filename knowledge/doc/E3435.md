# E3435: musl 下 fd_set/FD_SETSIZE/select 需显式 #include <sys/select.h>（glibc 经 sys/types.h 传递可见）

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, libc, musl, headers
- **作者**: A7F3

## 错误特征
```
unknown type name 'fd_set'|use of undeclared identifier 'FD_SETSIZE'|call to undeclared function 'select'|use of undeclared identifier 'FD_ISSET'|incomplete type 'struct timeval'
```

## 根因分析
glibc 的 <sys/types.h>（以及 <sys/socket.h> 等）会顺带定义 fd_set / FD_SETSIZE 并声明 select()，上游代码因此长期只包含 sys/types.h 或依赖其他系统头的传递包含；musl（OHOS SDK）不再提供这层传递可见性，编译期直接报 unknown type name 'fd_set'，且 select()/FD_ISSET 退化为隐式声明（C99 起为错误）。

## 推荐方案
**方法**: source-patch

**说明**: 在缺少该头的源文件里显式 #include <sys/select.h>（POSIX 标准头，glibc/BSD/macOS 同样存在，改动零风险）

**修复命令**:
```
# 补丁示例: +#include <sys/select.h>（加在现有系统头区块内）
```

**验证**:
```
printf '#include <sys/types.h>\nint main(void){fd_set s; FD_ZERO(&s); return 0;}\n' > $TMPDIR/t.c && clang -c $TMPDIR/t.c -o /dev/null && echo GLIBC_OK || echo MUSL_NEEDS_SYS_SELECT_H
```
