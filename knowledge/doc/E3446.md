# E3446: CI 预下载以宽松正则扫描 conandata.yml 全文（含注释），注释中的裸 URL 会被当第二个源码并污染 sources.url

## 基本信息
- **严重度**: 2
- **类别**: platform, conan
- **作者**: 567A

## 错误特征
```
NotADirectoryError: .*Not a directory: .*predl_cache/.*tar\.gz
```

## 根因分析
ci/conan/build_and_test.sh 预下载以宽松正则扫描整个 conandata.yml（含注释行），对每个命中 URL 下载到 predl_cache/{hash8}_{basename} 后执行 content.replace(url, file://+local)。若注释里出现完整 URL 且它是 sources.url 的前缀，长 URL 被替换成 file://<短URL缓存路径>/<其余路径>，形成不存在的目录路径，conan get() 报 NotADirectoryError（同一配方 conan-verify G2 却通过）。

## 推荐方案
**方法**: conandata.yml 注释中不写完整 http(s) URL（写成 git.sr.ht/~gregkh/verhaal 这类无 scheme 摘要）；本地 CI 报该错而 G2 通过时优先检查注释裸 URL。

**说明**: 一句话描述这个推荐方案
