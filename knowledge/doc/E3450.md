# E3450: 上游自带手写 configure + 递归 make（非单一 autotools/CMake 工程）时在 OHOS 的 Conan 适配模式与 2.29.1 API 三坑

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, cross-compile, conan
- **作者**: unknown
- **来源 PR**: erlang 28.5.0.7 适配（路径C）

## 错误特征
```
TypeError: apply_conandata_patches\(\) got an unexpected keyword argument 'base_path'|AssertionError: env argument to ConanFile.run\(\) should be a list|AttributeError: 'Environment' object has no attribute 'apply'|neither TARGET nor OVERRIDE_TARGET can be determined
```

## 根因分析
自研构建体系把"宿主环境"假设写死在脚本里（bash、GNU 工具链、/tmp、chmod、

## 推荐方案
**方法**: manual-configure-make-with-environment-context

**说明**: 绕开 AutotoolsToolchain，手写 configure/make/make install 三连 +

**修复命令**:
```
with self._configure_env().vars(self, scope="build").apply(): self.run("./configure --prefix=<stage> --build=aarch64-unknown-linux-ohos --host=aarch64-unknown-linux-ohos"); self.run("make -jN --jobserver-style=pipe"); self.run("make install")
```

**验证**:
```
conan create archives/e/erlang/28.5.0.7 -pr:h=ci/conan/profiles/ohos-aarch64
```
