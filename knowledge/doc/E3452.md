# E3452: CMake **没有 HarmonyOS 平台文件** ⇒ `LINUX` 变量为假 ⇒ 上游 `if(LINUX)` 分支被**静默跳过**（典型后果：共享库漏链 vendored 静态库 → 库自己编得过，消费方链接才报 `--no-allow-shlib-undefined`）

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, portability, cmake, packaging
- **作者**: unknown

## 错误特征
```
System is unknown to cmake, create:\s*Platform/HarmonyOS|undefined reference due to --no-allow-shlib-undefined|Compatibility with CMake < 3\.5 has been removed
```

## 根因分析
本仓工具链的 target 是 `aarch64-unknown-linux-ohos`，但 CMake 没有

## 推荐方案
**方法**: present-platform-as-linux-and-check-consumer-link

**说明**: ① **把平台呈现为 Linux**：`tc.cache_variables["CMAKE_SYSTEM_NAME"] = "Linux"`

**修复命令**:
```
-DCMAKE_SYSTEM_NAME=Linux   # cache var
```

**验证**:
```
/data/service/hnp/bin/llvm-readelf -d <pkg>/lib/libX.so | grep NEEDED
```
