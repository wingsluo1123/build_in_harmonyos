# E3455: 上游 CMake 测试清点必须按官方枚举器（tests/test.py 递归 glob *.cmake）全量枚举；顶层 CMakeLists 默认 TEST_CMAKE_FILE_NAME 只装配 1 个入口，据此申报 N 会触发平台 rule4 少报

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, testing, reporting
- **作者**: tianyi_wang

## 错误特征
```
No tests were found|1/1 Test|0 tests failed out of 1|rule4.*少报|N=4|TEST_CMAKE_FILE_NAME
```

## 根因分析
lwgps 2.4.0 顶层 CMakeLists 用 `set(TEST_CMAKE_FILE_NAME "test_parse_sat_det/cmake.cmake")` + `add_subdirectory(tests)` 装配测试：仅默认装配 test_parse_sat_det 一个入口。而上游官方枚举器 `tests/test.py`（上游 CI build-and-test.yml 即运行 `python test.py`）递归 glob `tests/**/*.cmake`（排除 __build__）枚举出 4 个测试入口（beidou/ext_time/sat_det/standard），每个入口经 `include()` 注入独立测试源与专用 lwgps_opts.h、在 tests/CMakeLists.txt 各注册 1 项 add_test(NAME Test)。r01 只按顶层默认装配运行 ctest（1/1）申报 N=1，平台实测上游 N=4 → rule4 少报 FAIL

## 推荐方案
**方法**: census-via-official-enumerator-and-per-entry-run

**说明**: 清点上游测试必须以官方枚举器（test.py 或等价 glob）为准，不用顶层 CMakeLists 默认装配：①在未修改上游树递归枚举全部 *.cmake（或 ctest/pytest 注册）入口，逐入口列出路径/源/注册项；②对每个入口在 tests/<entry>/__build__ 用 -DTEST_CMAKE_FILE_NAME=<绝对路径> 独立 configure+build+ctest 真实运行（ctest 需在含 add_test 的子目录运行）；③按实测 N 申报并与平台 N 对账，全部入口分类为可运行且已运行/未运行/不可运行并留日志与 SHA-256

**修复命令**:
```
cmake -DCMAKE_C_COMPILER=clang -DCMAKE_CXX_COMPILER=clang++ -S../.. -G Ninja -DTEST_CMAKE_FILE_NAME=<abs>/cmake.cmake && cmake --build . && ctest . --output-on-failure -C Debug
```

**验证**:
```
cd <unmodified-upstream>/tests && python3 -c "import glob,os; files=[f for f in glob.glob(os.path.join(os.getcwd(),'**','*.cmake'),recursive=True) if '__build__' not in f]; print(len(files))"  # 官方枚举器口径 N；再对每个入口 -DTEST_CMAKE_FILE_NAME=<abs cmake.cmake> 独立 configure+build+ctest 逐项运行
```
