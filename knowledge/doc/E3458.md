# E3458: POA consensus fixture must meet upstream minimum path length

## 基本信息
- **严重度**: 2
- **类别**: testing, api
- **作者**: A103

## 错误特征
```
bundling ended prematurely after 0 bundles
```

## 根因分析
generate_lpo_bundles rejects path_length below 10; an 8-residue fixture cannot produce a consensus even for identical sequences.

## 推荐方案
**方法**: use-valid-consensus-fixture

**说明**: Use identical 12-residue sequences and retain exact consensus and graph assertions.

**修复命令**:
```
python3 scripts/ohc-run.py conan-verify poa 2.0-20060928 --profile qemu-ohos7
```

**验证**:
```
Read heaviest_bundle.c path_length<10 and run the 12-residue consumer.
```
