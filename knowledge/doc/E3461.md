# E3461: Paho OpenSSL build macro-expands the HarmonyOS sched.h free declaration

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, headers, threading
- **作者**: F7D9

## 错误特征
```
expected parameter declarator|sched.h.*free
```

## 根因分析
Paho Heap.h defines free(x) as myfree(...); when it is included before POSIX pthread headers, HarmonyOS sched.h declaration free(void *) is macro-expanded and compilation fails.

## 推荐方案
**方法**: source-patch

**说明**: Include pthread.h before Heap.h in the OpenSSL SSLSocket translation unit so HarmonyOS system declarations are parsed before allocator macros are defined.

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
Conan create with with_ssl=True using the HarmonyOS AArch64 profile; confirm both paho-mqtt3cs and paho-mqtt3as compile.
```
