# E3463: "在 conan build() 内执行上游 shell 测试脚本时：source 环境脚本用通配（source con

## 基本信息
- **严重度**: P3
- **类别**: testing
- **作者**: unknown

## 错误特征
```
"VirtualRunEnv|conanrunenv 文件名|dotest-sfx|$0 带路径|bash ./dotest-py"
```

## 根因分析
"Conan 2.29 的 conan.tools.env 在该构建导出 VirtualRunEnv（大写 E）：脚本名 conanrunenv-*.sh / deactivate_conanrunenv-*.sh。上游测试框架的 dotest-sfx 等辅助脚本用 ${0%/*} 定位同目录 lib.sh，要求 $0 带路径——以 'dotest-py'（无路径）方式调用会在定位 lib.sh 时出错。"

## 推荐方案
**方法**: "在 conan build() 内执行上游 shell 测试脚本时：source 环境脚本用通配（source conanrun*.sh 或按实际导出名 VirtualRunEnv）；调用测试入口用 'bash ./dotest-py'（带 ./）保证 $0 含路径。"
