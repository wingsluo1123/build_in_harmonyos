# E3464: "W3 上游测试执行时：fixture 路径先 `test -x` 预检；缺失时如实记录空跑（E363 边界，与 pax

## 基本信息
- **严重度**: P2
- **类别**: environment
- **作者**: unknown

## 错误特征
```
"/bin 只读|/bin/bash 不存在|fixture 缺失|空跑|E363"
```

## 根因分析
"OHOS 设备 /bin 只读且无 /bin/bash（bash 在 ~/.harmonybrew/bin/bash）；/tmp 只读。依赖 glibc 路径 fixture（如 /bin/bash）的上游测试用例会空跑：脚本对不存在的输入产生空输出，负向断言（grep 期望无某词）vacuously PASS。"

## 推荐方案
**方法**: "W3 上游测试执行时：fixture 路径先 `test -x` 预检；缺失时如实记录空跑（E363 边界，与 pax-utils/1.3.10 同类），并用修复等价探针（真实存在的 ELF 输入 + 设备 python3 + conanrunenv）验证工具本体；探针输出差异按 musl/glibc 布局差异归因。临时文件一律用工作目录（_analysis/），不用 /tmp。"
