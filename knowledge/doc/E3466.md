# E3466: "消费 python 模块类依赖时，requires() 显式写 run=True（如 self.requires(\"

## 基本信息
- **严重度**: P1
- **类别**: recipe
- **作者**: unknown

## 错误特征
```
"python-require|BINARY_SKIP|package_folder=None|runenv 不聚合|requires run=True"
```

## 根因分析
"Conan 2.29 对无 C 头/库的依赖（如 python-require 包 pyelftools）在消费方 graph 计算中，若 requires 未显式声明 run=True，会按 _skip_binaries 逻辑（files=(headers|libs|run|build) 全空）判 BINARY_SKIP：package_folder=None，runenv（PYTHONPATH 等）不聚合到下游，下游脚本 import 时找不到模块。"

## 推荐方案
**方法**: "消费 python 模块类依赖时，requires() 显式写 run=True（如 self.requires(\"pyelftools/0.33\", run=True)），并在 conanfile 注释记录原因。诊断手段：conan graph info 看该节点是否 BINARY_SKIP / package_folder 是否 None；conan install 后 conanrunenv.sh 里是否有 PYTHONPATH。"
