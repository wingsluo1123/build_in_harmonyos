# E3467: "遇到 noarch 发行包子包名（如 lddtreepax）时，先反查其上游归属（本例 gentoo/pax-util

## 基本信息
- **严重度**: P3
- **类别**: packaging
- **作者**: unknown

## 错误特征
```
"lddtreepax|lddtree.py|pax-utils python 子包|noarch"
```

## 根因分析
"lddtreepax 不是独立上游库：它是 gentoo/pax-utils 仓库中纯 Python 实现的 lddtree（lddtree.py），Alpine Linux 将其拆出重命名为 lddtreepax 的 noarch 子包。同一仓库的 C 工具（scanelf/lddtree C 版等）属于 pax-utils 子包，需由独立的 conan 配方适配。对整棵 pax-utils 树做语言预检会得到 mixed（C+Python+shell），因为整树是多工具项目——预检与配方范围必须收窄到 lddtree.py + tests/lddtree 组件。"

## 推荐方案
**方法**: "遇到 noarch 发行包子包名（如 lddtreepax）时，先反查其上游归属（本例 gentoo/pax-utils tag v1.3.9 的 lddtree.py），配方只覆盖该组件的源码/测试范围；兄弟子包另立配方（本仓已有 pax-utils/1.3.10）。语言预检按组件范围传 --lang 与 --src。"
