# E3470: CPython three-way comparison used as an equality predicate makes alias dispatch unreachable

## 基本信息
- **严重度**: 3
- **类别**: compat, portability
- **作者**: QP97

## 错误特征
```
qpack latin1 dispatch: UnicodeDecodeError
```

## 根因分析
The Python3 compatibility macro returns -1/0/1 while its OR-combined callers expect equality booleans; at least one UTF8 alias comparison is unequal, so UTF8 is always selected and Latin1 is unreachable.

## 推荐方案
**方法**: explicit-equality-predicate

**说明**: Compare the CPython API result explicitly to zero, retain the native extension, and test non-ASCII alias dispatch against independently decoded expected values.

**修复命令**:
```
Normalize PY_COMPAT_COMPARE to (PyUnicode_CompareWithASCIIString(obj, str) == 0), then rebuild the actual native package and run its unchanged suite plus the narrow alias consumer.
```

**验证**:
```
python3 -c "import importlib.machinery as m,qpack,qpack._qpack as c; assert isinstance(c.__loader__,m.ExtensionFileLoader); assert qpack.unpackb is c._unpackb; assert qpack.unpackb(bytes.fromhex('81ff'),decode='latin1') == chr(255); print('qpack latin1 native dispatch: PASS')"
```
