# E3471: 在设备原生实测到的环境结论（sys.platform=linux / chmod 0600 / AF_UNIX 可 bind）写死进测试断言，远端 CI worker 沙箱三项都不成立 → 用例红，但被测软件毫无问题

## 基本信息
- **严重度**: 2
- **类别**: ohos, python, conan, test-design
- **作者**: A14E

## 错误特征
```
AssertionError: False is not true|sys\.platform\.startswith|chmod 0600 produced 0o640|PermissionError: \[Errno 1\] Operation not permitted|socket\.socket\.bind|AF_UNIX
```

## 根因分析
**把"本机实测"当成"跨沙箱不变量"**。设备原生与 CI worker 是两套不同的运行时/文件系统，

## 推荐方案
**方法**: runtime-capability-probe-and-property-assertions

**说明**: ①平台前提改锁软件真实依赖的那一项（`os.name`），并用静态断言证明包内不读 `sys.platform`；取值只进失败信息

**修复命令**:
```
if not probe_af_unix_bindable(): raise unittest.SkipTest(f"no AF_UNIX bind in this sandbox: {errno}")
```

**验证**:
```
python3 -c "import os,sys,socket;print(sys.platform, os.name); s=socket.socket(socket.AF_UNIX);s.bind('$HOME/probe.sock')"   # CI worker 期望 EPERM
```
