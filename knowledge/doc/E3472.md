# E3472: 手工铺 .dist-info 时目录名保留连字符（PEP-503 风格）导致 importlib.metadata 查不到分发；以及 vendored 上游包连带其 testutils 写死 /tmp，在 OHOS 只读 /tmp 上首次调用即崩

## 基本信息
- **严重度**: 3
- **类别**: hmdfs, ohos, python, conan, packaging
- **作者**: E420

## 错误特征
```
PackageNotFoundError: No package metadata was found for|importlib.metadata|OSError: \[Errno 30\] Read-only file system: '/tmp|RuntimeError: The application has not been initialized|click\.version_option
```

## 根因分析
①**元数据目录名口径**。`importlib.metadata` 找分发元数据时按 **PEP-427** 规则拼目录名：

## 推荐方案
**方法**: normalize-dist-info-dirname-and-prune-test-assets

**说明**: 自建 dist-info 时目录名用 `dist.replace('-', '_')`（METADATA 内 Name: 保留原名）；vendor 时 copytree 用 ignore_patterns 剪掉测试资产与自带 egg-info/dist-info

**修复命令**:
```
info = os.path.join(site, f"{dist.replace('-', '_')}-{version}.dist-info")
```

**验证**:
```
python3 -c "from importlib.metadata import version; print(version('click-option-group'))"   # 归一化前 PackageNotFoundError，归一化后 0.5.9
```
