# E3473: 纯 Python Conan 包的依赖闭包漏标 run=True 时，传递依赖被 Conan 归为 "Skipped binaries"，对下游 package_info() 完全不可见，消费端 import 直接崩溃

## 基本信息
- **严重度**: 3
- **类别**: compat, portability, python, conan, runtime
- **作者**: A14E

## 错误特征
```
ModuleNotFoundError: No module named 'chardet'|ModuleNotFoundError: No module named 'urllib3'|ModuleNotFoundError: No module named 'idna'|ModuleNotFoundError: No module named 'certifi'|Skipped binaries|ERROR: synadm/.*: Error in package_info\(\)
```

## 根因分析
Conan 2 的 `ConanFileDependencies.host` 属性按 `{"build": False, "test": False, "skip": False}` 过滤依赖。

## 推荐方案
**方法**: declare-import-closure-run-true-and-walk-host-deps

**说明**: 把被测包的完整**导入闭包**逐项声明为 `self.requires(<ref>, run=True)`（含被 skip 的传递依赖），并在 package_info() 遍历 `self.dependencies.host.values()` 收集各依赖的可导入根，逆序 prepend 进 buildenv_info/runenv_info 的 PYTHONPATH

**修复命令**:
```
self.requires("certifi/2026.7.22", run=True)  # 对 chardet/idna/urllib3 同理
```

**验证**:
```
conan install --requires=synadm/0.49.2 -r=ohpcd --build=missing 2>&1 | grep -A5 "Skipped binaries"；
```
