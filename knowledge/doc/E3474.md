# E3474: Conan 配方的项目级测试临时目录应限定到当前 build_folder

## 基本信息
- **严重度**: 2
- **类别**: build-system, conan, testing, environment, filesystem
- **作者**: iKalous_OscarP
- **来源 PR**: 15713

## 错误特征
```
CASCADE_TMP_DIR.*Permission denied|CASCADE_TMP_DIR.*Read-only file system|fixed.*device.*tmp.*path
```

## 根因分析
项目专用测试环境变量若指向设备上的固定任务路径，会脱离当前 Conan build 的生命周期，可能复用旧文件或与共享设备上的其他构建碰撞；标准 TMPDIR 也不能覆盖上游读取的专用变量。

## 推荐方案
**方法**: build-folder-scoped-project-tmpdir

**说明**: 在 build() 或 test() 中从 self.build_folder 派生项目专用 scratch 目录，创建后通过上游支持的环境变量传入；test_package 使用自己的 build_folder。

**修复命令**:
```
cascade_tmp_dir = os.path.join(self.build_folder, "_cascade_tmp"); os.makedirs(cascade_tmp_dir, exist_ok=True); self.run('CASCADE_TMP_DIR="{}" ctest ...'.format(cascade_tmp_dir))
```

**验证**:
```
conan create <recipe> -pr:h=<ohos-profile> -pr:b=<ohos-profile> --build=missing -c:a tools.build:jobs=2；确认构建与 test_package 分别传入各自 self.build_folder/_cascade_tmp，并检查上游测试计数、跳过数和退出码。
```
