# E3476: PkgConfigDeps 生成的 .pc 名与上游 Makefile 查询名不一致，触发错误的回退分支

## 基本信息
- **严重度**: 2
- **类别**: build-system, make, conan, dependency, pkg-config
- **作者**: PMD1

## 错误特征
```
Package .* was not found in the pkg-config search path|No package '.*' found|pkg-config:.*not found|shell: pkg-config .* --cflags.*\(empty\)
```

## 根因分析
Conan 的 PkgConfigDeps 按**Conan 引用名**生成 .pc 文件

## 推荐方案
**方法**: generate-pc-aliases-in-conanfile

**说明**: 在 conanfile 的 generate() 里，把 PkgConfigDeps 产出的

**修复命令**:
```
gen = self.generators_folder ; shutil.copyfile(os.path.join(gen,"dbus.pc"), os.path.join(gen,"dbus-1.pc")) ;
```

**验证**:
```
1) PKG_CONFIG_PATH=<gen> pkg-config dbus-1 --cflags 返回空或报 not found;
```
