# E3477: 纯 C 项目链接含 C++ 目标文件的静态库时缺 libc++，报 operator new 未定义

## 基本信息
- **严重度**: 2
- **类别**: toolchain, linking, c++, compilation, static-library
- **作者**: PMD1

## 错误特征
```
undefined symbol: operator new\[\]|undefined symbol: operator new|undefined reference to `operator new|__cxa_pure_virtual|std::__.*basic_string.*append|undefined symbol: _ZdlPv
```

## 根因分析
某个 Conan 依赖以**静态库**形式提供，但库内包含 C++ 目标文件

## 推荐方案
**方法**: link-cxx-runtime-explicitly

**说明**: 在链接行显式加入 C++ 运行时：OHOS/clang+libc++ 用 `-lc++`

**修复命令**:
```
make -j1 LDFLAGS="-lc++"        # OHOS / clang + libc++
```

**验证**:
```
1) 链接报 undefined symbol: operator new[] / __cxa_pure_virtual / std::__n1::...;
```
