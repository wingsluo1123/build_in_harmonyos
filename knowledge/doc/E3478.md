# E3478: musl libc 不传递包含 pthread 类型与 PATH_MAX，glibc 上能编的老 C 代码需要显式 include

## 基本信息
- **严重度**: 1
- **类别**: portability, libc, musl, posix, headers
- **作者**: PMD1

## 错误特征
```
unknown type name 'pthread_mutex_t'|unknown type name 'pthread_cond_t'|unknown type name 'pthread_t'|use of undeclared identifier 'PATH_MAX'|use of undeclared identifier 'PTHREAD_MUTEX_INITIALIZER'|storage size of '.*' isn't known
```

## 根因分析
glibc 的头文件会顺带引入 pthread 类型与 PATH_MAX，musl 严格按 POSIX 拆分头文件不做传递包含，导致 glibc 上能编的老 C 代码在 OHOS 上报 unknown type name。

## 推荐方案
**方法**: add-explicit-include-via-patch

**说明**: 在缺头文件的文件里补上显式 include：pthread 类型补 <pthread.h>，

**修复命令**:
```
# 在 beep.h 的 include guard 内加 #include <pthread.h> ;
```

**验证**:
```
1) 编译报 unknown type name 'pthread_mutex_t' / use of undeclared identifier 'PATH_MAX';
```
