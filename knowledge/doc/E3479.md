# E3479: x86 I/O 端口访问驱动在 aarch64 上无法编译：<sys/io.h> 存在但无 outb/inb/iopl

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, headers, compilation, architecture
- **作者**: PMD1

## 错误特征
```
call to undeclared function 'outb'|call to undeclared function 'inb'|call to undeclared function 'iopl'|implicit declaration of function 'out[bw]'|undefined reference to 'outb'|undefined reference to 'iopl'|sys/io\.h:.*empty
```

## 根因分析
x86 专有 I/O 端口原语（outb/inb/iopl/ioperm）在 aarch64 上既无声明也无指令，OHOS sysroot 的 <sys/io.h> 是空文件，于是 `#include <sys/io.h>` 成功但编译报 undeclared function。

## 推荐方案
**方法**: arch-guard-with-substantive-unsupported-path

**说明**: 用**架构能力**宏（__i386__ / __x86_64__）而不是 __OHOS__ 包一层守卫：

**修复命令**:
```
#if !defined(__i386__) && !defined(__x86_64__) / # define XXX_NO_PORT_IO 1 / #endif ;
```

**验证**:
```
1) grep -rn 'sys/io\.h' <src> 定位引用点;
```
