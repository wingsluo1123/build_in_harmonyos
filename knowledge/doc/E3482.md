# E3482: 配置期兼容诊断与模块加载分别验证

## 基本信息
- **严重度**: 2
- **类别**: configure, perl, testing
- **作者**: A139

## 错误特征
```
module load does not exercise import-time compatibility diagnostics
```

## 根因分析
Canary::Stability的use Module ()只加载模块而不调用import；原始加载测试不能证明依赖配置阶段的真实诊断行为。版本支持提示属于具体API的输出合同，必须与退出状态及目标软件实际测试分别判断。

## 推荐方案
**方法**: preserve-diagnostics-and-exercise-actual-import

**说明**: 绑定官方模块字节和真实安装位置；保留原始无import测试，新增真实import版本阈值调用并核对诊断；使用文档化NOPROMPT保持自动运行但不设置DISABLE跳过实际检查；分别保留上游、消费者及Harmony私有文件结果，父库仍须另行完整测试。

**修复命令**:
```
make -j1 test TEST_VERBOSE=1
```

**验证**:
```
make -j1 test TEST_VERBOSE=1
```
