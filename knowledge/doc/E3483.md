# E3483: 本机 Python subprocess 无法按 PATH 解析裸命令名（posix_spawn），只有绝对路径可用

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, python, tooling
- **作者**: unknown

## 错误特征
```
FileNotFoundError.*No such file or directory: 'git'|PF0 环境闸.*无法计算变更文件|FileNotFoundError: \[Errno 2\].*: '(ls|sh|git|python3)'
```

## 根因分析
在本 HarmonyOS PC 设备上用 CPython 3.12 调

## 推荐方案
**方法**: resolve-command-to-absolute-path-before-subprocess

**说明**: 在 subprocess 调用前把命令名解析为绝对路径：

**修复命令**:
```
exe=$(command -v git); "$exe" --version
```

**验证**:
```
python3 -c "import subprocess; subprocess.run(['ls','/'])"
```
