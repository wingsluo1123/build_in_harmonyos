# E3488: 可选功能被编译排除时，上游进程成功不能替代功能位图和真实消费者数据

## 基本信息
- **严重度**: 3
- **类别**: configure, dependency, testing
- **作者**: 2301

## 错误特征
```
upstream program returns success with optional feature body excluded|binary exists but runtime feature unavailable
```

## 根因分析
某些原始测试把整个测试主体包在功能宏内，禁用后仍以退出码0结束；测试注册数和进程PASS数不变，但具体能力和数据路径没有执行。存在recipe和binary并不证明消费者所需功能存在。

## 推荐方案
**方法**: bind-feature-bitmap-and-data-oracle

**说明**: 保留原始TESTS及条件分支，声明实际启用功能位图，追踪依赖构建选项并验证目标运行时能力；增加真实文件导入和模块数据读取oracle，将原上游进程数、消费者断言及启用分支分别记录，不以相同的历史N/N跨功能快照迁移。

**验证**:
```
original check_xls_load/check_zipshp guard-to-return source trace and108 original Automake IDs; current native formal r6 original108/108 zero skip, consumer20 internal assertions and Harmony1/1; exact actual load_XL/VirtualXL original-data evidence
```
