# E3502: Conan 缓存残缺二进制包被误视为完整导致 test 假失败

## 基本信息
- **严重度**: 2
- **类别**: conan, packaging, testing, cache
- **作者**: 1835

## 错误特征
```
bin/R RHOME returns //lib/R|package dir missing installed subtree \(e\.g\. lib/R/bin\)|Already installed! but test fails on missing files|moved package launcher cannot resolve R home
```

## 根因分析
package() 的 copytree 在运行被中断时留下部分拷贝, conan 仅凭 package_id 存在即判 Already installed, 残缺包被后续 create/test 直接复用

## 推荐方案
**方法**: conan-remove-binaries-rebuild

**说明**: 发现包目录缺子树时, 先 conan remove "name/ver:*" -c 清二进制缓存再从源码全量重建, 以重建结果为权威验证

**修复命令**:
```
conan remove "${name}/${ver}:*" -c && conan create . -pr:h=$PROFILE -pr:b=$PROFILE --build=missing
```

**验证**:
```
diff <(cd $STAGE && find . | sort) <(cd $PKG_FOLDER && find . | sort); 或 conan remove "name/ver:*" -c 后重建对比
```
