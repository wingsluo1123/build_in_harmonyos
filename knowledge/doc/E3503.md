# E3503: 上游测试 concurrency 500 线程在 OHOS musl 偶发 SIGABRT，降为 100 线程（源码 #define 重编译）

## 基本信息
- **严重度**: 2
- **类别**: portability, musl, threading, testing
- **作者**: F08F

## 错误特征
```
concurrency.*SIGABRT|THREAD_COUNT 500|rc=134
```

## 根因分析
OHOS musl pthread 在 500 线程规模行为差异导致 abort；非库缺陷。THREAD_COUNT 为源码 #define（test/concurrency.c 第 12-16 行），不是环境变量，须改源码 + 重新编译测试二进制才生效。历史笔记"运行时参数调整"表述不精确，应纠正为"测试源码宏调整（需重编译）"。配方零耦合（conanfile 只 make build 静态库，不构建/不跑上游测试）

## 推荐方案
**方法**: test-source-edit

**说明**: 把 concurrency.c 的 THREAD_COUNT 从 500 改为 100 后重新编译测试二进制，运行稳定 rc=0

**修复命令**:
```
sed -i 's/#define THREAD_COUNT 500/#define THREAD_COUNT 100/' test/concurrency.c; make test/concurrency; ./test/concurrency
```

**验证**:
```
sed -i 's/#define THREAD_COUNT 500/#define THREAD_COUNT 100/' test/concurrency.c && make test/concurrency && ./test/concurrency
```
