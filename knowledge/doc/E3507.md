# E3507: 废弃入口点 API 迁移必须用真实插件元数据验证分组和关闭开关

## 基本信息
- **严重度**: 3
- **类别**: compat, detection, portability, testing
- **作者**: ISBN

## 错误特征
```
ModuleNotFoundError: No module named .pkg_resources.
```

## 根因分析
Legacy plugin registry imports pkg_resources although packaging metadata omits the runtime dependency; plain top-level import can pass without exercising lazy registry discovery. Replacing discovery with an empty result hides the import error but disables plugins.

## 推荐方案
**方法**: migrate-entry-point-discovery-with-real-dist-info-regression

**说明**: Use importlib.metadata.entry_points; select(group=...) on selectable results or mapping.get(group, ()) on Python 3.8/3.9. Preserve name/load and configuration gates. In a fresh isolated interpreter install real METADATA and entry_points.txt fixtures, execute discovered callables and verify unrelated groups/disabled plugins stay absent.

**修复命令**:
```
python3 -I -S test_isbnlib.py InstalledIsbnlibTests.test_11_plugin_groups InstalledIsbnlibTests.test_12_plugins_disabled InstalledIsbnlibTests.test_13_no_plugins
```

**验证**:
```
ISBNLIB_PACKAGE_ROOT=<installed-site> python3 -I -S archives/i/isbnlib/3.10.14/test_package/test_isbnlib.py
```
