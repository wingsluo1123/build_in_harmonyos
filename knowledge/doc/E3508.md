# E3508: Bridge Conan CMakeDeps imported targets for upstream legacy CMake variables

## 基本信息
- **严重度**: 2
- **类别**: cmake, linking, conan, dependency
- **作者**: 7111

## 错误特征
```
libboost_program_options is required but not found|libsamplerate not found, but required|unable to find library -lfftw3|Target ".*" links to:.*but the target was not found
```

## 根因分析
Upstream CMake written for module/pkg-config mode checks legacy Boost_* or LIBSAMPLERATE_* variables, or passes bare -l names; Conan CMakeDeps config mode exports imported targets and private libdirs but does not populate those variables, so configure or link fails.

## 推荐方案
**方法**: bridge-conan-cmake-legacy-variables

**说明**: In generate(), set legacy cache variables to imported targets when upstream calls find_package; for pkg-config-only dependencies, set absolute library and include paths from dependency package folders.

**修复命令**:
```
rg -n "Boost_.*FOUND|FFTW3_LIBRARIES|LIBSAMPLERATE_FOUND|target_link_libraries" CMakeLists.txt
```

