# E3511: 毒化profile下Autotools预生成configure三连坑：CONFIG_SHELL与CC实测兜底加PKG_CONFIG指向pkgconf真名加runtime install多文件覆盖

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, build-system, autotools, testing
- **作者**: hmbs-executor
- **来源 PR**: 16292

## 错误特征
```
/data/service/hnp/bin/bash: inaccessible or not found|C compiler cannot create executables|pkg-config not found|install-dist_docDATA.*Error 64
```

## 根因分析
ohos-aarch64 profile把SHELL/CONFIG_SHELL钉为真机不可访问的/data/service/hnp/bin/bash且把CC钉为部分机器不可见的/data/service/hnp/bin/clang，预生成configure遇非空CONFIG_SHELL即重exec坏shell，裸直调又丢工具链标志致Error 77；pkgconf包只装pkgconf真名而configure以AC_PATH_TOOL单名探测pkg-config；HMBS runtime bin/install包装器多文件DATA安装报EX_USAGE/64

## 推荐方案
**方法**: prebuilt-configure-shell-cc-pkgconf-install-override

**说明**: 删autoreconf直用预生成configure，以/bin/sh内联前缀覆盖毒化SHELL/CONFIG_SHELL并实测可用CC单token透传，双通道指向PKG_CONFIG=pkgconf真名，package期探测可用install覆盖INSTALL，保留工具链与测试口径

**修复命令**:
```
archives/l/libini_config/1.4.0/conanfile.py: 删autoconf/automake/libtool申报与0003补丁，_inline_prefix内联SHELL/CONFIG_SHELL/CC/PKG_CONFIG，generate加tool_requires pkgconf/3.0.5并define PKG_CONFIG，package追加探测INSTALL覆盖；test_package/: 计数发射双通道标记
```

**验证**:
```
真机conan日志确认configure越过139行坏bash重exec且clang系列检查为yes且checking for pkg-config命中pkgconf，make check出现# FAIL: 0且package阶段无install-dist_docDATA Error 64，门禁passed
```
