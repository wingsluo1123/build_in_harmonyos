# E3512: 受限设备上 gpgrt-config 家族 fork 风暴：生成 fork-free shim 读 .pc 版本并预置 ac_cv_path 缓存跳过，辅以瞬时 posix_spawn EAGAIN 有界重试

## 基本信息
- **严重度**: 3
- **类别**: compat, ohos, build-system, autotools
- **作者**: hmbs-executor
- **来源 PR**: 13426

## 错误特征
```
can't fork - try again|posix_spawn failed: Resource temporarily unavailable|unable to execute command: posix_spawn failed
```

## 根因分析
configure 优先探测并调用 fork 极重的 gpgrt-config（约 715 行、37 处 $() 子 shell），而 libgpg-error 1.55 默认只装 gpgrt-config、不装轻量 gpg-error-config（需 --enable-install-gpg-error-config），受限设备进程表有限时连续 fork 触发 can't fork - try again；即便绕过 configure，make 阶段 clang posix_spawn 仍可能瞬时 EAGAIN

## 推荐方案
**方法**: fork-free-shim-with-ac_cv_path-preset

**说明**: 在 configure 顶部解析 --with-libgpg-error-prefix，真实 gpg-error-config 缺失时用 shell 内建 read 从依赖 gpg-error.pc 读版本，在 build 目录生成 fork-free gpg-error-config shim，并预置导出 GPG_ERROR_CONFIG/ac_cv_path_GPG_ERROR_CONFIG/ac_cv_path_GPGRT_CONFIG=no 跳过 fork 重型脚本；对瞬时 posix_spawn EAGAIN 在失败目标处做有界重试

**修复命令**:
```
patches/0001-*.patch：configure 顶部解析 prefix flag；gpg-error-config shim 以 .pc 读版本（内建 read，不 fork）；导出 ac_cv_path_* 缓存；mkheader 等目标仅当 stderr 含 Resource temporarily unavailable 签名时重试有限次
```

**验证**:
```
真机日志确认 checking for gpgrt-config... (cached) no、GPG Error - version >= 1.17... yes (1.55)、gpgrt-config 零调用，configure 与 make 全链路通过，上游测试正常执行
```
