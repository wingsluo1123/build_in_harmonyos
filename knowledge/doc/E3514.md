# E3514: Gate packages that need Linux kernel tracing (eBPF/kprobe/perf_event) — OHOS 无追踪接口

## 基本信息
- **严重度**: 3
- **类别**: limitation, detection, kernel, portability, syscall
- **作者**: 44F3

## 错误特征
```
Bad system call|SIGSYS|Function not implemented.*bpf|perf_event_open.*(Operation not permitted|EACCES|Function not implemented)|linux/bpf\.h.*No such file|/sys/kernel/debug/tracing.*No such file|cannot find -lbpf|libbpf
```

## 根因分析
OHOS 内核未提供 Linux 追踪接口：bpf() 被平台以 SIGSYS（aarch64 信号 31）直接终止进程而非返回 ENOSYS；perf_event_open 返回 EACCES；

## 推荐方案
**方法**: feature-gate-kernel-tracing

**说明**: 构建期保留产物（ply vendored <linux/bpf.h>，可编译通过）；运行期明确标注平台不支持——

**修复命令**:
```
ply --version   # 仅验证产物完整性；任何 kprobe/eBPF 脚本都会在 bpf() 处被 SIGSYS 终止
```

**验证**:
```
python3 -c "import ctypes,os;pid=os.fork();print('bpf() -> KILLED BY SIGNAL',os.waitpid(pid,0)[1]&0x7f) if pid else (ctypes.CDLL(None,use_errno=True).syscall(280,0,0,0,0,0),os._exit(0))"   # 预期: bpf() -> KILLED BY SIGNAL 31（aarch64 __NR_bpf=280；fork 隔离必需）
```
