# E3526: Conan "Copying sources to build folder" 报 [Errno 13] Permission denied 且路径落在一个符号链接上：copytree(symlinks=True) 建链成功后紧接着 copystat(follow_symlinks=False)，而 OHOS/HMDFS 不支持对符号链接设置属主权限（lchmod 返回 EACCES）—— 与"目录权限不足"无关，build() 根本还没开始跑

## 基本信息
- **严重度**: 3
- **类别**: hmdfs, conan, filesystem, permissions, symlink
- **作者**: 24E4

## 错误特征
```
Error copying sources to build folder|\[Errno 13\] Permission denied.*changelog
```

## 根因分析
Conan 2 默认 no_copy_source=False，installer._copy_sources() 用 shutil.copytree(source_folder, build_folder, symlinks=True) 把源码目录复制进构建目录。CPython 3.12 的 _copytree 对符号链接成员的处理是 os.symlink(linkto, dstname) 紧跟 copystat(srcobj, dstname, follow_symlinks=not symlinks)（shutil.py:522-523）：建链本身在 OHOS 应用私有存储（实测 os.symlink 返回 0）是可用的，但 follow_symlinks=False 的 copystat 走 lchmod/lutimes，鸿蒙存储文件系统不支持修改符号链接自身的属主/权限/时间戳，返回 EACCES(13)，被 copytree 收进 shutil.Error 后由 Conan 包成 "[Errno 13] Permission denied … Error copying sources to build folder"。触发前提是源码包里存在**符号链接成员**：shfs-0.35.tar.gz 里唯一一个就是 debian/changelog → ../Changelog（tar 成员 type=2、mode=0120777），它是 Debian 打包用的软链，与本项目构建毫无关系。注意 untargz(..., strip_root=True) 只在 linkpath 以根目录名开头时改写链接目标（files.py:483-486），"../Changelog" 不以 "shfs-0.35" 开头，故按原样建链——链接本身是好的，坏的是复制时的那次 lchmod。

## 推荐方案
**方法**: exclude-symlink-bearing-subtree-at-extract

**说明**: 在解压阶段就把"含符号链接且与构建无关"的子树排除掉，让 source_folder 天然没有链接成员。conan 2.29 里支持 excludes 的是解包类 API：conan.tools.files.get() 与 unzip() 都有 excludes 形参（download() 没有，只负责取文件不解包），且 untargz 用 fnmatch 对**未 strip_root 的原始成员名**做匹配（files.py:466-467），所以模式要写成带根目录前缀的形式。shfs 0.35 落地：source() 里 get(self, **self.conan_data["sources"], strip_root=True, excludes=["*/debian/*"])，既去掉唯一符号链接成员，又顺手丢掉 Debian 打包噪音（减小 source_folder 与复制耗时）。

**修复命令**:
```
# conanfile.py source() 内：get(self, **self.conan_data["sources"], strip_root=True, excludes=["*/debian/*"])
```

**验证**:
```
python3 -c "import os,shutil;d=os.environ['TMPDIR']+'/slp';shutil.rmtree(d,ignore_errors=True);os.makedirs(d+'/src/debian');open(d+'/src/Changelog','w').write('x');os.symlink('../Changelog',d+'/src/debian/changelog');shutil.copytree(d+'/src',d+'/bld',symlinks=True)"   # 期望 PermissionError(13) / shutil.Error，路径落在 changelog 符号链接
```
