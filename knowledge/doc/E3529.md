# E3529: OHOS/gl4es 的 GLU 是「只有头、没有符号」：libGL.so 不导出 gluPerspective，glu/9.0.3 与 ${OPENGL_glu_LIBRARY} 必须显式补进链接行，否则头能编、链接必炸

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, ohos, linking, opengl
- **作者**: 链主-100

## 错误特征
```
"undefined reference to `gluPerspective'|undefined symbol: gluPerspective|undefined reference to `gluLookAt'|undefined reference to `gluErrorString'|Could NOT find GLU"
```

|

## 推荐方案
**方法**: add-glu-dep-and-explicit-openGL-glu-link

**说明**: gl4es 的 GLU 只有头没有实现（libGL.so 不导出 gluPerspective）；须 requires glu/9.0.3 + 播种 OPENGL_glu_LIBRARY 并显式接进链接行

**修复命令**:
```
llvm-nm -D --defined-only "$(find $CONAN_HOME/p -path '*gl4es*/p/lib/libGL.so.1' | head -1)" | grep -c gluPerspective
```
