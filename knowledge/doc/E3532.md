# E3532: 1990s 代码的 K&R 变参（<varargs.h> + va_dcl + 单参 va_start）在 clang 上是三条硬错误，必须逐个入口转成 C99 <stdarg.h>；CFLAGS 无法绕过

## 基本信息
- **严重度**: 2
- **类别**: compat, libc, headers, compiler
- **作者**: unknown

## 错误特征
```
Please use <stdarg\.h> instead of <varargs\.h>|varargs\.h: No such file|expected function body after function declarator|too few arguments provided to function-like macro invocation|macro 'va_start' defined here|conflicting types for|incompatible integer to pointer conversion assigning to 'char \*' from 'int'
```

## 根因分析
pre-ANSI 的变参机制（`#include <varargs.h>`、函数头写 `f(va_alist)` 后跟一行

## 推荐方案
**方法**: convert-varargs-entrypoints-to-c99-stdarg

**说明**: 逐个变参入口做机械转换，纯 C、不加任何平台宏、glibc 下同样编译通过：

**修复命令**:
```
>
```

**验证**:
```
printf '#include <varargs.h>\n#include <stdio.h>\nvoid f(va_alist)\nva_dcl\n{\n  va_list ap; char *fmt;\n  va_start(ap);\n  fmt = va_arg(ap, char *);\n  vfprintf(stderr, fmt, ap);\n  va_end(ap);\n}\nint main(void){ f("n=%%d s=%%s\\n", 42, "x"); return 0; }\n' > /tmp/vargs-kr.c; clang --target=aarch64-linux-ohos --sysroot=$SYSROOT -c /tmp/vargs-kr.c -o /dev/null; sed -e 's/<varargs.h>/<stdarg.h>/' -e 's/void f(va_alist)/void f(char *fmt, ...)/' -e '/^va_dcl$/d' -e 's/va_start(ap);/va_start(ap, fmt);/' -e '/fmt = va_arg/d' /tmp/vargs-kr.c > /tmp/vargs-c99.c; clang --target=aarch64-linux-ohos --sysroot=$SYSROOT -c /tmp/vargs-c99.c -o /dev/null && echo C99_OK
```
