# E3537: dict subclass public mapping is not a raw-storage test oracle

## 基本信息
- **严重度**: 2
- **类别**: compat, detection, portability
- **作者**: 34CB

## 错误特征
```
FAIL: test_set_item_key_
```

## 根因分析
PyDict_Copy may merge through mapping keys when a dict subclass changes iteration; a filtered public view can hide reverse entries from a parent-copy observation while raw storage remains intact.

## 推荐方案
**方法**: explicit-base-storage-observer

**说明**: Use dict(dict.items(obj)) for raw-storage invariants, preserve original expected values, and propagate the custom unittest result to process status.

**修复命令**:
```
python3 -B test_twodict.py -v
```

**验证**:
```
python3 -B test_twodict.py -v
```
