# E3538: 老项目在新 Python 环境下的三处打包/测试坑：pkg_resources、命令脚本不落盘、告警污染输出断言

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, python, packaging, testing
- **作者**: 58D2

## 错误特征
```
No module named 'pkg_resources'|env: exec python: No such file or directory|缺少命令产物|\d+ errors during collection
```

## 根因分析
老项目（本例 vint 0.3.21，2018 年）的打包与验收测试依赖当时的工具链假设，换到新环境后

## 推荐方案
**方法**: pin-setuptools-and-generate-console-script

**说明**: ①运行时依赖显式钉 `setuptools<81`（才有 pkg_resources）；②本体用 `--no-deps` 安装

**修复命令**:
```
pip install --target <pkg> "setuptools<81" <deps>; pip install --no-deps --target <pkg> .
```

**验证**:
```
PYTHONPATH=<pkg>/python python3 -c "import pkg_resources, <mod>" && <pkg>/bin/<cmd> --version
```
