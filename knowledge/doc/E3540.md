# E3540: 终端/子进程类包在这类受限环境上的三个通用坑：PATH 不检索、tmp_path 属主、terminfo 缺失

## 基本信息
- **严重度**: 3
- **类别**: portability, testing, process
- **作者**: 4F19

## 错误特征
```
\[Errno 2\] No such file or directory: '\w+'|not owned by the current user|terminfo database|_curses.error|setupterm
```

## 根因分析
①Python 3.12 的 subprocess 在本平台走 os.posix_spawn（非 posix_spawnp），**不做 PATH 检索**

## 推荐方案
**方法**: three-portability-patches

**说明**: ①spawn 前用 `shutil.which` 解析裸命令名（只补 PATH 语义）；

**修复命令**:
```
cmd[0] = shutil.which(cmd[0]) or cmd[0]; export TMPDIR=<owned>; try: curses.setupterm() except curses.error: pass
```

**验证**:
```
python -c "import subprocess;subprocess.Popen(['echo','hi'])"; python -c "import curses;curses.setupterm()"
```
