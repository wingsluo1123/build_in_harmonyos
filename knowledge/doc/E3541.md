# E3541: test_package/conanfile.py 的 test() 未调用 self.run()（仅 meson.test()）导致 CI L0d 门禁 stub_test_method 拦截

## 基本信息
- **严重度**: 3
- **类别**: build-system, conan, testing
- **作者**: E843

## 错误特征
```
stub_test_method|test\(\) method has no self\.run\(\) call.*likely a stub|L0d:.*self\.run
```

## 根因分析
CI L0d 门禁（build_and_test.sh grep self\.run）要求 test_package/conanfile.py 的 test() 方法必须实际调用 self.run() 运行测试程序；仅调用 meson.test()/cmake.test() 构建系统测试助手会被判为 stub（空壳测试），L0 直接拦截、不进入编译，失败码 stub_test_method

## 推荐方案
**方法**: 在 test() 方法中用 self.run() 直接运行 meson/cmake 构建出的测试程序: test_exe = os.path.join(self.build_folder, "test_xxx"); if can_run(self): self.run(test_exe, env="conanrun")

**说明**: 参考已合入 jsonrpc-glib/gnome-autoar 的 meson test_package 写法：test() 内用 can_run(self) 判断 + self.run(测试程序, env="conanrun") 实际执行，取代仅 meson.test() 的空壳调用

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
grep -q "self\.run" test_package/conanfile.py  # 必须命中；完整验证: CI_PACKAGES="archives/w/wf-utils/0.4.0" zsh ci/conan/build_and_test.sh
```
