# E3542: wf-utils 为 Wayfire 基础工具库，作为 submodule 未单独发布导致下游链接失败或头文件缺失；上游无独立测试

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: E843

## 错误特征
```
No rule to make target.*wf-utils|undefined reference.*wf::|wayfire/condition.*not found
```

## 根因分析
wf-utils 为 Wayfire 基础工具库（action/condition/lexer/parser/rule/variant），上游无独立测试且无外部依赖；作为 submodule 随 wayfire 源码树提供时，若未单独发布会导致下游链接 wf-utils 符号失败或头文件缺失

## 推荐方案
**方法**: wf-utils 单独发布为 conan 包（meson 库名 wf-utils），下游用 requires("wf-utils/0.4.0") 引用；上游无测试时用鸿蒙 test_package 冒烟验证 variant_t/is_int/is_string API

**说明**: 将 Wayfire submodule 工具库单独发布为 Conan 包（archives/w/wf-utils/0.4.0），test_package 冒烟调用 variant_t/is_int/is_string/is_bool 验证库在 OHOS 上可构造 variant 并做类型判断

**修复命令**:
```
conan create archives/w/wf-utils/0.4.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```

**验证**:
```
conan create 通过，test_package 1/1 OK
```
