# E3544: OHOS 构建 CPython C 扩展（setup.py build_ext）的五个必改点：头文件路径、setuptools 引导、libpython 链接、ELF 签名、site-packages 布局

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, linking, runtime
- **作者**: 4464

## 错误特征
```
No module named .setuptools.|Python\.h: No such file or directory|Error (loading|relocating) shared library.*(cpython|site-packages).*|Error loading shared library.*Permission denied|INCLUDEPY.*//include
```

## 根因分析
conan python/3.12 的 sysconfig INCLUDEPY 解析为 //include/python3.12（无效路径）且包内不自带 setuptools；扩展模块未显式链接 libpython 时 musl BIND_NOW 下 dlopen 报 symbol not found；未签名 .so 在 OHOS 上 dlopen 报 Permission denied；setuptools 不读三元组/Conan 包信息，只认环境变量

## 推荐方案
**方法**: env-override

**说明**: 环境变量全量注入 CC/C_INCLUDE_PATH/CFLAGS/LDSHARED/LDFLAGS（LDSHARED 含 -L<python>/lib -lpython3.12）；pinned setuptools wheel 解包到 build 目录并置于 PYTHONPATH；按目标解释器 sysconfig 取 EXT_SUFFIX 命名产物；binary-sign-tool 自签 + chmod 755（复制后重签）；安装到 lib/pythonX.Y/site-packages

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
PYTHONPATH=<pkg>/lib/python3.12/site-packages <conan python> -c "import <module>; print(<module>.__file__)"
```
