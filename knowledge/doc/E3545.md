# E3545: OHOS aarch64 的 sys/io.h 为空头文件：x86 端口 I/O 调用编译只告警、链接不报错、dlopen 才报 symbol not found

## 基本信息
- **严重度**: 3
- **类别**: portability, headers, linking, runtime
- **作者**: 5CE0

## 错误特征
```
call to undeclared function .(outb|inb|outw|inw|outl|inl|ioperm|iopl).|Error relocating.*symbol not found|Error loading shared library.*symbol not found
```

## 根因分析
OHOS aarch64 sysroot 提供 sys/io.h 但其 bits/io.h 为空（无 outb/inb/ioperm 声明）；缺声明时 clang 仅给 implicit-function-declaration 告警，共享库允许未定义符号故链接成功，musl BIND_NOW 下 dlopen 才报 symbol not found

## 推荐方案
**方法**: ifdef-arch-guard

**说明**: 用架构宏（__i386__/__x86_64__）选择 x86 实现；非 x86 分支显式失败（抛错/返回 ENOSYS），禁止空 stub 与静默成功

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
llvm-readelf -sW module.so | grep " UND " | grep -E "outb|inb|ioperm"
```
