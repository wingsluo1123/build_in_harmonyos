# E3548: 依赖 pth（Portable Threads）包装库的老 C 代码移植到现代平台：#include<Pth头>→<pthread.h>、Pth_*→pthread_* 前缀批量替换、构建层摘 -lpth，三层同改一次过

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, headers, threading, build-system
- **作者**: unknown
- **来源 PR**: unicon 3.0.4 适配（本 PR，路径 B 知识库扩展）

## 错误特征
```
pth/pthread\.h: *No such file or directory|fatal error: *pth/|undefined reference to 'Pth_|cannot find -lpth|No such file or directory.*-lpth
```

## 根因分析
1990s 代码依赖的 pth 线程包装库在现代发行版/OHOS 中不存在（依赖链

## 推荐方案
**方法**: strip-thin-wrapper-three-layers

**说明**: 头文件替换（pth/pthread.h→pthread.h）+ API 前缀批量替换

**修复命令**:
```
sed -i 's|#include <pth/pthread.h>|#include <pthread.h>|' <files>
```

**验证**:
```
grep -rn "Pth_\|<pth/" --include='*.c' --include='*.h' . || echo "零残留 OK"
```
