# E3552: TUI/数据类工具交付时的两个要点：测试环境前提与"批处理可验证性"

## 基本信息
- **严重度**: 2
- **类别**: portability, packaging, testing
- **作者**: 7C3B

## 错误特征
```
not owned by the current user|XDG_CACHE_HOME|console script not generated|scripts= not installed
```

## 根因分析
①pytest 的 tmp_path 校验"临时目录属主 == 当前用户"，HMDFS 上构建目录属主是映射后的

## 推荐方案
**方法**: owned-tmpdir-plus-batch-mode-assertion

**说明**: ①测试环境按"属主 == 当前 uid 且可写"挑选 TMPDIR（专用临时挂载点优先），并清掉

**修复命令**:
```
export TMPDIR=<owned>; unset XDG_CACHE_HOME; <pkg>/bin/<cmd> -b -o out.csv in.csv
```

**验证**:
```
stat -c %u "$TMPDIR"; echo x | <pkg>/bin/<cmd> --version
```
