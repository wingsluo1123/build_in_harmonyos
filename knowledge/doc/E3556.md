# E3556: QSS 已解析值不可全局删除分号：区分字面 token 和声明终止符

## 基本信息
- **严重度**: 2
- **类别**: python, data-loss, parsing
- **作者**: 9920

## 错误特征
```
assert '"leftright"' == '"left;right"'
```

## 根因分析
StyleRule 对已解析属性值全局 replace 分号，损坏字符串、URL 和转义中的字面内容。

## 推荐方案
**方法**: token-aware-terminator-removal

**说明**: 使用已有tinycss2识别顶层literal分号，仅删除尾部声明终止符，保留其余原文。

**修复命令**:
```
应用patches/0001-qstylizer-style.py.patch后运行原suite及新增回归。
```

**验证**:
```
python -m pytest -p pytest_mock -q -o addopts= test_package/regression.py
```
