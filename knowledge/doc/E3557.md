# E3557: toybox coreutils 不支持 GNU 长选项导致上游 shell 测试失败

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, posix, testing
- **作者**: F7E9

## 错误特征
```
Unknown option 'printf=%s'|Unknown option 'bytes='|Unknown option 'ignore-initial='
```

## 根因分析
OHOS /bin 下 coreutils 为 toybox 实现，stat 仅支持 -c、cmp 仅支持 -n 与位置偏移参数，不支持 GNU 的 --printf/--bytes/--ignore-initial 长选项

## 推荐方案
**方法**: posix-test-port

**说明**: 把测试脚本改为 stat -c %s、cmp -n LEN FILE1 FILE2 [SKIP1 [SKIP2]]；注意 GNU --ignore-initial=SKIP 对两个文件同时生效，替换时要给两个偏移

**修复命令**:
```
sed -i 's/stat --printf=/stat -c /; s/cmp --bytes=/cmp -n /' test/*
```

**验证**:
```
/bin/cmp --bytes=1 a b; /bin/stat --printf=%s a
```
