# E3558: OHOS procfs /proc/self/fd st_size 固定 64 导致 readlink 路径截断

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, libc, testing
- **作者**: BA01

## 错误特征
```
Name += /[^\n]+(\.pnor|\.bin|\.img)$|pflash.*--info
```

## 根因分析
OHOS procfs 对 /proc/self/fd/<n> 的 lstat 返回固定 st_size=64，按该值分配 readlink 缓冲时超过 63 字节的路径被截断；libflash get_info_name 即按此实现

## 推荐方案
**方法**: short-tmpdir

**说明**: 程序按 PATH_MAX 分配 readlink 缓冲（或 len==size 时扩容重试）；测试临时目录放在可写构建目录，不要假定 /tmp 可写

**修复命令**:
```
TMPDIR=$BUILD_DIR/test-tmp make check
```

**验证**:
```
python3 -c "import os;f=open(os.path.expanduser('~/tmp/x'),'w');p='/proc/self/fd/%d'%f.fileno();print(os.lstat(p).st_size,len(os.readlink(p)))"
```
