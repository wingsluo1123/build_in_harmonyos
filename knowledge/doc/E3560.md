# E3560: 上游 Python 测试套件钉住旧 Pillow 时，测试比较助手需归一化 IFDRational（Pillow>=6）而非改库代码

## 基本信息
- **严重度**: 2
- **类别**: python, dependency, testing
- **作者**: unknown

## 错误特征
```
pack_byte|IFDRational|struct\.error.*B.*format requires|!= 180\.0
```

## 根因分析
Pillow>=6 将 EXIF rational 值从 (numerator, denominator) 元组改为返回 IFDRational

## 推荐方案
**方法**: test-helper-type-normalization

**说明**: 补丁仅改测试文件：在比较助手内加 normalize()，把带 numerator/denominator 属性

**修复命令**:
```
python3 tests/s_test.py  # 期望 Ran 55 tests ... OK
```

**验证**:
```
PYTHONPATH=<pillow site-packages>:<src> python3 tests/s_test.py
```
