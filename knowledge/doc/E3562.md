# E3562: 源内PEP517 backend-path自举与官方bootstrap安装器显式目的地契约

## 基本信息
- **严重度**: 2
- **类别**: autotools, python, packaging, install-destination
- **作者**: A139

## 错误特征
```
bootstrap_install[.]py|backend-path|flit_core[.]buildapi|flit_core[.]wheel
```

## 根因分析
A source-hosted PEP517 backend with empty build-system.requires can build its own wheel directly; its separate official bootstrap installer defaults to the running interpreter sysconfig purelib, which is independent of the Conan package destination. The source backend contract and explicit installer destination must be bound together.

## 推荐方案
**方法**: source-backend-wheel-entry-plus-official-installer-explicit-target

**说明**: 在既有Python源码自举规则上补充源内PEP517后端的双入口契约：先核对requires=[]、backend-path=["."]与flit_core.buildapi，直接用官方python -m flit_core.wheel生成自身wheel，再使用同一发布源bootstrap_install.py并显式传--installdir到Conan包内；该安装器默认目的地来自当前解释器sysconfig.purelib，不能靠Conan包目录自动改变默认值。安装前校验归档成员，安装后逐项匹配官方模块字节，并以安装后端构建wheel、sdist和editable产物验证完整元数据及RECORD。

**修复命令**:
```
python -B -m flit_core.wheel --outdir <owned-dist>; python -B bootstrap_install.py <wheel> --installdir <Conan-package-site>
```
