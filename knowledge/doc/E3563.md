# E3563: 手写 Makefile 用 INSTALLROOT+PREFIX 双层前缀（DESTDIR 只是回退）且

## 基本信息
- **严重度**: 2
- **类别**: build-system, make, pkg-config, packaging, versioning
- **作者**: unknown

## 错误特征
```
"(package_folder)/usr/local/lib|/usr/local/include/.*自 INSTALLROOT|pkg-config.*--modversion.*版本不符|Version: [0-9.]+.*≠.*tag 版本"
```

## 推荐方案
**方法**: makefile-installroot-plus-empty-prefix-then-relocate-pc

**说明**: Conan 配方 package() 同传「外层根=package_folder」与「内层空前缀」：

**修复命令**:
```
make install INSTALLROOT="$(pwd)/pkg" PREFIX=/ ARCH=aarch64 CC=clang HOSTCC=clang AS=clang LD=ld.lld AR=llvm-ar RANLIB=llvm-ranlib OBJCOPY=objcopy INSTALL=ginstall
```

**验证**:
```
( set -eu; PKG=gnu-efi; VER=4.0.4; T1="$(mktemp -d)"; T2="$(mktemp -d)";
```
