# E3568: 已发布测试框架归档未导出 CMake target 时应补真实 imported target 执行上游 tester

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, testing
- **作者**: asp1r1n1
- **来源 PR**: !15662

## 错误特征
```
bctoolbox-tester|BCTOOLBOX_TESTER_LIBRARY
```

## 根因分析
bctoolbox/5.3.115 的实际安装包有 tester 归档和头文件，但公共 CMakeDeps 元数据没有导出上游 oRTP tester 所需的 bctoolbox-tester target；仅运行 consumer 留下上游测试缺口。

## 推荐方案
**方法**: import-real-tester-archive-and-transitive-framework

**说明**: 上游 target 不存在时，用 UNKNOWN IMPORTED 指向真实 tester 归档，传递头文件目录和 bctoolbox、bcunit::bcunit；保留原始 tester 源码、断言及非零退出传播，并加入 build/src 和依赖库的运行时路径。

**验证**:
```
核实真实包内 libbctoolbox-tester.a 与 tester.h，ENABLE_UNIT_TESTS=ON 构建后执行原始 ortp_tester，并另跑安装后 consumer。
```
