# E3569: HarmonyOS 无 /var/lock 且无串口设备节点——termios 串口 bring-up 在锁文件阶段即失败，需按「无设备」降级取证而不是当配方缺陷排查

## 基本信息
- **严重度**: 2
- **类别**: platform, limitation, ohos, runtime, filesystem
- **作者**: 83FD

## 错误特征
```
Could not create lockfile /var/lock/LCK\.|lockfile directory unavailable|Unable to connect to card reader device at /dev/tty|serial device /dev/tty.* No such file or directory
```

## 根因分析
HarmonyOS PC 根目录没有 /var（实测 `ls -ld /var` → No such file or directory），传统 Unix 串口

## 推荐方案
**方法**: probe-lock-dir-and-degrade-plus-headless-device-probe

**说明**: 两件事一起做：①把锁文件目录当**可选前置**——stat 一下候选锁目录，不存在就打印一行

**修复命令**:
```
配方侧不加参数；包内新增 `--probe-reader`（patch_type=test），测试断言 PROBE 行与退出码
```

**验证**:
```
GDK_BACKEND=broadway BROADWAY_DISPLAY=:7 rfdump --probe-reader -p /dev/ttyUSB0 2>&1 | grep -cE "lockfile directory unavailable|Unable to connect to card reader device"; ls -ld /var/lock
```
