# E3575: nettle 2.x 消费者代码在 nettle 3.x 上编译：DSA 密钥接口已搬进官方 <nettle/dsa-compat.h>，include + 一处形参适配即可，勿重写 DSA 层

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, libc, linking, security
- **作者**: wanderlust_0823

## 错误特征
```
variable has incomplete type 'struct dsa_public_key'|
```

## 根因分析
nettle 3.0 起把 DSA 的"整键"接口从公开头里搬走： `struct dsa_public_key` / `struct dsa_private_key` 的定义、 `dsa_public_key_init` / `dsa_public_key_clear` / `dsa_private_key_init` / `dsa_private_key_clear`、`dsa_sha1_sign_digest` / `dsa_sha1_verify_digest` （以及 sha256 版）与按键生成 `dsa_generate_keypair`，在 nettle 3 的公开头 `<nettle/dsa.h>` 里**都不再存在**（3.10.2.1 的 dsa.h 只剩 `struct dsa_params`、 `struct dsa_signature`、`dsa_sign/dsa_verify(params, mpz_t, ...)` 与 sexp/DER 解析）。 这些旧接口被整体挪进官方兼容头 `<nettle/dsa-compat.h>`，该头同时 `#define dsa_generate_keypair nettle_dsa_compat_generate_keypair` 并给出旧结构体布局。 写于 nettle 2.x 时代的消费者代码（本案例是 lsh-utils 2.1，2013 年）只 include `<nettle/dsa.h>`，于是： * `struct dsa_public_key dsa;` → `error：variable has incomplete type`（编译期就死）； * `dsa_public_key_init(&dsa)` / `dsa_sha1_verify_digest(...)` → 隐式声明（返回 int）， 在 aarch64 上还会把指针截断； * 补上 include 后，`dsa_keypair_from_sexp_alist(pub, [priv,] p_max_bits, q_bits, i)` 这 4/5 参调用与 nettle 3 的 6 参原型不符 → `too few arguments to function call, expected 6, have 5`。 关键判断：**compat 头不是空壳**。3.10.2.1 的 libhogweed.a 里 `nettle_dsa_public_key_init` / `nettle_dsa_compat_generate_keypair` / `nettle_dsa_sha1_verify_digest` 都是已定义的 T 符号（实测，见 verification_cmd）， 所以这是一条"补 include + 对齐新形参"的路，不需要自己实现 DSA 或降级到别的版本。

## 推荐方案
**方法**: use-official-compat-header-and-align-signature

**说明**: 在用到旧 DSA 接口的翻译单元里，紧跟 `#include <nettle/dsa.h>` 之后

**修复命令**:
```
patch(src/<file>.c) 在 —— include <nettle/dsa.h> 后加 —— include <nettle/dsa-compat.h>；dsa_keypair_from_sexp_alist 调用点补 params/y/x 形参
```

**验证**:
```
nm -g <pkg>/lib/libhogweed.a | grep -E 'T (_?nettle_)?(dsa_public_key_init|dsa_compat_generate_keypair|dsa_sha1_verify_digest)$' —— 实测 nettle/3.10.2.1 三个都命中（T=已定义），证明 compat 头有真实现； —— 对照：struct dsa_public_key 在 include/nettle/dsa.h 里 grep 0 命中， ——       只在 include/nettle/dsa-compat.h 里有定义。
```
