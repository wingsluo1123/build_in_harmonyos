# E3579: 在 qt5-qtbase/5.15.2.2 上直接编 CMake+Qt5 消费方会连撞四个坑——包内 config 烙死构建树路径、CMakeDeps 生成物缺上游宏、find_program 的 NOTFOUND 会重新搜索、无 RUNPATH 的 ELF 只能靠内联 LD_LIBRARY_PATH

## 基本信息
- **严重度**: 2
- **类别**: ohos, cmake, cross-compile, conan, version
- **作者**: unknown

## 错误特征
```
Unknown CMake command "QT5_ADD_RESOURCES"|references the file .*mkspecs/linux-clang.* but this file does not exist|Compatibility with CMake < 3\.5|use of undeclared identifier 'yymore_used_but_not_detected'|ISO C\+\+17 does not allow 'register'|Error loading shared library libQt5(Core|Test)\.so\.5|redefinition of 'hash<QBitArray>'
```

## 根因分析
以 kdevelop-pg-qt/1.90.92 为例，四个坑彼此独立、都会让对方看起来"像另一个问题"：

## 推荐方案
**方法**: qt-prefix-mirror-and-explicit-env

**说明**: ① qtbase 用 **qt-prefix 镜像**接入：在 build 目录建镜像，除 `lib/` 外全部

**修复命令**:
```
cmake -DCMAKE_POLICY_VERSION_MINIMUM=3.5 -DFLEX_EXECUTABLE= -DBISON_EXECUTABLE= ...
```

**验证**:
```
readelf -d <build>/tests/<bin> | grep -E "RPATH|RUNPATH"   # 空 → 只能靠 LD_LIBRARY_PATH
```
