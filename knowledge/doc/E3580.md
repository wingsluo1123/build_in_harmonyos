# E3580: `conan create <recipe>` 时 **test_package 的 build_folder 就是 test_package 目录本身**，测试产物直接落进工作区，`git add <整目录>` 会把它一起提交（CI 的 JC 杂项检查正是拦这个）

## 基本信息
- **严重度**: 1
- **类别**: conan, ci-junk, git, repo-hygiene
- **作者**: unknown

## 错误特征
```
Test package build folder: .*test_package|^\?\? .*test_package/.*\.(cc|cpp|h|hpp|qm)$|only track changes|JC.*杂项文件
```

## 根因分析
本地运行 `conan create archives/…/<pkg>` 时，test_package 的构建目录被设为

## 推荐方案
**方法**: write-test-artifacts-to-tempdir

**说明**: 测试产物一律写到**系统临时目录**，不要写 `self.build_folder`：

**修复命令**:
```
git status --porcelain | grep test_package
```

**验证**:
```
git status --porcelain | grep test_package
```
