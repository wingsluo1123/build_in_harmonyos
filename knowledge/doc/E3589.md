# E3589: OHOS 制品仓 vtk 未启用 ParallelMPI，依赖 vtkMPIController 的库无法编译该模块（自带开关时可关闭，但运行期该输出样式报 Invalid dump style）

## 基本信息
- **严重度**: 2
- **类别**: limitation, detection, ohos, dependency
- **作者**: A2E8

## 错误特征
```
fatal error: 'vtkMPIController\.h' file not found|vtkMPIController\.h: No such file|cannot open shared object file.*libvtkParallelMPI|libvtkParallelMPI-9\.[0-9]+\.so: No such file|Invalid dump style
```

## 推荐方案
**方法**: probe-before-enable-then-disable-optional

**说明**: 先用 verification_cmd 探测 vtk 包是否含 ParallelMPI；库自身有 VTK 开关时关闭该功能、保留其余全部功能，并在 R51 测试口径中把「依赖该输出样式的上游用例」单列原因（不改仿真本体，只去掉输出请求行）

**修复命令**:
```
conan cache path vtk/<ver>   # 再 ls include/vtk-*/vtkMPIController.h 与 lib/libvtkParallelMPI*
```

**验证**:
```
VTK_P=$(conan cache path vtk/9.4.1); ls "$VTK_P"/include/vtk-9.4/vtkMPIController.h; ls "$VTK_P"/lib/libvtkParallelMPI-*.so
```
