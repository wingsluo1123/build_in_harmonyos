# E3599: OHOS sysroot 自引用宏触发 -Werror=disabled-macro-expansion 的通用降级与 Conan env fork EAGAIN 防护

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, libc, headers, build-system
- **作者**: hmbs-executor
- **来源 PR**: 15462

## 错误特征
```
disabled expansion of recursive macro \[-Werror,-Wdisabled-macro-expansion\]|can't fork - try again|fork: retry: Resource temporarily unavailable
```

## 根因分析
OHOS sysroot 的 stdio.h/ctype.h 将 stdin/stdout/stderr 及 isprint/isspace/isdigit 等声明为自引用宏（如 #define stdin (stdin)），源码中直接引用会展开成不再展开的递归宏，clang 报 -Wdisabled-macro-expansion；当上游把 -Weverything 与 -Werror=disabled-macro-expansion 无条件追加（与 PEDANTIC 无关）时升级为硬错误，逐对象豁免会连环失败。另一路失败是 Conan 默认 tools.env:deactivation_mode 未设置时，生成的环境脚本对每个变量执行 value=$(printenv $v) fork 子进程，在 fork 资源紧张的 worker 上首个 self.run 即 EAGAIN（日志伴生 fork: retry: Resource temporarily unavailable）。

## 推荐方案
**方法**: global-diagnostic-downgrade-plus-conan-env-function-mode

**说明**: 用一条全局 CFLAGS 把 -Werror=disabled-macro-expansion 降级为警告，一次性覆盖 stdio/ctype 全部自引用宏；同时在配方与 test_package 的 configure() 中设置 tools.env:deactivation_mode=function，去除 env 脚本逐变量 printenv 的 fork；对仍偶发的瞬时 fork 指纹做有限次重试，真实编译错误不重试

**修复命令**:
```
Makefile 顶部（或补丁 0002）加 CFLAGS += -W$(PEDANTRY_EXCEPTION)disabled-macro-expansion；conanfile.py 与 test_package/conanfile.py 增加 configure(): self.conf.define("tools.env:deactivation_mode", "function")；_run_capture 命中 Resource temporarily unavailable|can't fork 时最多重试 3 次
```

**验证**:
```
真机日志中不再出现 disabled expansion of recursive macro 与 can't fork - try again；保留 HMBS_UPSTREAM_TEST_RESULT 与 HMBS_TEST_PACKAGE_RESULT 真实计数（tenyr 上游 check_sw 88/88、test_package 6/6）；conan install 生成的 conanbuildenv-*.sh 中 grep -c printenv 为 0
```
