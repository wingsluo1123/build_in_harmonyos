# E3607: 构建工具类包（参考实现的等价重实现）在 OHOS 无 Go/原生 harness 时的全量回归：用构建机已有的参考实现（GNU make）做沙箱对差分——同输入双跑、归一化链对齐上游、产物清单比对、平台差显式 xfail 钉单（XPASS 视同失败），kati 355 用例真机 fail=0

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, testing, differential, methodology
- **作者**: unknown

## 错误特征
```
go: command not found|go tool.*not found|上游测试驱动为 Go 源码（run_test\.go）|
```

## 根因分析
构建工具类包（make 克隆、shell/awk 变体等）的上游测试本质是**行为回归**：同一输入跑"参考实现"与"被测物"各一遍，比对 stdout/stderr 与产物文件清单。此类测试驱动常绑定不可移植工具链（kati 的 run_test.go 依赖 go test，OHOS 无 Go）。但关键资源其实已在手：**参考实现本就存在于构建机**（GNU make 4.4.1 位于 conanbuild PATH）——差分测试不缺任何依赖，缺的只是把上游 harness 语义搬到本平台执行（见姊妹条目 Go-harness-Python-移植）。若因此放弃上游测试只留消费者冒烟，355 个行为用例的等价性验证全部丢失，且"构建工具自举"类包（kati 是 Android 构建系统的解释器）的回归风险无法闭环。

## 推荐方案
**方法**: reference-impl-sandbox-pair-differential

**说明**: 五件套（按实施顺序）：(1) **沙箱对布局**：out/<name>/{make,kati} 兄弟目录，workdir 深度严格对齐上游——用例以相对路径（../../../testcase/...）引用共享夹具，深度错位是隐性夹具契约破坏；(2) **执行顺序保真**：先全部 make 侧再全部 kati 侧、同 .mk 的 testN 顺序共用同一目录——顺序/共享状态本身就是测试语义（makefile_list 的 touch 顺序效应依赖它）；(3) **归一化链对齐**：上游 run_test.go 的每条正则（含 circular 前置抽取这类"先抽取置顶再比对"的非常规步骤）逐条移植，再按需追加平台噪声剥离；(4) **噪声剥离铁律**：只剥离零语义信息的环境噪声（如 bash getcwd 回退行 shell-init/chdir: error retrieving current directory，行数随子 shell 环境翻动），双侧同剥，getcwd 正常平台为 no-op；**钉单证据必须取自归一化后的最终输出**——归一化前抓的 diff 会把噪声伪影误判为语义差（实证：gate-PATH 取证后 4 项误钉解钉）；(5) **xfail 显式钉单**：平台差逐条写明根因入 xfail 文件，XPASS 与 FAIL 同样使套件失败（与上游 TODO 语义同严格），自洽性约束 = 任何归一化/钉住组合下 xpass 必须=0。配套节奏：musl 容器先摸底（Alpine 3.20 实测 316/15/24，归因出 3 类根因）→ 真机首跑按实测分布回填钉单（241/90 → 归一化+钉单收敛到 249/0/106/0）——musl 分布不代表真机（make 版本不同分布会变），只用于 harness 语义预验证。

**修复命令**:
```
python3 tests/run_testcases.py --workdir <source_folder>/out SHELL=<ohos bash>（示意；差分套件由 conan create 的 build() 驱动硬失败）
```

**验证**:
```
真机（MateBook，OHOS aarch64，GNU make 4.4.1）：差分 harness（run_testcases.py，语义对齐上游 run_test.go）以 source_folder/out 为 workdir，对 296 个 testcase/*.mk 展开的 355 个用例建沙箱对 out/<name>/{make,kati}（兄弟目录，相对深度是夹具契约），先跑完全部 make 侧再全部 kati 侧（顺序与共享目录语义对齐上游），双侧输出经同一归一化链（对齐上游正则 + 平台噪声剥离）后逐用例比对 stdout/stderr 与产物清单 → total=355 pass=249 fail=0 xfail=106 xpass=0，连跑 ×2 逐字一致。
```
