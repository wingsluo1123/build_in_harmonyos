# E3610: meson custom_target 直接执行 python 脚本依赖 shebang /usr/bin/env，OHOS 沙箱/精简环境无该路径导致 custom command 无法执行

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: 8C84

## 错误特征
```
custom target.*Permission denied|/usr/bin/env.*bad interpreter|update-merge-modes-tests.py.*not found
```

## 根因分析
meson custom_target 直接执行 python 脚本依赖 shebang /usr/bin/env；OHOS 沙箱与精简环境无 /usr/bin/env（实测 Permission denied），custom command 无法执行

## 推荐方案
**方法**: meson.build 的 custom_target command 改用 find_installation('python3') + script 显式执行（command: [python, script]），不依赖 shebang

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
