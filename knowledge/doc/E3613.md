# E3613: 测试辅助包与覆盖率测量工具依赖环的分层验证

## 基本信息
- **严重度**: 2
- **类别**: build-system, python, testing
- **作者**: UM16

## 错误特征
```
No module named coverage
```

## 根因分析
coverage 的完整测试需要 unittest-mixins，而 unittest-mixins 的 tox 通过 coverage 包装 pytest；测量工具依赖环不等同于运行库或原始测试断言依赖环。

## 推荐方案
**方法**: separate-measurement-from-assertions

**说明**: 分别核验运行图、断言执行图和测量工具图；先构建叶子并执行完整原版测试，明确测量未验证，待父项正式发布后补回原测量命令。

**修复命令**:
```
python3 -m pytest -ra -vv tests; python3 -m unittest discover -s tests -v
```

**验证**:
```
核对官方 sdist/tox/.coveragerc/setup.py；先保留原包装失败，再比对原版 stdlib 与 pytest 的完整用例 ID、结果和源码哈希；消费者验证真实安装载荷。
```
