# E3614: KF6/缺SONAME 依赖包的相对 DT_NEEDED 使消费方按 cwd 解析失败

## 基本信息
- **严重度**: high
- **类别**: linking
- **作者**: FD10

## 错误特征
```
error while loading shared libraries: ../../bin/libKF6ConfigCore.so: cannot open shared object file: No such file or directory
```

## 根因分析
依赖包共享库未写 SONAME（或链接时给的是路径），DT_NEEDED 保留构建期路径；musl loader 对含斜杠的 NEEDED 按进程 cwd 逐字解析，LD_LIBRARY_PATH/rpath 均不生效

## 推荐方案
**方法**: ancestor-bin-mirror

**说明**: 在 ctest/插件/test_package 的运行目录各级祖先生成 bin/ 兼容软链，镜像依赖库，使含斜杠的相对 DT_NEEDED 可被 loader 解析（knowledge/tools/kf6-relative-needed 的 apply-compat-shim.py，配方内即 _make_compat_mirrors()）

**修复命令**:
```
./apply-compat-shim.py --pkg-root ${PKG} --runtime-dir ${RUNTIME} --apply
```

**验证**:
```
python3 knowledge/tools/kf6-relative-needed/detect-relative-needed.py --pkg-root <PKG> --runtime-dir <DIR>
```
