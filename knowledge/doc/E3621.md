# E3621: 版本 banner 的否定品牌语句会命中宽松子串探测并误注册可选工具角色

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, autotools, testing
- **作者**: 2501

## 错误特征
```
is not GNU grep|PROG_GNU_GREP|negative version banner
```

## 根因分析
对完整版本输出只搜索品牌子串，无法区分品牌声明与否定声明；Toybox 的 is not GNU grep 被误当作 GNU grep，导致同一系统实现承担两个比较器角色。 Autoconf creates config.status scratch directories in two branches with owner-only masks. On HMDFS, changing file modes later or repairing PR transport cannot establish creation-time access. Replace both creation branches with exclusive mkdir under the recipe-private TMPDIR, use umask 022 at creation, restore configure timestamps, and prefix TMPDIR after Conan environment activation. Preserve cleanup and every original test.

## 推荐方案
**方法**: positive-provider-identity-at-role-boundary

**说明**: 在手写配置模板的可选角色边界匹配肯定身份格式，再让配置系统生成运行文件；保留必需系统角色、原测试分母、原输入和原迭代次数。 Autoconf creates config.status scratch directories in two branches with owner-only masks. On HMDFS, changing file modes later or repairing PR transport cannot establish creation-time access. Replace both creation branches with exclusive mkdir under the recipe-private TMPDIR, use umask 022 at creation, restore configure timestamps, and prefix TMPDIR after Conan environment activation. Preserve cleanup and every original test.

**修复命令**:
```
将品牌子串检查改为肯定 banner 结构检查，例如 GNU grep 首行包含 (GNU grep)；验证正反例后完整重跑实际框架，检查角色对应的工具能力，不能以 banner 代替能力测试。
```

**验证**:
```
检查真实 --version 首行、配置角色和完整测试执行记录；分别验证真实 GNU banner、Toybox 否定 banner、空输出与未知输出，后者不得注册 GNU 角色。
```
