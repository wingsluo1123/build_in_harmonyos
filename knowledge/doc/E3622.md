# E3622: HMDFS 大小写折叠致 git 双大小写路径恒 M（基线恢复）

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, filesystem, git
- **作者**: 115B

## 错误特征
```
git status 恒定 M|HMDFS 大小写折叠|case-insensitive.*dual.case|libXext.*libxext
```

## 根因分析
仓库 HEAD 同时跟踪同路径双大小写条目(如 archives/l/libXext 与 libxext)，HMDFS 大小写不敏感，checkout 只落一份物理文件，git status 对另一大小写路径恒显示 M

## 推荐方案
**方法**: git-restore-head-variant

**说明**: 按 checkout 基线内容恢复(git restore --source=HEAD -- <变体路径>)，记录 pre/post SHA-256 均等于 HEAD 变体，staged/PR 不含该路径；不得误判为外部污染或提交/删除

**修复命令**:
```
git restore --source=HEAD -- archives/l/libxext/README.md && sha256sum archives/l/libXext/README.md
```

**验证**:
```
git ls-files | grep -iE 'libXext|libxext' 确认双大小写条目; sha256sum 核对与 HEAD 变体一致
```
