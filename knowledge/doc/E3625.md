# E3625: 权限拒绝测试必须绑定实际执行 DAC 的文件系统并验证内核前提

## 基本信息
- **严重度**: 2
- **类别**: detection, hmdfs, portability, posix
- **作者**: LD66
- **来源 PR**: https://atomgit.com/OpenHarmonyPCDeveloper/build_in_harmonyos/merge_requests/15756

## 错误特征
```
error from write to write protected directory|kernel enforces fixture directory permissions
```

## 根因分析
HMDFS 缓存目录可接受 chmod(0) 却仍允许当前用户创建文件；以 chmod 返回0推断内核必定拒绝写入，会把夹具前提不成立误判为异步IO未传递EACCES。worker原始TMPDIR也可能在HMDFS，保存环境变量并不能证明权限能力。

## 推荐方案
**方法**: capability-proven-private-permission-fixture

**说明**: 对原始TMPDIR及应用沙箱temp/cache候选逐项使用唯一mkdtemp夹具，chmod(0)后独占open必须精确EACCES，恢复0700后同一路径必须创建成功，清理后才选定临时根；不合格根不能因可写或名称而接受。随后原C测试再次独立验证同步EACCES、异步回调同一errno和完整未写入数据。所有候选不合格必须fail closed，不能跳过或放宽断言。

**修复命令**:
```
ctest --output-on-failure --no-tests=error --parallel 1
```

**验证**:
```
对唯一mkdtemp目录chmod(0)，同步open(O_CREAT|O_EXCL|O_RDWR)必须精确返回EACCES；随后完整运行原异步错误及未写入数据断言和成功读回测试，核对所有注册CTest ID。
```
