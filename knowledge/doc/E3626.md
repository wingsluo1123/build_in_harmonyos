# E3626: 已知 PATCHES 大小写碰撞的无损替代：隔离源码与导出根并保留全部成员

## 基本信息
- **严重度**: 2
- **类别**: portability, conan, filesystem
- **作者**: LD65
- **来源 PR**: https://atomgit.com/OpenHarmonyPCDeveloper/build_in_harmonyos/merge_requests/15756

## 错误特征
```
IsADirectoryError.*PATCHES|IsADirectoryError.*[Pp]atches|FileExistsError.*unpack
```

## 根因分析
Conan 将 exports_sources 内容复制到缓存源码根；默认 source_folder 同为根时，strip_root 解包会把上游根文件与 recipe 导出目录合并。大小写不敏感的 worker 中，PATCHES 文件与 patches/ 目录是同一名字；下载和 SHA256 通过后仍会在文件写入时报 IsADirectoryError。仅在大小写敏感设备的私有目录验证无法暴露此问题。

## 推荐方案
**方法**: isolate-upstream-source-from-recipe-export-root

**说明**: 用标准 cmake_layout(self, src_folder="upstream") 或等价 self.folders.source 子目录隔离下载树。source() 的 get 仍使用官方 URL、原 SHA256 和 strip_root；构建、许可证复制与 apply_conandata_patches 使用 self.source_folder，patch_file 仍由 export_sources_folder 定位。保留所有上游文件及已验证补丁表示。

**修复命令**:
```
cmake_layout(self, src_folder="upstream")
```

**验证**:
```
在大小写不敏感文件系统使用真实 conan source 重现旧布局失败并验证子目录布局成功；随后从干净 Conan home 执行 native conan create、全部上游测试和安装包消费者，并在原 CI worker 复验。
```
