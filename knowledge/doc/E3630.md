# E3630: 本机 conan download -r=ohpcd 报 acceleration policy 时须对照已发布包再判依赖缺失

## 基本信息
- **严重度**: 1
- **类别**: limitation, detection, dependency
- **作者**: 8DC7

## 错误特征
```
system acceleration policy not enabled|Recipe not found|ERROR: Recipe not found
```

## 根因分析
本机对未发布包统一报 system acceleration policy not enabled，与已发布但本机受限不可区分；实测已发布包（libdockapp/0.7.3）可正常下载，未发布包（libwraster/0.96.0）恒报该错

## 推荐方案
**方法**: 1) 用已知已发布包做对照探测；2) 公开 search API 交叉验证；3) 以依赖 PR 是否合入（release 上传是否触发）作旁证；4) 判定缺失按 R41 上报 dependency_missing，禁止伪造绕过

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
