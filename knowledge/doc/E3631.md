# E3631: CI 构建机 fork 耗尽导致 autotools 生成文件缺规则

## 基本信息
- **严重度**: 2
- **类别**: platform, build-system, autotools
- **作者**: EE84

## 错误特征
```
can't fork - try again|config\.status: can't fork|No rule to make target '[^']*config-paths\.h'|No rule to make target
```

## 根因分析
worker fork 资源耗尽使 config.status 生成的顶层 Makefile 缺失 BUILT_SOURCES 规则（本地存在 Makefile.in:929 规则），报 No rule to make target 被伪装成配方错误

## 推荐方案
**方法**: 1) 配方内自生成该中间文件，不依赖顶层 make 规则；2) 把 config.status can't fork 归类为构建机环境问题上报，勿误判配方；3) 与 worker 侧 fork 资源问题联动

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
