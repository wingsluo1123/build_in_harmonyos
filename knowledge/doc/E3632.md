# E3632: pkg-config 硬探针造成的假依赖经 cpp_info 传递到下游产物

## 基本信息
- **严重度**: 2
- **类别**: detection, autotools, linking
- **作者**: A923

## 错误特征
```
PKG_CHECK_MODULES.*xft|checking for xft >=|libXft\.so\.2|NEEDED.*libXft
```

## 根因分析
上游 configure 的 PKG_CHECK_MODULES(xft>=2.1.0) 硬探针命中但源码零引用 Xft，配方误将 libxft 写入 requires/cpp_info.requires，下游 ELF 出现平台外 DT_NEEDED libXft.so.2（违反 R26）

## 推荐方案
**方法**: 1) 复核源码实际引用（grep 头文件/符号）；2) 删去探针引入的假依赖，用 <LIB>_CFLAGS/<LIB>_LIBS 旁路探针；3) readelf -d 复核下游产物 DT_NEEDED 可归因到 requires 闭包

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```
