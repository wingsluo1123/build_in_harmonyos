# E3636: GNOME dist configure 的 IT_PROG_INTLTOOL 展开共 8 处 intltool 相关 as_fn_error 硬错误（无 intltool 平台上本环境可达 5 处，另 3 处条件不可达）：应把可达点降级为 no-op 并配上游原生 --disable-nls，且注意 check 目标仍硬挂 $(PACKAGE).pot

## 基本信息
- **严重度**: 2
- **类别**: ohos, build-system, autotools, nls, intltool
- **作者**: gdl-3.40.0-builder
- **来源 PR**: gdl 3.40.0 适配

## 错误特征
```
as_fn_error .*intltool|The intltool scripts were not found|XML::Parser perl module is required|GNU gettext tools not found|--gettext-package: command not found|Makefile:[0-9]+: [a-z]+-[0-9.]+\.pot\] Error 127
```

## 根因分析
intltool.m4 在 GNOME dist 期被展开进预生成 configure，形成 8 处

## 推荐方案
**方法**: neutralize-intltool-as-fn-error-plus-disable-nls

**说明**: 对可达的 5 处 as_fn_error 逐处降级为 ':' no-op（探针保留、

**修复命令**:
```
patch: as_fn_error 5 处 → ':'（保探针）；configure_args 追加
```

**验证**:
```
grep -n "as_fn_error" <dist>/configure | grep -iE
```
