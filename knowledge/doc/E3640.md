# E3640: OHOS 上 SIOCETHTOOL/genetlink 双双 EACCES：功能面不可达，以信息面断言 + 差分能力探针全量披露交付

## 基本信息
- **严重度**: 2
- **类别**: platform, network, runtime, testing, capability
- **作者**: 主理-N <主理-N@local>

## 错误特征
```
SIOCETHTOOL.*Permission denied|SIOCETHTOOL.*EACCES|NETLINK_GENERIC.*Permission denied|genetlink.*Permission denied|AF_NETLINK.*GENERIC.*errno=13|/sys/class/net.*Permission denied
```

## 根因分析
进程态 CapEff=000000000000002a（无 CAP_NET_ADMIN/CAP_NET_RAW）、Seccomp=2：同套接字上 SIOCGIFFLAGS(0x8913)/SIOCGIFINDEX(0x8933) rc=0（正对照），而 SIOCETHTOOL(0x8946) 连只读 ETHTOOL_GDRVINFO 也 errno=13，NETLINK_GENERIC socket 创建即 errno=13，/sys/class/net listdir errno=13 ⇒ 被拦的恰是 ethtool 两面而非整个网络栈（NETLINK_ROUTE socket 可用、修正版 RTM_GETLINK dump 收 17916B/8 块/NLMSG_DONE）。上游源码穷举：args[] 表 no_dev=true 仅 -h|--help 与 --version 两条，功能命令全走 ETHTOOL_G/S ioctl（94 处）或 genetlink，--disable-netlink 只是两面互退，fopen 落盘路径都要先 send_ioctl ⇒ 无非特权替代路径。

## 推荐方案
**方法**: capability-split-differential-probe-with-informational-assertions

**说明**: ① 用差分探针把"能力面被拦"与"整个栈不可用"分开：同一 fd 上基础 ioctl 正对照 rc=0、目标 ioctl/genetlink EACCES，并跨机复测排除会话沙箱伪影；② 穷举上游 no_dev/文件替代路径，得出"无非特权替代"结论并把枚举行号写进披露；③ test_package 只断言信息面真实输出（退出码 + 非空 + 版本/用法特征串 grep -q），⛔ 不断言任何功能面可用、⛔ 不用 || true 兜底；④ notes 与 PR 正文披露三机 errno 读数与进程态（CapEff、Seccomp），措辞统一为"本平台测试进程无相应 capability，功能面未能实测；已实测 -h/--version 与构建产物完整"，⛔ 不写平台级"不可用"定性。

**修复命令**:
```
probe SIOCETHTOOL+NETLINK_GENERIC+sysfs on 3 hosts with SIOCGIFFLAGS positive control; grep no_dev=true in args[]; test_package asserts ethtool --version and -h output feature strings via grep -q
```

**验证**:
```
python3 差分探针：同一 AF_INET SOCK_DGRAM 套接字依次 ioctl(0x8913)=rc0、ioctl(0x8946)=errno13；socket(16,SOCK_RAW,16)=errno13；os.listdir(/sys/class/net)=errno13；/proc/self/status 读 CapEff/Seccomp；对照 socket(AF_CAN)=errno97。三机（本机/A/B）读数一致为准。
```
