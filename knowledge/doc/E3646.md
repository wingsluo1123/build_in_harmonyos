# E3646: CI G0 门禁编号规则停留在 3 位 E###.kv，未随知识库编号增长到 4 位 E####.kv，导致所有基于最新 main 的 PR 在 G0 硬失败

## 基本信息
- **严重度**: 3
- **类别**: build-system, infra, knowledge-base
- **作者**: yanjiaxin
- **来源 PR**: 13558

## 错误特征
```
G0b: knowledge/graph/ 下有 [0-9]+ 个非标准命名的 \.kv 文件|G0d: index.tsv 行数\([0-9]+\) vs \.kv 文件数\([0-9]+\) 不匹配
```

## 根因分析
ci/conan/build_and_test.sh 的 G0b/G0d 检查于 2026-08（提交

## 推荐方案
**方法**: 修改 ci/conan/build_and_test.sh 编号匹配，从固定 3 位放宽到 3-4 位

**说明**: G0b 白名单正则 '/E[0-9][0-9][0-9]\.kv$' → '/E[0-9][0-9][0-9][0-9]?\.kv$'（等价 E[0-9]{3,4}）；G0d 计数 glob 'E[0-9][0-9][0-9].kv' → 同时匹配 3/4 位（用 grep -cE '/E[0-9][0-9][0-9][0-9]?\.kv$' 统计）；错误消息"仅允许 E###.kv"同步改为"仅允许 E###.kv / E####.kv"；G0d 的 index.tsv 行数校验在放宽后自动对齐（1999 == 1999）

**修复命令**:
```
G0_BAD_KV=$(ls -1 "${GRAPH_DIR_G0}"/*.kv(N) 2>/dev/null | grep -vE '/E[0-9][0-9][0-9][0-9]?\.kv$|/_template\.kv$|/principles\.kv$' || true)
```

**验证**:
```
ls -1 knowledge/graph/*.kv | grep -vcE '/E[0-9][0-9][0-9]\.kv$|/_template\.kv$|/principles\.kv$'   # 返回 1000（E1000-E1999 全部被判非标准）
```
