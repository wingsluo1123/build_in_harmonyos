# E3648: 非 autotools/cmake 的私有 makefile 流程在 OHOS 上的接线范式（以 live555 的 genMakefiles 为例）

## 基本信息
- **严重度**: 2
- **类别**: ohos, nonstandard-build-systems
- **作者**: unknown

## 错误特征
```
Invalid configuration .*OS .*not recognized|fatal error: 'sys/types\.h' file not found|No rule to make target 'install'|fatal error: 'openssl/ssl\.h' file not found
```

## 根因分析
live555 的构建入口是 `./genMakefiles <platform>`——把 `$subdir/Makefile.head` + `config.<platform>` + `$subdir/Makefile.tail`

## 推荐方案
**方法**: generate-platform-config-trim-subdirs-and-collect-artifacts-in-recipe

**说明**: ①构建期生成 `config.<platform>`：编译器/归档器取 profile 的 `tools.build:compiler_executables`（含同目录 `llvm-ar`），

**修复命令**:
```
'conan create archives/l/live555/2026.08.14 -pr:h=ci/conan/profiles/ohos-aarch64 --build=missing'
```

**验证**:
```
<build log> | grep -E "fatal error: 'sys/types.h'|No rule to make target 'install'|fatal error: 'openssl/ssl.h'"
```
