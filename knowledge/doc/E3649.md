# E3649: "OHOS conan 工具链缺 CMake 平台模块致 UNIX 变量为空：Linux 分支全跳过 + clang15/libc++ 兼容补丁族"

## 基本信息
- **严重度**: P1
- **类别**: build-system
- **作者**: j669539
- **来源 PR**: "#16077"

## 错误特征
```
"CMAKE_SYSTEM_NAME=HarmonyOS.*UNIX is empty|X11 detection skipped|fatal error: 'ranges'|no member named 'partial_sort' in namespace 'std::ranges'|using value_type = Container::"
```

## 根因分析
"OHOS conan 工具链设 CMAKE_SYSTEM_NAME=HarmonyOS，但 CMake 无 HarmonyOS 平台模块——UNIX 变量为空，所有 Linux 分支（X11 探测、XWindows 平台源、Unix arch 源）被跳过；同时 OHOS 目标为 clang 15 + libc++，缺 std::ranges 若干算法（partial_sort/find/fill/find_if/for_each）、缺 P0970 make_shared 数组支持、pthread_setcancelstate/type 未声明、且 cppstd 需从 17 提到 20（toolchain 追加 -std=c++17 在 CMAKE_CXX_FLAGS 之后、尾随标志获胜）。"

## 推荐方案
**方法**: "1) 用 Linux 平台语义桥接：使 UNIX 分支在 HarmonyOS 下生效（等价 Linux 语义），X11 后端经 BUILD_X11_SUPPORT=ON 对接 conan 发布 X11 客户端库（barrier/2.4.0 同源先例）；2) libc++15 兼容补丁族：std::ranges 算法全量替换为迭代器对经典算法（<algorithm> 显式 include）、make_shared 数组改 new[]+value-init+shared_ptr 数组删除器、pthread cancellation 相关调用改协作式取消；3) C++20 提升：configure() 设 settings.compiler.cppstd=20（仅 toolchain 变量不够，须走 profile/configure 层）；4) Qt 版本无关解析：QT_VERSION_MAJOR 名解析 Qt Test 包 + gui 测试子目录门控 BUILD_GUI；5) AUToMOC 工具路径注入 + LD_LIBRARY_PATH 解析 libc++_shared.so。"

**说明**: (待补充)

**修复命令**:
```
"settings.compiler.cppstd=20; BUILD_X11_SUPPORT=ON; QT_VERSION_OVERRIDE=5.15; 打 clang15/libc++ 兼容补丁族（ranges→迭代器对/P0970/pthread）"
```

**验证**:
```
"grep -n 'CMAKE_SYSTEM_NAME' conan_toolchain.cmake; grep -c 'std::ranges' <src>/*.cpp  # 替换后应为 0"
```
