# E3654: OHOS libc++ std::sample 与上游全局 struct sample 同名歧义（::sample 全限定修复）

## 基本信息
- **严重度**: 2
- **类别**: compile-error
- **作者**: 1B75

## 错误特征
```
reference to 'sample' is ambiguous|libcxx-ohos/include/c\+\+/v1/__algorithm/sample\.h|std::sample
```

## 根因分析
OHOS libc++ 提供 C++17 std::sample（<__algorithm/sample.h>），当 .cpp 中 using namespace std; 且存在全局同名 struct sample 类型时，参数类型 sample* 产生歧义，编译失败

## 推荐方案
**方法**: 对冲突 .cpp 打 patch：将参数/局部类型的 sample 改为全局限定 ::sample（如 ::sample* sampleBuf），或收窄 using namespace std；patch 不得含 __OHOS__ 平台宏

**说明**: 将冲突 .cpp 中参数/局部类型的 sample 改为全局限定 ::sample，或收窄 using namespace std 作用域

**修复命令**:
```
patch: src/speechPlayer/src/speechWaveGenerator.cpp 参数类型 sample* → ::sample*
```

**验证**:
```
patch -p1 后 make -j1 编译 src/speechPlayer/src/speechWaveGenerator.cpp 通过
```
