# E3656: Extracted vendor CPU feature config selects an incomplete SVE/NEON branch on baseline AArch64

## 基本信息
- **严重度**: 3
- **类别**: compat, detection, portability, build-system
- **作者**: PG82

## 错误特征
```
SVE support not enabled|src_port_pg_popcount_aarch64
```

## 根因分析
The release bundles generated target feature configuration and AST-extracted vendor sources; compiler NEON detection selects a unit with inherited SVE configuration and omitted unused helper bodies.

## 推荐方案
**方法**: verify-extracted-feature-closure-before-selecting-portable-fallback

**说明**: Trace architecture macros, generated capability claims and retained function bodies together; use the existing portable implementation without increasing the target ISA.

**修复命令**:
```
Append -U__ARM_NEON to the private build CFLAGS only after verifying the complete portable implementation.
```

**验证**:
```
Inspect pg_config.h and pg_bitutils.h; compile baseline AArch64; compare native upstream tests before and after selecting the portable implementation.
```
