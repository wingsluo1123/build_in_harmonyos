# E3661: CMake 编译器探测试编译（try-compile）阶段 make 报 resource temporarily unavailable（EAGAIN）：worker 资源压力，非配方缺陷

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, cmake, make, ci-infra
- **作者**: unknown

## 错误特征
```
Check for working C compiler.*broken|is not able to compile a simple test program|resource temporarily unavailable|Problem parsing /proc/meminfo|Generator: build tool execution failed|cmTC_[0-9a-f]+/fast|ConanException: Error 1 while executing|L1_RESULT=fail: conan create failed
```

## 根因分析
worker 处于 fd/内存/进程数压力下，CMake 探测试编译阶段用 make -f Makefile cmTC_*/fast 派生 clang 编译子进程时 fork()/posix_spawn() 返回 EAGAIN（errno 11, "resource temporarily unavailable"），CMake 将其误报为 "The C compiler ... is not able to compile a simple test program" / "compiler - broken"，掩盖资源根因。与 libfprint meson EAGAIN、DRAFT-ci-worker-gate-fork-oom、DRAFT-11327-cannot-fork 同型；本日志 Conan toolchain 已正确注入 -stdlib=libc++（排除 E455），错误文本为 EAGAIN 而非 /bin/sh Permission denied（排除 E346），失败点在 make 启动子进程即 EAGAIN 而非 clang 编译输出错误。

## 推荐方案
**方法**: rebuild-on-idle-worker-no-recipe-change

**说明**: 环境性资源失败：不改配方/源码/测试，对同一 SHA 发起 /rebuild 换 worker；本地用与 CI 完全相同的 ci/conan/build_and_test.sh 复跑全绿即证明配方无问题（E491 forbid_3：改包代码前必须先有设备资源证据）。

**修复命令**:
```
/rebuild（CI 评论触发）；本地: CONAN_PROFILE=ohos-aarch64-local zsh ci/conan/build_and_test.sh（本机 profile 工具链路径已适配，直用 repo 内 CI profile 会报 CMAKE_C_COMPILER is not a full path）
```

**验证**:
```
本地同命令复跑：CI_PACKAGES="archives/a/apt-pkg/2.7.14" CI_BRANCH="feat/apt-pkg-2.7.14" CI_PR_NUMBER="14901" CONAN_PROFILE=ohos-aarch64-local zsh ci/conan/build_and_test.sh → 期望 EXIT=0、G0/L0/L1/L5_RESULT=pass、test_package 全 PASS、All packages built and tested successfully。
```
