# E3662: CMake 上游默认 REL_FLAGS 含 -march=native 时 OHOS 交叉构建必须整体覆盖；组合实现目录（crypto_aead_hash/）会按 crypto_aead_* 与 crypto_hash_* 双命名生成同内容库；上游无 install() 时配方需手动打包

## 基本信息
- **严重度**: 3
- **类别**: cmake, cross-compile, conan, lightweight-crypto, package
- **作者**: pc4-5

## 错误特征
```
invalid value '.*-O2' in '-std=c99 -O2'|Library '.*' not found in package|System is unknown to cmake.*Platform/HarmonyOS
```

## 根因分析
①上游 CMake 项目把编译器优化旗标放进可缓存变量 REL_FLAGS/DBG_FLAGS（默认含 -march=native -mtune=native），在 OHOS 交叉工具链（clang aarch64-linux-ohos）下 -march=native 按构建机 CPU 生成指令，产物不可复现且可能链接失败；命令行传 -DREL_FLAGS="-std=c99 -O2" 含空格会被当成单个参数（报 invalid value 'c99 -O2' in '-std=c99 -O2'），必须用分号分隔列表（-DREL_FLAGS="-std=c99;-O2"）或在 CMakeToolchain 中 tc.variables 传分号列表。②上游对"组合实现目录"（如 crypto_aead_hash/asconv13 同时提供 AEAD 与 HASH）在 CMake 的 foreach(CRYPTO aead hash auth) 循环中 fallback 生成两个库：crypto_aead_<alg>_ref 与 crypto_hash_<alg>_ref，内容相同且都含完整符号集；配方 components 若按目录名臆想库名（crypto_aead_hash_asconv13_ref）会在 CMakeDeps 阶段报 "Library not found in package"。③上游 CMakeLists 无 install() 规则时 cmake.install() 为空操作，package() 需手动复制声明头（tests/crypto_*.h）与各实现头目录、静态库到包内。

## 推荐方案
**方法**: override-rel-flags-plus-correct-component-libs-plus-manual-package

**说明**: 在 generate() 用 CMakeToolchain 设置 tc.variables["REL_FLAGS"]="-std=c99;-O2"（分号列表，勿用空格字符串）整体覆盖上游默认 -march=native；先用 nm/CMake 日志确认实际生成的库名（组合目录按 CRYPTO 类别双命名，如 crypto_aead_asconv13_ref / crypto_hash_asconv13_ref，内容一致选其一），components.libs 用真实库名；上游无 install() 时 package() 手动 copy 声明头+实现头+*.a。

**修复命令**:
```
tc.variables["REL_FLAGS"] = "-std=c99;-O2"; tc.variables["DBG_FLAGS"] = "-std=c99;-O2;-Wall;-Wextra;-Wshadow"; package(): copy(self, "crypto_aead.h", src=.../tests, dst=.../include); copy(self, "*.h", src=.../crypto_aead_hash/asconv13/ref, dst=.../include/crypto_aead_hash/asconv13/ref); copy(self, "*.a", src=bld, dst=.../lib, keep_path=False); cpp_info.components["asconv13"].libs = ["crypto_aead_asconv13_ref"]
```

**验证**:
```
conan-verify G2 conan create 通过；test_package 消费者链接 ascon-c::asconv13 后 configure/compile/link/run 全通过；ctest 199/199 KAT 比对通过；nm 静态库可见 crypto_aead_encrypt/crypto_hash 符号。
```
