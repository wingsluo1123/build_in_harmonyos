# E3664: CMSIS-DSP NEON 动态 Q31 CFFT（arm_cfft_init_dynamic_q31/NE10 路径）对含因子 5 的 FFT 尺寸在 clang 15 aarch64 上输出错误甚至段错误——失败尺寸严格二分于"是否含因子 5"

## 基本信息
- **严重度**: 3
- **类别**: ohos, toolchain, runtime, testing, aarch64
- **作者**: AtomCode
- **来源 PR**: (同 PR 交付)

## 错误特征
```
SNR.*< 100|Signal 11|core dumped|undefined symbol: vtable for TransformNeonCQ31|arm_cfft_init_dynamic_q31
```

## 根因分析
arm_cfft_init_dynamic_q31（NE10 动态实例化路径，仅 ARM_MATH_NEON 可用，见 transform_functions.h:380）对含因子 5 长度的蝶形分解/旋转因子生成在本工具链（clang 15.0.4 aarch64 OHOS）下不可靠：源码树无 radix5 实现文件、库中无 radix5 符号（nm 0 命中）；实测失败尺寸全部含因子 5（20/40/60/80/100/120/160/180/200/240/300/320/360/400/480），通过尺寸全部为 2/3 幂（24/32/36/48/64/72/96/108/128/144），严格二分；独立 20 点动态 Q31 CFFT 直接段错误（Signal 11）。

## 推荐方案
**方法**: upstream-toolchain-defect-with-evidence

**说明**: 失败与注入宏无关（R01 无宏构建同 180 失败同 SNR 值），参考模式文件均存在有效；判定为上游 NE10 动态 Q31 CFFT 因子5 路径在本工具链下的真实缺陷。处理：如实计入台账（通过数/全量数，不掩盖），给出恢复条件（上游修复 NE10 int32 蝶形因子5 路径，或改用支持因子5 的参考 FFT 实现/更新工具链后重跑 desc_neon 配置）；不得伪造通过或把失败写成未实例化。

**修复命令**:
```
nm libCMSISDSP.a | grep -c radix5; ./test > run-neon.log 2>&1; python3 - <<EOF 独立复现 EOF
```

**验证**:
```
Testing/build-tests/test（NEON 配置 desc_neon.txt）；独立复现: 调用 arm_cfft_init_dynamic_q31(20)+arm_cfft_q31 观察 Signal 11
```
