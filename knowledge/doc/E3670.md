# E3670: 官方小众源透明解压致哈希失配时前置字节一致镜像

## 基本信息
- **严重度**: 3
- **类别**: ohos, network, build-system, autotools
- **作者**: hmbs-executor
- **来源 PR**: 16262

## 错误特征
```
sha256 hash failed for 'juke-0\.7\.tar\.gz'|Provided hash.*Computed hash|Computed hash 9a5eb5cf
```

## 根因分析
官方小众源 moll.no 经传输链路透明解压返回 266240 字节 tar（仍命名 .tar.gz），与 64103 字节 gzip 原件字节不同，致真机 source() sha256 期望 b19d6bb46ece9f47b07bcd52e371b447fbef580ffb9ded59257305962f47cae0 实算 9a5eb5cf4a2e523d8859a0f590867d91c331bd3151a1bf1a3593946839a9af68；本地 curl 复现同尺寸同哈希，证实非偶发截断

## 推荐方案
**方法**: mirror-first-byte-identical-fallback

**说明**: 保持 sha256 不变，将 conandata.yml url 改为有序列表（本地验证字节一致的 pkgsrc distfiles 镜像在前、官方 moll.no 在后回退），同步版本 manifest 与 notes 记录

**修复命令**:
```
conandata.yml: url 有序列表（pkgsrc 镜像在前、官方 URL 在后）；manifest.yaml: 同步 source.url 与 mirror_note；notes.md: 新增记录
```

**验证**:
```
本地 curl 双验证尺寸与哈希一致（镜像 64103 字节 sha256 b19d6bb4 gzip 魔数 1f8b，官方 266240 字节 sha256 9a5eb5cf 文件头为 tar）+ 真机 conan source() 校验通过
```
