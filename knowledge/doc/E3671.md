# E3671: Autotools vendored noinst归档静态悬空补交付与过期测试PKI保扩展续期加单套件隔离计数

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, autotools, testing
- **作者**: hmbs-executor
- **来源 PR**: 16798

## 错误特征
```
/data/service/hnp/bin/bash: inaccessible or not found|ld\.lld: error: undefined symbol: .*_s|duplicate symbol: client_cert|CUnit suites total=.*ran=.*|subject name is expected to be in the format
```

## 根因分析
vendored safe_c_stub以noinst_LIBRARIES构建不被make install交付致静态libest.a的*_s符号悬空，叠加OHOS profile注入不可执行HNP bash致configure重exec失败、OpenSSL 3.x移除FIPS_mode_set、库侧--enable-brski与测试侧-DENABLE_BRSKI失配、测试PKI于2026-06-14过期且裸续签丢失v3_ca扩展致链断裂崩溃

## 推荐方案
**方法**: vendor-noinst-deliver-plus-pki-renew-isolate

**说明**: package补拷safe_c_stub归档为lib/libsafe_lib.a并libs追加safe_lib，改写conanbuild.sh硬编码SHELL并用/bin/sh显式驱动configure，测试域预编译FIPS桩，保持v3_ca扩展同密钥续期PKI并单套件隔离运行CUnit

**修复命令**:
```
archives/l/libest/3.2.0/conanfile.py: package补交付safe_lib与FIPS stub、build显式SHELL驱动与--enable-brski对齐、_renew_upstream_test_pki保扩展续期与run_one_suite隔离；test_package/: ctest单源计数
```

**验证**:
```
真机conan create全绿并保留lib/libsafe_lib.a交付与HMBS_TEST_PACKAGE_RESULT passed及HMBS_UPSTREAM_TEST_RESULT单套件隔离计数恒等式校验
```
