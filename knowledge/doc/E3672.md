# E3672: CMake 带 VERSION/SOVERSION 的共享库在 HarmonyOS HMDFS 上创建符号链接失败，需去版本号产扁平 .so

## 基本信息
- **严重度**: 3
- **类别**: posix, cmake, conan, filesystem, library
- **作者**: gcw_6YxinkyD
- **来源 PR**: ""

## 错误特征
```
failed to create symbolic link.*\.so|cmake_symlink_library.*Permission denied|libfreenect\.so\.[0-9].*Error
```

## 根因分析
CMake 给 SHARED 目标设置 VERSION/SOVERSION 后会生成 libx.so.major.minor 真文件并创建 libx.so.major->真文件、libx.so->libx.so.major 符号链接；HarmonyOS 真机 /storage 为 HMDFS，不支持 symlink(2)，cmake_symlink_library 返回 Permission denied，链接阶段失败（源码与编译均正常）。

## 推荐方案
**方法**: drop-versioning-flat-shared-lib

**说明**: 在配方 source() 中用 replace_in_file 移除 CMakeLists.txt 里 SHARED 目标的 set_target_properties(... VERSION ... SOVERSION ...)，让 CMake 只产扁平 libx.so；package_info.libs 仍按库名声明。同时对上游自定义 Find*.cmake，识别其复数 cache 变量短路点，在 generate() 直接写入 conan 依赖包的 include/lib 路径。

**修复命令**:
```
source(): replace_in_file(cmake, "set_target_properties ( freenect PROPERTIES\\n  VERSION ...\\n  SOVERSION ...)", "# dropped: HMDFS no symlinks"). generate(): tc.cache_variables["LIBUSB_1_INCLUDE_DIRS"]=...; tc.cache_variables["LIBUSB_1_LIBRARIES"]=...
```

**验证**:
```
conan create --profile:h=ohos-aarch64-fixed 成功；package/lib/ 下为扁平 libfreenect.so 与 libfreenect_sync.so（无 .so.N 软链）；test_package 中 test_freenect 调用 freenect_init/num_devices/shutdown、test_sync 调用 freenect_sync_stop 均实跑通过。
```
