# E3675: 老旧 CMake 2.x 项目同时构建 shared+static 同名库且依赖 pkg-config 的适配模式

## 基本信息
- **严重度**: 3
- **类别**: ohos, cmake, conan, pkg-config, legacy-build
- **作者**: gcw_6YxinkyD
- **来源 PR**: TBD

## 错误特征
```
pkg_check_modules.*not found|Compatibility with CMake < 3.10|FileNotFoundError.*patches/|install.*DESTINATION.*/lib/
```

## 根因分析
CMake 4.x 不兼容 cmake_minimum_required(VERSION 2.6) 等旧版本声明，需设置 CMAKE_POLICY_VERSION_MINIMUM=3.5；headless OHOS 环境无 pkg-config 和系统 .pc 文件，上游 pkg_check_modules 直接 FATAL_ERROR；上游 CMakeLists 同时构建 shared 和 static target 且 OUTPUT_NAME 相同，Conan 的 BUILD_SHARED_LIBS 无法切换；Conan 2.x 要求 exports_sources 和 export_conandata_patches 双重声明才能将补丁导出到构建目录；上游 install(DESTINATION /lib/...) 在无 root 权限下失败。

## 推荐方案
**方法**: conan-cache-vars-plus-conditional-patch

**说明**: 在 generate() 中用 CMakeToolchain 注入 CMAKE_POLICY_VERSION_MINIMUM=3.5 和依赖的 INCLUDE_DIRS/LIBRARIES 缓存变量；打补丁将 pkg_check_modules 替换为变量检查、将 add_library 改为 BUILD_SHARED_LIBS 条件分支、移除绝对路径 install；类属性声明 exports_sources="patches/*" 并在 export_sources() 中调用 export_conandata_patches(self)。

**修复命令**:
```
tc.cache_variables["CMAKE_POLICY_VERSION_MINIMUM"]="3.5"; tc.cache_variables["<DEP>_INCLUDE_DIRS"]=os.path.join(dep.package_folder, dep.cpp_info.includedirs[0]); tc.cache_variables["<DEP>_LIBRARIES"]=os.path.join(dep.package_folder, dep.cpp_info.libdirs[0], "lib<dep>.so"); exports_sources="patches/*"; export_conandata_patches(self)
```

**验证**:
```
conan create 成功，test_package 通过 C API 调用验证库可用；patches 干净应用无 hunk 失败；package/ 下无 /lib/udev 等系统绝对路径产物。
```
