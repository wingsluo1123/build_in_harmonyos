# E3676: 自研（非 autoconf 生成）configure 脚本按相对路径检查 config.d/config.config，要求 CWD=源码根目录；Conan 配方必须就地构建（cwd=source_folder），不能用 Autotools helper 默认构建目录

## 基本信息
- **严重度**: 2
- **类别**: build-system, configure, conan
- **作者**: pc4-29 <noreply@atomgit.com>
- **来源 PR**: pending

## 错误特征
```
Directory config\.d not found\. Run configure from the source root|config\.d not found|run configure from the source root|Cannot find config\.config
```

## 根因分析
magicrescue 等上游自带 hand-written configure 脚本（非 autoconf 生成，无 configure.ac/Makefile.am），脚本用 `[ -d config.d ] || echo "Directory config.d not found. Run configure from the source root."` 这类相对路径检查（config.d/、config.config），只支持在源码根目录就地运行。Conan 2.x Autotools helper 的 configure() 在构建目录（build_folder）下执行 configure，相对路径检查必然失败，表现为 G2 conan create 直接报 "Directory config.d not found"。

## 推荐方案
**方法**: in-source-configure-make

**说明**: 配方 build() 直接用 self.run() 在 source_folder 内就地运行 configure + make（cwd=self.source_folder，env="conanbuild"），绕过 Autotools helper 的构建目录执行；package() 用 make install DESTDIR=package_folder。configure 参数保持最少化（--prefix=/）。

**修复命令**:
```
|
```

**验证**:
```
grep -nE 'config\.d|source root|config\.config' configure | head; conan create <recipe> -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing（复现 "Directory config.d not found"）
```
