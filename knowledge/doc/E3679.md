# E3679: CMake 对 HarmonyOS 平台提示 unknown 且 Conan 消费者测试需验证被测包安装的 CLI 工具

## 基本信息
- **严重度**: 3
- **类别**: posix, cmake, conan, cli-tool, consumer-test
- **作者**: wingsluo
- **来源 PR**: 7698

## 错误特征
```
System is unknown to cmake.*Platform/HarmonyOS|nngcat.*not found|command not found.*nngcat
```

## 根因分析
CMake 对 HarmonyOS/OHOS 系统名没有内置 Platform/HarmonyOS.cmake 模块，配置时输出 "System is unknown to cmake, create: Platform/HarmonyOS"；对于不依赖 Linux 专有平台逻辑的 POSIX C/C++ 库（如 NNG），该提示不阻止构建，但需确认 Conan CMakeToolchain 已正确注入工具链。当库同时交付静态库和 CLI 工具时，Conan test_package 需验证消费者能通过 CMake target 链接库，且能执行安装后的可执行文件；直接执行命令名（如 "nngcat --version"）会因 PATH 未包含被测包的 bin/ 而失败。

## 推荐方案
**方法**: conan-toolchain-plus-absolute-cli-path

**说明**: 在 Conan 配方 generate() 中使用 CMakeToolchain 注入 Conan 工具链，显式配置 BUILD_SHARED_LIBS、<PROJ>_TESTS、<PROJ>_TOOLS 等；package_info() 声明 cpp_info.bindirs = ["bin"]；test_package 通过 self.dependencies["<pkg>"].package_folder 和 cpp_info.bindirs[0] 拼接被测 CLI 的绝对路径后以 self.run() 执行，而不是依赖 PATH。

**修复命令**:
```
conanfile.py generate(): tc.variables["BUILD_SHARED_LIBS"] = "ON" if self.options.shared else "OFF"; tc.variables["NNG_TESTS"] = "OFF"; tc.variables["NNG_TOOLS"] = "ON". package_info(): self.cpp_info.bindirs = ["bin"]. test_package: nngcat = os.path.join(dependency.package_folder, dependency.cpp_info.bindirs[0], "nngcat"); self.run(f'"{nngcat}" --version', env="conanrun")
```

**验证**:
```
conan create 成功后，test_package 应能通过 CMake target 链接被测库并运行 API smoke test；CLI 工具应通过 self.dependencies["<pkg>"].package_folder 和 cpp_info.bindirs[0] 定位后以绝对路径执行并返回 0。
```
