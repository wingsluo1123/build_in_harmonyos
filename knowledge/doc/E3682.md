# E3682: 上游零add_test时配方侧注入CTest注册与无SysV无SSL鸿蒙下Qt库的IPC替换及去守卫适配

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, syscall, socket, network
- **作者**: hmbs-executor
- **来源 PR**: 17083

## 错误特征
```
No tests were found!!!|SIGSYS\*\*\*Exception|no member named 'setMailAuthentication' in 'ImapConfigurationEditor'|no member named 'Encrypt_SSL' in 'QMailTransport'|Failed to bind socket.*Read-only file system
```

## 根因分析
上游tests仅add_executable零add_test致No tests were found；鸿蒙内核无SysV IPC致QSystemSemaphore触发不可捕获SIGSYS；OHOS qtbase为QT_NO_SSL变体致纯键值配置与Encrypt_SSL枚举被守卫缺成员；只读tmp加长路径超sun_path致dbus会话bind失败

## 推荐方案
**方法**: inject-ctest-qmutex-unguarding-abstract-dbus

**说明**: 配方侧解析tests动态注入29项add_test并WORKING_DIRECTORY指向各用例源码目录；OHOS下以进程内QMutex注册表替换locks.cpp的QSystemSemaphore；剥离纯配置QT_NO_SSL守卫并常驻Encrypt_SSL枚举；dbus最小配置改用unix abstract套接字绕过只读tmp与108字符上限

**修复命令**:
```
conanfile.py新增_patch_register_qmf_tests/_patch_locks_qmutex_on_ohos/_patch_qt_no_ssl_config/_patch_transport_encrypt_enum/_ensure_dbus_session抽象套接字；build()顺序调用；MANIFEST.yml披露harness接入与ohos_feature缺口
```

**验证**:
```
真机conan create后检查build/ctest_upstream.log含29项真实执行与HMBS_UPSTREAM_TEST_RESULT discovered=29 executed=29及dbus abstract套接字拉起与messageserver注册日志；test_package编译链接通过
```
