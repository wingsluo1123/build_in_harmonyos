# E3683: 双远端共存下裸依赖命中CCI cmake边时切换仓内独有后缀版本切断失败边

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, cmake
- **作者**: hmbs-executor
- **来源 PR**: 15035

## 错误特征
```
KeyError: 'OHOS'|cmake/4\.4\.4.*build\(\).*line ?35
```

## 根因分析
requires裸libxml2/2.15.3在conancenter与ohpcd双远端共存，真机预检conancenter优先命中CCI配方，其tool_requires cmake的conandata无OHOS条目，从源码构建cmake/4.4.4 build() line35报KeyError OHOS，本体尚未进入编译

## 推荐方案
**方法**: switch-to-suffixed-inhouse-version

**说明**: 将裸依赖切换到仓内同上游源码的适配后缀独有版本，切断CCI配方经tool_requires拉起无OHOS条目cmake的失败边并同步两级manifest与注释

**修复命令**:
```
conanfile.py: self.requires("libxml2/2.15.3.1")并注释CCI边依据；同步archives/r/rarcrack/manifest.yaml、版本manifest.yaml、notes.md
```

**验证**:
```
真机conan create依赖图仅命中仓内libxml2/2.15.3.1零tool_requires，不再拉起CCI cmake失败边且真机门禁全部通过
```
