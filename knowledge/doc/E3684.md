# E3684: profile钉死SHELL/CONFIG_SHELL下configure脚本内自净与daemon分套件串行回收及声明发现差值归因

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, autotools, testing
- **作者**: hmbs-executor
- **来源 PR**: 15693

## 错误特征
```
configure\[147\]: /data/service/hnp/bin/bash: inaccessible or not found|configure: error: C compiler cannot create executables|HMBS_UPSTREAM_TEST_RESULT=\{[^}]*"discovered": 15|FAIL: tests/rwflowappend-append-bad.pl
```

## 根因分析
ci/conan/profiles/ohos-aarch64以[buildenv]把SHELL/CONFIG_SHELL钉死为沙箱不可执行的/data/service/hnp/bin/bash，每次run()经conanbuild重聚合覆盖配方进程env与generate()覆盖层，autoconf configure经$CONFIG_SHELL重执行故在147行以127失败；单一顶层make check使daemon孤儿累积致末段SIGKILL/exit137与install期EAGAIN fork失败；configure自动关闭可选特性致声明1574与发现1521差53未被覆盖

## 推荐方案
**方法**: configure-script-selfclean-plus-per-suite-reap

**说明**: 不抢环境层而改configure脚本内容自净CONFIG_SHELL为可执行shell；分套件串行make check加套间daemon回收并以轻重分级并发压缩墙钟；声明与发现差值以undiscovered environment缺口补齐并放行被覆盖的SKIP

**修复命令**:
```
conanfile.py: _patch_configure_shell改写全部configure并同步SHELL，_run_upstream_tests逐套make -C check -j1/-j4加_cleanup_test_daemons，marker追加undiscovered environment gap；test_package/conanfile.py: 门禁改为gaps合计==failed+skipped+undiscovered且environment覆盖skipped+undiscovered
```

**验证**:
```
真机conan create核对configure越过147行且HMBS_UPSTREAM_TEST_RESULT以test-suite.log聚合discovered/executed/passed/failed/skipped加environment gaps覆盖skipped加undiscovered并满足declared-minus-passed恒等式；对照HMBS_PLATFORM_CAPABILITIES shell=/bin/sh与jobs=1
```
