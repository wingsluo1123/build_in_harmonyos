# E3692: KF6 6.18 闭包 registry 二进制漂移导致 conan graph 报 Missing packages: kiconthemes

## 基本信息
- **严重度**: 2
- **类别**: compat, build-system, cmake, conan, dependency
- **作者**: 7D29
- **来源 PR**: (本 PR)

## 错误特征
```
Missing packages: kiconthemes | WARN: There are some error\(s\) in the graph
```

## 根因分析
registry 上同名同版本包的**二进制**被后续重建为依赖另一条 karchive 版本线（kiconthemes/6.18.0 → karchive/6.19.0），而 KF6 6.18 闭包其余成员（knewstuff/6.18.0、kxmlgui/6.18.0）仍按 karchive/6.18.Z 解析；配方按 libkdegames 闭包 pin karchive/6.18.0 后，kiconthemes/6.18.0 计算出的 package_id 在制品仓不存在 → graph 报 Missing packages（注意：不是版本冲突，recipe 与 binary 都存在，只是 package_id 对不上）

## 推荐方案
**方法**: pin-karchive-618Z-built-kiconthemes-revision

**说明**: 选与 karchive 6.18.Z 同源构建的修订 kiconthemes/6.18.0.1 并 override=True，

**修复命令**:
```
self.requires("kiconthemes/6.18.0.1", override=True)
```

**验证**:
```
conan graph info <recipe> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --format=text | grep -A2 'Missing packages'
```
