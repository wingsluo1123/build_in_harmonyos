# E3694: 使用供应方LAPACK宏保留Fortran字符参数和整数ABI契约

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, headers
- **作者**: 8A28

## 错误特征
```
no matching function for call to '[ds]tptri_'|requires 7 arguments, but 5 were provided|LP64_REQUIRED|BLAS_LAPACK_WIDTH_MISMATCH
```

## 根因分析
C/C++消费方硬编码下划线符号和旧CLAPACK原型，与所链接供应方头文件规定的隐藏CHARACTER长度或整数宽度不一致。更换声明使编译通过本身不证明二进制ABI一致。

## 推荐方案
**方法**: vendor-lapack-macros-and-integer-contract

**说明**: 保留实际依赖包的lapacke.h/lapack.h，将name_调用替换为LAPACK_name，采用lapack_int并校验blasint及消费方索引宽度。先以负向编译证明差异，再用独立数值残差、错误路径和上游全量测试验证。

**修复命令**:
```
bash archives/k/kaldi-vosk/g20231219/knowledge-reproducer/run.sh OPENBLAS_PACKAGE_PREFIX
```

**验证**:
```
bash archives/k/kaldi-vosk/g20231219/knowledge-reproducer/run.sh OPENBLAS_PACKAGE_PREFIX
```
