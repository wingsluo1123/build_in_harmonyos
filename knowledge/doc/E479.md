# E479: ci/conan/build_and_test.sh G0a 门禁 zsh 空目录 null-glob 误报：knowledge/graph/draft/ 为空目录时，zsh null-glob `(N)` 把整条 glob 单词移除，ls 回退列 cwd，把仓库根 31 个顶层条目误数成草稿数，任何软件 finish W3 都会 G0 硬失败

## 基本信息
- **严重度**: 3
- **类别**: framework
- **作者**: 81E1

## 错误特征
```
G0a: knowledge/graph/draft/ 目录存在 31 个草稿 — 草稿只能放在 knowledge/drafts/
```

## 根因分析
ci/conan/build_and_test.sh 的 G0a 检查用 zsh null-glob：ls -1 "${GRAPH_DIR_G0}/draft"/*.kv(N)。当 knowledge/graph/draft/ 目录存在但为空（无 .kv 文件）时，(N) null-glob 会把整个单词（含目录路径）移除，命令退化为裸 ls -1（无参数）→ 列出当前工作目录（= 仓库根，31 个顶层条目），wc -l = 31 → 误报 31 个草稿并 G0 硬失败，阻塞所有软件（与本包无关）的 finish W3。zsh 的 (N) 空匹配行为与 bash 不同：bash 中未匹配的 glob 保持字面量导致 ls 报 No such file（0 计数），zsh 则静默删除整个单词。

## 推荐方案
**方法**: 框架层修复（单独 PR 改 ci/conan/build_and_test.sh）：把计数命令改为不会退化为裸 ls 的写法，例如 ls -1d "${GRAPH_DIR_G0}/draft"/*.kv(N) 2>/dev/null | wc -l（-d 防止空 glob 回退），或改用 find "${GRAPH_DIR_G0}/draft" -maxdepth 1 -name "*.kv" | wc -l。协作子任务遇此故障（禁止改 ci/）：删除空的 knowledge/graph/draft/ 目录（未跟踪的空目录，框架自身 G0a/graph.py C12 也要求其不存在），然后重跑 finish 即可解除阻塞；该目录为空时删除不改变任何文件内容。

**说明**: G0a 计数命令加 -d 防空 glob 回退，或改 find 计数

**修复命令**:
```
rmdir knowledge/graph/draft   # 协作子任务解除阻塞用（仅当目录为空）
```

**验证**:
```
zsh -c 'ls -1 "${REPO_ROOT}/knowledge/graph/draft"/*.kv(N) 2>/dev/null | wc -l' —— 当该目录存在且为空时返回仓库根条目数（本仓库为 31）而非 0
```
