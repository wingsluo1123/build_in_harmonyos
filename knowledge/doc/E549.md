# E549: colord 混合打包：daemon=false 禁用 daemon 但保留 client CLI（colormgr/cd-iccdump 等），产物含 bin/ 须声明 commands.json（type=tool）

## 基本信息
- **严重度**: 2
- **类别**: build-system, packaging, portability
- **来源事件**: colord 1.4.8 HarmonyOS 适配（archives/c/colord/1.4.8，已发布制品仓）
- **提升日期**: 2026-10-05
- **关联条目**: E545（同源 libcolord 纯库包适配，跳过 client/ 子目录、无需 commands.json）——两条为同一上游仓库的两种打包形态，按目标产物是库还是含 CLI 选择

## 错误特征
```
daemon=false.*colord|colord.*client.*subdir|colormgr|cd-iccdump
```

## 根因分析
colord 上游同一仓库产出 daemon（src/，依赖 polkit/libudev/libsystemd，OHOS 均无）、客户端 CLI 工具（client/：colormgr、cd-iccdump、cd-fix-profile 等）与客户端库 libcolord/libcolordprivate。OHOS 适配以 `-Ddaemon=false` 禁用 daemon，但保留 client/ 子目录：CLI 工具无 D-Bus 运行时依赖，PC 端色彩管理可直接使用。产物含 bin/ 可执行文件，按 R38 必须在软件级目录（archives/c/colord/）声明 commands.json（type=tool），conanfile 的 package_info 同步暴露 bindirs。

## 推荐方案
**方法**: daemon-off-keep-client-cli

daemon 依赖 polkit/udev/systemd 等 OHOS 缺失能力时 `-Ddaemon=false` 禁用 daemon，保留 client CLI 工具并声明 commands.json（type=tool）；CLI 无 D-Bus 依赖可独立使用。

## 实施记录（colord 1.4.8）
详见 archives/c/colord/1.4.8/notes.md 与 conanfile.py（`tc.project_options["daemon"] = "false"`、`self.cpp_info.bindirs = ["bin"]`），软件级 archives/c/colord/commands.json。

## 验证
```bash
test -f archives/c/colord/commands.json && grep -n 'bindirs' archives/c/colord/1.4.8/conanfile.py && grep -n "daemon.*false" archives/c/colord/1.4.8/conanfile.py
```
