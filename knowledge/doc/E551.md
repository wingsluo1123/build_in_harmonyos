# E551: 上游只发 configure.ac/Makefile.am 时在 OHOS 的自举三要点：tool_requires(automake/1.18)、分步 aclocal→autoconf→automake（禁 autoreconf）、经 $ACLOCAL/$AUTOMAKE 调用包装脚本

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, conan
- **作者**: unknown, ffieldd22_-, parasail-2.6.2 任务执行体（容器层 Agent）
- **来源 PR**: wmcdplay 1.1 适配

## 错误特征
```
aclocal: *(Permission denied|not found|command not found)|automake: *(Permission denied|not found)|autoconf: error: undefined macro AM_|autoreconf: autoconf\.m4f|configure: error: cannot find install-sh
```

## 根因分析
上游 tarball 未发布生成物 + OHOS 镜像缺 automake + autoreconf 的 m4 链在

## 推荐方案
**方法**: tool-requires-automake-plus-stepwise-bootstrap

**说明**: build_requirements() 声明 automake/1.18；generate() 里 VirtualBuildEnv

**修复命令**:
```
self.tool_requires("automake/1.18")  # build_requirements()
```

**验证**:
```
command -v automake || echo "no system automake (需 tool_requires)"; ls "$(conan profile show 2>/dev/null >/dev/null; echo)"; "${ACLOCAL:-aclocal}" --version
```
