# E552: automake 只把 AM_CFLAGS 传给 C 编译，C++ 源收不到 pkg-config 的 -I；须补 AM_CXXFLAGS

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools, cxx
- **作者**: unknown
- **来源 PR**: wmcdplay 1.1 适配

## 错误特征
```
fatal error: '.*' file not found|X11/X\.h.*file not found|X11/Xlib\.h.*file not found
```

## 根因分析
automake 对 C 与 C++ 使用不同的内建编译变量族；上游把"依赖注入变量"错误地

## 推荐方案
**方法**: add-am-cxxflags

**说明**: Makefile.am 增加 AM_CXXFLAGS，值与 AM_CFLAGS 一致；随后自举并确认 C++

**修复命令**:
```
AM_CXXFLAGS = $(x11_CFLAGS) $(xpm_CFLAGS) $(xext_CFLAGS)   # Makefile.am
```

**验证**:
```
grep -n "AM_CFLAGS\|AM_CXXFLAGS" Makefile.am; make V=1 2>&1 | grep -m1 "clang++\|g++"
```
