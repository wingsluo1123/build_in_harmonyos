# E553: X11 dockapp 上 OHOS 三连：libx11 的 x11.pc prefix=/ 不可重定位（须靠 AutotoolsDeps cpp_info 注入真实路径）、C++11 把 "... "MACRO 词法成用户自定义字面量、--host=aarch64-linux-ohos 是进入交叉模式的开关

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, cross-compile, cxx, x11
- **作者**: unknown
- **来源 PR**: wmcdplay 1.1 适配

## 错误特征
```
'X11/Xlib\.h.*file not found|-I//include|invalid suffix on literal|checking whether we are cross compiling\.\.\. no'
```

## 根因分析
三个独立的平台/标准差异被同一条构建链放大：不可重定位 pc 文件、C++11 词法

## 推荐方案
**方法**: cpp-info-injection-plus-space-out-macros-plus-host-triplet

**说明**: generate() 用 AutotoolsDeps 提供真实 include/lib；补丁为字符串字面量与

**修复命令**:
```
self._toolchain.configure_args.append("--host=aarch64-linux-ohos")
```

**验证**:
```
pkg-config --variable=prefix x11; llvm-readelf -h <bin> | grep Machine; grep -n 'cross compiling' config.log
```
