# E554: conan create 报 "aclocal: Permission denied"(rc=126) 的真因：以 $HOME/usr/local/bin/python3（HMDFS 解释器）启动的进程，其子进程 execve 系统根以外的任何路径（含 ELF）一律 EACCES；改用应用包内 python 启动 conan 即可

## 基本信息
- **严重度**: 2
- **类别**: ohos, conan, environment, sandbox
- **作者**: unknown
- **来源 PR**: wmcdplay 1.1 适配（本地验证链）

## 错误特征
```
Permission denied.*bin/aclocal|Error 126 while executing|bad interpreter.*safe-bin|SAFE_DELETE_BULK_GUARD_ERROR
```

## 根因分析
沙箱按进程启动解释器路径划分 exec 域：HMDFS 上的解释器（$HOME/usr/local/bin/

## 推荐方案
**方法**: run-conan-through-bundle-python

**说明**: 用应用包内 python（/data/storage/el1/bundle/libs/arm64/python/bin/python3）

**修复命令**:
```
unset BASH_ENV; PYTHONPATH=$HOME/usr/local/lib/python3.12/site-packages
```

**验证**:
```
python3 -c "import subprocess;subprocess.run(['/data/storage/el2/base/cache/conan-home/p/*/p/bin/aclocal','--version'])"
```
