# E557: "Keep the baked runtime path pointing at the final in-packag

## 基本信息
- **严重度**: P1
- **类别**: packaging
- **作者**: unknown

## 错误特征
```
"packaged default database missing|unable to open rgb database \"/[a-z]|install.*<pkg>.*<pkg>/share"
```

## 根因分析
"Conan's Autotools.install() installs via --destdir=<package_folder>, so every install directory coming from configure (--prefix and any explicitly absolute --with-*-dir) is treated as a path RELATIVE to the destination root and gets the package_folder prefixed onto it. When a recipe simultaneously bakes an absolute runtime path into the binary (to make a compiled-in default data location work) the two mechanisms fight: the data file lands at <pkg>/<pkg>/share/... instead of <pkg>/share/..., so the binary's compiled-in default can never be satisfied and the packaged data file appears to be missing."

## 推荐方案
**方法**: "Keep the baked runtime path pointing at the final in-package location (self.package_folder is already known in generate()), and in package() relocate the installed data file back to the canonical path under package_folder, then prune the duplicated absolute-path shell directory created by the destdir overlap. Do not try to solve it by making the baked path relative - the compiled-in string must match the file's real location at run time."
