# E560: automake per-target `*_CPPFLAGS =`（空值）替换 AM_CPPFLAGS：VPATH 构建下该目标的 -I 全丢，头文件找不到

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools, automake, flags, vpath
- **作者**: SunShine_06
- **来源 PR**: 10251

## 错误特征
```
^[A-Za-z_]+_(la_)?CPPFLAGS\s*=\s*$|
```

## 根因分析
automake 的 AM_CPPFLAGS 只是"默认值"，不是"追加值"：

## 推荐方案
**方法**: refill-per-target-vars-on-make-command-line

**说明**: make 命令行回填 per-target 变量——命令行变量优先级高于

**修复命令**:
```
make -C <subdir> <target>_CPPFLAGS="-I<src> -I<build>"
```

**验证**:
```
cd <cutter-build> && make V=1 2>&1 | head -5
```
