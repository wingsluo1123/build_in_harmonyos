# E565: conan create 在依赖二进制包下载阶段报 "Response ended prematurely"（ohpcd 制品仓传输中断）——环境网络问题，发生在 build() 之前，与配方/源码无关

## 基本信息
- **严重度**: 2
- **类别**: network, conan, dependency, registry
- **作者**: unknown

## 错误特征
```
Response ended prematurely|Download failed, check server, possibly try again|ConanConnectionError|Exception while getting package
```

## 根因分析
conan create 安装 tool_requires/build_requires 的预编译二进制包时，从 ohpcd 制品仓（conan.cnb.cool）拉取 conan_package.tgz 的 HTTP 传输被中途断开（urllib3 "Response ended prematurely"，服务端提前关闭连接/链路抖动），重试仍失败即抛 ConanConnectionError 终止构建。该失败发生在 "Downloading binary packages"（依赖安装阶段）、recipe build() 之前，配方与源码尚未参与，因此不是配方缺陷。典型触发：CI worker 缓存为空需全量下载、目标包体积较大（如 perl/5.42.2 二进制 17MB）、worker 到制品仓网络链路不稳定。puredata/0.54.1 CI #59420 实测：perl/5.42.2 的 17MB 包下载两次均 "Response ended prematurely"，同批其余 4 个小包（autoconf/automake/libtool/m4）全部正常 → 判定为传输中断而非制品缺失；同一包从正常网络路径 15 秒下载成功。

## 推荐方案
**方法**: verify-infra-then-retry

**说明**: 三步定位+重跑：① 看 conan create 日志确认失败发生在 "Downloading binary packages"（install 阶段、build() 之前）→ 排除配方问题；② 用全新 CONAN_HOME conan download 验证同一包当前可下载 → 确认制品仓健康；③ CI 评论 /rebuild 触发重跑（R42：CI 是评论触发型，push 本身不触发 CI）。瞬时网络中断重跑通常转绿，无需任何配方修改。

**修复命令**:
```
CONAN_HOME=$(mktemp -d) conan download "perl/5.42.2#13c4f5bde5668df0b7268c4d0c01073c:6b129b068851896169fae42d399fa922d239ce8a" -r ohpcd；PR 评论 /rebuild 触发 CI 重跑。
```

**验证**:
```
用全新缓存强制走远程下载验证制品仓健康：CONAN_HOME=<fresh-dir> conan remote add ohpcd https://conan.cnb.cool/OpenHarmonyPCDeveloper/Conan/-/packages/ && CONAN_HOME=<fresh-dir> conan download "<pkg>#<recipe_rev>:<package_id>" -r ohpcd；成功=制品仓健康、纯瞬时网络问题；配方本身用本地缓存 conan create 验证（下载失败点早于 build()，配方逻辑未被执行）。
```
