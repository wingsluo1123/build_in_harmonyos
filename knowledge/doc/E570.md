# E570: Samba wafsamba standalone libraries on OHOS: PYTHON-driven in-tree waf configure/make, non-fatal handling of sandbox-unpassable mandatory runtime probes (/tmp read-only + HMDFS mode normalization), and --disable-python for C-only packages

## 基本信息
- **严重度**: 3
- **类别**: ohos, build-system, configure, python, waf
- **作者**: unknown

## 错误特征
```
The configuration failed|Could not build a python embedded interpreter|unable to find library -lintl|mandatory failure for this one|Checking for HAVE_SECURE_MKSTEMP
```

## 根因分析
Samba-family standalone libraries (tdb/talloc/ldb/tevent) use the bundled Samba waf instead of autotools/cmake. configure is driven by lib/replace probes; several execute=True probes can never pass in the OHOS sandbox: (a) HAVE_SECURE_MKSTEMP hardcodes /tmp (read-only on OHOS, E002) and asserts file mode 0600, but HMDFS normalizes modes to 0640 (chmod ineffective, E046), and upstream marks this probe mandatory=True so configure aborts; (b) the pyembed test links via python3-config --embed flags, and the OHOS python config emits -lintl although musl has no libintl, so that fatal probe fails. The configure/make wrapper scripts additionally require $PYTHON to point at a usable python3 and must run in the source root (IN_LAUNCH_DIR makes the build standalone).

## 推荐方案
**方法**: ohos-wafsamba-standalone-build-policy

**说明**: Drive the build with `PYTHON=python3 ./configure --prefix=<pkg> [--disable-python] && make -jN && make test` from the source root (in-tree standalone build; the wrappers set PYTHONHASHSEED/WAF_MAKE themselves). Convert sandbox-unpassable mandatory runtime probes to non-fatal (patch mandatory=True -> False) and accept the truthful "not found" result so lib/replace builds its bundled replacements; never relax the 0600 assertion or hardcode a device-only path. For C-only packages use the official --disable-python and add a wscript testonly guard so python binding tests are explicitly skipped rather than false-failing.

**修复命令**:
```
PYTHON=python3 ./configure --prefix=${PREFIX} --disable-python && make -j2 && make test
```

**验证**:
```
PYTHON=python3 ./configure --prefix=$PREFIX --disable-python && make -j2 && make test
```
