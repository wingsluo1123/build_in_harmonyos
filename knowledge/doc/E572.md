# E572: qmake 探测目标编译器走 PATH 解析 clang++（不读 CC/CXX 环境变量），CI worker 受限 PATH 下报 "Cannot run target compiler 'clang++'"（输出为空）

## 基本信息
- **严重度**: 3
- **类别**: build-system, qmake, toolchain, environment, path
- **作者**: 11153-KTL
- **来源 PR**: 11153

## 错误特征
```
Project ERROR: Cannot run target compiler 'clang\+\+'|
```

## 根因分析
qmake 的 mkspec（common/clang.conf: QMAKE_CXX = $${CROSS_COMPILE}clang++，

## 推荐方案
**方法**: inline-run-path-prefix

**说明**: build()/package() 的 self.run 命令内联 PATH 前缀（posixsignalmanager

**修复命令**:
```
self.run("PATH=%s/bin:/data/service/hnp/bin:$PATH %s QMAKE_PKG_CONFIG=pkg-config src.pro" % (qt_pkg, qmake), cwd=src_dir)
```

**验证**:
```
CI_PACKAGES="archives/k/knowthelist/2.3.1" zsh ci/conan/build_and_test.sh
```
