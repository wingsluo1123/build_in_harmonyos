# E573: degrade-gracefully

## 基本信息
- **严重度**: 2
- **类别**: runtime, filesystem
- **作者**: unknown

## 错误特征
```
Can't open /proc/diskstats.*Permission denied|
```

## 根因分析
HarmonyOS PC 虚拟化环境将磁盘统计以

## 推荐方案
**方法**: degrade-gracefully

**说明**: 代码级优雅降级: fopen(/proc/diskstats) 失败时

**修复命令**:
```
patch: init_disks() 失败改 fprintf(stderr,...)
```

**验证**:
```
head -c 100 /proc/diskstats  # Permission denied
```
