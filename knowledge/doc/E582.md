# E582: OHOS 内核禁脚本 execve（binfmt_script 缺失）：Kbuild/Kconfig 直接 exec 的辅助脚本一律 EACCES rc=126，改经 sh/$(CONFIG_SHELL) 解释执行（不可改写调用点用同名 ELF 包装器）

- **严重度**: 1

## 错误特征
```
Permission denied.*EACCES|rc=126|exec.*not permitted
```

## 根因分析
OHOS 内核对 execve 的脚本路径（binfmt_script 处理器）
