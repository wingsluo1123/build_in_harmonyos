# E585: 构建树内相对路径假设在打包安装后断裂：argv[0] 目录相对运行时资源（other.dtb）与 CWD 相对测试数据（README）两类显形

## 基本信息
- **严重度**: 2
- **类别**: packaging, testing, relative-path, sandbox
- **作者**: LIMInGZE666 <LIMInGZE666@noreply.gitcode.com>

## 错误特征
```
Cannot open file '.*arch/sandbox/dts/other.dtb'|test_load_other_fdt.*got 0xfffffffb|Test 'membuf_readline' failed.*failures: 1
```

## 根因分析
上游测试/工具二进制默认"在构建树内运行"，其资源解析内嵌构建树布局假设，打包安装后不回放则静默断裂（in-tree 多轮全绿不蕴含包可用）。两类实例：(1) argv[0] 目录相对——sandbox 的 state_load_other_fdt() 经 state_get_rel_filename()（arch/sandbox/cpu/state.c:402，strrchr(argv[0], '/') 取可执行文件目录）拼接 <dir(argv0)>/arch/sandbox/dts/other.dtb；构建树内二进制 build/sandbox/u-boot 与资源 build/sandbox/arch/sandbox/dts/other.dtb 天然相对命中，包内二进制 bin/u-boot-sandbox 下该相对结构不存在 → OF_LIVE 组 15 个单元测试（dm_test_livetree_ensure + 14 个 dm_test_ofnode_*_ot）全部 test_load_other_fdt -5（-EIO）失败，逐子测试日志首行 "Cannot open file '<pkg>/bin/arch/sandbox/dts/other.dtb'"，断言链 test/dm/ofnode.c:1487 / test/test-main.c:385。(2) CWD 相对——test/lib/membuf.c 的 membuf_readline 以 os_read_file("README") 相对 CWD 读测试数据：上游 pytest 的 CWD=源码树根（README 天然在场），打包框架（conan test_package）在独立工作目录回放时该文件缺席 → -EIO → failures: 1。两类路径均无环境变量/命令行可覆盖（other.dtb 纯 argv[0] 相对；README 纯 CWD 相对），显形条件唯一：以包形态在独立 CWD/安装前缀下回放全部子测试。

## 推荐方案
**方法**: mirror-buildtree-layout-in-package

**说明**: 在打包层镜像上游相对布局：把 arch/sandbox/dts/other.dtb 落至包内 <bindir>/arch/sandbox/dts/other.dtb（与二进制保持同相对结构，消费方以任意路径调用 bin/u-boot-sandbox 均可解析）；CWD 相对数据文件（README）将上游源码树逐字节副本随包分发，测试脚本切换到其所在目录运行。第 0 步在位断言把该运行时资源纳入硬校验清单（9→10 项），防打包回归静默丢文件。

**修复命令**:
```
# conanfile.py package(): other_dst = os.path.join(bin_dir, "arch", "sandbox", "dts") / os.makedirs(other_dst, exist_ok=True) / shutil.copy2(os.path.join(sb, "arch", "sandbox", "dts", "other.dtb"), os.path.join(other_dst, "other.dtb"))
```

**验证**:
```
对照组（包内缺 other.dtb）：`u-boot-sandbox -d test.dtb -c "ut dm dm_test_ofnode_get_path_ot; exit"` → Cannot open file + :1487 -5；放置后同命令 → failures: 0（dm_test_livetree_ensure 同）。README 面：工作目录放入随包 README 副本后 `u-boot-sandbox -c "version; ut lib; exit"` → failures: 0（此前 failures: 1）。
```
