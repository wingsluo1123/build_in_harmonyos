# E587: 上游环境文件的宿主特性 #ifdef 门控在非默认配置组合下静默丢测试面：sandbox.env 的 SDL 门控吞掉 usbkbd stdin 条目 → dm_test_usb_keyb 必失败

## 基本信息
- **严重度**: 2
- **类别**: testing, config-matrix, console-input, sandbox
- **作者**: LIMInGZE666 <LIMInGZE666@noreply.gitcode.com>

## 错误特征
```
1 == tstc(): Expected 0x1 (1), got 0x0 (0)|failures: 2|dm_test_usb_keyb
```

## 根因分析
board/sandbox/sandbox.env 把 usbkbd 挂进 stdin 多路复用列表的 `stdin+=,cros-ec-keyb,usbkbd` 由 `#ifdef CONFIG_SANDBOX_SDL` 门控——上游 CI（SDL=y）编译产物 stdin 展开为 serial,cros-ec-keyb,usbkbd，而无 SDL2 宿主（OHOS 初版状态）的构建里该条目整条消失、stdin 只剩 serial。common/usb_kbd.c 的 probe_usb_keyboard() 在注册 stdio 设备后以 `strstr(stdinname, DEVNAME)` 决定是否 `iomux_doenv(stdin, stdinname)` 重跑指派：门恒假 → usbkbd 虽 stdio_register 成功却永不进 console_devices[stdin] → tstc() 永不调用 usb_kbd_testc() → test/dm/usb.c 的 dm_test_usb_keyb 断言 `ut_asserteq(1, tstc())` 在 emul add_string 之后仍得 0，live 遍 :449 失败、flat 遍级联 :433 -ENOENT。KDBG 仪器化实证：usb 匹配/绑定/keyb@3 probe/stdio_register 全链正常（`KDBG puk registered`），唯一断点=kbd probe 时 `KDBG puk stdin='serial'` 不含 usbkbd；同一二进制 `setenv stdin serial,usbkbd` 后单测两遍全过（failures: 0）。即"上游 CI 的绿"只覆盖 CI 自身的配置组合（SDL=y），env 文件里的主机特性门控在其它组合下把整条输入测试面静默移除，且不产生任何构建/启动告警。最终修复取向=回上游同形：本交付经制品仓 sdl2 依赖接入使 CONFIG_SANDBOX_SDL=y，该门控自然命中、usbkbd 条目回归（见 DRAFT-11418-uboot-sandbox-sdl2-registry-dep）；初版专用补丁 0016（#elif 解耦）随之退役、留档为无 SDL 宿主备选。

## 推荐方案
**方法**: adopt-upstream-config-shape (else gate-decouple)

**说明**: 优先让构建回到上游 CI 同形——接入制品仓 sdl2 依赖使 CONFIG_SANDBOX_SDL=y，sandbox.env 的 SDL 分支自然命中、usbkbd 条目回归（见 DRAFT-11418-uboot-sandbox-sdl2-registry-dep）；确无 SDL 可用时才用门控解耦补丁：SDL 分支之外补 `#elif defined(CONFIG_USB_KEYBOARD)` → `stdin+=,usbkbd`。SDL 构建行为逐字节不变；门控语义保持"宿主特性开关"而非"键盘存在性"。

**修复命令**:
```
# 首选：conanfile.py self.requires("sdl2/2.30.10")（PATH/SDL_CONFIG/KCFLAGS 三件套）；备选：sandbox.env #ifdef CONFIG_SANDBOX_SDL / stdin+=,cros-ec-keyb,usbkbd / #elif defined(CONFIG_USB_KEYBOARD) / stdin+=,usbkbd / #endif
```

**验证**:
```
同二进制反向验证：`u-boot -d test.dtb -c "setenv stdin serial,usbkbd; ut dm dm_test_usb_keyb; exit"` → failures: 0（对照组不加 setenv 得 :449 tstc=0）；最终态（sdl2 接入、SDL=y 同形）默认 env 直接 `ut dm dm_test_usb_keyb` → failures: 0 且 printenv stdin 含 usbkbd（真机 run7 全量 919/919 含此例）。
```
