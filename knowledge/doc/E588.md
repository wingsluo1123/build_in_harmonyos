# E588: 适配"缺件"先查平台制品仓：sandbox SDL 测试面以制品仓 sdl2 依赖 + PATH/SDL_CONFIG/KCFLAGS 三件套接线接入（OHOS 另配同名 ELF 包装器消解脚本 execve；替代自写存根/降级裁剪）

## 基本信息
- **严重度**: 2
- **类别**: portability, dependency, kconfig, registry, sandbox
- **作者**: LIMInGZE666 <LIMInGZE666@noreply.gitcode.com>

## 错误特征
```
uclass_first_device_err(UCLASS_VIDEO) -ENODEV|dm_2_dm_test_video_base absent from pairs.txt|CONFIG_VIDEO_SANDBOX_SDL silently n
```

## 根因分析
无系统 SDL2 的宿主上，arch/sandbox/Kconfig 的 HOST_HAS_SDL（def_bool $(success, sdl2-config --version)，Kconfig 解析期探针，要求 sdl2-config 在 PATH）失败 → SANDBOX_SDL 收敛 n → VIDEO_SANDBOX_SDL（depends on SANDBOX_SDL）静默收敛 → SDL 门控的 sandbox_sdl 驱动与 test/dm/video.o、test/boot/{cedit,expo}.o 整片测试面消失（构建零告警），bootstd 菜单类 6 子测试随之在 uclass_first_device_err(UCLASS_VIDEO) 处 -ENODEV。误判路径（本项实踩）：当成"必须自写存根/裁面"→ headless 存根驱动白工且 40 项 SDL 门控子测试被裁。正确接法=平台制品仓已有适配 sdl2/2.30.10（OHOS aarch64 静态构建，含自定位 sdl2-config）：conanfile requires + build() 三件套接线——① PATH 前置 <pkg>/bin（探针命中，决定性开关）；② SDL_CONFIG 钉到包内脚本（arch/sandbox/config.mk 覆盖位，链接取 -L<pkg>/lib -lSDL2）；③ KCFLAGS -I<pkg>/include（sdl2-config --cflags 只给 -I<prefix>/include/SDL2，而源码包含 <SDL2/SDL.h>；Makefile 将 KCFLAGS 并入 KBUILD_CFLAGS，syshdrs 文件自动 -I→-idirafter）。OHOS 第二层障碍：①②均为命令式调用（探针 popen PATH 查找 / $(shell $(SDL_CONFIG) ...)），而 sdl2-config 是 sh 脚本、OHOS 无 binfmt_script 恒 EACCES → 探针仍静默 n（真机 .config 实证；sh <裸名> 亦不可行——busybox sh 对 <script> 操作数不做 PATH 查找）→ 配方层编译同名 ELF 包装器（execv /bin/sh 打开真脚本；置 PATH 前位并钉 SDL_CONFIG；构建期冒烟 --version）后探针翻 y。接入后上游原生驱动与测试面全额回归，env 门控类内容（usbkbd stdin 等）自动回上游同形，自造补丁（0014/0016）全部退役。

## 推荐方案
**方法**: registry-dep-wiring

**说明**: conanfile requirements() 增 `self.requires("sdl2/2.30.10")`（平台制品仓），build() 两次 make 调用共享 env 三件套接线：PATH 前置 <pkg>/bin（Kconfig 探针命中）+ SDL_CONFIG=<pkg>/bin/sdl2-config（链接自定位）+ KCFLAGS=-I<pkg>/include（<SDL2/SDL.h> 包含路径）。接入后上游原生 sandbox_sdl 驱动与全部 SDL 门控测试面回归（headless 安全：show_lcd 默认 false，上游 CI 即 SDL=y headless 形态）。OHOS 上另配同名 sdl2-config ELF 包装器：三件套两处为命令式调用，脚本 execve 禁令下须包装器消解（见 DRAFT-11418-uboot-ohos-no-script-execve）。

**修复命令**:
```
# conanfile.py: def requirements(self): self.requires("sdl2/2.30.10")；build() 为 sandbox 两次 make 调用传 PATH/SDL_CONFIG/KCFLAGS 三件套 env
```

**验证**:
```
交付守卫：`grep -q "^dm_2_dm_test_video_base$" "$U_BOOT_UT_PAIRS"`（test_uboot.sh 第 0d 步，防静默收敛）；真机 `conan create` 全链逐子测试 919/919（879 + 40 项 SDL 门控面）。
```
