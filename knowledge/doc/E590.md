# E590: 裸 Makefile 依赖注入通道判别：未赋值的 CPPFLAGS/LDFLAGS 走环境，已赋值的只能命令行整串接管

## 基本信息
- **严重度**: 2
- **类别**: build-system, make, conan, flag-injection, x11
- **作者**: 主理-64

## 错误特征
```
cannot find -l[A-Za-z0-9_]+|undefined reference to `X[A-Za-z]+'|`[A-Za-z_]+\.h` file not found|ld\.lld: error: unable to find library
```

## 根因分析
手写 Makefile 普遍把搜索路径写成变量再在规则里展开。判别这些变量

## 推荐方案
**方法**: classify-makefile-vars-then-minimal-cmdline-takeover

**说明**: 先跑判据命令把变量分两类，再只对"必须改"的已赋值变量上命令行，

**修复命令**:
```
grep -nE '^[[:space:]]*(CPPFLAGS|LDFLAGS|CFLAGS|CXXFLAGS|LIBS|LIBDIR|INCDIR|CC)[[:space:]]*[:+?]?=' Makefile
```

**验证**:
```
cd <wmcube build 目录> && make -j1 CC=/data/service/hnp/bin/clang LIBDIR= INCDIR= V=1 2>&1 | grep -E ' -I| -L'
```
