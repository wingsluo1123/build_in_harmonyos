# E591: kamailio 多模块配方交叉编译：逐模块钉死外部库探测链（xml2-config/pkg-config 宿主劫持与 LOCALBASE 回退失效）

## 基本信息
- **严重度**: 2
- **类别**: platform, compat, build-system
- **作者**: bbzl <bbzl@noreply.gitcode.com>
- **来源 PR**: 13949

## 错误特征
```
cannot find -lxml2|xml2-config: not found|cannot find -lmnl|cannot find -lssl|xml2-config: command not found|undefined reference to `SSL_|undefined reference to `EVP_|Package libxml-2.0 was not found
```

## 根因分析
模块 Makefile 用 $(shell which xml2-config)/$(shell pkg-config --exists …) 在构建机探测外部库：交叉编译时命中宿主工具链导致 -I/-L 指向宿主路径；探测失败时若只传 LOCALBASE 而未把 XML2CFG/BUILDER 覆盖为空值，?=/$(shell) 已赋值使回退分支不生效；cdp 的 ifneq ($(OS),darwin) 分支在 OS=harmonyos 下恒真，无条件追加 -lssl -lcrypto

## 推荐方案
**方法**: makefile-var-pin-per-module

**说明**: 按模块覆盖 Makefile 探测链入口变量，强制走 conan 前缀分支（0 补丁）：xml2 系 XML2CFG= 空值 + LOCALBASE=<libxml2 前缀>；ims_ipsec_pcscf BUILDER= 空值 + LIBRARY_PATH=<libmnl 前缀>/lib；cdp 显式声明 openssl 依赖并纳入 LIBRARY_PATH；全模块 OS=harmonyos + extra_defs 注入 linux 等价宏集

**修复命令**:
```
make -j1 modules modules="modules/cdp modules/ims_auth …" OS=harmonyos XML2CFG= LOCALBASE=${XML2PREFIX} BUILDER= LIBRARY_PATH=${MNL_PREFIX}/lib:${OPENSSL_PREFIX}/lib extra_defs="${EXTRA_DEFS}"
```

**验证**:
```
readelf -d <module>.so | grep NEEDED   # 与 make 日志中实际生效的 -I/-L 比对；空 NEEDED 表示依赖静态内嵌
```
