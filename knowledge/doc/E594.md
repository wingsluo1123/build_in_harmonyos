# E594: find_package(Curses REQUIRED) cannot be satisfied by a conan ncurses package in a cross build: with CURSES_NEED_NCURSES the module reports "Could NOT find Curses (missing: CURSES_LIBRARY)", and once the recipe hands it the archive via the CURSES_LIBRARY cache variable, `link_libraries(${CURSES_LIBRARIES})` contributes that archive alone - no include directory - so the first `#include <ncurses.h>` fails to compile.

## 基本信息
- **严重度**: 2
- **类别**: cmake, cross-compile, dependency, ncurses
- **作者**: unknown

## 错误特征
```
Could NOT find Curses \(missing: CURSES_LIBRARY\)|fatal error: 'ncurses.h' file not found|Found Curses: .*libncurses
```

## 根因分析
CMake's FindCurses module searches library paths without any sysroot notion, so in a cross build (CMAKE_SYSTEM_NAME=Linux plus an OHOS clang from the profile conf) it never sees the target's ncurses. Seeding CURSES_LIBRARY/CURSES_NCURSES_LIBRARY makes the find succeed, but ${CURSES_LIBRARIES} expands to a bare path: link_libraries() propagates link flags, not include directories, and upstream projects that use it therefore get "fatal error: 'ncurses.h' file not found". Resolving the dependency through the CONFIG package that Conan generates (ncurses::ncurses) carries the include dir, the static libncursesw.a and the link order in one target.

## 推荐方案
**方法**: use-conan-ncurses-config-target

**说明**: Replace `find_package(Curses REQUIRED)` + `link_libraries(${CURSES_LIBRARIES})` with `find_package(ncurses CONFIG REQUIRED)` + `link_libraries(ncurses::ncurses)`. Generate the target with CMakeDeps; the ncurses recipe sets cmake_file_name=ncurses / cmake_target_name=ncurses::ncurses, so the CONFIG file is produced automatically. Drop the CURSES_* cache variables entirely - they are not needed once the CONFIG target resolves, and leaving them in produces a "Manually-specified variables were not used by the project" warning.

**修复命令**:
```
python3 scripts/ohc-run.py refresh-patch --auto <name> <ver>   # after editing CMakeLists.txt in the work tree
```

**验证**:
```
grep -n "CURSES" CMakeLists.txt   # after the patch: no CURSES_* should remain
```
