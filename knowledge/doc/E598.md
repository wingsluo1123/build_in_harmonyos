# E598: "rewrite the .pc prefix next to the build + inject CGO flags

## 基本信息
- **严重度**: 2
- **类别**: build-system, go, conan, pkg-config, cgo
- **作者**: unknown

## 错误特征
```
"cgo: 'pkg-config --cflags --libs libusb-1.0' resolves include/lib paths against /usr/local (system prefix baked into the registry package's lib/pkgconfig/libusb-1.0.pc) instead of the Conan dependency package folder; build picks up host headers or fails with 'libusb.h: No such file or directory'"
```

## 根因分析
"The ohpcd registry libusb/1.0.27 recipe installs via autotools 'make install DESTDIR=<package_folder> prefix='; libtool's pkgconfig file records prefix=/usr/local (the empty --prefix with DESTDIR does not rewrite libdir/includedir in the generated .pc). Any CGO build (#cgo pkg-config: libusb-1.0) that trusts pkg-config therefore gets -I/usr/local/include/libusb-1.0 and -L/usr/local/lib — host paths that do not exist on the OHOS device/CI worker. The conan package_info does ship cpp_info.includedirs/libdirs correctly, but the #cgo directive in the Go dependency (gousb) goes through pkg-config, not through conan generators."

## 推荐方案
**方法**: "rewrite the .pc prefix next to the build + inject CGO flags explicitly"
