# E604: OHOS 真机（HarmonyOS PC）上 Java/Maven 配方构建链四坑：设备无 curl 且 python3 无 CA bundle（Maven 自取必须带 python3 urllib 免证书回退）；HMDFS 禁 shebang 直接 exec（启动脚本必须显式 sh 调用）；asciidoctor/JRuby 在真机报 gemspec ENOENT（纯文档模块需跳过）；真机验证期 ghfast.top 读超时可用本机 http.server 镜像通道（提交配方保持官方 URL）

## 基本信息
- **严重度**: 3
- **类别**: ohos, java, asciidoctor, device, jruby
- **作者**: asus-05

## 错误特征
```
curl: inaccessible or not found|CERTIFICATE_VERIFY_FAILED.*unable to get local issuer certificate|bad interpreter: Permission denied|concurrent-ruby-[0-9.]+\.gemspec.*ENOENT|Error 127 while executing|Error 126 while executing
```

## 根因分析
①OHOS 真机 shell 环境无 curl 二进制（Error 127），且 python3 的 urllib 无 CA bundle——访问 https://repo1.maven.org 报 SSL: CERTIFICATE_VERIFY_FAILED (unable to get local issuer certificate)。Java 配方的 Maven 自取（上游无 mvnw wrapper）若只走 curl 单通道必然失败。②HMDFS 文件系统对带 shebang 的脚本禁止直接 exec()（报 bad interpreter: Permission denied，shell 错误 126）；ELF 二进制不受影响——java 可直接执行，但 mvn 启动脚本必须显式 sh {path}/bin/mvn 调用。③spec-doc 类文档模块的 asciidoctor-maven-plugin（JRuby）在真机 generate-pdf-doc 报 (ENOENT) file:.../concurrent-ruby-1.1.7.gemspec——JRuby 的 RubyGems 解析在 OHOS 文件系统布局下拿不到 gemspec 路径；该模块纯文档产物、不进包，OHOS 上应 -Dasciidoctor.skip=true 跳过（Linux CI 仍全量）。④真机验证期 ghfast.top 注入镜像可能读超时（ReadTimeoutError 30s×2）→ 设备侧临时把 conandata 源指向本机 http.server 镜像（sha256 不变）即可完成验证；提交配方必须保持官方原始 URL（R39）。

## 推荐方案
**方法**: python3-urllib-fallback-plus-sh-mvn-plus-asciidoctor-skip

**说明**: Maven 自取改双通道：先 curl -fsSL，捕获 ConanException 后回退 python3 -c 单行 urllib（ssl._create_unverified_context + build_opener(HTTPSHandler(context=ctx))，下载后 sha256 钉校验兜底完整性）；build() 里 mvn 调用显式 sh {maven_home}/bin/mvn（不放 PATH 依赖 shebang）；settings.os == "OHOS" 时追加 -Dasciidoctor.skip=true（纯文档模块不打包，Linux CI 全量构建不变）。

**修复命令**:
```
self.run('curl -fsSL -o "{}" "{}"'.format(dest, MAVEN_URL)) 包 try/except ConanException → 回退 self.run('python3 -c "import ssl,urllib.request,shutil;ctx=ssl._create_unverified_context();o=urllib.request.build_opener(urllib.request.HTTPSHandler(context=ctx));r=o.open(\'{url}\',timeout=300);f=open(\'{dest}\',\'wb\');shutil.copyfileobj(r,f);f.close();r.close()"')；mvn 行: f'bash -c "cd {self.source_folder} && sh {maven_home}/bin/mvn clean package -B -DskipTests=false{skip_doc}"'（skip_doc = " -Dasciidoctor.skip=true" if self.settings.os == "OHOS" else ""）
```

**验证**:
```
conan-verify jakarta-cdi-api 4.0.1 八门禁 Verdict PASS（G0-G4+L2/L4/L5）；真机 conan create 上游 56/56 TestNG（Tests run: 51+5=56，0 失败）构建时执行；test_package 消费者探针 19/19 + PASS。
```
