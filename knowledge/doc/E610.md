# E610: OHOS /system/bin/sh（Korn 系）算术展开内嵌命令替换翻倍命令名（$(( $(date +%s) + n )) → datedate）：等待/超时类 shell 逻辑立即误判超时

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, testing, shell
- **作者**: unknown

## 错误特征
```
"datedate.*not found|echoecho.*not found|bad uid|.*was not created in time"
```

## 根因分析
"The OHOS /system/bin/sh (Korn-family, tracked-alias semantics) duplicates the command word when a `$(...)` command substitution appears inside `$((...))` arithmetic expansion. The command is emitted twice ('date' -> 'datedate'), the (failed) substitution evaluates as empty, and arithmetic continues as if the value were 0. The bug only fires for the nested form `$(( $(cmd) ... ))`; plain `test x -lt \"$(date +%s)\"` and hoisted `now=$(date +%s); $((now + n))` are unaffected. Pattern is common in upstream wait/timeout helpers."

## 推荐方案
**方法**: "Hoist the command substitution OUT of the arithmetic expansion into a variable first: `now=$(date +%s)` then `deadline=$((now + timeout))`. When porting packages that run upstream shell suites (or ship shell scripts), grep for the nested pattern `\\$\\(\\s*\\$\\(` and rewrite every hit; do not rely on `env -i`, `unalias`, or bypassing PATH - the mis-tokenization happens before command lookup and cannot be aliased away."
