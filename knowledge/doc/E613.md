# E613: musl ships no error.h while GNU test programs call error()/error_at_line() - a generated shim header on a prepended -I path fixes every affected test source at once, but static-in-header state breaks nothing only because test programs are single-purpose

## 基本信息
- **严重度**: 2
- **类别**: portability, musl
- **作者**: unknown

## 错误特征
```
fatal error: 'error.h' file not found|undefined symbol: error|undefined reference to `error`
```

## 根因分析
glibc's <error.h> declares error(int,int,const char*,...) and error_at_line(int,int,const char*,unsigned int,const char*,...) plus the error_message_count/error_one_per_line/error_print_progname globals. musl intentionally ships neither the header nor the functions. Large GNU projects (elfutils 0.195 tests/ has 100+ call sites across ~40 programs, plus dead #include <error.h> lines in files that no longer call it) compile their test programs against these interfaces, so a bare musl build fails twice: first with fatal error: 'error.h' file not found, and after deleting those includes, with undefined symbol: error at link. Existing entries cover single-file avoidance (edit the one source to stop including error.h, as elfutils src/threadlib.c allows via an upstream conditional branch); that does not scale to a whole test suite.

## 推荐方案
**方法**: generated-shim-header-plus-prepended-include-path

**说明**: In the conan recipe generate(), write an error.h shim into the generators directory implementing error() and error_at_line() as static functions with the glibc semantics (flush stdout, program_invocation_short_name prefix, optional strerror(errnum), vfprintf message, increment error_message_count, exit(status) when status!=0; error_at_line adds a filename:line prefix) and prepend -I<shimdir> to CPPFLAGS so it wins include resolution. program_invocation_short_name is exposed by musl under -D_GNU_SOURCE, which the build must define anyway. A static-in-header implementation is safe for test programs (each TU gets a private copy; counters are per-TU which is irrelevant for pass/fail semantics). Do NOT delete error.h includes one file at a time when call sites are live - only dead includes (no error() call in the file) should be removed by patch. Separately, test programs that call pthread_cancel cannot be shimmed that way: musl does not implement cancellation, so a stub would leave threads unkillable and hang the suite - exclude those programs from tests/Makefile.in (check_PROGRAMS and TESTS lists) via a patch to the checked-in Makefile.in.

**验证**:
```
conan create archives/l/libdebuginfod/0.195 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
