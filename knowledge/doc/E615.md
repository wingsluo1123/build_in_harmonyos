# E615: 从 conan 工具包供给 OHOS Rust 工具链：搬移二进制会破 rustc 的 sysroot 推导（E0463 can't find crate for std），须显式 --sysroot 指回包目录；且 cargo 的动态依赖闭包随 rust 构型而变，不可假定工具包自带运行库

## 基本信息
- **严重度**: 2
- **类别**: toolchain, rust, conan, provisioning, sysroot
- **作者**: atomcode
- **来源 PR**: 13336

## 错误特征
```
E0463.*can't find crate for .std.|the .aarch64-unknown-linux-ohos. target may not be installed
```

## 根因分析
rustc 由**自身可执行文件路径**推导 sysroot

## 推荐方案
**方法**: relocate-executables-only-and-pass-explicit-sysroot

**说明**: 只复制并签名需要 exec 的少数文件（bin/cargo、bin/rustc，

**修复命令**:
```
RUSTFLAGS="--sysroot=<tool_requires 的 rust-toolchain 包目录> -C linker=<clang>" cargo build --release --locked
```

**验证**:
```
|
```
