# E616: 工具链可用性探测不能用 os.access(X_OK)：权限位说"可执行"而实际 exec 被拒，探测层必须真跑一次并查退出码，否则"回退 bootstrap"分支被永久短路

## 基本信息
- **严重度**: 3
- **类别**: ohos, toolchain, conan, provisioning, silent-misdetect
- **作者**: atomcode
- **来源 PR**: 13336

## 错误特征
```
PermissionError.*Errno 13.*Permission denied.*(bin/cargo|bin/rustc|usr/local/bin/cargo)|os\.access.*X_OK.*True
```

## 根因分析
两层叠加。①os.access(X_OK) 完全基于 POSIX mode 位与

## 推荐方案
**方法**: probe-by-execution-not-access

**说明**: 把探测从"查权限位"改为"真跑一次 + 查退出码"：

**修复命令**:
```
conan create archives/r/rainfrog/0.3.20 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
