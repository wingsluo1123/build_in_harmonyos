# E619: 上游 man 页规则执行编译产物:交叉构建必失败

## 基本信息
- **严重度**: 2
- **类别**: autotools, make, cross-compile, packaging
- **作者**: 2301_80739235
- **来源 PR**: 13401

## 错误特征
```
"Exec format error|cannot execute binary file|consolation.8|help2man|man.*rule.*fail|make.*MANS.*fail"
```

## 根因分析
上游 man 页由"执行刚编译出的守护进程"排版生成(src/Makefile.am 内联规则,help2man 风格),且 automake 把 $(MANS) 挂进 all-am——make 阶段即执行目标架构二进制,交叉构建宿主无法运行(Exec format error);该包无 --disable-manpages 开关,配置层无法规避。

## 推荐方案
**方法**: blank-dist-man-mans-before-configure

**说明**: configure 前把 src/Makefile.in 的 dist_man_MANS 行清空,使生成的 Makefile 不含 man 目标(all-am 不再触发、install-man 变 no-op);与 -Ddocumentation=false / --disable-manpages 同口径,在配方内做,不占补丁位。

**修复命令**:
```
conanfile.py build() 前置: sed 's|^dist_man_MANS = .*|dist_man_MANS =|' src/Makefile.in(或读文件做行替换)
```

**验证**:
```
grep -n "MANS" src/Makefile.am 看规则是否执行程序;构建应在 configure 前中性化 src/Makefile.in 的 dist_man_MANS 行后进行;CI conan create 构建成功即验证。
```
