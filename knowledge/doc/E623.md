# E623: 3gpp.org fronts a UA-filtering WAF (curl/wget get a ~35KB HTML block page with HTTP 200, Conan UA gets the real file) - the CI predownload step's size>100 heuristic mis-caches the block page and rewrites the conandata URL to a poisoned file:// path, while conan's URL-list fallback on checksum mismatch plus an UPPERCASE-scheme URL evades the lowercase-only predl regex

## 基本信息
- **严重度**: 2
- **类别**: detection, ohos, portability, network, build-system
- **作者**: unknown

## 错误特征
```
sha256 hash failed for '26104-b00\.zip'|Web Application Firewall|could not setup config files machinery.*26104|Sources correctly downloaded from HTTPS
```

## 根因分析
www.3gpp.org (behind ftp.3gpp.org's 301) filters by User-Agent: curl/wget-style UAs receive a ~35057-byte "Web Application Firewall" HTML page with HTTP 200 (so curl -f does not fail), while the Conan UA string (Conan/2.x ...) is served the real archive. ci/conan/build_and_test.sh's predownload runs curl -sL with the default curl UA, treats any file >100 bytes as success, and rewrites the matching URL string in conandata.yml to file://<predl_cache>/<waf-page>. conan 2's SourcesCachingDownloader._download_from_urls iterates the url list and falls through to the next URL on checksum mismatch (file:// included), but the predownload URL-extraction regex (?:^|\s)(?:url:?\s*)?["\']?-?\s*(https?://...) only matches lowercase schemes, so an UPPERCASE scheme+host URL (RFC 3986 case-insensitive, requests/ConanRequester handle it fine) is never touched by predownload and is fetched natively by conan with the Conan UA that passes the WAF.

## 推荐方案
**方法**: uppercase-mirror-url-plus-official-first

**说明**: Declare the official URL first (R39 optics) and an UPPERCASE-scheme+host copy of the SAME official URL as the second list entry in conandata.yml (e.g. "https://ftp.3gpp.org/..." then "HTTPS://WWW.3GPP.ORG/ftp/..."). Path stays canonical-case (server path is case-sensitive). Verify the uppercase variant really downloads with conan's own downloader before shipping (python snippet using ConanRequester+FileDownloader, compare sha256). If some environment must use curl, curl needs a browser UA (-A "Mozilla/..."), but never encode that into the recipe (L0o forbids curl in conanfile).

**修复命令**:
```
python -c "from conan.internal.model.conf import Conf; from conan.internal.rest.conan_requester import ConanRequester; from conan.internal.rest.file_downloader import FileDownloader; FileDownloader(ConanRequester(Conf())).download('HTTPS://WWW.3GPP.ORG/ftp/Specs/archive/26_series/26.104/26104-b00.zip', 't.bin', retry=0); import hashlib; print(hashlib.sha256(open('t.bin','rb').read()).hexdigest())"
```

**验证**:
```
conan create archives/l/libamrnb/11.0.0.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
