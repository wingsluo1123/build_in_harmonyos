# E624: Recipes for wrapper-plus-restricted-vendor-code projects (amrnb/amrwb style) declare BOTH archives in conandata sources, keep the vendor zip packed in source() and copy the whole tree to build_folder for an in-tree build so the Makefile's own prepare step (unzip+patch+sed) regenerates vendor sources into a disposable copy

## 基本信息
- **严重度**: 1
- **类别**: ohos, portability, build-system, autotools, sources
- **作者**: unknown

## 错误特征
```
You need unzip utility to prepare sources|You need patch utility to prepare sources|26104-b00_ANSI_C_source_code\.zip|prepare_sources\.sh
```

## 根因分析
Some codec wrappers (penguin.cz amrnb/amrwb for 3GPP TS 26.104/26.204) ship only the autotools skeleton; the actual vendor code arrives as a separate license-restricted archive (3GPP zips are not mirrored by any distro) that must sit next to configure before make. configure hard-probes host tools unzip and patch (AC_PATH_PROG + AC_MSG_ERROR when absent and sources not yet prepared), and the Makefile regenerates the vendor .c/.h into $(top_srcdir), mutating the source tree.

## 推荐方案
**方法**: dual-conandata-entry-plus-intree-build-copy

**说明**: (1) conandata.yml lists TWO source entries (wrapper tarball, vendor zip) each with url list + sha256; source() does get(entry0, strip_root=True) then download(entry1.url, "<vendor>.zip", sha256=...) so the zip stays packed in the source folder. (2) build() copies the pristine source tree (wrapper + zip) into self.build_folder and builds in-tree - the Makefile's prepare rule then unpacks/applies patches inside the disposable copy, keeping the conan source cache clean. (3) build() asserts the zip landed with its exact expected size (427897 for 26104-b00.zip) to catch WAF-page poisoning at a readable point. (4) make -j1: the prepare chain is upstream's own serialization point. (5) Host tool deps (bash/unzip/patch/sed/tr) must be probed on the build host before CI (configure errors out otherwise); OHOS real devices: unzip was missing on one lab machine - check command -v unzip patch first.

**修复命令**:
```
grep -n "download(self" archives/l/libamrnb/11.0.0.0/conanfile.py && grep -n "copy(self" archives/l/libamrnb/11.0.0.0/conanfile.py
```

**验证**:
```
conan create archives/l/libamrnb/11.0.0.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
