# E625: AMR-NB consumer tests must (a) assert exact GP3 storage frame sizes per mode (13/14/16/18/20/21/27/32 bytes for MR475..MR122 = 1 TOC byte + RFC4867 payload), (b) run a multi-frame round-trip before amplitude assertions because the decoder needs 2-3 frames from reset state, and (c) smoke the encoder CLI by checking the #!AMR\n magic + frame count

## 基本信息
- **严重度**: 1
- **类别**: limitation, ohos, portability, testing, codec
- **作者**: unknown

## 错误特征
```
decoded sine peak too low|mode \d: \d+ bytes|round-trip OK|#!AMR
```

## 根因分析
The 3GPP TS 26.104 reference decoder starts from a reset state and its output amplitude ramps up over the first 2-3 frames; a single-frame encode/decode round-trip assertion like peak >= 4000 for an 8000-amplitude input sine fails even though the codec is fully functional (observed: single-frame peak far below threshold, 6-frame run converges to peak=4152 = 52% of input on the very first converged frame). Separately, the default (GP3) interface emits the storage format: 1 TOC/header byte plus the RFC 4867 payload per mode, so encoded byte counts are exact constants suitable for strict assertions; the amrnb-encoder/amrnb-decoder sample CLIs write/read streams prefixed with the 6-byte AMR_MAGIC_NUMBER "#!AMR\n".

## 推荐方案
**方法**: exact-frame-sizes-plus-multiframe-convergence

**说明**: Encode one 160-sample (20 ms @ 8 kHz) sine frame in each of the 8 modes and assert exact GP3 sizes {13,14,16,18,20,21,27,32}; for the round-trip encode/decode 6 identical MR122 frames and measure the output peak only from frame 3 onward (require >= 50% of input amplitude); for the CLI smoke write 320 samples of PCM, run amrnb-encoder MR122 in.pcm out.amr, assert out.amr starts with b"#!AMR\n" and has 6 + 2*32 bytes. DTX check: Encoder_Interface_init(1) on silence must yield a small SID frame (n>0, n<=32).

**修复命令**:
```
grep -n "expect_bytes" archives/l/libamrnb/11.0.0.0/test_package/test.c
```

**验证**:
```
conan create archives/l/libamrnb/11.0.0.0 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64
```
