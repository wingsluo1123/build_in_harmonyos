# E626: link-clang-rt-builtins

## 基本信息
- **严重度**: 2
- **类别**: platform, build-system, linking
- **作者**: unknown

## 错误特征
```
Error relocating .*libzimg\.so.*: (__addtf3|__subtf3|__multf3|__divtf3|__netf2|__eqtf2): symbol not found
```

## 根因分析
OHOS 的 clang 包装器给 libtool 的共享库链接注入 -nostdlib（libtool archive_cmds

## 推荐方案
**方法**: link-clang-rt-builtins

**说明**: 在 LDFLAGS（conan 配方 generate() 里 AutotoolsToolchain.extra_ldflags 或

**修复命令**:
```
|
```

**验证**:
```
nm -D <built>.so | grep -E " U __(add|sub|mul|div)tf3|__n?etf2"
```
