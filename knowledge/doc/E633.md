# E633: 上游只有 MSVC 工程（.sln/.vcproj、无任何构建系统）时的 POSIX 移植清单：构建面补齐 + 头文件面补齐（errno/stdio/反斜杠 include/register）

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, musl, posix, headers
- **作者**: unknown

## 错误特征
```
undefined symbol: errno|unknown type name 'FILE'|use of undeclared identifier 'stdout'|use of undeclared identifier 'fopen'|register' storage class specifier|ISO C\+\+17 does not allow 'register'|file not found|not a zip file
```

## 根因分析
MSVC 的目标是 Windows CRT 语境，很多"能编过"的前提在 POSIX 上不成立，且都集中在头文件/构建面而非业务逻辑：(1) errno：源码手写 extern int errno;（MSVC CRT 导出同名全局符号），而 POSIX/musl/glibc 的 errno 是宏 (*__errno_location())，没有全局符号 → 链接期 undefined symbol: errno；(2) stdio：上游把 #include <stdio.h> 只放在 #ifdef WIN32 / #else 那一支（因为 Win32 上 <io.h>/<fcntl.h> 顺带引入），POSIX 分支只包 <unistd.h> → FILE/stdout/fopen 未声明；(3) 路径分隔符：include 写成 "..\\zlib\\zlib.h"，反斜杠在 POSIX 上不是分隔符 → fatal error: file not found；(4) 语言标准：1999 年的 register 存储类在 C++17 被删除，`register char *ptr;` 直接报错；字符串字面量转 char*（-Wwritable-strings）在多数组三元表达式里甚至升为 error；(5) 构建面：只有 .sln/.vcproj，没有任何 Makefile/CMake/configure，必须自建构建文件（本仓做法是补丁新增 CMakeLists.txt，并把"新增文件补丁必须用 --- /dev/null 头部"作为交付要求）。这些点彼此独立、都要改，且不会一次全暴露（改完 errno 才看到下一个），因此适合先做一次"语法普查"（-fsyntax-only 全量编译）把编译期问题一次收拢，再进真实构建、再进运行期。

## 推荐方案
**方法**: syntax-census-then-build-surface-then-runtime-roundtrip

**说明**: (1) 第一步做**语法普查**而不是直接构建：clang++ -std=c++17 -fsyntax-only 全量源文件，把 register / 缺头文件 / 反斜杠 include / 字符串字面量转换一次性列全（本例 26 处 error 归为 4 类），比"改一个编一次"快得多。(2) errno 一律 #include <errno.h> 并删除手写 extern 声明；stdio/stdlib/string 按 POSIX 分支补齐，不要依赖 WIN32 分支的间接包含。(3) 反斜杠 include 改成逻辑名（<zlib.h>）或正斜杠相对路径；若树内 vendored 第三方库，优先改为消费制品仓的 Conan 包（同时去掉 vendored 副本的编译）。(4) register 直接删除；字符串字面量转 char* 处显式加 (char *) 转换（三元表达式里 clang 不把该扩展作用于合成类型，会硬报错）。(5) 构建面：新增 CMakeLists.txt/补丁；新增文件补丁头部必须是 --- /dev/null（conan 的 apply_conandata_patches 会以 '--- a/<file>' 报 source/target file does not exist）；若 URL 无 .tar.gz 后缀（如 codeload 直链 .../refs/heads/master），conan get() 会误判为 zip 报 BadZipFile，改用 https://github.com/<o>/<r>/archive/refs/heads/<b>.tar.gz（302 到 codeload，sha256 一致）。(6) 验收必须落到运行期往返，不能停在"编过"。

**修复命令**:
```
clang++ -std=c++17 -fsyntax-only -I xmill/src -I xmill/zlib xmill/src/*.cpp 2>syntax.log ; grep -c "error:" syntax.log
```

**验证**:
```
clang++ -std=c++17 -fsyntax-only -I <src> -I <zlib-inc> <src>/*.cpp   # 语法普查，先收拢编译期问题；再 cmake --build；最后跑运行期往返
```
