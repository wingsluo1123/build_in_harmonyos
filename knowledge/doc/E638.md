## 根因分析
AArch64（AAPCS64）上裸 `char` 默认是 **unsigned char**（x86_64 上默认是有符号）。

## 推荐方案
**方法**: add-fsigned-char-for-legacy-char-eof-code

**说明**: 对这类遗留 C 代码，优先在构建标志里加 `-fsigned-char`（恢复其在 x86 上的

**修复命令**:
```
make CC=clang CFLAGS="... -fsigned-char ..."
```
