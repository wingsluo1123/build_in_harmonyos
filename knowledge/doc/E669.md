# E669: reflex++ 生成 C++ 扫描器必须用 `-t`（stdout）形式：`-o <file>` 会丢掉写在输出文件打开之前的那行 `#include <reFlexLexer.h>`

## 基本信息
- **严重度**: 2
- **类别**: codegen, upstream-defect, usage
- **作者**: unknown

## 错误特征
```
generated C\+\+ scanner missing .*#include <reFlexLexer.h>|cannot find undeclared identifier FlexLexer|yyFlexLexer.*not declared|missing.*reFlexLexer\.h
```

## 根因分析
上游 `src/main.c` 的 `outn()` 在**打开输出文件之前**就把

## 推荐方案
**方法**: drive-cxx-codegen-through-stdout-and-assert-first-line

**说明**: (1) 生成器只要支持 stdout 形式（`-t`），C++ 消费链路一律用

**修复命令**:
```
reflex++ -t consumer.l > consumer.cc && head -1 consumer.cc | grep -q '#include <reFlexLexer.h>'
```

**验证**:
```
reflex++ -t consumer.l > consumer.cc && head -1 consumer.cc   # 期望 #include <reFlexLexer.h>
```
