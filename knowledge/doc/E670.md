# E670: autoconf 的 config.status 在 HMDFS 上"刚建的目录写不进去"：本地全绿、CI 间歇失败，须把 TMPDIR 钉到非 HMDFS 可写根并显式 chmod 临时目录

## 基本信息
- **严重度**: 2
- **类别**: hmdfs, autotools, filesystem, ci-only-failure
- **作者**: unknown

## 错误特征
```
config\.status: line [0-9]+: .*(subs\.sed|subs\.frag|undefs\.sed|/out|/in): Permission denied|creating \./config\.status|cannot create a temporary directory in
```

## 根因分析
autoconf 生成的 config.status 在正文里自建临时目录：

## 推荐方案
**方法**: pin-tmpdir-to-verified-writable-root-and-chmod-the-scratch-dir

**说明**: (1) 先判定"是不是确定性问题"：**注意不能只看"同点复现"** —— 本包实测为间歇

**修复命令**:
```
os.environ.update(dict.fromkeys(("TMPDIR","TMP","TEMP"), "/data/storage/el2/base/cache"))
```

**验证**:
```
TMPDIR=$HOME/.cache/tmp ./configure >/dev/null 2>&1; ./config.status 2>&1 | head; grep -n 'chmod 700 "\$tmp"' config.status
```
