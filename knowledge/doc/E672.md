# E672: autotools 自举类包的 `make check` 只在 --build 与 --host canonical 相等时执行；交叉构建下该规则被 @no_cross@ 置空，"测试通过"是假象

## 基本信息
- **严重度**: 3
- **类别**: autotools, cross-compile, test-harness
- **作者**: unknown

## 错误特征
```
cannot guess build type; you must specify one|config\.guess: unable to guess system type|@no_cross@|Check successful, using COMPRESSION|no_cross
```

## 根因分析
`configure` 把 `cross_compiling` 结果写入 `@no_cross@` 替换位，自举/自检类规则

## 推荐方案
**方法**: set-equal-build-and-host-triplet-to-enable-self-tests

**说明**: (1) 先判断 `make check` 是否"真的跑了"：搜索其输出里有没有该套件特有的字串

**修复命令**:
```
./configure --prefix=/ --build=aarch64-linux-ohos --host=aarch64-linux-ohos --disable-shared --enable-static
```

**验证**:
```
./configure --build=aarch64-linux-ohos --host=aarch64-linux-ohos && make -j1 && make check 2>&1 | grep -E 'Check successful|diff scan\.c'
```
