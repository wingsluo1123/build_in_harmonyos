# E673: 上游测试目标首项是"裸 -C"而本版选项解析器把它与紧随的独立参数粘连 → 该目标在上游即失败，应只驱动可用的压缩模式并在 manifest 记录排除

## 基本信息
- **严重度**: 3
- **类别**: test-harness, upstream-defect
- **作者**: unknown

## 错误特征
```
unknown -C option '/'|bigcheck|COMPRESSION=|\./flex: unknown|invalid option.*-C
```

## 根因分析
reflex 的 `bigcheck` 目标把同一自举断言在 7 种表压缩模式下各跑一遍

## 推荐方案
**方法**: enumerate-available-test-modes-and-document-the-exclusion

**说明**: (1) 上游测试目标整体失败时先辨别"是本包引入还是上游自带"：在 pristine 源码

**修复命令**:
```
for m in -Ce -Cm -f -Cfea -CFer -l; do rm -f scan.c; make COMPRESSION=$m check || exit 1; done
```

**验证**:
```
for m in -Ce -Cm -f -Cfea -CFer -l; do rm -f scan.c; make COMPRESSION=$m check; done
```
