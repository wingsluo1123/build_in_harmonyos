# E675: "In package(): after cmake.install(), use conan.tools.files.

## 基本信息
- **严重度**: 2
- **类别**: cmake, no-install
- **作者**: unknown

## 错误特征
```
"CMakeLists.txt has no install\\(\\) rules|cmake\\.install\\(\\) produced no lib|package_folder missing lib.*include"
```

## 根因分析
"Upstream CMakeLists.txt only defines add_library + target_include_directories with no install(TARGETS/FILES) rules; conan cmake.install() therefore produces no lib/ or include/ artifacts, and consumer find_package fails. Secondary: *.h.in templates copied alongside generated *.h shadow the real headers for consumers."

## 推荐方案
**方法**: "In package(): after cmake.install(), use conan.tools.files.copy to manually collect lib<name>.a/.so into package_folder/lib and all public headers (both configure_file-generated and source-folder headers) into package_folder/include. Do NOT ship *.h.in templates. For upstream version-macro/SHARED hardcoding, use real patch files registered in conandata.yml (patches: list) and applied in build() via export_sources()+apply_conandata_patches() (G1 recipe-completeness gate); patch headers use a/ b/ relative paths."

**修复命令**:
```
"conan create archives/p/pxlib/0.6.9 -pr:h ohos-aarch64 -pr:b ohos-aarch64"
```

**验证**:
```
"find <package_folder>/lib -name 'libpxlib.*' | wc -l  # expect >= 1; find <package_folder>/include -name '*.h' | wc -l  # expect >= 3"
```
