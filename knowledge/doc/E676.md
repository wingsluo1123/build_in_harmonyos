# E676: HNP/HarmonyOS worker 测试脚本禁止硬编码 /tmp（不可写），必须用 "${TMPDIR:-$PWD}" 动态工作目录

## 基本信息
- **严重度**: 2
- **类别**: ohos, testing, filesystem, shell
- **作者**: unknown
- **来源 PR**: 14184

## 错误特征
```
无法生成存档|failed to open.*save|Operation not permitted.*tmp|cannot create.*tmp|ohos-save
```

## 根因分析
HNP/HarmonyOS worker 上 /tmp 不可写（只读或未挂载）；测试脚本硬编码 /tmp/fuzzsave、/tmp/ohos_save 时写入失败——fuzzpuzz-setup 无法生成存档、ohos-save FAIL，导致 CI L1 测试阶段红

## 推荐方案
**方法**: tmpdir-or-pwd-savedir-pattern

**说明**: 测试脚本默认 SAVEDIR="${TMPDIR:-$PWD}/<name>-save-$$"，mkdir -p 创建，trap 清理；全部 /tmp 引用替换为 $SAVEDIR

**修复命令**:
```
SAVEDIR="${TMPDIR:-$PWD}/puzzles-save-$$"; mkdir -p "$SAVEDIR"; trap 'rm -rf "$SAVEDIR"' EXIT
```

**验证**:
```
HNP CI 重跑 test_package（puzzles 构建 #66319 全绿）；本机 bash test_puzzles.sh 50/50 PASS
```
