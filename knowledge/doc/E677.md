# E677: conan 2 cmake_layout: CMake 输出目录即 self.build_folder（.../b/build/Release）；打包非 install 产物（auxiliary/cliprogram）须用 shutil.copy2 + isfile 检查，conan copy() 对缺失 src 静默跳过导致包缺文件但 create 成功、CI L1 才暴露

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, packaging, testing
- **作者**: unknown
- **来源 PR**: 14184

## 错误特征
```
command not found|Packaged [0-9]+ files|binary not found|Cannot find source file
```

## 根因分析
conan 2 的 cmake_layout 把单配置构建输出放在 build 根下的 build/Release，且生成器把 self.build_folder 指向该 CMake 输出目录本身（.../b/build/Release），不是 build 根；conan copy() 的 src 不存在时静默跳过（无告警），包内缺文件但 conan create 仍成功；上游 CMake 通常不 install auxiliary/cliprogram 类测试程序，需在 package() 显式搬运，否则 CI test_package 阶段从 PATH 找不到（command not found）

## 推荐方案
**方法**: shutil-copy2-absolute-src-in-package

**说明**: package() 先 cmake.install()，再用 shutil.copy2 显式复制辅助产物到 package_folder/bin：aux_src = os.path.join(self.build_folder, "auxiliary")（cmake_layout 下 self.build_folder 即 CMake 输出目录），逐个 os.path.isfile 检查后 copy2；fuzzpuzz 等顶层目标用 os.path.join(self.build_folder, "<tool>")

**修复命令**:
```
shutil.copy2(src, os.path.join(self.package_folder, "bin"))   # src 为绝对路径，先 os.path.isfile 检查
```

**验证**:
```
conan create archives/p/puzzles/20260720.3c36322 -pr:h=ohos-local -pr:b=ohos-local --build=missing -tf="" && ls "$(ls -dt ~/.conan2/p/b/puzzl* | head -1)/p/bin" | wc -l   # 期望 55（40 官方 + 14 auxiliary + fuzzpuzz）
```
