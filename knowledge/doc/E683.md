# E683: 适配 Pure Data 外部对象库（pd-* 系列，走上游自带 pd-lib-builder）到 OHOS：Pd API 头直接在制品仓的 puredata application 包里（不必再拉 pure-data 源码树）、平台由 `$(CC) -dumpmachine` 而非 uname 判定、install-datafiles 把所有 datafiles 拍平到一个目录——故一个 -path 即可同时拿到外部对象与全部帮助补丁

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, build-system, dependency, packaging
- **作者**: 4F7A

## 错误特征
```
error: m_pd.h: No such file or directory|PDINCLUDEDIR|uname.*HarmonyOS|ld.lld: error: undefined symbol: main|no rule to make target.*pd_linux|extension.*pd_darwin|permission denied.*pd_linux
```

## 根因分析
三个容易踩错的点叠在一起。

## 推荐方案
**方法**: 配方里不引入任何补丁，只做三件事：

**说明**: Pd API 头取自 puredata 包目录；make 传 system=Linux+PDINCLUDEDIR；帮助补丁 keep_path=False 拍平；build() 断言外部对象数精确相等

**修复命令**:
```
grep -n 'dumpmachine\|^system\|install-datafiles' <src>/pd-lib-builder/Makefile.pdlibbuilder
```

**验证**:
```
conan create <pkgdir> --name=<n> --version=<v> -pr:h=ohos-aarch64-wsl -pr:b=ohos-aarch64-wsl --build=missing \
```
