- **严重度**: 2
- **类别**: ohos, conan, runtime, objective-c, objfw
- **作者**: calbee21 <calbee21@users.noreply.gitcode.com>

## 错误特征
```
Signal 11.*core dumped|OFMethodNotFound|fconstant-string-class|OFConstantString|objc_msg_lookup.*objfw
```

## 根因分析
ObjFW ships its own Objective-C runtime (libobjfwrt) and

## 推荐方案
**方法**: publish-objcflags-in-package-info

**修复命令**:
```

```
