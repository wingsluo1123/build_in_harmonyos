# E710: conan 依赖包的 pkg-config / 链接元数据缺口四类：①.proc 变量缺（数据包 database）②包内无 .pc 需别名（dbus-1）③生成 .pc 丢 Requires（mm-glib 的 gio）④包内库未列入 cpp_info.libs（protobuf 的 utf8_range）——一律在 generate() 用"pc 补齐目录"修，不改上游源码

## 基本信息
- **严重度**: 3
- **类别**: portability, linking, conan, dependency, pkg-config
- **作者**: M5TN

## 错误特征
```
Could not get pkg-config variable and no default provided|Dependency "dbus-1" not found|fatal error: .*\.h file not found|undefined symbol: (g_file_new_for_path|g_io_error_quark|utf8_range_IsValid|utf8_range_ValidPrefix)|C shared or static library .* not found
```

## 根因分析
上游 meson.build 用 pkg-config 的名字/变量/传递依赖来描述依赖，

## 推荐方案
**方法**: generate-side-pkgconfig-overlay-dir

**说明**: 在 generate() 里建一个"pc 补齐目录"（os.path.join(self.build_folder,

**修复命令**:
```
pcfix = os.path.join(self.build_folder, "pkgconfig-fix"); os.makedirs(pcfix, exist_ok=True)
```

**验证**:
```
1) 枚举依赖包真实 .pc：`find <pkg_folder> -name '*.pc'`（含 share/pkgconfig），
```
