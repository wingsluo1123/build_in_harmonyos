# E712: clang 拒绝「case/default 标签后紧跟声明」（ISO C：标签只能标记语句，声明不是语句）——GCC GNU 扩展容忍、clang 报 expected expression；带 cleanup 属性的变量还会连带报「跳转绕过初始化」

## 基本信息
- **严重度**: 3
- **类别**: portability, compiler, clang, c-language
- **作者**: M5TN

## 错误特征
```
error: expected expression|cannot jump from switch statement to this case label|jump bypasses initialization of variable with __attribute__\(\(cleanup\)\)|error: use of undeclared identifier
```

## 根因分析
ISO C 规定 label 只能作为**语句**的前缀，而声明（declaration）不是语句。

## 推荐方案
**方法**: wrap-label-body-in-block-scope

**说明**: 给该 case 分支加一层块作用域 `{ ... }`（同时解决两个报错）：

**修复命令**:
```
# src/xxx.c
```

**验证**:
```
1) 复现最小例：printf 'int f(int c){switch(c){case 1: int x=0; return x;} return 0;}\n' > t.c
```
