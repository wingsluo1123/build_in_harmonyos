# E731: 改配方后的本地复验有两个静默陷阱：`conan create` 会复用已有 package folder（只改 package() 的 copy 语义时新旧文件**叠加**，看着像修复没生效），以及在分支还没有任何提交时跑 `ci/conan/build_and_test.sh` 会退化成整仓扫描、被 origin/main 已跟踪的隐藏文件误判成 JC1/JC5 红

## 基本信息
- **严重度**: 2
- **类别**: conan, ci-gate, process, tooling
- **作者**: 4F7A

## 错误特征
```
JC1: .* 个运行时状态文件被跟踪|JC5: .* 个 archives 下未登记的隐藏文件|JC_RESULT=fail|full 模式（整仓扫描）|package .* created|copy\(.*keep_path|预期布局未生效|旧文件仍在包内
```

## 根因分析
(a) package_id 只由 settings/options/requires 决定，**不含 package() 的实现**。

## 推荐方案
**方法**: 固化三条顺序，不要跳：

**说明**: 先 commit 再跑门禁；改 package() 先 conan remove -c；JC 报警先用 git cat-file -e origin/main 判存量

**修复命令**:
```
conan remove "pd-ggee/0.28" -c && conan create archives/p/pd-ggee/0.28 --name=pd-ggee --version=0.28 -pr:h=ohos-aarch64-wsl -pr:b=ohos-aarch64-wsl --build=missing
```

**验证**:
```
git cat-file -e origin/main:archives/c/cloog/0.21.1/.build-closed && echo STALE_IN_MAIN \
```
