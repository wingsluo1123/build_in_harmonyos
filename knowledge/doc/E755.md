# E755: musl 下 fd_set/select/timeval 未声明（use of undeclared identifier 'fd_set'）——根因是 glibc 的 sys/types.h 间接链出 sys/select.h 而 musl 不链，补 #include <sys/select.h> 即修，对 glibc 无害

## 基本信息
- **严重度**: 3
- **类别**: platform, ohos, portability, musl, network
- **作者**: unknown

## 错误特征
```
use of undeclared identifier 'fd_set'|variable has incomplete type 'struct timeval'|call to undeclared function 'FD_ZERO'|call to undeclared function 'select'|too many errors emitted
```

## 根因分析
glibc 的 sys/types.h 通过内部头文件链（bits/types.h 等）间接包含 sys/select.h，fd_set/struct timeval/FD_* 宏在 glibc 上"只 include sys/socket.h 也能用"；musl 严格按 POSIX 分层，sys/types.h 不链 sys/select.h，未显式包含即报 undeclared。与编译方言无关（gnu11+_GNU_SOURCE 与 gnu11+POSIX2008 两个组合实测均不可见），纯头文件链差异。注意并非所有文件都挂：包含 sys/time.h 的文件不挂（musl 的 sys/time.h 会带出 fd_set 定义），只挂"既无 sys/time.h 也无 sys/select.h"的文件

## 推荐方案
**方法**: add-sys-select-h-include-portability-patch

**说明**: 为每个使用 fd_set/select/struct timeval/FD_* 宏但未包含该头的源文件补 #include <sys/select.h>（portability 补丁）。补丁对 glibc/Linux 无害（include guard 幂等），是纯增益修复。注意必须 grep 全部使用文件逐一补齐，不能只补报错的第一个（编译器 -ferror-limit 截断会掩盖后续文件）

**修复命令**:
```
grep -ln "fd_set\|select(\|struct timeval" src/*.c 然后对每个缺 sys/select.h 的文件：补丁 +1 行 #include <sys/select.h>（参考 archives/l/libdsm/0.4.3/patches/0001-musl-include-sys-select-h-for-fd_set.patch：netbios_session.c 在 errno.h 后、netbios_utils.c 在 NS_ABORT_USE_PIPE include 块内）
```

**验证**:
```
1) 复现：conan create 编译含 fd_set 的源文件，报 use of undeclared identifier 'fd_set' / variable has incomplete type 'struct timeval'；2) 判别链：grep -ln "fd_set\|select(\|struct timeval" src/*.c 找出全部使用文件，再查各文件 include 列表确认缺 sys/select.h 且无 sys/time.h；3) 微型探针：echo '#include <sys/socket.h>' + fd_set 用法，用 clang -std=gnu11 -D_GNU_SOURCE 编译——glibc 过、musl 挂即锁定根因；4) 修复后 conan create RC=0
```
