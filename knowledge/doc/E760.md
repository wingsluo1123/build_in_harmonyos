# E760: 上游把 enable_testing() 放在 tests/ 子目录、且测试可执行文件全部 EXCLUDE_FROM_ALL 时（libcorrect 模式），根目录 `ctest` 报 "No tests were found"、默认构建也不产 runner——须显式构建上游聚合目标（如 test_runners）再进子目录跑 ctest，计数仍以子目录 LastTest.log 为唯一来源

## 基本信息
- **严重度**: 3
- **类别**: cmake, testing, ci-gate
- **作者**: A6F2
- **来源 PR**: 14383

## 错误特征
```
No tests were found!!!|test_runners EXCLUDE_FROM_ALL|enable_testing.*subdirectory|add_test.*not registered at root
```

## 根因分析
CMake 的测试注册是按目录的：enable_testing() 写在哪个目录的 CMakeLists.txt，CTestTestfile.cmake 就生成在哪个目录（含其子目录），顶层没有该文件时根级 ctest 扫不到任何条目，输出 "No tests were found!!!" 并以退出码 0 结束（假绿）。同时此类项目的测试可执行文件通常声明为 EXCLUDE_FROM_ALL（libcorrect tests/CMakeLists.txt 每个 add_executable 均如此），默认 cmake --build 根本不编译它们，只有上游提供的聚合目标（add_custom_target(test_runners DEPENDS ...)，即上游 make check 的入口）才会构建。两件事叠加：只做其一，要么 runner 不存在，要么 ctest 假绿。

## 推荐方案
**方法**: build-aggregate-target-then-ctest-in-subdir

**说明**: (1) 先 grep 三样东西：enable_testing() 的位置（顶层 vs tests/ 子目录）、测试 add_executable 是否带 EXCLUDE_FROM_ALL、是否存在 add_custom_target 聚合目标（test_runners / check 之类）；(2) 配方 build() 里 cmake.build() 之后显式 cmake.build(target="<聚合目标>")——这是上游自己 `make check` 的等价物，不引入任何测试代码改动；(3) ctest 的工作目录选含 CTestTestfile.cmake 的目录（通常 build/tests/），逐候选探测 os.path.isfile(join(dir, "CTestTestfile.cmake")) 后运行，根目录 "No tests were found" 不可作为通过依据（ctest 该路径退出码为 0，是经典假绿）；(4) 计数唯一来源仍是 ctest 写的 Testing/Temporary/LastTest.log（fail-closed 解析：N/M 分母一致性 + Test Passed/Failed 判决行 + 恒等式自检），不要对 stdout 做正则数数；(5) LastTest.log 要在 build 树里递归找（cmake_layout 单配置在 build/Release，子目录测试再深一层），walk 限深防炸。

**修复命令**:
```
cmake --build <build_dir> --target test_runners && (cd <build_dir>/tests && ctest --output-on-failure)
```

**验证**:
```
grep -n "enable_testing" CMakeLists.txt tests/CMakeLists.txt; grep -n "EXCLUDE_FROM_ALL" tests/CMakeLists.txt; grep -n "add_custom_target(test" tests/CMakeLists.txt; ctest 2>&1 | grep "No tests"
```
