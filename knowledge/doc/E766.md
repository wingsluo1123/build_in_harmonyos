# E766: D-Bus 依赖的 Qt/KDE 库适配 OHOS 双要点：KF6 基线 qtbase/6.11.1 是 DBus/openssl 关闭的缩减包需换 qtbase-sql-dbus 变体；无 dbus-daemon 环境消费者测试必须避开 sessionBus().interface() 空指针路径

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, build-system, testing
- **作者**: unknown
- **来源 PR**: 14214

## 错误特征
```
Target ".*" links to:.*but the target was not found.*Qt6::DBus|Could NOT find DBus|Test #.*\(.*\) .*SEGFAULT|feature_dbus.*OFF|qtbase.*reduced.*surface
```

## 根因分析
(1) 制品仓的 qtbase/6.11.1（KF6 6.26 基线所用）是缩减面包：configure 显式 FEATURE_dbus=OFF、FEATURE_openssl=OFF、testlib off，并且 cmake_find_mode=none 下 find_package(Qt6 COMPONENTS DBus) 直接找不到目标（"Target links to ... but the target was not found"）。任何非 ANDROID 平台硬依赖 Qt6::DBus/Qt6::Test 的 KDE 件（kunifiedpush 客户端库经 qt_add_dbus_adaptor/interface 生成 DBus 代码 + QtTest 上游套件）都不能沿用 KF6 基线的 qtbase 版本号。(2) OHOS 无会话 dbus-daemon：QDBusConnection::sessionBus() 返回的连接上 interface() 返回 nullptr，上游构造函数里 ConnectorUtils::selectDistributor() 无条件调用 registeredServiceNames() 直接段错误——这类"库正常但测试二进制崩"的根因是总线上线探测在 bus-less 主机不可用，不是库缺陷。

## 推荐方案
**方法**: qtbase-variant-selection-plus-busless-safe-consumer-test

**说明**: (1) W0 阶段先 grep qtbase 各版本配方的 FEATURE_dbus/FEATURE_testlib 开关再定 requires：需要 Qt6::DBus/Test/Sql 的件选 qtbase-sql-dbus/6.11.1（含 qdbusxml2cpp host 工具 + lib/cmake/Qt6DBus 的 Qt6DBusMacros.cmake，akonadi 25.12.3 / alligator 26.04.0 先例），纯 Core/Gui 件才用 qtbase/6.11.1；(2) ECM 件沿用 kcrash 6.26.0 模式：ECM_MODULE_PATH 手动指向 ecm 包 share/ECM 的 modules/find-modules/kde-modules，qtbase 系 cmake_find_mode=none 时手写 conan_cmakedeps_paths.cmake 把每个依赖的 lib/cmake、包根、include 前缀进 CMAKE_PREFIX_PATH/CMAKE_MODULE_PATH 并 set(CMAKE_FIND_PACKAGE_PREFER_CONFIG ON)；(3) 无 dbus-daemon 环境的消费者测试读上游源码找提前返回分支：kunifiedpush Connector 对空 serviceName 在 loadState()/selectDistributor() 之前 return（仅 qCWarning），既保住 D-Bus adaptor 注册路径（总线缺失降级 warning）又能真调全部属性 API；(4) 注意 C++ most-vexing-parse：Connector connector(QString()) 是函数声明不是对象，用命名变量 const QString s; Connector c(s); 规避。

**修复命令**:
```
conan create . -pr:h=/storage/Users/currentUser/.conan2/profiles/ohos-aarch64 --build=missing -c tools.build:jobs=2
```

**验证**:
```
conan create . -pr:h=<ohos-aarch64-profile> --build=missing && grep -c "tests passed" $(find . -name 'conan-create.log')
```
