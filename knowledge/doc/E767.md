# E767: 受限沙箱域 python3 禁 symlink 系统调用（任意路径 EACCES）——ELF 绝对路径 NEEDED 桥接必须带 copy2 兜底；诊断靠 python/ln × src/dst 2×2 矩阵

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, packaging, elf, test-harness
- **作者**: unknown
- **来源 PR**: 11760

## 错误特征
```
os.symlink|Errno 13|Permission denied|cannot create NEEDED fallback|Error relocating|symbol not found|Error loading shared library
```

## 根因分析
制品仓预编译二进制（如 libKDEGames6.so）内嵌构建机的绝对缓存路径 ~/.cache/conan2/p/<short>/p/lib/libKF6NewStuff*.so；消费端本机 conan 缓存为默认 ~/.conan2 时该路径不原生存在，test_package 的桥接逻辑（DT_NEEDED 扫描 + 建链）用 os.symlink 兜路径。鸿蒙 PC 上用 cmd-pkgs 安装的 python3 沙箱域被平台策略禁 symlink 系统调用：2×2 矩阵实证（python/ln × src∈{.conan2, /etc/hostname} × dst∈{.cache, ~/tmp}），python 侧任意组合均 [Errno 13] Permission denied，ln 二进制相同参数全部成功——限制跟随进程域而非路径。CI 端 python3 是 /data/app/bin/python3（另一域），不受限（kfourinline / kgoldrunner / libktorrent 同机制先例 CI 全绿可证）。故障链为：os.symlink EACCES → 代码仅 warning 后继续 → musl loader 重定位失败 "Error relocating ... symbol not found"，表面症状（KNSWidgets 符号缺失）与根因（syscall 权限）相距两层，极易误诊为缺库或版本不匹配。

## 推荐方案
**方法**: symlink-try-copy2-fallback-and-diagnose-with-2x2-matrix

**说明**: 桥接逻辑必须 try os.symlink / except OSError → shutil.copy2 兜底：实文件拷贝对 loader 语义等价、不依赖 symlink 权限，与文件内相对路径桥接 _prepare_runtime_links 既有兜底同款；CI 端 python 可 symlink 故兜底不触发、行为不变。诊断口诀：先跑 2×2 矩阵（python/ln × 任意 src/dst）区分"进程域限制"与"路径策略"——ln 成功而 python 同参数失败即进程域问题，不要在路径权限/HMDFS 上空耗。另注意表象差异的另一来源是缓存布局：CONAN_HOME=~/.cache/conan2 时内嵌路径原生存在（os.path.exists 短路，完全不走建链分支），默认 ~/.conan2 时才走建链；9 月 21 日本地绿跑与次日红跑的差异即源于此，CI worker 端（默认 ~/.conan2）始终走建链分支且其 python 不受限。

**修复命令**:
```
python3 -c "import shutil,os; src=os.path.expanduser('~/.conan2/p/knews8e3b6e11174be/p/lib/libKF6NewStuffWidgets.so'); dst=os.path.expanduser('~/.cache/conan2/p/knews8e3b6e11174be/p/lib/libKF6NewStuffWidgets.so'); os.makedirs(os.path.dirname(dst),exist_ok=True); shutil.copy2(src,dst); print('OK')" && CI_REPO_ROOT="$PWD" CI_PACKAGES="archives/k/ktuberling/26.04.0" CI_BRANCH="feat/ktuberling-26.04.0" CI_PR_NUMBER="11760" zsh ci/conan/build_and_test.sh
```

**验证**:
```
python3 -c "import os,os.path; os.symlink('/etc/hostname', os.path.expanduser('~/tmp/symlink-probe'))" （EACCES=受限域，ln 同参数成功即坐实进程域限制）&& CI_REPO_ROOT="$PWD" CI_PACKAGES="archives/k/ktuberling/26.04.0" CI_BRANCH="feat/ktuberling-26.04.0" CI_PR_NUMBER="11760" zsh ci/conan/build_and_test.sh （修复后 rc=0，"created N absolute-NEEDED compatibility links"）
```
