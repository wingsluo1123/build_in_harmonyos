# E770: kernel-style kbuild 包（klibc 家族）用命令行变量注入 EXTRA_KLIBCCFLAGS 会整体覆盖目录级配置宏：dash 的 config.h 与 -DBSD/-DSMALL/-DHAVE_CONFIG_H 丢失，system.h 的 sysconf() 声明被 klibc 函数式宏展开而编译失败

## 基本信息
- **严重度**: 2
- **类别**: portability, headers, build-system, compilation
- **作者**: unknown

## 错误特征
```
expected '\)'|cannot redeclare builtin function '__builtin_constant_p'|long sysconf\(int\) __attribute__\(\(__noreturn__\)\)
```

## 根因分析
GNU make 的命令行变量赋值优先级最高，会覆盖 Makefile 内所有同名赋值（含 := 与 +=）。klibc 的 usr/dash/Kbuild 用 EXTRA_KLIBCCFLAGS 承载三类必需内容：-I$(srctree)/$(src) -I$(objtree)/$(obj)、-include $(srctree)/$(src)/config.h、以及 $(config-cppflags)（-DBSD=1 -DSMALL -DJOBS=0 -DHAVE_CONFIG_H -DSHELL -DGLOB_BROKEN -DIFS_BROKEN）。一旦为了交叉编译在命令行写 EXTRA_KLIBCCFLAGS="--target=aarch64-linux-ohos"，这些内容全部失效：config.h 不再被 -include，HAVE_SYSCONF 未定义，于是 usr/dash/system.h 的 `long sysconf(int) __attribute__((__noreturn__));` 生效，而 klibc 的 usr/include/sys/sysconf.h 把 sysconf 定义为函数式宏 `#define sysconf(x) (__builtin_constant_p(x) ? __sysconf_inline(x) : sysconf(x))`，展开后产生 'expected )' 与 'cannot redeclare builtin function __builtin_constant_p' 两个看似无关的报错，错误行完全指向 system.h，容易误导到「上游代码不兼容」。注意 usr/klibc/Kbuild 不设置该变量，所以同一份配方对 libc 本体（klibc）构建正常——只有 dash/gzip 这类设置了 EXTRA_KLIBCCFLAGS 的子目录会踩中。

## 推荐方案
**方法**: inject-arch-flags-via-cc-ld-content-not-extra-vars

**说明**: 交叉编译的架构标志不要走 EXTRA_KLIBCCFLAGS/EXTRA_KLIBCLDFLAGS，而是写进 CC/LD 自身的「命令行内容」：CC="clang --target=aarch64-linux-ohos"、LD="ld.lld -m aarch64linux"（HOSTCC 保持本机 clang，hostprogs 如 mkinit/mknodes/mksyntax 在本机 OHOS 上运行）。kbuild 通过 $(CC)/$(LD) 调用工具，工具内的 --target/-m 会被正确传递；同时 cc-option、--print-libgcc-file-name、--print-file-name=include 等探测也在带 target 的 CC 下工作。若确实必须传 EXTRA_*，只能改用 Kbuild 里的 `override` 或在配方侧不设置该变量（本轮采用前者）。修复后 kbuild 的 `KLIBCRANLIB := $(RANLIB) -D` 等仍正常。

**修复命令**:
```
make KLIBCARCH=arm64 KLIBCKERNELSRC="<kernel-headers>" KLIBCASMDIR="aarch64-linux-ohos/asm" CC="clang --target=aarch64-linux-ohos" HOSTCC=clang AR=llvm-ar RANLIB=llvm-ranlib STRIP=llvm-strip NM=llvm-nm OBJCOPY=llvm-objcopy OBJDUMP=llvm-objdump LD="ld.lld -m aarch64linux" PERL=perl -j1
```

**验证**:
```
grep -n "EXTRA_KLIBCCFLAGS\|EXTRA_KLIBCLDFLAGS" <src>/usr/*/Kbuild <src>/Kbuild; grep -n "sysconf" <src>/usr/include/sys/sysconf.h <src>/usr/dash/system.h
```
