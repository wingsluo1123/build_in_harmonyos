# E775: OHOS 禁 FIFO（SELinux）的应用级后果：kamailio jsonrpcs 的 FIFO transport 在 mod_init 阶段 mkfifo EPERM → 模块初始化失败（错误链完整实证）

## 基本信息
- **严重度**: 2
- **类别**: limitation, ohos, selinux, posix, syscall
- **作者**: B7D2
- **来源 PR**: pending

## 错误特征
```
'Can.t create FIFO: Operation not permitted|jsonrpc_init_fifo_server|init_mod\(\).*Error while initializing module|error while initializing modules|mkfifo.*Operation not permitted|mkfifo.*EPERM'
```

## 根因分析
OHOS SELinux 策略禁止用户进程创建 FIFO（与 E525/E074 同源平台属性）。

## 推荐方案
**方法**: degrade-to-non-fifo-transport

**说明**: 按 P013 降级而非绕过：不使用 FIFO transport。

**修复命令**:
```
kamailio -E -f <cfg-without-fifo-transport>   # 实测可正常启动并写 pid
```

```
|
```
