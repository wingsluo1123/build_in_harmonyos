- **作者**: unknown

## 错误特征
```
Could NOT find Backtrace \(missing: Backtrace_INCLUDE_DIR\)|System is unknown to cmake.*HarmonyOS|add_subdirectory given source .*googletest-src.* which is not an existing directory|Compatibility with CMake < 3\.5 has been removed
```

## 根因分析
(1) CMake has no Platform/HarmonyOS module, so FindBacktrace's find_path misses the sysroot include even though execinfo.h is on the compiler default include path and backtrace() is in libc; REQUIRED makes configure fail outright. (2) Upstream test bootstrap via ExternalProject can pin an outdated cmake_minimum_required (< 3.5, rejected by CMake >= 4.0) and stale download URLs, making add_subdirectory fail on a missing source dir.
