# E793: test_package/消费者测试不得用 assert() 承载控制流前置检查：

## 基本信息
- **严重度**: 2
- **类别**: packaging, testing, release
- **作者**: unknown
- **来源 PR**: (embedmq 1.0.1 适配 PR，创建后回填)

## 错误特征
```
Signal 11|core dumped|Segmentation fault|assert.*compiled out|NDEBUG|test passed.*0 delivered|delivered=0
```

## 根因分析
C 标准 assert(EXPR) 在定义了 NDEBUG 时展开为 ((void)0)，EXPR 不求值。

## 推荐方案
**方法**: explicit-error-codes-instead-of-assert-control-flow

**说明**: 测试代码把全部前置检查（create/register/pthread_create 结果、NULL 守卫）

**修复命令**:
```
if (!q) { fprintf(stderr, "FAIL: create NULL\n"); return 2; }
```

**验证**:
```
clang -DNDEBUG -O2 <test>.c <lib>.a -pthread -o t && ./t ; echo $?  # 139=SIGSEGV
```
