# E794: Conan 2 配方手动打包规范化：上游 CMake 工程无 install() 规则时，

## 基本信息
- **严重度**: 2
- **类别**: cmake, conan, packaging, conan2
- **作者**: unknown
- **来源 PR**: (embedmq 1.0.1 适配 PR，创建后回填)

## 错误特征
```
No files in this package|Library '.*' not found in package|Error in package\(\) method|has no attribute 'copy'|'src' and 'dst' arguments must have different values
```

## 根因分析
上游 CMakeLists 只 add_library / add_executable 而不写 install() 规则时，

## 推荐方案
**方法**: conan2-manual-copy-into-package-folder

**说明**: package() 内：先从 conan.tools.files 导入 copy；用

**修复命令**:
```
copy(self, "libname.a", dst=os.path.join(self.package_folder, "lib"),
```

**验证**:
```
find <cache>/p -name 'lib*.a' ; grep -rn "install(" <src>/CMakeLists.txt ; find <pkg>/p -type f
```
