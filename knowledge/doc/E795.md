## 推荐方案
**方法**: scoped-umask-mkdir-and-rename-fallback-and-env-identity

**说明**: ① mkdir 调用点作用域化放宽 umask（保存旧值→umask(0022)→mkdir→恢复，

**修复命令**:
```
保存旧 umask；umask(0022); rc=mkdir(name,0777); umask(old);
```

**验证**:
```
在设备可写目录 clang 编译最小探针：mkdir(d,0700) 后
```
