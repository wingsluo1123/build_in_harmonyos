- **严重度**: 2
- **类别**: portability, toolchain, abi, c-language

## 根因分析
C 允许 plain char 符号性由实现决定；OHOS aarch64 工具链（clang 15，

## 推荐方案
**方法**: source-explicit-signed-char

**说明**: 把存哨兵/状态的 char 字段显式改为 signed char（源码级类型修正，不加

**修复命令**:
```
修改结构体字段声明：`char status;` → `signed char status;`（同字段
```

**验证**:
```
探针：`printf 'int main(){char c=-1;return c==-1?0:1;}' | clang -x c - -o /tmp/c && /tmp/c; echo $?`
```
