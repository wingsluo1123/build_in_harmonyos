# E813: C++17 下 register 关键字位于安装的公共头文件时须源码补丁（toolchain-flag 无法保护消费者）

## 基本信息
- **严重度**: 2
- **类别**: headers, c++, consumer, cppstd-17
- **作者**: unknown

## 错误特征
```
ISO C\+\+17 does not allow 'register' storage class specifier|
```

## 根因分析
2003 年代 C++ 代码使用 register 存储说明符（C++17 移除）。

## 推荐方案
**方法**: source-patch-installed-header

**说明**: 在 conanfile.py build() 的 apply_conandata_patches 阶段，用补丁

**修复命令**:
```
patches/000X-register-remove.patch: VolVolume.hpp 中
```

**验证**:
```
grep -nE '\\bregister\\b' <installed>/include/coin/*.hpp 应 0 命中；
```
