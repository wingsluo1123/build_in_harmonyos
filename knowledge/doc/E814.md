# E814: clips 6.3 嵌入式 API 两个易错语义：EnvBuild 每次只解析一个 construct；EnvFunctionCall 返回 TRUE=出错/FALSE=成功

## 基本信息
- **严重度**: 1
- **类别**: packaging, testing, api-semantics, clips, embed
- **作者**: unknown

## 错误特征
```
EnvRun.*fires.*rule.*FAIL|
```

## 根因分析
>

## 推荐方案
**方法**: split-constructs-per-envbuild-and-validate-data-object

**说明**: 每个 construct 单独调用一次 EnvBuild；EnvFunctionCall 断言写 ==0（FALSE=成功）并用 GetpType/ValueToLong 验 DATA_OBJECT 值

**修复命令**:
```
EnvBuild(env, "(deftemplate claim (slot content))"); EnvBuild(env, "(defrule r ...)"); EnvFunctionCall(env, "+", "2 3", &rv) == 0 && ValueToLong(GetpValue(&rv)) == 5
```

**验证**:
```
真机隔离作业 conan create archives/c/clips/6.3 后运行
```
