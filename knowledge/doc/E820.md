# E820: libsigc++-style CMake: patch away hardcoded add_library(SHARED) and add ARCHIVE/RUNTIME install destinations so Conan's BUILD_SHARED_LIBS actually controls the artifact; keep upstream tests (do not follow conan-center's patch that deletes them)

## 基本信息
- **严重度**: 2
- **类别**: conan, recipe-cmake-packaging
- **作者**: unknown

## 错误特征
```
add_library\(\$\{[A-Za-z_]+\} SHARED|install \(TARGETS.*LIBRARY DESTINATION "lib"\)|cannot install.*without ARCHIVE|CMAKE_CXX_STANDARD 17
```

## 根因分析
Upstream CMakeLists hardcodes add_library(${SIGCPP_LIB_NAME} SHARED ...) so a Conan static build (R26) never produces the archive, and install(TARGETS ...) declares only LIBRARY DESTINATION so even a type-flexible build would not install the static archive or Windows runtime; root CMakeLists additionally hardcodes set(CMAKE_CXX_STANDARD 17) which overrides the profile compiler.cppstd. libsigc++ 3.8.0 tarballs ship Autotools+Meson+CMake in parallel — picking the wrong one (or copying the older 3.0.x Meson recipe) wastes a round.

## 推荐方案
**方法**: three-single-purpose-patches-keep-tests

**说明**: Choose CMake among the triple build systems (matches conan-center libsigcpp/3.x.x and the repo CMake preference). Split the patch chain single-responsibility: 0001 remove the SHARED hardcode in sigc++/CMakeLists.txt (add_library(${NAME} ${SOURCE_FILES}) follows BUILD_SHARED_LIBS) AND add ARCHIVE DESTINATION "lib" + RUNTIME DESTINATION "bin" to install(TARGETS); 0002 delete set(CMAKE_CXX_STANDARD 17) from root CMakeLists so profile cppstd wins; 0003 drop ONLY add_subdirectory(examples) — keep add_subdirectory(tests) so cmake.test() runs the 42 upstream ctest cases for L1 evidence. Package layout keeps upstream names: libsigc-3.0, include/sigc++-3.0 plus the generated sigc++config.h under lib/sigc++-3.0/include (declare BOTH includedirs in package_info); rmdir lib/cmake and lib/pkgconfig so CMakeDeps/PkgConfigDeps properties do not collide with upstream-generated configs. Consumer-test note: libsigc++ 3.x connection::disconnect() returns void (2.x returned bool) — assert via !connected(), not the return value.

**修复命令**:
```
conan create archives/c/c-sig/3.8 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing -nr
```

**验证**:
```
conan create archives/c/c-sig/3.8 -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing -nr
```
