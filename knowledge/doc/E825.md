# E825: autotools 交叉适配 OHOS 的三个连续坑：config.sub 不认 aarch64-linux-ohos、未声明 AC_ARG_VAR 时 --CPPFLAGS/--LDFLAGS 被 configure 拒绝、AutotoolsToolchain 不会自动注入依赖的 include/lib 路径

## 基本信息
- **严重度**: 1
- **类别**: platform, ohos, portability, build-system, autotools
- **作者**: unknown

## 错误特征
```
Invalid configuration `aarch64-linux-ohos': OS `ohos' not recognized|unrecognized option: `--CPPFLAGS=|unrecognized option: `--cppflags=|autoreconf: error: 'configure.ac' is required|json-c/json.h' file not found
```

## 根因分析
(1) Conan 对 OHOS 推导出的 triplet 是 aarch64-linux-ohos，但 automake 自带的 config.sub（1.16）只认 linux/gnu 等已知 OS，直接 configure: error: Invalid configuration；(2) --CPPFLAGS/--LDFLAGS 这类 precious variable 只有在 configure.ac 里用 AC_ARG_VAR 声明后才可用，否则 configure: error: unrecognized option（大小写两种写法都不行）；(3) conan 2 的 AutotoolsToolchain 只设置 CC/CFLAGS/CXXFLAGS/LDFLAGS(defines)/PKG_CONFIG_PATH，不会遍历依赖去加 -I/-L，依赖若是用 AC_CHECK_LIB 而非 PKG_CHECK_MODULES 查找的，include 路径完全不会到达编译器，最终报 'json-c/json.h' file not found；(4) 附带一个布局坑：basic_layout 下 self.run() 的默认 cwd 是 build-release 子目录，里面没有 configure.ac，直接 self.run("autoreconf ...") 会报 autoreconf: error: 'configure.ac' is required。

## 推荐方案
**方法**: pin-triplet-to-aarch64-gnu-and-pass-dep-flags-via-env

**说明**: (1) config.sub 不认 linux-ohos 时，把 --host/--build 都显式钉成 --host=aarch64-linux-gnu --build=aarch64-linux-gnu（canonical 成 aarch64-unknown-linux-gnu，config.sub 接受），编译器驱动仍按 aarch64-linux-ohos 产出对象与链接；同时钉 build 可让"原生 OHOS runner"与"交叉宿主"两种环境行为一致；rt-app 的 configure.ac 无 AC_RUN_IFELSE，所以声明成 native 形态是安全的（若包里有 AC_RUN_IFELSE 则必须改 patch config.sub 加 ohos 分支）；(2) 依赖搜索路径不要指望 --CPPFLAGS/--LDFLAGS：未声明 AC_ARG_VAR 时 configure 会拒绝，改成在 configure 命令前用 CPPFLAGS="..." LDFLAGS="..." 环境变量前缀注入；(3) 依赖的 -I/-L 必须显式从 self.dependencies 遍历 cpp_info.includedirs/libdirs 并与 dep.package_folder 拼接（每个依赖包自己的私有前缀，绝不写 /usr/local），再拼进上面的环境变量前缀；(4) 跑 autoreconf 用 Autotools(self).autoreconf(...)，它默认在 source_folder 执行；若手写 self.run('autoreconf ...') 必须显式 cwd=self.source_folder。

**修复命令**:
```
tc.configure_args += ["--host=aarch64-linux-gnu", "--build=aarch64-linux-gnu"]\nself.run('CPPFLAGS="%s" LDFLAGS="%s" "%s/configure" %s' % (cppflags, ldflags, self.source_folder, " ".join(args)))
```

**验证**:
```
config.sub aarch64-linux-ohos   # 期望 OS `ohos' not recognized
```
