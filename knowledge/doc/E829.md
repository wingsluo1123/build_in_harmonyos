# E829: OHOS/musl 下上游头文件未覆盖 __OHOS__/__linux__ 分支时 htole32/16/64 宏未声明导致链接失败

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, libc, musl, headers
- **作者**: PC1-
- **来源 PR**: libntru-0.5.0-r01

## 错误特征
```
undefined reference due to --no-allow-shlib-undefined: htole32|use of undeclared function .*htole
```

## 根因分析
上游头文件仅按 __APPLE__/__MINGW32__/__GLIBC__<2.9/__OS2__ 条件定义 htole* 宏; OHOS 定义 __OHOS__+__linux__ 但无 __GLIBC__, 宏未声明 (musl 的 htole* 位于 <endian.h>)

## 推荐方案
**方法**: source-patch

**说明**: 头文件增加 #elif defined(__OHOS__) || defined(__linux__) || defined(__FreeBSD__) 分支 #include <endian.h>; 小端平台 htole* 恒等由 musl 提供

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
clang --target=aarch64-unknown-linux-ohos -include endian.h -c test.c && LD_LIBRARY_PATH=. ./testham
```
