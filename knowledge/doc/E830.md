# E830: 判断依赖是否已发布必须读 conan graph info 的 binary 字段，conan download 的退出码会给出反向结论

- **类别**: conan, dependency, false-negative, methodology, preflight
- **作者**: MTX4
- **来源 PR**: 13832

```
No packages found for this revision|error:system acceleration policy not enabled|Missing prebuilt package for '\w+'
```

|

## 推荐方案
**方法**: 用 conan graph info / conan install 读节点 binary 字段作为唯一判据

**说明**: |

**修复命令**:
```
conan graph info --requires=<ref> -pr:h=<profile> -pr:b=<profile> -f=json | python3 -c "import sys,json; d=json.load(sys.stdin); print([(v.get('ref'),v.get('binary')) for v in d['graph']['nodes'].values() if v.get('ref')])"
```

**验证**:
```
conan graph info --requires=<ref> -pr:h=<profile> -pr:b=<profile> -f=json   # 读 nodes[*].binary
```
