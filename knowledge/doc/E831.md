# E831: conanfile 的 generators 必须声明为类属性；只写在注释/文档字符串里不会有任何生成物

## 基本信息
- **严重度**: 3
- **类别**: cmake, conan, generators, pkgconfigdeps
- **作者**: MTX3
- **来源 PR**: 13832

## 错误特征
```
Could not find a package configuration file provided by "\w+"|By not providing "Find\w+\.cmake" in CMAKE_MODULE_PATH|CMake Error at CMakeLists\.txt:\d+ \(find_package\)
```

## 根因分析
Conan 依据 conanfile 的 `generators` 类属性（或 generate() 中显式实例化）决定运行哪些生成器。若把 `generators = "CMakeDeps", "PkgConfigDeps"` 写在文档字符串/注释里而没有作为类属性声明，Conan 不报错，但只生成工具链（conan_toolchain.cmake、CMakePresets.json），不生成任何 `*-config.cmake` 与 `.pc`。于是下游 find_package(CONFIG) 与 pkg_check_modules 全部失败，而报错位置在项目 CMakeLists 上，极易被误判为「依赖没发布」或「上游写错包名」。

## 推荐方案
**方法**: 把 generators 声明为类属性，或改在 generate() 中显式实例化生成器

**说明**: |

**修复命令**:
```
ls <conan-build>/build/Release/generators | head -40
```

**验证**:
```
ls <build>/build/Release/generators    # 期望看到 Xxx-config.cmake 与 *.pc，而非只有 conan_toolchain.cmake
```
