# E834: 1) tarfile.open 一律用 mode="r:*"（自动识别 gz/xz/bz2，纯 Python 无需外部 

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, autotools
- **作者**: unknown

## 错误特征
```
not a gzip file|tarfile\.open.*r:gz|EOFError: Compressed file ended
```

## 根因分析
Python tarfile.open 以 mode="r:gz" 打开 .tar.xz 归档时抛出 "not a gzip file"（read_gzip 魔数校验失败）。x.org 官方发布 .tar.xz，而常见镜像/文档示例默认 r:gz，导致 build() 内源码/SDK 提取静默失败，下游连锁报 fatal error: 'xxx.h' file not found（PR #6361 CI 25 连红的真实根因之一）。

## 推荐方案
**方法**: 1) tarfile.open 一律用 mode="r:*"（自动识别 gz/xz/bz2，纯 Python 无需外部 xz 依赖）；2) 多镜像 fallback 逐个 try/except，全部失败才 raise；3) 下载后先 sha256 校验再解压；4) 提取结果做哨兵校验（关键文件存在才视为成功），防止"下载成功但解压为空"静默通过。参考实现: archives/x/xf86-video-r128/6.13.0/conanfile.py (_download_xorg_server_source/_extract_sdk_headers)。
