# E836: 在测试/用户代码中以 __has_include(<source_location>) 探测，缺失时提供最小 std::

## 基本信息
- **严重度**: P2
- **类别**: compat, toolchain
- **作者**: D997

## 错误特征
```
libcxx-ohos.*source_location.*file not found|<source_location>.*fatal error|source_location file not found
```

## 根因分析
OHOS SDK 自带的裁剪版 libc++ (libcxx-ohos, _LIBCPP_VERSION 15004) 未随附 C++20 头 <source_location>，clang 15 虽支持 -std=c++20/2b 但找不到该头；测试代码 error() 默认参数 std::source_location::current() 仅用 file_name()/line()

## 推荐方案
**方法**: 在测试/用户代码中以 __has_include(<source_location>) 探测，缺失时提供最小 std::source_location shim（current() 用 __builtin_FILE/FUNCTION/LINE/COLUMN，file_name()/line() 等），只补测试代码不动库本体

**说明**: 以 __has_include(<source_location>) 探测缺失并用 __builtin_* 宏实现最小 std::source_location shim，仅覆盖 file_name()/line() 等实际使用成员

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
clang++ -std=c++20 -E -x c++ - <<< "#include <source_location>" 2>&1 | grep -c "file not found"; 修复后 ctest --output-on-failure 全量通过
```
