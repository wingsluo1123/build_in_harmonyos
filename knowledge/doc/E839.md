# E839: prover9 上游手搓递归 Makefile install 并行竞态：-j2 报 Error 1，须 -j1 串行

## 基本信息
- **严重度**: 2
- **类别**: build-system, make, install
- **作者**: B839

## 错误特征
```
make\[1\]: \*\*\* \[Makefile:.*: install\] Error 1|mkdir .* File exists.*prover9|cp: cannot create regular file.*bin/
```

## 根因分析
1990s 风格手搓递归 Makefile（顶层递归 ladr/mace4.src/provers.src/apps.src/，各自有 install 目标）

## 推荐方案
**方法**: 构建与安装一律 -j1 串行（上游全量构建仅 ~11s，并行无收益）；把 `make all -j1 CC=clang XFLAGS="-fPIC -O2"` 固化进配方 build()，不用上游 install 目标，package() 直接 shutil 复制 bin/ 产物（策略 B 手动布局）

**说明**: 并行竞态源于多子目录 install 目标争抢共享 ../bin/；-j1 串行彻底规避，且总耗时 <15s 无并行必要；配方内固化 -j1 保证可复现

**修复命令**:
```
cd source && make all -j1 CC=clang XFLAGS="-fPIC -O2" && package() 中 shutil.copytree(bin/, ${pkg}/bin)
```

**验证**:
```
cd ~/tmp/builds/prover9-2017-11A.work/Prover9-cdca95a51d3c3459b8fd2ebbb5ac1504be2172e3 && make -j2 install 2>&1 | grep -c "Error 1"  # >0 即复现；make -j1 install 全绿
```
