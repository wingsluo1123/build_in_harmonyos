# E840: OHOS libc++ (clang 15 工具链) 未实现 std::string_view 的 operator<=>，C++20 三路比较代码编译失败

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, build-system, cmake
- **作者**: B5EC

## 错误特征
```
invalid operands to binary expression \('std::string_view' \(aka 'basic_string_view<char>'\) and 'std::string_view'\)|no known conversion from 'std::string_view' .* to .* for 1st argument.*operator<=>|no member named 'operator<=>' in namespace 'std'
```

## 根因分析
OHOS SDK 的 libc++ 头文件（clang 15 工具链）不提供 std::basic_string_view 的三路比较运算符（上游 libc++ 在更高版本才实现），任何用 sv <=> sv 的 C++20 代码在该工具链上无法编译

## 推荐方案
**方法**: source-patch

**说明**: 将 sv <=> sv 改写为 sv.compare(other) <=> 0——compare 返回 int，内置整型 <=> 可用，保留 std::strong_ordering 语义

**修复命令**:
```
patch 源文件: return std::string_view{...}.compare(std::string_view{...}) <=> 0;
```

**验证**:
```
echo '#include <string_view>
```
