# E841: pip生成的console script shebang指向构建机Python路径不可迁移

## 基本信息
- **严重度**: 2
- **类别**: portability, python, packaging
- **作者**: B590
- **来源 PR**: 7675

## 错误特征
```
pip.*shebang.*not portable|console_scripts.*absolute path
```

## 根因分析
pip install生成的console script（bin/命令名）shebang硬编码构建机Python绝对路径，

## 推荐方案
**方法**: rewrite-shebang

**说明**: 在conanfile.py的package()中将pip生成的shebang改写为portable shell wrapper

**修复命令**:
```
sed -i '1c#!/bin/sh\nexec python3 -m <module> "$@"' ${conan_package_folder}/bin/<cmd>
```

**验证**:
```
head -1 $(conan cache path <pkg>/<ver>)/bin/<cmd> | grep -E '^#!/.*python'
```
