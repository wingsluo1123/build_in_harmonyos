# E842: 纯数据包（tarball→share/ 安装，无编译无链接）的 conan 配方范式与 R34 数据完整性测试豁免口径

## 基本信息
- **严重度**: 1
- **类别**: packaging, recipe, test
- **作者**: unknown

## 错误特征
```
no callable API|data[- ]only package|no library, no headers|nothing to compile|test_package has no API to call|missing_setting_compiler|missing_setting_build_type|ModuleNotFoundError: hashes_
```

## 根因分析
上游包只发布数据文件（数据库/资源/表），不含源码与构建系统，常规 autotools/cmake 配方模板与 "编译 consumer 调 API" 的 test_package 形态均不适用，需要专用范式

## 推荐方案
**方法**: noarch-data-package-pattern

**说明**: noarch 数据包五件套范式（见下），数据装 share/<生态>/<包名>/，测试以数据完整性验证替代 API 调用

**修复命令**:
```
conan create <配方目录> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```

**验证**:
```
tar -tzf <tarball> | head  # 若只列出 data/** 而无 *.c/configure/CMakeLists.txt 即为纯数据包
```
