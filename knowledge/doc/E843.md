# E843: 消费者测试遇「未初始化链表节点」：SIGSEGV 随 ASLR 漂移的栈外定位与桩层清零分配后端

## 基本信息
- **严重度**: warning
- **类别**: runtime, stub, 内存, 测试策略
- **作者**: B183

## 错误特征
```
sig=11 si_addr=0x[0-9a-f]+|si_addr=0x40000018|Segmentation fault.*(kam_chain|node_sel|ns_list)|\[FAULT\] sig=11.*\(unknown\)
```

## 根因分析
被测库存在**未初始化链表节点**缺陷时，消费者测试会观测到"随机崩溃"而非确定失败。

## 推荐方案
**方法**: consumer-test-zeroing-alloc

**说明**: 桩/测试层的内存后端改用清零分配（calloc 语义），使上游未初始化的 next 字段

**修复命令**:
```
kam_stub_xmallocxz(size) { return calloc(1, size); }   # 桩层 pkg/shm 后端
```

**验证**:
```
./test_presence_modules_e2e <modules_dir>   # 桩层清零后端下连跑 3 次应确定性全绿；
```
