# E844: 上游官方站死亡后 R39 权威镜像源认定：cs.unm.edu 不可达改用 ai4reason 承继仓

## 基本信息
- **严重度**: 2
- **类别**: detection, network, conan
- **作者**: A90F

## 错误特征
```
conandata URL.*cs\.unm\.edu.*(Failed to connect|Connection timed out|unreachable)|ERROR: Unable to download.*unm\.edu|url\.retrieve.*cs\.unm\.edu.*(timed out|refused)
```

## 根因分析
原作者 William McCune 2023 年去世，官方发布站 cs.unm.edu/~mccune/prover9/ 实测不可达

## 推荐方案
**方法**: 按四步论证链认定镜像源（prover9 实证）：① 官方站死亡证据（作者去世公告/域名不可达实测）；② 排除个人随意 fork——查镜像仓的承继关系（ai4reason 仓由社区维护、承载末代官方维护人 Bob Veroff 的延续线 LADR-2017-11A，⭐63 GPL-2.0）；③ 锁定不可变 commit archive URL（github.com/ai4reason/Prover9/archive/<40位sha>.tar.gz）+ sha256 校验；④ 论证链写入 notes.md 与 PR body 补充说明段供人审复核

**说明**: R39 镜像源认定必须可复核：死亡证据 + 承继关系 + 固定 commit + sha256 四要素齐全，杜绝"随便找个 fork"的不合规源

**修复命令**:
```
curl -sI --max-time 10 <official-url> ; curl -sL --max-time 30 -o /dev/null -w '%{http_code}' <mirror-archive-url>  # 官方死+镜像活，再 sha256sum 比对
```

**验证**:
```
curl -sI --max-time 10 https://www.cs.unm.edu/~mccune/prover9/ | head -1  # 超时/不可达即触发；镜像源 sha256 须与官方发布指纹比对（GitHub archive tag 固定 commit 即指纹锚点）
```
