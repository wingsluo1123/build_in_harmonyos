# E845: OHOS libc 符号族 configure 误检的 ac_cv 禁用模式 (fortify __*_chk / fpos64)

## 基本信息
- **严重度**: 2
- **类别**: ohos, libc, configure
- **作者**: 8FBE

## 错误特征
```
call to undeclared function '__fread_chk'|call to undeclared function '__fgets_chk'|use of undeclared identifier 'unknown'|FPOS64_CAST|implicit declaration.*_chk|Permission denied.*confXXXXXX|ungetc.*FAILED|553 tests|streambuf
```

## 根因分析
OHOS (musl 派生) libc 的 fortify helper 与 fpos64 家族与 glibc 语义不同：

## 推荐方案
**方法**: ac-cv-cache-var-disable

**说明**: 用 autoconf 的 ac_cv_* cache 变量按 OHOS libc 实际语义选择性禁用/保留

**修复命令**:
```
./configure ac_cv_func___fread_chk=no ac_cv_func___fgets_chk=no \
```

**验证**:
```
make -j4 && ./configure ac_cv_func___fread_chk=no ac_cv_func___fgets_chk=no ac_cv_func_fseeko64=no ac_cv_func_fsetpos64=no ac_cv_type_fpos64_t=no
```
