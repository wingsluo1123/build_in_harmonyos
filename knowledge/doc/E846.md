# E846: 外部框架头依赖消除：公开头文件引用仓库外作者框架头（AVR/平台专用）→ 以 stdint/stdbool + 所需位宏内联补丁替代 include

## 基本信息
- **严重度**: 2
- **类别**: portability, headers
- **作者**: 8B83

## 错误特征
```
fatal error: 'aKaReZa[^']*\.h' file not found|#include "[a-zA-Z]+\.h"
```

## 根因分析
上游公开头文件 #include 作者个人框架头（如 aKaReZa.h），该头不在本仓库内，且其 AVR 变体仅 AVR 可用（include <avr/io.h>），OHOS PC 无法编译

## 推荐方案
**方法**: inline-bit-macros-portability-patch

**说明**: 用 portability 补丁把 #include "aKaReZa.h" 替换为 <stdint.h> + <stdbool.h> + 所需位宏（bitSet/bitClear/bitCheck/bitChange/bitCheckHigh/bitShiftLeft 等，与作者 STM32 通用变体定义一致），消除对仓库外 AVR 专用框架头的依赖

**修复命令**:
```
conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing
```

**验证**:
```
conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing && CC=/data/service/hnp/bin/clang READELF=/data/service/hnp/bin/readelf STRINGS=/data/service/hnp/bin/strings python3 test_ohos/run_ohos_test.py <pkg>
```
