# E848: conan 版本号含大写字母报 must be all lowercase：slug 小写化 + HMDFS 大小写不敏感两步改名

## 基本信息
- **严重度**: 3
- **类别**: conan, packaging, version
- **作者**: 35E4

## 错误特征
```
Conan packages names '.*' must be all lowercase|ERROR:.*must be all lowercase|L0m: 版本目录.*不是 conan slug|branch name mismatch.*R40
```

## 根因分析
上游版本字符串含大写（prover9 官方发布名 "2017-11A (CIIRC)"）；conan 引用名（name/version）

## 推荐方案
**方法**: 三处统一小写化：① 版本目录 archives/<l>/<pkg>/<ver-slug>/；② conanfile.py version = "2017-11a"（配注释说明上游口径 2017-11A，二进制 --version 横幅断言仍用大写原串）；③ 分支 feat/<pkg>-<ver-slug>（L0n 精确匹配）。HMDFS 大小写不敏感环境改名须两步中转：mv X tmp-X && mv tmp-X x；git branch -m oldA tmpB && git branch -m tmpB newa。commands.json/manifest.yaml/MANIFEST.yml 同步小写 slug

**说明**: conan 引用/目录/分支三处必须同一小写 slug；上游原始版本串保留在描述、notes、横幅断言中（横幅输出 "2017-11A (CIIRC)" 是二进制行为，与小写 slug 无关）

**修复命令**:
```
mv archives/p/prover9/2017-11A archives/p/prover9/p9-tmp && mv archives/p/prover9/p9-tmp archives/p/prover9/2017-11a
```

**验证**:
```
conan create . --name=pkg --version=2017-11A 2>&1 | grep "must be all lowercase"  # 命中即复现；ls archives/<l>/<pkg>/ 与 git branch --show-current 应均为小写 slug
```
