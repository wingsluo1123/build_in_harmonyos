# E850: 上游工具硬编码 /tmp 临时目录且不读 TMPDIR 环境变量，OHOS /tmp 只读导致运行时崩溃

## 基本信息
- **严重度**: 2
- **类别**: platform, portability, libc
- **作者**: 28E9

## 错误特征
```
cannot create temporary: Read-only file system|mkstemp.*EROFS|Read-only file system.*mkstemp|Abort trap.*podiff
```

## 根因分析
上游 C 源码把临时目录硬编码为 "/tmp"（未遵循 GNU TMPDIR 环境变量惯例），

## 推荐方案
**方法**: source-patch

**说明**: 补丁让临时目录优先读 TMPDIR 环境变量（GNU 惯例），未设置时回落 /tmp 保持上游默认行为

**修复命令**:
```
patch: tmpdir = (env = getenv("TMPDIR")) && *env ? env : "/tmp";（见 archives/p/podiff/1.4/patches/0002-main.c.patch）
```

**验证**:
```
grep -n '"/tmp"' *.c（定位硬编码）; TMPDIR=$HOME/tmp ./tool a b; echo $?（适配前 134/SIGABRT，适配后正常 0/1）
```
