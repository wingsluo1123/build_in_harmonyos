# E853: "AX_LIB_READLINE 交叉编译分支固定失败时，以已解析依赖头文件校验后预置缓存结果"

## 基本信息
- **严重度**: 2
- **类别**: ohos, autotools, cross-compile, dependency-check
- **作者**: 2501_91199785

## 错误特征
```
"readline version.*4.3|AX_LIB_READLINE.*cross|ax_cv_lib_readline_version_ok=no"
```

## 根因分析
"旧版 AX_LIB_READLINE 使用 AC_RUN_IFELSE，交叉编译时不能运行探测程序，并把交叉分支写死为 no；目标机还拒绝运行未签名探测 ELF。即使 Conan 提供了足够版本的 readline，configure 仍误报缺失。"

## 推荐方案
**方法**: "verify-resolved-readline-header-then-preseed-cache"

**说明**: "先从 Conan 依赖包的 include 路径读取 readline/readline.h，解析 RL_READLINE_VERSION，确认达到宏要求；再在 configure 命令中预置 ax_cv_lib_readline_version_ok=yes，并保持链接步骤对实际 readline 库的校验。不能无条件强制 yes，也不能把未签名探测程序当作功能测试。"

**修复命令**:
```
"verify RL_READLINE_VERSION in Conan readline.h; configure --host=<target> ax_cv_lib_readline_version_ok=yes"
```

**验证**:
```
"W3 plptools-w3-20260930T173000Z: make check 0/0; four installed CLIs 4/4; receipt 12/12 W3_PASS"
```
