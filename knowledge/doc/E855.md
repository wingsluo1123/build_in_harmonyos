# E855: OHOS musl libc 缺 glibc 专有符号（malloc_stats）用 __GLIBC__ 守卫；uint32 对齐容量 64 位溢出改 size_t 并返回 EINVAL；测试循环计数类型须与 API 返回类型一致

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, musl, testing
- **作者**: 22EC

## 错误特征
```
undefined symbol: malloc_stats|malloc_stats.*referenced|while \(aligned_capacity < capacity\)|TEST failed.*clearsignal|ld\.lld: error: undefined symbol: malloc_stats
```

## 根因分析
①OHOS libc 为 musl 系，无 glibc 专有 malloc_stats()；上游测试在 #ifdef __linux 下编译该路径导致链接失败，需改 #if defined(__linux) && defined(__GLIBC__) 走上游自带回退分支（allocated_bytes 返回 0）。②uint32_t aligned_capacity 在 64 位上可超过 UINT32_MAX：new_iqueue(0xFFFFFFFF) 时左移 2^32 溢出为 0，while(0 < capacity) 死循环；上游在 32 位下靠 (size_t) 上限检查返回 EINVAL，64 位下该检查不可达。③测试循环 for(size_t i=1;;i<<=1) 与 uint32_t 返回类型比较，64 位 i≥2^32 时必然失败；循环计数须与 API 返回/字段类型一致。

## 推荐方案
**方法**: glibc-ext-guard-and-64bit-align-fix

**说明**: ①glibc 专有符号路径用 #if defined(__linux) && defined(__GLIBC__) 守卫，非 glibc（OHOS/musl）走上游自带 #else 回退；②容量对齐变量改 size_t 并在左移前检测超出 uint32_t 范围即返回 EINVAL；③测试循环计数类型与 API 返回类型（uint32_t）对齐。

**修复命令**:
```
sed -i 's/#ifdef __linux$/#if defined(__linux) \&\& defined(__GLIBC__)/' src/test.c   # + size_t aligned_capacity + uint32_t 循环计数
```

**验证**:
```
clang -Iinclude -std=c99 -O3 src/test.c bin/iqueue.a -lpthread -o bin/iqueue_test && ./bin/iqueue_test
```
