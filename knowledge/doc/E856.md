# E856: conanfile generate() 中 save_script("conanbuild") 覆盖 Conan 聚合 env → 自引用递归 SIGSEGV

## 基本信息
- **严重度**: 3
- **类别**: build-system, conan, environment
- **作者**: 0F20, D66C

## 错误特征
```
Error -11 while executing|Signal 11 \(core dumped\)|conanbuild\.sh.*sources.*itself|RecursionError|qmake.*Error -11
```

## 根因分析
Conan 自身在生成目录写入 conanbuild.sh（聚合 profile buildenv），配方 generate() 里再调用 Environment().vars(self).save_script("conanbuild") 会覆盖/改写该脚本，使其 . 自引用自身造成无限递归（栈溢出 → Signal 11 / Error -11），qmake 等子进程崩溃。

## 推荐方案
**方法**: env-apply-context           # 用 with env.vars(self).apply() 替代 save_script

**说明**: generate() 只生成 PkgConfigDeps/.pc；build()/package() 中创建 Environment 并用 with env.vars(self).apply(): 包裹 self.run()（不写 conanbuild.sh，避免覆盖聚合脚本）

**修复命令**:
```
def _build_env(self): env=Environment(); env.prepend_path(...); return env\nwith self._build_env().vars(self).apply():\n    self.run('qmake ...', cwd=src_dir)
```

**验证**:
```
在 build 目录 bash -c '. conanbuild.sh && <tool> --version' 观察 SIGSEGV；或检查生成的 conanbuild.sh 内容是否包含对自身路径的 . 引用。
```
