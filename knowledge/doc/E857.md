# E857: 无构建系统纯 C 库：source() 阶段 save() 注入最小 CMakeLists.txt，走标准 CMakeToolchain 流程（区别于手写 clang/llvm-ar 直接编译）

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan
- **作者**: E047

## 错误特征
```
no such file or directory: '.*\.c'|no input files|System is unknown to cmake|ConanException: \[conf\] 'tools\.build:archiver' does not exist
```

## 根因分析
上游仅含 .c/.h 源文件、无 configure/make/CMake 任何构建入口；init-build 按 autotools 模板生成的配方在 conan create 中失败；手写 clang 直接编译需处理 basic_layout 的 source_folder 路径，且 Conan 2.29 无 tools.build:archiver conf

## 推荐方案
**方法**: inject-cmakelists-at-source

**说明**: source() 内 save() 注入最小 CMakeLists.txt（add_library + PUBLIC_HEADER + install EXPORT + cmake_target_name），generate() 用 CMakeToolchain，build() 走标准 CMake configure/build，package() 用 cmake.install()；比手写 clang/llvm-ar 更贴近 CI 常规路径、免去 basic_layout 路径坑与 archiver conf 问题

**修复命令**:
```
conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing
```

**验证**:
```
conan create . -pr:h=ohos-aarch64 -pr:b=ohos-aarch64 --build=missing（test_package 全部断言通过）
```
