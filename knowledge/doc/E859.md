# E859: 无序集合进入连续整数分组导致合法区间被长度过滤误丢

## 基本信息
- **严重度**: 3
- **类别**: compat, portability
- **作者**: 9665

## 错误特征
```
test_good_port_ranges_unordered_set - assert []|assert [] == [(1003, 1036)]
```

## 根因分析
port-for1.0.0的good_port_ranges将set无排序转list；to_ranges按enumerate的value-index分组，连续整数必须已按数值递增。set迭代折返会把同一合法连续区间拆成短段，再被min_range_len加双border的过滤丢弃。

## 推荐方案
**方法**: sort-before-adjacency-grouping

**说明**: 在good_port_ranges调用to_ranges前以sorted(ports)替代list(ports)。保留范围包含/border/最小长度/长区间排序及socket探测策略；追加1条回归，不删改原断言。

**修复命令**:
```
patch -p1 < patches/0001-sort-port-set-before-range-grouping.patch
```

**验证**:
```
python -m pytest tests/test_cases.py::test_good_port_ranges_unordered_set -ra
```
