# E862: ohpcd 无 r-base：CRAN R 包适配必须走零未发布依赖路线（CI L0i hard-fail）

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, conan
- **作者**: 796E

## 错误特征
```
dependency NOT in registry|Registry unreachable.*r-base|error:system acceleration policy not enabled
```

## 根因分析
ohpcd 制品仓不含任何 R 系包（r-base/4.5.1 实测 HTTP 404，全量 7802 配方搜索无 R 系），而 CI 的 L0i 门禁自 commit 83c2f54f25 起对未发布的 requires 直接 hard-fail（本地对 archives/a/acepack/1.6.3 实测复现 L0_RESULT=fail: gate failed:registry_unreachable）

## 推荐方案
**方法**: dependency-free-adaptation

**说明**: 不声明任何 requires/tool_requires：纯 R 包（NeedsCompilation: no）直接做「上游 R 包树 → lib/R/library/<pkg>/」搬运，build() 只跑 R-free 的结构/数据校验；有 C/Fortran 源码的 R 包则把数值核心编成独立静态库（kernsmooth 路线，只依赖已发布的 flang-ohos+openblas）

**修复命令**:
```
conan create archives/b/boot/1.3-32 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```

**验证**:
```
conan download r-base/4.5.1 -r=ohpcd --only-recipe（rc=1，报 error:system acceleration policy not enabled）；对照 conan download kernsmooth/2.23-26 得 rc=0
```
