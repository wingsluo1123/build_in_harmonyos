# E863: conandata.yml 注释 URL 前缀撞车致 CI Pre-download NotADirectoryError

## 基本信息
- **严重度**: 2
- **类别**: conan
- **作者**: F434

## 错误特征
```
NotADirectoryError.*Not a directory.*predl_cache|Error in source\(\).*NotADirectoryError
```

## 根因分析
ci/conan/build_and_test.sh 的 Pre-download 步骤用正则抓取 conandata.yml 里所有 http(s) URL（含注释行），再用 str.replace 换成 file:// 本地路径。若注释中出现 sources.url 的前缀（例：注释写 https://github.com/atsb/worklog，真实 url 为 https://github.com/atsb/worklog/archive/refs/tags/X.tar.gz），replace 会连带把真正的 source URL 截断成 <hash>_<前缀文件名>/<剩余路径>，conan get() 随即报 NotADirectoryError。本地 conan create 直连官方源不复现，只有走 CI 门禁才炸。GitHub 类深层路径 URL 最易触发。

## 推荐方案
**方法**: conandata.yml 内只允许出现 sources 段那一个以 https:// 开头的 URL；注释里引用仓库地址时去掉 https:// 前缀（如写 github.com/owner/repo），使正则抓不到、也无法构成前缀替换。

**说明**: conandata.yml 注释不得出现 sources.url 的前缀 URL

**修复命令**:
```
sed -i 's|https://github.com/owner/repo|github.com/owner/repo|g' archives/<l>/<pkg>/<ver>/conandata.yml
```

**验证**:
```
grep -oE "(https?://[^[:space:]\"']+)" archives/<l>/<pkg>/<ver>/conandata.yml | wc -l  # 期望 1
```
