# E866: 旧式 C 源码缺 <time.h>：ctime/gmtime 隐式声明返回 int，aarch64 上指针被截断，编译仅告警、运行时段错误

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, libc, headers
- **作者**: F4EE

## 错误特征
```
call to undeclared function '(ctime|gmtime|localtime|time|strftime|mktime)'|
```

## 根因分析
上世纪 90 年代 C 源码（sysnews news.c）调用 ctime()/gmtime()/time()/strftime() 却没有

## 推荐方案
**方法**: include-missing-libc-header

**说明**: 用 refresh-patch 给对应 .c 增加缺失的标准头（<time.h>），不使用任何平台宏，对所有平台都是正确修复

**修复命令**:
```
sed -i 's|#include <limits.h>|#include <limits.h>\n#include <time.h>|' news.c && clang -Wall -O2 -c news.c 2>&1 | grep -c undeclared
```

**验证**:
```
cd $SRC && clang -Wall -O2 -c news.c 2>&1 | grep -c "undeclared function"; 补丁后应为 0；
```
