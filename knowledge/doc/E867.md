# E867: Makefile 调用 pod2man 解析到错误解释器（系统 perl 版本冲突或 conan perl 包 shebang 损坏）

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, autotools, perl
- **作者**: EF4F

## 错误特征
```
bad interpreter.*bin/perl|//bin/perl|doesn't match executable|PERL5LIB|Compilation failed in require at.*pod2man|Can't locate.*strict.pm.*@INC.*//lib
```

## 根因分析
'autotools Makefile 裸调 pod2man/pod2html, PATH 上系统(HNP) pod2man 与 conan perl 包 PERL5LIB 并存时 Config.pm 版本断言失败(5.42.0 vs 5.42.2), 而 conan perl 包自身的 pod 工具脚本 shebang 又是损坏的 "#!//bin/perl"（重定位缺陷）, 两条路都不通'

## 推荐方案
**方法**: pin-interpreter-script-in-makefile

**说明**: 构建期程序化改写 Makefile, 把 pod2man/pod2html 替换为 "<conan perl 绝对路径>" "<pod 工具脚本绝对路径>" 形式, 用解释器直接执行脚本, 绕过损坏的 shebang 与 PATH 顺序不确定性

**修复命令**:
```
content.replace("\tpod2man ", "\t\"%s\" \"%s\" " % (perl_bin, pod2man_script))  # 在 bash config.status 之后、make 之前对 Makefile 执行
```

**验证**:
```
head -1 $(conan cache 内 perl 包 bin/pod2man)  # 观察 #!//bin/perl
```
