# E868: Release 自带完整解析器时，区分 configure 的强制工具探测与真实再生成依赖

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, autotools, conan
- **作者**: 2501

## 错误特征
```
could not find required installation of FLEX|could not find required installation of BISON
```

## 根因分析
AC_PROG_LEX/AC_PROG_YACC 后的无条件报错并不检查归档是否含完整生成物，因而即使发布包已有双前缀 parser/lexer C 与匹配头文件，configure 仍拒绝缺少开发期生成器的目标。

## 推荐方案
**方法**: release-generated-parser-build-equivalence

**说明**: 以官方发行归档为输入，保留全部生产翻译单元和匹配 parser/lexer 输出；逐项补齐真实配置宏与安装契约，不调用无必要的生成器探测；保持所有注册上游测试，不用消费者测试冒充上游。

**修复命令**:
```
核对官方发行包中每份 grammar 的生成 C/头文件与完整生产源清单；只在无需再生成时用 Conan CMakeToolchain 构建完整生成物，并执行上游及安装消费者测试。
```

**验证**:
```
核对官方归档 SHA-256、所有 Makefile.am 生产源与成对生成头文件；在无 flex/bison 的目标运行完整 Conan create 与安装后解析/算法/错误输入测试。
```
