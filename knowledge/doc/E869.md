# E869: Upstream shunit2 runner pipes suites to tee and reports failure while make test exits zero

## 基本信息
- **严重度**: 2
- **类别**: detection, testing, shell
- **作者**: 1245

## 错误特征
```
FAILED \(failures=[1-9][0-9]*\)|[0-9]+ tests, [1-9][0-9]* failures, 0 skipped
```

## 根因分析
The shell runner pipes each shunit2 suite to tee, discarding suite exit status; it prints failed assertions without returning nonzero, so absent optional unace/unrar tools cause make test to return zero despite real failures.

## 推荐方案
**方法**: inspect-shunit-summary-and-dependencies

**说明**: >

**修复命令**:
```
grep -E 'Ran [0-9]+ tests|FAILED \(failures=|^OK$|tests, [0-9]+ failures' upstream.log
```

**验证**:
```
make test > upstream.log 2>&1; rc=$?; grep -E 'FAILED \(failures=|tests, [0-9]+ failures' upstream.log; printf 'make_rc=%s\n' "$rc"
```
