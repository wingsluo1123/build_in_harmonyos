# E870: 通过 npm 分发的单文件 bash 脚本（无扩展名，package.json 含 bin）被 lang-preflight 判 nodejs 且源码统计为空，默认口径会误写 env_unsupported 终态

## 基本信息
- **严重度**: 2
- **类别**: limitation, detection, build-system
- **作者**: X7C1

## 错误特征
```
detected_language.*nodejs.*无源文件可统计|build_system.*npm.*package\.json 含 main/scripts/engines/bin|语言不匹配: task=cpp, detected=nodejs
```

## 根因分析
lang_detect._manifest_scan 见到 package.json 含 "bin" 键即判 manifest=nodejs/npm；源码统计 _EXT_LANG 只按扩展名归类

## 推荐方案
**方法**: declare-detector-language-and-document

**说明**: 赛事接受 Shell 适配，不是止损条件。先用只读 detect_language 判定并确认仓库只有 bash 脚本（head -1 看 shebang、无 JS 源码），

**修复命令**:
```
python3 $SKILL_ROOT/scripts/ohc-run.py lang-preflight <软件> <版本> --src $BUILD_SRC_DIR --lang nodejs
```

**验证**:
```
python3 -c "import sys; sys.path.insert(0,'scripts'); from ohc.lang_detect import detect_language; print(detect_language('<src>'))"; head -1 <src>/<bin 脚本>
```
