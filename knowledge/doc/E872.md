# E872: Qt JSON 日期测试须显式区分本地时区输入与序列化格式

## 基本信息
- **严重度**: 2
- **类别**: compat, portability
- **作者**: 2501

## 错误特征
```
FAIL!.*JsonCreatorTest::test(EpisodeActions|Settings)
```

## 根因分析
无时区的 QDateTime::fromString 默认按本地时间解析；生产代码转换 UTC 后数值变化，而 QVariant JSON 日期与显式 Qt::ISODate 字符串还具有不同的毫秒格式。

## 推荐方案
**方法**: source-patch

**说明**: 先定位实际序列化 API 和接口契约，再为 UTC fixture 显式 setTimeSpec(Qt::UTC)，按各 API 保留精确格式断言，完整重跑原测试。

**修复命令**:
```
先比较原始 fixture 的 timeSpec 与生产 toUTC/toString 调用；在测试源码为 UTC 输入声明 timeSpec，分开验证 QVariant JSON 毫秒和 ISODate 输出；重跑每个命名用例。
```

**验证**:
```
分别回读两个 QtTest 程序的 -functions 清单并完整执行；核对 32+5 个逻辑方法的命名 PASS 与进程 RC0，不计 initTestCase/cleanupTestCase。
```
