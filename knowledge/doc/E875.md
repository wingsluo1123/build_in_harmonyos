# E875: Separate byte-case API contracts from a native strcasecmp oracle on high bytes

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, testing
- **作者**: 2501

## 错误特征
```
strcasecmp \(0\) and .*case_compare \(1\) differ|case comparison oracle differs on high bytes
```

## 根因分析
A byte-oriented library folds unsigned octets with toupper, but its upstream test assumes native strcasecmp has identical ordering. On the current OHOS libc the original Latin-1 pair compares equal with strcasecmp while toupper/tolower preserve those high bytes.
