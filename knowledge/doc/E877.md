# E877: Zero the full pointer member of a mixed integer/pointer union

## 基本信息
- **严重度**: 3
- **类别**: ohos, aarch64, cpp, pointer-initialization, union
- **作者**: 2501_91199785

## 错误特征
```
killing signal catched|SIGSEGV.*Var::copy_value|invalid.*m_value.c
```

## 根因分析
A value-initialized union initializes only its first member. When the first member is int32_t but later code reads char* from the same union, the pointer's upper bytes are not guaranteed to be zero on AArch64. A copy constructor then treats garbage m_value.c as allocated storage and writes through it.

## 推荐方案
**方法**: initialize-full-pointer-union-storage

**说明**: Make the pointer member the first union member when the existing constructors use value initialization, or explicitly initialize the pointer member in every constructor. Preserve the union's external layout and verify copy, destruction, and full upstream tests on the target.
