# E878: 替换/降级测试框架版本导致 ±inf 断言假失败：googletest 1.14.0 的 ASSERT_NEAR 没有同号无穷短路分支，把两侧都等于 -inf 的比较算成 NaN

## 基本信息
- **严重度**: 2
- **类别**: compat, build-system, testing
- **作者**: 962E

## 错误特征
```
The difference between .* is nan, which exceeds|
```

## 根因分析
googletest 1.14.0 的 DoubleNearPredFormat 先算 diff = fabs(val1 - val2)，

## 推荐方案
**方法**: pin-upstream-pinned-test-framework-revision

**说明**: 把 vendor 的测试框架换回**上游自己钉的同一 revision**，不要用"仓库里别处现成"的版本；

**修复命令**:
```
grep -rn "googletest/archive" <upstream-src>/cmake/DownloadGoogleTest.cmake
```

**验证**:
```
sh $HOME/tmp/xnnpack-0.0-git20241108.4ea82e5/repro-e756.sh
```
