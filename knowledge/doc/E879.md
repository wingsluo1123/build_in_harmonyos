# E879: clang 把裸 -export-dynamic 当成 -e xport-dynamic：ELF 入口点丢失，程序启动即 SIGSEGV

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, build-system, autotools, clang
- **作者**: 4C11

## 错误特征
```
cannot find entry symbol [A-Za-z-]*dynamic
```

## 根因分析
自动化工具生成的 Makefile 里把 --export-dynamic 写成裸 -export-dynamic；GCC 驱动把它当自身选项转成 --export-dynamic，而 clang 驱动不识别、原样转给链接器，链接器按 -e 解析成入口符号 xport-dynamic（不存在），ELF e_entry 因此未设置。

## 推荐方案
**方法**: patch-generated-makefile-link-flag

**说明**: 把裸 -export-dynamic 改成 -Wl,--export-dynamic（只补丁生成物 Makefile.in，不动 Makefile.am，避免触发 automake 重生成）。

**修复命令**:
```
在生成的 Makefile.in 里把 '-export-dynamic' 改成 '-Wl,--export-dynamic'（补丁），随后用 readelf -h <bin> | grep Entry_point 复核
```

**验证**:
```
readelf -h <bin> | grep Entry_point（应为非 0 的可执行地址）；构建日志里出现 ld.lld 的一行 cannot find entry symbol xport-dynamic 警告
```
