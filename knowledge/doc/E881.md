# E881: tool_requires autoconf 会把 perl/5.42.2 的 PERL5LIB（threaded XS）灌进构建环境，而 automake/aclocal 的 shebang 写死 HNP 的非线程 perl —— 两者混用必炸 `Perl_my_cxt_init` 符号失配（symbol not found）；正解是不 tool_requires autoconf（用 HNP 的 autoreconf/autoconf），只留 automake/1.18 并把 PERL5LIB 收窄到 automake share

## 基本信息
- **严重度**: 2
- **类别**: platform, ohos, toolchain, perl, conan
- **作者**: 47D9

## 错误特征
```
Perl_my_cxt_init.*symbol not found|Can.t load .*auto/Cwd/Cwd\.so|Error relocating .*\.so.*symbol not found at .*XSLoader
```

## 根因分析
HNP（/data/service/hnp）自带 autoconf/autoreconf/autoheader/autom4te/m4/perl（perl 5.42.0，archname=aarch64-linux，非线程），但**不含 aclocal/automake**；conan 的 automake/1.18 包里 `.aclocal-real`/`.automake-real` 的 shebang 被写死为 `#!/data/service/hnp/bin/perl`（PATH 前置改不了绝对 shebang）。一旦配方再 tool_requires autoconf/2.72，它的传递依赖 perl/5.42.2（archname=aarch64-linux-thread-multi，线程版）会把自己的 XS 库目录灌进 buildenv 的 PERL5LIB；于是 HNP 的非线程 perl 去加载线程版的 `auto/Cwd/Cwd.so`，动态重定位缺 `Perl_my_cxt_init` 直接失败，aclocal 第 31 行 `require File::Path` 即中止、autoreconf rc=255。两层叠加还有第二面：OHOS profile 把 /data/service/hnp/bin 排在 PATH 最前，HNP 的 autoreconf 会遮蔽 conan 提供的同名工具，而设备上 harmonybrew 的 aclocal/automake 1.19 又会让「设备全绿、CI 却用 1.18」的两套判据面出现（设备事实 §一.4 同族）。

## 推荐方案
**方法**: drop-autoconf-tool-require-narrow-perl5lib

**说明**: 不要 tool_requires autoconf/2.72（它连带 perl/5.42.2，PERL5LIB 注入即触发 XS 符号失配）；HNP 已有 autoreconf/autoconf/autoheader/autom4te/m4/perl，直接用它，只补 HNP 缺的 automake/1.18。每条 self.run 前缀 `PATH="<conan-bin>:…:$PATH" PERL5LIB="<automake-pkg>/share/automake-1.18"`：PATH 前置保证设备与 CI 都用 conan 的 aclocal/automake（避免 harmonybrew 1.19 与 CI 1.18 两套判据面），PERL5LIB 收窄后 HNP perl 用自己的核心 XS、Automake::* 纯 perl 模块仍可加载。若必须保留 autoconf tool_requires，则要给 aclocal/automake 做 shim 用 conan perl 绝对路径调 .real 脚本，代价更大。

**修复命令**:
```
self.run(f"{env_pre} autoreconf -fi", cwd=work)   # env_pre = PATH="<conan bin>:$PATH" PERL5LIB="<automake share>"
```

**验证**:
```
sh -c "P=$(ls -d $HOME/.conan2/p/perl*/p/lib/perl5/5.42.2 2>/dev/null | head -1); [ -n \"$P\" ] && PERL5LIB=$P /data/service/hnp/bin/perl -MCwd -e 1"; sh -c "unset PERL5LIB; /data/service/hnp/bin/perl -MCwd -e \"print qq(ok\\n)\""
```
