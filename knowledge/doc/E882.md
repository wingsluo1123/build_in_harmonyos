## 推荐方案
**方法**: autotools-libtool-bootstrap-plus-synthetic-input-test

**说明**: tool_requires 补齐 automake/libtool 引导链 + 三元组与 umask 两处 HMDFS 归一 + 按四口径清点上游 N=0 后，用「读解析代码逆向合成最小合法输入」重建测试面，并把上游演示程序端到端跑成带产物断言的证据。

**修复命令**:
```
self.tool_requires("automake/1.18"); self.tool_requires("libtool/2.5.4"); tc.configure_args += ["--build=aarch64-unknown-linux-ohos", "--host=aarch64-unknown-linux-ohos", "--enable-static", "--disable-shared"]; self.run("autoreconf -fi", cwd=self.source_folder, env="conanbuild")
```

**验证**:
```
cd "$HOME/ws/tmp/builds/libsmacker-1.1.1r35.orig" && grep -rnE "\bassert\s*\(|#include <assert\.h>|EXPECT_|ASSERT_|CK_assert|cmocka|CuTest|TEST\(|START_TEST" --include=*.c --include=*.h . | wc -l; grep -nE "^(TESTS|check_PROGRAMS|check-local)" Makefile.am | wc -l
```
