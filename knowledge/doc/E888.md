# E888: "Upstream assertions that can never pass on 64-bit OHOS ((unsigned long)atof(-1) is UB and aarch64 fcvtzu saturates to 0, and 4294967295 hardcodes 32-bit long) must not be edited to pass — gate them with a known-failure whitelist, per-TEST rc archiving and two-stage make-check cross-checking"

## 基本信息
- **严重度**: !!int "3"
- **类别**: upstream-test-known-broken
- **作者**: unknown

## 错误特征
```
"grep 65535|grep 4294967295|is not a valid positive integer, will use \\[0\\]|[0-9] of [0-9] tests failed"
```

## 根因分析
"opt_atou() computes x = (unsigned long)atof(s); converting the negative double -1.0 to unsigned long is undefined behaviour, aarch64's fcvtzu saturates it to 0 (x86-64 would wrap), and the upstream expectation 4294967295 = 2^32-1 hardcodes a 32-bit unsigned long so no 64-bit platform can ever print it. Editing the assertions would be test-tuning; Debian's own opt_3.19-4 debian/rules tolerates the identical failures with 'dh_auto_test || true'."

## 推荐方案
**方法**: "known-failure-whitelist-gate-with-two-stage-cross-check"

**说明**: "Run each automake TEST individually with '{ cmd; rc=$?; echo HMBS_TEST_RC name=$rc; exit $rc; } > log 2>&1' and read the rc back from the log (missing rc = judge evidence missing -> raise). Then run 'make check' for the framework PASS:/FAIL: view and require both stages to agree. Count assertions with make-noise lines stripped ('make: ... is up to date.' contains dots) and treat '^Error: ' lines as failed assertions. Gate: failures must be a subset of the known broken set {USHORT error, ULONG error}, only checkopt may be non-zero, all three TESTs must be present; anything else raises ConanException. Emit HMBS_UPSTREAM_TEST_RESULT with the real failed count and report the real pass rate in notes and the PR body — never edit the assertions, never edit the library, never write PASS."

**修复命令**:
```
"grep -E '^(PASS|FAIL):|HMBS_UPSTREAM_TEST_RESULT' <build>/make-check.log <build>/upstream-*.log"
```

**验证**:
```
"sh -c 't=\"$HOME/tmp/opt-3.19/w0/probe3/b/test/testtypes\"; \"$t\" -n -1; \"$t\" -o -1'"
```
