# E889: "When upstream is dead, source from the Debian/Ubuntu pool with a four-source same-sha cross-check plus dual .dsc Checksums-Sha256 corroboration, and only pick a URL whose PF7 _pf7_classify is None (deb.debian.org is blocked both http and https)"

## 基本信息
- **严重度**: !!int "2"
- **类别**: source-acquisition-mirror
- **作者**: unknown

## 错误特征
```
"PF7.*(Debian 下游重打包源|明文 http 源)|vanished upstream|search_url.*(404|could not resolve)"
```

## 根因分析
"Upstream project sites from the 2004 era are gone (OPT: vanished upstream as of 2011-04-28 per Debian copyright), so the only authoritative copies are distro pool files; but PF7 rejects deb.debian.org for both plaintext http ('R39 requires https') and https ('Debian repack source'), so the obvious pool URL never passes preflight. Trusting a single mirror without cross-checks risks a wrong sha256 or a gzip-transparent-decoding mismatch between download stacks."

## 推荐方案
**方法**: "four-source-same-sha-plus-dual-dsc-plus-pf7-none"

**说明**: "Download the same orig tarball from four hosts (ftp.debian.org, archive.ubuntu.com, plus two non-blacklist mirrors) with both curl and urllib; require sha256 distinct=1 across all eight fetches and record Content-Encoding. Corroborate with the Checksums-Sha256 blocks of both Debian and Ubuntu .dsc files (they must agree on hash and size). Simulate PF7 (_pf7_classify) for every candidate URL and only write the one that returns None; keep the two blocked deb.debian.org forms in notes as counter-evidence. Add in-tree version evidence (configure.in AM_INIT_AUTOMAKE, version.texi, NEWS) and write the four-way sha table plus the repro commands into notes.md."

**修复命令**:
```
"python3 -c \"import sys; sys.path.insert(0, '$HOME/ws/build_in_harmonyos/scripts'); from ohc.preflight import _pf7_classify; print(_pf7_classify('https://ftp.debian.org/debian/pool/main/o/opt/opt_3.19.orig.tar.gz'))\""
```

**验证**:
```
"sh -c 'for u in https://ftp.debian.org/debian/pool/main/o/opt/opt_3.19.orig.tar.gz https://archive.ubuntu.com/ubuntu/pool/universe/o/opt/opt_3.19.orig.tar.gz https://mirrors.ustc.edu.cn/debian/pool/main/o/opt/opt_3.19.orig.tar.gz https://mirrors.tuna.tsinghua.edu.cn/ubuntu/pool/universe/o/opt/opt_3.19.orig.tar.gz; do curl -sS -m 60 \"$u\" | sha256sum; done | sort -u'"
```
