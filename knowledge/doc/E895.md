# E895: 上游 configure 用 command -v ed 决定安装名：产物名随构建机环境漂移

## 基本信息
- **严重度**: 2
- **类别**: build-system
- **作者**: F3C5

## 错误特征
```
installed binary name differs between builders: ed vs oed
```

## 根因分析
oed 的手写 configure 在 146-150 行用 command -v ed 判断 PATH 中是否已有 ed，有则把 prog 设为 oed、否则设为 ed。因此同一个源码在不同构建机上装出的可执行文件名不同（ed 或 oed），产物不可复现，消费者按名字调用也会失败。

## 推荐方案
**方法**: 显式固定产物名

**说明**: 配置阶段显式传入 --program-name=ed（上游已支持该选项），使安装名与构建机 PATH 解耦。

**修复命令**:
```
./configure --program-name=ed && grep '^prog' Makefile
```

**验证**:
```
./configure && grep PROG Makefile   # 换 PATH 会得到不同值
```
