## 根因分析
A custom bootstrap recipe that relies on a host compiler name or an ambient temporary directory is not reproducible in a closed OHOS Conan environment. tempfile.mkdtemp inherits TMPDIR, and a worker path under /storage/Users can allow Phase 1 execution while rejecting the Phase 2 rename/locking operations, producing ios_base::failure: Operation not permitted. A later worker root under /data/storage/el2/base/cache passed basic create/write/rename checks but still failed when build2 replaced its existing executable target, reporting failed to update .../build2/b/exe{b.}, so the probe must cover replacement-over-existing and the next candidate should prefer /data/local/tmp. Keeping HOME/XDG/TMP on /storage can preserve the same restriction after the source tree moves, so all child-tool state must bind to the probed root. The OHOS SDK clang++ wrapper can then invoke llvm/bin/lld without its sibling llvm/lib/libxml2.so.16 in LD_LIBRARY_PATH, yielding xml* relocation failures after object compilation. Build2 testscript files are also target-typed by directory buildfiles; passing raw file paths can resolve file{...} targets and fail after the suite was discovered. After the compiler, permitted work root, SDK runtime libraries, and target syntax are bound, every expanded phase still needs an independent terminal. CI #37895 additionally failed in Phase 2 because libbuild2/cc/pkgconfig.hxx includes libpkg-config/pkg-config.h from the vendored libbutl tree, but the bootstrap command did not import libbutl's exported build configuration; explicitly setting config.import.libbutl to the copied libbutl source makes that include closure visible. CI #37986 then failed G0e because current main contributed tracked root markers .ci-branch-marker-v6 and .ci-marker-v7b that were absent from the historical PR diff; a feature branch that is merged with the current main and explicitly deletes those markers carries the required removal in the next PR diff. CI #39372 proved that copying an already built tree between CI_REPO_ROOT and Conan cache children does not repair Bash startup: both /storage candidates still deny the parent traversal Bash performs before reading the script. A missing imported vendored dependency, a main-only CI marker, or a shell-startup cwd limitation is a configuration/CI-boundary failure, not a reason to reduce the upstream test denominator.

## 推荐方案
**方法**: bind-closed-bootstrap-toolchain-and-target-replacement-root

**说明**: Resolve the target compiler from Conan conf rather than shell variables, keep vendored dependencies in the recipe source tree, choose a permitted OHOS work root with bounded filesystem probes before bootstrap, require replacement-over-existing executable semantics and prefer /data/local/tmp before app cache, bind HOME/XDG/TMP/TEMP below it, derive the OHOS SDK llvm/lib runtime directory for LD_LIBRARY_PATH, enable build2 -V when a nested final update reports only failed to update, pass config.import.libbutl=<copied-libbutl-root> for libpkg-config/pkg-config.h and its exported closure, rebase or merge the current target main before final CI so root-marker changes are represented in the PR diff and delete only the known CI marker files that violate the whitelist, preserve upstream test bytes while using a task-private stable-cwd Bash launcher when /storage startup getcwd fails, interpose a target-compiled test-only helper for a proven missing GNU command option while preserving ordinary platform-command behavior, invoke tests through the declared testscript{stem} root runner while separating common harness files from runnable targets, and publish only phases with authoritative terminal results.

**修复命令**:
```
'conan create recipe --profile:host=<ohos-profile> -c tools.build:compiler_executables.cpp=<absolute-clang++>; verify package binary and consumer --version'
```
