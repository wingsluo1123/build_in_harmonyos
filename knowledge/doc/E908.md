# E908: 显式窄整数指针转换在 aarch64 上截断地址

## 基本信息
- **严重度**: 2
- **类别**: compat, portability, autotools, runtime
- **作者**: 6837
- **来源 PR**: !9557

## 错误特征
```
cast to smaller integer type.*unsigned|pointer.*truncat|Segmentation fault \(core dumped\)
```

## 根因分析
旧 C/C++ 代码把指针显式转换为 32 位 unsigned 参与对齐或地址运算；在 64 位目标上高位地址被截断，编译仅给出警告，首次执行相关路径时会访问错误地址并产生 SIGSEGV。

## 推荐方案
**方法**: pointer-width-safe-alignment

**说明**: 引入 stdint.h，使用 uintptr_t 完成指针宽度安全的对齐/地址运算，再按原表达式语义转换回指针；保留原始分配边界和掩码，不用诊断抑制掩盖问题。

**修复命令**:
```
"#include <stdint.h>; #define ALIGN(p) ((uintptr_t)((p) + ALIGNBYTES) & ~(uintptr_t)ALIGNBYTES)"
```

**验证**:
```
grep -n 'ALIGN.*unsigned' src/*.h; make -j1; make -j1 check; clang -Wall -Wpointer-to-int-cast -c affected.c
```
