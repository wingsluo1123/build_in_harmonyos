# E909: 平台无 raw socket/真实网卡 → 用上游官方 SKIP_* 环境变量机制跳过平台阻塞测试（SKIP_ETHERNET）

## 基本信息
- **严重度**: 3
- **类别**: platform, portability, network, testing
- **作者**: 4725

## 错误特征
```
Could not find the interface|Could not open an ETH recv channel|ETH recv|raw socket|AF_PACKET
```

## 根因分析
check_pubsub_connection_ethernet 打开 AF_PACKET raw ETH socket 需要真实以太网接口与 raw-socket 能力；OHOS worker 无接口（/sys/class/net 不可访问）且无权限，ETH recv 通道必然失败。上游在 ethernet_config.h 提供官方 SKIP_ETHERNET 环境变量，main() 检测到即 EXIT_SUCCESS；这是上游自带机制而非伪造通过

## 推荐方案
**方法**: generate() 设 SKIP_ETHERNET=1；台账将该用例如实记录为 not-run/platform-blocked + 恢复条件（有网卡/raw socket 权限的环境），不计为通过

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan create . --user=ohpcd --channel=stable -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing（SKIP_ETHERNET=1 后 exit_code=0，146/146）
```
