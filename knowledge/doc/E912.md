# E912: Validate test_package helper imports on the executed path

## 基本信息
- **严重度**: 1
- **类别**: conan, test-package-runtime
- **作者**: A7F3
- **来源 PR**: https://gitcode.com/OpenHarmonyPCDeveloper/build_in_harmonyos/pull/8134

## 错误特征
```
"NameError: name .* is not defined|test_package.*build failed after package created"
```

## 根因分析
A test_package can pass recipe syntax and package creation while a helper function references a standard-library module that was never imported. The missing import appears only when the CI test-package path executes that helper, after the main package has already built.

## 推荐方案
**方法**: executed-helper-import-audit

**说明**: For every helper called by test_package build() or test(), inspect imports and run the branch under the same profile and environment as CI; do not treat conan create of the main package as sufficient.

**修复命令**:
```
python -m py_compile test_package/conanfile.py && conan create <recipe> -pr:h=<ohos-profile> -pr:b=<windows-profile>
```

**验证**:
```
Run the exact test_package build path used by CI and require the helper branch to execute; fail closed on NameError before claiming package validation.
```
