# E913: Bind the OHOS linker host runtime beside the selected LLVM toolchain

## 基本信息
- **严重度**: 1
- **类别**: ohos, cross-compile, linker-runtime
- **作者**: A7F3, 1742
- **来源 PR**: https://gitcode.com/OpenHarmonyPCDeveloper/build_in_harmonyos/pull/8134

## 错误特征
```
"Error loading shared library libxml2.so.16|Error relocating .* lld: .* symbol not found|unable to execute command"
```

## 根因分析
A target worker may expose a clang wrapper in one directory while its lld binary loads host-side shared libraries from a versioned SDK llvm/lib directory. CMake invoked with env=None does not inherit a usable runtime path, so compilation succeeds until lld starts and fails to load libxml2.so.16 or relocations.

## 推荐方案
**方法**: task-owned-llvm-runtime-path

**说明**: Discover only compiler-adjacent SDK llvm/lib candidates containing the required host linker runtime, prepend the selected directory to the current process environment, and keep shared tool directories untouched.

**修复命令**:
```
test -f <sdk>/ohos/native/llvm/lib/libxml2.so.16 && LD_LIBRARY_PATH=<sdk>/ohos/native/llvm/lib:$LD_LIBRARY_PATH cmake -S . -B build
```

**验证**:
```
Before CMake configure, resolve the compiler-adjacent versioned SDK llvm/lib directory containing libxml2.so.16, prepend it to the task process LD_LIBRARY_PATH, then verify the CMake compiler probe and consumer link complete.
```
