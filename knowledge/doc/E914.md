# E914: explicit-status-check

## 基本信息
- **严重度**: 3
- **类别**: consumer-validation, release-build
- **作者**: 2301_80739235
- **来源 PR**: 8474

## 错误特征
```
"assert.*NDEBUG|Release.*assert|consumer.*PASS.*without.*check"
```

## 根因分析
The C and C++ assert macros are removed when NDEBUG is defined, so a consumer test that only uses assert can print PASS after an incorrect result in the default Release configuration.

## 推荐方案
**方法**: explicit-status-check

**说明**: Replace assertion-only validation with an explicit condition that reports the mismatch and returns non-zero before any PASS marker.

**修复命令**:
```
"if (actual != expected) { report failure; return 1; }"
```

**验证**:
```
Build the consumer in Release, inspect the binary path, and exercise a deliberate mismatch to require a non-zero exit; then run the real consumer and require the expected PASS output.
```
