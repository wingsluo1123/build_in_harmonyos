# E915: capability-gated-test-registration

## 基本信息
- **严重度**: 2
- **类别**: platform, cmake, capability, upstream-tests
- **作者**: 2301_80739235
- **来源 PR**: 8474

## 错误特征
```
"no type named 'suspend_point'|no member named 'suspend'|__TBB_RESUMABLE_TASKS"
```

## 根因分析
An upstream CMake test list can register a test unconditionally even when the test source excludes itself or its public API is disabled by a target capability macro. On OHOS oneTBB sets __TBB_RESUMABLE_TASKS false because the target is Linux-like but not glibc, while the resumable-task conformance target still compiles against the unavailable API.

## 推荐方案
**方法**: capability-gated-test-registration

**说明**: Keep the upstream test option enabled. Gate only the unsupported target using the exact CMake platform or capability condition, preserve every other test, and report source inventory and target-supported inventory as separate denominators.

**修复命令**:
```
"inspect capability macro and test/CMakeLists.txt; patch one registration; run ctest --output-on-failure"
```

**验证**:
```
Enable the upstream test option, inspect the target capability macro and registration site, apply the smallest platform condition, then run the complete remaining CTest inventory and record the excluded test name and reason.
```
