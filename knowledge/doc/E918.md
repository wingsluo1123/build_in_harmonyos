# E918: 固定端口测试套件在 ctest 并行执行下互相冲突（Address in use / 假 SEGFAULT）→ CTEST_PARALLEL_LEVEL=1 串行化

## 基本信息
- **严重度**: 3
- **类别**: portability, cmake, conan, testing
- **作者**: DC03

## 错误特征
```
Address in use|Broken pipe|SEGFAULT|tests failed out of
```

## 根因分析
多个 server 测试套件经 UA_ServerConfig_setDefault 绑定同一固定默认端口 4840；CTEST_PARALLEL_LEVEL=16 时并行运行互相抢端口，表现 Address in use / Broken pipe / 虚假 SEGFAULT，30/146 项失败；串行后 0 失败

## 推荐方案
**方法**: conanfile.py generate() 设 CTEST_PARALLEL_LEVEL=1（配方层，无源码补丁）；上游默认即串行，并行是配方作者加的加速项

**说明**: 一句话描述这个推荐方案

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
conan create . --user=ohpcd --channel=stable -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing（串行配置后 exit_code=0，146/146 通过）
```
