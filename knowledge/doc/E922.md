# E922: OHOS 用 musl libc，getopt() 严格 POSIX 不做 GNU 置换——选项放在文件名之后会被当成输入文件

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, libc, musl, posix
- **作者**: potool019

## 错误特征
```
"Can't open input file: -|Cannot open (input )?file: -[a-z]|optind=1 argc=|positional\\[[0-9]+\\]=-[a-z]"
```

## 根因分析
|

## 推荐方案
**方法**: reorder-argv-options-first

**说明**: 把调用方脚本里的选项搬到文件名之前（`$potool -fnth "$POFILE"`），同步改写同一行的错误提示串；不要动被调用程序的 getopt 解析器（改脚本面最小、且不改上游 C 语义）

**修复命令**:
```
"$potool \"$POFILE\" -fnth  →  $potool -fnth \"$POFILE\""
```

**验证**:
```
"cd /storage/Users/currentUser/tmp/potool-0.19/w0 && clang -O0 -o gpprobe gpprobe.c && ./gpprobe in.po -fnth && ./gpprobe -fnth in.po"
```
