# E925: OHOS 单文件 Perl 脚本包适配套路：shebang 必须改 /usr/bin/env perl（设备与 worker 均无 /usr/bin/perl，toybox env 无 -S 故 -w 不可保留），lang-preflight 对无扩展名脚本恒判 other 须按 §4.2 人工复核留证

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, build-system
- **作者**: DACA

## 错误特征
```
bad interpreter|/usr/bin/perl.*No such file or directory|Unknown option .S perl|detected_language.*other|无可统计源文件|Can't exec .locale
```

## 根因分析
设备与 CI worker 的 perl 都在 HNP 路径（/data/service/hnp/bin/perl 5.42.0），/usr/bin/perl 不存在，上游 shebang 直执即 rc=126 bad interpreter；shebang 改 /usr/bin/env perl 后可直执（/usr/bin/env 存在＝toybox）。上游 shebang 上的 -w 开关无法随 env 形式保留（toybox env 不支持 -S，实测 rc=125），实测去掉 -w 前后 stdout/stderr 行为一致。lang_detect 只按扩展名与构建系统统计，无扩展名单文件脚本恒返回 other（无可统计源文件）且不嗅探 shebang，若按真实语言传 perl 会触发假 env_unsupported 终态并污染 result 草稿链。缺 locale 命令时 mencal 类 backtick 降级只产生 stderr 两行噪声，stdout 正确，测试应只断言 stdout。

## 推荐方案
**方法**: shebang-env-perl-and-lang-manual-review

**说明**: 新增单文件脚本包时三步走。一 shebang：在 .work 里改首行为 #!/usr/bin/env perl（不要试 env -S 保 -w，toybox 不支持），track-edit add 登记后 refresh-patch --auto 产补丁并在 build() 加守卫断言（首行不符即 RuntimeError）防补丁静默失效假绿。二 lang-preflight：检测报 other 且 evidence 为无可统计源文件时，先用 file 与 head -1 人工复核定真实语言，再以 --lang other 取 rc=0 过门禁（真实语言证据进 notes/feedback/知识草稿三处披露），禁止按 perl 传参吃假 env_unsupported 终态（依据 device-facts §4.2 误判不构成终止依据）。三 测试与产物：build 只做安装树装配（system none），test_package 断言直执（证明 shebang 生效）加 -V 版本串；运行期噪声（缺 locale 等）只断言 stdout 不断言 stderr 为空；测试临时目录走 TMPDIR 链而非 PWD（否则落进工作区污染提交面）。

**修复命令**:
```
conan create /storage/Users/currentUser/ws/worktrees/mencal-3.0/archives/m/mencal/3.0 -pr:h=/storage/Users/currentUser/ws/worktrees/mencal-3.0/ci/conan/profiles/ohos-aarch64 -pr:b=/storage/Users/currentUser/ws/worktrees/mencal-3.0/ci/conan/profiles/ohos-aarch64 --build=missing
```

**验证**:
```
cd /storage/Users/currentUser/tmp/mencal-3.0/w0src/mencal-3.0 && head -1 mencal && ./mencal -V; echo rc=$?
```
