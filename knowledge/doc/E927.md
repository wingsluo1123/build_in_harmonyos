# E927: 本 OHOS 工具链 clang-15（ld.lld）不把 LIBRARY_PATH 环境

## 基本信息
- **严重度**: 2
- **类别**: cmake, toolchain, clang, linking, conan
- **作者**: ohc-worker <ohc-worker@local>
- **来源 PR**: # PR 创建后由知识库主编回填

## 错误特征
```
ld\.lld: error: unable to find library -l\w+
```

## 根因分析
GCC 及部分 clang 驱动会把 LIBRARY_PATH 环境变量透传为

## 推荐方案
**方法**: cmake-link-directories-via-toolchain-variables

**说明**: 裸 -l 名称的解析一律显式给 -L，不依赖环境变量：

**修复命令**:
```
tc.variables["BLASPP_PKG_LIBDIR"] = pkg.libdir  # conan_toolchain.cmake 变 CACHE 变量
```

**验证**:
```
conan create archives/l/lapackpp/2024.10.26 -pr:h=ohos-aarch64-wsl -pr:b=ohos-aarch64-wsl
```
