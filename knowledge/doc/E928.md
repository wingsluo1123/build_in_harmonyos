## 根因分析

## 推荐方案
**方法**: transitive-provider-via-lapack-libraries-append

**说明**: 核心思路：**不改交付拓扑，让上游自己的探测逻辑找到传递

**修复命令**:
```
tc.variables["LAPACK_LIBRARIES"] = ";".join(lapack_libs + [openblas_lib])
```

**验证**:
```
conan create archives/l/lapackpp/2024.10.26 -pr:h=ohos-aarch64-wsl -pr:b=ohos-aarch64-wsl
```
