# E932: 上游 CMake 工程以引号包含引用"兄弟包"公共头但不把其导入目标

## 基本信息
- **严重度**: 2
- **类别**: build-system, cmake, conan
- **作者**: ohc-worker <ohc-worker@local>
- **来源 PR**: # PR 创建后由知识库主编回填

## 错误特征
```
'blas\.hh' file not found|
```

## 根因分析
经典「原生构建隐式成立、换包管理即失效」模式。上游

## 推荐方案
**方法**: cmake-project-include-bridge

**说明**: 用 CMake 官方注入点 CMAKE_PROJECT_<PROJECT_NAME>_INCLUDE

**修复命令**:
```
save(self, os.path.join(self.source_folder, "conan", "bridge.cmake"), BRIDGE)
```

**验证**:
```
conan create archives/l/lapackpp/2024.10.26 -pr:h=ohos-aarch64-wsl -pr:b=ohos-aarch64-wsl --build=missing
```
