# E937: BLAS++/LAPACK++ 族 CMake 后端探测失败（-lblas 裸链接缺 Fortran 运行时）；

## 基本信息
- **严重度**: 3
- **类别**: build-system, cmake, fortran, blas, lapack
- **作者**: ohc-worker <ohc-worker@local>
- **来源 PR**: # PR 创建后由知识库主编回填（执行体单次 push 口径，见 final-report 遗留项）

## 错误特征
```
BLAS\+\+ requires a BLAS library and none was found|
```

## 根因分析
blaspp/lapackpp（UTK ICL SLATE 族）不用 conan，其

## 推荐方案
**方法**: blas-libraries-passthrough

**说明**: 走 finder 内置的第一候选 BLAS_LIBRARIES/LAPACK_LIBRARIES

**修复命令**:
```
tc.variables["BLAS_LIBRARIES"] = ";".join([lapack_a, cblas_a, blas_a, frt_a, fdec_a, "m"])
```

**验证**:
```
conan create archives/b/blaspp/2024.10.26 -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=ci/conan/profiles/ohos-aarch64 --build=missing
```
