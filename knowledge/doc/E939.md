# E939: touch-t-dependency-order-normalization

## 基本信息
- **严重度**: 2
- **类别**: build-system, autotools, automake, make-dist, timestamps
- **作者**: lnav-0.13.2 任务
- **来源 PR**: feat/lnav-0.13.2

## 错误特征
```
(aclocal|automake|autoconf)-[0-9.]+\s.*is missing on your system|
```

## 根因分析
automake 生成的 Makefile.in 自带 maintainer 规则

## 推荐方案
**方法**: touch-t-dependency-order-normalization

**说明**: 构建前（configure 之前）用 touch -t 显式分钟级时间戳按

**修复命令**:
```
touch -t 202601010000.00 configure.ac *.m4 **/*.m4 &&
```

**验证**:
```
grep -n "am--refresh\|$(ACLOCAL)" <包>/Makefile.in | head -3
```
