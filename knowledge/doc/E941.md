# E941: 镜像级文件系统工具（UDF toolkit）在 OHOS 的“无挂载闭环”验证模式：文件镜像须显式扇区大小，写路径依赖介质语义

## 基本信息
- **严重度**: 2
- **类别**: ohos, portability, runtime, testing, filesystem
- **作者**: 9C4A
- **来源 PR**: 13235

## 错误特征
```
UDF volume sets marked alive :\s*$|Can't determine directory the new directory needs to be created in|b 2048
```

## 根因分析
工具默认按光盘介质推断扇区大小，对普通文件镜像不适用：未显式 -b 2048 时 mount 路径扫不到 VDS（udfdump/udfclient 输出 “UDF volume sets marked alive :” 为空），只有顺序描述符扫描（-S）仍可读；镜像写路径（mkdir/put）依赖介质写语义，上游在纯文件镜像上给出 “Can't determine directory ...” 而不落盘。

## 推荐方案
**方法**: file-image-explicit-sector-size-and-readonly-loop-test

**说明**: 文件镜像一律显式 -b 2048；闭环测试 = newfs_udf 建镜像 → udfdump -S 命中卷标 → udfdump -b 2048 [-t] 卷集/目录树 → printf 'ls\nexit\n' | udfclient -b 2048 只读列举 → 缺失镜像负向控制；写路径与 SCSI/光盘工具列为未验证边界。

**修复命令**:
```
printf 'ls\nexit\n' | udfclient -b 2048 img.udf
```

**验证**:
```
newfs_udf -L OHOSTESTVOL -b 2048 -s 8192 img.udf && udfdump -S img.udf | grep OHOSTESTVOL && udfdump -b 2048 img.udf | grep 'Volume set'
```
