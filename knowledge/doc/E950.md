# E950: COIN-OR 家族下游包 configure 报依赖不可得：已发布依赖包 .pc 固化 prefix=/ 且 Libs 内嵌构建机绝对路径，须改子包 configure 的 flags 模式注入

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability, build-system, autotools
- **作者**: coinor-cbc-2.10.13

## 错误特征
```
One or more required packages CoinUtils, Osi, and Cgl are not available|Required package Clp unavailable|checking for COINDEPEND\.\.\. no|Package .* not found in the pkg-config database
```

## 根因分析
COIN-OR 依赖包（coinutils/osi/clp/cgl）以 autotools prefix=/ 安装打包, 生成的 .pc 把 libdir 固化为 /lib 且 Libs 字段内嵌构建时的绝对缓存路径, 下游（如 Cbc）子包 configure 的 AC_COIN_CHECK_PACKAGE 经 pkg-config 解析时指向不存在的路径; configure 的 flags 分支（--with-<pkg>-lib/--with-<pkg>-incdir/--with-<pkg>-datadir）可直接置 coin_has_*=yes 并跳过 pkg-config

## 推荐方案
**方法**: build-config

**说明**: 直接驱动子包 configure（顶层 configure 仅做子包编排），以 flags 模式显式注入——incdir 只收单目录故先合并各包 include/coin 到单一 staging；闭包链接串以直连 .a 路径按依赖方在前重复展开（libCgl.a libOsi.a libCoinUtils.a libz.a -lm 等，禁用 -l 形式见 forbid_2）；测试数据以 --with-<pkg>-datadir 注入；可选外部求解器逐个 --without-*

**修复命令**:
```
./configure --prefix=/ --enable-static --disable-shared --disable-dependency-tracking --with-coindepend-incdir=<merged-include> --with-coindepend-lib='<cgl>/lib/libCgl.a <osi>/lib/libOsi.a <coinutils>/lib/libCoinUtils.a <zlib>/lib/libz.a -lm' --with-clp-incdir=<merged-include> --with-clp-lib='<clp>/lib/libOsiClp.a <clp>/lib/libClpSolver.a <clp>/lib/libClp.a <同前闭包>' --with-ositests-lib='<osi>/lib/libOsiCommonTests.a <同前闭包>' --with-sample-datadir=<Data-Sample> --with-miplib3-datadir=<Data-miplib3>
```

**验证**:
```
grep -n "libdir=" <依赖包>/lib/pkgconfig/*.pc; pkg-config --libs coinutils（应见 -L/lib 或绝对缓存路径即为不可用形态）
```
