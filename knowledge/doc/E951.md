# E951: test_package 用字符串切分 tested_reference_str 取版本：conan-verify（带 user/channel）通过，W3/CI（无 user/channel）引用形如 name/ver#<recipe-revision>%<timestamp>，比对失败

## 基本信息
- **严重度**: 2
- **类别**: conan, version, testing
- **作者**: E327

## 错误特征
```
[0-9][0-9A-Za-z._+-]*#[0-9a-f]{32}%[0-9]+\.[0-9]+|\(test package\): tested reference: .*#[0-9a-f]{32}%[0-9]+
```

## 根因分析
两道本地门禁用的 `conan create` 形态不同：`conan-verify` 传 `--user=ohpcd --channel=stable`，test_package 里 `self.tested_reference_str` 是 `shml/1.1.0@ohpcd/stable`；W3 的 `ci/conan/build_and_test.sh` 与 CI 不传 user/channel，Conan 2.29.1 下它形如 `shml/1.1.0#<recipe-revision>%<timestamp>`（例 `shml/1.1.0#c64f229a68c0ef1a356bc467219d1d75%1790670804.0011215`，revision 与时间戳每次不同）。用 `self.tested_reference_str.split("/", 1)[1].split("@")[0]` 取版本，前一形态得 `1.1.0`，后一形态得 `1.1.0#<recipe-revision>%<timestamp>`，与包自报的版本（如 `shml version 1.1.0`）比对失败，test() 抛自定义异常，W3 判 conan create failed。因为 conan-verify 先跑且通过，问题只在 finish 的 W3 才暴露。

## 推荐方案
**方法**: read-version-from-dependency-ref-object

**说明**: 不要切分引用字符串。在 build()/test() 里用 `dep = self.dependencies[self.tested_reference_str]` 取被测包，再用 `str(dep.ref.version)`（名字用 `dep.ref.name`）获得版本/名字；需要比对包自报版本时用它做期望值。把 `self.output.info(f"tested reference: {self.tested_reference_str} (version {version})")` 留在日志里，两种 conan create 形态的取值一眼可对。修完后必须两种形态都本地实跑（conan-verify 的带 user/channel 形态 + W3 的无 user/channel 形态）。

**修复命令**:
```
version = str(self.dependencies[self.tested_reference_str].ref.version)
```

**验证**:
```
python3 -c 'r="shml/1.1.0#c64f229a68c0ef1a356bc467219d1d75%1790670804.0011215"; print(repr(r.split("/",1)[1].split("@")[0]))'
```
