# E952: 上游 `make test` 在运行时 curl|bash 拉取浮动引用的测试框架（shunt）：配方须固定官方 tag 归档 + sha256 自包含，且 shunt 遇到含 "-h" 的路径会打印 usage 并以 0 退出（测试被静默跳过）

## 基本信息
- **严重度**: 2
- **类别**: network, packaging, testing, shell
- **作者**: 64F7

## 错误特征
```
curl -L https://raw\.githubusercontent\.com/[^ ]+/install\.sh \| bash|test/shunt\.sh: No such file or directory|No rule to make target ['"`]?test/shunt\.sh|L0o: conanfile\.py 使用外部命令 \(curl/wget\) 下载源码|Usage: .*shunt\.sh <test files>
```

## 根因分析
shml 的 Makefile 把测试框架当成运行时下载物：`test/shunt.sh` 目标执行 `curl -L https://raw.githubusercontent.com/odb/shunt/latest/install.sh | bash -s latest local`，而 install.sh 又从 `.../shunt/master/shunt.sh` 下载。引用是浮动的（latest 标签、master 分支）、无任何校验和，且需要出站网络。在 Conan 配方里这条路走不通：CI L0o 禁止 conanfile.py 用 curl/wget 下载；构建/测试机可能无网或无 curl；本地与 CI 拿到的框架版本也无法保证一致。另有一个会让「测试全过」变成假象的坑：shunt.sh 用 `echo "$options" | grep "\-h"` 判定 `--help`，`options` 里包含所有测试文件路径，因此任何路径含 "-h" 的片段（如目录 `my-http/`、`foo-hidden/`）都会触发 `__usage`——打印 Usage 后 `exit 0`，0 个测试被执行而退出码为 0。shunt 的退出码还是失败数（`exit $__failed`），失败数为 256 的倍数时同样退出 0。

## 推荐方案
**方法**: pin-official-tag-archive-of-test-framework

**说明**: 不要在配方或测试脚本里 curl|bash。在 conandata.yml 里给测试框架单独加一段（如 `shunt: {url: 官方 tag 归档, sha256: ...}`，URL 只用官方 github.com/<owner>/<repo>/archive/refs/tags/<tag>.tar.gz），`source()` 里用 `get(self, **self.conan_data["shunt"], strip_root=True, destination=os.path.join(self.source_folder, "shunt"))` 自包含下载；先用 verification_cmd ① 证明固定 tag 与上游浮动引用字节一致再固定。`build()` 里用 `self.run` 以显式 bash 运行 `shunt/shunt.sh --plain --verbose <相对路径的测试文件…>`（cwd=源码根，路径务必相对，避开 "-h" 陷阱），解析汇总行 `Total: N  Passed: P  Failed: F`，并同时断言退出码为 0、F==0、N==预期的运行时断言数（shml 1.1.0 为 172，来自 9 个文件 142 处 assert_equal 调用点）——N 不符即说明测试被静默跳过。日志打印 `<PKG> UPSTREAM TEST PASS/FAIL: P/N`，并在 notes/PR 里如实回填 N 与通过率。

**修复命令**:
```
cd $SRC && bash shunt/shunt.sh --plain --verbose test/*_tests.sh | tail -3   # 相对路径；期望 Total: 172  Passed: 172  Failed: 0
```

**验证**:
```
curl -fsSL https://raw.githubusercontent.com/odb/shunt/master/shunt.sh | sha256sum; curl -fsSL https://github.com/odb/shunt/archive/refs/tags/v0.3.1.tar.gz | tar xzO shunt-0.3.1/shunt.sh | sha256sum
```
