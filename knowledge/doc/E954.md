# E954: 老式 C 代码 times()/CLK_TCK 换算秒数：OHOS musl 无 CLK_TCK 宏，改 sysconf(_SC_CLK_TCK)

## 基本信息
- **严重度**: 2
- **类别**: libc, compilation, api, legacy-c
- **作者**: unknown

## 错误特征
```
use of undeclared identifier 'CLK_TCK'|'CLK_TCK' undeclared|CLK_TCK.*undeclared
```

## 根因分析
CLK_TCK 是 POSIX.1-1988/ANSI 草案时代的"每秒时钟滴答数"宏，POSIX.1-2001 已删除，改由 sysconf(_SC_CLK_TCK) 运行时查询（times() 返回值与 struct tms 字段的单位）。OHOS NDK sysroot（musl 系）的 <time.h>/<sys/times.h>/<limits.h> 均不定义 CLK_TCK，只在 <unistd.h> 提供 _SC_CLK_TCK（值 2）；现代 glibc 在默认特性宏（_DEFAULT_SOURCE ⇒ __USE_XOPEN2K）下同样不定义，gcc -std=c89 亦报 undeclared。1990s 的基准、计时、进程统计工具（ubench、dhrystone 的 times 分支、utime 等）直接用它做除数，于是编译期 error。不能用 CLOCKS_PER_SEC 顶替：那是 clock() 的单位（XSI 规定恒为 1000000），而 times() 的单位是内核 USER_HZ（Linux/OHOS 为 100），错用会让换算出的秒数小 10^4 倍，校准循环（while (load(i) < 0.4s) i*=2）甚至不收敛。

## 推荐方案
**方法**: replace-clk-tck-with-sysconf

**说明**: 在源码补丁里把 CLK_TCK 的每个使用点替换为 sysconf(_SC_CLK_TCK)（需 <unistd.h>，多数老代码已包含），保持除法语义不变；这是可移植 POSIX 写法，不需要 __OHOS__ 等平台宏，补丁可直接进 patches/。ubench 0.32 实测：-cs/-ms 单次校准回报 0.40s，与 0.4s 目标一致。

**修复命令**:
```
sed -i 's/(double )CLK_TCK/(double )sysconf(_SC_CLK_TCK)/' cpubench.c membench.c   # 在 .work 中改源码后 refresh-patch --auto 生成补丁
```

**验证**:
```
grep -rn 'CLK_TCK' <src> ; printf '#include <unistd.h>\nlong t(void){return sysconf(_SC_CLK_TCK);}\n' | clang -x c -c - -o /dev/null   # 前者列出待替换点，后者证明 _SC_CLK_TCK 可用
```
