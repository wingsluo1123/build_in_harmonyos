# E958: Validate OHOS target tool paths with POSIX semantics and defer target filesystem checks

## 基本信息
- **严重度**: 2
- **类别**: meson, cross-compile, conan, path-semantics
- **作者**: 2301_80739235

## 错误特征
```
OHOS Meson builds require an absolute C compiler path|absolute archiver path
```

## 根因分析
Python os.path follows the host platform. During a Windows-hosted OHOS Conan install, os.path.isabs rejects a valid /data/... target path and os.path.isfile queries the wrong filesystem. Generator time needs a syntactically valid target tool path for the Meson cross file, while target existence and executability are build-time properties.

## 推荐方案
**方法**: target-posix-path-generation-build-time-existence

**说明**: Resolve target compiler and archiver values with posixpath.isabs/dirname/join during generate(), emit the exact POSIX archiver into the Meson toolchain, and reuse the same resolver in build() before checking os.path.isfile and os.access on the target host.

**修复命令**:
```
use posixpath for target path syntax in generate(); require file and X_OK at the start of build()
```

**验证**:
```
In a fresh isolated OHOS/armv8 Conan home, run graph info and install --build=never with absolute POSIX compiler paths; require install RC0, then run the production install with relative compiler and relative explicit archiver profiles and require distinct fail-closed RCs and messages.
```
