# E960: 带有无害提示的绘图工具探针应按退出码判定，不能将输出当作缺失功能

## 基本信息
- **严重度**: 2
- **类别**: ohos, test-accounting, tool-probe
- **作者**: 8B7F

## 错误特征
```
SKIP.*_reg|set terminal png.*rc=0.*warning|gnuplot.*font support
```

## 根因分析
上游测试包装器对 gnuplot -e 'set terminal png' 使用非空 stdout/stderr 判失败；OHOS 目标上的真实 gnuplot 选择 PNG 终端成功且返回 0，却因状态文件权限或 libgd 字体回退输出提示，导致 25 项已注册回归测试退出 77 而未运行。

## 推荐方案
**方法**: exit-status-capability-gate-with-full-inventory

**说明**: 在构建源码副本中把外部工具探针从“非空输出即失败”改为“退出码非零才失败”，让工具在可写私有 HOME/TMPDIR 下执行；不删除原测试、断言或工具调用，只有完整回归与实际生成场景均通过时才申报全通过。

**修复命令**:
```
gnuplot -e 'set terminal png'; make check -j1 SHELL=/system/bin/sh; 核对 Automake summary 的 TOTAL/PASS/SKIP/FAIL 与安装后消费者。
```

**验证**:
```
记录工具的退出码和输出；保留全量注册测试分母；按退出码改造门槛后逐项运行原测试并核对 PASS+SKIP+FAIL 等于注册数，另做安装后消费者验证。
```
