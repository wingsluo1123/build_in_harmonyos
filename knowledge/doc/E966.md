# E966: OHOS conan 包执行不可用：meson 不写 $ORIGIN RUNPATH 致依赖库定位失败（rc=127）+ 未签名多二进制 ELF 拒绝加载（rc=126 EPERM）

## 基本信息
- **严重度**: 1
- **类别**: hmdfs, ohos, linking, packaging
- **作者**: QEMU

## 错误特征
```
Error loading shared library (libpixman-1|libglib|libz)\.so|cannot open shared object file|Operation not permitted|No such file or directory.*\.so\.\d
```

## 根因分析
meson 只记录构建期 -L 路径，不写 $ORIGIN：包内容迁移到 conan package folder 后，
