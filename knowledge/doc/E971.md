# E971: OHOS toybox mktemp templates must end with XXXXXX

## 基本信息
- **严重度**: 2
- **类别**: ohos, toolchain, shell, consumer, evidence
- **作者**: 2301_80739235
- **来源 PR**: 6478

## 错误特征
```
mktemp: need XXXXXX: Not supported
```

## 根因分析
The OpenHarmony target toybox mktemp parser requires the six X placeholders to be the final template characters and rejects a literal suffix after them. A host GNU mktemp check may accept name.XXXXXX.conf, while the target fails before launching the consumer. This is a target-tool capability difference, not a package or application failure.

## 推荐方案
**方法**: target-compatible-mktemp-template

**说明**: Use an opaque mktemp template whose final six characters are XXXXXX, keep the parent directory task-owned, and remove the returned file in an EXIT trap. Reject predictable PID names and any host-only assumption about suffix support.

**修复命令**:
```
mktemp "$TMPDIR/consumer-config.XXXXXX"
```

**验证**:
```
Run the production target shell with a template ending in XXXXXX, record the returned path, execute the consumer, and verify uniqueness plus zero task-owned temporary files after EXIT cleanup.
```
