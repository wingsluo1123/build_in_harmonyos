# E974: OpenBSD calendar 依赖外部 cpp 展开 #include，无预处理器环境（OHOS）打不开任何日历文件

## 基本信息
- **严重度**: 2
- **类别**: compat, detection, ohos, portability, libc
- **作者**: 9C4A

## 错误特征
```
calendar:.*cpp.*No such file or directory|/usr/bin/cpp
```

## 根因分析
OpenBSD calendar 把 #include 展开委托给外部 C 预处理器（execl /usr/bin/cpp -traditional ...）；OHOS 无任何 cpp，opencal() 子进程 exec 失败，calendar 报错且不输出任何事件

## 推荐方案
**方法**: builtin-preprocessor-fallback

**说明**: 当 /usr/bin/cpp 不存在时改用内置 #include 展开（pipe+fork 流式），保留 -I. 加 _PATH_INCLUDE 搜索语义；缺失 include 仅告警不中断

**修复命令**:
```
可选: 具体命令模板(${VAR}变量引用)
```

**验证**:
```
calendar -f <file-with-include> -t 20260101
```
