# E979: 无扩展名 POSIX shell 主程序且无构建 manifest 时 lang-preflight 误报 other

## 基本信息
- **严重度**: 2
- **类别**: detection, build-system, shell
- **作者**: 1AD8

## 错误特征
```
detected_language.*other.*无源文件可统计|语言不匹配.*detected=other
```

## 根因分析
lang_detect.py _source_stats 仅根据文件扩展名统计并把 bash 排除 total；主程序 slay 只有 #!/bin/sh 无 .sh 后缀，_manifest_scan 对无 Makefile/configure 的源码返回 None，最终判 other，默认 cpp 任务会自动写错误的 env_unsupported 终态。

## 推荐方案
**方法**: manual-shell-main-source-review

**说明**: 在会写 env_unsupported 终态的 lang-preflight 前复核主程序 shebang 和真实源码；若主程序是无扩展名的 POSIX shell 文件且无编译目标，按当前允许的纯脚本路径打包脚本并如实记载检测误报；用安全 --help 测试实包，不修改源码或框架文件。

**修复命令**:
```
SRC=/absolute/path/to/source; head -n 1 "$SRC/slay"; sh "$SRC/slay" --help
```

**验证**:
```
SRC=/absolute/path/to/source; python3 -c "import sys;sys.path.insert(0,'scripts');from ohc.lang_detect import detect_language;print(detect_language(sys.argv[1]))" "$SRC"; head -n 1 "$SRC/slay"
```
