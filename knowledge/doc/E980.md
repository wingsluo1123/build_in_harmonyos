# E980: 旧式 C 测试程序用 `char` 承接 getopt() 返回值 → OHOS aarch64 上 EOF 哨兵截断失效，测试程序直接退出（`Failed with: Invalid parameter`），整轮用例 0 执行

## 基本信息
- **严重度**: 3
- **类别**: ohos, portability, libc, autotools, testing
- **作者**: 1687

## 错误特征
```
Failed with: Invalid parameter|testsuite.*Invalid parameter|Invalid parameter
```

## 根因分析
测试程序里写 `char c; while ((c = getopt(argc, argv, "...")) != EOF)`：

## 推荐方案
**方法**: use-int-for-getopt-return

**说明**: 在 patches/ 中把承接 getopt() 返回值的 `char` 改为 `int`（getopt 规范返回 int）。

**修复命令**:
```
sed -i 's/^\([[:space:]]*\)char c;/\1int c;/' <test>.c   # 建议以 patches/000N-*.patch 固化，便于审计
```

**验证**:
```
grep -n 'char c;' utils/testsuite.c ;
```
