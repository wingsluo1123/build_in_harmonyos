# E982: conan 组图 zlib 版本冲突：boost 固定 1.3.1 与 glib 固定 1.3.1.1，用 requires(override=True) 统一

## 基本信息
- **严重度**: 2
- **类别**: build-system, dependency
- **作者**: BE99

## 错误特征
```
Version conflict: Conflict between zlib/1.3.1.1 and zlib/1.3.1 in the graph|Conflict originates from glib
```

## 根因分析
两个直接依赖各自的传递依赖钉死了不同的 zlib 精确版本：boost/1.84.0 requires zlib/1.3.1，glib/2.84.0.1 requires zlib/1.3.1.1，conan 组图时两个精确版本冲突（Version conflict ... originates from glib/2.84.0.1）。

## 推荐方案
**方法**: conan-dependency-version-override

**说明**: 在消费者配方 requirements() 里加 self.requires("zlib/1.3.1.1", override=True)，把 boost 侧的 zlib/1.3.1 统一到 glib 侧的 1.3.1.1

**修复命令**:
```
'在消费者 conanfile.py 的 requirements() 内加入: self.requires("zlib/1.3.1.1", override=True)  # 版本取冲突双方中较新的那个'
```

**验证**:
```
conan install --requires=<A/boost-based> --requires=<B/glib-based> -pr:h=ci/conan/profiles/ohos-aarch64 -pr:b=... 复现冲突
```
