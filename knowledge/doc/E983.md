# E983: BSD make $(.TARGET) 语法的手写 Makefile 在 GNU make/Conan out-of-source 构建下的两类规则失效与等价改写

## 基本信息
- **严重度**: 2
- **类别**: portability, build-system, autotools, make, conan
- **作者**: 9C4A
- **来源 PR**: 13235

## 错误特征
```
No rule to make target '.*\.o'|clang: error: no input files|\[<builtin>: \.o\]|\(\.TARGET\)
```

## 根因分析
上游手写 Makefile.in 的链接规则使用 BSD make 专有自动变量 $(.TARGET)（GNU make 无此变量，展开为空），规则退化并触发内建 .o 规则（clang -o .o / no input files）；同时该 Makefile 没有 VPATH，Conan 在独立 build folder 中 configure 后 GNU make 无法在 srcdir 定位 .c 源文件（No rule to make target '<app>.o'）。

## 推荐方案
**方法**: rewrite-bsd-make-rules-to-gnu-make

**说明**: 将 $(.TARGET) 链接规则等价改写为 GNU make 静态模式规则（$(APPS): %: %.o ... + $@.o），并在 Makefile 头部增加 VPATH= @srcdir@ 支持 out-of-source 构建；不改上游源码逻辑。

**修复命令**:
```
patches/0001-Makefile.in.patch (udfclient 0.8.21, PR #13235)
```

**验证**:
```
grep -n '(\$\.TARGET)' Makefile.in; ./configure --prefix=/tmp/p && make -j1
```
