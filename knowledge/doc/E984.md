# E984: OHOS <utmp.h> 只声明 setutent/getutent/pututline/endutent/utmpname：getutline()/getutid() 无声明、libc.so 不导出（仅 libc.a 有），老代码 `u = *getutline(&ut)` 编译报 "indirection requires pointer operand ('int' invalid)"，补 prototype 后动态链接 undefined symbol，改静态链接又因 musl utmp 桩恒返回 NULL 而在退出时 SIGSEGV

## 基本信息
- **严重度**: 2
- **类别**: portability, libc, musl, headers
- **作者**: 788E

## 错误特征
```
call to undeclared function 'getutline'|
```

## 根因分析
OHOS SDK（clang 15.0.4，aarch64-unknown-linux-ohos）的 sysroot/usr/include/utmp.h

## 推荐方案
**方法**: getutent-scan-with-null-check

**说明**: 用已声明且 libc.so 导出的 getutent() 顺序扫描替代 getutline()/getutid()：

**修复命令**:
```
python3 scripts/ohc-run.py refresh-patch --auto <软件> <版本>
```

**验证**:
```
SR=$NDK/sysroot; L=$SR/usr/lib/aarch64-linux-ohos
```
