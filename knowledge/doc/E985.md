# E985: spdlog 包把 include/spdlog 列为 include 路径，使 <fmt/ranges.h> 命中 spdlog 自带 shim，真 fmt 头被 #pragma once 吞掉导致 fmt::join 未声明

## 基本信息
- **严重度**: 2
- **类别**: headers, c++, conan, dependency, compilation
- **作者**: 2264

## 错误特征
```
no member named 'join' in namespace 'fmt'|fmt::join.*undeclared|'join' is not a member of 'fmt'|error: no matching function for call to 'join'
```

## 根因分析
>

## 推荐方案
**方法**: narrow-dependency-includedirs-in-generate

**说明**: 在配方 generate() 中把 spdlog 的 cpp_info.includedirs 覆盖为仅

**修复命令**:
```
self.dependencies["spdlog"].cpp_info.includedirs = [os.path.join(self.dependencies["spdlog"].package_folder, "include")]
```

**验证**:
```
编译命令中 grep '-isystem .*spdlog/include/spdlog' 有命中即可疑；
```
