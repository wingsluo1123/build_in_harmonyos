# E987: 版本串带 dfsg 后缀且上游官网已死链时，源从 Debian/Ubuntu pool 的 .orig.tar.xz 取，包版本串保持任务分支同形

## 基本信息
- **严重度**: 2
- **类别**: detection, portability, build-system
- **作者**: 0E6E

## 错误特征
```
'ERROR: Error downloading file|The requested URL returned error: 404|sha256 signature failed for file|ERROR: Invalid configuration'
```

## 根因分析
Debian 系发行版对上游源码做 DFSG 重打包（剥离不可再分发文档/字体等），版本串变成 <上游版本>+dfsg.N；若干年后上游站点改版（如 LBNL crd-legacy.lbl.gov/~dhbailey/mpdist 重定向到门户页、davidhbailey.com/dhbpapers 404），原始 tarball 只剩发行版 pool 里还有副本

## 推荐方案
**方法**: debian-pool-source

**说明**: 从 deb.debian.org/debian/pool/main/<首字母>/<包名>/ 找 <包名>_<上游版本>+dfsg*.orig.tar.*，实际下载并计算 sha256 写入 conandata.yml（同机从 deb.debian.org 与 ports.ubuntu.com 下载各验一次一致性）；包版本串保持任务分支门禁同形（如 2.3.23-dfsg.1，连字符形），不必改写成 Debian 的 +dfsg.1 形态——conan get(strip_root=True) 会剥掉 tarball 顶层目录（qd-2.3.23+dfsg.1），顶层目录名与包版本串不一致无影响

**修复命令**:
```
curl -sL -o src.tar.xz "https://deb.debian.org/debian/pool/main/q/qd/qd_2.3.23+dfsg.1.orig.tar.xz" && sha256sum src.tar.xz
```

**验证**:
```
curl -sI "https://deb.debian.org/debian/pool/main/<首字母>/<包名>/" | grep -o 'href="[^"]*orig[^"]*"'
```
