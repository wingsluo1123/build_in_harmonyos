# E989: autotools 把生成的 PDF 文档列进 BUILT_SOURCES，out-of-tree/无 LaTeX 构建在 make all 第一步即失败

## 基本信息
- **严重度**: 3
- **类别**: portability, build-system, autotools
- **作者**: CE02

## 错误特征
```
'make\[\d+\]: \*\*\* docs?: No such file or directory\.  Stop\.|make: \*\*\* \[Makefile:\d+: docs?/[^]]*\.pdf\] Error \d+|No rule to make target .docs?/.*\.pdf. needed'
```

## 根因分析
上游 Makefile.am 把 docs/*.pdf 写进 BUILT_SOURCES（automake 在 all 之前必建）和 dist_doc_DATA；out-of-tree 构建目录里没有 docs/ 子目录（make -C docs 直接 No such file or directory），且设备/CI 都没有 LaTeX 工具链，即使补上目录也造不出 PDF

## 推荐方案
**方法**: patch-makefile-in

**说明**: 补丁生成的 Makefile.in：BUILT_SOURCES 置空并从 dist_doc_DATA 移除 PDF（保留 README，automake 的 install 规则对缺失文件有 $(srcdir)/ 回退，README 在 out-of-tree 下可正常安装）

**修复命令**:
```
sed -i 's/^BUILT_SOURCES = docs\/qd.pdf$/BUILT_SOURCES =/; s/^dist_doc_DATA = README docs\/qd.pdf$/dist_doc_DATA = README/' Makefile.in
```

**验证**:
```
grep -n "BUILT_SOURCES" Makefile.am Makefile.in
```
