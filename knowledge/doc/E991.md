# E991: OHOS 无系统时区数据库：Python 标准库 zoneinfo（tzlocal/dateparser 走它）需随包 vendored PyPI tzdata

## 基本信息
- **严重度**: 2
- **类别**: compat, ohos, portability, python, runtime
- **作者**: U4D2

## 错误特征
```
zoneinfo\._common\.ZoneInfoNotFoundError|No time zone found with key|tzlocal\(\) does not support non-zoneinfo timezones like
```

## 根因分析
本平台没有 /usr/share/zoneinfo（stdlib zoneinfo 的 TZPATH 系统目录全部不存在），Python 标准库

## 推荐方案
**方法**: vendor-tzdata-package

**说明**: 把 PyPI 的 tzdata 包（zoneinfo 数据库）vendored 进包内 site-packages；stdlib zoneinfo 在系统

**修复命令**:
```
pip install --only-binary=:all: --target=<私有 deps 目录> tzdata
```

**验证**:
```
python3 -c "import zoneinfo; print(zoneinfo.ZoneInfo('UTC'))"
```
