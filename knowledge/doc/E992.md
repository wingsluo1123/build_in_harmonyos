# E992: 纯脚本 CLI 的语言预检把 Bash 排除主体统计，误阻断已批准脚本适配

## 基本信息
- **严重度**: 2
- **类别**: limitation, detection, build-system, shell
- **作者**: ADAF

## 错误特征
```
语言不匹配: task=cpp, detected=other|无可统计源文件.*env_unsupported|纯 shell.*detected_language=other
```

## 根因分析
lang_detect.py _source_stats 对 .sh 增加 bash 计数，但总数 total 排除 bash；无 C/C++ manifest 的上游纯 shell 项目即使包含真实可执行脚本，也被判 other(none)。旧 R47 默认以任务 cpp 和 other 不兼容自动写 env_unsupported；在脚本工具已获准适配的任务中，此结果只说明无 C/C++ 编译主体，不说明脚本不可打包。

## 推荐方案
**方法**: explicit-script-acceptance-and-real-consumer-test

**说明**: 先核对用户/赛事是否允许纯 shell，再检查官方源码清单及版本；获准的任务明确指定 lang-preflight --lang other，记录检测到的 other 与批准理由；配方无编译，安装原版脚本并实际执行安装后 CLI 的行为断言，不伪称交叉编译或 qemu 实跑。未获准时仍按旧 R47 上报真实语言/能力限制。

**修复命令**:
```
python3 scripts/ohc-run.py lang-preflight xtitle 1.0.4 --src /root/tmp/builds/xtitle-1.0.4.work --lang other
```

**验证**:
```
python3 scripts/ohc-run.py lang-preflight xtitle 1.0.4 --src /root/tmp/builds/xtitle-1.0.4.work --lang other && python3 scripts/ohc-run.py conan-verify xtitle 1.0.4
```
