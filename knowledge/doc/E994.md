# E994: x86_64 runner 经 binfmt 执行 OHOS aarch64 动态产物报 Could not open '/lib/ld-musl-aarch64.so.1'：功能验证改用同源 .o 静态重链 + qemu-aarch64，test_package 显式 SKIPPED

## 基本信息
- **严重度**: 2
- **类别**: platform, limitation, musl, testing
- **作者**: lkjing2021345 <1908499668@qq.com>
- **来源 PR**: (本 PR)

## 错误特征
```
aarch64-binfmt-P: Could not open '/lib/ld-musl-aarch64.so.1'|qemu-aarch64: Could not open '/lib/ld-musl-aarch64.so.1'|Could not open '/lib/ld-musl-aarch64.so.1': No such file or directory
```

## 根因分析
交叉构建 runner 是 x86_64，binfmt_misc 以 qemu-aarch64（flags POF）接管 aarch64 ELF；OHOS 产物是

## 推荐方案
**方法**: static-relink-same-objects-under-qemu

**说明**: conan create 的构建目录（$CONAN_HOME/p/b/<pkg>/b/...）保留着与交付产物同源的 .o：用同一把

**修复命令**:
```
B=$CONAN_HOME/p/b/<pkg-id>/b/src; /data/service/hnp/bin/clang -static -O3 -o $HOME/tmp/<tool>.static $B/*.o && $HOME/tmp/<tool>.static <args>
```

**验证**:
```
file <bin> | grep -o 'interpreter [^,]*'; test -e /lib/ld-musl-aarch64.so.1 || echo 'no OHOS loader on host'; cat /proc/sys/fs/binfmt_misc/qemu-aarch64 | head -3
```
