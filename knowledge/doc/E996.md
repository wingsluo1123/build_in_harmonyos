# E996: CMake install 规范化 RUNPATH 尾冒号（/path/lib: → /path/lib）导致 OHOS bin 可执行文件 execve EPERM

## 基本信息
- **严重度**: 3
- **类别**: ohos, cmake, linking, runtime
- **作者**: unknown

## 错误特征
```
Operation not permitted|Error 126 while executing|cannot execute.*Operation not permitted|install 后 bin.*无法执行
```
