# E998: Conan patch_ng 需要针对实际解压源码验证补丁上下文

## 基本信息
- **严重度**: 3
- **类别**: build-system, conan, testing, patch
- **作者**: 202B

## 错误特征
```
Hunk.*FAILED|patch.*cannot apply|patch_ng.*(mismatch|failed)|Invalid Context|context does not match
```

## 根因分析
unified diff 的 hunk 起始行号只是定位提示，真正能否应用取决于上下文行和 Conan 解压后的源码快照。源码归档、换行、前序补丁或生成文件差异会让看似正确的补丁在 Conan 实际使用的 patch_ng 阶段失败。

## 推荐方案
**方法**: exact-source-patch-validation

**说明**: 用与 Conan recipe 相同的源码归档和 patch_ng，在临时副本按 conandata.yml 顺序逐个应用，并同时执行 git apply --check。

**修复命令**:
```
git apply --check patches/*.patch && conan create archives/e/ext2fuse/0.8.1 --build=missing
```

**验证**:
```
python -c "import patch_ng; print('patch_ng available')" && git apply --check patches/*.patch
```
