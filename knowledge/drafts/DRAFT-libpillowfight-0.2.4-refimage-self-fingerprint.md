## 1. 现象

为把上游测试从 2/15 冲到 15/15，按"决定性实验=参考图自指纹"方向执行：用候选编解码器把
参考图自身解码像素重新编码，逐字节比对输出与参考 jpg 原文件。穷举 libjpeg-turbo
3.0.4 / 3.2.0（Pillow-save 与 cjpeg）与 libjpeg/10（cjpeg）后，15 张参考图**全部 0 命中**，
最近差异均≈文件大小（全字节面不同）。

## 2. 根因（结构性）

JPEG 有损编解码不可逆：参考 jpg 的解码像素 ≠ 其编码前像素（量化丢失信息）。因此对解码像素
用**任何**编码器（即使与生成环境完全同版本同参数）重编码，其 DCT 系数与字节流均与原文件
不同。该"自指纹逐字节复现"判据对任何编码器结构性 0 命中——无法据此锁定生成参考图的
编解码器版本；字节等值测试的"编码器身份"前置无法由该判据确立。

## 4. 处置（libpillowfight R05 实测）

- 记录结构性根因（有损不可逆）与穷举命中表（逐图 × 逐候选：0/15）。
- 转入"可运行最优对齐统一基线"：turbo 3.2.0 编解码器 + glibc rand 家族 shim（逐值校验）+
  qsort_r shim + 默认编译参数；编码参数核对（默认 save==quality 75）与解码确定性复验通过。
- 全量复跑 + 残余漂移量化/空间分布/函数级定位证据链，交分析端最终裁决。

## 5. 边界与反例

- **与 E453 的区别**：E453 是 HMDFS 物化共享库模式校验；本条是测试裁决方法学。
- **与 jpeg-codec-byte-equality 草案的关系**：该条管"编解码器选择影响字节流"；本条管
  "自指纹判据结构性不可达"的裁决路径。
- **反例**：无损编解码（PNG）下自指纹判据可成立；测试用无损中间态比对时不需要此裁决路径。
- **限制**：0 命中不得当作"跳过候选版本"（须穷举并记录不可得/不可用证据）；不得无指纹
  命中表即宣布环境固有不可达。
