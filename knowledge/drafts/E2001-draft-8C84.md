# E2001 — meson custom_target 依赖 /usr/bin/env shebang 在 OHOS 沙箱不可用

meson.build 的 custom_target command 直接执行 python 脚本时依赖脚本 shebang /usr/bin/env；OHOS 沙箱与精简环境无 /usr/bin/env（实测 Permission denied），custom command 无法执行。

修复：custom_target command 改用 find_installation('python3') + script 显式执行（command: [python, script]），不依赖 shebang。
