# E202610130531 — CWEB 在较长 Conan 路径下生成失败

SGB 20210202 使用已发布 `cweb/4.12.2` 生成源码时，传入完整 Conan 缓存路径产生 `Filename too long` 与 `ctangle failed for gb_flip`。CWEB 的 `max_file_name_length` 缓冲上限为 60，完整输入、change file 和输出文件名可能超过限制。

将原版 CWEB 模块、boilerplate.w、gb_types.w 和 PROTOTYPES 逐字复制到私有生成目录的 `input/`，在该目录运行短相对名称：

```sh
CWEBINPUTS=input ctangle input/gb_flip.w input/PROTOTYPES/gb_flip.ch sgb_gb_flip.c
```

保持原 `.w/.ch` 文件不变，采用上游推荐的 change file 流程；独立生成与构建包装标明非 GraphBase 原始组成部分。不要直接编辑受许可保护的原始 CWEB 文件，或提交预生成的 C 文件替代该步骤。

本次官方 Conan 验证返回 0；四个原版测试程序通过，两份黄金输出逐字相同。六项安装消费者也通过，实际执行104次 CHECK。构建后的全部124个原版文件逐字未变。执行环境为 OHOS7 Beta/AArch64 QEMU，不能当作正式OHOS6真机或远端CI证明。
