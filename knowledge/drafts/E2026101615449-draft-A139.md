# E2026101615449: 源内 PEP517 后端的自举入口与 bootstrap 安装目录契约

在既有Python源码自举规则上补充源内PEP517后端的双入口契约：先核对requires=[]、backend-path=["."]与flit_core.buildapi，直接用官方python -m flit_core.wheel生成自身wheel，再使用同一发布源bootstrap_install.py并显式传--installdir到Conan包内；该安装器默认目的地来自当前解释器sysconfig.purelib，不能靠Conan包目录自动改变默认值。安装前校验归档成员，安装后逐项匹配官方模块字节，并以安装后端构建wheel、sdist和editable产物验证完整元数据及RECORD。

## 来源与实际行为

官方FlitCore4.1.0发布源pyproject.toml同时声明空build-system.requires、flit_core.buildapi与backend-path=["."]，project.dependencies也为空。bootstrap_install.py明确用于不依赖其他打包工具的自举，默认installdir取运行解释器sysconfig.get_path('purelib')，另提供--installdir参数。配方实际执行官方wheel入口与官方安装器并传入Conan私有包目录，保留模块、dist-info及原始测试。这里记录发布源的可核实契约和实际成功路径，未实测的循环依赖失败不作为证据。

## 可复用步骤

1. 先联合读取build-system.requires、build-backend和backend-path，确认后端确在发布源内；普通外部后端仍需真实依赖。
2. 使用实际目标Python在官方源码根执行python -B -m flit_core.wheel。不得将依赖Wheel的构建前端作为FlitCore自身的必需前置。
3. 验证wheel成员唯一、相对路径和类型，再执行官方bootstrap_install.py <wheel> --installdir <actual-Conan-package-site>；默认sysconfig目录必须作为共享解释器边界单独核对。
4. 逐项比较安装13个官方Python文件与源字节，保留发行元数据；安装后端再实际生成并检查wheel RECORD、真实sdist及PEP660 editable路径。
