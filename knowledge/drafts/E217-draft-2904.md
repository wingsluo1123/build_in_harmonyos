# E217: HMDFS 下脚本 Shebang 无法被内核 execve

## 错误特征
```
/data/service/hnp/bin/bash: /storage/.../aclocal: /data/.../perl: bad interpreter: Permission denied
Can't exec "aclocal": Permission denied
posix_spawn: Permission denied
```

## 触发条件
- 构建系统: autotools（aclocal, automake, autoconf, libtoolize）
- 阶段: configuration（autogen/configure 阶段）
- 平台: HarmonyOS，工具安装在 /storage/ 文件系统下

## 根因分析
HarmonyOS HMDFS 文件系统（挂载在 /storage/）下的脚本文件，其 shebang 行（如 `#!/data/service/hnp/bin/perl`）无法被内核 `execve()` 识别。即使 shebang 指向的 `/data/` 路径有效，内核仍拒绝从 /storage/ 执行脚本。Python 的 `posix_spawn()` 和 Perl 的 `exec()` 同样受此限制。

受影响工具：aclocal（perl 脚本）、automake（perl 脚本）、libtoolize（shell 脚本）、mpicc wrapper（shell 脚本）等所有通过 shebang 执行的脚本。

## 解决方案

### 推荐方案
显式通过解释器二进制调用脚本：
- Perl 脚本：`perl /path/to/aclocal --force`
- Shell 脚本：`bash /path/to/libtoolize --copy --force`

对 autotools 工具链还需设置环境变量：
```bash
AUTOM4TE=/path/to/autom4te AUTOCONF=/path/to/autoconf PERL5LIB=/path/to/autoconf/share
```

对 mpicc wrapper：跳过 wrapper，直接使用 `CC=clang` + `CFLAGS=-I<mpi_inc>` + `LDFLAGS=-L<mpi_lib> -lmpi` 传递 MPI 路径。

### 禁止做法
- ❌ 修改脚本 shebang 行（治标不治本，其他 /storage/ 脚本仍有问题）
- ❌ 复制脚本到 /data/ 执行（失去相对路径引用）
- ❌ 使用 `sh -c "tool"`（仍会触发 execve shebang 解析）

## 验证
```bash
# 验证 perl 脚本可通过显式调用执行
python3 -c "import subprocess; r=subprocess.run(['/data/service/hnp/bin/perl', '/storage/.../aclocal', '--version'], capture_output=True); print(r.stdout.split(chr(10))[0])"
```
