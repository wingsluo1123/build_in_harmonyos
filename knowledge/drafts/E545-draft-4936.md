# E545 — Conan AutotoolsToolchain 丢弃自定义 CPPFLAGS 且不注入依赖 include

## 错误特征

依赖头文件在 configure 阶段被硬校验拦下，看起来像"依赖没装好"：

```
checking for fst/fst.h... no
configure: error: fst/fst.h header not found
```

```
fatal error: 'fst/fst.h' file not found
```

根因的取证指纹是 toolchain 生成文件里 CPPFLAGS 只剩 `-DNDEBUG`：

```
$ grep '^export CPPFLAGS' build-release/conanautotoolstoolchain.sh
export CPPFLAGS="${CPPFLAGS:-}${CPPFLAGS:+ }-DNDEBUG"
```

## 触发条件

- 构建系统: autotools（Conan `AutotoolsToolchain`）
- 阶段: configure
- 前置: 依赖的 `includedirs` 不在编译器默认搜索路径（conan 依赖包都是这种情况）

## 根因分析

Conan 2 的 `AutotoolsToolchain.generate()` 会自己拼装 `conanautotoolstoolchain.sh`，
**CPPFLAGS 由它整段重写**——只写它自己产生的 `-D` 宏（如 `-DNDEBUG`）。配方里用
`environment().define("CPPFLAGS", "… -I<dep>")` 写入的自定义内容会被覆盖丢弃，
不报错、不警告，纯静默失效。

同时 toolchain **不会**把依赖包的 `includedirs`/`libdirs` 自动接到编译/链接行上
（另一路 `AutotoolsDeps` 会把依赖写进 `LIBS`/`CPPFLAGS`，但那会引发 E467：
autoconf 最早的 `AC_PROG_CC` 探测就带着整条依赖闭包去链接 conftest）。

于是依赖头文件既没被注入、又不在默认搜索路径里，configure 的
`AC_CHECK_HEADER([...], [], [AC_MSG_ERROR([...])])` 逐个失败并中止。

**实测取证**（`tmp/envprobe/conanfile.py` 探针：空配方只放三种指令，看落盘结果）：

| 通道 | 生成文件里的结果 |
|---|---|
| `extra_cflags` | `CFLAGS` = `… -O3 -I/PROBE-CFLAGS` ✅ 生效 |
| `extra_cxxflags` | `CXXFLAGS` = `… -stdlib=libc++ -std=c++17 -O3 -I/PROBE-CXXFLAGS` ✅ 生效 |
| `environment().define("CPPFLAGS", …)` | `CPPFLAGS` = `-DNDEBUG`（自定义 `-I/PROBE-CPPFLAGS` 消失）❌ 被覆盖 |

## 解决方案

### 推荐方案

在 `generate()` 中走 `AutotoolsToolchain` 的 `extra_*` 通道：

```python
tc = AutotoolsToolchain(self)
tc.extra_cflags.append(f"-I{fst_include}")      # 依赖 includedir
tc.extra_cxxflags.append(f"-I{fst_include}")
tc.extra_ldflags.append(f"-L{static_dir}")      # build_folder 内私有静态库目录
tc.generate()
```

`extra_cflags`/`extra_cxxflags`/`extra_ldflags` 由 toolchain 以
`${CFLAGS:-}${CFLAGS:+ }…` 形式**追加**，不与 toolchain 自身标志冲突；
`extra_ldflags` 落在 `LDFLAGS` 前段，是链接行上第一个 `-L`。

### 禁止做法

- ❌ `environment().define("CPPFLAGS", …)` —— 被 toolchain 整段覆盖，写了等于没写
- ❌ `ac_cv_prog_cc_works=yes` 之类的预置缓存变量 —— 只是盖住告警，依赖并未真的接上，
  失败点被推到编译期且更难定位
- ❌ 注入共享系统前缀（`/usr/local` 等）—— 见 E524

## 验证

```bash
# 1) 根因确认：生成文件里没有自定义 -I
grep -n '^export CPPFLAGS' <build_folder>/conanautotoolstoolchain.sh

# 2) 修复确认：include 进了 CFLAGS/CXXFLAGS，configure 通过
grep -n '^export CXXFLAGS' <build_folder>/conanautotoolstoolchain.sh
./configure --prefix=$DEFAULT_PREFIX && echo CFG_RC=$?
```
