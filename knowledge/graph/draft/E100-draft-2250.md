# E100: HMDFS config.status umask 077 导致临时文件创建失败

## 问题描述

在 HMDFS（鸿蒙分布式文件系统）上编译 Autotools 项目时，configure/config.status 脚本中的 `umask 077` 导致临时文件创建失败。

## 根因

1. **umask 077 限制**: config.status 使用 `(umask 077 && mktemp -d "./confXXXXXX")` 创建临时目录。在 HMDFS 上，0700 权限目录中的文件创建被拒绝（Permission denied），即使当前用户是目录所有者。

2. **GNU coreutils stdin 管道限制**: GNU cat 和 GNU sort 无法在 HMDFS 上处理 stdin→stdout 管道操作。`echo "test" | sort` 和 `echo "test" | cat` 都会报 Permission denied。但 `/bin/cat`（toybox）可以正常工作。

## 解决方案

1. **移除 umask 077**: 在 configure 脚本中将 `(umask 077 && mktemp -d "./confXXXXXX")` 改为 `(mktemp -d "./confXXXXXX")`，将 `(umask 077 && mkdir "$tmp")` 改为 `(mkdir "$tmp")`。

2. **替代 GNU cat/sort**:
   - `cat`: 创建 symlink `~/usr/local/bin/cat → /bin/cat`（toybox 版本）
   - `sort`: 创建 wrapper 将 stdin 写入临时文件后用真实 sort 处理

## 影响范围

所有使用 Autotools 构建系统的项目在 HMDFS 上编译都会遇到此问题。
